## フリック漢字(`kanken/`。けいくん 2026-10-16「フリック漢字検定を作成したい / 書き取り機能は付けれる？」→ 名前「フリック漢字」・書き取り「はじめから C」・範囲「漢字検定1級レベルにアップしてください」・並び「国語のすぐあと」。まとめは `docs/フリック漢字検定-はじめかた.md`)

- ⚠️⚠️ **「漢字検定」「漢検」は (公財)日本漢字能力検定協会の 登録商標**(協会の 受検案内に 表示。2026-10-16 に 確かめた)。**画面・ことばの ファイルに 書かない**。「1級」「準1級」「2級」の 字も 書かない(`tools/kanken/terms_js.py` の `BAN` が 止める)。
  むずかしさは **🐣 小1 〜 🍀 小6 → 🎒 中学 → 🌱 常用(常用漢字 2136字・高校卒業 程度)→ 🔥 表外(約3000字)→ 🐉 最難関(約6000字)の めやす** と 言う。ページの 下に「漢字の 検定を 行う 団体とは 関係ありません」
- 旅は 8つ + 🏆 マスター(各 90語 = 30/30/30。ぜんぶで 720語): 📖 読み `knyomi` / ✍️ 書き取り `knkaki` / 🧩 部首 `knbushu` / ✏️ 送りがな `knokuri` / 🔗 熟語の構成 `knjukugo`(5つの 型を 打つ。ホームに 型の 図)/ 🀄 四字熟語 `knyoji` / ⇔ 対義語・類義語 `kntaigi`(「楽観 ⇔ ？」の 答えの 読みを 打つ)/ 🔄 同音・誤字 `kndoon`
- ⭐⭐ **書き取り(`knkaki`)と 同音・同訓・誤字(`kndoon`)は 指で 書く。機械が 1画ずつ 自動で ◯×**(けいくん「はじめから C」)。しくみは `kanken/kanken.js` の `PAD`:
  ・字の 形 = **KanjiVG**(© Ulrich Apel・**CC BY-SA 3.0**。2026-09-30 の 版)。`tools/kanken/strokes.py` が **使う 字だけ** 取り出して `kanken/strokes.js` に する(1画ごとに 線 d と 線の 上の 16点)。あたまに ライセンスを 書いた。ゲームの 下(rule)にも 出どころを 書いた
  ・KanjiVG は 入れものに 入れていない。作りなおす ときは `GIT_LFS_SKIP_SMUDGE=1 git clone --depth 1 https://github.com/KanjiVG/kanjivg /home/user/kanjivg/kanjivg` → `python3 tools/kanken/strokes.py`
  ・判定: **1画 書くたびに 書き順どおりの つぎの 1画と くらべる**(場所・形(16点)・長さ・向き・線を 4つに 分けた 曲がりかた)。2画 合格したら 書いた 人の 大きさ・場所の くせを 合わせる。合えば お手本の 線に、ちがえば 赤く 消えて まちがい 1回(`qMiss`)。2回 つづけて まちがえると つぎの 1画が うすく 見える。💡 ヒントも ある(まちがい 1回)
  ・**👀 答え**(けいくん 2026-10-16「書き取り問題に答えボタンを作成して 書き取り欄に答えと書き順を表示」): おすと 書くマスに その 字の 全画が うすい 赤で 1画ずつ のびて 出て、書きはじめに 書き順の 番号。見たら まちがい 1回(1問に 1回だけ。もう一度 おすと アニメだけ 見なおせる)。上から なぞって 書けば そのまま 進める(`PAD` の `show` / `play()`)
  ・書く 問題では 入力欄を かくす(`body.kk-writing`。キーボードを 出さない)。打っても 進まない(`retarget` が `\u0000`)
  ・🏆 マスターは **打つ 6つの 旅だけ**(書く 旅を まぜると キーボードが 出たり 消えたり するため)
  ・図鑑では その 字の **書き順アニメ**(おすと もう一度)
  ・⚠️ 書いた 線は どこにも 送らない(外の 手書き認識サービスは 使わない)
  ・⭐ **短い 線(お手本で 12〜22)は 長さの 下限を 見ない**(けいくん 2026-10-24「学」の 4画め(冖の 左の 点)が「何回書いても合格しない」)。
    お手本は 長さ 17 だが、指では 点のように 短く 書く 人が 多く「お手本の 35%未満」で はねていた。書いた 線が お手本の 半分より 短い ときは
    向きが 逆で なければ 通す(5より 短ければ 場所だけ)。くせの 合わせ(acc)には 入れない。長く 書いた ときは いままでどおり ぜんぶ 見る。
    確かめかた: scratchpad の `gaku2.mjs`(学の 4画めを 点・短い・右・ななめ・逆向き で 書く。逆向きだけ ×)
  ・⭐ **くせを 合わせた 線で ちがっても、書いた そのままの 線で もう一度 くらべる**(けいくん 2026-11-10「願」の「3画目が反応しない / こういうのが他にもあるか確認してすべて修正」)。
    はじめの 2画を お手本と ちがう 大きさ・場所に 書くと 3画めから くせの 合わせ(`fit`)が かかり、そのあと 💡 ヒント・👀 答えの うすい 線を なぞっても、なぞった 線が ずらされて 何回 書いても × だった。
    ぜんぶの 字(2231字)で 試すと、はじめの 2画を ずらして 書いた あと お手本を なぞって 止まるのが **13%(1919字。ほとんど 3画め)→ 0**。ちがう 字を 書いた ときに 止まる 早さは 変わらない。⚠️ `judge()` の 2回めの `match` を 消さない
  ・⭐ **👀 答えの 書き順の 番号は いちばん 上に かく・かさならない 場所に ずらす**(同じ日)。前は 書いた 線の 下に かくれ(願の 3・4)、書きはじめが 同じ 画は 番号が かさなっていた(1・2 / 13・14)。
    場所は `labelPos()`(図鑑の 書き順アニメも 同じ)。もう 書いた 画の 番号は 出さない・つぎの 1画の 番号は 大きく こく
  ・確かめかた: `python3 -m http.server 8765` → `node tools/kanken/kaki-test.mjs 390`(お手本を なぞって ぜんぶの ステージを 通す・小さく ずらして 書いても 通る・逆向きは まちがい・画面が 動かない)。2026-10-16 に 390px・320px で 通した。ちがう 字を 書くと 1〜4画で × に なる(「叩」に「叶」も 4画めで ×)
  ・⚠️ 1回で ぜんぶ 通すと 15分を こえる。旅ごとに: `node tools/kanken/kaki-test.mjs 390 kndoon`(ステージごとに 進みを 出す)
  ・⚠️ `play-all.mjs` / `click-all.mjs` では knkaki・kndoon が「すすまない」と 出る。打っても 進まない 作りなので それで 正しい(書く テストは kaki-test.mjs)
  ・⚠️ **本当の 指の 書き心地は けいくんの iPhone で 見てもらう**(きびしすぎ / あますぎ は そこで 直す。ゆるめる ところは `judge()` の 数字)
- ⭐ **小学1年生の 漢字から**(けいくん 2026-10-16「小学1年生の漢字から対応してほしい！」)。むずかしさは **10段**(dv1〜6 = 小1〜小6 / dv7 = 中学 / dv8〜10 = 常用・表外・最難関。前の 1〜3 は 8〜10 に 番号を ずらした)

  ・⭐ **書き順の データは 学年ごとに 分けて あとから 読む**(2231字・5.8MB を 17こ。`kanken/strokes/<組>.js`。中学は 135字ずつ 7a〜7h)。
    `kanken/strokes.js` は 字 → 組 の 一覧だけ(5KB)。`kanken.js` の `needStrokes` が そのステージの 字の 組を 読む(`makeQs` で 先に 読みはじめ、マスは 読み終わってから)。

  ・⚠️ 中学の 字には やさしい 語の 無い 字が ある(拉致・拷問・誘拐・賄賂・訃報・詐欺・窃盗・逮捕・焼酎・賭ける・淫雨 など)。こわくない 場面に して 入れてある(けいくん決定 2026-10-16「1」= このまま 入れる。常用漢字なので 外すと 検定の 勉強に 穴が あく)。⚠️ よかれと 思って 外さない
