## A. 試験

## B. 安衛法の 安全衛生管理体制(現行の 条文)

### B-1. 総括安全衛生管理者(法10条・令2条・則2〜3条の2)
| 事実 | 出どころ |
|---|---|
| 選任が 要る 規模(常時 使用する 労働者数): **①林業・鉱業・建設業・運送業・清掃業 = 100人以上** / **②製造業(物の加工業を含む)・電気業・ガス業・熱供給業・水道業・通信業・各種商品卸売業・家具等卸売業・各種商品小売業・家具等小売業・燃料小売業・旅館業・ゴルフ場業・自動車整備業・機械修理業 = 300人以上** / **③その他の 業種 = 1,000人以上** | 令2条(e-Gov) |
| **その事業場で 事業の 実施を 統括管理する 者**を あてる(法10条2項)。資格・免許は 不要 | 法10条 |
| 統括管理する 業務: 危険・健康障害の 防止 / 安全衛生教育 / 健康診断 など 健康の 保持増進 / 労働災害の 原因調査と 再発防止 / 省令で 定めるもの(安全衛生方針の 表明・リスクアセスメント・安全衛生計画の 作成〜改善 = 則3条の2) | 法10条1項・則3条の2 |
| 選任は 事由が 生じた日から **14日以内**。選任したら **遅滞なく 所轄労働基準監督署長に 報告**(電子) | 則2条 |
| 旅行・疾病・事故 などで 職務が できないときは **代理者**を 選任 | 則3条 |
| **都道府県労働局長**は 業務の 執行について 事業者に **勧告**できる(法10条3項)。⚠️ 安全管理者・衛生管理者の「増員・解任の 命令」は **労働基準監督署長**(法11条2項・12条2項) | 法10〜12条 |

### B-2. 衛生管理者(法12条・令4条・則7〜12条)
| 事実 | 出どころ |
|---|---|
| 選任が 要る 規模: **常時 50人以上**(業種を 問わない) | 令4条 |
| **選任数**: **50〜200人 = 1人 / 200人超〜500人 = 2人 / 500人超〜1,000人 = 3人 / 1,000人超〜2,000人 = 4人 / 2,000人超〜3,000人 = 5人 / 3,000人超 = 6人** | 則7条1項4号 |
| 選任は **14日以内**。**その事業場に 専属**の 者(2人以上 選任するとき、労働衛生コンサルタントが いれば そのうち **1人**は 専属で なくてよい) | 則7条1項1〜2号 |
| **第一種免許(または 衛生工学免許)が 要る 業種**: **農林畜水産業・鉱業・建設業・製造業(物の加工業を含む)・電気業・ガス業・水道業・熱供給業・運送業・自動車整備業・機械修理業・医療業・清掃業**。**その他の 業種**は 第二種免許でも よい | 則7条1項3号 |
| 免許の ほかに 衛生管理者に なれる 資格: **医師・歯科医師・労働衛生コンサルタント**・厚生労働大臣の 定める者 | 則10条 |
| **専任**の 衛生管理者が 要る(少なくとも 1人): **①常時 1,000人超** / **②常時 500人超 で、坑内労働 または 労基則18条の 有害業務(多量の 高熱物体・低温物体、有害放射線、粉じん、異常気圧、振動、重量物、強烈な騒音、坑内、深夜業を含む業務、有害物の 取扱い・ガス等の 発散場所、病原体 など)に 常時 30人以上** | 則7条1項5号 |
| **衛生工学衛生管理者免許**の 者を 1人 選任: **常時 500人超 で、坑内労働 または 労基則18条の 1号・3〜5号・9号の 業務(多量の 高熱物体・著しく暑熱 / 有害放射線 / 粉じん / 異常気圧 / 有害物の ガス・蒸気・粉じんの 発散場所)に 常時 30人以上**。その人に 衛生工学に 関する 事項を 管理させる | 則7条1項6号・則12条 |
| **定期巡視: 少なくとも 毎週1回**。有害の おそれが あれば 直ちに 措置。事業者は 衛生に 関する 措置を なし得る **権限**を 与える | 則11条 |
| 選任したら **遅滞なく 所轄労働基準監督署長に 報告**。代理者の 規定(則3条)は 衛生管理者にも 準用 | 則7条2〜3項 |

### B-3. 安全衛生推進者・衛生推進者(法12条の2・則12条の2〜4)
| 事実 | 出どころ |
|---|---|
| 規模: **常時 10人以上 50人未満**。安全管理者の 選任が 要る 業種(令2条1号・2号)なら **安全衛生推進者**、それ以外の 業種は **衛生推進者**(衛生に 係る 業務だけ) | 法12条の2・則12条の2 |
| **14日以内**に 選任。原則 **専属**(労働安全・労働衛生コンサルタント などは 例外)。都道府県労働局長の 登録を 受けた 者が 行う **講習の 修了者** など | 則12条の3 |
| ⚠️ 監督署への **報告は 不要**。かわりに **氏名を 作業場の 見やすい 箇所に 掲示** するなどで 周知 | 則12条の4 |

### B-4. 産業医(法13条・令5条・則13〜15条)
| 事実 | 出どころ |
|---|---|
| 規模: **常時 50人以上**(業種を 問わない)。**医師**のうちから 選任。50人未満は 医師等に 健康管理を 行わせる **努力義務**(法13条の2) | 令5条・法13条・13条の2 |
| **14日以内**に 選任。**選任できない 人**: 法人の 代表者 / 事業を 営む 個人 / 事業の 実施を 統括管理する 者 | 則13条1項1〜2号 |
| **専属**が 要る: **常時 1,000人以上** または **一定の 有害業務(多量の 高熱物体・低温物体、有害放射線、粉じん、異常気圧、振動、重量物、強烈な騒音、坑内、**深夜業を 含む 業務**、有害物 など)に 常時 500人以上** | 則13条1項3号 |
| **常時 3,000人超 → 2人以上** | 則13条1項4号 |
| 産業医の 要件: 厚労大臣の 指定する 者の 研修 修了 / 産業医科大学 など の 課程 / 労働衛生コンサルタント(保健衛生) / 大学で 労働衛生の 科目を 担当する 教授・准教授・常勤講師 など | 法13条2項・則14条2項 |
| 職務: 健康診断・面接指導・ストレスチェックの 実施と 事後措置 / 作業環境の 維持管理 / 作業の 管理 / 健康管理 / 健康教育・健康相談 / 衛生教育 / 健康障害の 原因調査・再発防止 | 則14条1項 |
