## 2. はじめに けいくんに 聞く 5つ(保育士・看護師・ゲームクリエイターと 同じ 形。「全部おすすめで」と 返ってくる ことが 多い)
1. **名前**: 「フリック医師」で よいか(絵が 届いたら 絵の 題名に そろえる。フォルダ名 `ishi` は 変えない)
2. **旅の 分けかた**(おすすめ 7つ + 🏆 マスター):
   🩺 診察のことば(問診・視診・聴診 …)/ 🔬 検査のことば(血液検査・レントゲン・CT・MRI・心電図 …)/
   💊 治療とくすりのことば(処方・点滴・手術・リハビリ … **名前と 目的だけ**)/ 🏥 診療科と専門(内科・外科・小児科・救急 …)/
   🧬 からだと病気のしくみ(炎症・感染症・生活習慣病 … からだ旅行・看護師と 同じ 語も 復習として 入れて よい)/
   🌍 公衆衛生と予防(検診・予防・感染症法・保健所 …)/ ⚖️ 医師の制度と倫理(医師法・インフォームドコンセント・守秘義務・チーム医療 …)
3. **むずかしさの 3段**: 入門(病院で 聞く ことば)→ 中級(**医師国家試験の 必修・一般の 範囲の めやす**)→ 上級(専門・制度の こまかい ところ)
4. **1語に 持たせる 科目**(`field`): 医師国家試験の 出題基準の 大きな 分け(たとえば 必修の基本的事項 / 医学総論 / 医学各論 / 公衆衛生 …)。**確かめてから 決める**(下の 4)
5. **入れない もの**: 薬の 量・処置の 手順・診断の 決めうち・こわい 病名の ならび(看護師と 同じ)。課金などは 関係なし

## 3. ⚠️⚠️⚠️ ぜったいの 決まり(看護師の PROMPT.md と 同じ。医師は なおさら)
- **医療の やりかたを 書かない**: 薬の 量・投与の しかた・手術の 手順・「この しょうじょうなら この 病気」「こういう ときは こうする」・正常値の 数字・薬の 商品名。**名前と 目的だけ**
- **小学生も あそぶ**: 血・苦しむ ようす・死ぬ ようす・こわい 先を 書かない。病気は「何が 起きている 状態か」+「お医者さんが 助ける」だけ。
  めずらしい 病気・こわい 病名の ならびは 入れない。**迷ったら 入れない**
- ✅ **からだ旅行・看護師と 同じ 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。
  看護師の ときの「かぶらせない」の 決まりは **医師では 使わない**。`terms_js.py` を 写すとき、`karada-words.txt` と 看護師の 語で 止める ところは **外す**。
  ただし 説明は **医師の 目線**で 書きなおす(看護師の 文を そのまま 写さない)
- **読み(ひらがな)は 医師の 7つの 旅の 中では かぶらない**(ほかの ゲームとは かぶって よい)
- 画面(ホームの 下・遊びかた)に「これは ことばを おぼえる ゲームです。本当に 具合が わるい ときは、大人に 言って お医者さんへ」「厚生労働省とは 関係ありません」
- **作った 助手とは 別の 助手が 1語ずつ 確かめる**(意味・読み・やりかたを 書いていないか・こわくないか)。ふりがなも 全語 見る(`tools/ruby_fix.json`)

## 4. 試験の 事実は **その日に 厚生労働省の ページで 確かめてから** 書く
`meta.json` の `exam` に 確かめた 日を つける。書く 中身(すべて 確かめる。**記憶で 書かない**):
医師は 国家資格(医師法・厚生労働大臣の 免許)/ なりかた(医学部 6年 → 医師国家試験 → 臨床研修 2年)/ 試験は 年 1回・2月(第◯回の 日づけ)/
問題の 区分(必修・医学総論・医学各論 など)と 合格の 決まり(必修は 8割 など)/ 出題基準の 版(令和◯年版)と 大きな 科目の 分け /
禁忌肢の しくみ(**あるなら 名前だけ**。中身は 書かない)

## 5. 作りかたの 手順(看護師の ときと 同じ)
1. けいくんに 2 の 5つを 聞く → 返事を CLAUDE.md に 書く
2. `tools/ishi/PROMPT.md` `meta.json` を 作る → 旅ごとに 助手に 70語ずつ 頼む(`PROMPT.md` を そのまま わたす)→ `terms-<旅>.json`
3. `terms_js.py` で 止められた 語を 直す → 別の 助手が 1語ずつ 確かめる → ふりがな
4. `ishi/ishi.js`(kango.js を 写す)・`build_games.py`・`index.html` の SERIES → `python3 tools/build_games.py`
5. 手元で 通す: `python3 -m http.server 8765` → `node tools/play-all.mjs`(4とおりの 打ちかた)/ `node tools/click-all.mjs`(W=320 も)
6. PR は **rebase で 取りこむ**(この 入れもの)。speed-king は squash。コミットの 末尾は Co-Authored-By と Claude-Session の 2行
7. かずとも `speed-king`: `FLICK_MODES` / `FLICK_LINK_TARGETS` に `ishi`(PR → squash)。`HOME_GAMES` は 絵と OK の あと
8. けいくんに ChatGPT で 絵を 頼む 文を わたす(トップ 1536×1024 + 四角い 絵 1254px。**人物は 画面の 下 3分の1に 小さく**・指5本・首が 見える。
   絵の 中の 字は「フリック医師」だけ・ゲームに 無い 機能の 絵を 入れない)。届いたら **まず 字を 切り出して 読む**(「ごっかしけん」の 前例)
9. 絵を 入れたら CLAUDE.md に 節を 書く(名前・旅・語数・確かめた 日・入れなかった 語と 理由)

## 6. 気をつける 前例
- 看護師で 統合失調症 → 適応障害に 入れかえた(子どもが こわく 感じる)。医師でも 同じ 目で 見る
- 読みの かぶり(声かけ・既往歴 …)は 片方を べつの 語に
- 絵は 1回目・2回目とも 字が ちがった → 絵の 中で 直した(`tools/kango/fix_text.py`)
- マイページ(右上の 1枚)は 土台の `index.html` に あるので、ゲームを 足すと 自動で 出る。`SERIES` に 足すだけで 一覧の タイルにも 出る(絵は `ishi/apple-touch-icon.png`)
