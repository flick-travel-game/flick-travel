## フリック救急隊員(`kyukyutai/`。けいくん 2026-10-03「救急隊員の専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」・重い ことば(心肺停止・大量出血・多数傷病者)は「事実だけ おだやかに 入れる」。まとめは `docs/フリック救急隊員-はじめかた.md`)

- 名前は「フリック救急隊員」(絵が 届いたら 題名に そろえる。フォルダ名 `kyukyutai` は 変えない。`kyukyu` は 消防士の 旅の id なので 使わない)。シリーズの 絵文字は 🚑。`SERIES_ORDER` は 消防士の となり
- 旅は 7つ(救急のきほん `kihon`・救命の手当て `kyumei`・からだを見る `kansatsu`・けがと病気 `byoki`・現場から病院へ `hansou`・救急車と資器材 `kikai`・救急のしくみと法律 `shikumi`)+ マスター。
  **旅ごとに 70語(入門20・中級25・上級25)= 490語**。かずともの 旅の 名前は **`qq` で はじめる**(qqkihon / qqkyumei / qqkansatsu / qqbyoki / qqhansou / qqkikai / qqshikumi / qqmas)
- むずかしさは 3段: 入門(くらし・救命講習の ことば)→ 中級(**消防学校の 救急課程(救急隊員の 資格)の めやす**)→ 上級(**救急救命士 国家試験の 範囲の めやす**)。
  1語ごとに **試験の 科目**(`field` → 📘 試験の 科目)。救急救命士 国家試験の 5科目: 基礎医学 / 臨床救急医学総論 / 臓器器官別臨床医学 / 病態別臨床医学 / 特殊病態別臨床医学
- ことばは `tools/kyukyutai/terms-<旅>.json`(決まりは `tools/kyukyutai/PROMPT.md`)→ `tools/kyukyutai/terms_js.py` → `kyukyutai/terms.js` + `data/kyukyutai.json`。
  しくみは `kyukyutai/kyukyutai.js`(消防士を 写した。4択クイズ あり)。しくみ図は コードで 描く 箱の 図 7つ(**119番から 病院までの 流れ**・**救命の連鎖**・**からだを 見る 図**・けがと 病気・現場から 病院へ・**救急車の 中の 図**・救急の しくみ。`tools/kyukyutai/mkmeta.py`)。ホームでは たたんで ある
- 資格の いまの形は `tools/kyukyutai/exam.txt`(→ meta.json の `exam`)に **確かめた日つき**(2026年10月2日に 厚生労働省「第50回救急救命士国家試験の施行」(令和8年9月1日)・第49回の 合格発表・消防白書で 確かめた):
  救急隊員 = 消防職員で 救急業務に関する講習(救急科。標準 250時間)を 修了 / 救急救命士 = 国家資格(救急救命士法 1991年・厚生労働大臣の 免許)/ なりかたは 養成校で 2年 以上 か、消防で 5年(または 2,000時間)救急業務の あと 養成所で 6か月 以上 → 国家試験 /
  第49回 2026年3月8日・第50回 2027年3月14日(事務は 日本救急医療財団)/ 試験科目 5つ / 特定行為 = 施行規則の 一覧(器具の 気道確保・静脈路確保と 輸液・アドレナリン・心肺機能停止前の 輸液・ブドウ糖)。
  ⚠️ **血糖測定は 特定行為では ない**(救急救命処置の ひとつ)。⚠️ 文を 直すときは その日に 確かめて `exam` の 日付も 上げる
- ⚠️⚠️⚠️ **手当て・処置の やりかたを 書かない**(胸骨圧迫の 深さ・回数・速さ / 止血・AED の 手順 / 薬の 量 / 正常値・JCS の 点の 中身 / 診断の 決めうち / 行動の 指示)。**名前と「何の ための 手当て・しくみか」「救急隊が どう 見て、病院へ つなぐか」だけ**。
  手当ての 説明には「やりかたは 救命講習で 習います」。画面に「手当ての やりかたは 消防署の 救命講習で 習おう」「からだの ぐあいが わるい ときは おうちの 人に 知らせて、こまったら 119番や #7119 に 相談」「総務省消防庁・厚生労働省・市町村の 消防とは 関係ありません」
- ⚠️⚠️ **小学生も あそぶ**: 心肺停止は「心臓と 呼吸が 止まった 状態」と 事実だけ。多数傷病者事故は「トリアージで 順番を 決めて 助ける」。トリアージの 黒の 意味・くも膜下出血・DNAR・死戦期呼吸(「ふだんどおりの呼吸」に 言いかえ)は 入れていない。
  `terms_js.py` の `BAN` が こわい ことば(死・殺・脳死 …)・回数や 深さ・mg / mL・%・mmHg の 数字を 止める(⚠️「殺」で 殺菌も 止まる。消毒・除菌と 書く)
- **実在の 団体の 名前は 入れない**(救急振興財団 → 養成所・JPTEC は 入れなかった)。役所(厚生労働省・消防庁 など)は よい
- ✅ 消防士・医師・看護師 など ほかの ゲームと 同じ 語を 入れて よい(説明は 救急隊員の 目線)。読みは **救急隊員の 7つの 旅の 中で** かぶらない(`terms_js.py` が 止める)。
  はじめ フェイスシールドが 救命と 資器材で かぶったので、救命の ほうを「感染防護具」に した。AED は 救命の 旅・資器材の 旅は 除細動器 / 自動体外式除細動器
