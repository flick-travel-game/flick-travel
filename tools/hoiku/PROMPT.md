# フリック保育士: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
しくみ図の どこに あるか(📍)が 出る。あそぶのは **小学生〜保育士を めざす 学生・大人**。
**保育の ことばと しくみを おぼえる ゲーム**(試験の 問題集では ない)。

## ⚠️⚠️ この ゲームだけの いちばん 大事な 注意 — **小学生も あそぶ**

保育士の 勉強には つらい 話も 入る。**そのままの 言いかたに しない**。

- **入れてよい**: 「こまっている 子どもや おうちの 人を 助ける しくみ」として、**事実だけを やさしく**
  (例: 児童相談所 = こまっている 子どもや おうちの 人の 相談に のる ところ)
- **書かない**: むごい ようす・けがや 体の ようす・数の 多さで こわがらせる 書きかた・
  「あなたの まわりにも ある」と 思わせる 書きかた・親を せめる 書きかた
- **SIDS(乳幼児突然死症候群)** は 保育士に 欠かせない ことばなので 入れる。ただし
  **「あおむけで ねかせる」「決まった 時間ごとに 見る」など 気をつける ことを おだやかに**。数や ようすで こわがらせない
- 読んだ 子が **自分は だいじょうぶだと 思える** 書きかたに する。迷ったら その 語を 入れない

## 1語の 形(JSON)

```json
{"id":"ha-aichaku","name":"愛着","reading":"あいちゃく","journey":"hattatsu","category":"心の育ち","difficulty":2,
 "subject":"保育の心理学","type":"concept","emoji":"🤱","mapNode":"kodomo:aichaku","relatedTerms":["ha-hitomishiri"],
 "description":"赤ちゃんと おうちの 人の あいだに できる 心の きずな。安心できる 人が いると、子どもは 外の 世界へ 出て いけます。",
 "example":"(なくてもよい)たとえば〜"}
```

- **id**: 旅の 頭 + `-` + 英小文字(`ha-` / `ho-` / `fu-` / `ke-` / `sh-` / `ji-`)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(漢字・カタカナ。保育の 現場の ふつうの 言いかた)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白は ダメ)。
  - カタカナ語は ひらがなに(あたっちめんと)
  - 英字の 略語は 日本の ふつうの 読み(SIDS → `えすあいでぃーえす` / PTSD → `ぴーてぃーえすでぃー`)
  - 数字は ひらがな(5領域 → `ごりょういき` / 3歳児 → `さんさいじ`)
  - ゆれる ことばは 1つに 決め、別の 読みは `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 長い 読みは 入れない**(子どもが 飽きる)。長い ことばは 短い 言いかたに する
    (例: ×「発達の最近接領域」→ ○「最近接領域」)。どうしても 長いものは **上級だけ**に、旅で 1〜2語まで
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級(下の「3段の 分けかた」)
- **subject**: 保育士試験の 筆記の 科目名。つぎの 9つの どれか(入門の 語でも いちばん 近い ものを 書く):
  `保育の心理学` `保育原理` `子ども家庭福祉` `社会福祉` `教育原理` `社会的養護` `子どもの保健` `子どもの食と栄養` `保育実習理論`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)。いっしょに おぼえると よい ことば
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / いつ・どこで 出てくるか / なぜ 大事か」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  専門用語を 専門用語だけで 説明しない
- **example**: なくてもよい(ある ときは 身近な たとえ 1文)

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | 保育の 現場の ことば。小学生でも 聞いた ことが ある / 絵が うかぶ(おひるね・えほん・きゅうしょく・はいはい) |
| 2 | 中級 | **保育士試験の 筆記の 範囲の めやす**。保育を 学ぶと 出てくる ことば(愛着・5領域・離乳食・感染症) |
| 3 | 上級 | こまかい 制度・法律・学説の めやす(児童福祉法・要保護児童対策地域協議会・最近接領域) |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる
(ならんだ 順が そのまま ステージの 順に なる)。

## 旅ごとに 入れる / 入れない(⚠️ **読みが かぶると 台本が 止まる**)

- **hattatsu**(育ち): 月齢ごとの 育ち・首すわり・はいはい・人見知り・愛着・喃語・一語文・イヤイヤ期・平行遊び・ごっこ遊び・
  自我・社会性・気質・心理学の 人(ピアジェ・エリクソン・ボウルビィ・ヴィゴツキー など)・発達検査の 考えかた。
  **入れない**: 保育所保育指針・5領域(hoiku)/ 病気・身体測定(hoken)
- **hoiku**(考えかた): 保育所保育指針・養護と 教育・5領域(健康・人間関係・環境・言葉・表現)・幼児期の終わりまでに育ってほしい姿・
  環境を通して行う保育・自発的な あそび・保育課程と 指導計画・週案・日案・保育記録・自己評価・園内研修・
  保育の 歴史の 人(フレーベル・モンテッソーリ・倉橋惣三・石井十次 など)・幼稚園教育要領。
  **入れない**: 心理学の 人(hattatsu)/ 手あそび・絵本の やりかた(jitsugi)
- **fukushi**(しくみ): 児童福祉法・こども基本法・児童の権利に関する条約・こども家庭庁・市区町村・児童相談所・家庭児童相談室・
  保育所・認定こども園・幼稚園・地域型保育(家庭的保育・小規模保育)・企業主導型保育・一時預かり・延長保育・病児保育・
  放課後児童クラブ・児童館・社会的養護(乳児院・児童養護施設・里親・特別養子縁組・ファミリーホーム)・自立支援・
  障がいのある 子の 支え(児童発達支援・保育所等訪問支援)・児童手当・保育の無償化・要保護児童対策地域協議会・
  児童福祉施設の設備及び運営に関する基準・保育士登録・守秘義務。
  ⚠️ つらい 話の 語(虐待・要保護児童 など)は **「助ける しくみ」として 事実だけ やさしく**。上の ⚠️⚠️ を 守る。
  **入れない**: 指針・5領域(hoiku)
- **hoken**(健康): 身体測定・カウプ指数・体温・発熱・かぜ・感染症(インフルエンザ・水痘・麻疹・手足口病・RSウイルス など)・
  出席停止・予防接種・定期接種・乳歯・むし歯・アトピー性皮膚炎・アナフィラキシー・熱性けいれん・脱水・熱中症・
  うつぶせ寝を さける こと・午睡チェック・SIDS・ヒヤリハット・応急手当の 考えかた・園医・学校保健安全法・健康診断。
  **入れない**: 食物アレルギーの 除去食・栄養素(shoku)。
  ⚠️ **手あての やりかた(どう 押す・どう 冷やす・薬の 使いかた)は 書かない**。「何に 気をつけるか」まで
- **shoku**(食と栄養): 母乳・育児用ミルク・調乳・離乳食・離乳の 完了・手づかみ食べ・幼児食・おやつ(間食)・
  5大栄養素・炭水化物・たんぱく質・脂質・ビタミン・ミネラル・鉄・カルシウム・食物繊維・食事摂取基準・
  給食・アレルギー対応食・特定原材料・誤えん・よくかむ こと・食育・共食・食事のあいさつ・栄養士・調理員・検食・食中毒。
  **入れない**: アトピー・アナフィラキシー(hoken)
- **jitsugi**(実技と現場): 手あそび・わらべうた・絵本・紙芝居・素話・パネルシアター・エプロンシアター・ペープサート・
  折り紙・のり・クレヨン・粘土・なぐり描き・見立て・リズムあそび・楽譜・拍子・音符・休符・ト音記号・移調・
  和音(コードは 少しだけ)・リトミック・鬼ごっこ・砂あそび・水あそび・散歩・連絡帳・おたより・個人面談・
  午睡・排せつの 自立・着がえ・行事(運動会・生活発表会・七夕 など)・保育実習・自己評価。
  ⚠️ **絵本や 童謡の 中身・歌詞は 書かない**(題名を 出すのも さける)。昔からの 手あそび(いとまきまき など)の 名前まで

## ぜったいに 守ること

- **自分の ことばで 書く**。過去問・問題集・参考書・保育所保育指針や 法律の **本文を 写さない**
  (指針・条文は「どんな ことが 書いてあるか」を やさしく 言いかえる)
- **手あての やりかた・処置の 手順を 書かない**。「本当の ときは 園の きまりと 大人の 指示に したがう」が この ゲームの 立ち位置
- **園の 名前・会社の 名前・商品名・絵本や 歌の 題名は 出さない**(商標・著作権)
- 数字(年齢の めやす・日数・人数の 基準)は **まちがいない ときだけ**。都道府県や 園で ちがう 数は 書かない。
  **「いつから 変わった」の 年は 書かない**(制度は 変わる)
- 学者の 説は **「〜と 考えた」** の 形に する。「こうすれば かならず こう 育つ」と 言いきらない
- 事実が あやしい 語は **入れない**(まちがいを 書くより 入れないほうが よい)
- ほかの 旅と **読みが かぶらない**(上の 入れる / 入れない を 守る)

## 出すもの

`tools/hoiku/terms-<旅id>.json` に JSON の 配列(70語)で 書く。書いたら
`python3 -c "import json;d=json.load(open('<file>'));print(len(d))"` で 読めるか 確かめる。
そのあと `python3 tools/hoiku/terms_js.py --check` で 形を 確かめる(まちがいが あれば 止まる)。
