## ⚠️⚠️⚠️ いちばん 大事な 決まり(さいしょに 読む)
1. **災害を こわく しない**。台風・大雨・竜巻・なだれ・高潮は「どう 起きるか」と「どう 身を 守るか」だけ。
   被害の ようす・亡くなった 人の 数・こわれた 家・流された 町・泣いている 人は 書かない。「早めに 逃げれば 守れる」の 向きで 終わる。
   「死」「遺体」「犠牲」「惨」「行方不明」「怪我」「流され」「こわい」「壊滅」「倒壊」の 字は **使わない**(`terms_js.py` が 止める)。
   歴史の 事実として「伊勢湾台風(1959年)を きっかけに 災害対策基本法が できた」の ように **しくみが 生まれた 理由**までは よい(被害の 数は 書かない)
2. **数字は「変わらない 自然の 決まり」だけ**。1気圧 ≒ 1013hPa・気温減率 およそ 6.5℃/km・乾燥断熱減率 およそ 10℃/km(9.8)・対流圏は およそ 11km まで(地域で ちがう) など 物理の 数は「およそ」を 付けて よい(確かな ものだけ)。
   ❌ 変わる 数字は 書かない: 地域ごとの 警報の 基準・いまの 気候の 記録・猛暑日の 日数・台風の 年間の 数・試験の 合格率

7. **事実は 確かめる**。人・年・制度は WebSearch で 確かめた ものだけ。あやしい ものは 書かない・入れない

## ゲームの かたち
「表示された ひらがなを フリックで 打ち写す」タイピング。打ち終わると 説明(1〜3文)が 出る。説明の 下に 📘 分野 と 📝 試験の 札。
4択クイズ(説明 → ことば)も ある。あそぶのは 小学生〜気象予報士を めざす 人

## 1語の 形(JSON)
{"id":"ta-oni","name":"温位","reading":"おんい","journey":"taiki","category":"熱力学","difficulty":3,"type":"concept",
 "emoji":"🌡","mapNode":"taiki:oni","field":"大気の熱力学","ruleset":"学科一般","relatedTerms":["ta-dannetsu","ta-soto"],
 "description":"空気を 1000hPa まで 乾燥断熱で 下ろした ときの 温度。上がり下がりしても 変わらないので、空気の かたまりの 目じるしに なります。"}
- id: 旅の 頭文字2つ + "-" + 英小文字(ki- / ta- / ri- / ge- / ka- / ni- / bo- / ho- / ji-)
- name: 画面に 出す 名前。⚠️ 900hPa のような 数字入りも よい(読みは ひらがな)
- reading: **ひらがなと ー だけ**。数字は ひらがな(850hPa → はっぴゃくごじゅうへくとぱすかる)。ゆれは "acceptedReadings":["よみ1","よみ2"](先頭は reading)。
  ⚠️ 読みまちがい注意: 渦度=うずど / 湿数=しっすう / 移流=いりゅう / 温位=おんい / 寒気=かんき / 暖気=だんき / 巻雲=けんうん / 雹=ひょう / 霰=あられ / 霙=みぞれ / 靄=もや / 凪=なぎ / 五月晴れ=さつきばれ / 小春日和=こはるびより / 二十四節気=にじゅうしせっき / 啓蟄=けいちつ / 渋川春海=しぶかわはるみ / 岡田武松=おかだたけまつ / 中谷宇吉郎=なかやうきちろう
  ⚠️ **読みは この ゲームの 9つの 旅の 中で かぶらない**(plan.json の とおり。同じ 読みを 2つ 入れない)
- difficulty: 1 = 入門(天気が すきな 小学生) / 2 = 中級(高校の 地学・防災) / 3 = 上級(気象予報士試験の 範囲)
- type: いつも "concept"
- category: 図鑑で しぼる 分類(短い 日本語。旅の 中で 4〜8種類)
- emoji: 1つ。⚠️ 災害の こわい 絵文字は 使わない。🫃 など 意味の ちがう 人の 絵文字に 注意
- mapNode: その 旅の 図の 場所(下の 表から)
- field: 試験の 科目: 大気の構造 / 大気の熱力学 / 降水過程 / 大気の放射 / 大気の力学 / 気象現象 / 気候 / 気象業務法 / 観測 / 数値予報 / 予報 / 防災気象情報 / 実技 の どれか
- ruleset: 試験の どこで 出るか: 学科一般 / 学科専門 / 実技 / 共通(入門の くらしの ことばなど)。**上級は かならず 付ける**(中級・入門も なるべく)
- relatedTerms: **同じ ファイルの 中の** id を 1〜3個
- description: 1〜3文・**130字以内**。やさしい です・ます。語と 語の あいだに 半角スペース(上の 例のように)。⭐ ときどき「へえ」の 1文。
  **予報士の 目線**(「予報に どう 使うか」「天気図で どう 見えるか」)で 書く(理科の 天気と かぶる 語も 目線を 変える)
- formula: **jitsugi の「公式を 打つ」語だけ**(任意)。公式の 見本(例 "Δp = −ρgΔz")。reading は その 読みあげ(下の 読みかた)
- example: なくてもよい

## 公式を 打つ(jitsugi の 上級 8〜12語。数学ゲームと 同じ 型)
name = 公式の 名前(例「静力学平衡の式」)、formula = 式、reading = 式の 読みあげ。読みかた(tools/sugaku/PROMPT.md と 同じ):
＝ いこーる / ＋ たす / − ひく / × かける / ÷ わる / 分数 a/b → びーぶんのえー / ² → のにじょう / Δ でるた / ρ ろー / θ しーた / ω おめが / φ ふぁい / f えふ / g じー / z ぜっと / p ぴー / T てぃー。
例: Δp = −ρgΔz → でるたぴーいこーるまいなすろーじーでるたぜっと(「ひく」でなく 符号は まいなす)。**式は 試験で 本当に 使う ものだけ**(静力学平衡・状態方程式・コリオリパラメータ f=2Ωsinφ・地衡風・温位・気温減率)。数字の 代入は しない
