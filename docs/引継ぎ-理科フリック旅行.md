## 小学生から 大学受験まで — レベルの 並べかた

- 1つの 旅の中で **学年の順**に 並べる: **小学校 → 中学校(高校受験)→ 高校(大学受験)**
- TSV に「学年」の 列を足す(例 `e`=小学 / `j`=中学 / `h`=高校)。`index.html` の `LEVELS` を作るところで
  いまは `f:1`(はじめの レベル)→ 打ちやすさ の順。**理科版は 学年 → 打ちやすさ の順**に する(株式が 時価総額で 並べているのと 同じ考えかた)
- 各レベルの カード(「レベル1」…)に 学年の めやすを 出すと 分かりやすい(例: レベル1〜5 小学生 / 6〜12 中学 / 13〜 高校)
- **学習指導要領の 範囲に 合わせる**(小学校・中学校・高校の 理科の 教科書に 出てくる ことば)。
  高校は 物理基礎・化学基礎・生物基礎・地学基礎 → 物理・化学・生物・地学 の順

## ことばの 例(打つのは よみ = ひらがな)

- **物理**: 小=てこ・ふりこ・電磁石・豆電球・音の高さ / 中=オームの法則・電流・電圧・抵抗・浮力・圧力・仕事・慣性・屈折 /
  高=運動方程式・運動量・万有引力の法則 は宇宙と かぶる → 除く・ドップラー効果・コンデンサー・電磁誘導・光電効果
- **化学**: 小=水溶液・酸性・アルカリ性・リトマス紙・ろ過 / 中=元素記号・原子・分子・イオン・中和・酸化・還元・電気分解・質量保存の法則 /
  高=モル・アボガドロ定数・化学平衡・触媒 は からだと かぶる → 除く・有機化合物・高分子。**元素は 118**(水素〜オガネソン)を 化学の中に 入れても、別の 旅に しても よい
- **生物**: 小=光合成 は からだに ある → 除く・発芽・受粉・食物連鎖・メダカ / 中=被子植物・裸子植物・セキツイ動物・無セキツイ動物・生態系 /
  高=窒素循環・バイオーム・進化・自然選択・種
- **地学**: 小=流れる水のはたらき・地層・化石・火山・地震 / 中=震度・マグニチュード・P波・S波・プレート・前線・気圧・湿度・露点・火成岩・堆積岩 /
  高=ジオイド・アイソスタシー・大気の大循環・エルニーニョ

⚠️ **ほかの ゲームに もう ある ことば**は `tools/*.tsv` を 名前で さがして 除く(`grep -h '^[^#]' tools/*.tsv | cut -f2`)

## 解説の 書きかた

- **80〜120字、自分の 言葉で**(教科書・参考書・Wikipedia を そのまま 写さない。著作権)
- **本当のことだけ**。数字(光の速さ・アボガドロ定数など)は 値を 確かめる。受験で よく 問われる ポイントを 1つ 入れると 役に立つ
  (例: 「P波は S波より 速い。この 差で 震源までの 距離が 分かる」)
- 小学生も 読むので、むずかしい 漢字には ふりがな(`tools/make_ruby.py` が 自動で つける)

## 絵・図

- 写真: 鉱物・岩石・動物・植物・実験器具は **Wikimedia Commons の 写真**が 合う(`tools/fetch_series_photos.py`。ライセンスは PD / CC0 / CC BY / CC BY-SA だけ。英語の 字が 目立つ 図は さける。1枚ずつ 目で 確かめる)。
  抽象的な ことば(法則など)は 絵文字でよい
- 📍の 図は **コードで 描く SVG**(`index.html` の `SVG_MAPS`。宇宙の「太陽系」と 同じ しくみ)。案:
  - **周期表**(化学): 118の マスを コードで 並べて、元素の マスに 📍。いちばん おすすめ(形が 正確に 描ける)
  - **地球の 断面・プレートの 図**(地学)/ **電気回路・力の 図**(物理)/ **生態系の つながり図**(生物)
  - ⚠️ **AIの 絵で 図を 作らない**(字が まちがう)。トップの 絵と 四角い アイコンだけ けいくんに ChatGPT で 作ってもらう(横長 1536×1024、四角 1254×1254)

## 作りかた(いまの しくみを そのまま使う)

- エンジンは `index.html` 1つ。`tools/build_games.py` の `GAMES` に 1つ足すと 下の フォルダ(例 `rika/`)に ページが できる
- 旅を `MODES`(`ALL_MODES`)/ `MAPS` / `POOLS` / 色(`COLORS`)に 足す(例 `rphys` `rchem` `rbio` `rgeo`)
- データ: `tools/rika-*.tsv` → `tools/add_spots.py` に kind を足して 流しこむ → `tools/make_ruby.py` → 写真 → `tools/build_games.py`。
  形は 宇宙・からだの 11列(`tools/space.tsv`)+ 学年の 列。検査は `tools/check_series_tsv.py` を まねる
- **言葉の 数は 10の倍数**(あまりが 出ると 最後の レベルに 前の レベルから もう一度 出して 10問にする しくみは 入っている)

## 手元での 確かめかた

- すべての レベルが 10問か: `GAME.modes.map(m => [m, POOLS[m].length, LEVELS[m].every(l => l.length === 10)])`
