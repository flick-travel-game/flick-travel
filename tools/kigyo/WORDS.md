# フリック起業家: 旅ごとの ことばの 置き場所(10の 旅 × 70語)

`PROMPT.md` の「旅ごとに 入れる 語」の 一覧。**ここに ある 語だけを、書いて ある 旅に 入れる**。

- 形: `- 名前 | よみ | mapNode | メモ`
- 各 旅は 入門(difficulty 1)20語・中級(2)25語・上級(3)25語。段の 中は **よく 知られている 順**
- ⚠️ **よみ(と 別読み)は 10の 旅 ぜんぶで 1回だけ**。ほかの 旅に ある 語は 入れない
- メモの 先の 🍋 = レモネードの 屋台の たとえが 合いそうな 語
- 別読みは メモに「(別読み: …)」と 書く(JSON では `acceptedReadings`。先頭は reading と 同じ)
- かさなりやすい 語の 置き場所(決めたもの): ミッション・ビジョン・バリュー・パーパス・経営理念 = kihon / 価値提案 = model /
  ターゲット・市場 = shijo / ブランド・顧客・広告 = hanbai / 利益・売上・費用 = okane / 株式・株主・資金調達・投資家 = chotatsu /
  株式会社・資本金・株主総会・個人事業主・帳簿 = hojin / 仲間・リーダー・共通目標 = team / 目標・KPI・ピボット・上場・イノベーションの 戦略 = seicho /
  イノベーション(ことばそのもの)・リスク・失敗 = kihon
