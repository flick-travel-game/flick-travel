⭐ **いちばん 近い 手本は フリック宅建士(`takken/`)と フリック衛生管理者の 下ごしらえ(`tools/eisei/`・`eisei/eisei.js`)**。作りかたは `docs/フリック宅地建物取引士-はじめかた.md`・`docs/フリック衛生管理者-はじめかた.md`・`takken/CLAUDE.md` を なぞる。

⭐⭐ **「受かる レベル」の ための 決めごと**(宅建士・衛生管理者と 同じ 5つ + 社労士だけの 1つ):
社労士試験は **年 1回・8月の 日曜**。**選択式 8問(1問 5つの 空欄 × 1点 = 40点)+ 択一式 70問(5つから 1つ・1問 1点 = 70点)**。合格は **選択式・択一式の それぞれで「総得点の 基準」かつ「科目ごとの 基準」を 同時に 満たす**(基準点は **毎年 補正される**。令和7年度は 選択 22点 / 各科目 3点(労災・労一・社一は 2点)、択一 42点 / 各科目 4点(雇用は 3点))。**合格率は 5〜7%**(画面には 出さない)。**10の 法律の 数字(日数・年数・%・円)を 正確に おぼえているか**が 合否を 分ける。
ことばを 打つ だけでは **「数字」「似た 制度の 区別」「条文の 空欄」に 弱い**。宅建士と 同じく **ことば + 問題 + 模擬試験**:
① **ことば 1,000語**(10の 旅 × 100語 = 入門15・中級30・上級55)
② **⭕❌ 一問一答 約1,300問**(択一式の 1つの 文が ⭕❌ の 1問。自分の 文で 書く。⚠️ 過去問の 文を 写さない)
③ **🔢 数字クイズ 約250問**(社労士は 数字が いちばん 多い 試験: 待期 3日・休業補償 60%・基本手当の 日数・育児休業 1歳 / 2歳・標準報酬 50等級 / 32等級・保険料率・老齢基礎年金の 満額・支給開始 65歳・繰上げ 0.4% / 繰下げ 0.7%・時効 2年 / 5年・保存 5年 / 3年 など)。**⚠️ 毎年 4月に 変わる 数字(年金額・保険料率・在職老齢年金の 基準額・標準報酬の 上限)は「◯年度」つきで 1か所に まとめる**
④ **🎯 模擬試験 = 択一式**(本番と 同じ **5つから 1つ・70問・210分・科目の 数も 本番どおり**。1問 = 同じ 科目の ⭕❌ の 文を 5つ ならべて「正しい / 誤っている ものは どれか」。合格の きまりは「総得点 ◯点 かつ 各科目 ◯点」)
⑤ ⭐ **📝 選択式の 練習(社労士だけ)**: 条文の 文の **空欄 1つ**を 20の 語群(本番と 同じ 形)…は 画面が せまいので、**空欄 1つを 5つの 語から えらぶ**形で 約300問(`tools/sharoshi/sentaku-<旅>.json`)。本番の 選択式(1問 5空欄・語群 20)を まるごと まねる 画面は 作らない(スマホで 読めない)。模擬試験の 結果の 画面に「選択式は 📝 で 練習」と そえる
⑥ **❌ まちがえた 問題の 復習**(運転免許・宅建士・衛生管理者に つづく 例外。けいくんの 宅建士の 決定の まま)
