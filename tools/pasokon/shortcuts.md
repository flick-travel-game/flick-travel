表記のメモ:
- Apple のページは「shift + command + 3」のように **英語名で** 書いている。ここでは 頼まれた形(⌘ を先、記号)に 置きかえた。キーの組み合わせ自体は 変えていない
- Apple のページの矢印の記号は ▲ ▼ ◀ ▶、esc は ⎋、return は ⏎、tab は ⇥。ここでは ↑ ↓ ← → / esc / Return / Tab で書いた
- 動作名は Apple の説明文から 短く取った(「」の中が Apple の言いかたに近いもの)

## 確認できなかったもの / 注意
- **「閉じたタブを再び開く ⌘ + ⇧ + T」は 一般ページ A には載っていない**。Safari のページ E にだけある(Safari 限定として扱う)。A の ⌘ + ⇧ + T は Finder のタブバー切り替え
- 絵文字(文字ビューア): A に「control + command +スペースバー または fn + E」、さらに「fn + fn:文字ビューアを表示」の記載あり。**「🌐 + E」という書き方は A には無い**(A の本文は「fn + E」。修飾キー表で Fn と地球儀を同じキーとして扱っている)
- A は 2026-10-03 時点で macOS 27 Golden Gate・Siri AI(ベータ版)の項目(⌘ + ⇧ + 6、⌘ + ⇧ + Space)を含む。版で変わりうるので 一覧には入れていない
- 英語版 https://support.apple.com/en-us/102650 は 今回 照合していない(日本語版 A で すべて確認)
- 「Space」のキー記号は Apple の修飾キー表に無い(本文では「スペースバー」)
