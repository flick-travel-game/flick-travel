# フリックマナー: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)が 出る。
あそぶのは **小学生〜大人**(家族で あそぶ)。**マナーの ことばと「なぜ そう するのか」を おぼえる ゲーム**(検定の 問題集では ない)。
けいくん 2026-10-03「マナーの専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください」。

## ⭐ この ゲームの 心(いちばん 大事)
- **マナーは「相手を 思いやる 気持ちを 形に した もの」**。きまりを おぼえる ゲームでは なく、**「なぜ そう するのか」(相手が うれしい・安心する・こまらない ため)** が わかる ゲームに する。
  説明文は かならず **理由**を 書く(例: 「名刺を 両手で わたすのは、相手を 大切に 思って いる 気持ちを 伝える ため です」)。**理由の わからない きまりは 入れない**
- ⚠️⚠️ **人を 責めない・はずかしめない**。「マナー違反の 人は …」「こんな ことも 知らないと はずかしい」は 書かない。**知らなかった ことは、知れば いい**
- ⚠️⚠️ **「正解は 1つ」と 決めつけない**。マナーは **地域・家・お店・国・宗教・時代で ちがう**。「〜が 一般的」「〜と される ことが 多い」「〜と いう 考えかたも ある」の 形で
- ⚠️⚠️ **根拠の うすい「新しい マナー」を 入れない**(ネットで 広まった「とっくりの 注ぎ口を 使うのは 失礼」「はんこは おじぎする ように 斜めに 押す」「ノックは 3回 / 2回は トイレ」の ような **説が わかれる・根拠が はっきり しない もの**)。**ひろく 知られ、秘書検定・ビジネス実務マナー検定・マナー・プロトコール検定の 本や、礼法・茶道の 本に のって いる もの だけ**

## ⚠️⚠️ ぜったいに しない こと
- ❌ **「失礼」「非常識」「はずかしい」「NG」「マナー違反」「失格」「常識が ない」を 人に 向けて 使わない**(台本で 止まる。「失礼」の 字も 使わない)。かわりに「〜すると 相手が こまる ことが ある」「〜の ほうが 気持ちよく すごせる」「〜を さける ことが 多い」
- ❌ **まちがえた 人を 笑う 書きかた・こわがらせる 書きかたを しない**
- ❌ **数字の 決めうちを 書かない**: おじぎの 角度・電話の コール数・訪問の 何分前 / 後・ご祝儀 / 香典 / お年玉 / チップの 金額や 割合・焼香の 回数(台本で 止まる)。「少し」「ふかく」「早めに」で 書く。⚠️ 例外: 名前に 数字が 入る もの(一汁三菜・還暦・喜寿・米寿・三三九度・四十九日 など)は よい
- ❌ **「死」「亡」「殺」「血」の 字を 使わない**(小学生も あそぶ。台本で 止まる)。お悔やみの 旅は「しのぶ」「お別れ」「大切な 人が いなく なった とき」ではなく「**大切な 人を しのぶ 場**」「**故人**」(故人は よい)。こわく 感じる 文・悲しく なる 文は 書かない。迷ったら 入れない
- ❌ **忌み言葉の 例は 少なく・おだやかに**(「切れる」「別れる」の ように 1〜2個まで。ならべない)
- ❌ **宗教や 国の よしあしを 書かない**。「〜の 宗教では 〜と される」「〜の 地域では 〜と される ことが ある」。**仏式 だけに しない**(神式の 玉串・キリスト教の 献花も 名前を 出す)。**「〜人は 〜だ」と 国の 人を 決めつけない**
- ❌ **性別で 決めつけない**(「女性が お茶を 出す」「男性が 〜」の 役わりを 書かない。⚠️ 昔の 本に ある ものも 入れない)。**レディーファースト**は「〜の 国で 大切に されて きた 考えかた」と 事実として
- ❌ **実在の お店・ホテル・ブランド・会社・マナー講師の 名前を 入れない**。茶道の 流派(表千家・裏千家)・小笠原流(礼法)は 文化として 名前を 出して よい
- ❌ **検定の 問題・本・ウェブの 文を 写さない**。自分の ことばで 書く
- ❌ 「〜すべき」「〜しなければ ならない」「〜しなさい」「ぜったい」は 使わない(台本で 止まる)。「〜すると よい」「〜が 一般的」

## 1語の 形(JSON)

```json
{"id":"kh-eshaku","name":"会釈","reading":"えしゃく","journey":"kihon","category":"おじぎ","difficulty":1,
 "field":"立ち居振る舞い","type":"concept","emoji":"🙇","mapNode":"kihon:ojigi","relatedTerms":["kh-keirei","kh-saikeirei"],
 "description":"かるく 頭を 下げる、いちばん あさい おじぎです。ろうかで すれちがう ときなど に 使います。ことばが なくても「あなたに 気づいて いますよ」と いう 気持ちが 伝わります。",
 "naze":"相手に 気づいて いる ことを 伝えると、おたがいに 安心して すごせる から。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(漢字・カタカナ。ふつうの 言いかた)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白は ダメ)
  - カタカナ語は ひらがなに(ないふ・なぷきん・ちっぷ)
  - 数字は ひらがな(一汁三菜 → `いちじゅうさんさい`)
  - ゆれる ことばは 1つに 決め、別の 読みは `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 長い 読みは 入れない**
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級(下の「3段の 分けかた」)
- **field**: 学ぶ 分野。つぎの 8つの どれか(秘書検定・ビジネス実務マナー検定・マナー・プロトコール検定の 分けを もとに した めやす):
  `立ち居振る舞い` `ことばづかい` `食事の作法` `訪問と接遇` `ビジネス実務` `社会生活` `冠婚葬祭・贈答` `国際儀礼`
  (あいさつ・おじぎ・身だしなみ=立ち居振る舞い / 敬語・話しかた・手紙の ことば=ことばづかい / 訪問・来客・お茶=訪問と接遇 / 電話・メール・席次・文書=ビジネス実務 / 公共の 場・スマホ・SNS=社会生活 / お祝い・お悔やみ・季節の 贈りもの=冠婚葬祭・贈答 / 世界の マナー=国際儀礼)
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(⚠️ 宗教の しるし(✝️☪️🕉️☸️ など)は 使わない)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / どんな 場面で / **なぜ そうするのか**」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)
- **naze**(任意): ⭐「💡 なぜ そうするの?」として 説明の 下に 出る **1文(70字まで)**。**相手が どう うれしい・安心する・こまらないか** を 書く。
  **1つの 旅に 5〜10語だけ**(台本が 数える)。とくに「理由を 知ると へえ と なる」語に 付ける
- **example**: なくてもよい(ある ときは 身近な たとえ 1文。例「『おそれいりますが、お名前を うかがっても よろしいですか』」)

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | **毎日の マナーが わかる 子**: あいさつ・おじぎ・食事・みんなの 場所・きほんの 敬語。小学生でも 場面が うかぶ |
| 2 | 中級 | **社会に 出る 人**: 秘書検定 3級・2級、ビジネス実務マナー検定の 範囲の めやす。敬語・電話・メール・名刺・席次・お祝いと お悔やみの きほん |
| 3 | 上級 | **マナーの 専門家**: 秘書検定 準1級・1級、マナー・プロトコール検定の 範囲の めやす。冠婚葬祭・和室・茶道の ひとこと・手紙・プロトコール・国ごとの ちがい |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる(ならんだ 順が そのまま ステージの 順に なる)。

## 旅ごとの 注意
- **kihon**: あいさつ(おはよう・いただきます・ありがとう・ごめんなさい)・おじぎ(会釈・敬礼・最敬礼。**角度の 数字は 書かない**)・語先後礼・分離礼 / 同時礼・笑顔・身だしなみ・姿勢・時間を 守る・返事・思いやり。「いただきます」は 食事の 旅に 置く
- **keigo**: 尊敬語・謙譲語(Ⅰ・Ⅱ)・丁寧語・美化語・クッション言葉・二重敬語・ら抜き言葉(説明として)・バイト敬語(**責めずに「〜と 言う ほうが 伝わりやすい」**)・「させて いただく」・お / ご の つけかた・身内の 呼びかた(内と 外)・「了解しました / 承知しました」は「目上の 人には 承知しました を 使う ことが 多い」と おだやかに。国語旅行と かさなって よい
- **shokuji**: 箸(⚠️ 箸わたし・拾い箸は「ほかの 場面(お別れの 式の 習わし)を 思い出させる ので さける、と されて きた」と おだやかに。「死」は 書かない)・嫌い箸・お膳(ごはんは 左・汁物は 右)・お椀の ふた・懐紙・一汁三菜・洋食(外側から・ナプキン・パン・スープ・食事中 / 食べ終わりの 合図)・中華(回転テーブル)・立食・乾杯
- **homon**: 訪問の 約束・時間(**数字は 書かない**。「約束の 時間ちょうどか 少し あと」が 一般的)・くつの そろえかた・手みやげ・上座 / 下座・床の間・敷居 / 畳の へりを ふまない・座布団・お茶の 出しかた・茶道の ひとこと(お先に・お点前 ちょうだいします。流派で ちがう)・お見舞い(花の 決まりは「〜と される ことが ある」)
- **kokyo**: 電車・バス(優先席・リュックは 前に・電話を ひかえる)・エスカレーター(⚠️ **「立ち止まって 乗る」ことを よびかける 動きが ある。「片側を あける」を 正しいと 書かない**)・図書館・病院・映画館・列・ゴミを 持ち帰る・スマホ(歩きスマホ)・SNS(人の 写真を のせる 前に 聞く・悪口を 書かない)・ユニバーサルマナー(声かけは「何か お手伝い できる ことは ありますか」)
- **biz**: 名刺交換・電話(名のる・メモ・復唱。**コール数は 書かない**)・メール(件名・宛名・署名・CC / BCC)・報連相・席次(会議室・車・エレベーター・タクシー)・来客の 案内・お茶出し(⚠️ **「女性が」と 書かない**)・身だしなみ・オンライン会議・ビジネス文書
- **oiwai**: のし・水引(結び切り = 1回で ある ように / 蝶結び = 何度 あっても よい)・表書き(御祝・寿・内祝)・ご祝儀(**金額は 書かない**。新しい お札を 用意する は よい)・袱紗・結婚式(招待状の 返事・忌み言葉(例は 少なく)・服装)・出産祝い・入学祝い・内祝い・長寿の お祝い(還暦・古希・喜寿・傘寿・米寿・卒寿・白寿)
- **okuyami**: ⚠️⚠️ **いちばん 気を つける 旅**。お通夜・告別式(名前と 意味だけ)・香典(**金額は 書かない**)・不祝儀袋・薄墨(理由は「悲しみを 表す と いわれる」まで)・数珠・焼香(**宗派で ちがう。回数は 書かない**)・お悔やみの ことば(「このたびは …」)・喪服・法事・お盆 / お彼岸の お墓参り・神式の 玉串奉奠・キリスト教式の 献花。**宗教の よしあしは 書かない**。⚠️ 小学生が「家族が いなく なる」を 思い出す 書きかたは しない

## ぜったいに 守ること
- **自分の ことばで 書く**。本・ウェブ・検定の 問題の **文を 写さない**
- ✅ ほかの ゲーム(国語旅行の 敬語・家事の 行事・英会話の あいさつ・花屋の 母の日 など)と 同じ 語を 入れて よい(復習に なる)。説明は **相手を 思う 目線**で 書きなおす
- 事実が あやしい 語・説が わかれる 語は **入れない**(まちがいを 書くより 入れないほうが よい)。「いつから 変わった」の 年は 書かない
- いわれは「〜と 言われます」「〜と いう 意味が こめられて います」の 形に する(言いきらない)
- ほかの 旅と **読みが かぶらない**(`tools/manner/plan.json` の 置き場所を 守る)

## 出すもの

`tools/manner/terms-<旅id>.json` に JSON の 配列(70語)で 書く。書いたら
`python3 -c "import json;d=json.load(open('<file>'));print(len(d))"` で 読めるか 確かめる。
そのあと `python3 tools/manner/terms_js.py --only <旅id>` で 形を 確かめる(まちがいが あれば 止まる。直して もう一度)。
