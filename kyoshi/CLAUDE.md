## フリック教師(`kyoshi/`。けいくん 2026-09-30「教師になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」)

- 名前は「フリック教師」(絵が 届いたら 題名に そろえる。フォルダ名 `kyoshi` は 変えない)。シリーズの 絵文字は 🏫
- 旅は 7つ(教育の考えかた `kangae`・子どもの心と育ち `kokoro`・授業のつくりかた `jugyo`・学級と学校のしくみ `gakko`・支える指導 `shien`・教育の法律と制度 `hoki`・教育の歴史と世界 `rekishi`)+ マスター。
  **旅ごとに 70語(入門20・中級25・上級25)= 490語**。かずともの 旅の 名前は **`t` で はじめる**(tkangae / tkokoro / tjugyo / tgakko / tshien / thoki / trekishi / tmas)。
  ⚠️ `ky` は 国語(kyomi / kyoji)が 使っているので 使わない
- むずかしさは 3段: 入門(学校で 聞く ことば)→ 中級(**教員採用試験の 教職教養の 範囲の めやす**)→ 上級(法律の 名前・こまかい 制度・教育史の 人物)。
  1語ごとに **教職教養の 科目**(`field` → 画面では 📘 教職教養の 科目。教育原理 / 教育心理 / 教育法規 / 教育史 / 教育時事 / 生徒指導・特別支援 の 6つ)。図鑑で しぼれる
- 学校は 小学校を 中心に、中学・高校に 共通する ことば。**教科の 中身(算数・国語 …)は 入れない**(数学旅行・国語旅行の 役目)
- ことばは `tools/kyoshi/terms-<旅>.json`(決まりは `tools/kyoshi/PROMPT.md`)→ `tools/kyoshi/terms_js.py` → `kyoshi/terms.js` + `data/kyoshi.json`。
  しくみは `kyoshi/kyoshi.js`(医師を 写した。4択クイズ あり)。しくみ図は コードで 描く 箱の 図 7つ(教育の考えかた・子どもの心・**教室の地図**・**学校の地図**・支える指導・教育の決まり・歴史と世界。`tools/kyoshi/mkmeta.py` が meta.json を 作る)。ホームでは たたんで ある
- 試験・免許の いまの形は `tools/kyoshi/meta.json` の `exam` に **確かめた日つき**(2026年9月30日に 文部科学省・都道府県教育委員会の ページで 確かめた):
  教職課程 → 教員免許状(都道府県教育委員会が 出す。普通・特別・臨時。普通は 専修・一種・二種で 教えられる 範囲は 同じ)→ 教員採用選考試験(都道府県・政令市ごと。中身は 自治体で ちがう)/
  **教員免許更新制は 2022年7月1日に なくなった**(有効だった 免許状は 期限なしに)/ 学習指導要領は 小中 2017年・高校 2018年 告示が いまの もの。
  次の 改訂は 中教審で 審議中で 小学校は 令和12年度(2030年度)から 全面実施の 予定(文部科学省「学習指導要領等の改訂に関するスケジュール」令和8年7月8日)/

- ⚠️⚠️ **小学生も あそぶ**: いじめ・不登校・虐待・障害は **「先生と 学校が 守る・助ける・支える しくみ」の 書きかただけ**。つらい ようす・こわい 先・数・子どもや 親を せめる 書きかたは しない。
  子どもの貧困・ネットいじめ・性に関する教育は 入れていない(`PROMPT.md`)。就学援助も「必要な 家庭を 市町村が 手助けする しくみ」と だけ
