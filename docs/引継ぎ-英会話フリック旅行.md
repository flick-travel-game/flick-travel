## 先に けいくんに決めてもらうこと(番号で聞く)

1. **ゲームの名前**: 「英会話フリック旅行」/「英語フリック旅行」/ そのほか
2. **何を 打つか**(いちばん 大事。おすすめは ①)
   1. **英語を 見て 英語を 打ち写す**(おすすめ)。シリーズの「表示された字を 打ち写す」と 同じ あそびかた。打ち終わると **意味・発音(音が出る)・例文**が 出る。つづりが 指で おぼえられる
   2. 日本語の 意味を 見て 英語を 打つ(むずかしい。上のコースや「チャレンジ」向け)
   3. 英語の 音を 聞いて 打つ(聞き取り。英検・TOEIC の リスニング対策)
   → おすすめは **①を 基本に、②③は マスター/チャレンジの 旅として あとから 足す**
3. **iPhone で どの キーボードで 打つか**
   - iPhone の「日本語かな」キーボードの **「ABC」(英字フリック)**なら フリックで 英語が 打てる(abc / def … を フリック)。**シリーズの 名前どおり フリックで あそべる**
   - ふつうの 英語キーボード(QWERTY)でも 打てる。どちらも 使えるように しておき、案内だけ「ABC で フリックしてね」と 出すのが おすすめ
4. **レベルの 表しかた**: 「英検5級〜1級」「TOEIC 400〜900点」の **めやす**として 出してよいか(⚠️ 下の「商標」の 注意)
5. **音(発音)を 出すか**: おすすめは **出す**(ブラウザに 入っている 読み上げ `speechSynthesis`。サーバーも お金も 要らない。英語の 声は 端末ごとに ちがう)

## 旅(コース)の 案 — 株式と 同じ「つみあげ」

| コース | 中身 | めやす |
|---|---|---|
| 🌱 入門 | 身のまわりの 単語(動物・食べ物・色・数・家族・学校)| 英検5級 / 小学生〜中1 |
| 📘 初級 | 中学の 基本単語 + あいさつ・自己紹介の フレーズ | 英検4〜3級 / TOEIC 〜400 |
| 🧭 中級 | 高校の 基本単語 + 旅行・買い物・道案内・レストランの 会話 | 英検準2〜2級 / TOEIC 400〜600 |
| 🌐 上級 | 仕事・ニュースの 単語 + 電話・会議・メールの 表現 | 英検準1級 / TOEIC 600〜800 |
| 🏆 マスター | 上級の 単語・言いまわし・熟語 | 英検1級 / TOEIC 800〜 |

- **1回は かならず 10問**(シリーズの 決まり)。むずかしさは「出る ことば」で 上げる
- **旅の 分けかた(2つの 柱)**
  - **📖 英単語**: コースごと
  - **💬 日常英会話**: 場面ごと(自己紹介・あいさつ / 空港・ホテル / レストラン・カフェ / 買い物 / 道案内・電車 / 病院・困ったとき / 電話 / 仕事・会議 / SNS・メッセージ / 気持ちを 伝える)
  - マスターは 株式の マスター(地域別・業種別)と 同じく **場面別・品詞別**で えらべる形に
- **ふくしゅう**(まちがえた・時間がかかった・ひさしぶり を 先に)と **単語帳(図鑑)**は 株式の しくみを そのまま 使う
  (`kabu.js` の `reviewPick` / `openZukan` / `TITLES`)。図鑑は「おぼえた 単語帳」、まだの 単語は ？？？
- 数の めやす: 単語 3,000〜5,000 + フレーズ 1,000〜1,500。**10の倍数**に そろえる
- 「外国人と コミュニケーションが とれる」を ねらうので、**フレーズは 短く、実際に 使う 形**(`Could you say that again?` `I'm looking for the station.`)。
  中級から **返事の 例**(相手が 言いそうな 文)も 入れると 会話の 練習に なる

## データ(⚠️ 作り話を 入れない・人の 本を 写さない)

- 置き場所: **`data/english.json` の 1か所**(株式の `data/companies.json` と 同じ 考えかた)。CSV ⇄ JSON の 道具も 株式の `tools/kabu/companies_csv.py` を まねる
- 1語・1文の 項目の 案:
  `id` / `text`(打つ 英語)/ `meaning`(日本語の 意味)/ `kind`(word / phrase)/ `pos`(品詞)/ `ipa`(発音記号・あれば)/ `example` と `exampleJa`(例文)/
  `scene`(会話の 場面)/ `course` / `level`(めやすの 級・点)/ `freqRank` / `source`(出どころ)
- **単語の 出どころ(ライセンスが はっきり しているもの)**
  - **NGSL**(New General Service List。よく使う 2,800語)/ **TSL**(TOEIC Service List。TOEIC に よく出る 1,200語)/ **BSL**(Business Service List)
    … どれも **CC BY-SA 4.0**(作者: Browne, Culligan, Phillips)。⚠️ **使うなら 表示と 同じ ライセンスの 決まりを 守る**(data の meta と 案内ページに 出どころを 書く)
  - **CEFR-J Wordlist**(A1〜B2 の レベル付き)… 使う前に **利用条件を 読んで けいくんに 伝える**
  - ⚠️ **市販の 単語帳(出る単・ターゲット など)や 英検・TOEIC の 過去問を 写さない**(本の 並べかた・例文・訳にも 権利が ある)
- **例文・フレーズの 出どころ**
  - 自分で 書く(短く・ふつうの 言いかた)。⚠️ 英語が 自然か 必ず 見なおす
  - **Tatoeba**(英日の 文の 組が たくさん。**CC BY 2.0 FR**)は 使ってよいが、訳の 品質に ばらつきが あるので 1文ずつ 見る
- **日本語の 意味・説明は 自分の ことばで**(辞書の 文を 写さない)。1〜2行。小学生にも わかる ように
- 株式の ときと 同じく、たくさん 作るときは **決まりを 1つの 文書に 書いて**(`tools/kabu/enrich/PROMPT.md` のように)**助手に 分けて 頼み**、**形を 確かめる 台本**(`check_enrich.py` のような)で 確かめる

## ⚠️ 商標・言いかた(英検・TOEIC)

- **「英検」は 日本英語検定協会の、「TOEIC」は ETS の 登録商標**。このゲームは 協会・ETS とは 関係が ない
- 画面の 言いかたは **「英検◯級 レベルの めやす」「TOEIC ◯点 レベルの めやす」**にする。「英検 公式」「◯級に 合格できる」とは 書かない
- 案内ページの 下に「英検は 公益財団法人 日本英語検定協会の 登録商標です。TOEIC は ETS の 登録商標です。このゲームは これらの 団体とは 関係ありません」
- ⚠️ **レベルの めやすは 公開されている 目安表(CEFR との 対応)を もとに**。けいくんに「めやす」で よいか 確かめる(先に 聞く 4)

## しくみで 気をつけること(いまの 土台との ちがい)

- **打つ字が 英字**になる。いまの 判定(`index.html` の `norm` / `judge`)は ひらがな むけ:
  - `norm` は 空白・句読点(、。・.,!?)を 消す → 英文でも **空白と ,.!? は 打たなくてよい**に なる(おすすめ: そのまま。子どもが つまずかない)。
    ⚠️ ただし **アポストロフィ(I'm の ')**は 消えない → `norm` に 足すか、英字の ときだけ 小文字にして 記号を 消す 関数を 分ける
  - **大文字・小文字は 区別しない**(小文字に そろえてから くらべる)
  - `base()`(濁点の 途中を ゆるす)は 英字では 何も しない → そのままで よい
- 入力欄: 英語の 旅の ときだけ `lang="en"`・`autocapitalize="off"`・`autocorrect="off"`・`spellcheck="false"`(いまも off)。
  ⚠️ **iPhone の 英語キーボードの 予測変換は ページから 完全には 止められない** → シリーズの ルール「予測変換は 使わずに 自分の 指で」を 案内に 出す
- レベルの 並べかた: いまは「打つ字の 多さ」(`cost`)。英語は **頻度・級の 順 → 字の 多さ**(株式が 知名度の 順に したのと 同じ)
- **音**: `speechSynthesis.speak(new SpeechSynthesisUtterance(text))`、`lang="en-US"`。
  ⚠️ iPhone は **タップの 中でないと 音が 出ない**(ボタン「🔊 きく」を 押させる。自動で 鳴らさない)。音が 出ない 端末でも あそべる ように
- 1つの 文が 長いと 打つのが つらい → **フレーズは 40字くらいまで**。長い 会話は 2つに 分ける
