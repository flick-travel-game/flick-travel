## フリック薬剤師(`yakuzai/`。けいくん 2026-10-03「薬剤師の専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」。まとめは `docs/フリック薬剤師-はじめかた.md`)

- 名前は「フリック薬剤師」(絵が 届いたら 題名に そろえる。フォルダ名 `yakuzai` は 変えない)。シリーズの 絵文字は 💊。`SERIES_ORDER` は **医師の となり**
- 旅は 9つ(薬のきほん `kihon`・薬がきくしくみ `yakuri`・薬の種類 `shurui`・薬がからだを旅する `dotai`・病気と薬の治療 `chiryo`・調剤と服薬指導 `chozai`・薬局の薬(OTC) `otc`・衛生と公衆衛生 `eisei`・法律と歴史・倫理 `hoki`)+ マスター。
  **旅ごとに 70語(入門20・中級25・上級25)= 630語**。かずともの 旅の 名前は **`yk` で はじめる**(ykkihon / ykyakuri / ykshurui / ykdotai / ykchiryo / ykchozai / ykotc / ykeisei / ykhoki / ykmas)。作る 前に ぶつからない ことを 確かめた
- むずかしさは 3段: 入門(**くすりを 正しく 使える 人**。小中学校の「くすりの 正しい 使い方」)→ 中級(**登録販売者試験の 範囲の めやす**)→ 上級(**薬剤師国家試験の 範囲の めやす**)。
  1語ごとに **試験の 科目**(`field` → 📘 試験の 科目)7つ: 物理・化学・生物 / 衛生 / 薬理 / 薬剤 / 病態・薬物治療 / 法規・制度・倫理 / 実務(第112回の 施行公告の 書きかた)
- ことばは `tools/yakuzai/terms-<旅>.json`(決まりは `tools/yakuzai/PROMPT.md`。**どの 語を どの 旅に 入れるかの 一覧**も ここ)→ `tools/yakuzai/terms_js.py` → `yakuzai/terms.js` + `data/yakuzai.json`。
  しくみは `yakuzai/yakuzai.js`(農家を 写した。4択クイズ あり。クイズの 文は「薬の 使いかたでは ありません。薬は お医者さん・薬剤師さんの 言う とおりに」)。
  しくみ図は コードで 描く 箱の 図 9つ(`tools/yakuzai/mkmeta.py`): **薬の 形の 一覧(錠剤・カプセル・散剤・液剤・軟膏と 貼り薬・目薬・吸入・坐剤・注射 + 飲む 時間・保管)**・薬が きく しくみ・薬の 種類の 棚・
  **薬が からだを 旅する 地図(飲む → 胃 → 小腸で 吸収 → 門脈と 初回通過 → 肝臓で 代謝 → 血液で 分布 → きく 場所 / 腎臓で 排泄)**・病気と 治療・
  **処方箋が 薬に なるまで(医師の 処方 → 受付 → 処方の 確認 → 疑義照会 → 調剤 → 鑑査 → 服薬指導 → お薬手帳と 薬歴)**・**薬局の 薬の 分け方(医療用 / 要指導 / 第1類〜第3類 / 登録販売者)**・みんなの 健康・薬の 決まりと 歴史
- 試験・制度の 事実は `tools/yakuzai/exam.txt`(→ meta.json の `exam`)に **確かめた日つき**(2026年10月3日。厚生労働省の 第111回 合格発表・第112回 施行公告・e-Gov の 薬剤師法 / 薬機法 / 学校保健安全法・PMDA・文部科学省):
  厚生労働大臣の 免許 / 薬学部 6年制・共用試験(CBT・OSCE)→ 実務実習 → 国家試験 / 年1回(第111回 2026年2月21・22日、第112回 2027年2月20・21日)/ 必須 90・薬学理論 105・薬学実践 150 = 345問 /
  第111回の 合格基準 = 426点以上(686点満点)・必須 70%以上(各科目 30%以上)・禁忌肢 2問以下 / 出題基準は 平成28年版(第106回から。第115回から 新しい 基準の 予定)/
  登録販売者(都道府県知事・第2類と 第3類)/ 要指導医薬品は 一般用とは べつの 区分 / 学校薬剤師(学校保健安全法)/ 医薬品副作用被害救済制度(PMDA・1980年)。⚠️ 数字は 毎年 変わる。直すときは その日に 確かめて `exam` の 日付も 上げる。
  ⚠️「専門家に なれる レベル」は **薬剤師国家試験の 科目の ことばを ひととおり 知っている** めやす。調剤・服薬指導は 薬学部と 実務実習で 身に つく
- ⚠️⚠️⚠️ **薬の 使いかたを 教える ゲームに しない**: 薬の 量・飲む 回数・最大量・「この しょうじょうなら この 薬」・具体的な 飲み合わせ・正常値・**商品名・製薬会社・薬局チェーン** は 書かない(台本 `BAN` / `BAN_RE` が mg・錠・回・包・滴・円・% の 数字・商品名・会社名を 止める)。
  ⭐「正しく 使う 考えかた」(時間と 量を 守る・人の 薬を 飲まない・水で 飲む・飲みきる ように 言われた 薬は 自分で やめない・おかしいと 思ったら 大人と 薬剤師さんに)は 書いて よい
- ⚠️⚠️ **小学生も あそぶ**: 「死」「殺」「致死」「過量」・中毒の ようす・乱用薬物の 名前(台本が 止める)は 書かない。毒薬・劇薬・麻薬・向精神薬は「法律で きびしく 管理される 薬」まで。
  薬物乱用防止は「ダメ。ゼッタイ。」と「誘いを 断って 大人に 言う」の 形だけ。抗がん剤・麻薬・向精神薬の 個別の 成分名は 入れない。殺菌は 入れず 除菌・滅菌・消毒
- 一般名は 有名な ものだけ(アセトアミノフェン・イブプロフェン・アスピリン・ペニシリン・インスリン など)。⚠️ 台本の「一包化」は `OK_WORDS`(「一」+「包」が 量に 見えて 止まったため)
