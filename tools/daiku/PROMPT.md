# フリック大工: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
学ぶ 分野・しくみ図の どこに あるか(📍)が 出る。あそぶのは **小学生〜大工を めざす 高校生・大人**。
**大工と 家づくりの ことばと 意味を おぼえる ゲーム**(試験の 問題集でも、作業の 教科書でも ない)。
もとは `tools/toshika/PROMPT.md`(投資家)と `tools/seibi/PROMPT.md`(整備士)。
けいくん 2026-10-03「大工の専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 6つ

### 1. 道具の 使いかた・作業の 手順を ぜったいに 書かない(整備士の「締めつけの 手順は 書かない」と 同じ)
- ❌ **書かない**: 「のこぎりは ◯◯の ように ひく」「丸のこは ◯◯して 切る」「かんなは ◯◯して 削る」「◯◯の 順に 組む」/ 研ぎかた・打ちかた・刻みかたの コツ
- ⭕ **書くのは**: その ことばが **何を さすか**・**何の ための 道具や 部材か**・**家の どこに あるか**・**大工さんが なぜ 大事に するか**
  - 例: 鉋(かんな) = 木の 表面を うすく 削って、なめらかに する 大工道具です。日本の かんなは 手前に 引いて 使う ものが ふつうです
    (「引いて 使う」の ように **しくみの 説明**までは よい。「どう 引くか」の 手順は 書かない)
- **刃物・電動工具の 語の 説明には「おとなの 大工さんが 使う 道具」**の ように、子どもが まねしない 書きかたを する
- 「ひきかた」「切りかた」「削りかた」「研ぎかた」「打ちかた」「使いかた」の 字は 台本が 止める

### 2. 小学生も あそぶ(こわく しない)
- ❌ **けが・事故・落ちる・切る ようす・血・死・「命に かかわる」**は 書かない(台本が 止める。整備士で「命に かかわる」→「とても 危ない」に 直した 前例)
- 安全の ことば(安全帯・墜落制止用器具・ヘルメット・足場・KY活動・指差し呼称・保護めがね・防じんマスク)は **「みんなで 安全を 守る しくみ」**として おだやかに
  - 「墜落」の 字は **「墜落制止用器具」という 名前の 中だけ** 使って よい(台本が 見る)。説明では「高い ところで 体を 支える 安全の 道具」の ように 書く
- 粉じん・騒音は「体を 守る ため マスクや 耳栓を 使う」の ように おだやかに

### 3. ⚠️⚠️ 寸法・強さ・値段の 数字を 書かない
- **mm・cm・kN・kg・円・%・割・倍 の 数字は 書かない**(台本が 止める)。建築基準法の 数字・木材の 強さの 値・柱の 太さ・金物の 本数も 書かない
- ⭕ **単位の 名前と 意味**は よい: 尺・寸・分・間・坪・畳 など。「1間は 約1.8m」「1尺は 約30.3cm」の ような **だれでも 確かめられる 単位の 大きさ**だけは 書いて よい
  (⚠️ cm の 字は 台本が 止めるので「1尺は 約30cm」も ダメ。尺・寸は「1尺は 10寸」「1寸は 10分」の ように 単位どうしで 書く。m だけは よい: 「1間は 6尺で、約1.8m」)
- 年(できごとの 年)は **まちがいない ときだけ**: 法隆寺(世界遺産 1993年)・建築基準法 1950年・伝統建築工匠の技(ユネスコ無形文化遺産 2020年)。あやしい ときは 年を 書かない
- 条の 番号(第◯条)は 書かない

### 4. 実在の 会社の 名前を 出さない
- **実在の 工務店・ハウスメーカー・ゼネコン・道具メーカー・商品・お店の 名前を 書かない**(台本が 止める)
- ⭕ 歴史上の 建物(法隆寺・伊勢神宮・出雲大社・東大寺・桂離宮・姫路城 など)と 歴史上の 人(聖徳太子・西岡常一・千利休 など。**亡くなった 人だけ**。生きている 職人の 名前は 入れない)は よい
- ⭕ 公の 組織・制度の 名前は よい: 厚生労働省・国土交通省・文化庁・中央職業能力開発協会・建築基準法・建築士法・労働安全衛生法・ユネスコ
- **言い伝えは 言い伝えと 書く**(左甚五郎 など:「〜と 言い伝えられています」)
- **宗教の よしあしを 書かない**。地鎮祭・上棟式・棟上げは「家づくりの 節目の 行事」として

### 5. 大工の 目線で 書く(ほかの ゲームと 同じ 語を 入れて よい)
- ✅ **整備士・社会・理科 など ほかの ゲームと 同じ ことばを 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。説明は **大工の 目線**で 書きなおす
- **読み(ひらがな)は 大工の 8つの 旅の 中で かぶらない**(台本が 止める)。下の「旅ごとに 入れる 語」を 守る。**ほかの 旅の 欄に ある 語は 入れない**
- 文体は **はじめから「〜です・ます」**(体言止めで はじめない)

### 6. 事実が あやしい 語は 入れない
- まちがいを 書くより 入れないほうが よい。読みが あやしい 語・意味が 地方で ちがう 語は さける
- **自分の ことばで 書く**。教科書・問題集・Wikipedia・公式の 文を 写さない

## 1語の 形(JSON)

```json
{"id":"dg-kanna","name":"鉋","reading":"かんな","journey":"dogu","category":"削る 道具","difficulty":1,
 "field":"道具","type":"concept","emoji":"🪵","mapNode":"dogu:kanna","relatedTerms":["dg-nomi"],
 "description":"木の 表面を うすく 削って、なめらかに する 大工道具です。日本の かんなは 手前に 引いて 使う ものが ふつうです。おとなの 大工さんが 使う 刃物です。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(大工の 現場で ふつうに 使う 書きかた。漢字・カタカナ)。むずかしい 漢字の 語でも name は 漢字で よい(読みは reading が 出す)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)
  - カタカナ語は ひらがなで(ツーバイフォー → つーばいふぉー、プレカット → ぷれかっと)
  - ⚠️ **大工の ことばは 読みが ゆれる**(鴨居・長押・框・垂木・桁・束・鼻隠し・破風 など)。ゆれる 語は **いちばん ふつうの 読みを reading** に、
    ほかを `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は 上級だけ・旅で 1〜2語まで
  - 読みの 例: 棟梁 とうりょう・工務店 こうむてん・地鎮祭 じちんさい・上棟式 じょうとうしき・在来工法 ざいらいこうほう・檜 ひのき・欅 けやき・柾目 まさめ・板目 いため・
    心材 しんざい・辺材 へんざい・鉋 かんな・鑿 のみ・玄能 げんのう・墨壺 すみつぼ・差金 さしがね・曲尺 かねじゃく・土台 どだい・梁 はり・桁 けた・筋かい すじかい・
    垂木 たるき・棟木 むなぎ・母屋 もや・束 つか・大引 おおびき・根太 ねだ・継手 つぎて・仕口 しぐち・蟻継ぎ ありつぎ・鎌継ぎ かまつぎ・金輪継ぎ かなわつぎ・
    規矩術 きくじゅつ・敷居 しきい・鴨居 かもい・長押 なげし・框 かまち・建具 たてぐ・造作 ぞうさく・宮大工 みやだいく・数寄屋 すきや・左官 さかん・鳶 とび・
    番匠 ばんしょう・式年遷宮 しきねんせんぐう
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級
- **field**: 学ぶ 分野。次の 8つの どれか(建築大工技能検定の 学科の 科目を めやすに した):
  `建築一般` `木材` `道具` `構造` `規矩・墨付け` `造作・仕上げ` `安全` `歴史`
  - めやす: 家づくりの 流れ・職人・図面・工法・法律・単位 → `建築一般` / 木の 種類・性質・木材加工品・材料 → `木材` /
    手道具・電動工具・機械・釘 → `道具` / 基礎・軸組・床組・小屋組・屋根・耐震・断熱 → `構造` / 継手・仕口・墨付け・規矩術・木割り → `規矩・墨付け` /
    内装・建具・和室・造作・仕上げ → `造作・仕上げ` / 安全の 道具・安全の しくみ → `安全` / 歴史の 建物・人・伝統 → `歴史`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(💀 🔫 🩸 💣 ⚔️ 🔪 は 使わない。🪚🪵🔨🏠🏗️🌲📐🧰⛩️🚪 など)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / 何の ために あるか / 家の どこに あるか・大工は どう 見るか」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  専門用語を 専門用語だけで 説明しない。「1人」「2人」は ふりがなが 読みまちがえるので **ひとり・ふたり** と ひらがなで 書く
- **example**: なくてもよい

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | 家や 道具で よく 聞く ことば。小学生でも 聞いた ことが ある(大工・柱・屋根・のこぎり・木目・和室) |
| 2 | 中級 | **建築大工技能士 2級・3級(国家検定)の 範囲の めやす** |
| 3 | 上級 | **建築大工技能士 1級・二級建築士の 構造の 範囲の めやす**: 規矩術・継手仕口の 名前・構造の こまかい 部材 |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる
(ならんだ 順が そのまま ステージの 順に なる)。

## ぜったいに 守ること

- **自分の ことばで 書く**。教科書・問題集・Wikipedia・公式の 文を 写さない
- **数字(mm・cm・kg・円・%・割・倍)は 書かない**。資格・制度の 事実は `tools/daiku/exam.txt` に 合わせる
- 「100マス計算」「百ます計算」の 字を 使わない

## 出すもの

`tools/daiku/terms-<旅id>.json` に JSON の 配列(70語)で 書く。書いたら
`python3 tools/daiku/terms_js.py --only <旅id>` で 形を 確かめる(まちがいが あれば 止まる)。
