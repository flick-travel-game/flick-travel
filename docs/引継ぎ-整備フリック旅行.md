- **レベル = 入門 → 3級 → 2級 → 1級 の 順**(株式が 知名度の 順に したのと 同じ。コースの 中は 打ちやすさ の順)

- 打ち終わると **「何を する 部品か」の 1〜2行** + すかし図に 📍(どこに あるか)
- 株式と 同じ **ふくしゅう**(まちがえた・時間がかかった・ひさしぶり を 先に)と **部品図鑑**(まだの 部品は ？？？)
- 数の めやす: 各旅 60〜150語、ぜんぶで 500〜800語。**10の倍数**に そろえる

## 図(📍を 立てる 絵) — からだの しくみを そのまま 使う

- からだは `body-front.webp` の 上に x,y(0〜1)で 📍(`SVG_MAPS` の `front`)。同じ形で:
  - **車の すかし図**(横から 見た 車。エンジン・トランスミッション・足まわり・ブレーキ・バッテリーが 見える)
  - **エンジンの 断面図**(ピストン・バルブ・クランク)
  - **バイクの すかし図**(横から)
- 絵は けいくんに ChatGPT で 作ってもらう。⚠️ **ラベル(字)は 入れない 絵**にして もらう(📍と 名前は ゲームが 出す)。
  ⚠️ **メーカーの ロゴ・車種が 分かる 形に しない**(ふつうの 車・ふつうの バイク)
- ⚠️ AI の 絵は 部品の 位置が 正しくないことが ある → **📍を 置く 前に 絵を 見て 確かめる**。まちがった 位置に 部品が 描かれていたら 作りなおしを 頼む

## ⚠️ 資格・安全・権利の 注意

- **自動車整備士は 国家資格**(国土交通省。試験は 日本自動車整備振興会連合会(JASPA)などが 行う)。
  ⚠️ **試験の 級・種類・制度は 変わることが ある** → 作る前に **国土交通省・JASPA の 公式ページで いまの 形を 確かめて** README に 日付つきで 書く(想像で 書かない)
- 画面の 言いかたは **「◯級 自動車整備士の 試験範囲の めやす」**。「合格できる」「公式」とは 書かない。ページの 下に「国土交通省・日本自動車整備振興会連合会とは 関係ありません」
- ⚠️ **過去問・市販の 問題集・教科書の 文を 写さない**(試験範囲を 知る 手がかりに するだけ。説明は 自分の ことばで)
- ⚠️ **安全**: このゲームは 部品の 名前と しくみを おぼえる もの。**整備の やりかた(分解・ブレーキの 作業・高電圧の あつかい)は 書かない**。
  案内に「実際の 整備は 資格を もつ 人・お店に まかせよう」。EV・ハイブリッドの 高電圧は「さわると 危ない」ことだけ 書く
- 数字(圧縮比・トルクの 値・規定値)は **確かな ときだけ**。車ごとに ちがう 値は 書かない
- **メーカー名・車の 名前・ロゴは 使わない**(商標。株式フリック旅行とは 別の 話)

## しくみで 気をつけること

  ⚠️ **よみは 整備の 現場で ふつうに 言う 読み**(例: 「ばね」「スプリング」どちらで 出すか そろえる。ゆれが ある ことばは 1つに 決めて README に 書く)
