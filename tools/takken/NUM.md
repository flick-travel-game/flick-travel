# フリック宅建士: 🔢 数字クイズの 作りかた

宅建は **数字が 合否を 分ける**(期間・面積・割合・日数・人数・金額)。数字を 4つから えらぶ クイズ。**約200問**。旅ごとの `tools/takken/num-<旅>.json` に 配列で(id は 旅の 中で n001 から)。

## 決まり
1. **facts-A/B/C.md に ある 数字だけ**。条文で 確かめた もの。統計・合格点・地価は 入れない
2. 正解 1つ + まちがい 3つ。まちがいは **試験で まぎらわしい 数字**(8日 → 10日・14日・20日 / 2週間 ↔ 1週間 / 2,000㎡ ↔ 5,000㎡ ↔ 10,000㎡ / 3か月 ↔ 6か月 / 10分の2 ↔ 10分の1 ↔ 10分の3)。同じ 単位で そろえる
3. 問い(`q`): 70字 以内。「〜は 何日以内?」の ように 答えが 数字に なる 形。主語と 条件を はっきり(自ら 売主・専任媒介 など)
4. `why`: 90字 以内・やさしい です・ます。`law`: 法律名 + 条
5. `j`: どの 旅か(kenri … kakaku)。`rs`: 科目(MARU.md と 同じ)
6. 同じ 数字を 2回 聞かない

## 形
{"id":"n001","j":"torihiki","rs":"宅建業法","q":"クーリング・オフが できるのは、その しくみを 書面で 告げられた 日から 何日?","a":"8日","opts":["8日","10日","14日","20日"],"why":"告げられた 日から 数えて 8日を すぎると、クーリング・オフは できません。","law":"宅建業法37条の2"}
