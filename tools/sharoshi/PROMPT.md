# フリック社労士: ことばの 作りかた(助手に 分けて 頼むときの 決まり)

けいくん 2026-11-11「社会保険労務士に **受かる レベル**に フリック問題で なれるように」。名前は **フリック社労士**(けいくん決定 2026-11-11)。まとめは `docs/フリック社会保険労務士-はじめかた.md`。
**1,000語(10の 旅 × 100語 = 入門15・中級30・上級55)**。ほかに ⭕❌ 一問一答(`MARU.md`)・🔢 数字クイズ(`NUM.md`)・📝 選択式の 練習(`SENTAKU.md`)。
⚠️ 2026-11-11 は 見本として **労働基準法(roki)だけ** 作る(けいくん「1つの 旅で 見本」)。

## ⚠️⚠️⚠️ いちばん 大事な 決まり(さいしょに 読む)
1. ⭐⭐ **数字は 条文・公式の 資料で 確かめた ものだけ**。`tools/sharoshi/facts-A.md`(労基法・安衛法・試験の 事実)に ある ものだけ。
   無い 数字は e-Gov 法令API v2(`https://laws.e-gov.go.jp/api/2/law_data/<法令ID>?law_full_text_format=json`)・厚生労働省 で 確かめてから。**記憶で 書かない**。確かめられない ものは 入れない
   ❌ 書かない 数字: 合格率・受験者数・白書や 統計の 数字・毎年 変わる 額を 年度なしで
2. ⭐⭐ **いまの 法令が 答え**(本番は 試験の 年の 4月10日 現在 施行の 法令。2026年11月 時点の 条文で 書く)。2024年4月の 労働条件明示の 追加・時間外の 上限規制の 建設・運転・医師への 適用・2025年6月の「拘禁刑」など。古い 名前・古い 答えは **name に しない**。説明に「前は ◯◯でした」の 1文だけ
3. **法令の ことばづかいに そろえる**(使用者・労働者・平均賃金・解雇予告手当・休業手当・労使協定・過半数代表者・所轄労働基準監督署長 …)。くだけた 名前は 説明の 中で「◯◯とも いいます」
4. ⭐ **科目の 札(ruleset)**: 労基・安衛 / 労災 / 雇用 / 徴収 / 労一 / 社一 / 健保 / 厚年 / 国年。roki と anei は **労基・安衛**。
   ⚠️ 労働契約法・パート有期法・育児介護休業法 などは **労一**(roki に 入れない。説明で「労働契約法では …」と ふれる のは よい)
5. ⭐ **似た 制度の 区別を 中心に**(上級): 解雇予告 30日 と 解雇制限 30日 / 休業手当 60%(労基26条)と 休業補償 60%(労基76条)/ 6時間を こえる 45分 と 8時間を こえる 1時間 / 1か月単位(就業規則でも)と 1年単位(労使協定だけ)/ 届出が いる 協定 と いらない 協定 / 意見を 聴く と 同意 / 5年(当分 3年)と 2年 / 「以上」と「こえる」/ 行政官庁の 認定・許可・届出
6. ⭐ **社労士の 目線**(会社と 働く 人の 手続きで どう 使うか・だれを 守る しくみか)。**人を こわがらせない・だれかを わるく 言わない**(会社・上司・働く 人)。トラブルは「どう ふせぐか」で 書く
7. 「死」の 字は 使わない(`terms_js.py` の `BAN`)。「死亡年月日」など 法令の ことばだけ `BAN_WORD_OK`。説明は「亡くなった とき」
8. **実在の 会社・個人・事件・判例の 当事者名を 書かない**。役所(厚生労働省・労働基準監督署・都道府県労働局)は よい
9. **本物の 試験問題・過去問・問題集・テキストの 文を 写さない**。自分の ことばで
10. **小学生も あそぶ**。入門は「働く 人なら 知っておきたい」くらしの ことば(給料・残業・有給休暇・休憩・労働時間・就業規則 など)。やさしい です・ます。迷ったら 入れない

## ゲームの かたち
「表示された ひらがなを フリックで 打ち写す」タイピング。打ち終わると 説明(1〜3文)が 出る。説明の 下に 📘 法律 と 📝 科目の 札。

## 旅と 図の 場所(mapNode = "<旅>:<場所>")
- `roki` 📜 労働基準法(rk-): gensoku 総則・労働条件の 原則 / keiyaku 労働契約・明示 / kaiko 解雇・退職 / chingin 賃金・平均賃金 / jikan 労働時間・休憩・休日 / henkei 変形労働時間制・フレックス / saburoku 時間外・36協定・割増 / minashi みなし労働・裁量・適用除外 / nenkyu 年次有給休暇 / hogo 年少者・妊産婦 / kisoku 就業規則・寄宿舎 / kantoku 記録・災害補償・監督・罰則
- ほかの 9つの 旅の 場所は `mkmeta.py` の `D`

## 旅ごとの 語数
**100語: difficulty 1 を 15語、2 を 30語、3 を 55語**。同じ difficulty の 中は 大事な・試験に よく 出る 順。JSON の 配列も 1 → 2 → 3 の 順。12の 場所に だいたい 均等に(1か所 5〜12語)

## ほかの ゲームと かぶる 語
