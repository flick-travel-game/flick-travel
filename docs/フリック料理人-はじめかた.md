## 2. はじめに けいくんに 聞く 5つ(「全部おすすめで」と 返ってくる ことが 多い)
1. **名前**: 「フリック料理人」か「フリックシェフ」か(絵が 届いたら 絵の 題名に そろえる。フォルダ名 `chef` は 変えない)
2. **旅の 分けかた**(おすすめ 7つ + 🏆 マスター):
   🥬 食材のことば(野菜・魚・肉・米・調味料の 名前と 旬 …)/ 🔪 切りかたと下ごしらえ(千切り・乱切り・面取り・かくし包丁・湯むき・霜降り …)/
   🍳 調理のわざ(炒める・煮る・蒸す・揚げる・だし・あく取り・とろみ・火加減の ことば …)/ 🍱 日本料理(和食の 献立・一汁三菜・懐石・郷土料理・出汁の 種類 …)/
   🍝 世界の料理(フランス・イタリア・中国 などの 料理と ことば: ソテー・コンフィ・アルデンテ・炒飯 …)/
   🧼 衛生と安全(食中毒・手洗い・HACCP・温度管理・アレルギー表示・食品衛生法 …)/ 🥗 栄養と食文化(五大栄養素・食事バランス・行事食・箸の 作法 …)
3. **むずかしさの 3段**: 入門(台所で 聞く ことば)→ 中級(**調理師試験の 6科目の 範囲の めやす**)→ 上級(専門の 用語・技能検定・フランス語/中国語の 厨房の ことば)
4. **1語に 持たせる 科目**(`field`): 調理師試験の 6科目(公衆衛生学 / 食品学 / 栄養学 / 食品衛生学 / 調理理論 / 食文化概論)の どれか。**確かめてから 決める**(下の 4)
5. **お酒の ことば**: 料理酒・みりんは 入れる / ワイン・日本酒の 銘柄や 飲みかたは **入れない**(子どもが あそぶ)。カクテル・バーの ことばは 無し

## 3. ⚠️⚠️⚠️ ぜったいの 決まり
- ✅ **ほかの ゲーム(パティシエ・からだ旅行・看護師 など)と 同じ 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」。医師・教師と 同じ)。
  ただし 説明は **料理人の 目線**で 書きなおす(パティシエの 文を そのまま 写さない)
- **読み(ひらがな)は 料理人の 7つの 旅の 中では かぶらない**(ほかの ゲームとは かぶって よい)
- **小学生も あそぶ**: 包丁・火・油・食中毒の ことばは 入れて よいが、**「安全に 使う ための ことば」「守る しくみ」の 書きかた**だけ。
  けがの ようす・こわい 先を 書かない。**子どもが 家で 1人で まねを したく なる 書きかた(火・油・包丁の やりかた)を しない**。
  画面に「火や 包丁を 使う ときは かならず 大人と いっしょに」を 出す
- **数字の 決めうちを 書かない**(温度・時間・分量。「中心温度 75℃で 1分」の ような 決まりは **法律・手引きの 数字なら 書いて よい**が、
  レシピの 数字は 書かない。**まよったら 書かない**)。パティシエと 同じ
- **お店の 名前・商品名・ブランド名**は 入れない(商標)。料理の 名前・地方の 名前は よい
- 画面(ホームの 下・遊びかた)に「これは ことばを おぼえる ゲームです。本物の 試験問題では ありません。都道府県・厚生労働省とは 関係ありません」
- **作った 助手とは 別の 助手が 1語ずつ 確かめる**(意味・読み・レシピの 数字を 書いていないか・子どもが まねを したく ならないか)。ふりがなも 全語 見る(`tools/ruby_fix.json`)

## 5. 作りかたの 手順(パティシエ・看護師の まとめと 同じ)
1. けいくんに 2 の 5つを 聞く → 返事を CLAUDE.md に 書く
2. `tools/chef/PROMPT.md` `meta.json` を 作る → 旅ごとに 助手に 70語ずつ 頼む(`PROMPT.md` を そのまま わたす)→ `terms-<旅>.json`
3. `terms_js.py` で 止められた 語を 直す → 別の 助手が 1語ずつ 確かめる → ふりがな
4. `chef/chef.js`(kango.js を 写す)・`build_games.py`・`index.html` の SERIES → `python3 tools/build_games.py`
5. 手元で 通す: `python3 -m http.server 8765` → `node tools/play-all.mjs`(4とおりの 打ちかた)/ `node tools/click-all.mjs`(W=320 も)
6. PR は **rebase で 取りこむ**(この 入れもの)。speed-king は squash。コミットの 末尾は Co-Authored-By と Claude-Session の 2行
7. かずとも `speed-king`: `FLICK_MODES` / `FLICK_LINK_TARGETS` に `chef`(PR → squash)。`HOME_GAMES` は 絵と OK の あと
8. けいくんに ChatGPT で 絵を 頼む 文を わたす(トップ 1536×1024 + 四角い 絵 1254px。**人物は 画面の 下 3分の1に 小さく**・指5本・首が 見える・**包丁を 持つ 手は 描かない**(手が 崩れやすい)。
   絵の 中の 字は「フリック料理人」だけ・ゲームに 無い 機能の 絵を 入れない)。届いたら **まず 字を 切り出して 読む**(「ごっかしけん」の 前例)
9. 絵を 入れたら CLAUDE.md に 節を 書く(名前・旅・語数・確かめた 日・入れなかった 語と 理由)
