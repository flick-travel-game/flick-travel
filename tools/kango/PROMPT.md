# フリック看護師: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
しくみ図の どこに あるか(📍)が 出る。あそぶのは **小学生〜看護師を めざす 学生・大人**。
**看護の ことばと 意味を おぼえる ゲーム**(試験の 問題集でも、医療の 手引きでも ない)。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 3つ

### 1. やりかたを 書かない(いちばん 大事)
- ❌ **書かない**: 薬の 量・注射や 点滴の しかた・心臓マッサージの 回数や 深さ・処置の 手順・
  「この しょうじょうなら この 病気」「こういう ときは こうする」の 言いかた・薬の 商品名
- ⭕ **書く**: その ことばが **何を さすか**・**何の ために あるか**・どこで 出てくるか
  (例: AED = 心臓の 動きが みだれた ときに 電気を 流して もとに もどす ための 機械。使いかたは 機械の 声が 教えてくれます)
- **数字は なるべく 出さない**(体温・脈・血圧の 決まった 数は 本や 年れいで ちがう)。
  どうしても 要る ときは「だいたいの めやす」と 書き、**まちがいない ものだけ**。まよったら 数字を 書かない

### 2. 子どもも あそぶ
- 血・苦しむ ようす・死ぬ ようす・こわい 先(「この 病気に なると こうなる」)を **書かない**
- 病気や けがの ことばは「看護師さんが どう 助けるか / 何の ための しくみか」を やさしく。**助ける 仕事**として 書く
- 死に かかわる ことば(看取り など)は 入れて よいが、**「その 人らしく すごせるように そばで 支える」** の ように おだやかに
- めずらしい 病気・こわい 病気(がんの 種類の 名前・命に かかわる 病名の ならび)は 入れない。**よく 聞く ものだけ**
- 読んだ 子が **こわく ならない**・**「助けてくれる 人が いる」と 思える** 書きかたに する。**迷ったら その 語を 入れない**

### 3. からだ旅行と かぶらせない
**フリックからだ旅行**に もう ある ことば(骨・筋肉・臓器・細胞・ツボ・体温・血圧・脈はく・発熱・脱水・呼吸・
免疫・ワクチン・予防接種・インフルエンザ・アレルギー・骨折・ねんざ・熱中症・かぜ・インスリン・血糖値 など)は **入れない**。
一覧は 頼む ときに わたす(`karada-words.txt`)。**同じ 字の ことばは 入れない**。
看護の 言いかた(検温・血圧測定・バイタルサイン・脱水症状 ではなく「脱水」は ダメ …)に 言いかえて よい。
**からだの 部品の 名前(心臓・肺・胃 …)は 見出しに しない**(説明の 中で 使うのは よい)

## 1語の 形(JSON)

```json
{"id":"ba-kenon","name":"検温","reading":"けんおん","journey":"vital","category":"はかる","difficulty":1,
 "field":"基礎看護学","type":"concept","emoji":"🌡","mapNode":"byoshitsu:taion","relatedTerms":["ba-vital"],
 "description":"体温を はかる こと。病院では 決まった 時間に はかって、いつもと ちがう ところが ないか 見ます。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(病院で ふつうに 使う 言いかた。漢字・カタカナ・英字の 略語)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白は ダメ)
  - カタカナ語は ひらがなに(ないちんげーる)
  - 英字の 略語は 下の「略語の 読み」の とおり。ない ものは 日本の ふつうの 読み
  - 数字は ひらがな(2類 → にるい)
  - ゆれる ことばは 1つに 決め、別の 読みは `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 読みは 入れない**。長い ことばは 短い 言いかたに する。16〜20字は **上級だけ**に、旅で 1〜2語まで
  - ⚠️ **読みを まちがえやすい ことば**(清拭 せいしき・褥瘡 じょくそう・喀痰 かくたん・誤嚥 ごえん・臥位 がい・仰臥位 ぎょうがい・
    側臥位 そくがい・腹臥位 ふくがい・端座位 たんざい・起座位 きざい・罨法 あんぽう・浣腸 かんちょう・導尿 どうにょう・吸引 きゅういん・
    嚥下 えんげ・悪心 おしん・嘔吐 おうと・咳嗽 がいそう・喘鳴 ぜんめい・浮腫 ふしゅ・褥婦 じょくふ・悪露 おろ・
    羞明 しゅうめい・疼痛 とうつう・掻痒感 そうようかん・失禁 しっきん・徘徊 はいかい)は **1語ずつ 確かめる**
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級(下の「3段の 分けかた」)
- **field**: 看護師国家試験の 出題基準の 科目。つぎの 11の どれか(入門の 語でも いちばん 近い ものを 書く):
  `人体の構造と機能` `疾病の成り立ちと回復の促進` `健康支援と社会保障制度` `基礎看護学` `成人看護学` `老年看護学`
  `小児看護学` `母性看護学` `精神看護学` `地域・在宅看護論` `看護の統合と実践`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(🩸 や 💀 など こわい 絵文字・注射器 💉 の 多用は さける)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / どこで 出てくるか / なぜ 大事か」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  専門用語を 専門用語だけで 説明しない
- **example**: なくてもよい

## 略語の 読み(1つに 決める)

ADL → えーでぃーえる / QOL → きゅーおーえる / AED → えーいーでぃー / CPR → しーぴーあーる /
SpO2 → えすぴーおーつー / ICU → あいしーゆー / MRI → えむあーるあい / CT → しーてぃー /
BMI → びーえむあい / NICU → えぬあいしーゆー / PPE → ぴーぴーいー / MRSA → えむあーるえすえー /
DNAR → でぃーえぬえーあーる(入れる なら 上級・おだやかに)/ IC → 使わない(インフォームドコンセントと 書く)

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | 病院で 見かける ことば。小学生でも 聞いた ことが ある / 絵が うかぶ(点滴・カルテ・車いす・ナースコール・手あらい) |
| 2 | 中級 | **看護師国家試験の 必修・一般の 範囲の めやす**。看護を 学ぶと 出てくる ことば(清拭・褥瘡・標準予防策・アセスメント) |
| 3 | 上級 | こまかい 制度・専門の ことばの めやす(保健師助産師看護師法・インフォームドコンセント・看取り) |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる
(ならんだ 順が そのまま ステージの 順に なる)。

## ぜったいに 守ること

- **自分の ことばで 書く**。過去問・問題集・教科書・看護手順書・法律の **本文を 写さない**
- **病院・薬・会社の 名前は 使わない**(商標)。薬は「痛みどめ」の ような 一般の 言いかた
- **数字は まちがいない ときだけ**(制度の「いつから」の 年は 書かない)
- 学者・歴史の 人の 話は **「〜と 考えた」「〜と 言われている」** の 形に
- 事実が あやしい 語は **入れない**(まちがいを 書くより 入れないほうが よい)
- ほかの 旅と **読みが かぶらない**(上の 入れる / 入れない を 守る)。**からだ旅行の ことばと 同じ 字の 見出しは 作らない**
- 「100マス計算」「百ます計算」の 字を 使わない

## 出すもの

`tools/kango/terms-<旅id>.json` に JSON の 配列(70語)で 書く。書いたら
`python3 tools/kango/terms_js.py --only <旅id>` で 形を 確かめる(まちがいが あれば 止まる)。
