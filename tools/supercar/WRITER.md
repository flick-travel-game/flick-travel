# ことばを 書く 係への おねがい(フリックスーパーカー。1つの 旅を 書く)

1. まず `tools/supercar/PROMPT.md` を ぜんぶ 読む(決まり・1語の 形・mapNode の 表)。手本の 書きぶりは `tools/cabin/terms-kihon.json`(キャビンアテンダント)と `tools/soccer/terms-legend.json`(サッカー。実在の 名前の 書きかた・country)
2. `tools/supercar/plan.json` の あなたの 旅の 110語を、**plan の 順番の まま**(name・reading・difficulty・mapNode は plan の とおり。直したい ときは 下の 6 を 見る)で 書く
   - phase 1 の 70語 → `tools/supercar/terms-<旅>.json`
   - phase 2 の 40語 → `tools/supercar/later/terms-<旅>.json`
   - relatedTerms は **同じ 旅の** id だけ(phase 1 の 語は phase 1 の 語に、phase 2 の 語は 自分の ファイル か phase 1 の ファイルの 語に つないで よい。⚠️ phase 1 の 語から phase 2 の 語へは つながない)
   - id は 旅の 頭文字(PROMPT.md)+ "-" + 英小文字。かぶらない ように
3. description は **スーパーカーの 目線**で、やさしい です・ます、語と 語の あいだに 半角スペース、130字以内。⭐ 説明は「何か → どこが すごいか / へえ と 思う 事実」。⭐ 車の すごさは **しくみ・デザイン・歴史**で 書く(お金・スピードの 自慢で 書かない)
4. country・maker・year・ei を PROMPT.md の とおりに 付ける(車には なるべく 全部。人には country)。year は **発表した 年**。自信が ない 年は 付けない
5. ⚠️ **事実は たしかな ものだけ**。年・エンジンの 形・デザイナー・限定の 台数は **WebSearch / WebFetch で Wikipedia(日本語 か 英語)や メーカーの 公式ページを 見て 確かめてから** 書く。確かめられない ものは **書かない**(数字を 外すか、説明を その ものの 意味だけに する)。
   馬力・最高速を 書く ときは「◯◯馬力 ほど」「テストコースで 時速 ◯km ほど」と まるめて、答えの 手がかりに しない(書かなくても よい)
6. plan の 語が 決まりに 合わない(お金・事故・あやしい 事実・戦争)と 思ったら、**同じ difficulty・同じ mapNode の 別の 語に かえて よい**。⚠️ その ときは かならず `python3 tools/supercar/terms_js.py --check --with-later` で 読みの かぶり(9つの 旅 ぜんぶ)が 0 か 確かめ、さいごの 報告に「かえた 語」を 書く
7. 書いたら `python3 tools/supercar/terms_js.py --check --with-later` を 走らせて、**あなたの 旅の 語**に ❌ が 出ない ことを 確かめる(ほかの 旅の ファイルが まだ 無い / 書きかけ の ことによる ❌ は 気に しない。⚠️ ほかの 旅の ファイルは さわらない)。⚠️ 長い 説明の ⚠️ も 直す
8. 報告は みじかく: 書いた 語数・かえた 語と 理由・自信が なくて ぼかした 事実・**確かめに 使った おもな ページ(URL)**

## よく まちがえる 事実(気を つける)
- **会社の 国**: ランボルギーニ = イタリア(親会社は ドイツ)・ブガッティ = フランス(モルスハイム)・ベントレー / ロールス・ロイス / ロータス / マクラーレン / アストンマーティン = イギリス・ケーニグセグ = スウェーデン・リマック = クロアチア・スパイカー = オランダ・ゼンヴォ = デンマーク・パガーニ = イタリア(創業者は アルゼンチン 生まれ)
- **年は 発表の 年**(コンセプトの 発表と 市販車の 発表が ちがう 車が ある。どちらの 年か 説明で わかる ように)

- **名前の 由来**の 説が 分かれる ものは「と 言われる」
