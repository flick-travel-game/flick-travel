## 3. ⚠️⚠️⚠️ ぜったいの 決まり(サッカーと 同じ)
- ⭐⭐ **数字が 変わる ものを 書かない**(この ゲームで いちばん 事故が 起きやすい):

  - ✅ **変わらない 事実は よい**: 国籍(代表)・ポジション・**得意な 技 / プレーの 特徴**・**過去の 受賞と その 年**(「◯◯年の MVP」)・**オリンピック / W杯の 優勝の 年と 国**・**引退した 選手の 所属の 歴史**
- ⚠️⚠️ **いまの 選手の 書きかた**(`star` の 旅): 「**◯◯代表の フォワード。長い 腕を 生かした ディフェンスと 3ポイントが 武器**」の ように **国・ポジション・プレーの 特徴**で 書く。**チーム名を 答えの 手がかりに しない**。
  答えに した 選手は `meta.json` に **確かめた 日**を つけて、**1年に 1回 見なおす**(引退・代表の 変更が あるため)
- ⭐ **ルールは 2つ ある**: **FIBA**(国際ルール。オリンピック・W杯・B リーグ・日本の 部活)と **NBA**。**どちらの 話か 説明に かならず 書く**。⚠️ ショットクロックの リセットの 秒数・クォーターの 長さ・ファウルアウトの 回数・3ポイントラインの 距離などは **その年の 版を 確かめて から**。`meta.json` に 「FIBA ◯年版 / NBA ◯年度で 確かめた」と 書く
- ✅ **実在の 選手・チーム・リーグ・大会の 名前は 入れて よい**(事実として。サッカーと 同じ)。
  ❌ ただし **絵には 描かない**(実在の 選手の 顔・チームの ロゴ・ユニフォーム・スポンサー・大会の ロゴ)。**商品名**(シューズの 名前など)は 説明にも 入れない
- **人を けなさない**: 「ダメな 選手」「負けた チーム」の 書きかたを しない。**フリースローを 外した 話・退場**など 人が 悲しんだ 場面は 入れない(名場面は **いい ほう** だけ)
- **ラフプレー・反則を すすめない**: 「フロッピング」は **反則の 名前として**(「ぶつかられた ふりを する 反則」)。ずるい 技としては 書かない
- **技は 「練習で 身に つける 技」として**。⚠️ **相手を ばかに する ための 技としては 書かない**
- **小学生も あそぶ**: ケガ・乱闘・差別・賭け・人の 死の 話は 入れない。**迷ったら 入れない**
- ✅ **ほかの ゲーム(世界旅行の 国・歴史の 人物・英語・フリックワールドサッカー など)と 同じ 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。説明は **バスケの 目線**で
  - ⚠️ サッカーと かさなる 語(**ピボット**・**アシスト**・**ハットトリック**は バスケでは 使わない・**オフェンス / ディフェンス**・**ゾーン**・**マンツーマン**)は、**バスケでの 意味**で 書く
- **読み(ひらがな)は ワールドバスケットボールの 9つの 旅の 中では かぶらない**(ほかの ゲームとは かぶって よい。`terms_js.py` が 止める)。⚠️ `legend` と `move`(カリーム と スカイフック)、`team` と `league`(NBA)、`kihon` と `tactic`(ポジション)、`legend` と `cup`(ドリームチーム)は かさなりやすい。**先に 9つの 旅の 語の 一覧を 1人の 助手に 作らせて** 置き場所を 決めてから 頼む
- **カタカナの 書きかたを そろえる**(JBA・B リーグ・日本の 新聞で よく 使う 書きかたに。例: 「レイカーズ」「セルティックス」「ユーロステップ」)。⚠️ 答えの 字が ゆれると フリックで 打てない。**別の 書きかたは `alias`(読み)で 受ける**
- 画面(ホームの 下・遊びかた)に「これは ことばを おぼえる ゲームです。**選手の 所属や 記録は 変わる ことが あります**」「FIBA・NBA・各リーグ・各チームとは 関係ありません」
- **作った 助手とは 別の 助手が 1語ずつ 確かめる**(**選手と 国・技と 使い手・年と 大会・ルールの 版と FIBA / NBA**・変わる 数字が 無いか・人を けなして いないか・商品名が 無いか)。ふりがなも 全語 見る(`tools/ruby_fix.json`)
