# フリックワールドバスケットボール: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
どの 国の 話か(国旗の 札)・ルールの 札(FIBA / NBA / 両方)・学ぶ 分野・しくみ図の どこに あるか(📍)が 出る。
あそぶのは **バスケが すきな 小学生〜中高生・ミニバスの コーチ・バスケが すきな 大人・解説者を めざす 人**。
**バスケの ことばと 意味を おぼえる ゲーム**(ニュースでも、試合の 記録集でも ない)。
もとは `tools/soccer/PROMPT.md`(ワールドサッカー)。けいくん 2026-10-10「ワールドバスケットボールの専門家(解説者)になれるレベルになるために必要な 知識、
主要バスケリーグ、有名バスケ選手、有名な技、ルールをフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」。
⭐ けいくんは **スポーツの 人**(サッカースクールの 代表・コーチ)。まちがいは すぐ 気づかれる。**選手と 国・技と 使い手・年と 大会・ルールと FIBA / NBA は かならず 確かめて から** 書く。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 9つ

### 1. ⭐⭐ 数字が 変わる ものを 書かない(いちばん 事故が 起きやすい)
- ❌ **いまの 所属チーム**(トレードで 変わる。NBA は シーズン中にも 動く)・年俸・契約金・いまの 順位・**通算得点 / 通算記録**(いまの 選手)・いまの 平均得点・いまの ヘッドコーチ・年齢(「◯歳」)
- ✅ **変わらない 事実は よい**: 国籍(代表)・ポジション・**得意な 技 / プレーの 特徴**・**過去の 受賞と その 年**(「2024年の MVP」)・
  **オリンピック / ワールドカップの 優勝の 年と 国**・**引退した 選手の 所属の 歴史**・ドラフトの 年・優勝回数(チーム)・ルールの 秒・分・距離
- リーグの **参加チーム数は 書かない**(変わる)。「アメリカと カナダの プロリーグ」まで
- ⚠️ 台本 `terms_js.py` が「年俸・トレード・通算・順位・◯歳・◯円・◯%」などを 止める

### 2. ⭐⭐ いまの スター選手(`star`)の 書きかた
- 「**◯◯代表の ガード。速い ドリブルと 長い 3ポイントが 武器**」の ように **代表の 国・ポジション・プレーの 特徴**で 書く
- ❌ **チーム名を 書かない**(説明にも 名前にも。NBA・WNBA・B リーグの チーム名ぜんぶ)。「所属」「在籍」「移籍」「加入」「契約」「トレード」も 書かない(台本が 止める)
- ✅ 代表で 勝った 大会(「2024年 パリ五輪で 金メダルの アメリカ代表の 一員」)・個人の 受賞と 年(「2023年の MVP」)・ドラフトの 年と 順位(チーム名は 書かない)は よい
- ⚠️ **2026年10月の 時点で 現役か** を 1人ずつ web で 確かめる。引退した 選手は 入れない(legend の 担当が 入れる)。
  **38歳を こえる 選手・引退が うわさの 選手**は 入れない(1年で 変わる)
- ⚠️ 選手の ケガ・不調・私生活・SNS・発言は 書かない

### 3. ⭐⭐ ルールは 2つ ある(FIBA と NBA)。**どちらの 話か かならず 書く**
- **FIBA** = 国際ルール(オリンピック・ワールドカップ・B リーグ・W リーグ・日本の 部活と ミニバス)。日本では JBA が 日本語版を 出す
- **NBA** = アメリカの プロリーグの ルール
- ルールの 語には **`ruleset` の 欄**を 付ける: `"FIBA"`(FIBA だけの 話 / FIBA の 数字を 書いた) / `"NBA"`(NBA だけの 話) / `"両方"`(どちらも 同じ)。
  ⚠️ 数字が ちがう ルール(クォーターの 長さ・ファウルアウトの 回数・3ポイントラインの 距離 など)は、説明に **両方の 数字を 書いて `"両方"`**、または **片方の 数字だけ 書いて その 片方**
- 事実は `tools/basket/exam.txt` の ①に 合わせる。**そこに 無い 数字は 書かない**(web で 確かめられた ときだけ)
- ⭐⭐ **いまの 版は FIBA Official Basketball Rules 2026**(2026年10月1日から。日本では JBA「2027 バスケットボール競技規則」。B リーグ・W リーグは 2026-27 シーズンから 先に 使っている)と **NBA Official Rules 2026-27**。
  ⚠️ **FIBA 2026 では「アンスポーツマンライク・ファウル」が なくなり、「ディスラプティブ・ファウル」と「フラグラント・ファウル」に 分かれた**。テクニカルファウルも 2つの 種類に 分かれた。
  「アンスポーツマンライク・ファウル」を 入れるなら「**2024年版までの** FIBA の よび名」と 書く。ノーチャージ・セミサークルは FIBA 2026 で **1.30メートル**
- 条の 番号(第◯条)は 書かない(台本が 止める)
- 迷う 細かい ところ(例外の 例外)は 書かない。**審判の 学ぶ 範囲**を 中心に

### 4. 実在の 選手・チーム・リーグ・大会の 名前は 入れて よい(事実として)
- ✅ 名前は よい。❌ **スポンサー名・チームの ロゴの 中身の 説明・ユニフォームの メーカー**は 書かない。会社名が 入る アリーナの 名前は 入れない
- ❌ **商品の 名前**(シューズ・ボールの 会社 など。「エア・ジョーダン」も だめ)。❌ **まんが・アニメの 登場人物**(⚠️ ダンクの「スラムダンク」・NBA の「スラムダンクコンテスト」は よい)
- カタカナは **JBA・B リーグ・日本の 新聞で よく 使う 書きかた**に そろえる(例: レイカーズ・セルティックス・ウォリアーズ・ユーロステップ・ピック&ロール)
- 別の 書きかた・読みは `acceptedReadings` で 受ける

### 5. 人を けなさない・悲しい 場面を 入れない
- 「ダメな 選手」「負けた チーム」の 書きかたを しない。**フリースローを 外した 話・退場・大敗**など 人が 悲しんだ 場面は 入れない(名場面は **いい ほう** だけ)
- ❌ 乱闘・差別・八百長・賭け・薬物・ケガ・死・事故・私生活・スキャンダルは 入れない(台本が 止める)
- 亡くなった 名選手も 入れて よいが「亡くなった」とは 書かない(功績で 書く。歴史の 人物と 同じ)

### 6. ラフプレー・反則を すすめない・相手を ばかに しない
- 「フロッピング」は **反則の 名前として**(「ぶつかられた ふりを する 反則」)。ずるい 技として 書かない
- ⭐ **技は「練習で 身に つける 技」として**。❌「相手を ばかに する」「挑発」の 書きかたを しない。
  「アンクルブレイク」は「相手が バランスを くずすほど 鋭い 切り返し」まで
- ⚠️ **技の 名前の もとは 説が 分かれる ものが 多い**。「◯◯が はじめた」と 言いきらず「◯◯の 得意技として 有名」「◯◯が 世界に 広めた」まで
  (例: スカイフック = カリーム・アブドゥル＝ジャバーの 得意技として 有名 / ドリームシェイク = アキーム・オラジュワンの 得意技として 有名)

### 7. ほかの ゲームと 同じ 語は 入れて よい(けいくん決定 2026-09-30)
- フリックワールドサッカー・世界旅行・英語 などと 同じ 語(アシスト・オフェンス・ディフェンス・マンツーマン・ゾーン・ピボット など)は、**バスケでの 意味**で 書く
- 読みが かぶっては いけないのは **ワールドバスケットボールの 9つの 旅の 中だけ**(台本が 止める)

### 8. 事実を 正しく(⭐ かならず 確かめる)
- **選手と 国・技と 使い手・年と 大会・チームと 町・ライバルの 組み合わせ・ルールの 数字と FIBA / NBA** は 1語ずつ web で 確かめる(記憶で 書かない)
- 大会・賞の 事実は `tools/basket/exam.txt` に 合わせる。そこに 無い 年・大会を 書くときは web で 確かめてから
- 事実が あやしい 語は 入れない。**自分の ことばで 書く**(Wikipedia・公式の 文を 写さない)

### 9. 小学生も あそぶ
- ケガ・乱闘・差別・賭け・人の 死の 話は 入れない。**迷ったら 入れない**

## 1語の 形(JSON)

```json
{"id":"mv-eurostep","name":"ユーロステップ","reading":"ゆーろすてっぷ","journey":"move","category":"ステップ","difficulty":1,
 "field":"技術","type":"concept","emoji":"🐍","mapNode":"move:footwork","relatedTerms":["mv-spin"],"country":"ヨーロッパ",
 "description":"ゴールに 向かう とちゅうで 左右に 大きく 1歩ずつ ふみ出して、守る 人を よける ステップです。ヨーロッパで よく 使われて いた 動きが、NBA でも 広まりました。"}
```
ルールの 語の 例:
```json
{"id":"rl-foulout","name":"ファウルアウト","reading":"ふぁうるあうと","journey":"rule","category":"ファウル","difficulty":1,
 "field":"ルール","type":"concept","emoji":"🖐️","mapNode":"rule:foul","relatedTerms":["rl-personal"],"ruleset":"両方",
 "description":"ファウルが 決まった 回数に なると、その 試合には もう 出られなく なる ことです。FIBA では 5回、NBA では 6回で ファウルアウトです。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(日本の 新聞・JBA で ふつうに 使う 書きかた。選手は「ステフィン・カリー」の ように ふつうに 知られた よび名)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)
  - カタカナ語は ひらがなで(ユーロステップ → ゆーろすてっぷ)。「・」「&」は 取る(ピック&ロール → ぴっくあんどろーる)
  - 数字・英字の 入る 名前は 読みで(3ポイント → すりーぽいんと、3x3 → すりーえっくすすりー、NBA → えぬびーえー、24秒 → にじゅうよんびょう)
  - ゆれる ことばは いちばん ふつうの 読みを reading に、ほかを `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は 上級だけ・旅で 1〜2語まで(長い 名前の 選手は ふつうに 知られた よび名に する)
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級(下の「3段の 分けかた」)
- **field**: 学ぶ 分野。次の 6つの どれか: `ルール` / `技術` / `戦術` / `リーグ・チーム` / `選手` / `大会・歴史`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(🩸 💀 ☠️ 🔪 🤕 🚑 😭 😱 は 使わない。🏀 ばかりに しない。国旗の 絵文字は 使わない(札で 出る ため))
- **country**(関係が あれば 付ける): その 選手・チーム・技・大会が どの 国の 話か。次の どれか。2〜3つなら「・」で(`"アメリカ・カナダ"`):
  `世界` `ヨーロッパ` `アジア` `アフリカ` `南アメリカ` `北中米` `オセアニア`
  `アメリカ` `カナダ` `メキシコ` `プエルトリコ` `ドミニカ共和国` `バハマ` `ブラジル` `アルゼンチン`
  `日本` `中国` `韓国` `フィリピン` `台湾` `イラン` `ヨルダン` `レバノン` `オーストラリア` `ニュージーランド`
  `セルビア` `スロベニア` `クロアチア` `モンテネグロ` `ボスニアヘルツェゴビナ` `ユーゴスラビア` `ソ連` `ロシア`
  `リトアニア` `ラトビア` `エストニア` `フィンランド` `スペイン` `フランス` `ドイツ` `イタリア` `ギリシャ` `トルコ`
  `イスラエル` `ポーランド` `チェコ` `ベルギー` `イギリス` `オランダ` `ウクライナ` `ジョージア`
  `ナイジェリア` `カメルーン` `セネガル` `南スーダン` `コンゴ民主共和国` `アンゴラ` `マリ` `エジプト`。
  選手は **代表の 国**(NBA の 選手でも 代表の 国)。ルール・きほんの ことばなど 国と 関係ない 語は 付けない(⚠️ アメリカで 生まれた ことば・ヨーロッパで 広まった 技 などは 付けて よい = へえ)
- **ruleset**(⭐ ルールの 語だけ。`rule` の 旅は ほぼ ぜんぶ、ほかの 旅でも ルールの 話なら): `"FIBA"` / `"NBA"` / `"両方"`(上の 3.)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / どんな 特徴か / へえ」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  文体は **はじめから「〜です・ます」**(体言止めで はじめない)。「1人」「2人」は ふりがなが 読みまちがえるので **ひとり・ふたり** に 言いかえる
- **example**: なくてもよい
- 「へえ」を 1文 入れると よい(「はじめの ゴールは 桃を 入れる かごだった」「NBA は 12分、国際ルールは 10分の クォーター」)

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | **バスケが すきな 小学生**。ポジション・きほんの ルール・だれでも 知っている 選手と 技と 大会の 名前 |
| 2 | 中級 | **ミニバスの コーチ・バスケが すきな 大人**。**審判の 学ぶ 範囲の めやす**の ルール・リーグと チーム・技の 中身・FIBA と NBA の ちがい |
| 3 | 上級 | **解説者**。戦術の ことば・スタッツの ことば・名コーチ・大会の 歴史・ルールの 細かい ところ |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる
(ならんだ 順が そのまま ステージの 順に なる)。

## 旅ごとに 入れる 語(⚠️ **読みが かぶると 台本が 止まる**。ほかの 旅の 欄に 書いてある 語は 入れない。ここに 無い 語を 足すのは よい)

⭐ 1つの 旅に **70語**(入門20・中級25・上級25)。下は **85〜100語の 候補**。多めに 書いて あるので **書く 人が えらぶ**(えらばなかった 語を ほかの 旅へ 動かさない)。
⭐ 候補の 選手の 現役 / 引退は **2026-10-10 に 一部だけ web で 確かめた**(田臥勇太・ダイアナ・タウラジ・吉田亜沙美・レブロン・ジェームズ)。⚠️ の 付いた 人は **書く 前に もう一度 確かめる**。

### 読み(ひらがな)の 決まり(⚠️ 9つの 旅で そろえる)
- 数字は **読む とおりに ひらがな**: 3ポイント → **すりーぽいんと** / 3x3 → **すりーえっくすすりー** / 24秒 → **にじゅうよんびょう** / 14秒 → **じゅうよんびょう** / 3秒ルール → **さんびょうるーる** / 8秒ルール → **はちびょうるーる** / 5秒ルール → **ごびょうるーる** / 360ダンク → **さんびゃくろくじゅうだんく** / 7戦4勝制 → **ななせんよんしょうせい** / 2-3ゾーン → **にーさんぞーん** / 3-2ゾーン → **さんにーぞーん** / 1-3-1ゾーン → **いちさんいちぞーん**
- 英字の 略は **英字の 読み**: NBA → **えぬびーえー** / WNBA → **だぶりゅーえぬびーえー** / NCAA → **えぬしーえーえー** / FIBA → **ふぃば** / JBA → **じぇいびーえー** / B.LEAGUE → **びーりーぐ** / Wリーグ → **だぶりゅーりーぐ** / MVP → **えむぶいぴー** / MIP → **えむあいぴー** / PER → **ぴーいーあーる** / +/- → **ぷらすまいなす** / eFG% → **いーえふじーぱーせんと** / TS% → **てぃーえすぱーせんと** / CBA → **しーびーえー** / NBL → **えぬびーえる**
- 「&」は **あんど**: ピック&ロール → **ぴっくあんどろーる** / キャッチ&シュート → **きゃっちあんどしゅーと** / ペース&スペース → **ぺーすあんどすぺーす** / ラン&ガン → **らんあんどがん**
- 中黒(・)・＝・長い音の 区切りは 読みに 入れない: カリーム・アブドゥル＝ジャバー → **かりーむあぶどぅるじゃばー**
- ヴ は **ぶ** で 読む(ノヴィツキー → **のびつきー**、ヴィクター → **びくたー**)。小さい ぃ・ぇ・ゅ は 残す(ウェンバンヤマ → **うぇんばんやま**)
- 選手は **ふつうに 知られた よび名**を reading に(⚠️ **20字 以内**)。長い 名前・名字だけの よび名は acceptedReadings に(例: シェイ・ギルジャス＝アレクサンダー → reading **しぇいぎるじゃすあれくさんだー**(15字)・acceptedReadings **えすじーえー**)
- ⚠️ 名字だけの 読み(**じょーだん**・**ばーど**・**まじっく** など)は reading に **しない**。かならず フルネーム(**まいけるじょーだん**)。名字だけに すると ほかの 語(チーム名・異名)と かぶりやすい

## ぜったいに 守ること

- **自分の ことばで 書く**。Wikipedia・公式の 文を 写さない
- **お金・年齢・通算記録・いまの 順位・いまの 所属は 書かない**。年と 大会・優勝回数・人数・ルールの 数字は よい。事実は `tools/basket/exam.txt` と web で 確かめる
- 「100マス計算」「百ます計算」の 字を 使わない
