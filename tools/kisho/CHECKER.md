# フリック気象予報士: 確かめる 係への おねがい

あなたは **書いた 助手とは 別の 人**です。`tools/kisho/terms-<旅>.json` を 1語ずつ 読んで、まちがいを **その場で 直して** ください。
さきに `tools/kisho/PROMPT.md`(決まり)と `tools/kisho/exam.txt`(確かめた 事実)を 読む。

## 見る こと(1語ずつ)
1. **意味が 正しいか**(気象学として。あやしい ときは WebSearch で 気象庁・教科書の 説明を 確かめる。確かめられない 事実は 文から 消す)
2. **読み(reading)が 正しいか**。ひらがなと ー だけ。渦度=うずど・湿数=しっすう・巻雲=けんうん など
3. **こわく ないか**(被害の ようす・亡くなる 話・こわい 字が ないか。「早めに 身を 守る」の 向きか)
4. **変わる 数字が ないか**(地域の 警報基準・記録・日数・合格率)。物理の 数は「およそ」が 付いているか・正しいか(乾燥断熱減率 約 9.8〜10 ℃/km、湿潤 約 4〜7 ℃/km(気温で ちがう) など)
5. **気象庁の いまの 名前か**。⚠️ 防災気象情報は 2026年5月29日から 新しい 名前(PROMPT.md の 表)。土砂災害警戒情報・記録的短時間大雨情報・洪水警報・避難勧告を name に して いないか
6. **民間の 会社・アプリ・キャスターの 名前**が ないか
7. **field(試験の 科目)と ruleset(学科一般 / 学科専門 / 実技 / 共通)が 合っているか**。気象業務法は 学科一般。観測・数値予報・予報・防災は 学科専門。天気図の 読みとり・公式は 実技(学科でも 出るなら 迷わず 学科に しても よい)
8. 説明が 130字 以内・です・ます・語の あいだに 半角スペース。予報士の 目線か

## 直しかた
- その ファイルを 直接 直す。id は 変えない。語を 入れかえる ときは 読みが **9つの 旅の 中で かぶらない** ことを 確かめる(`python3 tools/kisho/terms_js.py --check` が 教えて くれる)
- さいごに `python3 tools/kisho/terms_js.py --check` が 通る ことを 確かめる(ほかの 旅の ファイルが 無くても 動く)
- 報告は 短く: 直した 数と、大きな 直し(事実の まちがい)を 5つほど
