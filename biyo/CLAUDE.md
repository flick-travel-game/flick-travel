## フリック美容師(`biyo/`。けいくん 2026-09-29「美容師になれるレベルで」「ぜんぶおすすめで」)

- 旅は 7つ(カットとスタイル `bcut`・パーマとカラー `bperm`・髪と肌のしくみ `bkami`・美容の化学 `bkagaku`・清潔と衛生 `beisei`・メイク ネイル 着付け `bmake`・お店としくみ `bmise`)+ マスター `bmas`。
  **旅ごとに 80語(入門20・中級30・上級30)= 560語**。「美容師になれるレベルで」なので 中級+上級で 筆記の 課目の 大事な ことばを ひととおり
- むずかしさは 3段: 入門(美容室で 聞く ことば)→ 中級(**美容師国家試験の 筆記の 範囲の めやす**)→ 上級(こまかい 化学・制度・歴史の めやす)。
  1語ごとに **筆記の 8課目**(`field` → 画面では 📘 試験の 課目)を 持ち、図鑑で しぼれる
- ことばは `tools/biyo/terms-<旅>.json`(決まりは `tools/biyo/PROMPT.md`)→ `tools/biyo/terms_js.py` → `biyo/terms.js`。しくみは `biyo/biyo.js`(看護師を 写した。4択クイズ あり)。
  しくみ図は コードで 描く 箱の 図 7つ(`tools/biyo/make_meta.py` が meta.json を 作る)。**髪の 断面と 肌の 図**・**お店の 地図** ふくむ
- 試験の いまの形は `tools/biyo/meta.json` の `exam` に **確かめた日つき**(2026年9月29日に 理容師美容師試験研修センターの 合格基準・受験資格・第54回の 受験案内、厚生労働省の 美容師法で 確かめた):
  筆記 55問・60%以上 + 8課目 どれも 0点で ない / 実技は 衛生上の取扱 + カッティング・ワインディング / 養成施設は 昼間・夜間 2年以上・通信 3年以上
- ⚠️⚠️ **ほかの ゲームと 同じ 見出しを 入れない**(理科の pH・還元、からだの たんぱく質、看護の 消毒・手洗い … ぜんぶで 約1万語)。
  一覧は `tools/biyo/other-words.txt`(`make_other_words.py` が 作る。**ゲームが 増えたら 走らせなおす**)。`terms_js.py` が 止める
- ⚠️⚠️ **やりかたを 書かない**(薬の 混ぜかた・時間・濃さ・%・カットの 手順)。**見た目を わるく 言わない**(くせ毛・白髪・肌)。`BAN` が いくつか 止める。
  ⚠️ **顔そりは 理容師の 仕事**(理容師法)。美容師の 仕事と 書かない
- 作った 助手とは **別の 助手が 1語ずつ 確かめた**(意味・読み・かぶり・やりかた・見た目)。ふりがなの 読みまちがい 6つを `tools/ruby_fix.json` に context 付きで 足した(白髪・無彩色・薬機法・立毛筋・銀杏返し・ハチの 張りかた)
- ⚠️ ふりがなを 作るには `pip install sudachipy sudachidict_core`(`tools/make_ruby.py`)
- 絵(2026-09-29): けいくんの ChatGPT の 絵。トップ `biyo/hero.webp`(1536×1024)・四角い 絵(1254px)から アイコン・題名は `tools/biyo/logo_cut.py`(GrabCut。紺の ふちの そばの 鮮やかな 字を 種に する)。
