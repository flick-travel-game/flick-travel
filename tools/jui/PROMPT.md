# フリック獣医師: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
どの 動物の 話か(🐾 札)・学ぶ 分野(獣医師国家試験の 科目)・しくみ図の どこに あるか(📍)が 出る。
あそぶのは **小学生〜獣医学部を めざす 中高生・獣医学生・動物が すきな 大人**。
**動物の お医者さん(獣医師)の ことばと 意味を おぼえる ゲーム**(試験の 問題集でも、動物の 手当ての 手引きでも ない)。
もとは `tools/yakuzai/PROMPT.md`(薬剤師)と `tools/ishi/PROMPT.md`(医師)。
けいくん 2026-10-03「獣医師の専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 7つ

### 1. 治療の やりかたを 書かない(いちばん 大事)
- ❌ **書かない**: 薬の **量**・手術の **手順**・「この しょうじょうなら この 病気 / この 薬」・正常値の 数字(体温・心拍・呼吸の 数)・
  **家で できる 治療や 手当て**・ワクチンの **回数・時期**・寿命の 数字・薬や フードの **商品名**
- ⭕ **書く**: その ことばが **何を さすか**・**何の ために あるか**・**どんな しくみか**・獣医師は どう かかわるか
  (例: 聴診器 = からだの 中の 音を 聞く 道具です。動物は どこが 苦しいか 言えないので、心臓や 肺の 音から ようすを 考えます)
- ⭐ **「すぐ 動物病院へ」の 考えかたは 書いて よい**(動物の 安全に 役立つ):
  「いつもと ようすが ちがったら 早めに 動物病院へ」「人の 薬を 動物に あげない」「食べては いけない ものを 食べたら すぐ 動物病院に 電話」
- 薬は **グループの 名前と 目的と しくみだけ**。どの 病気に どれを どれだけ 使うかは 書かない

### 2. ⚠️⚠️ 動物の いのちの 終わりの 話を 書かない
- **安楽死・殺処分・と畜・寿命の 数字・死・動物実験の ようす**は 書かない(台本が「死」「殺」「安楽」「と畜」「処分」「寿命」「動物実験」を 止める)。
  **子どもは 自分の ペットを 思いうかべる**
- **保護犬・保護猫**は「新しい 家族を まって いる 犬や 猫。ゆずり受けて 家族に なれる」と 前向きに
- **食肉衛生検査**は「お店に ならぶ お肉が 安全か、獣医師が 確かめて いる」**まで**(と畜の ようすは 書かない)
- **動物が 年を とる 話**は「シニア期 = 年を とった ころ。ゆっくり すごせる 工夫を する」まで
- 「殺菌」は 使えないので **除菌・滅菌・消毒**。「死んだ 細胞」も 使わない

### 3. 小学生も あそぶ(こわく しない)
- 血・苦しむ ようす・こわい 先を 書かない。病気は **「何が 起きている 状態か」+「獣医さんが 助ける」** だけ
- **めずらしい 病気・こわい 病名の ならびは 入れない**。**迷ったら その 語を 入れない**
- **人獣共通感染症・家畜伝染病は こわく 書かない**: 「手洗い・予防注射・みんなで 防いで いる」で 終わる。動物を こわがらせる・きらいに させる 書きかたを しない
- **虐待・捨てる 話は 書かない**(台本が「虐待」「捨て」を 止める)。動物愛護管理法は「動物を 大切に する ための 法律」と 前向きに
- 避妊・去勢は「子どもが できない ように する 手術。病気の 予防にも なる」まで
- 読んだ 子が **こわく ならない**・**「助けて くれる 人が いる」と 思える** 書きかたに する

### 4. 品種と 病気を むすびつけない
- **品種名は よく 知られた もの だけ**(柴犬・トイプードル・チワワ・ゴールデンレトリバー・ラブラドールレトリバー・ダックスフンド・ポメラニアン・
  スコティッシュフォールド・アメリカンショートヘア・マンチカン・日本猫(雑種)など)
- ⚠️ **「◯◯犬は ◯◯の 病気に なりやすい」は 書かない**(その 犬を 飼って いる 子が 悲しむ)。品種の 説明は 生まれた 国・見た目・性格の めやすまで

### 5. 実在の 名前・商品・年ごとに 変わる 数字を 出さない
- **実在の 動物病院・動物園・水族館の 名前・ペットフード・動物の 薬の 商品名・会社名**を 書かない(台本が 止める)。
  **動物園の 有名な 動物の 名前(個体名)も 入れない**
- ⭕ 公の 組織・制度の 名前は よい: 農林水産省・環境省・厚生労働省・保健所・家畜保健衛生所・動物検疫所・WHO・WOAH(国際獣疫事務局)
- 人の 名前は 歴史として よい(**事実を 確かめて**。亡くなった 話は 書かない)
- **合格率・人数・%・円・年齢・体温・回数** は 書かない(台本が 止める)。試験の しくみは `tools/jui/exam.txt` に 合わせる。条の 番号(第◯条)も 書かない

### 6. 獣医師の 目線で 書く(ほかの ゲームと 同じ 語を 入れて よい)
- ✅ **医師・看護師・薬剤師・からだ旅行・理科の 生物・恐竜図鑑・農家 など ほかの ゲームと 同じ ことばを 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)
- ⚠️ ただし 説明は **獣医師の 目線**で 書きなおす: 「動物は 痛いと 言えない」「話せない 動物の かわりに 飼い主さんの 話と からだの サインから 考える」
  「犬と 猫と 人で ちがう」。農家 = 育てる / 獣医師 = 健康を 守る
- **読み(ひらがな)は 獣医師の 9つの 旅の 中で かぶらない**(台本が 止める)。下の「旅ごとに 入れる 語」を 守る。**ほかの 旅の 欄に ある 語は 入れない**
- 文体は **はじめから「〜です・ます」**(体言止めで はじめない)
- 「へえ」を 1文 入れると よい(「犬は 汗を ほとんど かかず、舌を 出して ハアハア する ことで 体温を 下げます」「鳥は 恐竜の なかま」)

### 7. 事実を 正しく
- 事実が あやしい 語は 入れない。**自分の ことばで 書く**(教科書・Wikipedia・公式の 文を 写さない)
- 「獣医士」「獣医者」の 打ちまちがいに 気を つける

## 1語の 形(JSON)

```json
{"id":"kr-panting","name":"パンティング","reading":"ぱんてぃんぐ","journey":"karada","category":"体温","difficulty":1,
 "field":"生理学","type":"concept","emoji":"🐕","mapNode":"karada:ase","relatedTerms":["kr-asesen"],"animal":"犬",
 "description":"犬が 舌を 出して ハアハアと 速く 息を する こと。犬は 汗を ほとんど かかないので、こうして 口や 舌から 熱を 逃がし、体温を 下げます。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(動物病院・教科書で ふつうに 使う 書きかた。漢字・カタカナ・英字の 略語)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)
  - カタカナ語は ひらがなで(トリミング → とりみんぐ)。英字の 略語は 下の「略語の 読み」の とおり
  - ゆれる ことばは いちばん ふつうの 読みを reading に、ほかを `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は 上級だけ・旅で 1〜2語まで
  - ⚠️ **読みを まちがえやすい ことば**(獣医師 じゅういし・反すう はんすう・第一胃 だいいちい・肉球 にくきゅう・跛行 はこう・
    外耳炎 がいじえん・歯石 しせき・誤飲 ごいん・分娩 ぶんべん・口蹄疫 こうていえき・豚熱 とんねつ・検疫 けんえき・
    疥癬 かいせん・瘤胃 りゅうい・乳房炎 にゅうぼうえん・削蹄 さくてい・蹄 ひづめ / てい・終生飼養 しゅうせいしよう)は **1語ずつ 確かめる**
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級(下の「3段の 分けかた」)
- **field**: 学ぶ 分野 = **獣医師国家試験の 科目**。次の どれか(入門の 語でも いちばん 近い ものを 書く):
  - `獣医療の基本(役割・倫理・法)` … 獣医師の 役割・倫理・動物福祉・法律・制度・歴史・動物病院の しくみ
  - `構造と機能` … 骨・内臓・からだの はたらき(解剖・生理)・動物ごとの からだの ちがい
  - `生殖と行動` … 発情・妊娠・お産・子育て・動物の 行動や しぐさ・しつけ
  - `薬理作用と毒性` … 動物の 薬の グループと しくみ・食べては いけない もの(中毒の 原因)・麻酔
  - `病原体と寄生体` … ウイルス・細菌・ノミ・マダニ・フィラリア・おなかの 虫
  - `病理・病態` … 病気の とき からだで 何が 起きているか(炎症・結石 など)
  - `検査と診断` … 問診・聴診・血液検査・レントゲン・エコー など 調べる こと
  - `治療と処置` … 手術・点滴・入院・リハビリ・看護(⚠️ 名前と 目的だけ)
  - `動物衛生と公衆衛生` … 家畜の 伝染病を 防ぐ・保健所・検疫・ワクチン・予防
  - `動物の飼育・衛生管理` … ペットや 家畜の 飼いかた・えさ・お手入れ・アニマルウェルフェア・動物園の 飼育
  - `食品衛生` … お肉・牛乳・卵の 安全・食肉衛生検査・食中毒
  - `人獣共通感染症` … 動物から 人へ うつる 病気と その 予防
  - `環境衛生` … 野生動物・生態系・外来種・水と 環境・ワンヘルス
  - `臨床(動物の病気)` … よく ある 病気の 名前(外耳炎・歯周病・乳房炎 など)
  (獣医師国家試験の 出題基準 令和7年度改正(第78回から)の 4つの カテゴリ = 獣医療の 基本的事項 / 獣医学の 基本的事項 / 衛生学に 関する 事項 / 獣医学の 臨床的事項 の 中の 項目を 14に まとめた もの)
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(💀 ☠️ 🩸 🔫 🔪 🥩 は 使わない。💉 の 多用も さける)
- **animal**(⭐ この ゲームだけの 欄。**なるべく 付ける**。どの 動物にも あてはまる 語は 付けないか「いろいろな動物」):
  `犬` `猫` `うさぎ` `ハムスター` `小鳥` `爬虫類` `魚` `牛` `豚` `鶏` `馬` `羊` `やぎ` `野生動物` `動物園の動物` `人と動物` `いろいろな動物` の どれか。
  2〜3つなら「・」で つなぐ(`"犬・猫"`)。説明の 上に 小さな 札で 出て「犬と 猫で ちがう!」が へえに なる
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / 何の ために あるか / 獣医師は どう 見るか」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  専門用語を 専門用語だけで 説明しない。「1人」「2人」「1頭」は ふりがなが 読みまちがえるので **ひとり・ふたり・1つ** などに 言いかえる
- **example**: なくてもよい

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | **ペットを 正しく 飼える 人**。動物の からだの ちがい・毎日の 世話・食べさせては いけない もの・予防の ことば。小学生でも 聞いた ことが ある |
| 2 | 中級 | **動物病院で 働く 人**。**愛玩動物看護師の 範囲の めやす**(検査の 名前・よく ある 病気・予防・飼い主への 説明・法律の 基本) |
| 3 | 上級 | **獣医師**。**獣医師国家試験の 範囲の めやす**(解剖・生理・病理・微生物・産業動物・公衆衛生・法規) |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる
(ならんだ 順が そのまま ステージの 順に なる)。

## ぜったいに 守ること

- **自分の ことばで 書く**。教科書・問題集・Wikipedia・公式の 文を 写さない
- **数字(%・円・回・歳・℃・頭・か月)は 書かない**。資格・制度の 事実は `tools/jui/exam.txt` に 合わせる
- 「獣医士」「獣医者」の 打ちまちがいに 気を つける
- 「100マス計算」「百ます計算」の 字を 使わない
