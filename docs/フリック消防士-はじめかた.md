## 2. はじめに けいくんに 聞く 5つ(「全部おすすめで」と 返ってくる ことが 多い)
1. **名前**: 「フリック消防士」で よいか(絵が 届いたら 絵の 題名に そろえる。フォルダ名 `shobo` は 変えない)
2. **旅の 分けかた**(おすすめ 7つ + 🏆 マスター):
   🚒 消防車と 道具の ことば(ポンプ車・はしご車・救急車・ホース・消火栓・防火服・空気呼吸器 … **名前と 役目だけ**)/
   🔥 火と 消火の ことば(燃える 3つの 条件・初期消火・消火器・スプリンクラー・延焼・放水 …)/
   🚑 救急と 救助の ことば(救急救命士・AED・心肺蘇生(**名前と 目的だけ**)・救助工作車・トリアージ …)/
   🏠 火事を ふせぐ(火災報知器・避難経路・防火管理者・消防設備点検・たばこ・コンロの 注意 …)/
   🌊 災害と 消防(地震・水害・土砂・緊急消防援助隊・ハイパーレスキュー・消防団・避難所 …)/
   ⚖️ 消防の 法律と しくみ(消防法・消防組織法・消防庁・市町村の 消防本部・消防署・階級(消防士〜消防総監)・119番 …)/
   🧭 消防士の 心と からだ(交代制の 勤務・訓練・体力・チームワーク・ことばづかい・公務員の 決まり …)
3. **むずかしさの 3段**: 入門(まちで 見かける 消防の ことば)→ 中級(**消防官採用試験の 教養試験 + 消防学校で 学ぶ ことばの めやす**)→ 上級(法律の 名前・設備の 専門用語・階級と 組織の こまかい ところ・**消防設備士・危険物取扱者**の 資格の ことば)
4. **1語に 持たせる 科目**(`field`): 消防学校の 教育の 大きな 分け(消防法規 / 火災防ぎょ / 救急 / 救助 / 予防 / 警防 / 体育・訓練 … の めやす)。**確かめてから 決める**
5. **入れない もの**(下の 3 と かさなる): 火の つけかた・燃えやすい ものの 組みあわせ・危険物の あつかいかた・救命処置の 手順・けがの ようす。**守る 側の ことばでも、まねできる 形には 書かない**

## 3. ⚠️⚠️⚠️ ぜったいの 決まり(看護師・警察官と 同じ。火は なおさら)
- ✅ **ほかの ゲーム(からだ旅行・看護師・警察官 など)と 同じ 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。ただし 説明は **消防士の 目線**で 書きなおす
- **読み(ひらがな)は 消防士の 7つの 旅の 中では かぶらない**(ほかの ゲームとは かぶって よい)
- **火の つけかた・広げかた・燃えやすい 組みあわせ・危険物の あつかい・救命処置の 手順(回数・深さ)・はしご・ロープの 使いかた** を **ぜったいに 書かない**。
  書くのは **その ことばが 何を さすか・何の ための しくみか**だけ(例: 消火器 = 小さな 火を 消す ための 道具。使いかたは 本体に 書いてあり、大人と いっしょに 練習します)
- **小学生も あそぶ**: 火事・事故・けが・死の ようすを 書かない。**「消防士が どう 守るか・助けるか」「どう 気をつければ よいか」の 書きかた**だけ。
  こわい 先・実際の 火災や 災害の 名前(**ただし 東日本大震災・阪神淡路大震災 など 防災教育で 学ぶ 大きな 災害は 名前だけ 入れて よい**。中身の ようすは 書かない)・実在の 人物は 入れない
- **子どもが 家で 1人で まねを したく なる 書きかた(火・コンロ・ライター・花火)を しない**。画面に「火を 使う ときは かならず 大人と いっしょに」を 出す
- **数字の 決めうち**(温度・時間・回数)は 書かない。**法律・手引きの 数字なら 書いて よい**(まよったら 書かない)
- 画面(ホームの 下・遊びかた)に「これは ことばを おぼえる ゲームです。本物の 試験問題では ありません。消防庁・市町村の 消防とは 関係ありません。火事や けがの ときは 119番」
- **作った 助手とは 別の 助手が 1語ずつ 確かめる**(意味・読み・やりかたを 書いていないか・こわくないか・まねできる 形に なっていないか)。ふりがなも 全語 見る(`tools/ruby_fix.json`)

## 5. 作りかたの 手順(看護師・医師・教師・料理人・警察官の まとめと 同じ)
1. けいくんに 2 の 5つを 聞く → 返事を CLAUDE.md に 書く
2. `tools/shobo/PROMPT.md` `meta.json` を 作る → 旅ごとに 助手に 70語ずつ 頼む(`PROMPT.md` を そのまま わたす)→ `terms-<旅>.json`
3. `terms_js.py` で 止められた 語を 直す → 別の 助手が 1語ずつ 確かめる → ふりがな
4. `shobo/shobo.js`(kango.js を 写す)・`build_games.py`・`index.html` の SERIES → `python3 tools/build_games.py`
5. 手元で 通す: `python3 -m http.server 8765` → `node tools/play-all.mjs`(4とおりの 打ちかた)/ `node tools/click-all.mjs`(W=320 も)
6. PR は **rebase で 取りこむ**(この 入れもの)。speed-king は squash。コミットの 末尾は Co-Authored-By と Claude-Session の 2行
7. かずとも `speed-king`: `FLICK_MODES` / `FLICK_LINK_TARGETS` に `shobo`(PR → squash)。`HOME_GAMES` は 絵と OK の あと
8. けいくんに ChatGPT で 絵を 頼む 文を わたす(トップ 1536×1024 + 四角い 絵 1254px。**人物は 画面の 下 3分の1に 小さく**・指5本・首が 見える・**燃えている 建物や けが人を 描かない**(消防車の 前で 敬礼・ホースを 持たない)。
   絵の 中の 字は「フリック消防士」だけ・ゲームに 無い 機能の 絵を 入れない・**本物の 消防の 紋章や 実在の 消防本部の 名前を 描かない**)。届いたら **まず 字を 切り出して 読む**(「ごっかしけん」の 前例)
9. 絵を 入れたら CLAUDE.md に 節を 書く(名前・旅・語数・確かめた 日・入れなかった 語と 理由)

- マイページ(右上の 1枚)は 土台の `index.html` に あるので、`SERIES` に 足すだけで 一覧の タイルにも 出る(絵は `shobo/apple-touch-icon.png`)
