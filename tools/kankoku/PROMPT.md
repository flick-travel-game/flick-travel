# フリック韓国語: ことばを 作る 決まり

子ども(小学生)〜大人が、**ハングルを 見て 🔊 で 聞きながら、読みの ひらがなを フリックで 打つ** ゲーム。
打ち終わると「日本語の 意味・例文」が 出る。**ネイティブが ふだん 使う ことば・文法・敬語・言いまわしを ひととおり 知る** のが ねらい。
⚠️ 「勉強っぽさ」は 出さない(TOPIK・検定・学年・「〜級」などの ことばは 書かない)。

## 出力(JSON の 配列だけ。指示された ファイルに 書く)

### ことば(単語の 旅・ハングルの 旅)
```json
{"text":"학교","pron":"학꾜","pos":"名詞","meaning":"学校","emoji":"🏫","category":"学校・勉強","example":"학교에 가요.","exampleJa":"学校に行きます。","note":"漢字語(学校)。日本語の「がっこう」と音がにている","difficulty":1}
```
### 文・フレーズ(文法と敬語・日常会話・ネイティブの表現)
```json
{"text":"이거 얼마예요?","pron":"이거 얼마에요","meaning":"これはいくらですか?","scene":"shop","style":"해요","who":"お店の人に","reply":"만 원이에요.","replyJa":"1万ウォンです。","tip":"指さして使える","difficulty":1}
```

### 各項目
- **text**: 画面に 出す ハングル(正しい つづり・分かち書き)。
  - 単語: 1語(きほん形。動詞・形容詞は 〜다)。**15字まで**
  - 文: **20字まで**(空白・記号も 数える)。使える 記号は 空白 . , ? ! だけ(数字・アルファベット・かっこ・〜 は なし。数は ハングルで 書く: 만 원)
- ⭐⭐ **pron**: **発音どおりの ハングル**(ゲームが この 字から 読みの ひらがなを 自動で 作る。**ひらがなは 書かない**)
  - 連音化(한국어 → 한구거)・鼻音化(감사합니다 → 감사함니다、국물 → 궁물)・濃音化(학교 → 학꾜)・激音化(좋다 → 조타)・
    流音化(신라 → 실라)・口蓋音化(같이 → 가치)・ㅎ の 弱まり(좋아요 → 조아요)を **ぜんぶ すませた** 形で 書く
  - 語の とちゅうの 의 は 이(회의 → 회이)、助詞の 의 は 에(나의 → 나에)。ㅖ は 子音の あとなら ㅔ(시계 → 시게)
  - 예요 は 에요、ㅆ어요 は 써요(있어요 → 이써요)。空白は text と 同じ 場所に 入れる。記号(? ! . ,)は 書かない
  - 発音が text と 同じなら text と 同じ 字を 書く
- **meaning**: 日本語の 意味(単語は 20字まで・文は 30字まで)。辞書を 写さず 自分の ことばで
- **emoji**: 合う 絵文字 1つ(❔ は 使わない)
- **pos**(単語だけ): 名詞 / 動詞 / 形容詞 / 副詞 / 代名詞 / 数詞 / 助詞 / 感動詞 / 連体詞 / 依存名詞 の どれか
- **category**(単語・ハングル・文法・ネイティブ): 指示された 分類から 1つ
- **scene**(日常会話だけ): 指示された 場面の id
- **style**(文だけ。かならず): その 文の 敬語の 段 = `합니다`(かしこまった)/ `해요`(ていねい)/ `반말`(ため口)
- **who**(文だけ。かならず): だれが だれに 言うか(15字まで)。例「店員さんに」「友だちに」「先生に」「お母さんが子どもに」。
  ⚠️ **年上・先生・店員さん・知らない人には 반말を 使わない**。반말は 友だち・年下・家族(親が子に)だけ
- **example / exampleJa**(単語・ハングル): その 語を 使った 短い・自然な 例文(30字まで)と その 訳
- **reply / replyJa**(文): 相手が 言いそうな 返事(なるべく 入れる。30字まで)
- **note**(なくてよい): へえ に なる ひとこと(40字まで)。漢字語なら「漢字語(約束)。日本語の やくそく と 音が にている」の ように
- **tip**(文。なくてよい): いつ 使うか の ひとこと(25字まで)
- **difficulty**: 1 入門(ハングルが 読めて あいさつ)/ 2 初級(旅行で 困らない)/ 3 中級(韓国の 友だちと ふつうに 話す。敬語と ため口の 使いわけ)/ 4 上級(ネイティブ: ニュース・ことわざ・くだけた 言いかた・文化)

## ⚠️⚠️ ぜったいの 決まり
- **韓国語は ソウルの 標準語で、ネイティブが いま ふつうに 使う 形**。古い 言いかた・直訳・日本語の 語順を そのまま 置きかえた 文は ダメ
- **市販の 単語帳・TOPIK の 過去問・教科書の 文を 写さない**。例文・訳は ぜんぶ 自分で 書く
- **敬語の 段を まちがえない**(style と 文の 語尾を そろえる)
- 子どもが 見るので、**お酒(焼酎・マッコリ)・たばこ・お金もうけ・こわい話・恋愛の 話**は 入れない。사랑해 は **家族に 言う 場面**なら よい
- **政治・歴史の あらそいの 話は 入れない**(日本と 韓国の 歴史問題・領土・北朝鮮・戦争・軍隊)。**国や 人を 下げる 書きかたを しない**
- **悪口・スラング・からかいの ことばは 入れない**(若者ことばは やさしい ものだけ。迷ったら 入れない)
- **実在の 芸能人・アイドル・グループ・ドラマ・お店・会社・商品の 名前を 入れない**(「K-POP」「ドラマ」という ことばまで は よい)
- ✅ 食べもの・地名・行事の 名前は よい(キムチ・ビビンバ・トッポッキ・ソウル・釜山・済州島・ソルラル・チュソク)
- 人名を 使うなら 민수 / 지민 / 서연 / 유키 / 켄 くらい
- 同じ text を 2回 入れない(ほかの 旅と かぶらないよう 指示された 一覧を 守る)
- 日本語は やさしく。小学生が 読める ていど(漢字は 使ってよい。あとで ふりがなを 付ける)。**日本語訳の 語の あいだに 半角スペースを 入れない**
- 「十分」(じゅうぶん と 読める)の ような 読みちがいを さける(→「10分」)
