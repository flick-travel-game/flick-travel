## フリックアドラー心理学(`adler/`。けいくん 2026-10-02「アドラー心理学の専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」・「劣等コンプレックス・神経症・不登校・ひきこもり」は「4つとも入れる」。まとめは `docs/フリックアドラー心理学-はじめかた.md`)

- 名前は「フリックアドラー心理学」(絵が 届いたら 題名に そろえる。フォルダ名 `adler` は 変えない)。シリーズの 絵文字は 🧠。`SERIES_ORDER` は 税理士の となり
- 旅は 7つ(アドラー心理学のきほん `kihon`・共同体感覚と対人関係 `kyodotai`・勇気づけ `yuki`・ライフスタイルと性格 `lifestyle`・子育てと学校 `kosodate`・カウンセリングと援助 `enjo`・アドラーの歴史と人びと `rekishi`)+ マスター。
  **旅ごとに 70語(入門20・中級25・上級25)= 490語**。かずともの 旅の 名前は **`ad` で はじめる**(adkihon / adkyodotai / adyuki / adlifestyle / adkosodate / adenjo / adrekishi / admas)
- むずかしさは 3段: 入門(本や 講座で まず 出る ことば)→ 中級(**日本アドラー心理学会の 基礎講座・入門書の 範囲の めやす**)→ 上級(専門用語・原語(ドイツ語・英語)の 訳語・歴史の 人名)。
  1語ごとに **分野**(`field` → 📘 分野)。資格の 科目は 無いので 7つ: 理論 / 対人関係 / 勇気づけ / ライフスタイル / 子育て・教育 / カウンセリング / 歴史
- ことばは `tools/adler/terms-<旅>.json`(決まりは `tools/adler/PROMPT.md`)→ `tools/adler/terms_js.py` → `adler/terms.js` + `data/adler.json`。
  しくみは `adler/adler.js`(税理士を 写した。4択クイズ あり。クイズの 文は「ことばの 意味を たしかめる 練習」「心理テストや こころの 診断では ありません」)。
  しくみ図は コードで 描く 箱の 図 7つ(**こころの地図(劣等感 → 補償 → 目標 …)**・**対人関係の図(課題の分離・横の関係・共同体感覚)**・勇気づけ・**ライフスタイルと3つの輪(仕事・交友・愛)**・家庭と教室・援助・歴史と人びと。`tools/adler/mkmeta.py`)。ホームでは たたんで ある
- **国家資格は 無い**。専門家に なる 道は `tools/adler/exam.txt`(→ meta.json の `exam`)に **確かめた日つき**(2026年10月2日に 日本アドラー心理学会の ページ(資格・沿革)と 公認心理師法の 施行の 資料で 確かめた):
  日本アドラー心理学会(1984年2月 設立)の 認定資格(カウンセラー・心理療法士・家族コンサルタント・EOLECTファシリテーター。カウンセラーは 基礎講座 理論編・実践編 → 中級 → 養成講座 → 試験、心理療法士は 認定カウンセラー + スーパーヴィジョン + 実技試験)/
  こころの 国家資格は 公認心理師(公認心理師法 2017年9月15日 施行・はじめての 試験 2018年)・民間は 臨床心理士 など / アドラー 1870年 ウィーンの 近くで 生まれ・1911年に フロイトの 会を 離れる。
  ⚠️ 「専門家に なれる レベル」は **資格の 試験では なく、学会の 基礎講座 〜 専門書の ことばを ひととおり 知っている** めやす
- ⚠️⚠️⚠️ **カウンセリング・心理療法の やりかた(手順・台本・「こう 言えば 変わる」)を 書かない**。技法(アズイフ・ボタン押し・再方向づけ …)は **名前と ねらいだけ**。「スープに唾」は 入れていない。
  **悩みの 相談の 答え・人を 診断する / 決めつける 書きかたを しない**。出生順位・4つの 型(支配型 …)は「アドラーは 〜の 傾向が あると 考えた。決まりでは ない」の **傾向の 話**として。
  画面に「カウンセリングの やりかたでも、悩みの 相談の 答えでも、こころの 診断でも ありません。こころの ことで こまったら 家族や 先生・専門の 人に 相談」「日本アドラー心理学会とは 関係ありません」
- ⚠️⚠️ **小学生も あそぶ**: 自殺・虐待・暴力・体罰・こわい ことば・病名(うつ病 など)は 入れない(台本が 止める)。不適切な行動の 4つの目的は **注目を得る・権力(力を示す)・仕返し・あきらめ(無気力の誇示)**(「復讐」の 字は 使わない)。
  ✅ **劣等コンプレックス・神経症・不登校・ひきこもりは 入れた**(けいくん決定 2026-10-02「4つとも入れる」)。「アドラー心理学では 〜と 考える」の 書きかたで、**ようす(症状・つらさ)は 書かない**。不登校・ひきこもりは **だれも せめず、まわりが 勇気づけで 支える** 向き
- ⚠️ **生きている 人の 名前・現代の 本の 書名は 入れない**(台本が『嫌われる勇気』『幸せになる勇気』と 著者名を 止める)。アドラーブームは「2010年代に 日本で アドラー心理学の 本が 広く 読まれた」とだけ。
  人物は 歴史上の 人だけ(アドラー・フロイト・ユング・ドライカース・アンスバッハー夫妻・アレクサンドラ / カート・アドラー・ラザースフェルド・ファイヒンガー・フルトミュラー など)。亡くなった ことは 書かない。日本の 人の 名前は 1人も 入れていない
- **フロイト・ユング・ほかの 学派(ロゴセラピー・来談者中心療法・認知療法)の よしあしを 書かない**。考えかたの ちがい だけ
- ✅ 教師・保育士・看護師 など ほかの ゲームと 同じ 語を 入れて よい(説明は アドラーの 目線)。読みは **アドラーの 7つの 旅の 中で** かぶらない(`terms_js.py` が 止める)
