# フリック哲学: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
分野・しくみ図の どこに あるか(📍)が 出る。ときどき「💭 考えて みよう」の 問いかけも 出る。
あそぶのは **考える ことが すきな 小学生〜高校「倫理」を 学ぶ 高校生・大学で 哲学を 学ぶ 人・大人**。
**哲学の 専門家に なるための ことばと 意味を おぼえる ゲーム**(哲学の 答えを 教える ものでは ない)。
もとは `tools/adler/PROMPT.md`(アドラー心理学)。まとめは `docs/フリック哲学-はじめかた.md`。
けいくん 2026-10-03「哲学の専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 7つ

### 1. 「どちらが 正しい」を 書かない(哲学は 立場が ならぶ 学問)
- 功利主義と 義務論、経験論と 合理論、性善説と 性悪説 などは **「〜と 考えた」「〜と いう 立場」**で 書き、勝ち負けを つけない
- ❌「〜が 正しい」「〜は まちがい」「〜を のりこえた(=前の 人が 負けた)」「正解は」
- ⭕ 後の 人が 前の 人を 批判した ときは「〜を 批判して、〜と 考えた」(どちらが 勝ったかは 書かない)

### 2. 人の 考えを 決めつけない
- 「〜と 考えた 人も いる」「〜と いう 見かたが ある」。**有名な ことばの 意味は ゆれる**ので、ひろく 知られた 読みかたを 1つ 書く
- ⚠️ **だれの ことばか の まちがいが いちばん 多い**。あやしい ものは 入れない:
  「知は 力なり」= ベーコン / 「人間は 考える葦である」= パスカル / 「万物は 流転する」= ヘラクレイトス(ことばは のちの 人が まとめた もの)/
  「われ思う、ゆえに われあり」= デカルト『方法序説』/「万物の 根源は 水」= タレス / 「人間は ポリス的動物」= アリストテレス /
  「天は 人の 上に 人を 造らず」= 福沢諭吉『学問のすゝめ』(「〜と 云えり」= 人の ことばとして 紹介した 形)/「和を もって 貴しと なす」= 十七条憲法(聖徳太子が つくったと 伝えられる)

### 3. こわく しない(小学生も あそぶ)
- ❌ **死・自殺・いのちを くらべる 話**: トロッコ問題・ソクラテスの 最期(毒)・カミュの「シーシュポスの神話」の はじまりの 問い・死生観・「死への 存在」は 入れない。
  台本が「死」「殺」「血」「処刑」「トロッコ」「不条理」を 止める。**「死」の 字は どこにも 書けない**(生まれた 年・亡くなった 年も 書かない。「◯世紀ごろの 人」「◯年ごろ 活やく」で)
- ハイデガーは **世界内存在・道具・気づかい** などで 書く。ニーチェの「神は〜」の 有名な ことばは **入れない**(超人・力への意志・永劫回帰・ルサンチマン は おだやかに)
- 水槽の脳 は 入れて よいが「頭の 中の 体験が 本物か 考える 思考実験」と おだやかに(手術などの 話は しない)
- こわい 絵文字(💀 ☠️ 🔪 🩸 ⚰️ 🪦)は 使わない

### 4. 宗教・政治は 中立に
- ブッダ・孔子・アウグスティヌス・トマス・親鸞・道元 などは **思想の 特徴**として。**どの 宗教が よい / 正しいは 書かない**。神の 存在の 議論は **名前だけ**
  (「神の 存在証明 = 神が いる ことを 理くつで 示そうと した 議論」)。宗教の 大きな しるし(✝️ ☪️ ☸️ 🕉 ✡️)は 絵文字に しない
- マルクス・ホッブズ・ロールズ などは **考えの 中身**だけ。**今の 国・政党・政治家・選挙を 書かない**(台本が 止める)

### 5. 昔の 哲学者の 差別的な 考えは 入れない
- 女性・ほかの 民族・身分(奴隷 など)に ついての 昔の 考えは 入れない。その 人の ほかの 考えで 書く(台本が「奴隷」「差別」「人種」を 止める)

### 6. やさしい ことばで 言いかえて から 専門の 名前を 出す
- むずかしい カタカナ語・ドイツ語を ならべない。「イデア = いつも 変わらない、ものの ほんとうの 形」の ように、**ふつうの ことばが 先**
- **本の 名前(『国家』『方法序説』『純粋理性批判』『論語』『善の研究』)は 書いて よい**(古典)。⚠️ 今 売っている 解説書・自己啓発書の 書名は 書かない
- **生きている 人の 名前は 入れない**(人物は 歴史上の 人だけ)

### 7. 哲学の 目線で 書く(社会旅行・歴史旅行・アドラー心理学・国語・AI旅行と 同じ 語を 入れて よい)
- ✅ ほかの ゲームと 同じ 語や 人を 入れて よい(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)
- ⚠️ ただし 説明は **哲学の 目線**(「この 人は 何を 問い、どう 考えたか」)で 書きなおす
  例: ソクラテス … 歴史旅行「古代ギリシャの 哲学者」/ 哲学「自分が 知らない ことを 知って いる(無知の知)と 考え、対話で ほんとうの 知を さがした 人」
- **読み(ひらがな)は 哲学の 9つの 旅の 中で かぶらない**(台本が 止める)。**人の 名前の 語は 1回だけ**(いちばん 合う 旅に)。
  ほかの 旅では **考えの 名前**(定言命法・社会契約説)で 出す。置き場所は `tools/tetsugaku/plan.json`(先に 決めた 一覧)を 守る

## 1語の 形(JSON)

```json
{"id":"kd-sokuratesu","name":"ソクラテス","reading":"そくらてす","journey":"kodai","category":"アテネの哲学者","difficulty":1,
 "field":"倫理学","type":"concept","emoji":"💬","mapNode":"kodai:sokrates","relatedTerms":["kd-muchinochi","kd-mondoho"],
 "description":"紀元前5世紀ごろの アテネの 哲学者。自分が 知らない ことを 知って いる ことが 知の はじまりだと 考え、まちの 人と 対話を かさねて「よく 生きる」とは 何かを 問いました。",
 "toi":"知らない ことを 知って いる のは、知って いる より かしこい?"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(高校の 倫理の 教科書で ふつうに 使う 書きかた。漢字・カタカナ)。⚠️ 年表の 名前と そろえる 人: plan.json の とおり
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」「、」は ダメ)
  - カタカナ語は ひらがなに(いであ)。ゆれる 読みは `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)。例: ウィトゲンシュタイン うぃとげんしゅたいん / びとげんしゅたいん
  - 「ヴ」は `ゔ` で 書き、バ行の 読みも acceptedReadings に(ヴィトゲンシュタイン)
  - ⚠️ **20字を こえる 読みは 入れない**(「われおもうゆえにわれあり」は 12字で よい)。16〜20字は 上級だけ・旅で 1〜2語まで
- **journey** / **difficulty**(`1` 入門 / `2` 中級 / `3` 上級)
- **field**: つぎの 9つの どれか: `形而上学` `認識論` `倫理学` `美学` `社会・政治哲学` `論理学` `心の哲学` `東洋思想` `日本思想`
  (人物は その 人の いちばん 有名な 考えの 分野。東洋の 旅は ふつう `東洋思想`、日本の 旅は ふつう `日本思想`)
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / だれが 考えたか / なぜ 大事か」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  人物は「◯世紀ごろの ◯◯の 哲学者」「◯年ごろ 活やく」(生まれた・亡くなった は 書かない)。
  「1人」「2人」は ふりがなが 読みまちがえるので **ひとり・ふたり** と ひらがなで 書く
- **toi**(任意): **💭 考えて みよう**。1文の 問いかけ・**「?」で 終わる**・**50字まで**・**答えは 書かない**。**1旅に 5〜10語**(台本が 数を 見る)。
  例: テセウスの船 →「部品を ぜんぶ かえた 船は、同じ 船?」/ 胡蝶の夢 →「いま 見て いるのが 夢では ないと、どう わかる?」。
  こわい 問い・いのちを くらべる 問い・宗教や 政治の よしあしを 聞く 問いは ダメ
- **example**: なくてもよい

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | **考える ことが すきな 子**: 有名な 哲学者の 名前と ひとこと・思考実験・「なぜ?」の ことば(ソクラテス・孔子・無知の知・イデア・テセウスの船) |
| 2 | 中級 | **高校「倫理」・共通テスト「公共，倫理」の 範囲の めやす**: 思想家と 考えの 中身・主な 本の 名前(定言命法・社会契約説・方法的懐疑・『純粋理性批判』) |
| 3 | 上級 | **大学の 哲学科の 入門〜専門書の ことばの めやす**: 立場の ちがい・現代哲学・日本の 哲学(志向性・言語ゲーム・反証可能性・純粋経験・間柄) |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる(ならんだ 順が そのまま ステージの 順)。

## 旅ごとに 入れる 語

**`tools/tetsugaku/plan.json` に 9つの 旅 × 70語の 置き場所(name・reading・difficulty)が 決めてある**。その とおりに 書く。
どうしても 事実が あやしい 語は 入れかえて よいが、**ほかの 旅の 語・読みと かぶらない**ように(plan.json を 見る)。入れかえたら 報告する

## ぜったいに 守ること

- **自分の ことばで 書く**。教科書・事典の 本文を 写さない
- **数字・年は まちがいない ときだけ**。事実が あやしい 語は **入れない**(まちがいを 書くより 入れないほうが よい)
- 人物の 話は **「〜を となえた」「〜と 考えた」「〜を ひらいた」** の 形に
- **人と 考えの 組み合わせ**(だれの ことば・だれの 本)を 1つずつ 確かめる

## 出すもの

`tools/tetsugaku/terms-<旅id>.json` に JSON の 配列(70語)で 書く。書いたら
`python3 tools/tetsugaku/terms_js.py --only <旅id>` で 形を 確かめる(まちがいが あれば 止まる)。
