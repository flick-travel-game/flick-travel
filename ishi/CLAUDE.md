## フリック医師(`ishi/`。けいくん 2026-09-30「医師になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」)

- 名前は「フリック医師」(絵が 届いたら 題名に そろえる。フォルダ名 `ishi` は 変えない)。シリーズの 絵文字は 🥼(看護師の 🩺 と かぶらないように)
- 旅は 7つ(診察のことば `shinsatsu`・検査のことば `kensa`・治療とくすりのことば `chiryo`・診療科と専門 `shinryo`・からだと病気のしくみ `byotai`・公衆衛生と予防 `koshu`・医師の制度と倫理 `seido`)+ マスター。
  **旅ごとに 70語(入門20・中級25・上級25)= 490語**。かずともの 旅の 名前は `i` で はじめる(ishinsatsu / ikensa / ichiryo / ishinryo / ibyotai / ikoshu / iseido / imas)。恐竜が `d` を 使っているので `d` に しない
- むずかしさは 3段: 入門(病院で 聞く ことば)→ 中級(**医師国家試験の 必修・一般の 範囲の めやす**)→ 上級(専門・制度の こまかい ところ)。
  1語ごとに **出題基準(令和6年版)の 区分**(`field` → 画面では 📘 試験の 区分。必修の基本的事項 + 医学総論の 9章 + 医学各論 = 11)。図鑑で しぼれる
- ことばは `tools/ishi/terms-<旅>.json`(決まりは `tools/ishi/PROMPT.md`)→ `tools/ishi/terms_js.py` → `ishi/terms.js` + `data/ishi.json`。
  しくみは `ishi/ishi.js`(看護師を 写した。4択クイズ あり)。しくみ図は コードで 描く 箱の 図 7つ(**診察室の地図**・検査室・治療・**病院の地図**・病気のしくみ・みんなの健康・医師のしごと。`tools/ishi/mkmeta.py` が meta.json を 作る)。ホームでは たたんで ある
- 試験の いまの形は `tools/ishi/meta.json` の `exam` に **確かめた日つき**(2026年9月30日に 厚生労働省の 第120回の 合格発表・第121回の 施行・令和6年版 出題基準と ブループリントで 確かめた):
  医師免許 = 厚生労働大臣(医師法)/ 医学部 6年(臨床実習の 前に 共用試験)→ 国家試験 → 臨床研修 2年 以上 / 年1回・2月(第120回は 2026年2月7日・8日、第121回は 2027年2月6日・7日)/
  第120回の 合格基準 = 必修 200点中 160点以上(一般 1点・臨床実地 3点)+ 必修以外 300点中 224点以上 + **禁忌肢問題を えらんだ 数が 3問 以下**。
  ⚠️ 数字は 毎年 変わる。文を 直すときは その日に 厚生労働省の ページで 確かめて `exam` の 日付も 上げる
- ⚠️⚠️⚠️ **医療の やりかたは 書かない**(薬の 量・処置や 手術の 手順・「この しょうじょうなら この 病気」・正常値の 数字・薬の 商品名)。**名前と 目的だけ**。
  救急蘇生・AED も 手順は 書かない(「機械の 声が 教えてくれる」まで)
- ⚠️⚠️ **小学生も あそぶ**。がんは しくみの ことばとして 1語だけ・おだやかに(がんの 種類の 名前・転移 は 入れない)。死亡・脳死・安楽死・死亡診断書 は 入れない(`terms_js.py` の `BAN`)。
  野口英世も 亡くなった 話は 書かない。アポトーシスは「役目を 終えた 細胞が 静かに いなくなる しくみ」
- ✅ **からだ旅行・看護師と 同じ 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。看護師の `karada-words.txt` の 止めは 写していない。説明は 医師の 目線で 書きなおした
