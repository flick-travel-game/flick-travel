# フリックポルトガル語: ことばを 作る 決まり

子ども(小学生)〜大人が、**ポルトガル語を 見て 🔊 で 聞きながら、読みの ひらがなを フリックで 打つ** ゲーム
(「⌨️ 打ちかた」で ABC に すると ポルトガル語の つづりを 打つ。アクセント記号と ç は 打たなくても 正解)。
打ち終わると「日本語の 意味・例文」が 出る。**ネイティブが ふだん 使う ことば・文法・活用・言いまわしを ひととおり 知る** のが ねらい。
⭐ **基本は ブラジルの ポルトガル語**(けいくん決定 2026-11-06)。ポルトガル(リスボン)だけの 言いかたは region の 札で。
⚠️ 「勉強っぽさ」は 出さない(CELPE-Bras・検定・学年・「〜級」などの ことばは 書かない)。

## 出力(JSON の 配列だけ。指示された ファイルに 書く)

### ことば(単語の 旅・発音の 旅)
```json
{"text":"o livro","pos":"名詞","meaning":"本","emoji":"📕","category":"学校・勉強","example":"Eu leio um livro.","exampleJa":"わたしは本を読みます。","note":"男性名詞。スペイン語でも el libro","difficulty":1}
```
### 文・フレーズ(文法と活用・日常会話・ネイティブの表現)
```json
{"text":"Quanto custa isso?","meaning":"これはいくらですか?","scene":"shop","style":"você","who":"お店の人に","reply":"Custa dez reais.","replyJa":"10レアルです。","tip":"指さして使える","difficulty":1}
```

### 各項目
- **text**: 画面に 出す ポルトガル語。**アクセント記号(á â à é ê í ó ô ú ã õ)と ç を かならず 正しく**(1990年の つづりの 取り決めの あとの 形: ideia・voo・ü は 使わない)
  - 単語: **名詞は かならず 定冠詞を つける**(o livro / a mesa / os sapatos / as frutas)。動詞は 原形(-ar / -er / -ir)、形容詞は **男性形単数**。**24字まで**
  - 文: **40字まで**(空白・記号も 数える)。使える 記号は 空白 . , ? ! と 語の 中の ハイフン(-)だけ(数字・かっこ・〜・「」・¿ ¡ は なし。数は 文字で: dez reais)
  - 打つ ゲームなので、なるべく 短く 自然に
- **pron**(なくてよい): ゲームは text から ブラジルの 読みの ひらがなを **自動で** 作る(下の「読みの 表」)。
  **表どおりに 読まない 語だけ**、読みどおりの ポルトガル語の つづりを 書く。**ひらがなは 書かない**。例:
  táxi → "táksi" / exemplo → "ezemplo" / próximo → "prósimo" / máximo → "másimo" / desculpa → "disculpa" / pizza → "pitsa" / muito → "muinto" / menino → "mininu"(ふつうは 書かなくて よい)
  ⚠️ x を くす・ず・す と 読む 語は かならず pron(表は x を しゃ行に する)
- **meaning**: 日本語の 意味(単語は 20字まで・文は 30字まで)。辞書を 写さず 自分の ことばで
- **emoji**: 合う 絵文字 1つ(❔ は 使わない)
- **pos**(単語だけ): 名詞 / 動詞 / 形容詞 / 副詞 / 代名詞 / 数詞 / 前置詞 / 接続詞 / 感動詞 / 冠詞 / 表現 の どれか(ことわざ・慣用句は 表現)
- **category**(単語・発音・文法・ネイティブ): 指示された 分類から 1つ
- **scene**(日常会話だけ): 指示された 場面の id
- **style**(文だけ。かならず): その 文の 話しかけかた = `você`(ブラジルの ふだん。友だち・家族・お店の人に)/ `tu`(親しい 人に。ポルトガルの ふだん・ブラジルの 一部)/
  `o senhor`(年上・先生・お客さまに ていねいに。a senhora も これ)/ `vocês`(みんなに)/ `-`(だれかに 話しかける 形では ない。例: Está calor.)
- **who**(文だけ。かならず): だれが だれに 言うか(15字まで)。例「店員さんに」「友だちに」「先生に」「お母さんが子どもに」。
  ⚠️ **年上・先生・お年よりへの ていねいな 文は o senhor / a senhora**
- **region**(なくてよい): その 言いかたが **ブラジルで よく 使う**なら `BR`、**ポルトガルで よく 使う**なら `PT`。どちらでも 通じるなら 書かない。
  ⭐ ちがう 言いかたが ある 語は 両方 入れてよい(ônibus(BR)/ autocarro(PT))。note に もう一方を 書く。**どちらが 正しい とは 書かない**
- **example / exampleJa**(単語・発音): その 語を 使った 短い・自然な 例文(40字まで)と その 訳
- **reply / replyJa**(文): 相手が 言いそうな 返事(なるべく 入れる。40字まで)
- **note**(なくてよい): へえ に なる ひとこと(40字まで)。スペイン語・英語と にている 語・**にているのに 意味が ちがう 語**は ここに
- **tip**(文。なくてよい): いつ 使うか の ひとこと(25字まで)
- **difficulty**: 1 入門(発音が 読めて あいさつ)/ 2 初級(旅行や まちで 困らない)/ 3 中級(友だちと ふつうに 話す。過去形・você と o senhor)/ 4 上級(ネイティブ: 接続法・ことわざ・国ごとの 言いまわし・文化)

## 読みの 表(ゲームが 自動で 作る。知っておくと pron が いるか 分かる)
- 母音 あいうえお。のばす 音(ー)は 書かない
- **語の おわりの 記号の ない e / es → い / いす、o / os → う / うす**(leite → れいち・obrigado → おぶりがどぅ)。você・avô・café は え / お の まま
- **ti di → ち ぢ。語の おわりの te de も ち ぢ**(noite → のいち・cidade → しだぢ・de → ぢ)
- **語の おわりと 子音の 前の l → う**(Brasil → ぶらじう・alto → あうとぅ)
- **語の はじめの r と rr → は行**(Rio → ひう・carro → かふ)。母音の あいだの r → ら行。子音の 前と おわりの r → る
- lh → りゃ行・nh → にゃ行・ch → しゃ行・j と ge gi → じゃ行・ç と ce ci → さ行・**x → しゃ行**(ちがう 語は pron)
- s: 語の はじめ・ss → さ行、母音の あいだ → ざ行(casa → かざ)。z → ざ行
- 鼻に ぬける 音: ão → あうん・ãe → あいん・õe → おいん・ã → あん・母音 + m / n → ん・おわりの em → えいん(bem → べいん)・おわりの am → あうん
- 語の はじめの es + 子音 → いす(estou → いすとう)
- 子音の あとに 母音が ない とき: d → ぢ・t → ち・p → ぴ(advogado → あぢぼがどぅ)。br pr tr cl などは ぶ ぷ と く

## ⚠️⚠️ ぜったいの 決まり
- **ポルトガル語は ネイティブが いま ふつうに 使う 形**。直訳・日本語の 語順を そのまま 置きかえた 文は ダメ。ふだんの 例文は **ブラジルの 形**(você・a gente も よい)
- **名詞の 性と、形容詞・冠詞の 性と 数を そろえる**(a casa branca / os meninos pequenos)。**動詞の 活用を 主語に 合わせる**(você は 3人称の 活用)
- ⭐ **obrigado / obrigada**: 言う 人が 男なら obrigado、女なら obrigada。例文・文の who に だれが 言うかを 書く
- **冠詞と 前置詞の くっつき**を 正しく(de + o = do・em + a = na・a + a = à・por + o = pelo)
- **市販の 単語帳・試験の 過去問・教科書の 文を 写さない**。例文・訳は ぜんぶ 自分で 書く
- 子どもが 見るので、**お酒(cerveja・vinho・cachaça・caipirinha)・たばこ・お金もうけ・こわい話・恋愛の 話**は 入れない。Te amo は **家族に 言う 場面**なら よい
- **下品な 語・スラングの 悪口・からかいは 1語も 入れない**(feio・gordo・burro・chato・bobo も 人に 向けない)。
  ⚠️⚠️ **国に よって 下品・差別に なる 語は 入れない**: rapariga(🇵🇹 女の子 / 🇧🇷 下品)・puto(🇵🇹 男の子 / 🇧🇷 下品)・bicha(🇵🇹 行列 / 🇧🇷 差別の 語)・
  rola・pica・pinto・grelo・cacete・pau・veado・bunda・macaco など。**ポルトガルで ふつうでも ブラジルで 下品なら 入れない。迷ったら 入れない**(ゲームが 止める)
  「行列」は a fila、「女の子」は a menina、「男の子」は o menino、「ひよこ」は o pintinho も 使わない(o filhote などで)
- ⚠️ **記号を はずすと 子どもに 不向きな 語に なる 語は 入れない**: cocô(うんち)は 入れない(o coco = ココナツは よい)
- ⚠️ **記号だけで 意味が 変わる 大事な 組は、1つの 短い 文で 両方 見せる**(単語の 一覧に 片方ずつ 入れない):
  avô / avó・pais / país・e / é・por / pôr・da / dá・nos / nós・pode / pôde・esta / está(例: O meu avô e a minha avó.)
- **政治・歴史の あらそいの 話は 入れない**(植民地・奴隷・独裁の よしあし・移民の 問題)。**貧しさや 治安を 下げて 書かない**(ファヴェーラの 名前ごと 入れない)。**国や 人を 下げる 書きかたを しない**
- **実在の 芸能人・歌手・サッカー選手・クラブ・ドラマ・お店・会社・商品の 名前を 入れない**(「サッカー」「歌」「サンバ」という ことばまでは よい)
- ✅ 食べもの・地名・行事・文化の 名前は よい(feijoada・pão de queijo・brigadeiro・açaí・pastel de nata・Rio de Janeiro・São Paulo・Lisboa・Porto・Carnaval・festa junina・samba・bossa nova・capoeira・fado・saudade)
- 人名を 使うなら Ana / Maria / Pedro / Lucas / Beatriz / Rafael / Yuki / Ken くらい
- 乾杯の Saúde! は 使わない(お酒の 場面に なる)。Saúde! は **くしゃみの とき**の 場面で
- 同じ text を 2回 入れない(アクセント記号を はずして くらべる。ほかの 旅と かぶらないよう 指示された 一覧を 守る)
- 日本語は やさしく。小学生が 読める ていど(漢字は 使ってよい。あとで ふりがなを 付ける)。**日本語訳の 語の あいだに 半角スペースを 入れない**
- 「十分」(じゅうぶん と 読める)の ような 読みちがいを さける(→「10分」)
