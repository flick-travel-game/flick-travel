# フリックITパスポート: 🔢 数字・計算クイズの 作りかた

ITパスポートは **数字 より 計算と 略語**(まとめの 6)。数字を おぼえる 問題に **計算の 問題**(2進数・稼働率・損益分岐点・表計算の 式・SQL の 結果・転送時間・ビットと バイト・ROI・期待値)を 多く 入れる。4つから えらぶ。**約220問**。旅ごとの `tools/itpass/num-<旅>.json` に 配列で(id は 旅の 中で n001 から)。

## 旅ごとの 数(めやす)
keiei 25(損益分岐点・粗利・ROE・ROI・減価償却(定額法)・在庫)/ homu 15(著作権の 保護期間・特許の 存続期間・法律の 数字)/ senryaku 20(市場シェア・ABC 分析の 割合・パレート・RFM・損益)/ shisutemu 15(投資の 回収・人月 ✕ 単価・見積)/ kaihatsu 25(アローダイアグラムの クリティカルパス・人月・ファンクションポイント・進み具合)/ service 15(稼働時間・SLA の 稼働率・MTBF と MTTR)/ kiso 30(2進数 ↔ 10進数 ↔ 16進数・論理演算・確率・組合せ・情報量 2ⁿ)/ konpyuta 30(直列 / 並列の 稼働率・クロック と 命令数・表計算の 相対参照 / 絶対参照・画像の データ量)/ nettowaku 25(転送時間(ビット ↔ バイト)・IP アドレスの 数・SQL の 結果の 行数・ポート番号)/ sekyuriti 20(公開鍵 / 共通鍵の 鍵の 数・パスワードの 組合せの 数・リスク値)

## 決まり
1. 事実の 数字は **facts-A/B/C.md に ある ものだけ**(シラバス・公式で 確かめた もの)。計算の 問題は **自分で 計算して 答えを 2回 確かめる**(python で 計算して よい)。合格率・統計は 入れない
2. 正解 1つ + まちがい 3つ。まちがいは **よく ある まちがい**(2進数の 桁ずれ・直列と 並列の 取りちがえ・ビットと バイトの 8倍・%の 計算の 順・クリティカルパスを 短い ほうで 取る)。同じ 単位で そろえる
3. 問い(`q`): **100字 以内**。答えが 数字(か 短い 式・記号)に なる 形。計算に 要る 数は ぜんぶ 問いに 書く(図は 使えない。アローダイアグラムは「A(3日)→ B(2日)…」の ように 字で)
4. `why`: **110字 以内**・やさしい です・ます。計算の 問題は **式を 1行**(例「0.9 × 0.9 = 0.81」)。`law`: 法律名(条)か シラバスの 小分類の 名前
5. `j`: どの 旅か。`rs`: 分野の 札(MARU.md の 12 と 同じ)
6. 同じ 数字・同じ 計算を 2回 聞かない。⭐ 計算問題を 各旅の 半分 以上(homu を のぞく)
7. 表計算の 式は シラバスの 書きかたに 近い 一般的な 形(`=A1*$B$1` など)で、製品名は 書かない
