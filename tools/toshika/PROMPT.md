# フリック投資家: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
学ぶ 分野・しくみ図の どこに あるか(📍)が 出る。あそぶのは **小学生〜投資を 学ぶ 高校生・大学生・大人**。
**長く 会社を 応援する 投資家に なるための ことばと 意味を おぼえる ゲーム**(試験の 問題集でも、投資の 相談でも、投資の すすめでも ない)。
もとは `tools/zeirishi/PROMPT.md`(税理士)。
けいくん 2026-10-02「投資家の専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください。
日本一の投資家、竹田和平さんのように **好きな企業を応援する長期投資スタイルがメインの投資家**に育ってほしいです」。

## この ゲームの 芯
- めざす 投資家 = **会社の 仕事・商品・人を 知って 好きに なり、株主として 長く 応援する 人**(竹田和平さんの ような 長期投資)
- 短く 売り買いして もうける 話は 芯では ない。デイトレード・信用取引・FX・仮想通貨は **名前と しくみだけ**(すすめない・やりかたを 書かない)
- お金の 多さで 人を くらべない。「徳」「まわりを 幸せに する」「感謝」「応援」を まん中に

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 6つ

### 1. 投資を すすめない・銘柄を すすめない・売り買いの 時期を 書かない(金融商品取引法の「投資助言」に ならない ように)
- ❌ **書かない**: 「◯◯を 買うと よい」「いまが 買い時 / 売り時」「◯%もうかる」「必ず 上がる」「損を しない」「この やりかたで 勝てる」/ 売買の テクニック・手順
- ⭕ **書くのは**: その ことばが **何を さすか**・**何の ための しくみか**・**長く 応援する 投資家は どう 考えるか**
  - 例: 配当 = 会社が 利益の 一部を 株主に 分ける お金です。長く 株を 持つ 投資家に とって、会社と いっしょに 育つ よろこびの ひとつです
  - 例: 分散 = お金を いくつかの 会社や 商品に 分けて 持つ 考えかたです。ひとつの 値段が 下がっても、ぜんぶが いっしょに 下がりにくく なります
- 「もうかる」「儲かる」「必ず」「買い時」「売り時」「損しない」の 字は 使わない(台本が 止める)

### 2. 投資の 相談の 答えに しない
- ❌「あなたの 場合は …」「この 条件なら …」「◯才なら …」のような、読んだ 人が 自分の お金に あてはめる 書きかたを しない
- ⭕ 一般的な しくみの 説明だけ。必要なら「お金の ことは おうちの 人や 専門の 人と 相談」で しめる

### 3. ⚠️⚠️ 株価・利回り・税率・金額・割合・倍率の 数字を 書かない(税理士と 同じ。投資は 毎年 変わるので もっと きびしく)
- **%・割・円・倍の 数字は ぜんぶ 書かない**(台本が 止める)。PER・PBR・ROE は「何を 見る ものさしか」だけ。「◯倍なら 割安」も 書かない
- **NISA の 上限額・非課税の 年数・税率は 書かない**。NISA は「投資で えた もうけに 税金が かからない しくみ(名前と 目的)」だけ
- 年(できごとの 年)は **まちがいない ときだけ**: オランダ東インド会社 1602年・堂島米会所 1730年(幕府が 公に みとめた)・東京株式取引所 1878年・
  竹田和平 1933年 生まれ・東証の 市場区分(プライム・スタンダード・グロース)2022年4月・新しい NISA 2024年・NISA の はじまり 2014年。あやしい ときは 年を 書かない
- 条の 番号(第◯条)は 書かない

### 4. 小学生も あそぶ(こわく しない・ギャンブルに しない)
- ❌ **借金・破産・倒産・大損・暴落・崩壊の こわい ようす・自殺・死**は 書かない(台本が 止める)。リスクは「値段が 下がる ことも ある」と おだやかに
- バブルは「値段が 実際の 価値より ずっと 高く なり、そのあと 大きく 下がった できごと」と 名前と しくみだけ。人が こまった ようすを 書かない
- **ギャンブル・賭け・くじ・ガチャの かおりを つけない**(ことばにも 絵文字にも)。🎰🎲🃏💸 は 使わない。💴💵💰 の お札の 絵文字の 多用も さける
- 人を「お金持ちは えらい」で くらべない

### 5. ⚠️⚠️ 実在の 会社・生きている 人の 名前を 出さない
- **実在の 会社・商品・ブランド・証券会社・銀行の 名前を 例に しない**(「ある お菓子の 会社」の ように 書く)。
  ⭕ 公の 組織・制度の 名前は よい: 東京証券取引所(東証)・日本取引所グループ・大阪取引所・金融庁・日本銀行・日本証券業協会・日本証券アナリスト協会・日本FP協会・日経平均株価・TOPIX
  ⭕ 歴史の 会社は よい: オランダ東インド会社・イギリス東インド会社・堂島米会所・東京株式取引所
- **人物は 歴史上の 人・亡くなった 人だけ**。亡くなった ことは 書かない(「1933年 生まれの 投資家」と 書けば よい)。
  ⭕ 竹田和平・渋沢栄一・本間宗久・ベンジャミン・グレアム・フィリップ・フィッシャー・ジョン・メイナード・ケインズ・ジョン・テンプルトン・ジョン・ボーグル・
  ハリー・マーコウィッツ・ダニエル・カーネマン・アダム・スミス・福沢諭吉 など
  ❌ **生きている 投資家・学者・経営者の 名前は 入れない**(バフェット・ソロス・シラー・セイラー・ファーマ など。台本が 止める)
- 竹田和平さん(1933年 名古屋 生まれ)について 書いて よい 事実(2026-10-02 に 確かめた):
  お菓子の 会社を つくり、たまごの ボーロを 大ヒットさせた / 上場している 会社 100社 以上の 大株主に なり「日本一の 個人投資家」と 呼ばれた /
  自分で「平成の 花咲爺(はなさかじいさん)」と 名のり、経営者や 投資家を はげました / 「徳」を 大切に し、「貯徳(ちょとく)」「智徳(ちとく)」を ことばに した /
  「恒産なくして 恒心なし」(暮らしの 土台が ないと 心も 落ちつかない)を 大切に した。
  ❌ 会社名・商品名(竹田製菓・竹田本社・タマゴボーロ)・金(きん)の 商品・亡くなった こと は 書かない。「和製ウォーレン・バフェット」も 書かない(生きている 人の 名前の ため)

### 6. 投資家の 目線で 書く(株式旅行・税理士 など ほかの ゲームと 同じ 語を 入れて よい)
- ✅ **ほかの ゲームと 同じ ことばを 入れて よい**(けいくん決定 2026-09-30)。説明は **長く 会社を 応援する 投資家の 目線**で 書きなおす。
  株式旅行 = 会社を 知る / 税理士 = 税と 会計で 支える / 投資家 = 会社を 知って 長く 応援する
- **読み(ひらがな)は 投資家の 7つの 旅の 中で かぶらない**(台本が 止める)。下の「旅ごとに 入れる」を 守る

## 1語の 形(JSON)

```json
{"id":"kh-haito","name":"配当","reading":"はいとう","journey":"kihon","category":"株主の よろこび","difficulty":1,
 "field":"投資のきほん","type":"concept","emoji":"🎁","mapNode":"kihon:haito","relatedTerms":["kh-kabunushi"],
 "description":"会社が 利益の 一部を 株主に 分ける お金です。長く 株を 持つ 投資家に とって、会社と いっしょに 育つ よろこびの ひとつです。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(ふつうに 使う 言いかた。漢字・カタカナ・英字の 略語)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)
  - 英字・カタカナの 語は ひらがなで(ETF → いーてぃーえふ、ROE → あーるおーいー、PER → ぴーいーあーる)
  - ゆれる ことばは 1つに 決め、別の 読みは `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は 上級だけ・旅で 1〜2語まで
  - ⚠️ **読みを 1語ずつ 確かめる**: 株式 かぶしき・株主 かぶぬし・配当 はいとう・優待 ゆうたい・複利 ふくり・分散 ぶんさん・銘柄 めいがら・
    利回り りまわり・上場 じょうじょう・決算 けっさん・貸借対照表 たいしゃくたいしょうひょう・損益計算書 そんえきけいさんしょ・
    純資産 じゅんしさん・議決権 ぎけつけん・増配 ぞうはい・債券 さいけん・為替 かわせ・投資信託 とうししんたく・相場 そうば・
    堂島米会所 どうじまこめかいしょ・花咲爺 はなさかじいさん(はなさかじじい も 認める)・恒産 こうさん・徳 とく・暴騰は 使わない
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級
- **field**: 学ぶ 分野。次の 7つの どれか:
  `投資のきほん` `企業分析` `財務・決算` `市場と制度` `長期投資` `行動ファイナンス` `歴史`
  - めやす: 投資・株式・配当・リスク・複利・分散・NISA の 名前 → `投資のきほん` / 事業・商品・競争力・経営・ESG → `企業分析` /
    決算書・指標 → `財務・決算` / 取引所・証券会社・投資信託・債券・金利・法律 → `市場と制度` / 長く 持つ・株主の 権利・再投資・つみたて → `長期投資` /
    こころの くせ・心がまえ → `行動ファイナンス` / 歴史の できごと・人・名言 → `歴史`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(💀 🔫 🔪 🩸 💣 ⚔️ 🎰 🎲 🃏 💸 は 使わない。💴💵💰の 多用も さける。🌱🌳🏢📊🤝🎁📘 など)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / 何の ために あるか・長く 応援する 投資家は どう 見るか」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  専門用語を 専門用語だけで 説明しない。「1人」「2人」は ふりがなが 読みまちがえるので **ひとり・ふたり** と ひらがなで 書く
- **example**: なくてもよい

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |

| 2 | 中級 | **証券外務員・FP(ファイナンシャル・プランナー)の 範囲の めやす**(大きな ことば) |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる
(ならんだ 順が そのまま ステージの 順に なる)。

## ぜったいに 守ること

- **自分の ことばで 書く**。教科書・問題集・Wikipedia・公式の 文を 写さない
- **数字(%・円・割・倍)は 書かない**。資格・制度の 事実は `tools/toshika/exam.txt` に 合わせる
- 「72の法則」「ギャンブラーの誤謬」は 入れない(数字・ギャンブルの 字が 出るため)
- 「100マス計算」「百ます計算」の 字を 使わない

## 出すもの

`tools/toshika/terms-<旅id>.json` に JSON の 配列(70語)で 書く。書いたら
`python3 tools/toshika/terms_js.py --only <旅id>` で 形を 確かめる(まちがいが あれば 止まる)。
