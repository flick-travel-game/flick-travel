# フリックパソコン(`pasokon/`)を 作る ための まとめ(2026-10-03。新しい セッション用)

けいくん 2026-10-03「新しいセッションで フリックパソコンを作成したい。**MacBookの専門家になれるレベル**になるために必要な 知識をフリック形式の問題にしてください。
**ショートカットもたくさん出してください**」

## ⚠️⚠️ まず 名前と 商標の こと(フリックスマホと 同じ)
- 名前は けいくんの「**フリックパソコン**」で よい(商標で ない ふつうの 言葉)。フォルダ `pasokon`
- **中身は MacBook(macOS)が 中心**(けいくんの ねがい どおり)。ただし **「MacBook」「Mac」「macOS」「Finder」「Spotlight」「Safari」「Time Machine」「Touch ID」「AirDrop」「Launchpad」「Mission Control」「Siri」は アップルの 商標**。
  → **1語の 答え(`name`)に しない**。一般の 言葉で 答えに する(ファイルを 整理する アプリ / 検索の 機能 / ブラウザ / 自動バックアップの 機能 / 指紋認証 / 近くの 機械に ファイルを 送る 機能 / ウインドウを 一覧する 機能)。
  ⭐ 説明文の 中で「Mac では『Finder』と いう 名前」と **事実として 1回 ふれて よい**(どの 機械の 何の こと か わかる ため)。**くわしい 決まりは `docs/フリックスマホ-はじめかた.md` の 3 と まったく 同じ**
- ゲームの 名前・題名の 絵・アイコン・販売ページ・規約には **「MacBook」「Mac」を 入れない**

## ⭐ ショートカットの 問題の 形(このゲームの いちばんの 目玉)
けいくんの「**ショートカットもたくさん**」に こたえて、**旅を 3つ ショートカットに する**(10の 旅の うち 3つ = **210語**)。
- ⭐ **出す 手がかり = キーの 組み合わせ / 答え = その 動きの 名前**。例: 画面に 大きく **「⌘ + C」** → 答え「**コピー**」(よみ こぴー)
  - 語に **`keys` の 欄**(文字列。例 `"⌘ + C"`・`"⌘ + ⇧ + 4"`・`"⌃ + ⌘ + Q"`)。**しくみ側で 問題の 上に 大きな キーの ふだ**(キーボードの キーの 形の 箱)で 出す。**このゲームの いちばん 大切な 見た目**
  - `name` は **動きの 名前**(コピー・貼り付け・取り消し・すべて選択・画面を ロック …)。読みは ひらがな(こぴー・はりつけ・とりけし)
  - 説明は「**何が 起きるか + いつ 使うと 便利か**」(「⌘ + Z = 1つ前に もどす。まちがえて 消した ときに 便利」)
  - ⭐ ときどき(1旅に 10語くらい)**Windows での キー**を 1行(「Windows では Ctrl + C」)。パソコン全体の 知識に なる。⚠️ Windows も Microsoft の 商標なので **説明の 中だけ**
- ⚠️⚠️ **キーは 1つずつ アップルの 公式の ページ「Mac のキーボードショートカット」で 確かめる**(記憶で 書かない)。**OSの バージョンで 変わる もの・アプリに よって ちがう もの は 入れない**(または「多くの アプリで」と 書く)
- ⚠️⚠️ **確かめられた ショートカットが 70に 足りない 旅は、むりに 作らない**。足りない 分は **キーの 名前**(⌘ コマンド・⌥ オプション・⌃ コントロール・⇧ シフト・fn・esc・delete・return・tab・caps lock・英数 / かな キー・**ファンクションキー**)と **しくみの ことば**(修飾キー・ショートカット・メニューバー の 表示 など)で うめる。**ありもしない ショートカットを 作らない**
- 記号の 字: ⌘ ⌥ ⌃ ⇧ ⏎ ⌫ ⎋ ← → ↑ ↓。**スマホでも 出るか**(とくに ⎋)を `click-all.mjs` で 確かめる。出ない 字は「esc」の ように 文字で
