# フリックワールドボクシング(`boxing/`)を 作る ための まとめ(2026-10-12。新しい セッション用)

けいくん 2026-10-12「新しいセッションで フリックワールドボクシングを作成したい。**ワールドボクシングの専門家(解説者)になれるレベル**になるために必要な 知識、**主要な団体、有名ボクシング選手、有名な技、ルール**をフリック形式の問題にしてください」

⭐ **フリックワールドサッカー(`soccer/`)・バスケットボール(`basket/`)・ベースボール(`baseball/`)と 兄弟の ゲーム**。まとめの 型・決まりは その 3つの `docs/フリックワールド◯◯-はじめかた.md` と **ほぼ 同じ**。
⚠️⚠️ ただし **ボクシングは 人を なぐる 競技**。ほかの 3つより **「小学生も あそぶ」の 決まりが ずっと 大事**になる(下の 3 を 先に 読む)。**ケガ・KO された ようす・流血・脳の 話は 1語も 入れない**。書くのは **技・ルール・歴史・ことば**だけ。

## 3. ⚠️⚠️⚠️ ぜったいの 決まり(兄弟と 同じ + ボクシングだけの もの)
- ⭐⭐⭐ **ボクシングだけの いちばん 大事な 決まり**: **なぐられた 側の ようすを 書かない**。**技は「出す 側の 動き」として だけ** 書く(「腰の 回転で 横から 打つ パンチ」まで。「相手が 倒れる」「効く」「あごを 打ちぬく」は 書かない)。**ケガ・血・脳・死亡事故は 1語も 入れない**。**迷ったら 入れない**。これは 小学生が あそぶ ゲームで、**けいくんは 子どもの スクールの 先生**
- ⭐⭐ **数字が 変わる ものを 書かない**(この ゲームで いちばん 事故が 起きやすい):
  - ❌ いまの ベルト(**防衛・陥落・返上で 変わる**)・いまの 戦績(◯勝◯敗)・ランキング・PFP の 順位・ファイトマネー・いまの 所属ジム・いまの 階級(⚠️ 階級を 上げる ことが ある)
  - ✅ **変わらない 事実は よい**: 国籍・かまえ(オーソドックス / サウスポー)・**得意な パンチ / スタイルの 特徴**・**過去の 達成と その 年**(「◯◯年に ◯◯級の 王者に なった」「◯◯年に 4団体を 統一した」)・**オリンピックの メダルと 年**・**引退した 選手の 記録**(具志堅用高の 13回 防衛 など。確かめる)
- ⚠️⚠️ **いまの 選手の 書きかた**(`star` の 旅): 「**◯◯の ボクサー。◯◯年に ◯◯級の 世界王者に。するどい 左ジャブと カウンターが 武器**」の ように **国・達成の 年・プレーの 特徴**で 書く。**いまの ベルトと 戦績を 答えの 手がかりに しない**。
  答えに した 選手は `meta.json` に **確かめた 日**を つけて、**1年に 1回 見なおす**(引退・階級の 変更が あるため。⚠️ ボクサーは 引退と 復帰が 多い)
- ⭐ **ルールは プロと アマが ちがう**: **プロ**(JBC・4団体。ラウンド数・ダウン制・10点法)・**アマ**(オリンピック・World Boxing。3ラウンド・ヘッドギア・5人の ジャッジ)。**どちらの 話か 説明に かならず 書く**。⚠️ **団体・興行で ちがう ルール**(スリーノックダウン制の 有無・フリーノックダウン)も ある。`meta.json` に 「JBC ◯年版 / World Boxing ◯年度で 確かめた」と 書く
- ✅ **実在の 選手・団体・ジム・会場の 名前は 入れて よい**(事実として。兄弟と 同じ)。
  ❌ ただし **絵には 描かない**(実在の 選手の 顔・団体の ベルトの 絵・ジムの ロゴ・スポンサー)。**商品名**(グローブ・シューズの 名前など)は 説明にも 入れない
- **人を けなさない**: 「負けた 選手」「弱い 選手」の 書きかたを しない。**名勝負は 「名勝負」として だけ**(だれが 倒れたか は 書かない)。⚠️ **敗者の 名前を 答えに しない**
- **ラフプレー・反則を すすめない**: ローブロー・バッティング・ラビットパンチは **反則の 名前として**。「相手を 怒らせる」「挑発」は 入れない
- **技は 「練習で 身に つける 技」として**
- **小学生も あそぶ**: ケガ・乱闘・薬物・賭け・人の 死・事件の 話は 入れない。**迷ったら 入れない**(⚠️ ほかの スポーツより 厳しく)
- ✅ **ほかの ゲームと 同じ 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。説明は **ボクシングの 目線**で
  - ⚠️ ほかの スポーツと かさなる 語(**カウンター**(サッカーにも ある)・**ガード**(バスケの ポジション)・**フック**(バスケの フックショット)・**MVP**)は、**ボクシングでの 意味**で 書く
- **読み(ひらがな)は ワールドボクシングの 9つの 旅の 中では かぶらない**(ほかの ゲームとは かぶって よい。`terms_js.py` が 止める)。⚠️ `kihon` と `waza`(ジャブ・フック)、`org` と `rule`(計量)、`legend` と `waza`(デンプシー と デンプシーロール)、`org` と `cup`(WBC と 大会)は かさなりやすい。**先に 9つの 旅の 語の 一覧を 1人の 助手に 作らせて** 置き場所を 決めてから 頼む
- **ことばの 書きかたを そろえる**(日本の 新聞・JBC で よく 使う 書きかたに)。⚠️ 階級名は 「スーパーフライ級」(WBC / WBO)と 「ジュニアバンタム級」(WBA / IBF)の ように **団体で 呼び名が ちがう**。**答えは 日本で よく 使う ほうに 1つに 決めて、もう片方は `alias`(読み)で 受ける**
- 画面(ホームの 下・遊びかた)に「これは ことばを おぼえる ゲームです。**選手の 王座や 記録は 変わる ことが あります**」「WBA・WBC・IBF・WBO・JBC・各ジムとは 関係ありません」
- **作った 助手とは 別の 助手が 1語ずつ 確かめる**(**選手と 国・技と 使い手・年と 達成・ルールの 版と プロ / アマ**・変わる 数字が 無いか・**ケガ・血・倒れた ようすが 無いか**(⭐ ボクシングは ここを いちばん 強く)・人を けなして いないか・商品名が 無いか)。ふりがなも 全語 見る(`tools/ruby_fix.json`)
