# フリックパイロット: ことばの 作りかた(助手に 分けて 頼むときの 決まり)

## ⚠️⚠️⚠️ いちばん 大事な 決まり(さいしょに 読む)
1. **こわく しない**。飛行機は いちばん 安全な 乗り物の 1つ。失速・乱気流・メーデー・ゴーアラウンド・着氷・雷 などは
   **「そう ならない ように / なっても 安全に する ための しくみ」の 向き**で 書く。
   「落ちる」「墜落」「事故」「死」「けが」「危険」「こわい」「爆発」「ハイジャック」「テロ」の 字は **使わない**(`terms_js.py` が 止める)
   - 失速 →「翼の 上の 空気の 流れが はがれて、揚力が 急に へる こと。訓練で ふせぎかたと 立て直しを 練習します。」まで
   - 乱気流 →「空気が ゆれて 飛行機が ゆれる こと。シートベルトを しめていれば 安全です。」まで
   - メーデー →「いちばん 急いで 助けが ほしい ときに、無線で 3回 くりかえす ことば。」まで
   - 7700 は 上級に 1語だけ(「助けが いる ことを 管制に 知らせる 番号」まで)。**7500・7600 の 語は 入れない**
2. **本物の 操縦・無線の 手順書に しない**。ゲームで おぼえても 飛べない。
   「何を する ものか / なぜ 大事か」まで。操縦の 手順(何を どの 順に どう うごかす)・本物の 交信の 文まるごと は 書かない
3. **実在の 航空会社・機体メーカーの 名前**(JAL・ANA・ボーイング・エアバス など)は **事実の 説明に 1回だけ**。
   ロゴ・宣伝の ような 書きかた・悪い 例 は ぜったいに しない。迷ったら 書かない。**今の 航空会社の 名前は 使わない**
4. **事故・墜落・ハイジャック・テロの 話は 入れない**(有名な 事故の 名前・日付も)。人の 生まれた 年・亡くなった 年は 書かない(「◯年に 〜を した」は よい)。アメリア・イアハートの 行方不明の 話は 書かない
5. **給料・合格率・訓練の 値段・年れいの 決まり**は 書かない
6. **数字は まちがいない ものだけ**(1ノット = 時速 約1.85km、1フィート = 約30cm、滑走路の 番号 など)。機体の 大きさ・速さは「約」で。**記憶で あやしい ものは 書かない・入れない**
7. **自分の ことばで 書く**。過去問・問題集・教科書・Wikipedia の 文を 写さない

## ゲームの かたち
「表示された ひらがなを フリックで 打ち写す」タイピング。打ち終わると ことばの 説明(1〜3文)が 出る。
遊ぶのは 小学生〜パイロットを めざす 学生・大人。**飛行機と 空の ことばを おぼえる ゲーム**

## 1語の 形(JSON)
{"id":"ki-shuyoku","name":"主翼","reading":"しゅよく","journey":"kihon","category":"翼","difficulty":1,"type":"concept",
 "emoji":"🪽","mapNode":"kihon:shuyoku","field":"航空工学","relatedTerms":["ki-hojoyoku","ki-flap"],
 "description":"胴体の 左右に のびる 大きな 翼。空気の 流れから 揚力を 生んで、飛行機を 空に ささえます。",
 "kotoba":"(無線の ことばだけ)交信で どう 使うか 1文","example":"(なくてもよい)たとえば〜"}

- id: 旅の 頭文字2つ + "-" + 英小文字(ki- / yo- / ke- / te- / ko- / mu- / ho- / ku- / ji-)。英小文字・数字・- だけ
- name: 画面に 出す 名前(漢字・カタカナ・英字。ふつうの 言いかた。英字の 略語は そのまま VOR・ILS)
- reading: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白は ダメ)
  - 英語の 語(ピッチ・ヨー・ロール・メーデー)は **ふだんの カタカナ読みを ひらがなで**(ぴっち・よー・ろーる・めーでー)
  - 英字の 略語は 日本の ふつうの 読み(VOR → ぶいおーあーる / ILS → あいえるえす / GPS → じーぴーえす)
  - 数字は ひらがな(7700 → ななせんななひゃく / 747 → ななよんなな)
  - ゆれる ことばは 1つに 決め、別の 読みは "acceptedReadings":["よみ1","よみ2"](先頭は reading と 同じ)
  - **フォネティックコード**は 1語ずつ ことばに する(アルファ → あるふぁ / ブラボー → ぶらぼー …)。名前は 「アルファ(A)」の 形
  - ⚠️ **読みは この ゲームの 9つの 旅の 中で かぶらない**(同じ 読みの 語を 2つ 入れない)
- difficulty: 1 = 入門(飛行機が すきな 子) / 2 = 自家用操縦士の 学科試験の めやす / 3 = 事業用・定期運送用操縦士の めやす
- type: いつも "concept"
- category: 図鑑で しぼる 分類(短い 日本語。旅の 中で 4〜8種類)
- emoji: 1つ
- mapNode: その 旅の 図の 場所(下の 表から)
- field: **学科試験の 科目**: 航空工学 / 航空気象 / 空中航法 / 航空通信 / 航空法規 / 空港・管制 / しごと・歴史 の どれか
- relatedTerms: **同じ ファイルの 中の** id を 1〜3個(自分は ダメ)
- description: 1〜3文・**130字以内**。やさしい です・ます。語と 語の あいだに 半角スペースを 入れる 書きかた(上の 例のように)。
  **カタカナ語を ならべない**。ふつうの 言葉で 言いかえて から 専門の 名前(「ゴーアラウンド = 着陸を やめて、もう一度 やりなおす こと」)。
  ⭐ ときどき「へえ」と 思える 事実を 1文(向かい風で 離陸する わけ・ブラックボックスは じつは オレンジ色 など)
- kotoba: **無線・管制の 語だけ**(任意)。1文で「交信で どう 使うか」(例: ラジャー →「相手の 話を 受けとった、と 伝える 返事。」)。本物の 交信の 文を ならべない
- example: なくてもよい

## 旅ごとの 語数
**110語: difficulty 1 を 30語、2 を 40語、3 を 40語**。同じ difficulty の 中は 有名な・大事な 順。
(1回目は 70語 = 20 / 25 / 25。2回目に 40語 = 10 / 15 / 15 を うしろに 足す。前の 語の 順番・中身は 変えない)

## ほかの ゲームと かぶる 語
整備士・理科(地学)・宇宙図鑑・英会話・社会と 同じ 語を 入れて よい(けいくん決定 2026-09-30「復習になるから」)。説明は **パイロットの 目線**で 書きなおす

## 出すもの
`tools/pilot/terms-<旅id>.json` に JSON の 配列で 書く。書いたら `python3 tools/pilot/terms_js.py --check` で 確かめる
