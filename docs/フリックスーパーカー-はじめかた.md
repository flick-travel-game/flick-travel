# フリックスーパーカー(`supercar/`)を 作る ための まとめ(2026-10-21。新しい セッション用)

けいくん 2026-10-21「新しいセッションで フリックスーパーカーを作成したい。**すべてのスーパーカー、ハイパーカーを 知っている 専門家レベル**になるために必要な知識をフリック形式の問題にしてください」

⭐ いちばん 近い 兄弟は **フリックワールドサッカー(`soccer/`。`docs/フリックワールドサッカー-はじめかた.md`)**(実在の 名前を 事実として 書く・**変わる 数字を 書かない**・国の 札)と **フリック整備士(`seibi/`)**(エンジン・しくみの ことば・4択クイズ・計算問題)。
写真が 主役の 図鑑なので **フリック恐竜図鑑(`kyoryu/`)** の 写真の 出しかたも 見る。
⚠️ ほかの ゲームと ちがう 3つの 気をつけ:
① ⭐ **資格試験が 無い**。「専門家レベル」= **メーカー・車名・国・年代・エンジン・デザイナー・伝説の 名車を 見て すぐ 言える** こと、と けいくんに 伝える
② ⭐⭐ **数字が いちばん 事故を 起こす**。馬力・最高速・値段は **年式・版・出どころで ちがう**。書くなら **メーカーの 公表値を まるめて + 確かめた 日**。**値段・オークションの 値段は 書かない**(下の 3)
③ ⭐ **スピードを あおらない**。子どもが 遊ぶ ゲーム。最高速は **テストコース・サーキットの 話**。「公道で ◯◯km/h」「速く 走ると かっこいい」の ような 書きかたを しない

### 🧮 計算問題の なかま(おすすめ。⚠️ 「ゲームの 練習問題です」と 1行。数字は きりの よい 練習用)
| なかま | 中身(れい) | むずかしさ |
|---|---|---|
| ⚡ 馬力の 単位 | 600PS は 何kW(1PS ≒ 0.735kW)/ kW → PS / ⭐ PS と hp の ちがい | 入門〜中級 |
| 🏁 速さの 単位 | km/h ↔ mph(1mile ≒ 1.609km)/ 時速 → 秒速(時速 360km = 秒速 100m) | 入門 |
| ⚖️ パワーウェイトレシオ | 重さ 1,500kg ÷ 600PS = 1馬力あたり 2.5kg(⭐ 小さいほど 軽快) | 中級 |
| 🔧 排気量 | 1気筒 500cc × 12気筒 = 6.0L / L ↔ cc | 入門 |
| 🌀 回転数 | 毎分 9,000回転 は 1秒に 何回転 | 中級 |
| 🔋 電気の 車 | 電池 100kWh を 50kW で 充電すると 何時間 | 中級 |
⚠️ **実在の 車の 本当の 数字で 問題を 作らない**(出どころで ちがうので 答えが ぶれる)。練習用の 数字だけ

3. **むずかしさの 3段**:
   ・入門 = **車が すきな 小学生**(メーカーの 名前と 国・有名な 車名・ドアの 開きかた・エンジンの 場所)
   ・中級 = **車好きの 大人**(車名と メーカーの 組み・年代・エンジンの 形・しくみの ことば)
   ・上級 = **専門家**(限定車・デザイナー・カロッツェリア・ハイパーカーの 技術・ル・マンの 歴史)
4. **1語に 持たせる 分野**(`field`): メーカー / 車 / しくみ / デザイン / レース / 人 / 歴史(**4 で 確かめてから 決める**)
5. **入れない もの**: **値段・オークションの 値段・中古の 相場**・**年収・お金持ちの 自慢**・**持ち主の 有名人**・**事故**(⚠️ 有名人の 事故・ル・マンの 事故も)・**公道の スピード**・**違法改造・ゼロヨン・暴走**・**ロゴ・エンブレムの 絵**・**メーカーの 宣伝文を そのまま 写す**・**実在の 人の 顔写真**

## 3. ⚠️⚠️⚠️ ぜったいの 決まり(サッカー・パイロットと 同じ + この ゲームだけの もの)
- ⭐⭐⭐ **変わる 数字・ぶれる 数字を 答えに しない**(この ゲームで いちばん 事故が 起きやすい):
  - ❌ **値段**(新車も オークションも)・**生産台数**(確かめられない ものは)・**いま 売っているか**(終わる)・**最高速の 順位**(すぐ 変わる)・**ニュルの タイムの 順位**
  - ✅ **変わらない 事実は よい**: メーカーと 国・**発表した 年**・エンジンの 形(V12 など)・エンジンの 場所・ドアの 形・デザイナー・名前の 由来・**限定車の 予定台数**(⚠️ **メーカーの 発表で 確かめた ものだけ**。F40・エンツォ・ラフェラーリ など)
  - 馬力・最高速は **説明の 中に 「◯◯馬力 ほど(メーカーの 公表値)」**と まるめて 書くのは よい。**答えの 手がかりに しない**。`meta.json` に 出どころと 確かめた 日
- ⭐⭐ **スピードを あおらない**: 最高速・加速は **テストコース・サーキットの 話**と はっきり 書く。「公道で」「飛ばす」「スピード違反」の 字を `BAN` で 止める。⭐ 画面の 下に 1行「道路では 交通ルールを 守りましょう」
- ⭐ **お金の 話を しない**: 「◯億円」「お金持ちの 車」と 書かない。車の **すごさ**は **しくみ・デザイン・歴史**で 書く
- ⭐ **これで 専門家に なれる わけでは ない** と 画面に 書く: 「これは ことばを おぼえる ゲームです。実在の メーカーとは 関係ありません」
- ✅ **実在の メーカー・車名・人の 名前は 入れて よい**(事実として。サッカーと 同じ)。⚠️ **ロゴ・エンブレム・宣伝の 写真・メーカーの 宣伝文**は 入れない。悪く 言う 書きかた・くらべて けなす 書きかたを しない
- **車名の 読み**: 日本で ふつうに 使う カタカナを ひらがなに(「かうんたっく」)。⚠️ 同じ 名前の 車が 何台も ある(「GT」「スパイダー」)ので **メーカー名を つけた 名前**で 1語に する(「ふぇらーりえふよんじゅう」が 長すぎる ときは けいくんに 聞く)
- **読みは この ゲームの 9つの 旅の 中では かぶらない**(`terms_js.py`)。**先に 9つの 旅の 語の 一覧を 1人の 助手に 作らせて** 置き場所を 決める(`hyper` と `italia`(ラフェラーリ)、`densetsu` と `italia`(ミウラ・カウンタック)、`sekai` と `hyper`(シロン・ジェスコ)が かさなりやすい。⭐ **車は 国の 旅に、ハイパーカーの 旅は 「ことば・技術・記録の 話」**に 寄せる)
- ✅ **整備士・サッカーと 同じ 語を 入れて よい**。説明は **スーパーカーの 目線**で 書きなおす
- **別の 助手が 1語ずつ 確かめる**(メーカー・国・**発表の 年**・エンジンの 形・デザイナー・つづり・**写真が その 車か**)。⚠️ **車の まちがいは 車好きに すぐ ばれる**(サッカーと 同じ)。計算問題は **1しゅるいずつ 手で 答えを 確かめる**

## 4. 事実は **その日に 公式の ページ・Wikipedia で 確かめてから** 書く
`meta.json` の `source` に 確かめた 日を つける。**記憶で 書かない**:
