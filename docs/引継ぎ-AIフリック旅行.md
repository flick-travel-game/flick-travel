## 解説の 書きかた(⚠️ ここが いちばん 大事)

- **80〜120字**(ほかの旅と 同じ)。**自分の 言葉で 書く**(Wikipedia・公式ドキュメント・記事を そのまま 写さない)
- **本当のことだけ**。AIの 世界は 変わるのが 速いので、**バージョン・値段・「いちばん」など すぐ古くなる数字は 書かない**。
  書くなら「2026年9月時点」と 日付を つける
- よくある つまずきを 1つ 入れると 覚えやすい(例: ハルシネーション =「それらしい うそ。答えは かならず 確かめる」)
- けいくんの 実際の 経験に もとづく 例を 入れてもよい(例: Stripe の Webhook の 住所は `www` 付き・Vercel の 環境変数は 変えたら 作りなおす)。
  ⚠️ ただし **サンクチュアリ千葉・本物の チーム名・人の名前・住所は 出さない**
- 会社名・サービス名は 事実として 書くのは よいが、**ロゴは 使わない**(商標)

## 絵(写真)

- 抽象的な ことばが 多いので **写真は 使わず 絵文字**(世界史・日本史・首都と 同じ。写真なしでも 画面は 成り立つ)
- 📍の図を 作るなら **コードで描く SVG**(`index.html` の `SVG_MAPS`。宇宙の「太陽系」・からだの「からだ」と 同じ しくみ)。例:
  - **Webサービスの 全体図**: スマホ(ブラウザ)→ ドメイン/DNS → Vercel(サーバー)→ Supabase(データベース)/ Stripe(お金)/ GitHub(コード)/ メール
  - **AIの しくみ図**: プロンプト → モデル(学習データ)→ 答え、まわりに ツール・MCP・エージェント・コンテキスト
  - ⚠️ **AIの 絵(ChatGPT)で 図を 作らない**(字が まちがう・📍の 場所が 合わない)。トップの絵と 四角いアイコンだけ けいくんに ChatGPT で 作ってもらう(横長 1536×1024、四角 1254×1254)

## 作りかた(いまの しくみを そのまま使う)

- エンジンは `index.html` 1つ。`tools/build_games.py` の `GAMES` に 1つ足すと 下の フォルダ(例 `ai/`)に ページが できる
- 旅(モード)を `MODES` / `MAPS` / `POOLS` / 色(`COLORS`)に 足す(例 `aiword` `webtech` `webops`)
- データ: `tools/ai.tsv` など → `tools/add_spots.py` に kind を足して 流しこむ → `tools/make_ruby.py`(ふりがな)→ `tools/build_games.py`。
  形は 宇宙・からだの 11列(`tools/space.tsv`)を まねるのが 早い(図の 列 + x,y)。検査は `tools/check_series_tsv.py`
- **言葉の数は 10の倍数**(あまると 最後のレベルに 前のレベルから もう一度 出して 10問に する しくみは 入っている)
- 結果の画面の Googleマップ リンクは 要らない(場所が無い)。かわりに 公式ドキュメントへの リンクを 出すなら **本物で 確かめた URL だけ**

## ぜったいに 守ること(シリーズの 決めごと)

- サンクチュアリ千葉の 名前を ゲーム・入れものに 出さない
- ロゴ・題名を CSS やフォントで 似せない(題名は けいくんの 絵から 切りぬく)
- 秘密の鍵を ゲームの中に 書かない。書きこみは かずともの サーバーだけ
- 広告・チャットは 作らない
- 数字(金額・日数)は 画面に 直接 書かず 1か所から 読む
- けいくんへの 説明は やさしい日本語。リンクは 1行に そのまま 置く。コミットに モデルの 名前を 書かない
