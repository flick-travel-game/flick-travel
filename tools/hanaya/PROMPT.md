# フリック花屋: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
**花の 名前には 💐 花言葉**、学ぶ 分野・しくみ図の どこに あるか(📍)が 出る。あそぶのは **小学生〜花屋で 働きたい 人・花屋を 開きたい 大人**。
**花屋の ことばと 意味を おぼえる ゲーム**(試験の 問題集でも、花束の 作りかたの 教科書でも ない)。
もとは `tools/noka/PROMPT.md`(農家)。まとめは `docs/フリック花屋-はじめかた.md`。
けいくん 2026-10-03「花屋の専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください。**花の名前や花言葉も詳しく入れてください**」
→ 同じ日「**花屋さんで働けるレベルの知識をつけたい / 花屋で起業して 経営者として 上手く経営出来るレベルまで 仕上げたい**」。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 8つ

### 1. ⭐ 花の 名前には 花言葉を くわしく 入れる(けいくんの ねがい)
- **花・木・グリーンの 名前の 語には かならず `"hanakotoba":["感謝","あたたかい心"]` を 足す**(1〜3つ。1つ 20字まで。ひらがな・漢字・カタカナ。「」は 付けない)
- 説明文(description)の **さいごの 1文は「花言葉は「◯◯」「◯◯」です。」**(hanakotoba と 同じ ことば。2つまでで よい)
- 花言葉は **日本で 広く 知られた もの**を えらぶ。本や 国・お店で ちがう ことが あるが、それは 旅の はじめの 説明に 書くので **1語ずつには 書かない**
- ⚠️⚠️ **こわい・悲しい 花言葉は えらばない**(「死」「呪い」「憎しみ」「裏切り」「別れ」「絶望」「嫉妬」「悲しみ」「復讐」 など)。
  よく 知られた 花言葉に こわい ものが まざる 花は、**明るい ほうの 花言葉だけ**を 書く(例: 黄色い バラ → 「友情」「平和」)。
  **明るい 花言葉が 無い 花は 入れない**(黒い バラ・ヒガンバナ・オトギリソウ・クロユリ などは 入れない)。迷ったら 入れない
- 花言葉は「◯◯という 花言葉が あります」の 気もちで。**「ぜったい この 意味」と 決めつけない**
- 花の 名前で ない 語(水あげ・損益分岐点 など)には hanakotoba を 付けない

### 2. 花屋の 目線で 書く(ほかの ゲームと 同じ 語を 入れて よい)
- ✅ **農家・理科・パティシエ・税理士 など ほかの ゲームと 同じ ことばを 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。
  説明は **花屋の 目線**(お客さんに 選んで・長もちさせて・気持ちを 届ける)で 書く
  (例: チューリップ = 農家では 球根を 育てる / 花屋では「春の 店先の 主役。切ったあとも 茎が のびて 花の 向きが 変わります」)
- **読み(ひらがな)は 花屋の 11の 旅の 中で かぶらない**(台本が 止める)。下の「旅ごとに 入れる 語」を 守る。**ほかの 旅の 欄に ある 語は 入れない**
- ⚠️ **同じ 花を 2回 入れない**(季節の 旅の どこに 置くかは 下の 欄で 決めて ある。バラ・カーネーション・かすみ草は 花言葉の 旅)
- 文体は **はじめから「〜です・ます」**(体言止めで はじめない)。**語と 語の あいだに 半角スペースを 入れる 書きかた**(下の 例のように)
- 事実が あやしい 語は 入れない。**自分の ことばで 書く**(図鑑・Wikipedia・お店の 文を 写さない)

### 3. 小学生も あそぶ(こわく しない)
- ❌ **「死」「殺」「血」「呪」「憎」「葬」「弔」の 字を 使わない**(台本が 止める)
- お供えの 花・お葬式の 花は **「大切な 人を しのぶ ときの 花」「ご先祖さまに そなえる 花」** と おだやかに
- けが・事故・「命に かかわる」も 使わない

### 4. 毒の ある 植物は おだやかに 1文だけ
- すずらん・スイセン・あじさい・クリスマスローズ・ポインセチア などは、名前と 花言葉は よい。
  毒の ことは **「口に 入れない ように 気を つける 花です。」** と 1文だけ(「毒」の 字・毒の 中身・どこに あるか は 書かない。台本が「毒」を 止める)
- ユリの 花粉は「服に つくと 落ちにくい ので、花屋では おしべを とって わたす ことが あります」は よい(ペットの 話は 書かない)

### 5. 刃物の 使いかた・手順を 書かない
- 花ばさみ・ナイフは「花の 茎を 切る 道具です。おとなと いっしょに 使います」**まで**。持ちかた・切りかたの 手順は 書かない
- 水あげの 方法は **名前と 何の ための ことか**(「湯あげ = 茎の 先を 熱い お湯に つけて、水を 吸いやすく する 方法です。熱い お湯は おとなが あつかいます」)。
  火を 使う「焼き」の 水あげ・薬品の 名前と 量は 書かない

### 6. ⚠️⚠️ 数字の 決めうちを 書かない(経営の 旅は とくに)
- **値段・日持ちの 日数・市場の 数・開業資金や 家賃の 金額・「ふつうは ◯%」の 原価率や ロス率・税率・補助金の 金額** は 書かない(台本が %・円・割・◯日 を 止める)
- 書くのは **ことばの 意味と 考えかた**(「粗利 = 売上から 仕入れを 引いた 残り」「損益分岐点 = 赤字と 黒字の さかいめの 売上」)
- ⭕ 変わらない ことは よい: 母の日は 5月の 第2日曜日・父の日は 6月の 第3日曜日・**よく 知られた バラの 本数の 意味**(1本・3本・12本(ダズンローズ)・108本 などに 限り「〜と 言われます」)
- 「もうかる」「かならず 成功する」と **決めつけない**
- 税・法律の ことば(開業届・青色申告・インボイス)は **名前と 何の ための ものか** まで。手続きの 手順・期限は 書かない(「くわしくは 税務署や 税理士に」は よい)

### 7. 実在の 花屋・ブランド・商標を 出さない
- **実在の 花屋・花の 宅配の 会社や サービス・資材の 会社の 名前を 書かない**(台本が 止める)
- ⚠️ **「オアシス」は 商標**。吸水スポンジは **「吸水スポンジ」「フローラルフォーム」** と 書く
- **商標の 品種名を 入れない**。園芸で ふつうに 使う 名前(ソメイヨシノ・カサブランカ・アナベル など)は よい。あやしい ものは 入れない
- ⭕ 文化として よい: 生け花の 流派(池坊・小原流・草月流)・公の 組織や 制度の 名前(農林水産省・国税庁・フラワー装飾技能士・日本フラワーデザイナー協会)
- 歴史上の 人は **亡くなった 人だけ**

### 8. 経営の ことばは 花屋の 例で
- 「ロス率 = 仕入れた 花の うち、売れずに 捨てた 花の 割合です。母の日の 前に 仕入れすぎると 上がります」の ように **花屋の 場面で** 説明する
- 税理士・投資家の ゲームと 同じ 語(粗利・資金繰り・青色申告)が 出て よいが、**花屋を 開く 人の 目線**(母の日の 仕入れ・ロス・定期便)で 書く

## 1語の 形(JSON)

```json
{"id":"hr-tulip","name":"チューリップ","reading":"ちゅーりっぷ","journey":"haru","category":"球根の 花","difficulty":1,
 "field":"植物一般","type":"concept","emoji":"🌷","mapNode":"haru:kyukon","relatedTerms":["hr-hyacinth"],
 "hanakotoba":["思いやり"],
 "description":"春の 店先の 主役に なる 球根の 花です。切り花に しても 茎が のびて、花の 向きが 光の ほうへ 変わります。花言葉は「思いやり」です。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(**花屋で ふつうに 書く 書きかた**。カタカナ・ひらがな・漢字)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)
  - カタカナ語は ひらがなで(ガーベラ → があべら では なく **がーべら**)
  - ⚠️ **花の 名前は 読みが ゆれる**(百合 ゆり・紫陽花 あじさい・向日葵 ひまわり・秋桜 こすもす・吾亦紅 われもこう・トルコキキョウ / リシアンサス など)。
    **いちばん ふつうの 読みを reading** に、ほかを `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)。
    ⚠️ acceptedReadings に 入れた 読みも 花屋の 中で かぶっては いけない
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は 上級だけ・旅で 1〜2語まで
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級
- **field**: 学ぶ 分野。次の 12の どれか:
  `植物一般` `材料` `フラワー装飾一般` `フラワー装飾作業法` `安全衛生` `接客と販売` `仕入れと在庫` `開業` `お金の計算` `集客` `人` `税と帳簿`
  - はじめの 5つは **フラワー装飾技能士の 学科の 科目の 名前**(厚生労働省の 試験科目の 表で 2026-10-03 に 確かめた。1級・2級・3級 どれも 同じ 5科目)。のこりは お店の 経営の 分け
  - めやす: 花・木・グリーンの 名前・花の つくり・なかま分け・育てかた → `植物一般` /
    切り花・ドライフラワー・リボン・ワイヤー・吸水スポンジ・花器 などの 材料と その あつかい(水あげ・長もち)→ `材料` /
    デザインの 考え・色・花の 文化と 歴史・生け花・花言葉 → `フラワー装飾一般` / 花束・アレンジの 形・ワイヤリング・ラッピング・装花を 作る 作業 → `フラワー装飾作業法` /
    道具や 刃物の 安全・衛生・働く 人の 安全の 決まり → `安全衛生` / お客さん・注文・行事・お届け → `接客と販売` /
    市場・仕入れ・鮮度・在庫・ロス → `仕入れと在庫` / 開業届・事業計画・立地・設備 → `開業` / 売上・原価・粗利・損益分岐点・資金繰り → `お金の計算` /
    SNS・看板・口コミ・定期便 → `集客` / 店長・アルバイト・教育・人件費 → `人` / 青色申告・帳簿・消費税・インボイス → `税と帳簿`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(💀 🔫 🩸 💣 ⚔️ 🔪 ☠️ ⚰️ は 使わない。🌷🌸🌻🌹🌺🌼💐🪷🍁🌿🍀🎀✂️🪣🧾💴📈 など)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **hanakotoba**: 花・木・グリーンの 名前の 語だけ(上の 1)。それ以外は 書かない
- **description**: **1〜3文・130字以内**(hanakotoba の ある 語は **150字以内**)・やさしい です・ます。
  「何の ことか / 花屋では どう 見るか・どう 役立つか / (花なら)花言葉」。
  専門用語を 専門用語だけで 説明しない。「1人」「2人」は ふりがなが 読みまちがえるので **ひとり・ふたり** と ひらがなで 書く
- **example**: なくてもよい

## 3段の 分けかた(けいくんの「働ける → 店長 → 経営者」)

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | **花屋で 働きはじめる 人**: 店に 並ぶ 花の 名前・よく 知られた 花言葉・水かえ・ラッピング・お客さんへの あいさつ。小学生でも 聞いた ことが ある |
| 2 | 中級 | **ひとりで 店を まかせられる 人(店長)**: **フラワー装飾技能士 3級・2級の 範囲の めやす**(花材の 名前・水あげ・アレンジの 形・仕入れ・在庫・法人の 注文) |
| 3 | 上級 | **花屋を 開いて 経営する 人**: **フラワー装飾技能士 1級の 範囲の めやす** + 経営(科名・めずらしい 花・デザイン理論・原価と 粗利・損益分岐点・資金繰り・事業計画) |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる
(ならんだ 順が そのまま ステージの 順に なる)。

## 旅ごとに 入れる 語(⚠️ **読みが かぶると 台本が 止まる**。ほかの 旅の 欄に 書いてある 語は 入れない。ここに 無い 語を 足すのは よい)

**季節の 4つの 旅は 70語の うち 55語 以上を 花・木・グリーンの 名前に する**(のこりは その 季節の 花の ことば: 花見・開花・満開 など)。
花の 名前は **切り花・鉢花・庭の 花として 花屋で よく 見る 季節**で 分けた。下の 欄の 花を 中心に、足りなければ **ほかの 旅の 欄に 無い** 花を 足す。

## ぜったいに 守ること

- **自分の ことばで 書く**。図鑑・問題集・Wikipedia・公式の 文を 写さない
- **数字(%・円・割・◯日・◯年 もつ)は 書かない**。資格・制度の 事実は `tools/hanaya/exam.txt` に 合わせる
- 「100マス計算」「百ます計算」の 字を 使わない

## 出すもの

`tools/hanaya/terms-<旅id>.json` に JSON の 配列(70語)で 書く。書いたら
`python3 tools/hanaya/terms_js.py --only <旅id>` で 形を 確かめる(まちがいが あれば 止まる)。
