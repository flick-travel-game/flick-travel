# フリックスマホ: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
学ぶ 分野・しくみ図の どこに あるか(📍)・ときどき「📱 やって みよう」が 出る。あそぶのは **小学生〜スマホに くわしく なりたい 中高生・大人**。
**スマホの ことばと しくみを おぼえる ゲーム**(取扱説明書でも、試験の 問題集でも ない)。
もとは `tools/yakuzai/PROMPT.md`(薬剤師)と `tools/code/PROMPT.md`(プログラマー)。
けいくん 2026-10-03「フリックiPhoneを作成したい。iPhoneの専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください」
→ 名前は 商標の ため **「フリックスマホ」**。5つの 問いに「全部おすすめで」。まとめは `docs/フリックスマホ-はじめかた.md`。
**中身は iPhone(iOS)を 中心に**、ところどころ Android との ちがいを 1文(しくみの ちがい として。どちらが よい は 書かない)。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 7つ

### 1. 商標を 1語の 答え(`name`)に しない(いちばん 大事)
- 「iPhone」も アップルの 機能の 名前の 多くも **商標**。かずともは お金を いただく サービスなので、商標を 答えの 名前に すると 商品名に 使った ことに なる
- ❌ `name` に 入れない(台本が 止める): iPhone・iPad・iOS・Apple・Face ID・Touch ID・AirDrop・Siri・Apple Pay・iCloud・App Store・Live Photos・FaceTime・
  AirPods・Apple Watch・AirTag・iMessage・Lightning・MagSafe・Android・Google・Google Play・Gmail・QRコード・iモード・おサイフケータイ・ポケットベル・Suica など
- ⭕ **一般の 言葉で 答えに する**: 顔認証 / 指紋認証 / 近くの 機械に ファイルを 送る 機能(name は「近距離ファイル共有」など)/ 音声アシスタント / タッチ決済 /
  クラウド / アプリストア / ライブ写真 / ビデオ通話 / ワイヤレスイヤホン / スマートウォッチ / 二次元コード / 無線呼び出し(ポケベル)
- ⭐ **説明文の 中では** 「iPhone では『Face ID』と いう 名前です」と **事実として 1回 ふれて よい**(どの 機械の 何の こと か わかる ため)。
  ただし **1語に 1回まで**・**ほめ言葉や 売り文句に しない**(「すごい」「いちばん」「おすすめ」を 商標と ならべない)
- ✅ Wi-Fi・Bluetooth・USB・5G・4G・NFC・GPS・SIM・eSIM・HDR は **世界の 決まり(規格)の 名前**として ふつうに 使われているので `name` に して よい
- ⚠️ ことばそのものが 一般の 言葉なら よい(ホーム画面・ロック画面・コントロールセンター・通知センター・ウィジェット・集中モード・ダークモード・スクリーンショット・
  スクリーンタイム(= 画面を 見ている 時間 として)・低電力モード・機内モード)

### 2. 機種名・バージョンの 番号・毎年 変わる ことを 書かない
- ❌ 「iPhone 17」「iOS 26」「Android 16」「ダイナミックアイランド」・**ボタンの 押しかたの 手順**・**設定の 道すじ**(設定 → 一般 → …)は **毎年 変わる / 古く なる**
- ⭕ **何年たっても 正しい しくみ**で 書く(タッチパネル・顔認証・クラウド・2ファクタ認証)。書くのは「設定アプリで 変えられます」まで
- ❌ **数字を 書かない**: 値段・料金・電池の 回数・画面の 大きさ(インチ)・画素数・ギガの 量・通信の 速さ・%(台本が 止める)。
  歴史の 年(1876年・2007年 など)は **確かめた もの だけ**よい

### 3. ⚠️⚠️ 子どもを 守る 決まりを ぬける 方法を ぜったいに 書かない
- ❌ スクリーンタイムや フィルタリングの **外しかた・ぬけ道**・パスコードの ぬけ道・**年れいを いつわる**・**脱獄(ジェイルブレイク)・root化・改造**
- ⭕ スクリーンタイム・フィルタリングは **「家族で 決めた ルールを 守る ための しくみ」**と 前向きに 書く

### 4. 人を 傷つける 使いかたを 書かない
- ❌ 人の スマホを のぞく・**位置を こっそり 調べる**・なりすまし・のっとり・**ハッキングの やりかた**
- ⭕ 安全の 旅は **守る がわ** だけ(「こう される かも しれない → こう 守る」)

### 5. こわがらせない。お金は おうちの 人に
- ネットいじめ・知らない 人・詐欺 は **「こまったら すぐ 大人に 相談」** で 終わる。こわがらせて スマホを きらいに させない。
  ⭐ **便利で 楽しい 道具。正しく 使えば 安心** が 伝わる 書きかた
- アプリ内課金・タッチ決済・ギフトカードは **「おうちの 人に 聞いて から」**。「ギフトカードで 払って と 言われたら 詐欺の 手口」は 守る 知識として 書いて よい

### 6. 実在の 会社・サービスの 名前を 出さない
- ❌ **通信会社・SNS・ゲームアプリ・修理店・スマホを 作る 会社**の 名前(台本が 止める)。「LINE」「YouTube」「ドコモ」も ❌
- ⭕ 説明の 中で どの 機械の 話か 示す ための「iPhone では」「Android では」は よい(上の 1)
- ⭕ 人の 名前は 歴史として よい(グラハム・ベル・スティーブ・ジョブズ・栗田穣崇 など。**事実を 確かめて**)
- ⭕ 公の 組織・制度は よい(総務省・警察・消費生活センター・IPA)

### 7. 事実を 正しく・スマホを 使う 人の 目線で
- 事実が あやしい 語は 入れない。**自分の ことばで 書く**(公式の 説明・Wikipedia を 写さない)
- ✅ **AI旅行・プログラマー・ゲームクリエイター・理科 など ほかの ゲームと 同じ 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。
  説明は **スマホを 使う 人の 目線**で 書きなおす(「写真が いっぱいに なったら」「おうちの 人の スマホを 手伝う とき」)
- ⭐ 理科と つなぐと へえに なる(「スマホの カメラも 理科の レンズ」「タッチパネルは からだの 電気を 感じる」)。こういう「へえ」を 1文 入れると よい
- **カタカナ語は ふつうの 言葉で 言いかえて から**(「ストレージ = 写真や アプリを しまって おく 場所」)
- **読み(ひらがな)は スマホの 10の 旅の 中で かぶらない**(台本が 止める)。下の「旅ごとに 入れる 語」を 守る。**ほかの 旅の 欄に ある 語は 入れない**
- 文体は **はじめから「〜です・ます」**(体言止めで はじめない)

## 1語の 形(JSON)

```json
{"id":"so-screenshot","name":"スクリーンショット","reading":"すくりーんしょっと","journey":"sosa","category":"画面を 残す","difficulty":1,
 "field":"使いかたと 操作","type":"concept","emoji":"📸","mapNode":"sosa:home","relatedTerms":["so-gamenshuroku"],
 "description":"いま 画面に 出ている ものを、そのまま 写真の ように 保存する ことです。人の メッセージを 写す ときは、のせて よいか 考えましょう。",
 "yatte":"写真の アプリを ひらいて、スクリーンショットだけを 集めた ところを さがして みよう。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(ふつうの 書きかた。漢字・カタカナ・英字の 略語。**商標は ダメ**)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)
  - カタカナ語は ひらがなで(スワイプ → すわいぷ)。英字の 略語は 下の「略語の 読み」の とおり
  - ゆれる ことばは いちばん ふつうの 読みを reading に、ほかを `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は 上級だけ・旅で 1〜2語まで
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級(下の「3段の 分けかた」)
- **field**: 学ぶ 分野。次の 7つの どれか:
  `ハードウェア` `OSと ソフトウェア` `ネットワーク` `セキュリティ` `使いかたと 操作` `くらしと ルール` `歴史`
  - めやす: 画面・チップ・電池・センサー・カメラの 部品・修理 → `ハードウェア` / OS・アプリ・アップデート・設定の しくみ・データ・バックアップ → `OSと ソフトウェア` /
    Wi-Fi・電波・基地局・クラウド・Bluetooth・GPS → `ネットワーク` / パスコード・認証・フィッシング・マルウェア・個人情報 → `セキュリティ` /
    ジェスチャー・画面の 名前・撮影の しかた・文字入力 → `使いかたと 操作` / 家族の ルール・SNS・健康・お金・マナー・リサイクル → `くらしと ルール` / 歴史と 人 → `歴史`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(🍎 は 使わない = りんごの マークに 見える。💀 ☠️ 🔪 も 使わない)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / 何の ために あるか / どう 使うと よいか」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  「1人」「2人」は ふりがなが 読みまちがえるので **ひとり・ふたり** と ひらがなで 書く
- **yatte**(任意。⭐ 新しい 欄): **「📱 やって みよう」**。1文・60字以内。いま 手元の スマホで ためせる こと。
  **旅ごとに 5〜10語**だけ。⚠️ **ボタンの 押しかた・設定の 道すじは 機種と 年で 変わる**ので、**ずっと 変わらない もの だけ**
  (ピンチで 写真を 大きく する・設定アプリを ひらいて みる・コントロールセンターを 出して みる・写真の アプリで アルバムを 見て みる)。
  ⚠️ **お金が かかる こと・設定を 変えて 困る こと(初期化・リセット・機内モードで 通話できなく なる)・人の スマホを さわる ことは 書かない**。
  「おうちの 人と いっしょに」を 付けると よい ものも ある
- **example**: なくてもよい

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | **スマホを 安全に 使いはじめる 子**。ボタン・ジェスチャー・きほんの 設定・あやしい メッセージ・家族の ルール。小学生でも 聞いた ことが ある |
| 2 | 中級 | **家族の スマホを 手伝える 人**。設定・通信・写真・バックアップ・安全の しくみ |
| 3 | 上級 | **スマホの 専門家**。ITパスポートの スマホ・ネット・セキュリティの ことばと、スマホの サポートの しくみの ことば(チップ・電波・認証・トラブルの 考えかた・歴史) |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる
(ならんだ 順が そのまま ステージの 順に なる)。
