## 3. ⚠️⚠️⚠️ ぜったいの 決まり(料理人・整備士と 同じ。食べものと 機械は なおさら)
- ✅ **ほかの ゲーム(料理人・理科・社会 など)と 同じ 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。説明は **育てる 人の 目線**で 書きなおす(例: トマト = 料理人では 食材 / 農家では 夏に 実る 野菜で、支柱を 立てて 育てる)
- **読み(ひらがな)は 農家の 8つの 旅の 中では かぶらない**(ほかの ゲームとは かぶって よい。`terms_js.py` が 止める)
- ⚠️⚠️ **農薬の 名前・量・まきかた を ぜったいに 書かない**。農薬は「作物を 病気や 害虫から 守る ために 決まりに そって 使う 薬」まで。**農薬・肥料の よしあし(安全か 危険か)を 書かない**(有機農業も 慣行農業も「育てかたの ちがい」として)
- ✅ **機械の 使いかたは 書く**(けいくん決定 2026-10-03「機械の使いかたも書いてください。農家が大変な仕事だと思われているから、機械を使い効率的に仕事が出来ることを使える方が良い」)。
  ⚠️ 整備士・大工の「使いかたを 書かない」とは **ちがう 決まり**。農家では **機械で 何が できて、どの 作業が らくに・速く なるか** を いちばん 大事に 書く
  (例: 田植え機 = 苗を 何列も いっぺんに 植えて いく 機械。人の 手で 1本ずつ 植えていた 田植えが 早く 終わる / ドローン = 空から 田畑の ようすを 見たり 肥料を まいたり する)。
  「農業は 大変・きつい」では なく **「機械と 工夫で 効率よく できる、かっこいい 仕事」** の 目線で。昔の 手作業と くらべる 書きかたは よい。
  ただし **刃や 回る ところに さわる・子どもが 運転する** 話は 書かない。運転・操作は「講習を 受けた おとなが 使う」と そえる(公道を 走る トラクターには 運転免許が 要る。確かめる)
- **小学生も あそぶ**: 家畜の と畜・病気で 処分・事故(機械・熊・はち)・災害の こわい ようすを 書かない。畜産は「牛乳や 卵・お肉に なる 動物を 大切に 育てる 仕事」と おだやかに。
  「殺」「死」の 字を 使わない(台本で 止める。害虫は「作物を 食べる 虫」・駆除は「追いはらう・ふせぐ」)
- **数字の 決めうちを 書かない**(食料自給率・収穫量・値段・農家の 数 など 年ごとに 変わる 数字は 書かない。**二十四節気の 名前・旬の 季節** など 変わらない ことは よい)
- **政治の よしあしを 書かない**(減反・TPP・輸入の 是非 など。制度は 名前と 何の ための しくみか だけ)
- **実在の 会社・農家・ブランドの 名前を 入れない**。**品種名は 商標で ない もの だけ**(コシヒカリ・ふじ(りんご)・あまおう(⚠️ 商標)… **確かめてから**。あやしい ものは 入れない)
- **作った 助手とは 別の 助手が 1語ずつ 確かめる**(意味・読み・農薬や 機械の 使いかたを 書いていないか・商標・こわくないか)。ふりがなも 全語 見る(`tools/ruby_fix.json`)。
  ⚠️ 農業の ことばは **読みが ゆれる**(苗代 なわしろ・代かき しろかき・畝 うね・堆肥 たいひ・摘果 てきか など)。ゆれる 語は `acceptedReadings` に 入れ、**いちばん ふつうの 読みを 先頭**に

## 5. 作りかたの 手順(大工・救急隊員の まとめと 同じ)
1. けいくんに 2 の 5つを 聞く → 返事を CLAUDE.md に 書く
2. `tools/noka/PROMPT.md` `exam.txt` `mkmeta.py` → `meta.json` を 作る → 旅ごとに 助手に 70語ずつ 頼む(`PROMPT.md` を そのまま わたす。**助手は 2人ずつ**)→ `terms-<旅>.json`
3. `terms_js.py` で 止められた 語を 直す → 別の 助手が 1語ずつ 確かめる → ふりがな
4. `noka/noka.js`(chef.js を 写す)・`build_games.py`・`index.html` の PLUG と SERIES → `python3 tools/build_games.py`
5. 手元で 通す: `python3 -m http.server 8765` → `node tools/play-all.mjs noka/` / `node tools/click-all.mjs noka/`
6. PR は **rebase で 取りこむ**(この 入れもの)。speed-king は squash。コミットの 末尾は Co-Authored-By と Claude-Session の 2行
7. かずとも `speed-king`: `FLICK_MODES` / `FLICK_LINK_TARGETS` に `noka`(PR → squash)。`HOME_GAMES` は 絵と OK の あと
8. けいくんに ChatGPT で 絵を 頼む 文を わたす。**3つ**:
   ・トップの 絵(1536×1024)。**人物は 画面の 下 3分の1に 小さく**・指5本・首が 見える。実った 畑と 田んぼ・果樹園が 広がる 里山で、麦わら帽子の 子どもと 白い 犬が 笑っている 絵。
     **かま・くわ などの 刃物や 農薬の ボトルを 手に 持たせない**(手が 崩れやすい・刃物を 子どもが 持つ 絵に しない。かごや 野菜を 置く)。**トラクターを 子どもに 運転させない**。
     ⚠️ その かわり **畑の 奥で 自動運転の トラクターや ドローンが 働いている 絵**に する(機械で 効率よく できる 農業を 見せる。けいくん決定 2026-10-03)。
     絵の 中の 字は「フリック農家」だけ・ゲームに 無い 機能の 絵を 入れない・**実在の 農協・メーカーの ロゴ・ブランドの 名前を 描かない**。届いたら **まず 字を 切り出して 読む**
   ・四角い 絵(1254px)… **切らずに そのまま アイコンに する**ので、**小さく しても わかる 絵**(人と 犬と 野菜の かご くらい。まわりに 字の 札を ならべない)で 頼む
   ・**題名だけの 透明 PNG**(CLAUDE.md「題名は ChatGPT に 切りぬいてもらう」の 文を そのまま。「フリック農家」と **はっきり 書く**。⚠️ ChatGPT は 字を 変える。**届いた 字を かならず 読む**)
9. 絵を 入れたら CLAUDE.md に 節を 書く(名前・旅・語数・確かめた 日・入れなかった 語と 理由)

## 6. 気をつける 前例
- 料理人(`chef/`)と **同じ 語が 多い**(野菜・果物・お米・旬・地産地消 など)。**同じ 語を 入れて よい**が、料理人 = 食べる・料理する 目線 / 農家 = 育てる 目線、と 分ける
- 理科旅行の 生物・地学(光合成・根・茎・葉・土・天気)とも かさなる。同じ 語で よい。説明は 農家の 目線で
- 整備士で「命に かかわる」を「とても 危ない」に 直した(2026-10-01)。農家でも 機械・はち・熊の 書きかたを おだやかに
- ⚠️ 機械の 使いかたは 書く(整備士・大工と ちがう)。**よかれと思って「使いかたを 書かない」に もどさない**(けいくん決定 2026-10-03)
- 社会旅行に 食料自給率・地産地消 などが ある。数字は 書かない 決まりを そろえる
- 2026-10-03 の 時点で 30ゲーム(投資家まで。大工・救急隊員は まとめだけ)。**フォルダ・id・modes 名を まぜない**(`noka`)
