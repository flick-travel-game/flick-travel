# フリック警察官: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
学ぶ 分野・しくみ図の どこに あるか(📍)が 出る。あそぶのは **小学生〜警察官を めざす 中高生・大学生・大人**。
**警察官に なるための ことばと 意味を おぼえる ゲーム**(試験の 問題集では ない)。
もとは `tools/kango/PROMPT.md`(看護師)と `tools/chef/PROMPT.md`(料理人)。
けいくん 2026-10-01「警察官になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 5つ

### 1. やりかたを 書かない(看護師の「処置の やりかたを 書かない」と 同じ。警察官は なおさら)
- ❌ **書かない**: 犯罪の やりかた・だましかた・にげかた・かくれかた / 武器の あつかい・しくみ / 取りしまりの 手順 / 逮捕の しかた /
  捜査の こつ(どこを どう 調べるか)/ 防犯の しくみの 弱いところ / ハッキングの 手口
- ⭕ **書くのは**: その ことばが **何を さすか**・**何の ための しくみか**・**警察官が どう 守るか・助けるか**・**みんなが どう 気をつければ よいか**
  - 例: 指紋 = 人に よって ちがう 指の もよう。現場に 残った ものと くらべて、事件の 手がかりに します
  - 例: 特殊詐欺 = 電話や メールで 家族や 役所の ふりを して お金を だまし取ろうと する 犯罪。「お金の 話が 出たら、まず 家族や 警察に 相談」が 大切です
- **銃・けん銃・警棒・手錠などの 装備は 入れない**(まよったら 入れない、の 決まりに したがう)。装備は「制服」「無線」「警察手帳」「反射たすき」など こわくない ものだけ
- **取りしまる 側の ことばでも、まねできる 形に 書かない**

### 2. 小学生も あそぶ(こわく しない)
- ❌ 事件・事故・けが・死の ようすを 書かない。血・遺体・凶器 の 話を しない
- ❌ **殺人・強盗・誘拐・放火・性犯罪・薬物の 具体名(覚醒剤・大麻・麻薬)・暴力団・テロ** などは **入れない**。
  犯罪の 大きな 分けかた「凶悪犯」「粗暴犯」「知能犯」も **入れない**(けいくん決定 2026-10-01)
- ⭕ 入れて よい 犯罪の 名前は **子どもが 気をつけられる もの だけ**: 詐欺・特殊詐欺・窃盗・万引き・自転車盗・空き巣・ひったくり・不審者・いたずら電話・ネットの 悪口 など。
  書きかたは「警察官が どう 守るか」「どう 気をつければ よいか」
- ⭕ **実際の 事件の 名前・実在の 人物・実在の 県警の 事件は 入れない**
- 読んだ 子が **「助けて くれる 人が いる」「こまったら 110番 や 交番」** と 思える 書きかたに する。**迷ったら その 語を 入れない**
- 「死亡」「死ぬ」「亡くなる」「殺」「遺体」「血」「銃」「撃」は 使わない(台本が 止める)

### 3. 法律は 名前と 目的だけ
- 法律は **「名前」と「何の ための 法律か」** だけ。**条文を 写さない**・**罰の 重さ(懲役◯年・罰金◯円)を 書かない**・条文の 中身を 決めうちしない
- 条の 番号は **まちがいない ときだけ**(憲法 第9条・第25条、警察法 第2条・第62条 など)
- **政治・思想の よしあしを 書かない**(どの 党・どの 考えかたが 正しい、を 書かない)

### 4. 試験・制度の 事実は `tools/keisatsu/exam.txt` に 合わせる
- 警察官の ほとんどは **都道府県警察の 地方公務員**。警視正 以上は 国家公務員(地方警務官)。警察庁の 警察官も 国家公務員
- 採用試験は **都道府県ごと**。区分名(Ⅰ類・Ⅲ類・A・B …)は **県で ちがう** と 書く
- 階級は **9つ**(巡査・巡査部長・警部補・警部・警視・警視正・警視長・警視監・警視総監)。**巡査長は 階級ではない**(巡査の 中の 呼び名)
- 警察学校の 長さは **県で ちがう**(警視庁は 大学卒業程度 6か月・高校卒業程度 10か月)
- 数字・年・条は **まちがいない ときだけ**。あやしい 語は **入れない**

### 5. 警察官の 目線で 書く(社会・教師など ほかの ゲームと 同じ 語を 入れて よい)
- ✅ **ほかの ゲームと 同じ ことばを 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)
- ⚠️ ただし 説明は **警察官の 目線**で 書きなおす。例: 三権分立 … 社会「国の 力を 3つに 分ける しくみ」/
  警察官「警察は 行政の 一部。逮捕や 捜索には 裁判所の 令状が いる ことが 多く、裁判所が 行政の 行きすぎを 止める しくみ」
- **読み(ひらがな)は 警察官の 7つの 旅の 中で かぶらない**(台本が 止める)。下の「旅ごとに 入れる / 入れない」を 守る

## 1語の 形(JSON)

```json
{"id":"kb-koban","name":"交番","reading":"こうばん","journey":"koban","category":"交番と駐在所","difficulty":1,
 "field":"地域警察","type":"concept","emoji":"🚓","mapNode":"koban:koban","relatedTerms":["kb-chuzaisho"],
 "description":"まちの 中に ある 警察官の 小さな 拠点。道案内や 落とし物、こまった ことの 相談を 受け、まわりを パトロールして 地域を 守ります。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(ふつうに 使う 言いかた。漢字・カタカナ・英字の 略語・数字 110番 など)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)
  - 数字は ひらがな(110番 → ひゃくとおばん / #9110 → しゃーぷきゅういちいちまる)
  - ゆれる ことばは 1つに 決め、別の 読みは `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)。例: ひゃくとおばん / ひゃくとうばん
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は **上級だけ**に、旅で 1〜2語まで(長い 法律名は 短い 呼び名に。警察官職務執行法 → 警職法(けいしょくほう)、説明に 正式な 名前)
  - ⚠️ **読みを まちがえやすい ことば**(巡査 じゅんさ・警邏 けいら・遺失物 いしつぶつ・拾得物 しゅうとくぶつ・被疑者 ひぎしゃ・令状 れいじょう・
    鑑識 かんしき・検視 は 入れない・送致 そうち・勾留 こうりゅう・黙秘権 もくひけん・公安委員会 こうあんいいんかい・警視総監 けいしそうかん・
    礼式 れいしき・術科 じゅつか・守秘義務 しゅひぎむ・駐在所 ちゅうざいしょ・所轄 しょかつ …)は **1語ずつ 確かめる**
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級(下の「3段の 分けかた」)
- **field**: 学ぶ 分野。次の 11の どれか(入門の 語でも いちばん 近い ものを 書く):
  `社会科学` `憲法` `行政法` `刑法` `刑事訴訟法` `地域警察` `交通警察` `刑事警察` `生活安全警察` `警備・災害` `警察官の基本`
  - めやす: 政治・経済・時事・国の しくみ → `社会科学` / 憲法・人権 → `憲法` / 警察法・警察官職務執行法・行政の しくみ・公務員の 法律 → `行政法` /
    犯罪の 名前・罪の 考えかた → `刑法` / 捜査・逮捕・裁判の 手続きの ことば → `刑事訴訟法` / 交番・パトロール・110番・落とし物 → `地域警察` /
    交通・道路交通法・免許 → `交通警察` / 捜査・鑑識の ことば → `刑事警察` / 防犯・少年・詐欺・サイバー・相談 → `生活安全警察` /
    警備・災害・国際 → `警備・災害` / 礼式・術科(柔道・剣道)・体力・倫理・採用試験・警察学校 → `警察官の基本`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(🔫 🔪 🩸 💀 ☠️ 💣 💊 など こわい・武器の 絵文字は 使わない。🚓 👮 の 多用も さける)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / 何の ために あるか・警察官は どう 守るか」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  専門用語を 専門用語だけで 説明しない。「1人」「2人」は ふりがなが 読みまちがえるので **ひとり・ふたり** と ひらがなで 書く
- **example**: なくてもよい

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | まちで 見かける 警察の ことば。小学生でも 聞いた ことが ある(交番・パトカー・110番・信号・落とし物) |
| 2 | 中級 | **警察官採用試験の 教養試験の 範囲の めやす**(憲法・法律の 名前・時事・一般常識・警察の しくみ) |
| 3 | 上級 | 法律の 名前と 条の めやす・階級と 組織の こまかい ところ・専門の 部門・警察学校で 学ぶ ことば |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる
(ならんだ 順が そのまま ステージの 順に なる)。

## ぜったいに 守ること

- **自分の ことばで 書く**。過去問・問題集・教科書・Wikipedia の 文を 写さない
- **実在の 事件・人物・会社・商品・県警の ゆるキャラの 名前**は 使わない(警視庁・警察庁など **役所の 名前は よい**)
- **数字は まちがいない ときだけ**
- 画面には「これは ことばを おぼえる ゲームです。本物の 試験問題では ありません。警察庁・都道府県警察とは 関係ありません。こまった ときは 110番 か 近くの 交番へ」が 出る
- 「100マス計算」「百ます計算」の 字を 使わない
