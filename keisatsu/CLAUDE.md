## フリック警察官(`keisatsu/`。けいくん 2026-10-01「警察官になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」)

- 名前は「フリック警察官」(絵が 届いたら 題名に そろえる。フォルダ名 `keisatsu` は 変えない)。シリーズの 絵文字は 🚓
- 旅は 7つ(交番とまちのことば `koban`・交通のことば `kotsu`・事件と捜査のことば `sosa`・まもるしくみ `mamoru`・法律のことば `horitsu`・警察のしくみ `soshiki`・警察官の心とからだ `kokoro`)+ マスター。
  **旅ごとに 70語(入門20・中級25・上級25)= 490語**。かずともの 旅の 名前は **`po` で はじめる**(pokoban / pokotsu / pososa / pomamoru / pohoritsu / pososhiki / pokokoro / pomas)。⚠️ `p` だけは パティシエが 使っている
- むずかしさは 3段: 入門(まちで 見かける 警察の ことば)→ 中級(**警察官採用試験の 教養試験の 範囲の めやす**)→ 上級(法律の 名前・階級と 組織の こまかい ところ・専門の 部門)。
  1語ごとに **学ぶ 分野**(`field` → 画面では 📘 学ぶ 分野。採用試験の 教養 + 警察学校で 学ぶ 分け: 社会科学 / 憲法 / 行政法 / 刑法 / 刑事訴訟法 / 地域警察 / 交通警察 / 刑事警察 / 生活安全警察 / 警備・災害 / 警察官の基本 の 11)。図鑑で しぼれる
- ことばは `tools/keisatsu/terms-<旅>.json`(決まりは `tools/keisatsu/PROMPT.md`)→ `tools/keisatsu/terms_js.py` → `keisatsu/terms.js` + `data/keisatsu.json`。
  しくみは `keisatsu/keisatsu.js`(料理人を 写した。4択クイズ あり)。しくみ図は コードで 描く 箱の 図 7つ(**交番の地図**・道路・捜査・まもる・法律・**警察署の地図**・心とからだ。`tools/keisatsu/mkmeta.py` が meta.json を 作る)。ホームでは たたんで ある
- 試験・制度の いまの形は `tools/keisatsu/exam.txt`(→ meta.json の `exam`)に **確かめた日つき**(2026年10月1日に 警察庁・警視庁・警察白書 令和8年版と 警察法・警察官職務執行法で 確かめた。e-Gov は その日 メンテナンス中だった):
  ほとんどは 都道府県警察の 地方公務員(警視正 以上は 国家公務員の 地方警務官)/ 採用試験は 都道府県ごと・区分名は 県で ちがう(警視庁は Ⅰ類 大卒程度・Ⅲ類 高卒程度。教養試験 五肢択一 50問 / 30問)/
  警察学校は 警視庁で 6か月 / 10か月 / 階級は 9つ(巡査長は 階級ではない)/ 地方警察官の 定員 260,550人(令和8年4月1日)/ 110番は 通信指令室・相談は #9110。⚠️ 文を 直すときは その日に 確かめて `exam` の 日付も 上げる
- ⚠️⚠️⚠️ **やりかたを 書かない**: 犯罪の やりかた・だましかた・武器(銃・警棒・手錠)・取りしまりや 逮捕の 手順・捜査の こつ。**名前と「何の ための ものか」「警察官が どう 守るか」「どう 気をつけるか」だけ**。
  画面(ホームの 下・遊びかた)に「これは ことばを おぼえる ゲームです。本物の 試験問題では ありません。こまった ときは 110番 か 近くの 交番へ」「警察庁・都道府県警察とは 関係ありません」
- ⚠️⚠️ **小学生も あそぶ**: 殺人・強盗・誘拐・放火・性犯罪・薬物の 具体名・暴力団・テロ・「凶悪犯」「知能犯」は **入れない**(けいくん決定 2026-10-01「全部おすすめで」)。
  入れて よい 犯罪の 名前は 子どもが 気をつけられる もの(詐欺・万引き・空き巣・ひったくり・不審者 など)。法律は 名前と 目的だけ(罰の 重さ・条文の 写しは 書かない)。政治の よしあしは 書かない(憲法第9条・憲法改正も 中立に)
- `terms_js.py` の `BAN` が こわい ことば・入れない 犯罪名・武器・罰の 重さを 止める。⚠️ 「撃」は「目撃」だけ 通す(正規表現)
- ✅ 社会・教師 など ほかの ゲームと 同じ 語を 入れて よい。読みは **警察官の 7つの 旅の 中で** かぶらない(`terms_js.py` が 止める)。
  はじめ 通学路(交番・交通)・警察安全相談(交番・まもる)が かぶったので 交番の ほうを「登下校の見守り」「相談窓口」に。警視長は 警視庁と 読みが 同じ(けいしちょう)なので 語に せず、警視正・警視監の 説明の 中で 教える。
  補導は 歩道(ほどう)と かぶるので「街頭補導」
- ふりがなの 読みまちがいは **警察官の 中だけで** 直す(`terms_js.py` の `FIX`): ひとつだけの 数 → かず / 立番 → りつばん / 1日中 → いちにちじゅう / 4月1日 → ついたち / 局 → きょく / 委員会の 長 → ちょう
