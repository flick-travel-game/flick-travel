# フリックプログラマー: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
しくみ図の どこに あるか(📍)が 出る。あそぶのは **小学生〜プログラマー・エンジニアを めざす 学生・大人**。
**プログラミングの ことばと 意味を おぼえる ゲーム**(コードの 書きかたの 教科書では ない)。
(けいくん 2026-09-29「プログラマーになれるレベルになるために必要な 知識をフリック形式の問題にしてください」。
 決めたこと: 名前 = フリックプログラマー(中に 👷 エンジニアの 旅)/ 3段 / 言語は 少しだけ / 2進数・16進数を 入れる / 図を 作る。
 引継ぎは `docs/引継ぎ-プログラマーフリック旅行.md`)

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 5つ

### 1. 目線は「**自分で コードを 書く 人**(作る 側)」
- フリックAI旅行(`ai/`)は「AIに 作ってもらう 人(使う 側)」の ゲーム。こちらは **プログラミングの 仕事が できる** ための ことば
- **AI旅行・ゲームクリエイターと 同じ ことばを 入れて よい**(時間を あけた 復習に なる。けいくん決定 2026-09-29)。
  ただし **説明の 文は 作る 側の 目線で 書きなおす**。`tools/code/other-words.tsv`(ゲーム・名前・読み・説明)を 見て、
  **同じ 文・ほとんど 同じ 文に しない**。例:
  - API … AI旅行「よその サービスと つなぐ ための 入口」→ こちら「自分の プログラムを ほかから 呼べるように する 決まり」
  - テスト … AI旅行「ちゃんと 動くか たしかめる こと」→ こちら「部品 1つずつが 正しく 動くかを **自動で** 調べる しくみ」
  - Git … AI旅行「直した ところを 記録する しくみ」→ こちら「**みんなで 1つの コードを 直す** ための しくみ」
  - バグ … AI旅行「思ったとおりに 動かない こと」→ こちら「**なぜ そうなるかを 見つけて 直す**ところまでが 仕事」
  - データベース … AI旅行「データを しまう ところ」→ こちら「どんな 形で しまうかを **自分で 決める**(設計)」
- ゲームクリエイターの「⌨️ コードと作りかた」(if文・for文・クラス …)とも かぶる。そちらは **ゲーム作りの 目線**、こちらは **仕事の 目線**

### 2. **コードを 打たせない**(打つのは ことばの 読みだけ)
- `if (x > 0) {` や `print("hello")` は 打てない。**見出しは ことばの 名前**(じょうけんぶんき・はいれつ・さいき)
- 短い コードの 見本は **`example` に 1〜2行**(下の「example の 書きかた」)。**説明(description)には 記号 `< > & { } ; =` を 入れない**
- **やりかたの 手順(プログラムの 書きかた・コマンドの 打ちかた)を 長々と 書かない**。ことばの 意味を おぼえる ゲーム

### 3. **言語を えらばない・順位を つけない**
- Python・JavaScript などの 名前は 入れて よいが **💻 コンピュータのきほん の「言語の 港」だけ**・少しだけ(8語くらい)。
  説明は「その 言語で **何が 書けるか / どこで よく 使われるか**」の 目線
- 「◯◯が 一番」「◯◯は おそい」「◯◯は 古い」と 書かない。**どれにも よい ところが ある**

### 4. 会社・製品・サービスの 名前を むやみに 出さない
- ❌ 会社名・サービス名・商品名(台本の BAN が 止める)。道具は **一般の 名前**で(「バージョン管理の 道具」「エディター」)
- ⭕ プログラミング言語の 名前・Git・Linux・SQL・HTML・CSS・HTTP・Unicode などの **みんなの 決まりの 名前** は よい
- **お金の ことば**(給料・年収・円・売上・値段)を 書かない。見積もりは「時間と 人」の 話だけ

### 5. 「やってみたい」を じゃましない
- あそぶ 子は プログラマーに なりたい 子かも しれない。こわがらせない。「天才で ないと むり」と 思わせない
- ことばに よっては **はじめの 一歩が 見える 一言**(「まちがえるのは ふつうの ことです」「小さく 作って ためすのが 大事です」)
- 自分の 宣伝(かずとも・フリック旅行の 名前)を 書かない。「100マス計算」「百ます計算」の 字を 使わない

## 1語の 形(JSON)

```json
{"id":"ka-hensu","name":"変数","reading":"へんすう","journey":"kata","category":"入れもの","difficulty":1,
 "role":"みんな","type":"concept","emoji":"📦","mapNode":"kata:hensu","relatedTerms":["ka-teisu"],
 "description":"数や 字に 名前を つけて しまっておく 入れもの。あとから 中身を 入れかえられるので、点数や 名前を 覚えておくのに 使います。",
 "example":"score = 0"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(プログラマーが ふつうに 使う 言いかた。漢字・カタカナ・英字)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白は ダメ)
  - カタカナ語は ひらがなに(りふぁくたりんぐ)。英字は 下の「英字の 読み」の とおり。ない ものは 日本の ふつうの 読み
  - 数字は ひらがな(2進数 → にしんすう / 16進数 → じゅうろくしんすう)
  - ゆれる ことばは 1つに 決め、別の 読みは `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 読みは 入れない**。13字を こえる ものは **上級だけ**
- **journey**: その 旅の id / **difficulty**: `1` 入門 / `2` 中級 / `3` 上級
- **role**(図鑑で しぼる「分野」): `みんな`(どの エンジニアも 使う)`フロントエンド`(画面がわ)`バックエンド`(サーバーがわ)`インフラ`(サーバー・ネットワーク・クラウド)`データ`(データベース・データの 分析)`セキュリティ` `テスト`(品質)`チーム`(すすめかた・チームの ことば)の どれか
- **type**: いつも `"concept"` / **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**)
- **emoji**: 1つ(💰 💴 など お金の 絵文字・武器の 絵文字は 使わない)
- **mapNode**: `"<旅の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の 表)
- **relatedTerms**: **同じ 旅(ファイル)の 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / どこで 使うか / なぜ 大事か」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例の ように)。
  カタカナの 専門用語を カタカナだけで 説明しない。**説明の 中に 英語・記号を まぜない**。
  「1人」「2人」は ふりがなが「ひと」に なるので **ひらがなで「ひとり」「ふたり」**
- **example**: なくて よい。書く ときは 下の 決まり

## example の 書きかた(コードの 見本 か、たとえ話 の どちらか)

- **コードの 見本**: **1〜2行の ASCII だけ**(日本語を まぜない。コメントも 英語か なし)。**1行 40字くらいまで**。
  - どの 言語でも 読める **C系・Python 風の かんたんな 形**。言語 だけの 書きかたは その 言語の 語の ときだけ
  - 変数名・関数名は 英語の かんたんな 名前(score / total / items / add())
  - **動く 正しい 書きかた**で。まちがいを 見せる 語(構文エラー など)は「まちがい」の 1行 と「直した 形」の 1行
  - 2行に する ときは 改行 `\n` で つなぐ
- **たとえ話**: 日本語 1文(「たとえば〜」の 形は いらない。画面に「たとえば」と 出る)。**記号 `< > &` を 入れない**
- 画面は **日本語が 1字でも 入っていれば たとえ話、なければ コードの 箱**に 出す

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | **学校の プログラミングで 出てくる ことば**。小学生〜中学生でも 聞いた ことが ある(変数・くりかえし・エラー・並べかえ・2進数・キーボード) |
| 2 | 中級 | **仕事で 使う 考えかた**。プログラマーが 毎日 使う ことば(型・引数・戻り値・クラス・例外・コードレビュー・ブランチ) |
| 3 | 上級 | **くわしい しくみ**。仕事で 一人前の めやす(スコープ・再帰・継承・計算量・二分探索・文字コード・正規化・技術的負債) |

⚠️ **本当に プログラマーに なれる レベル**に する。上級は 手を ぬかない。現場で 本当に 使われている ことばだけ、意味を 正しく。
説明は **子どもにも 読める やさしい ことば**で(むずかしい ことばを やさしく 言いかえるのが この ゲームの いちばんの 価値)。

**1つの 旅に 80語: difficulty 1 を 20語、2 を 30語、3 を 30語**。
⚠️ **👷 エンジニアの 旅だけ 入門なし: 2 を 40語、3 を 40語**(1〜7の 旅を あるいた 人が たどりつく さいごの 旅)。
同じ difficulty の 中は **よく 知られている 順**(ならんだ 順が そのまま ステージの 順)。

## ぜったいに 守ること

- **自分の ことばで 書く**。本・記事・Wikipedia・公式ドキュメントの **本文を 写さない**
- **意味を 正しく**。事実が あやしい 語は **入れない**。数字は まちがいない ときだけ(1バイト = 8ビット は よい)
- **会社・製品・サービスの 名前を 使わない**・**お金の ことばを 使わない**(台本の BAN が 止める)
- ほかの 旅と **読みが かぶらない**(上の 入れる / 入れない を 守る)

## 出すもの

`tools/code/terms-<旅id>.json` に JSON の 配列(80語)で 書く。書いたら
`python3 tools/code/terms_js.py --only <旅id>` で 形を 確かめる(まちがいが あれば 止まる)。
