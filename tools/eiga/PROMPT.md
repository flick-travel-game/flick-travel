# フリック映画評論家: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

## ⚠️⚠️⚠️ いちばん はじめに 読む: 入れない 映画・書かない こと

この ゲームは **小学生も あそぶ**。けいくんは **子どもの スクールの 先生**。だから 映画の 題名を 入れるのは **子どもが 見て よい 映画だけ**。

- ❌❌❌ **題名を 入れるのは 映倫の 区分が G か PG12 の 作品だけ**(海外の 作品は 日本で 公開した ときの 区分。古い 作品で 区分が 無い ものは、**こわい・暴力・大人むけで ない** ことを 確かめて から)。
  **R15+ / R18+ は 題名も 入れない**(説明の 中にも 書かない)。PG12 でも **こわい・暴力・戦争・人の 死が 中心の 作品は 入れない**。**迷ったら 入れない**
- ❌❌ **有名でも 入れない 作品**(例): 『ゴッドファーザー』『時計じかけのオレンジ』『羊たちの沈黙』『セブン』『ジョーカー』『パラサイト 半地下の家族』『タイタニック』『ジョーズ』『シャイニング』『エクソシスト』『火垂るの墓』『もののけ姫』
  『羅生門』『戦艦ポチョムキン』『カサブランカ』『ロッキー』『タクシードライバー』『ショーシャンクの空に』『リメンバー・ミー』『バンビ』『ハチ公物語』『万引き家族』『ドライブ・マイ・カー』『AKIRA』『鬼滅の刃』の 映画。
  映画史の 流れ(アメリカン・ニューシネマ・ホラーの ジャンル など)は **作品名を 出さずに** 書く
- ❌❌ **ネタバレを 書かない**。あらすじは **「どんな 話の はじまりか」1行まで**。**結末・どんでん返し・だれが 何者か・だれが 亡くなるか**は 書かない。
  「どんでん返しで 有名な 作品」の **例の 題名も 書かない**(それ自体が ネタバレ)
- ❌❌ **数字が 変わる ものを 書かない**: 興行収入・観客動員・歴代◯位・配信の 再生数・レビューサイトの 点・俳優の いまの 所属・いま 公開中の 作品。
  ✅ **変わらない 事実は よい**: 公開年・監督・**受賞と その 年**・映画祭の 開かれる 街・技法の 名前・「はじめての ◯◯」(**確かめて から**)
- ❌ **評論は 意見**。「名作」「傑作」「最高」「いちばん おもしろい」を **事実のように 書かない**。「名作として よく 挙げられる」「映画史の 本に よく 出る」「多くの 評論家が 高く 評価した」まで。**ランキング(◯位)を 書かない**
- ❌ **映画を けなさない**(駄作・失敗作・つまらない・こけた・ラジー賞)
- ❌ **実在の 人の 私生活・事件・病気・亡くなった 話**は 書かない(功績だけ)。生まれた 年・亡くなった 年も 書かない(「1950年代から 活やく」の ように)
- ❌ **生きている 評論家の 名前は 入れない**(亡くなった 評論家は 功績だけ: 淀川長治・水野晴郎・ロジャー・イーバート・アンドレ・バザン)
- ❌ **キャラクターの 名前を 答えに しない**(トトロ・アトム・ゴジラ・ヨーダ・ミッキー)。作品名(『となりのトトロ』)は 答えに して よい。キャラクター名は 説明の 中で 1回まで
- ❌ **俳優の 名前は 答えに しない**(説明の 中で「◯◯が 主演」は よい)。答えは **作品・監督・技法・ことば・映画祭・賞**
- ❌ **配信サービス・映画館チェーン・カメラや 編集ソフトの 商品名**は 書かない。会社の 名前(東宝・東映・松竹・ディズニー・ピクサー・スタジオジブリ)は **事実として よい**が、どれかを 上に 書かない
- 台本 `terms_js.py` が「死・殺・血・ホラー・R15・R18・興行収入・億円・駄作・結末は」などを 止める

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
どの 国の 話か(国旗の 札)・いつの 話か(年代の 札)・**🍿 見どころ**(作品だけ)・学ぶ 分野・しくみ図の どこに あるか が 出る。
あそぶのは **映画が すきな 小学生〜中高生・映画の 感想を 書いて みたい 人・映画評論家を めざす 人**。
けいくん 2026-10-12「**映画評論家の世界トップレベル**になるために必要な 知識をフリック形式の問題にしてください」→
同じ日「**観たい映画を増やしたいので 世界と日本の有名な作品を観たくなるように詳しくお願いします**」。

## ⭐⭐⭐ けいくんの ねがい: 「観たく なる」ように 書く

- 作品の 語は **説明(description)** と **🍿 見どころ(midokoro)** の 2つで 書く
  - **description**(130字まで): 「**◯◯年の アメリカ映画。△△監督。**」+ どんな 話の **はじまり**か 1行 + **へえ**(はじめての ◯◯・受賞・技法・のちの 映画への 影響)
  - **midokoro**(90字まで・**作品の 語は かならず**): **ここを 見て ほしい** を 1〜2文。**映像・音楽・場面の 空気・技法・演技の 見どころ**で 書く(「雨の 中で 歌い おどる 場面の よろこびが 画面いっぱいに あふれます」)。
    ⚠️ **結末・どんでん返し・だれが 何者かは ぜったいに 書かない**。「ラストが すごい」「最後に おどろく」も 書かない(期待させる こと 自体が ネタバレに なる)。
    ⚠️ 「名作」「最高」を 事実に しない。読んだ 子が **「見て みたい」と 思える 具体的な 1場面・1工夫**を 書く
- 作品・監督の 語には **era**(公開の 年代)を 付ける。監督は **いちばん 活やくした 年代**

## 1語の 形(JSON)

```json
{"id":"sk-singin","name":"『雨に唄えば』","reading":"あめにうたえば","journey":"sekai","category":"ミュージカルの 名作","difficulty":2,
 "field":"作品・人","type":"concept","emoji":"☔","mapNode":"sekai:musical","relatedTerms":["sk-gene","gn-musical"],"country":"アメリカ","era":"1950s",
 "description":"1952年の アメリカ映画。ジーン・ケリーと スタンリー・ドーネンの 監督。サイレント映画から トーキーに 変わる ころの ハリウッドが 舞台の ミュージカルです。",
 "midokoro":"どしゃぶりの 雨の 中、かさを 手に 歌い おどる 場面は 映画史に 残る 名場面と よく いわれます。水たまりを けとばす よろこびを 見て みよう。"}
```
```json
{"id":"gh-closeup","name":"クローズアップ","reading":"くろーずあっぷ","journey":"giho","category":"ショットの 大きさ","difficulty":1,
 "field":"技法","type":"concept","emoji":"🔍","mapNode":"giho:size","relatedTerms":["gh-longshot"],
 "description":"顔や 手など 一部を 画面いっぱいに 大きく うつす ショットです。気持ちの ゆれや 大事な 小物に 目を 向けさせます。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前。**作品名は 『 』で かこむ**(日本で 公開した ときの 題名・中点も そのまま:『スター・ウォーズ』)。副題は 説明に。人は 日本で ふつうに 使う 書きかた(スティーブン・スピルバーグ)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」「『』」「。」「!」は ダメ)
  - 作品名の 記号は 取る(『君の名は。』→ きみのなは / 『E.T.』→ いーてぃー / 『Shall we ダンス?』→ しゃるうぃだんす)。数字は 読みで(『101匹わんちゃん』→ ひゃくいっぴきわんちゃん)
  - 人の 名前は **名字だけ でも よい**(すぴるばーぐ)が、ほかの 人と かぶらない ように。ゆれる 読みは `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 読みは 入れない**(長い 題名は 短く 呼ばれる 形で:『ハリー・ポッターと賢者の石』→ はりーぽったーとけんじゃのいし は 16字で よい)。16〜20字は 上級だけ・旅で 2〜3語まで
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級
- **field**: 学ぶ 分野。次の 7つの どれか: `映画史` / `技法` / `物語` / `作品・人` / `賞・映画祭` / `評論` / `業界`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(🩸 💀 ☠️ 🔪 🔫 💣 👻 🧟 🧛 😱 😭 は 使わない。🎬 ばかりに しない。国旗の 絵文字は 使わない(札で 出る ため))
- **country**(関係が あれば): `世界` `ヨーロッパ` `アジア` `日本` `アメリカ` `カナダ` `メキシコ` `ブラジル` `イギリス` `アイルランド` `フランス` `イタリア` `ドイツ` `スペイン` `デンマーク` `スウェーデン` `ロシア` `チェコ` `ポーランド`
  `インド` `イラン` `中国` `台湾` `香港` `韓国` `オーストラリア` `ニュージーランド` の どれか。2〜3つなら「・」で。技法・きほんの ことばなど 国と 関係ない 語は 付けない
- **era**(作品・人・できごとの 語): `1890s` `1900s` `1910s` … `2020s` の どれか(**公開の 年代**)。年代と 関係ない 語は 付けない
- **midokoro**: **作品の 語は かならず**(90字まで)。作品で ない 語には 付けない
- **mapNode**: `"<旅の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **9つの 旅の どこかの** id を **1〜3個**(自分は ダメ。ほかの 旅の id も よいが、**その id が 本当に ある か**を 下の 一覧で 確かめる。わからなければ 同じ ファイルの 中から)
- **description**: **1〜3文・130字以内**・やさしい です・ます。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。「1人」「2人」は **ひとり・ふたり** に 言いかえる
- 「へえ」を 1文 入れると よい(「カチンコの 音で 映像と 音を あとで ぴったり 合わせる」「ヴェネツィア国際映画祭は 世界で いちばん 古い 映画祭」)

## 事実を 正しく(⭐ いちばん 大事)
- ⭐⭐ **作品と 監督と 年の 組み合わせ**が いちばん まちがえやすい。**1つずつ web で 確かめて から 書く**(『E.T.』= スピルバーグ 1982年・『隠し砦の三悪人』= 黒澤明 1958年)。公開年は **その 国で はじめて 公開した 年**
- ⭐⭐ **映倫の 区分**: 日本で 公開した ときの 区分を 確かめる(映倫の サイトの 作品検索・作品の 公式・配給会社)。わからない・大人むけの 場面が ある と 書かれている 作品は **入れない**
- ⭐ **受賞と 年**: 各映画祭・アカデミー賞の 公式で 確かめる(授賞式の 年と 対象の 年が ちがう ので 「◯年の 授賞式で」と 書く)
- 「はじめての ◯◯」は 説が 分かれる ことが 多い。「はじめての ◯◯の 1つと いわれる」「◯◯の はじまりと よく いわれる」まで
- **自分の ことばで 書く**(Wikipedia・公式の 文を 写さない)
