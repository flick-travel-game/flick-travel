# フリック自動車運転免許: 🖼 危険予測(本免の イラスト問題と 同じ 形)の 作りかた

本免の 学科試験には 絵を 見て 危険を 予測する 問題が 5問(1問に ⭕❌ 3つ。3つ ぜんぶ 正しくて 2点。facts.md で 確かめる)。
この ゲームでは 絵を **コードで 描く 上からの 図**に する(⚠️ AI の 絵は 使わない — 位置が ずれると 答えが 変わる)。**約60場面**。

## 決まり
1. `PROMPT.md` の 決まりを 守る(こわく しない・2026年の 改正)。「〜かもしれないので」の 考えかたを とき方に
2. 1つの 場面に ⭕❌ を **3つ**。3つの うち ⭕ は 1〜2つ(ぜんぶ ⭕ / ぜんぶ ❌ は 少しだけ)
3. 文は 本物と 同じ「時速◯kmで 進んでいます。どのようなことに注意して運転しますか?」の 形。選択肢は「〜かもしれないので、〜する。」
4. 図は 下の 部品だけで 描ける 場面に する(複雑に しない)
5. 交差点・横断歩道・駐車車両の かげ・バス停・踏切・自転車・子ども・対向車の 右折・後ろの 二輪・夜・雨・高速の 合流 など **はば広く**

## 形(`tools/menkyo/kiken-q.json` に 配列で)
{"id":"kq-001","text":"時速30kmで進んでいます。前に止まっているバスがあります。どのようなことに注意して運転しますか?",
 "scene":{"road":"straight2","items":[
   {"t":"me","x":40,"y":85,"dir":"up"},{"t":"bus","x":40,"y":45,"dir":"up","stop":true},{"t":"stop","x":27,"y":45},
   {"t":"person","x":46,"y":32,"hidden":true},{"t":"car","x":60,"y":20,"dir":"down"}]},
 "opts":[{"s":"バスの前から人が道路を横断するかもしれないので、速度を落として注意して進む。","a":true},
         {"s":"バスの右側を通るときは、対向車が来るかもしれないので注意する。","a":true},
         {"s":"バスは止まっているので、急いで追い越す。","a":false}],
 "why":"止まっている バスの かげは 見えない ところ(死角)です。人が 出てくる かもしれないと 考えて 速さを 落とします。"}
- 座標: x, y は 0〜100(図の 左上が 0,0。右が x+・下が y+)。
- ⚠️⚠️ **日本は 左側通行**。上へ 進む 車(自分の 車も)は **道の 左がわ**、下へ 来る 車(対向車)は **道の 右がわ**に 置く:
  ・straight2 / cross / crossSignal / tLeft / tRight / rail / parking(道は x 30〜70・中央線 x 50): 上へ 進む 車の 車線の まん中 **x 40**、対向車 **x 60**。歩道がわ(左の はし)は x 32〜34
  ・straight1(中央線 なし。道は x 36〜64): 上へ 進む 車 x 44、対向車 x 56
  ・横の 道(cross など。y 30〜70・中央線 y 50): **右へ 進む 車は 下がわ y 60**、**左へ 進む 車は 上がわ y 40**
  ・highway(本線は 上へ 一方通行。x 30〜55 が 走行車線(まん中 x 42)、x 55〜80 が 追越車線(まん中 x 67)、x 14〜32・y 40 から 下が 加速車線(まん中 x 23))
  ・curve(下から 上へ 来て 右へ 曲がる): 上へ 進む 車 x 40(y 60〜100)
  ・**自分の 車(me)は ふつう 下の ほう(y 80〜90)で 上へ 進む**(x は 上の 車線の まん中)
  ・部品の 大きさ: 車 6×10・トラック 7×15・バス 7×18(向きの 方に 長い)。重ならない ように 置く
- road(道の 形): "straight2"(片側1車線の まっすぐな 道。中央線 あり)/ "straight1"(中央線の ない せまい 道)/ "cross"(十字路。信号 なし)/ "crossSignal"(十字路。信号 あり)/ "tLeft"・"tRight"(T字路)/ "highway"(高速道路の 本線 2車線 + 左に 加速車線)/ "rail"(踏切が ある 道)/ "curve"(右カーブ)/ "parking"(駐車場の 出入口が ある 道)
- items の t(部品): me(自分の 車)/ car(車)/ truck(トラック)/ bus(バス)/ bike(二輪車)/ bicycle(自転車)/ person(人)/ child(子ども)/ elder(高齢者)/ ball(ボール)/ crosswalk(横断歩道の しま。x,y,w,h)/ stop(バス停の 札)/ signal(信号。"c":"red"|"yellow"|"green")/ wall(へい・建物の 角。x,y,w,h。死角を つくる)/ tree(木)/ cone(工事の コーン)
- 部品の オプション: dir("up"|"down"|"left"|"right" = 向き)/ stop(true = 止まっている)/ hidden(true = かげに いて 見えにくい = うすく 描く)/ blink("left"|"right" = 方向指示器)/ light(true = ライトを つけている)/ moving(true = 動いている 矢印)
- 夜は "night":true、雨は "rain":true を scene に
- why: 90字 以内。text: 70字 以内。opts.s: 60字 以内
