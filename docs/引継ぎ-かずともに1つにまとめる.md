## 作るもの

1. **kazutomo.app の ホーム**(`sanctuary-chiba/speed-king`)
   - 10の ゲームの カード(絵・名前・ひとこと・リンク)。かずとも も 1枚の カードとして ならべる
   - 料金(`src/lib/price.ts` から 読む)と「1か月 無料で はじめる」ボタン(いまの アカウント登録・お支払いの しくみを そのまま 使う)

2. **各 ゲームの ページ**(`flick-travel-game/flick-travel`)
   - 名前を 新しい 名前に(`tools/build_games.py` の `GAMES` の `name`・`<title>`・ホーム画面に 追加した ときの 名前 = manifest)
   - 料金・申し込みの 案内は **kazutomo.app の ホームへ つなぐ だけ**に する(ばらばらの 案内を なくす)
   - `about.html`(シリーズの 案内)は ホームに 役目を ゆずる か、名前を 直す(けいくんに 聞く)
3. **規約**(speed-king): `src/lib/flick-url.ts` の `FLICK_SERIES_NAME` / `FLICK_SERIES_GAMES` を 新しい 名前に。
   **お金・規約の 変更なので PR を 作って けいくんの OK を もらってから** 取りこむ
4. **ランキングの 旅の しるし**(`FLICK_MODES`)は 変えない(名前が 変わっても しるしは 同じ)

## トップの絵を 作りなおす(けいくん「トップの絵は作り直す」)

名前が 変わる **9つ**(フリック世界旅行・歴史フリック・宇宙フリック・からだフリック・株式フリック・フリックAI・理科フリック・フリック英会話・フリック整備士)。かずともは そのまま。
1つの ゲームに **2枚**: 横長 1536×1024(トップ)と 正方形 1254×1254(アイコン)。
けいくんに ChatGPT で 作ってもらう。**いまの 絵を 見せて「題名の 字だけ 変えて」と 頼むと 絵の 感じが そろう**。頼む文の 例:

```
この絵と まったく同じ 絵で、題名の 字だけを「歴史フリック」に 変えてください。
字の 色・形(虹色の ぷっくりした 字・白い ふち)・大きさ・場所・ほかの 絵は いっさい 変えないでください。
(フリック世界旅行 以外は)「旅行」の 字は 消してください。
```

- 届いたら 題名を 切りぬく(`tools/logo-sticker-cut.py`。やりかたは flick-travel-game の CLAUDE.md と `tools/build_games.py` の `art`)。
  **絵の 中の 字は かならず 切り出して 読んで 確かめる**(ChatGPT は 字を まちがえる)
- 名前の 数字を 上げて 入れる(`hero2.webp` など)。同じ 名前で 上書き しない(古い 絵が 残る)
