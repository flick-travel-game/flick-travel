- ⭐ 心: 起業 = **「だれかの 困りごと」を 見つけて、新しい しくみで 解決する こと**。お金もうけの ゲームに しない。失敗は はずかしく ない(ピボット・失敗から 学ぶ を 前向きに)
- 旅は 10こ(起業のきほん `kihon`・アイデアと困りごと探し `idea`・ビジネスモデル `model`・市場と競合 `shijo`・売る・広める `hanbai`・お金のきほん `okane`・お金を集める `chotatsu`・会社のつくりかたと法律 `hojin`・チームとリーダー `team`・大きくする・続ける `seicho`)+ マスター。
  **旅ごとに 70語(入門20・中級25・上級25)= 700語**。かずともの 旅の 名前は **`kg` で はじめる**(kgkihon / kgidea / kgmodel / kgshijo / kghanbai / kgokane / kgchotatsu / kghojin / kgteam / kgseicho / kgmas。作る 前に build_games.py と speed-king の flick.ts で 空いている ことを 確かめた)
