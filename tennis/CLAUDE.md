## フリックワールドテニス(`tennis/`。けいくん 2026-10-24 まとめ `docs/フリックワールドテニス-はじめかた.md` の とおりに → 名前・9つの旅・段・入れないもの は おすすめ / シナー・シフィオンテク・ズベレフは「名前・国・プレーの特徴だけで入れる」)

- 名前は「フリックワールドテニス」(フォルダ `tennis`・modes `TENNIS`)。シリーズの 絵文字は 🎾。`SERIES_CHAPTERS` の スポーツの 章、バレーボールの となり。
  かずともの 旅の 名前は **`tn` で はじめる**(tnkihon / tnrule / tntour / tnslam / tnstar / tnlegend / tnwaza / tntactic / tncup / tnmas)
- 旅は 9つ(テニスのきほん `kihon`・ルール `rule`・ツアーと大会 `tour`・4大大会と歴史 `slam`・いまのスター選手 `star`・伝説の選手 `legend`・技とテクニック `waza`・戦術と解説のことば `tactic`・国別対抗とオリンピック `cup`)+ マスター。**旅ごとに 70語(入門20・中級25・上級25)= 630語**
- ⭐ **2つの 札**: 国旗(`country` → `co`)と **コートの 面の 札**(`ruleset` → `rs`: `ハード` / `クレー` / `グラス` / `共通`。「・」で 3つまで)。ルールの 語は ほとんど 共通。大会・選手の 得意な 面・技(ムーンボール・サーブ&ボレー)に 付く
- ことばは `tools/tennis/terms-<旅>.json`(決まりは `tools/tennis/PROMPT.md`。いちばん下の「けいくんと 決めた こと」が 勝つ)→ `tools/tennis/terms_js.py` → `tennis/terms.js` + `data/tennis.json`。しくみは `tennis/tennis.js`(バレーボールを 写した)。図は `tools/tennis/mkmeta.py`(9つ)
- 事実は `tools/tennis/exam.txt`(2026年10月24日に 確かめた)。ルールは **ITF「2026 Rules of Tennis」**+ ATP・WTA・4大大会の 発表。⚠️ JTA の ルールブックの 年度版は 確かめられなかったので 書いていない
  ・4大大会の 最終セットは 2022年から 6-6 で 10点タイブレーク / コートの 外からの コーチングは 大会が 認めれば よい(2025年〜)/ ATP は 2025年から 電子の ライン判定・ウィンブルドンも 2025年から・全仏は 2026年も 線審 / Next Gen は **20さい 以下**(2024年から)
- ⚠️⚠️ **数字が 変わる ものを 書かない**: いまの ランキング・賞金・年齢・%・**いまの 選手の 4大大会の 回数**・いまの コーチ(台本 `BAN` / `STAR_BAN`)。いまの スターは 国・利き手・バックハンド・プレーの 特徴・**年つきの 実績 1〜2つ**だけ
- ⚠️⚠️ **入れない 人**(「迷ったら 入れない」。よかれと 思って もどさない): ベッカー・セレシュ・シャラポワ・ハレプ(台本が 名前ごと 止める)/
  確かめ役が 外した: ボンドロウソバ(2026年6月 4年の 資格停止)・ルブレフ・オスタペンコ・ブブリク・シャポバロフ・コスチュク(star)/ ヒンギス・コート・サンチェス・ビカリオ・チルデン・ビランデル・カフェルニコフ(legend)/
  書いた 助手が 外した: ムペシペリカール・クビトバ・カサトキナ
  ・⭐ **シナー・シフィオンテク・ズベレフは star に 入れた**(けいくん決定)。名前・国・プレーの 特徴・年つきの 実績だけ。⑩の 話は 1文字も 書かない
  ・メドベージェフ・サバレンカ・アンドレエワは 中立 → `country` なし・国の 話を しない
  ・**錦織圭は legend**(2026年10月1日が 最後の 試合)。**ジョコビッチ・ビーナスは star**(現役)。⚠️ **セリーナも star**(2026年 ウィンブルドンに 出て 復帰。確かめ役が web で 確かめた)
