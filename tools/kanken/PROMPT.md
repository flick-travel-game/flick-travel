# フリック漢字: ことばの 作りかた(助手に 分けて 頼むときの 決まり)

ゲームは「表示された ひらがなを フリックで 打ち写す」タイピング + **指で 漢字を 書く 書き取り**。打ち終わる(書き終わる)と ことばの 説明(1〜3文)が 出る。
遊ぶのは 中学生〜高校生・大人。**常用漢字(高校卒業 程度)から、常用漢字の 外の むずかしい 漢字(約6000字の いちばん むずかしい めやす)まで**を おぼえる ゲーム。
(けいくん 2026-10-16: 名前「フリック漢字」/ 書き取りは はじめから 機械が 自動で ◯× / 1級レベルまで / 国語の すぐ あと)

## ⚠️⚠️ いちばん 大事
- **「漢検」「漢字検定」の 字を 書かない**(どの 欄にも。協会の 登録商標)。「2級」「準1級」「1級」の 字も 書かない(むずかしさは difficulty で 言う)
- **自分の ことばで 書く**。検定の 過去問・問題集・参考書・辞典・Wikipedia の 文を 写さない。例文(sentence)も ぜんぶ 自分で 作る
- 例文は **やさしい 場面**(学校・家・スポーツ・自然・仕事・旅)。こわい・悲しい 場面(事件・事故・病気・死)、人を けなす 文、実在の 人・会社・商品の 名前は 入れない
- 事実(読み・部首・送りがな・意味・熟語の 型)は **まちがいない ときだけ**。辞書で ゆれる もの(部首が 辞書で ちがう 字・読みが 2つ 認められる 語)は **入れない**
- 字は **JIS の 字(ふつうの パソコンで 出る 字)だけ**。異体字・旧字の 書き分けを 問わない

## むずかしさ(difficulty。どの 旅も 3段・同じ 数ずつ)
- 1 = **常用**: 常用漢字表(2010年・2136字)の 字と 読みだけ。高校卒業 程度で まちがえやすい もの
- 2 = **表外**: 常用漢字の 外の 字や 読みを ふくむ 約3000字(JIS第一水準)の めやす。例: 嘗める・燕・叩く・蔑む・揃う・柘榴・国字(凩・凪・辻 など)
- 3 = **最難関**: 約6000字(JIS第二水準も ふくむ)の いちばん むずかしい めやす。例: 齟齬・鬱蒼・逡巡・躊躇・蹂躙・饒舌・顰蹙・魑魅魍魎 など
- 同じ difficulty の 中は よく 見る 順

## 1語の 形(JSON。ぜんぶの 旅で 共通の 欄)
{"id":"yo-hanrei","name":"凡例","reading":"はんれい","journey":"yomi","category":"まちがえやすい音読み","difficulty":1,
 "type":"concept","emoji":"📘","relatedTerms":["yo-sousai"],"description":"本の はじめに ある、使いかたや 記号の 決まりを まとめた ところです。「ぼんれい」と 読むのは まちがいです。"}

- id: 旅の 頭 + "-" + 英小文字・数字・-(下の 表)。ぜんぶで かぶらない
- name: 画面に 出す 字。**ふりがな・かっこの 読みを 付けない**
- reading: 打つ ひらがな。**ひらがなと ー だけ**。ゆれる 読みは 入れない(1つに 決まる 語だけ)
- type: いつも "concept"
- category: 図鑑で しぼる 分類(短い 日本語。旅の 中で 3〜8種類)
- emoji: 1つ
- relatedTerms: **同じ ファイルの 中の** id を 1〜3個(自分は ダメ)
- description: 1〜3文・**130字以内**。やさしい です・ます。語と 語の あいだに 半角スペース(上の 例の 書きかた)。
  **漢字の 目線**で 書く(成り立ち・部首・使いわけ・まちがえやすい ところ)。
  ⚠️ **説明の 中に 答え(reading の ひらがな)を 書かない**。まちがい読みの 注意は「〜と 読むのは まちがいです」の 形で よい
- kanji: **その 問題の 主役の 1字**(書き取り・同音・送りがな・部首では かならず。ほかは あれば)

## 旅と 数と 旅ごとの 欄
| 旅(journey) | id の 頭 | 語数(1/2/3) | 中身 |
|---|---|---|---|
| yomi 読み | yo- | 90(30/30/30) | 熟語の 読み(音読み・訓読み・熟字訓・当て字)と 国字(1字)。name は 漢字。**3 は ゲームで 読みを かくす**ので 1つに 決まる 語だけ |
| kaki 書き取り | ka- | 90(30/30/30) | 下の「書き取り」 |
| bushu 部首 | bs- | 90(30/30/30) | name = 漢字 1字、reading = **部首の 名前**(さんずい・くさかんむり・れっか …)、**bushu = 部首の 字**(氵・艹・灬 …)、kanji = name |
| okuri 送りがな | ok- | 90(30/30/30) | 下の「送りがな」 |
| jukugo 熟語の 組み立て | jk- | 90(30/30/30) | 下の「熟語の 組み立て」 |
| yoji 四字熟語 | yj- | 90(30/30/30) | name = 四字熟語、reading = その 読み。説明に 意味と(はっきり している ときだけ)出典 |
| taigi 対義語・類義語 | tg- | 90(30/30/30) | 下の「対義語・類義語」 |

### 書き取り(kaki)… 指で 書く 旅
{"id":"ka-idomu","name":"挑む","reading":"いどむ","kanji":"挑","sentence":"強い 相手に【イド】む","journey":"kaki", …}
- **kanji = 書く 1字**(1字だけ)。name = 正しい 書きかた(送りがな ふくむ)。reading = name の 読み
- **sentence = 例文。書く ところだけを【 】で かこんだ カタカナ**(kanji の その 語での 読みだけ。送りがなは【 】の 外に ひらがなで)。
  熟語の ときは 書かない ほうの 字を 漢字で 出す: 「【ゲン】格な ルール」(kanji = 厳 / name = 厳格)
- sentence は 30字以内。語と 語の あいだに 半角スペース
- 1 は 常用漢字、2 は 約3000字の 字(常用の 外)、3 は 約6000字の 字(JIS第二水準も)
- ⚠️ 同じ kanji を 2回 使わない(旅の 中で)
- 説明は その 字の 形の 注意(部首・まちがえやすい 形・似た 字との ちがい)と 語の 意味

### 送りがな(okuri)
{"id":"ok-kokoroyoi","name":"快い","reading":"い","kanji":"快","sentence":"【ココロヨイ】風が ふく","journey":"okuri", …}
- 画面には sentence と「快＿」が 出て、**送りがなの ひらがな だけ**(reading)を 打つ
- name = 正しい 書きかた / kanji = 語の あたまの 漢字 1字(name の 1字め)/ **reading = name から 漢字を 取った のこりの ひらがな**
- sentence の【 】は 語ぜんぶを カタカナで
- 決まりは **内閣告示「送り仮名の付け方」の 本則と 例外**(許容は 正解に しない)。漢字は 1字の 語(快い・承る・著しい・紛らわしい など)
- 3段とも 常用漢字で よい(むずかしさ = 送りがなの まちがえやすさ。3 は ゲームで 答えを かくす)

### 熟語の 組み立て(jukugo)
{"id":"jk-shinkyu","name":"新旧","reading":"はんたい","mapNode":"kumitate:hantai","journey":"jukugo", …}
- name = 2字の 熟語。**reading = 型の 名前(この 5つだけ)**:
  はんたい(反対・対の 意味の 字を 重ねた: 新旧)/ にたいみ(似た 意味の 字を 重ねた: 岩石)/ しゅうしょく(上の 字が 下の 字を 修飾: 洋画)/ もくてき(下の 字が 上の 字の 目的語・補語: 着席)/ うちけし(上の 字が 下の 字の 意味を 打ち消す: 非常)
- **mapNode = kumitate:hantai / kumitate:nita / kumitate:shushoku / kumitate:mokuteki / kumitate:uchikeshi**(reading と 合わせる)
- 5つの 型を だいたい 同じ 数ずつ。**型が 説によって ゆれる 語は 入れない**
- 説明に その 熟語の 読み・意味・なぜ その 型か(「着 = つく、席 = に」)。ここは 説明に 熟語の 読みを 書いて よい(答えは 型の 名前)

### 対義語・類義語(taigi)
{"id":"tg-hikan","name":"悲観","reading":"ひかん","pair":"楽観","rel":"対","journey":"taigi", …}
- 画面には「楽観 ⇔ ？」(rel = "対")か「寄与 ≒ ？」(rel = "類")が 出て、**答えの 熟語(name)の 読み**を 打つ
- pair = 問題に 出す 熟語 / name = 答えの 熟語 / rel = "対" か "類"。対と 類を だいたい 半分ずつ
- 答えが 1つに 決まる 組だけ(ほかにも 答えが ある 組は 入れない)

### 同音・同訓・誤字(doon)… 指で 書く 旅
{"id":"dn-hosho","name":"保障","reading":"ほしょう","kanji":"障","kind":"doon","sentence":"安全を 保【ショウ】する","journey":"doon", …}
{"id":"dn-hayai","name":"速い","reading":"はやい","kanji":"速","kind":"dokun","sentence":"足の【ハヤ】い 選手","journey":"doon", …}
{"id":"dn-shoukai","name":"紹介","reading":"しょうかい","kanji":"紹","kind":"goji","wrong":"招","sentence":"友だちを【招】介する","journey":"doon", …}
- kind = "doon"(同音異字)/ "dokun"(同訓異字)/ "goji"(誤字訂正)。3つを だいたい 同じ 数ずつ
- doon・dokun: sentence の【 】は 書く 字の 読みの カタカナ(書きかたは kaki と 同じ)
- **goji: sentence の【 】の 中は まちがった 漢字 1字**(wrong と 同じ)。正しい 字(kanji)を 書く
- 説明に **使いわけ**(保障 = 守る / 保証 = うけあう / 補償 = うめあわせる)
- ⚠️ 同じ kanji を 2回 使わない(旅の 中で)

## 旅ごとに 入れる / 入れない
- yomi と yoji と taigi の **reading は かぶらない**(3つの 旅を あわせて。変換台本が 止める)。ほかの 旅は かぶって よい(部首名・型の 名前・送りがなは かぶるのが ふつう)
- 四字熟語は yoji だけ。故事成語(矛盾・推敲 など 2字の もの)は yomi に 入れて よい
- 国語(フリック国語)と 同じ 語が 出ても よい(復習に なる)。説明は 漢字の 目線で 書きなおす

## 出すもの
`tools/kanken/terms-<journey>.json` に JSON の 配列で 書く。書いたら
`python3 tools/kanken/terms_js.py --only <journey>` で 確かめる(まちがいが あれば 止まる)
