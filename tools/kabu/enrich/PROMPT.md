# 株式フリック旅行: 会社の「読み・説明・業種・知名度」を 付ける 決まり

入力: `tools/kabu/enrich/in/<name>.jsonl`(1行 = 1社。id と よりどころ)
出力: `tools/kabu/enrich/out/<name>.jsonl`(入力と 同じ順・同じ数。1行 = 1社の JSON)

```json
{"id":"nvidia","name":"NVIDIA","reading":"えぬびでぃあ","nameJa":"エヌビディア","sector":"semi","industry":"半導体(GPU)","description":"AI向けGPUで 世界的に知られる 半導体の会社。","fame":5,"emoji":"💾"}
```

## 各項目
- **id**: 入力の id を そのまま
- **name**(画面に出す 会社名。20字まで)
  - 日本の会社: 日本で ふつうに使う 社名。`oldName` が あれば それを使う。なければ `srcName`(JPX の銘柄名)。「株式会社」は 付けない
  - 欧米などの 英字の会社: **英語の 通称**(ブランド名)。例 `Apple` `Microsoft` `NVIDIA` `Alphabet(Google)` `Meta` `Coca-Cola` `McDonald's` `Novo Nordisk` `ASML` `LVMH`。「Inc.」「Corporation」「Common Stock」などは 付けない
  - 中国・台湾・香港・韓国の会社: 日本の ニュースで ふつうに使う 表記(例 `TSMC` `テンセント` `アリババ` `中国工商銀行` `サムスン電子` `鴻海精密工業` `BYD` `貴州茅台酒`)
- **reading**(打つ よみ): **ひらがな と ー だけ**(`^[ぁ-ゖー]+$`)。name を 日本で 一般的に 読む 読みかた。
  英字は 日本での ふつうの 読み(`NVIDIA`→えぬびでぃあ、`Apple`→あっぷる、`TSMC`→てぃーえすえむしー、`LVMH`→えるゔぃえむえいち でなく えるぶいえむえいち、`3M`→すりーえむ)。
  記号・スペース・「(Google)」の かっこ内は 読まない(`Alphabet(Google)`→あるふぁべっと)。日本の会社は `edinetYomi`(小さい字が 大きく 書かれているので 直す。先頭の カブシキガイシヤ は 外す)や `jawiki` の 読みを 手がかりに。
  **長くても 24字まで**(子どもが フリックで 打つため)
- **nameJa**: カタカナ・日本語の 呼び名(日本の会社は name と 同じ)。例 NVIDIA → エヌビディア
- **sector**: 下の 14の どれか 1つ(id で)
- **industry**: 日本語で 短く(12字まで)。例「半導体(GPU)」「検索・広告」「スマホ・パソコン」「銀行」「ゲーム」「自動車」
- **description**: **子どもから 大人まで わかる 1〜2行(20〜50字)**。「何を している 会社か」。
  - よりどころ(`about` `jawiki` `jpx業種` `nasdaqIndustry` `categories` `oldDescription`)に 書いてあること・確かに知っていることだけ。**数字・順位・歴史は 確かなときだけ**。あいまいなら 業種だけから 書く(例「ドイツの 大きな 保険の 会社。」)
  - よりどころの 文を **写さない**(英語を そのまま 訳しただけ も ×)。自分の ことばで 短く
  - 「投資」「買い」「もうかる」「おすすめ」は 書かない。会社を ほめすぎない・けなさない
  - 文の おわりは「。」
- **fame**: **日本に すむ人から 見た 知名度** 1〜5
  - 5 = 日本の 小学生でも 知っている(Apple, Google, Amazon, トヨタ, 任天堂, ソニー, マクドナルド, コカ・コーラ, ディズニー, ユニクロ, サンリオ, セブン-イレブン)
  - 4 = 日本の 大人の 多くが 知っている(Samsung, Nestlé, Visa, Starbucks, 三菱UFJ, JR東日本, キリン, NVIDIA, Tesla, Netflix, Nike)
  - 3 = ニュースや 投資で よく 目にする(TSMC, ASML, Broadcom, Salesforce, Novo Nordisk, Berkshire Hathaway, キーエンス, 東京エレクトロン, ファナック)
  - 2 = その国・その業界では 有名(ヨーロッパの 電力会社・インドの 大手銀行・日本の 地方銀行や 中堅の 有名企業)
  - 1 = 日本では ほとんど 知られていない
- **emoji**: その会社の 仕事を 表す 絵文字 1つ(国旗・会社の ロゴは ×)
