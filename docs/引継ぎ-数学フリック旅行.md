## 数学だけの しくみ(整備士と ちがう ところ)

- **記号の 打ちかた**: 打つのは ひらがなだけ なので、記号は 読みで 出す。
  π → ぱい / √ → るーと / sin → さいん / cos → こさいん / tan → たんじぇんと / log → ろぐ / Σ → しぐま / ∫ → いんてぐらる
  ⚠️ **読みの ゆれは 1つに 決めて `PROMPT.md` に 書く**。別の 読みは `acceptedReadings`
- **公式を 打つ 問題**(決めてもらうこと 3): 名前を 出して、公式を **読みあげの 形で 打つ**。
  例: 円の面積 → 「はんけい かける はんけい かける えんしゅうりつ」/ 三平方の定理 → 「えーのにじょう たす びーのにじょう いこーる しーのにじょう」
  ⚠️ 長く なるので **1レベルに 数問まで**、上級だけ。読みあげの 言いかたを 決めてから 作る(「たす」か「ぷらす」か など)
- **図**(決めてもらうこと 4): **コードで 描く**(SVG。シリーズの 決まり「図は AI の 絵に しない」)。
  図形(三角形・円・放物線・ベクトル・箱ひげ図)を 描いて、打った 用語の ところに 📍や 色を つける。からだの `SVG_MAPS` の しくみを 手本に
  ⚠️ 図の 数字・角度は **正しく 描く**(ちがう 図は 数学では いちばん まずい)
- **数式の 見せかた**: 説明の 中の x² や √ は 画面で 読めるか 確かめる(ふりがなの 台本が 数式を こわさないように。数字は ふりがなを 付けない しくみが もう ある)
