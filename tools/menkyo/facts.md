## A. 試験

### A-1. 学科試験の 形(普通免許・普通仮免許)
| 事実 | 出どころ |
|---|---|
| 普通免許(本免)は **文章問題 90問 + イラスト問題 5問**。仮運転免許は **文章問題 50問・イラスト問題なし** | 警察庁丁運発第46号(令和5年3月30日)「学科試験の出題形式、出題範囲及び出題基準等について(通達)」 https://www.npa.go.jp/laws/notification/koutuu/menkyo/menkyo20230330_46.pdf |
| 解答は 文章問題 = **正誤式**、イラスト問題 = **三肢の正誤式** | 同上 |
| 配点: 文章問題 **1問1点**、イラスト問題 **1問2点**。イラスト問題は **三肢の解答が すべて正しい場合のみ 配点** | 同上 |
| 合計: 本免 **100点** / 仮免 **50点**。制限時間: 本免 **50分** / 仮免 **30分**。合格基準 **90%**(= 本免 90点以上・仮免 45点以上) | 同上(別添の表) |
| 大阪府警: 普通免許の学科は「95問の択一式又は正誤式で行います(50分)」「90パーセント以上」 | https://www.police.pref.osaka.lg.jp/tetsuduki/untenmenkyo/juken/choku/3709.html |
| この通達は 有効期間 令和10年3月31日まで。令和8年2月4日の 警察庁丁運発第23号(再試験)も「第46号の基準に準じて」と 書いており、**2026年に 出題形式が 変わった 通達は 見つからなかった** | https://www.npa.go.jp/laws/notification/menkyo20260204_23.pdf(検索の 抜き書きで 確かめた。本文は 開いていない) |
| 小型特殊・原付は 文章46問 + イラスト2問(参考) | 第46号通達 |

⚠️ 「95問」(大阪府警)と「90問 + 5問」(警察庁)は **同じこと**(食いちがいではない)。

| 事実 | 出どころ |
|---|---|

### C-13. 酒気帯び
| 事実 | 出どころ |
|---|---|
| 「何人も、**酒気を帯びて** 車両等を運転してはならない」(量の 下限は 書かれていない) | 法65条1項 |
| 罰則の 対象になる 程度: **血液1mLにつき0.3mg 又は 呼気1Lにつき0.15mg**(以上)。罰は 3年以下の拘禁刑 又は 50万円以下の罰金 | 令44条の3・法117条の2の2第1項3号 |
| 教則: 「酒を飲んだのが前夜であつても、翌朝の運転時まで酒の影響が…」の 注意がある | 交通の教則(下の C-14 の PDF) |

**⚠️ ゲームに 書いてよいか(判断)**: 0.15mg/L は **罰則の線**であって「ここまでなら 飲んでよい」の線では ない。法65条1項は **少しでも 酒気を帯びたら 禁止**。
ゲームでは **「少しでも飲んだら運転しない」を 正解**にし、0.15 を 出すなら「罰則の 基準の 数」として だけ。**0.15 未満なら 運転してよい、と 読める 問題は 作らない**。
子どもも 遊ぶ ゲームなので、**数字は 出さない ほうが 安全**(おすすめ)。
