## C-1. 健康保険法

### 保険者・適用事業所
| 事実 | 出どころ |
|---|---|
| 健康保険(日雇特例被保険者の 保険を 除く)の **保険者は 全国健康保険協会(協会けんぽ)と 健康保険組合** | 健保4 |
| 協会は 健康保険組合の 組合員で ない 被保険者の 保険を 管掌。協会けんぽの **資格の 取得・喪失の 確認、標準報酬月額・標準賞与額の 決定、保険料の 徴収(任意継続を 除く)は 厚生労働大臣**(実務は 日本年金機構) | 健保5①② |
| 健康保険組合は その 組合員で ある 被保険者の 保険を 管掌 | 健保6 |
| 健康保険組合の 設立: **単独 = 常時 700人以上**、**共同(総合) = 合算して 常時 3,000人以上** の 被保険者 | 健保11、健保令1条の3 |
| **強制適用事業所**: ① 法定の 事業(製造・建設・鉱業・電気・運送・販売・金融・保管・媒介・広告・教育・医療・通信・社会福祉・士業 など)で **常時 5人以上** の 従業員を 使う 事業所 ② **国・地方公共団体・法人**の 事業所で **常時 従業員を 使う** もの(1人でも) | 健保3③ |
| **任意適用**: 適用事業所 以外の 事業主は **厚生労働大臣の 認可**。被保険者と なるべき 者の **2分の1以上の 同意** で 申請 | 健保31 |
| 任意適用の **取消し**: 大臣の 認可。被保険者の **4分の3以上の 同意** | 健保33 |

### 被保険者と 適用除外
| 事実 | 出どころ |
|---|---|
| 被保険者 = 適用事業所に 使用される 者 と 任意継続被保険者。⚠️ 健康保険には 厚生年金の ような **年齢の 上限(70歳)は ない**(75歳で 後期高齢者医療に 移るので 適用除外) | 健保3①・①七 |
| **適用除外**(日雇特例被保険者と なる 場合を 除く): 船員保険の 被保険者 / 臨時に 使用される 者(**日々雇い入れ**で 1か月を 超えない、**2か月以内の 期間を 定めて** 使われ それを 超える 見込みが ない)/ 所在地が 一定しない 事業所 / **季節的業務(4か月 以内)** / **臨時的事業(6か月 以内)** / 国民健康保険組合の 事業所 / **後期高齢者医療の 被保険者等** / 大臣等の 承認を 受けた 者 / 短時間労働者の 一部 | 健保3①一〜九 |
| **短時間労働者**: 1週の 所定労働時間 または 1月の 所定労働日数が 通常の 労働者の **4分の3未満** で、かつ「**1週 20時間 未満**」か「**高校生・大学生 など**(省令で 定める 者)」なら 被保険者に ならない | 健保3①九(いまの 版) |
| ⚠️ 2026-04-10 の 版には 3つめの 要件「報酬 … **8万8千円 未満**」が あった。**2026-10-01 に 消えた**(令和7年法律第74号)。日本年金機構も「週の 所定労働時間が 20時間以上 かつ 学生 ではない 場合は 加入対象」(更新日 2026-10-01)。最低賃金の 減額特例を 受けて 8.8万円 未満の 人は「**特定減額特例対象者**」= 原則 加入しないが、申出で 任意加入できる(事業主の 同意 不要) | e-Gov の 2つの 版の くらべ、日本年金機構「短時間労働者に対する健康保険・厚生年金保険の適用の拡大」 https://www.nenkin.go.jp/service/kounen/tekiyo/jigyosho/tanjikan.html 、厚年附則4の6 |
| 短時間労働者が 加入に なるのは **特定適用事業所**(厚生年金の 被保険者が 1年のうち 6か月以上 **51人以上** と 見込まれる 企業等)・任意特定適用事業所・国 / 地方公共団体の 事業所。**令和9年(2027年)10月から 36人以上**(⚠️ 企業規模要件の 段階的な 廃止は C-2 の 表) | 日本年金機構 同ページ |
| 資格取得: 適用事業所に 使用されるに 至った 日 など **その日** から。資格喪失: 死亡・使用されなくなった・適用除外に なった ときの **翌日** から(その日に 再び 取得する ときは その日) | 健保35・36 |
| 資格の 得喪は **保険者等の 確認**で 効力を 生ずる(任意適用の 取消しに よる 喪失 と 任意継続の 得喪は 確認 不要) | 健保39① |
| 資格取得届は 事実が あった 日から **5日以内** | 健保則24① |

### 被扶養者
| 事実 | 出どころ |
|---|---|
| 被扶養者は **日本国内に 住所**(留学生・海外赴任に 同行 など 省令の 例外 あり)。**同居 不要** = 直系尊属・配偶者(事実婚を 含む)・子・孫・**兄弟姉妹** で 主として 被保険者に より 生計を 維持する もの | 健保3⑦一、健保則37条の2 |
| **同一世帯 が 要件** = ① 上の 者 以外の **3親等内の 親族** ② 事実婚の 配偶者の 父母・子(配偶者の 死亡後も 引き続き 同一世帯なら) | 健保3⑦二〜四 |
| 収入の めやす: **年間収入 130万円 未満(60歳以上 または 障害者は 180万円 未満)**、かつ 同居なら 被保険者の 収入の **半分 未満**、別居なら **仕送り額 未満**。給与なら **月額 108,333円 以下** | 日本年金機構「従業員が家族を被扶養者にするとき …」(更新日 2026-09-30) https://www.nenkin.go.jp/service/kounen/tekiyo/hihokensha1/20141202.html |
| ⚠️ **19歳以上 23歳未満**(被保険者の **配偶者を 除く**)は **150万円 未満**。扶養認定日が **令和7年(2025年)10月1日 以後** の もの から。年齢は 扶養認定日の 属する 年の **12月31日** の 年齢で 判定、学生かは 問わない | 厚労省 保保発0704第1号・年管発0704第1号(令和7年7月4日)https://www.mhlw.go.jp/hourei/doc/tsuchi/T250724S0010.pdf 、日本年金機構 同ページ |
| ⚠️ 課題の「19〜22歳」は 通知の ことばでは「**19歳以上23歳未満**」 | 同上 |

### 任意継続被保険者・特例退職被保険者
| 事実 | 出どころ |
|---|---|
| 任意継続: 資格喪失の 日の 前日まで **継続して 2か月以上** 被保険者(日雇特例・任意継続・共済組合員を 除く)だった 者が 保険者に 申し出る | 健保3④ |
| 申出は 資格を 喪失した 日から **20日以内**(正当な 理由が あれば 後でも 受理できる)。はじめの 保険料を 納付期日までに 払わないと **任意継続被保険者と ならなかった ものと みなす** | 健保37 |
| 資格喪失: **任意継続被保険者と なった 日から 2年**を 経過 / 死亡 / 保険料の 滞納 / 被保険者・船員保険・後期高齢者医療に なった / **本人が 希望して 申し出て 受理された 月の 末日**(翌日 喪失。被保険者・船員保険・後期高齢 は その日) | 健保38 |
| 任意継続被保険者の 保険料は **全額 自己負担**。納付期日は **その月の 10日**(はじめは 保険者が 指定する 日)。一般の 被保険者は **翌月末日** | 健保161①ただし書、164① |
| 任意継続被保険者には **傷病手当金・出産手当金は 出ない**(99条・102条の「被保険者」から 除く。継続給付は 別) | 健保99① |
| **特例退職被保険者**: 大臣の 認可を 受けた **特定健康保険組合** の 組合員だった 者で 規約で 定める もの が 申し出て なる。**傷病手当金は 支給しない**。任意継続被保険者と みなす | 健保附則3 |

### 標準報酬月額・標準賞与額
| 事実 | 出どころ |
|---|---|
| 健康保険の 標準報酬月額は **第1級 58,000円 〜 第50級 1,390,000円 の 50等級**(第50級は 報酬月額 1,355,000円 以上) | 健保40①の 表 |
| 3月31日に 最高等級の 被保険者が **1.5%** を 超え 続くと 認められるとき、**9月1日** から 政令で 上に 等級を 足せる(足した 後の 最高等級が 0.5% を 下回っては ならない) | 健保40② |
| **報酬** = 労働の 対償として 受ける すべて。**臨時に 受ける もの・3か月を 超える 期間ごとに 受ける もの は 除く**。**賞与** = 3か月を 超える 期間ごとに 受ける もの | 健保3⑤⑥ |
| **標準賞与額**: 賞与額の **1,000円 未満 切り捨て**。**年度(4月1日〜翌年3月31日)の 累計 573万円** が 上限 | 健保45① |
| **資格取得時決定**: 月給なら 取得日の 報酬 ÷ 日数 × 30 など。決めた 額は 取得月 から **その年の 8月**(**6月1日〜12月31日** に 取得なら **翌年 8月**)まで | 健保42 |
| **定時決定**: **7月1日** に 使用される 事業所で **同日前 3か月(4〜6月)** に 受けた 報酬の 平均(支払基礎日数 **17日 未満**の 月は 除く。短時間労働者 など は **11日**)。**9月 から 翌年 8月** まで 使う | 健保41①② |
| 6月1日〜7月1日に 資格を 取得した 者、7〜9月に 随時改定 等 される 者は その年の 定時決定を しない | 健保41③ |
| **算定基礎届**(報酬月額の 届出)は **7月10日 まで** | 健保則25① |
| **随時改定**: 継続した **3か月**(各月 **17日 以上**)の 報酬の 平均が 著しく 高低した とき、**その 翌月(= 4か月目)** から 改定。7〜12月から 改定なら 翌年 8月まで。⚠️「**2等級 以上**」の 差は 条文には なく 厚労省の 通知の 基準(通知は 読んでいない → 未確認) | 健保43 |
| **育児休業等 終了時改定**: 育休等を 終えて **3歳未満の 子**を 養育する 被保険者が **事業主を 経由して 申出**。終了日の 翌日が 属する 月 以後 3か月の 平均で、**2か月を 経過した 日の 属する 月の 翌月** から 改定 | 健保43の2 |
| **産前産後休業 終了時改定**: 産前産後休業(出産日 以前 **42日(多胎 98日)**〜出産日後 **56日**)を 終えて その 子を 養育する 被保険者の 申出で 同じ ように 改定 | 健保43の3 |
