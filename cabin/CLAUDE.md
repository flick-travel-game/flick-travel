## フリックキャビンアテンダント(`cabin/`。けいくん 2026-10-20「キャビンアテンダントに受かるレベルになるために必要な知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」・デッドヘッドは「入れる」・並びは「パイロットのすぐあと」。まとめは `docs/フリックキャビンアテンダント-はじめかた.md`)

- 名前は「フリックキャビンアテンダント」(フォルダ `cabin`・modes `CABIN`)。シリーズの 絵文字は 💺。`SERIES_ORDER` は **パイロットの すぐ あと**。
  かずともの 旅の 名前は **`cr` で はじめる**(crkihon / crhoan / crkyumei / crservice / crmanner / creigo / crsekai / crkuko / crshigoto / crmas。`ca`・`cb` は 使用中)。speed-king の `FLICK_MODES` / `FLICK_LINK_TARGETS` に 足した
- 旅は 9つ(採用試験と 入社後の 訓練(保安・救急・サービス・接遇・英語)に そろえた): 客室と飛行機のきほん `kihon`・安全を守る `hoan`・お客さまの体調 `kyumei`・機内のサービス `service`・おもてなしとマナー `manner`・空の英語 `eigo`・世界の都市と文化 `sekai`・空港とフライト `kuko`・しごととなりかた `shigoto` + 🏆 マスター
- ⭐ **2回に 分けて 出す**(パイロットと 同じ): **1回目 = 旅ごとに 70語(入門20・採用めやす25・訓練めやす25)= 630語**(2026-10-21)。
  **2回目の 40語ずつ(10・15・15)は もう 書いて 確かめてある** → `tools/cabin/later/terms-<旅>.json`。足すときは 各旅の `terms-<旅>.json` の うしろに つなぐだけで 990語。
  ⚠️ 足す 前に `python3 tools/cabin/terms_js.py --check --with-later`(990語の 読みの かぶり 0 を 確かめてある)。足したら ふりがなを 見る(`RB_FIX`)・写真と Wikipedia を 取りなおす
