## 2. はじめに けいくんに 聞く 5つ(「全部おすすめで」と 返ってくる ことが 多い)

### 2-1. ⭐⭐ いちばん 大事: **アクセント記号を どう 打つか**
スペイン語は 英語と 同じ **ローマ字**なので、英会話と 同じく 日本語キーボードの「ABC」で **そのまま 打ち写せる**(⭐ 韓国語の ような「読みの かな」は 要らない)。
こまるのは **á é í ó ú ñ ü と ¿ ¡**。iPhone の 英字キーボードでも **長押し**で 出せるが、子どもは 知らないし、打つのに 時間が かかって スピード勝負に ならない。3つの 案を 出す:

| 案 | 打つ もの | よい ところ | こまる ところ |
|---|---|---|---|
| **A(おすすめ)** | **記号なしで 打って よい**(niño → `nino` でも 正解。¿ ¡ は 打たない) | ふつうの ABC で 打てる。スピード勝負が こわれない | 記号を おぼえない かも → **画面には 記号つきで 大きく 見せる**・記号の ところだけ 色を 変える(英会話の `tgtHtml` と 同じ しくみ) |
| B | **記号も 正しく 打つ**(長押し) | ネイティブと 同じ 打ちかた | 小学生には むずかしい・時間が かかる |
| C | A が はじめ + 記号つきで 打った ときは **「✨ アクセントも ばっちり」**の ひとこと | 両方 よろこべる | 作る 量が 少し ふえる |

⭐ **おすすめは C**(どちらでも 正解。記号まで 打てたら ほめる)。まず **A** で 作って C は あとから でも よい(けいくんに 聞く)。
- `norm`(くらべる ための 形)は **記号を はずして くらべる**(á→a、ñ→n、ü→u、¿ ¡ と 句読点は 消す・大文字小文字を 区別しない)。⚠️ **ñ と n は 意味が 変わる 語が ある**(año(年)/ ano(おしり))。⚠️ **ano の ような 語が 正解に ならない ように**、記号なしで 打った 字が **別の 子どもに 不向きな 語と 同じに なる 語は 入れない**(`spanish_js.py` で 止める)
- 画面には **スペイン語(大きく・記号つき)+ 日本語訳(小さく)+ 🔊**。⭐ **カタカナの 読みは 出さない**(スペイン語は ローマ字の まま ほぼ 読める。英会話と 同じ)

### 2-2. **名前と どこの スペイン語か**
- 「フリックスペイン語」で よいか(フォルダ名 `supein` は 変えない。かずともの 旅の 名前は **`es`** で はじめる: eskihon / esw1 / esw2 / esw3 / esw4 / esgram / estalk / esnative / esmas。**作る 前に `build_games.py` と speed-king の `flick.ts` で `es` と `"supein"` が 空いているか 確かめる**。2026-10-16 には 空いていた(⚠️ **`sp` は フリックスマホ**(`spkihon` など)が 使って いる。`eg` は 英語、`ew` は 英会話))
- ⭐ **スペインの スペイン語 か、中南米(メキシコ など)の スペイン語 か**:
  - おすすめ = **どこでも 通じる ふつうの 形**を 基本に、**ちがう ところは 札で 見せる**(`region` の 欄: `ES`(スペイン)/ `LA`(中南米)/ 空 = どちらも)。⭐ 例: パソコン = ordenador(ES)/ computadora(LA)、車 = coche(ES)/ carro(LA)、「あなたたち」= vosotros(ES)/ ustedes(LA)。**へえ に なる**
  - 🔊 の 声は **`es-ES`** が はじめ(けいくんに 聞く。中南米に したい なら `es-MX`)
  - ⚠️ **vosotros**(スペインだけの「君たち」)は **文法の 旅で 1つの 項目と して**。ふだんの 例文は **ustedes** で そろえる(どこでも 通じる)

### 2-3. **旅の 分けかた**(おすすめ 8つ + 🏆 マスター。英会話の「単語 4段 + 日常会話」に、スペイン語に 要る **発音・文法(活用)・ネイティブ表現**を 足した)
- 🔤 **発音と つづりの きほん** `eskihon`(⭐ スペイン語だけの 旅: **ローマ字読みで ほぼ 読める**(へえ)・母音は a e i o u の 5つ(日本語と 同じ!)・**ñ**(ニャ行)・**ll / y**・**rr**(巻き舌)・**j / g**(のどの 音)・**h は 読まない**・**c / z**(スペインと 中南米で ちがう)・**アクセント記号の 決まり**・**¿ ¡**(⭐ 文の はじめにも 逆さの 記号)・**アルファベットの 名前** …。答えは **短い 語**)
- 🌱 **入門の 単語** `esw1`(数(uno dos tres …)・家族・色・食べもの・動物・からだ・曜日・月・**あいさつ**(hola / gracias / adiós)…)。⭐ **名詞には 性**(el / la)を **かならず いっしょに**(el libro / la mesa)
- 📘 **初級の 単語** `esw2`(毎日の 会話で よく 使う ことば。**動詞の 原形**(-ar / -er / -ir)・形容詞(男性形 / 女性形))
- 🧭 **中級の 単語** `esw3`(旅行・買い物・気持ちを 伝える ことば。⭐ **英語と にている ことば**(información / importante / animal)は「英語では ◯◯」と そえると へえ。⚠️ **にているのに 意味が ちがう ことば**(embarazada = 妊娠している(⚠️ 子どもむけに **入れない**)、éxito = 成功(exit では ない))は 上級で 1つか 2つ)
- 🏙 **上級の 単語** `esw4`(仕事・ニュース・SNS で 出会う ことば・**ことわざ**(refranes)・**慣用句**)
- 📐 **文法と 活用** `esgram`(⭐ ネイティブに 要る: **ser と estar**(どちらも「〜です」。⭐ いちばん の へえ)・**冠詞**(el / la / los / las / un / una)・**性と 数の 一致**・**動詞の 活用**(現在形の 6つの 形・**不規則動詞**(ser / ir / tener / hacer)・**過去**(点過去 / 線過去)・**未来**・**命令形**・**接続法**(上級))・**目的格代名詞**(lo / la / le)・**gustar**(⭐「〜が 好き」の 言いかたが 日本語・英語と 逆)・**tú と usted**(ため口 / ていねい)…。⚠️ **文で 出す**(英語(`eigo/`)の 文法の 旅と 同じ 形))
- 💬 **日常会話** `estalk`(英会話の 場面を 写す: あいさつ・自己紹介 / 気持ち・あいづち / 聞き返す・たのむ / **レストラン・バル**(⚠️ お酒の 場面に しない。タパス・食事)/ 買い物 / 道案内・地下鉄 / 空港・ホテル / 病院・困ったとき / 電話・約束 / 仕事。⭐ **スペイン語圏らしい 場面**: **ほおに キスの あいさつ**(dos besos。⚠️ 文化と して)・**シエスタ**・**夕ごはんが おそい**・**サッカーの 話**(⭐ けいくんの スクールと つながる。⚠️ 実在の クラブ・選手の 名前は 入れない。**「サッカー」「試合」「ゴール」の ことばまで**))
- 🌟 **ネイティブの 表現** `esnative`(⭐「ネイティブに なれる レベル」の 本体: **あいづち**(¡Claro! / ¡Vale!(ES)/ ¡Órale!(MX)/ ¡Qué bien!)・**よく 使う 言いまわし**(¡Qué padre!(MX)/ ¡Qué guay!(ES)= すごい!)・**縮めた 言いかた**(pa' = para など。上級)・**擬音語**・**呼びかけ**(amigo / tío(ES)/ cuate(MX)。⚠️ やさしい ものだけ)・**文化の ことば**(fiesta / siesta / tapas / mariachi / flamenco / Día de Muertos(⚠️「家族を 思い出す お祭り」と して))・`region` の 札で **国の ちがい**を 見せる)

⚠️ 英会話と 同じく **1回は かならず 10問・いつも 同じ 10問**(スピード記録勝負)。苦手克服・ふくしゅうは 作らない(けいくん 2026-09-27「苦手克服と復習は無しにして スピード記録勝負に揃えてください」)

### 2-4. **むずかしさの 4段**(英会話と 同じ `difficulty` 1〜4)
- 1 入門 = **発音が 読めて あいさつが できる**
- 2 初級 = **旅行で 困らない**(レストラン・買い物・道を 聞く)
- 3 中級 = **スペイン語圏の 友だちと ふつうに 話せる**(過去形・tú と usted の 使いわけ)
- 4 上級 = **ネイティブ**(接続法・ことわざ・国ごとの 言いまわし・文化の ことば)
- ⚠️ 画面に「DELE ◯級」「スペイン語検定」など **試験の ことばは 書かない**(英会話の「勉強っぽさは 出さない」と 同じ)。作る 側の めやすとして **DELE(A1〜C2)・スペイン語技能検定の 範囲**を 参考に するのは よい

### 2-5. **語数**
英会話は 単語 1000(200 / 280 / 280 / 240)+ 会話 300。韓国語は **半分(810問)で 出して あとで 1560問に ふやした**。スペイン語も **まず 半分で 出して ふやす**のを すすめる(けいくんに 聞く): 発音 40 + 単語 4段 × 100〜140 + 文法 100 + 会話 150 + ネイティブ 100 くらい

## 3. ⚠️⚠️⚠️ ぜったいの 決まり(英会話の PROMPT.md と 同じ + スペイン語だけの もの)
- **スペイン語は ネイティブが いま ふつうに 使う 形**。直訳・日本語の 語順を そのまま 置きかえた 文は ダメ。**アクセント記号は 例文・答えとも かならず 正しく**(画面に 出す 字は 記号つき)
- **名詞は 性を いっしょに**(el / la)。**形容詞の 性と 数を 名詞に 合わせる**(⚠️ 助手が いちばん まちがえる。2人目が 1語ずつ 見る)
- **市販の 単語帳・DELE の 過去問・教科書の 文を 写さない**。例文・訳は ぜんぶ 自分で 書く
- **tú と usted を まちがえない**: 例文ごとに **だれが だれに 言うか**を 書く。⚠️ **お店の人・年上・先生への 例文は usted**
- **国の ちがいを 決めつけない**: スペイン・メキシコ・アルゼンチン などの 言いかたは **「◯◯で よく 使う」**(どれが 正しい とは 書かない)。`region` の 札で 見せる
- 子どもが 見るので、**お酒(ワイン・サングリア・テキーラ)・たばこ・お金もうけ・こわい話・恋愛の 話**は 例文に 入れない(英会話と 同じ)。⚠️ **闘牛は 入れない**(動物が つらい 思いを する)。⚠️ Te quiero(愛してる)は **家族に 言う 場面**なら よい
- ⚠️⚠️ **記号を はずすと 別の 語に なる もので、子どもに 不向きな 語が できる ものは 入れない**(2-1。año → ano)。`spanish_js.py` に **止める 語の 一覧**(`BAN`)を 置く。**下品な 語・スラングの 悪口は 1語も 入れない**(スペイン語は 国に よって ふつうの 語が 別の 国では 下品に なる ことが ある(⚠️ coger など)。**迷ったら 入れない**)
- ⚠️ **政治・歴史の あらそいの 話は 入れない**(スペインの 内戦・独裁・植民地の 歴史の よしあし・移民の 問題)。**国や 人を 下げる 書きかたを しない**
- **実在の 芸能人・歌手・サッカー選手・クラブ・ドラマの 名前を 入れない**(⚠️ 子どもが 喜ぶが、商標・肖像の 心配が ある。**「サッカー」「歌」と いう ことばまで**)。店・会社・商品の 名前も 入れない
- ✅ **食べもの・地名・行事の 名前は よい**(パエリア・タコス・トルティーヤ・チュロス・マドリード・バルセロナ・メキシコシティ・ブエノスアイレス・フィエスタ)
- ✅ **ほかの ゲーム(英会話・英語・世界旅行・ワールドサッカー など)と 同じ 意味の 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。⭐ **英語と にている 語**は「英語では ◯◯」と 説明に そえると へえ
- **同じ スペイン語を 2回 入れない**(`spanish_js.py` が 止める。⚠️ 記号を はずして くらべる)
- 日本語は やさしく。小学生が 読める ていど(漢字は 使ってよい。あとで ふりがなを 付ける)。**日本語訳の 語の あいだに 半角スペースを 入れない**(英会話と 同じ)
- 画面に「これは ことばを おぼえる ゲームです」・🔊 は「端末の 読み上げ機能を 使うので、端末に よって 声が ちがいます」・**「アクセント記号は 打たなくても 正解に なります」**(2-1 で A か C に した とき)
- **作った 助手とは 別の 助手が 1語ずつ 確かめる**(意味・**性と 数の 一致**・**活用**・**tú / usted**・**アクセント記号**・自然な スペイン語か・子どもに よいか・**国に よって 下品に ならないか**)。⚠️ **ネイティブの 目で 見てくれる 人**が いれば いちばん よい(けいくんに 聞く)

## 4. 事実は **その日に 確かめてから** 書く
- **つづりと アクセントの 決まり** … **RAE**(スペイン王立アカデミー)の 辞書(DLE)と 決まり(⚠️ 2010年の 改正で 変わった つづりが ある。solo / sólo など)で 確かめる
- **国ごとの 言いかた** … RAE の 辞書の 地域の しるし で 確かめる
- **スペイン語を 話す 国の 数・人の 数** … ⚠️ **数字は 書かない**(変わる)。「世界の たくさんの 国で 話されている」まで
- ⚠️ 「ネイティブに なれる レベル」= **ネイティブが ふだん 使う ことば・文法・活用・言いまわしを ひととおり 知っている**こと、と けいくんに 伝える。**話す・聞く 力**は 🔊 と 実際の 会話で 身に つく もの。ゲームは その 土台(英会話・韓国語と 同じ 伝えかた)
