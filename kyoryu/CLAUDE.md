## フリック恐竜図鑑(`kyoryu/`。けいくん 2026-09-29「恐竜博士になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「すべておすすめで」)

- 決めたこと: 名前は 仮「フリック恐竜図鑑」(絵が 届いたら 題名に そろえる。フォルダ名 `kyoryu` は 変えない)/ **恐竜 120 + ことば 100 = 220** / **写真は あとから**(いまは 絵文字の カード)/ **見つかった 場所を 世界地図に 📍** / 打つのは ひらがな
- 旅は 7つ(肉を食べる恐竜 `dniku` 50・草を食べる恐竜 `dsou` 50・日本の恐竜 `djapan` 20・3つの時代 `djidai` 30・体と化石 `dkaseki` 30・恐竜ではない生きもの `dnotdino` 20・調べる人と道具 `dshirabe` 20)+ マスター `dmas`。むずかしさは 3段: 入門(だれでも 知っている)→ 中級(図鑑に のっている)→ 上級(恐竜博士)
- ことばは `tools/kyoryu/terms-<旅>.json`(決まりは `tools/kyoryu/PROMPT.md`)→ `tools/kyoryu/terms_js.py` → `kyoryu/terms.js`。しくみは `kyoryu/kyoryu.js`(美容師を 写した。4択クイズ あり)
- 1語ごとに `kind`(恐竜 / 恐竜では ない 生きもの / ことば)・`period`(ペルム紀〜新生代)・`diet`・`place` と `lat`/`lon` を 持つ。図鑑で **時代・食べもの**でも しぼれる
- 図は 2つ: **世界地図**(世界旅行の `world-map-color.jpg` に 📍。位置は `MAPS.world.pos` と 同じ 式)と **中生代の 年表**(コードで 描く。区切りの 年は ICS の だいたいの 数字)
- ⚠️⚠️ **古い 知識を 書かない**(羽毛・しっぽを ひきずらない・鳥は 恐竜の 仲間・ブロントサウルスの 復活・板や えりの 役目は 言いきらない)。
  **恐竜では ない 生きもの**(翼竜・首長竜・魚竜・モササウルス・ディメトロドン …)は `notdino` の 旅だけ・説明に「恐竜では ありません」(`terms_js.py` が 見る)
- ⚠️ **ほかの ゲームと 同じ 見出しは 入れない**(化石・地層・中生代・始祖鳥・生痕化石・学名・骨格 …)。一覧は `tools/kyoryu/other-words.txt`(`make_other_words.py`。ゲームが 増えたら 走らせなおす)
- 「ヴ」の 名前(ヴェロキラプトル・オヴィラプトル …)は `ゔ` の 読み + バ行の `acceptedReadings`(べろきらぷとる でも 通る)
- 作った 助手とは **別の 助手が 1語ずつ ネットで 確かめた**(41か所 直した: 場所・緯度経度・年代を ICS に・分類の 話しあい・大きさの まちがい など)。
  ふりがなの 読みまちがい 29か所を `tools/ruby_fix.json` に context 付きで 足した(角=つの・首長竜・堅頭竜・手取層群・北谷町・茂師・淡路島・単弓類・「2億140万」などの 億の 数)
- **写真(けいくん 2026-09-29「恐竜の写真をすべて入れてください」)**: 恐竜と 恐竜では ない 生きもの **131しゅるい ぜんぶ**に 写真(`photo-kyoryu-<id>.jpg`・`photos.js` の `PHOTOS[id]`)。
  骨の 標本(全身骨格・頭骨・化石)が ほとんど。骨の 写真が 無い もの(ノドサウルス・サルタサウルス・ドレッドノータス・エウオプロケファルス・ベイピャオサウルス・ノアサウルス・ヒプノヴェナトル・パラリテリジノサウルス・アルバロフォサウルス・ニッポノプテルス など)だけ 新しい 形の 復元図。ことば(kind:word)には 写真を 付けていない
  - 台本 `tools/kyoryu/fetch_photos.py`: `candidates`(Wikipedia の 代表画像 + Commons 検索で 1しゅるい 9枚まで → `photo-candidates.json` と 見くらべる 絵)→ 人・助手が 1枚ずつ 目で 見て `photo-picks.json` に きめる → `save`
  - ⚠️ **Wikimedia の 429**: commons の Special:FilePath と もとの 大きさの ファイルは すぐ 断られる。**決まった 幅(960 / 500 / 330)の 縮小版**(upload.wikimedia.org/…/thumb/…/960px-…)だけ 使う(`save` が そう している)
