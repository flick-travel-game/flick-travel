# 📝 ⭕❌ 一問一答の 作りかた(フリック日商簿記)

文を 読んで 正しければ ⭕・まちがいなら ❌。**1級の 会計学(理論)・2級の 会計の 考えかた**が 中心。3級は 勘定の きまり(資産は ふえたら 借方 など)。

## 1問の 形(JSON。`tools/boki/maru-<旅id>.json` に 配列で)
{"id":"a1-m001","q":"企業会計原則の 継続性の原則は、正当な 理由が あっても 会計処理の 方法を 変えては ならない という 決まりである。","a":false,
 "why":"正当な 理由が あれば 変えられます。むやみに 変えて 期間の くらべが できなく なるのを ふせぐ 決まりです。","src":"企業会計原則 一般原則","dv":2,"term":"a1-keizokusei","rs":"会計学"}
- id: 旅の id の 頭文字(ki- / s3- / k3- / s2- / c2- / g2- / s1- / a1- / g1-)+ "m" + 3けた
- q: 80字 くらい まで(長くても 120字)。**一つの 文で 一つの こと**
- a: true(⭕)/ false(❌)。⭕ は 40〜60%
- why: なぜ ⭕ / ❌ か。130字 以内。❌ の ときは **正しくは どうか**を 書く
- src: よりどころ(「企業会計原則 一般原則」「収益認識に関する会計基準」「原価計算基準」など。**番号は 書かない**)。3級・2級の 勘定の きまりは 書かなくて よい
- dv: 1 / 2 / 3(上級 3 が 半分 以上)
- term: 関係する ことばの id(同じ 旅の 中。無ければ 書かない)
- rs: 商業簿記 / 工業簿記 / 会計学 / 原価計算

## 決まり
- ⭐ ひっかけの 形: 「かならず」「すべて」「〜しなければ ならない」/ 借方 ⇄ 貸方 / 資産 ⇄ 費用 / 定額法 ⇄ 定率法 / 直接法 ⇄ 間接法 / 個別 ⇄ 総合 / 有利差異 ⇄ 不利差異 / 原則 ⇄ 例外
- 同じ ことの ⭕版と ❌版を 両方 入れない(どちらか 1つ)
- いまの 会計基準・出題区分表が 答え(facts.md)。会計基準の 番号は 書かない
- 過去問・問題集の 文を 写さない
