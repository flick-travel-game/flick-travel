## A-1. 労働基準法(社労士の 目線)

> ここから「確かめられなかった こと」の 手前まで の 小見出し「労働契約・解雇・賃金」〜「就業規則・寄宿舎・記録・災害補償・監督」は `tools/eisei/facts-B.md` の「B-1. 労働基準法」を **そのまま 写した もの**(2026-11-10 に e-Gov で 確かめた)。そのあとの「A-1 で 足した もの」が 2026-11-11 に 足した ぶん

### 労働契約・解雇・賃金
| 事実 | 出どころ |
|---|---|
| 使用者は 労働契約の 締結に 際し **賃金・労働時間 その他の 労働条件を 明示**。賃金・労働時間 など 省令で 定める 事項は 省令の 方法(= **書面の 交付**。本人が 希望すれば FAX・電子メール等 でも よい)で 明示 | 労基15①、労基則5③④ |
| 明示された 労働条件が 事実と ちがえば 労働者は **即時に 労働契約を 解除**できる。就業の ため 住居を 変えた 人が **14日以内に 帰郷**するなら 使用者が 旅費を 負担 | 労基15②③ |
| 書面で 明示する 事項(絶対的明示事項): 契約期間 / 有期契約の 更新の 基準(通算期間・更新回数の 上限を 含む)/ **就業の 場所・業務(変更の 範囲を 含む)**/ 始業・終業時刻、所定外労働の 有無、休憩、休日、休暇、交替制 / 賃金の 決定・計算・支払方法、締切・支払時期(昇給は 書面でなくて よい)/ 退職(解雇の 事由を 含む) | 労基則5①一〜四・③ |
| **平均賃金** = 算定事由の 発生した 日 以前 **3か月間**の 賃金総額 ÷ その 期間の 総日数。賃金締切日が あれば 直前の 締切日から。業務上の 休業・産前産後休業・使用者の 責めによる 休業・育児介護休業・試用期間は 日数も 賃金も 除く。臨時の 賃金・3か月を 超える 期間ごとの 賃金は 入れない | 労基12①〜④ |
| **解雇制限**: 業務上の 負傷・疾病で 休業する 期間 + **その後30日間**、産前産後休業(65条)の 期間 + **その後30日間**は 解雇できない。例外: 打切補償(81条)を 払う とき / 天災事変等で 事業の 継続が 不可能(**行政官庁の 認定**が いる) | 労基19 |
| **解雇予告**: **少なくとも30日前**に 予告。しないなら **30日分以上の 平均賃金**(解雇予告手当)。予告日数は 1日分の 平均賃金を 払った 日数だけ 短縮できる。例外: 天災事変等で 事業継続不可能 / 労働者の 責に 帰すべき 事由(どちらも 行政官庁の 認定) | 労基20①②③ |
| **賃金支払の 5原則**: ①通貨で ②直接 労働者に ③全額を ④**毎月1回以上** ⑤**一定の 期日を 定めて**。例外: 法令・労働協約に 定めが あれば 通貨以外 / 法令に 定め・労使協定が あれば 一部控除 / 臨時の 賃金・賞与は 毎月払いの 対象外 | 労基24①② |
| **非常時払**: 出産・疾病・災害 その他 非常の 場合の 費用の 請求が あれば、支払期日前でも **既往の 労働の 賃金**を 払う | 労基25 |
| **休業手当**: 使用者の 責に 帰すべき 事由の 休業は 平均賃金の **100分の60以上** | 労基26 |

### 労働時間・休憩・休日
| 事実 | 出どころ |
|---|---|
| 法定労働時間: 休憩時間を 除き **1週40時間**・**1日8時間** | 労基32①② |
| **特例 44時間**: 別表第一の **第8号(商業)・第10号(映画の 製作を 除く 映画・演劇)・第13号(保健衛生)・第14号(接客娯楽)**の 事業で **常時10人未満**の 事業場は **1週44時間・1日8時間**まで | 労基40①、労基則25の2① |
| **1か月単位の 変形労働時間制**: 労使協定 **または 就業規則**等で、1か月以内の 期間を 平均して 週40時間を 超えない 定めを したとき。協定は 行政官庁に 届出 | 労基32の2 |

### B-4. 産業医(法13条・令5条・則13〜15条)
| 事実 | 出どころ |

### B-8. 健康診断(法66条〜66条の7・則43〜52条)
| 事実 | 出どころ |
|---|---|
| **雇入時**(則43条): 常時 使用する 労働者を 雇い入れるとき。医師の 健診後 **3か月を 経過しない 者**が 結果の 書面を 出せば 相当する 項目を 省略できる。⚠️ 項目の 省略(年齢)は **できない** | 則43条 |
| **定期**(則44条): **1年以内ごとに1回**。項目(現行): 既往歴・業務歴 / 自覚・他覚症状 / 身長・体重・腹囲・視力・聴力 / 胸部エックス線・喀痰 / 血圧 / 貧血 / 肝機能 / 血中脂質 / 血糖 / 尿 / 心電図。**医師が 必要でないと 認めるとき 省略できる 項目**: 身長等(3号)・胸部X線等(4号)・貧血〜血糖(6〜9号)・心電図(11号)。⚠️ **血圧・尿・既往歴・自覚症状は 省略できない** | 則44条1〜2項 |
| 聴力は **45歳未満(35歳・40歳を 除く)**は 医師が 適当と 認める 方法(1,000Hz・4,000Hz 以外)で 代えられる | 則44条4項 |
| **省略の 基準(年齢。R8.4.28 厚労告示204号)**: 身長 = **20歳以上** / 腹囲 = **40歳未満(35歳を除く)**・妊娠中 など・BMI 20未満・自己申告(BMI 22未満) / 胸部X線 = **40歳未満で、20・25・30・35歳でなく**、結核の 定期健診の 対象施設・じん肺健診の 対象でない 者 / **貧血・肝機能・血中脂質・血糖 = 35歳未満 と 36〜39歳** / 血清クレアチニン = 40歳未満 / **心電図 = 35歳未満 と 36〜39歳**。省略は **医師が 個々の 労働者ごとに** 判断 | 厚労省リーフレット https://www.mhlw.go.jp/content/001724786.pdf |
| ⚠️ **2027年(令和9年)4月から 項目が 変わる**(R8.4.28 基発0428第10号): **喀痰検査を 削除**、肝機能の 酵素名を **GOT→AST・GPT→ALT・γ-GTP→γ-GT** に、**血清クレアチニン検査を 追加**。2026年度の 試験は 現行(喀痰あり)で 出るはず | 同上 |
| **特定業務従事者**(則45条): 則13条1項3号の 業務(深夜業 など)に 常時 従事する 者に **配置替えの 際 と 6か月以内ごとに1回**。胸部X線は 1年以内ごとに1回で よい | 則45条 |
| **海外派遣**(則45条の2): **6か月以上** 派遣するとき **あらかじめ**、帰国後 国内の 業務に つかせるとき | 則45条の2 |
| **給食従業員の 検便**: 雇入れの 際・配置替えの 際 | 則47条 |
| **歯科医師による 健診**: 令22条3項の 業務(塩酸・硝酸・硫酸・亜硫酸・弗化水素・黄りん など 歯に 有害な 物の ガス等の 発散場所)に 常時 従事: 雇入れ・配置替え・**6か月以内ごとに1回** | 則48条・法66条3項 |
| **記録**: 健康診断個人票(様式第5号)を 作り **5年間 保存** | 則51条 |
| **医師等の 意見聴取**: 異常の 所見が ある 労働者について、健診の 日から **3か月以内**(自発的健診は 書面提出から 2か月以内)。意見を 個人票に 記載 | 法66条の4・則51条の2 |
| 事後措置: 就業場所の 変更・作業の 転換・労働時間の 短縮・深夜業の 回数の 減少 など、意見の 衛生委員会への 報告 | 法66条の5 |
| **本人への 通知**: 遅滞なく(定期・雇入時 など すべて) | 法66条の6・則51条の4 |
