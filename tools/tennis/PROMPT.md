# フリックワールドテニス: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
どの 国の 話か(国旗の 札)・コートの 面の 札(ハード / クレー / グラス / 共通)・学ぶ 分野・しくみ図の どこに あるか(📍)が 出る。
あそぶのは **テニスが すきな 小学生〜中高生・テニススクールや 部活の コーチ・テニスが すきな 大人・解説者を めざす 人**。
**テニスの ことばと 意味を おぼえる ゲーム**(ニュースでも、試合の 記録集でも ない)。
もとは `tools/volley/PROMPT.md`(ワールドバレーボール)。けいくん 2026-10-24「ワールドテニスの専門家(解説者)になれるレベルになるために必要な 知識、
主要なテニスリーグ、有名テニス選手、有名な技、ルールをフリック形式の問題にしてください」→ 5つの 問いに「おすすめ」。
⭐ けいくんは **スポーツの 人**(サッカースクールの 代表・コーチ)。まちがいは すぐ 気づかれる。**選手と 国と 利き手・技と 使い手・年と 大会・ルールと どの 大会の 話か は かならず 確かめて から** 書く。
⭐ テニスには「リーグ」が ほとんど 無い。**ツアー(男子 ATP・女子 WTA)**が それに あたる(`tour` の 旅)。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 10こ

### 1. ⭐⭐ 数字が 変わる ものを 書かない(いちばん 事故が 起きやすい)
- ❌ **いまの 世界ランキング**(毎週 変わる)・賞金・年収・スポンサー契約・**いまの 勝率**・**いまの コーチ**・年齢(「◯歳」)・
  **いまの 選手の 4大大会の 優勝回数**(シナー・アルカラス・サバレンカ・シフィオンテク などは まだ ふえる)
- ✅ **変わらない 事実は よい**: 国籍・利き手・片手 / 両手バックハンド・**得意な サーフェス / プレーの 特徴**・
  **過去の 優勝と その 年**(「2024年の 全豪オープンで 優勝」)・**引退した 選手の 通算の 記録**(フェデラー 20回・ナダル 22回)・**オリンピックの メダルと 年**・ルールの 点・秒
- 大会の **出場人数・賞金・ポイントの 細かい 数**は 書かない(変わる)。「4大大会の 優勝は 2000ポイント」の ように **しくみの 数**で exam.txt に ある ものは よい
- ⚠️ 台本 `terms_js.py` が「賞金・年収・◯歳・◯円・◯ドル・◯%」などを 止める(⚠️ **「%」「パーセント」も 止まる**。スタッツは「入った 割合」「取った 割合」と 書く)

### 2. ⭐⭐ いまの スター選手(`star`)の 書きかた
- 「**イタリアの 男子選手。右利きで 両手バックハンド。ベースラインからの 速くて 正確な ストロークが 武器**」の ように **国・利き手・バックハンド・プレーの 特徴**で 書く
- ❌ **ランキング・「世界1位」・優勝回数・通算・連勝・いまの コーチ**を 書かない(台本 `STAR_BAN` が 止める)。
  ✅ 年つきの 事実は よい(「2024年 全米オープンで 優勝」「パリ2024 で 金メダル」)。⚠️ 1人に 書く 優勝は **1〜2つ まで**(ならべると 回数の 話に なる)
- ⚠️ **2026年10月の 時点で 現役か** を `exam.txt` の ⑤ と web で 1人ずつ 確かめる。引退した 選手は legend
- ⚠️ ケガ・休養・棄権・不調・私生活・結婚・SNS・発言は 書かない(「休養」「棄権」「引退」も 台本が 止める)

### 3. ⭐⭐ サーフェス(コートの 面)が 3つ。**どの 面の 話か・どの 大会の 話か 書く**
- **ハード**(全豪・全米・多くの 大会)/ **クレー**(赤土。全仏・ヨーロッパの 春)/ **グラス**(芝。ウィンブルドン・6月)/ 日本に 多い **オムニ**(砂入り人工芝)・カーペット・インドア
- 面に かかわる 語には **`ruleset` の 欄**を 付ける: `"ハード"` / `"クレー"` / `"グラス"` / `"共通"`(どの 面でも 同じ)。2〜3つなら「・」で(`"ハード・クレー"`)。
  4大大会・マスターズ・選手の 得意な 面・技(クレーで 効く ムーンボール など)に 付けると へえ。⚠️ ルールの 語は ほとんど `"共通"`
- ⚠️ **ATP / WTA / 4大大会 / ITF(デビスカップ・ジュニア)で ルールが 少し ちがう**(最終セットの 形・ショットクロック・コーチング・ダブルスの ノーアド)。**どの 大会の 決まりか 説明に 書く**
- 事実は `tools/tennis/exam.txt` の ①に 合わせる。**そこに 無い 数字は 書かない**(web で 確かめられた ときだけ)
- 条の 番号(第◯条)は 書かない(台本が 止める)。迷う 細かい ところは 書かない。**審判(JTA 公認審判員)の 学ぶ 範囲**を 中心に

### 4. 実在の 選手・大会・ツアーの 名前は 入れて よい(事実として)
- ✅ 名前は よい。❌ **大会の スポンサー名**(ジャパンオープンの 頭に つく 会社名・大会名に 入る 銀行名 など)は 書かない。「東京で 開かれる ATP の 大会」まで
- ❌ **ラケット・ガット・ボール・シューズ・ウェア・時計の 商品名と メーカー名**(テニスは 道具の 話が 多い。「ラケット」「ガット」まで。台本が 止める)
- ❌ **まんが・アニメの 登場人物・作品名**(テニスの まんがは とても 有名だが 入れない。台本が 止める)
- カタカナは **JTA・大会の 日本語 公式・日本の 新聞で よく 使う 書きかた**に そろえる(ウィンブルドン・ローランギャロス・タイブレーク・ジョコビッチ・シフィオンテク・サバレンカ)。
  ⚠️ 外国の 選手は 書きかたが ゆれる(シフィオンテク / シュフィオンテク / スウィアテク・シナー / シンナー・アルカラス / アルカラズ)。**答えは 1つ**に 決めて、ほかの 読みは `acceptedReadings` で 受ける

### 5. 人を けなさない・悲しい 場面を 入れない
- 「ダメな 選手」「負けた 選手」の 書きかたを しない。**ダブルフォルトで 負けた 話・判定で もめた 話・ラケットを こわした 話・大敗**など 人が 悲しんだ 場面は 入れない(名場面は **いい ほう** だけ)
- 名勝負は「**史上 最長の 決勝**」の ように 試合の 事実だけ。**どちらが 負けたかを 強く 書かない**
- 亡くなった 名選手・名コーチも 入れて よいが「亡くなった」とは 書かない(功績で 書く。歴史の 人物と 同じ)

### 6. ⚠️⚠️ ケガ・ドーピング・賭け・八百長・審判への 暴言・事件の 話は ぜったいに 入れない
- テニスは この 話題が 多い。**1語も 書かない**(台本が 止める)。「メディカルタイムアウト」「コードバイオレーション」は **ルールの 語として だけ**(だれが された かは 書かない)
- ⚠️ 事件・薬・賭けの 報道が ある 選手は **名前ごと 入れない**(`exam.txt` の ⑩。説明の 中にも 名前を 出さない)

### 7. ラフプレー・反則を すすめない・相手を ばかに しない
- 反則は **反則の 名前として**。「時間を かせぐ」「相手の じゃまを する」書きかたを しない
- ⭐ **技は「練習で 身に つける 技」として**。❌「相手を ばかに する」書きかたを しない。**アンダーサーブは 正式に みとめられた サーブ**として 書く
- ⚠️ **技の 名前の もとは 説が 分かれる ものが 多い**。「◯◯が はじめた」と 言いきらず「◯◯の 得意技として 有名」「◯◯で 知られる」まで

### 8. ほかの ゲームと 同じ 語は 入れて よい(けいくん決定 2026-09-30)
- フリックワールドサッカー・バレーボール・世界旅行 などと 同じ 語(ボレー・スマッシュ・ラリー・ブレーク・シード など)は、**テニスでの 意味**で 書く
- ⚠️ **テニスの「ブレーク」は 相手の サービスゲームを 取る こと**(サッカー・バレーの ブレイクと 別)。**サッカーの ボレーと テニスの ボレーも 別**
- 読みが かぶっては いけないのは **ワールドテニスの 9つの 旅の 中だけ**(台本が 止める)

### 9. 事実を 正しく(⭐ かならず 確かめる)
- **選手と 国と 利き手・バックハンド・技と 使い手・年と 大会・面・ルールの 数字と 大会** は 1語ずつ `exam.txt` と web で 確かめる(記憶で 書かない)
- 事実が あやしい 語は 入れない。**自分の ことばで 書く**(Wikipedia・公式の 文を 写さない)

### 10. 小学生も あそぶ
- ケガ・暴力・差別・賭け・人の 死の 話は 入れない。**迷ったら 入れない**

## 1語の 形(JSON)

```json
{"id":"wz-moonball","name":"ムーンボール","reading":"むーんぼーる","journey":"waza","category":"ストロークの 技","difficulty":2,
 "field":"技術","type":"concept","emoji":"🌙","mapNode":"waza:stroke","relatedTerms":["wz-topspin"],"ruleset":"クレー",
 "description":"ネットの ずっと 上を 通る、高く 弾む トップスピンの ボールです。相手を 後ろに 下げて 時間を つくります。はずみの 大きい クレーコートで よく 使われます。"}
```
ルールの 語の 例:
```json
{"id":"rl-let","name":"レット","reading":"れっと","journey":"rule","category":"フォルトと レット","difficulty":1,
 "field":"ルール","type":"concept","emoji":"🔁","mapNode":"rule:fault","relatedTerms":["rl-fault"],"ruleset":"共通",
 "description":"サーブが ネットに ふれてから 正しい サービスボックスに 入った ときなどに、その 1本を やりなおす ことです。失点にも 得点にも なりません。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(日本の 新聞・JTA で ふつうに 使う 書きかた。選手は「錦織圭」「ヤニック・シナー」の ように ふつうに 知られた よび名)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)
  - カタカナ語は ひらがなで(ボレー → ぼれー)。「・」「&」は 取る(サーブ&ボレー → さーぶあんどぼれー)
  - 数字・英字の 入る 名前は 読みで(ATP → えーてぃーぴー、WTA → だぶりゅーてぃーえー、ITF → あいてぃーえふ、JTA → じぇいてぃーえー、マスターズ1000 → ますたーずせん、15 → ふぃふてぃーん、40 → ふぉーてぃ)
  - ゆれる ことばは いちばん ふつうの 読みを reading に、ほかを `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は 上級だけ・旅で 1〜2語まで
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級(下の「3段の 分けかた」)
- **field**: 学ぶ 分野。次の 6つの どれか: `ルール` / `技術` / `戦術` / `ツアー・大会` / `選手` / `歴史`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(🩸 💀 ☠️ 🔪 🤕 🚑 😭 😱 💊 💰 は 使わない。🎾 ばかりに しない。国旗の 絵文字は 使わない(札で 出る ため))
- **country**(関係が あれば 付ける): その 選手・大会・技が どの 国の 話か。次の どれか。2〜3つなら「・」で(`"スペイン・フランス"`):
  `世界` `ヨーロッパ` `アジア` `アフリカ` `南アメリカ` `北中米` `オセアニア`
  `日本` `中国` `韓国` `台湾` `インド` `カザフスタン` `ウズベキスタン` `カタール` `サウジアラビア` `アラブ首長国連邦`
  `アメリカ` `カナダ` `メキシコ` `ブラジル` `アルゼンチン` `チリ`
  `イギリス` `フランス` `スペイン` `イタリア` `ドイツ` `スイス` `オーストリア` `オランダ` `ベルギー` `スウェーデン` `ノルウェー` `デンマーク`
  `セルビア` `クロアチア` `チェコ` `スロバキア` `ポーランド` `ハンガリー` `ルーマニア` `ブルガリア` `ギリシャ` `ロシア` `ベラルーシ` `ウクライナ` `ラトビア`
  `ソ連` `チェコスロバキア` `ユーゴスラビア` `西ドイツ` `オーストラリア` `ニュージーランド` `南アフリカ` `モナコ`。
  選手は **いまの 国籍**(国籍を 変えた 話は 書かない)。ルール・きほんの ことばなど 国と 関係ない 語は 付けない(⚠️ イギリスで 生まれた ことば・フランスの ジュ・ド・ポーム などは 付けて よい = へえ)
- **ruleset**(コートの 面の 話の 語): `"ハード"` / `"クレー"` / `"グラス"` / `"共通"`(上の 3.)。面の 話で ない 語は 付けない
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / どんな 特徴か / へえ」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  文体は **はじめから「〜です・ます」**(体言止めで はじめない)。「1人」「2人」は ふりがなが 読みまちがえるので **ひとり・ふたり** に 言いかえる
- **example**: なくてもよい
- 「へえ」を 1文 入れると よい(「0点を ラブと よぶのは フランス語の たまご(ルフ)から と 言われる」「ウィンブルドンは 白い ウェアの 決まりが ある」)

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | **テニスが すきな 小学生**。スコアの よびかた・きほんの ルール・4大大会の 名前・だれでも 知っている 選手と 技の 名前 |
| 2 | 中級 | **テニススクールに 通う 人・部活の コーチ・テニスが すきな 大人**。**審判(JTA 公認審判員)の 学ぶ 範囲の めやす**の ルール・ツアーの しくみ・技の 中身・サーフェスの ちがい |
| 3 | 上級 | **解説者**。戦術の ことば・スタッツの ことば・名コーチ・4大大会の 歴史・ルールの 細かい ところ・国別対抗の 形 |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる
(ならんだ 順が そのまま ステージの 順に なる)。

## 旅ごとに 入れる 語(⚠️ **読みが かぶると 台本が 止まる**。ほかの 旅の 欄に 書いてある 語は 入れない。ここに 無い 語を 足すのは よい)

⭐ 1つの 旅に **70語**(入門20・中級25・上級25)。下は **80〜100語の 候補**。多めに 書いて あるので **書く 人が えらぶ**(えらばなかった 語を ほかの 旅へ 動かさない)。
⭐ 候補の 選手の 現役 / 引退・年・国は **`exam.txt` と web で 確かめて から** 書く。⚠️ の 付いた ものは とくに。

### 読み(ひらがな)の 決まり(⚠️ 9つの 旅で そろえる)
- 数字は **読む とおりに ひらがな**: 15 → **ふぃふてぃーん** / 30 → **さーてぃ** / 40 → **ふぉーてぃ** / マスターズ1000 → **ますたーずせん** / ATP500 → **えーてぃーぴーごひゃく** / 5セットマッチ → **ごせっとまっち** / 25秒 → **にじゅうごびょう**
- 英字の 略は **英字の 読み**: ATP → **えーてぃーぴー** / WTA → **だぶりゅーてぃーえー** / ITF → **あいてぃーえふ** / JTA → **じぇいてぃーえー** / ELC → 語に する ときは「電子ライン判定」で
- 中黒(・)・＝・& は 読みに 入れない: ダウン・ザ・ライン → **だうんざらいん** / サーブ&ボレー → **さーぶあんどぼれー**
- ヴ は **ぶ** で 読む。小さい ぃ・ぇ は 残す
- 選手は **ふつうに 知られた よび名**を reading に(⚠️ **20字 以内**)。⚠️ 名字だけの 読みを reading に **しない**。かならず フルネーム(**にしこりけい** / **おおさかなおみ** / **やにっくしなー**)。
  ⚠️ ウィリアムズ姉妹・ブライアン兄弟・ズベレフ兄弟は フルネームで 分ける
- 愛称の 語(「クレーの 王」など)は **legend の nickname** で、答えの 人は 説明に 書く

## ぜったいに 守ること

- **自分の ことばで 書く**。Wikipedia・公式の 文を 写さない
- **お金・年齢・いまの ランキング・いまの 選手の 優勝回数は 書かない**。年と 大会・引退した 選手の 記録・ルールの 数字は よい。事実は `tools/tennis/exam.txt` と web で 確かめる
- **ケガ・ドーピング・賭け・事件・まんがの 登場人物・商品名・大会の スポンサー名は 書かない**
- 「100マス計算」「百ます計算」の 字を 使わない

## 出すもの

`tools/tennis/terms-<旅id>.json` に JSON の 配列(70語)で 書く。書いたら
`python3 tools/tennis/terms_js.py --only <旅id>` で 形を 確かめる(まちがいが あれば 止まる)。
