## 3. ⚠️⚠️⚠️ ぜったいの 決まり(パティシエ・美容師と 同じ。花言葉は なおさら)
- ✅ **ほかの ゲーム(農家・理科・パティシエ など)と 同じ 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。説明は **花屋の 目線**(お客さんに 選んで・長もちさせて・気持ちを 届ける)で 書きなおす
- **読み(ひらがな)は 花屋の 11の 旅の 中では かぶらない**(ほかの ゲームとは かぶって よい。`terms_js.py` が 止める)。⚠️ 季節の 旅に **同じ 花を 2回 入れない**(バラ・カーネーションは 花言葉の 旅に まとめる など、どの 旅に 置くかを 先に 決める)
- ⭐ **花言葉は くわしく 入れる**(けいくんの ねがい)。ただし:
  - **花言葉は 国・本・お店で ちがう**。日本で **広く 知られた もの**を 1〜3つ えらび、説明に「花言葉は 本や 国に よって ちがう ことが あります」を 旅の はじめの 説明に 書く(1語ずつ には 書かない)
  - ⚠️ **こわい・悲しい 花言葉は えらばない**(黒い バラ・ヒガンバナ・アネモネの 一部・オトギリソウ など、よく 知られた 花言葉が こわい ものは、**明るい ほうの 花言葉だけ**を 書く。明るい 花言葉が 無い 花は 入れない)
  - 「ぜったい この 意味」と 決めつけない(「◯◯という 花言葉が あります」の 形)
- **毒の ある 植物**(すずらん・スイセン・キョウチクトウ・あじさい など)は、名前と 花言葉は よい。毒の ことは「**口に 入れない ように 気を つける 花**」と おだやかに 1文だけ(毒の くわしい 中身は 書かない)
- **小学生も あそぶ**: お供えの 花・お葬式の 花は「大切な 人を しのぶ ときの 花」と おだやかに。「死」の 字を 使わない(台本で 止める)
- **刃物の 使いかた・手順を 書かない**(花ばさみ・ナイフは「花の 茎を 切る 道具。おとなと いっしょに 使う」まで)。水あげの 方法は **名前と 何の ための ことか**(「湯あげ = 茎を 熱い お湯に つけて 水を 吸いやすく する 方法」は よい。熱湯は「おとなが する」と そえる)
- **数字の 決めうちを 書かない**(値段・日持ちの 日数・市場の 数 など)。⚠️ **経営の 旅は とくに**: 開業資金の 金額・家賃・原価率や ロス率の 「ふつうは ◯%」・税率・補助金の 金額は **書かない**(変わるし、店で ちがう)。書くのは **ことばの 意味と 考えかた**(「粗利 = 売上 − 仕入れ」「損益分岐点 = 赤字と 黒字の さかいめの 売上」)。
- 経営の ことばは **花屋の 例で 説明する**(「ロス率 = 仕入れた 花の うち、売れずに 捨てた 花の 割合。母の日の 前に 仕入れすぎると 上がる」)。⚠️ 税理士・投資家の ゲームと 同じ 語(粗利・資金繰り・青色申告)が 出て よいが、説明は **花屋の 目線**で 書きなおす
- ⚠️ 税・法律の ことば(開業届・青色申告・インボイス)は **名前と 何の ための ものか**まで。手続きの 手順や 期限は 書かない(変わるため。「くわしくは 税務署や 税理士に」)
- 「もうかる」「かならず 成功する」と **決めつけない**。経営の 旅の はじめの 説明に「お店に よって ちがう。考えかたを 知る 旅」と 書く**バラの 本数の 意味**は よく 知られた もの(1本・3本・12本(ダズンローズ)・108本 など)に 限り、「〜と 言われます」の 形で
- **実在の 花屋・ブランド・商標の 品種名・花の 宅配の 会社や サービスの 名前を 入れない**(生け花の 流派の 名前(池坊・小原流・草月流)は 文化として よい。確かめる)
- **作った 助手とは 別の 助手が 1語ずつ 確かめる**(意味・読み・花言葉が こわくないか・季節が 合っているか・同じ 花が 2回 出ていないか)。ふりがなも 全語 見る(`tools/ruby_fix.json`)。
  ⚠️ 花の 名前は **読みが ゆれる**(百合 ゆり・紫陽花 あじさい・向日葵 ひまわり・秋桜 こすもす・吾亦紅 われもこう など)。**カタカナ・ひらがなで ふつうに 書く 名前を `name` に**、ゆれる 読みは `acceptedReadings`

## 5. 作りかたの 手順(農家・大工の まとめと 同じ)
1. けいくんに 2 の 5つを 聞く(**旅は 11こで 決まっている**ので、聞くのは 名前・入れない もの の 確かめ くらいで よい) → 返事を CLAUDE.md に 書く
2. `tools/hanaya/PROMPT.md` `exam.txt` `mkmeta.py` → `meta.json` を 作る → 旅ごとに 助手に 70語ずつ 頼む(`PROMPT.md` を そのまま わたす。**助手は 2人ずつ**。⚠️ `shigoto` / `shiire` / `sekkyaku` / `keiei` は **ことばが かさなりやすい**(市場・予約・法人)。**先に 4つの 旅の 語の 一覧を 1人の 助手に 作らせて** 置き場所を 決めてから 頼む。⚠️ 季節の 4つの 旅は **同じ 助手に 続けて** 頼むか、花の 一覧を 先に 決めて わたす(同じ 花が 2回 出ないように))→ `terms-<旅>.json`
3. `terms_js.py` で 止められた 語を 直す → 別の 助手が 1語ずつ 確かめる(**花言葉の 出どころが ふつうか・こわくないか**も)→ ふりがな
4. `hanaya/hanaya.js`(patissier.js を 写し、💐 花言葉の 表示を 足す)・`build_games.py`・`index.html` の PLUG と SERIES → `python3 tools/build_games.py`
5. 手元で 通す: `python3 -m http.server 8765` → `node tools/play-all.mjs hanaya/` / `node tools/click-all.mjs hanaya/`
6. PR は **rebase で 取りこむ**(この 入れもの)。speed-king は squash。コミットの 末尾は Co-Authored-By と Claude-Session の 2行
7. かずとも `speed-king`: `FLICK_MODES` / `FLICK_LINK_TARGETS` に `hanaya`(PR → squash)。`HOME_GAMES` は 絵と OK の あと
8. けいくんに ChatGPT で 絵を 頼む 文を わたす。**3つ**:
   ・トップの 絵(1536×1024)。**人物は 画面の 下 3分の1に 小さく**・指5本・首が 見える。色とりどりの 花で いっぱいの 花屋の 前で、エプロンの 子どもと 白い 犬が 笑っている 絵。
     **花ばさみ・ナイフを 手に 持たせない**(手が 崩れやすい。花束は 台の 上や バケツに 置く)。季節の 花(春夏秋冬)が まざった 店先に すると ゲームの 旅と 合う。
     絵の 中の 字は「フリック花屋」だけ・ゲームに 無い 機能の 絵を 入れない・**実在の 花屋・ブランドの 名前や ロゴを 描かない**。届いたら **まず 字を 切り出して 読む**
   ・四角い 絵(1254px)… **切らずに そのまま アイコンに する**ので、**小さく しても わかる 絵**(人と 犬と 花束 くらい。まわりに 字の 札を ならべない)で 頼む
   ・**題名だけの 透明 PNG**(CLAUDE.md「題名は ChatGPT に 切りぬいてもらう」の 文を そのまま。「フリック花屋」と **はっきり 書く**。⚠️ ChatGPT は 字を 変える。**届いた 字を かならず 読む**)
9. 絵を 入れたら CLAUDE.md に 節を 書く(名前・旅・語数・確かめた 日・入れなかった 花や 花言葉と 理由)

## 6. 気をつける 前例
- 農家(`noka/`)の「果物と 花」の 旅と かさなる 語が ある(花き・球根・苗 など)。**同じ 語を 入れて よい**が、農家 = 育てる / 花屋 = 選んで 届ける 目線で
- 理科旅行の 生物(花の つくり)とも かさなる。同じ 語で よい

- 看護師で 統合失調症 → 適応障害に 入れかえた ように、**こわく 感じる ものは 入れない**。花言葉で 迷ったら 入れない
