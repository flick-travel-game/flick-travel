## B-1. 労働基準法(関係法令・有害業務以外)

### 労働契約・解雇・賃金
| 事実 | 出どころ |
|---|---|
| 使用者は 労働契約の 締結に 際し **賃金・労働時間 その他の 労働条件を 明示**。賃金・労働時間 など 省令で 定める 事項は 省令の 方法(= **書面の 交付**。本人が 希望すれば FAX・電子メール等 でも よい)で 明示 | 労基15①、労基則5③④ |
| 明示された 労働条件が 事実と ちがえば 労働者は **即時に 労働契約を 解除**できる。就業の ため 住居を 変えた 人が **14日以内に 帰郷**するなら 使用者が 旅費を 負担 | 労基15②③ |
| 書面で 明示する 事項(絶対的明示事項): 契約期間 / 有期契約の 更新の 基準(通算期間・更新回数の 上限を 含む)/ **就業の 場所・業務(変更の 範囲を 含む)**/ 始業・終業時刻、所定外労働の 有無、休憩、休日、休暇、交替制 / 賃金の 決定・計算・支払方法、締切・支払時期(昇給は 書面でなくて よい)/ 退職(解雇の 事由を 含む) | 労基則5①一〜四・③ |
| **平均賃金** = 算定事由の 発生した 日 以前 **3か月間**の 賃金総額 ÷ その 期間の 総日数。賃金締切日が あれば 直前の 締切日から。業務上の 休業・産前産後休業・使用者の 責めによる 休業・育児介護休業・試用期間は 日数も 賃金も 除く。臨時の 賃金・3か月を 超える 期間ごとの 賃金は 入れない | 労基12①〜④ |
| **解雇制限**: 業務上の 負傷・疾病で 休業する 期間 + **その後30日間**、産前産後休業(65条)の 期間 + **その後30日間**は 解雇できない。例外: 打切補償(81条)を 払う とき / 天災事変等で 事業の 継続が 不可能(**行政官庁の 認定**が いる) | 労基19 |
| **解雇予告**: **少なくとも30日前**に 予告。しないなら **30日分以上の 平均賃金**(解雇予告手当)。予告日数は 1日分の 平均賃金を 払った 日数だけ 短縮できる。例外: 天災事変等で 事業継続不可能 / 労働者の 責に 帰すべき 事由(どちらも 行政官庁の 認定) | 労基20①②③ |
| **賃金支払の 5原則**: ①通貨で ②直接 労働者に ③全額を ④**毎月1回以上** ⑤**一定の 期日を 定めて**。例外: 法令・労働協約に 定めが あれば 通貨以外 / 法令に 定め・労使協定が あれば 一部控除 / 臨時の 賃金・賞与は 毎月払いの 対象外 | 労基24①② |
| **非常時払**: 出産・疾病・災害 その他 非常の 場合の 費用の 請求が あれば、支払期日前でも **既往の 労働の 賃金**を 払う | 労基25 |
| **休業手当**: 使用者の 責に 帰すべき 事由の 休業は 平均賃金の **100分の60以上** | 労基26 |

### 労働時間・休憩・休日
| 事実 | 出どころ |
|---|---|
| 法定労働時間: 休憩時間を 除き **1週40時間**・**1日8時間** | 労基32①② |
| **特例 44時間**: 別表第一の **第8号(商業)・第10号(映画の 製作を 除く 映画・演劇)・第13号(保健衛生)・第14号(接客娯楽)**の 事業で **常時10人未満**の 事業場は **1週44時間・1日8時間**まで | 労基40①、労基則25の2① |
| **1か月単位の 変形労働時間制**: 労使協定 **または 就業規則**等で、1か月以内の 期間を 平均して 週40時間を 超えない 定めを したとき。協定は 行政官庁に 届出 | 労基32の2 |
| **フレックスタイム制**: 就業規則等で 始業・終業を 労働者の 決定に 委ね、労使協定で ①対象者 ②**清算期間(3か月以内)** ③総労働時間 ④その他を 定める。清算期間が **1か月を 超える** ときは、1か月ごとに 平均して **週50時間**を 超えない こと、かつ 協定の **届出**が 要る(1か月以内なら 届出 不要) | 労基32の3①②④ |
| **1年単位の 変形労働時間制**: 労使協定で 対象期間(**1か月を 超え 1年以内**)を 平均して 週40時間以内。限度: 労働日数 **年280日**(対象期間が 3か月を 超える とき)、**1日10時間・1週52時間**、連続労働日数 **6日**(特定期間は 1週1日の 休日が 確保できる 日数)。協定は 届出 | 労基32の4①③④、労基則12の4③④⑤ |
| **1週間単位の 非定型的変形労働時間制**: 省令で 定める 事業(**小売業・旅館・料理店・飲食店**)で **常時30人未満**。労使協定で **1日10時間**まで。各日の 労働時間は その週の 開始前に **書面**で 通知 | 労基32の5、労基則12の5①②③ |
| **災害等の 臨時の 必要**: 行政官庁の **許可**で 時間外・休日労働。急迫で 許可を 受ける 暇が なければ **事後に 遅滞なく 届出** | 労基33① |
| **休憩**: 労働時間 **6時間を 超える** とき **45分**、**8時間を 超える** とき **1時間**を 労働時間の 途中に。**一斉に** 与える(労使協定が あれば 例外)。**自由に 利用**させる | 労基34①②③ |
| **休日**: **毎週 少なくとも1回**。または **4週間を 通じ 4日以上** | 労基35①② |
| **36協定**: 労使協定を 行政官庁に 届け出れば 時間外・休日労働が できる。協定で 定める 事項: 対象者 / 対象期間(**1年間**)/ 時間外を させられる 場合 / 1日・1か月・1年の 延長時間 と 休日労働の 日数 / 省令事項 | 労基36①② |
| 36協定の **限度時間**: **1か月45時間・1年360時間**(1年単位の 変形制で 対象期間 3か月超 なら **42時間・320時間**) | 労基36③④ |
| **特別条項**(通常 予見できない 業務量の 大幅な 増加等 臨時的な とき): 1か月の 時間外 + 休日労働 **100時間未満**、1年の 時間外 **720時間以内**。限度時間(月45時間)を 超えられる 月数は **1年に 6か月以内** | 労基36⑤ |
| 協定で 定めても 守る 要件: ①坑内労働 など 健康上 特に 有害な 業務の 時間外は **1日2時間**以内 ②1か月の 時間外 + 休日労働 **100時間未満** ③直前 **2〜6か月**の どの 期間の 平均も **80時間以内** | 労基36⑥ |
| 限度時間 など(3〜5項・6項2号3号)は **新技術・新商品等の 研究開発業務**には 適用しない | 労基36⑪ |
| **割増賃金**: 時間外 **2割5分以上**(政令で 2割5分)、休日 **3割5分**(政令)、**深夜(午後10時〜午前5時)2割5分以上**。1か月 **60時間を 超える** 時間外は **5割以上**(労使協定で 代替休暇に できる) | 労基37①③④、割増賃金令 |
| 割増賃金の 基礎に **家族手当・通勤手当** その他 省令の 賃金は 入れない | 労基37⑤ |
| **事業場外労働の みなし**: 労働時間を 算定し難い ときは **所定労働時間** 労働したと みなす(通常 所定を 超えるなら 通常 必要な 時間。労使協定で 定めた 時間 → 届出) | 労基38の2 |
| **専門業務型 裁量労働制**: 労使協定で 対象業務・みなし時間・具体的指示を しない こと・健康福祉確保措置・苦情処理 など を 定め、届出 | 労基38の3 |
| **企画業務型 裁量労働制**: 労使委員会の **5分の4以上**の 多数の 決議 + 届出 + **本人の 同意**(同意しない 人への 不利益取扱い 禁止) | 労基38の4① |
| **適用除外**(労働時間・休憩・休日の 規定を 適用しない): ①農業(林業を 除く)・畜産水産業 ②**管理監督者・機密の 事務を 取り扱う者** ③監視・断続的労働で **行政官庁の 許可**を 受けた者。⚠️ 深夜業の 割増は 除外されない(条文の 対象は 労働時間・休憩・休日) | 労基41 |
| **高度プロフェッショナル制度**: 労使委員会の 5分の4以上の 決議 + 届出 + 本人の 書面同意。年収は 基準年間平均給与額の **3倍を 相当程度 上回る**(省令)。**年104日以上 かつ 4週4日以上**の 休日 | 労基41の2①二・四 |

|---|---|

| 継続勤務年数ごとの 加算: 6か月経過日から 1年=+1(**11日**)/ 2年=+2(**12日**)/ 3年=+4(**14日**)/ 4年=+6(**16日**)/ 5年=+8(**18日**)/ 6年以上=+10(**20日**)。前年に 8割未満 出勤なら その年は 付与しない | 労基39② |
| **比例付与**の 対象: 週所定労働時間 **30時間未満** かつ 週所定労働日数 **4日以下**(または 年 **216日以下**)。通常の 労働者の 週所定労働日数 = **5.2日** | 労基39③、労基則24の3①②④⑤ |
| 比例付与の 日数(週4日/年169〜216日): 7・8・9・10・12・13・15日 / 週3日(121〜168日): 5・6・6・8・9・10・11日 / 週2日(73〜120日): 3・4・4・5・6・6・7日 / 週1日(48〜72日): 1・2・2・2・3・3・3日(6か月 → 6年6か月以上の 順) | 労基則24の3③ の表 |
| **時間単位年休**: 労使協定で **5日以内** | 労基39④ |
| **時季指定権 と 時季変更権**: 労働者の 請求する 時季に 与える。事業の 正常な 運営を 妨げる ときは 他の 時季に | 労基39⑤ |
| **計画的付与**: 労使協定で 時季を 定めたとき、**5日を 超える 部分**について | 労基39⑥ |
| **使用者の 時季指定義務**: 10労働日以上 付与される 労働者に、基準日から 1年以内に **5日**は 使用者が 時季を 定めて 与える(本人の 請求・計画的付与で 与えた 日数は 差し引く) | 労基39⑦⑧ |
| 年休中の 賃金: 平均賃金 / 通常の 賃金 / (労使協定で)健康保険の 標準報酬日額 | 労基39⑨ |
| **出勤したと みなす**: 業務上の 傷病の 休業、育児休業・介護休業、産前産後休業 | 労基39⑩ |
| **年次有給休暇管理簿**: 時季・日数・基準日を 労働者ごとに 明らかにして 作成、その 期間中 と 期間満了後 **5年間**(当分の間 3年)保存 | 労基則24の7(→ 労基則71・労基143) |
| 年休の 請求権の **時効は 2年**(賃金以外の 請求権) | 労基115 |

### 年少者
| 事実 | 出どころ |
|---|---|
| 児童は **満15歳に 達した 日 以後の 最初の 3月31日**まで 使用できない(非工業的 事業の 軽易な 労働は 行政官庁の 許可で **満13歳以上**、映画・演劇は 13歳未満も) | 労基56①② |
| **満18歳未満**: 年齢を 証明する **戸籍証明書**を 事業場に 備え付ける | 労基57① |
| 親権者・後見人は 未成年者に 代わって 労働契約を 締結できない / 未成年者は **独立して 賃金を 請求**できる(親が 代わって 受け取れない) | 労基58①・59 |
| 満18歳未満には **変形労働時間制(32条の2〜5)・36協定・40条の 特例・高プロ**を 適用しない。例外: 満15歳以上18歳未満は 1週40時間内で 1日 **4時間以内に 短縮した 日が あれば 他の 日に 10時間**まで、または 1週 **48時間**以内・1日8時間以内で 1か月・1年単位の 変形制 | 労基60①③ |
| **深夜業の 禁止**: 満18歳未満を **午後10時〜午前5時**に 使用できない。例外: 交替制の **満16歳以上の 男性** / 交替制の 事業は 行政官庁の 許可で 午後10時30分まで / 農林水産・保健衛生・電話交換は 適用なし | 労基61①③④ |
| **危険有害業務の 就業制限**(運転中の 機械の 掃除・注油、動力クレーンの 運転 など 省令の 業務 / 毒劇物・爆発物、粉じん・有害ガス・高温高圧 など)/ **坑内労働の 禁止** | 労基62・63 |

### 妊産婦等
| 事実 | 出どころ |
|---|---|
| **妊産婦** = 妊娠中の 女性 + **産後1年を 経過しない** 女性 | 労基64の3① |
| 坑内業務: 妊娠中の 女性 と 申し出た 産後1年未満の 女性は **すべての 坑内業務** 禁止。それ以外の 満18歳以上の 女性は 人力掘削 など 省令の 業務が 禁止 | 労基64の2 |
| 妊産婦を **重量物・有害ガス発散場所** など 妊娠・出産・哺育に 有害な 業務に 就かせない。業務の 範囲は 省令(女性則)。妊産婦以外の 女性にも 一部 準用 | 労基64の3 |
| **産前**: **6週間**(多胎妊娠 **14週間**)以内に 出産予定の 女性が **請求**したら 就業させない。**産後**: **8週間**は 就業させない(ただし **6週間** 経過後に 本人が 請求し **医師が 支障ないと 認めた 業務**は 可) | 労基65①② |
| 妊娠中の 女性が 請求したら **他の 軽易な 業務**に 転換 | 労基65③ |
| 妊産婦が 請求したら: 変形労働時間制でも **1週40時間・1日8時間**を 超えて 働かせない(フレックスは 制限の 対象外)/ **時間外・休日労働**を させない(33条の 災害時・公務も 含む)/ **深夜業**を させない | 労基66①②③ |
| **育児時間**: **生後満1年に 達しない** 生児を 育てる 女性は、休憩のほか **1日2回 各 少なくとも30分** 請求できる | 労基67 |
| **生理休暇**: 生理日の 就業が 著しく困難な 女性が 請求したら 就業させない | 労基68 |

### 就業規則・寄宿舎・記録・災害補償・監督
| 事実 | 出どころ |
|---|---|

| 測定点(A測定): 床面上 **6m以下**の 等間隔の 縦横の 線の 交点、床上 **50cm以上150cm以下**。測定点は **5以上**。試料採取は **10分間以上** | 作業環境測定基準2①(上の 厚労省資料に 転載) |
