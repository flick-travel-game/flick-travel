# フリック薬剤師: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
学ぶ 分野(薬剤師国家試験の 科目)・しくみ図の どこに あるか(📍)が 出る。あそぶのは **小学生〜薬学部を めざす 中高生・薬学生・大人**。
**薬の ことばと 意味を おぼえる ゲーム**(試験の 問題集でも、薬の 使いかたの 手引きでも ない)。
もとは `tools/ishi/PROMPT.md`(医師)と `tools/noka/PROMPT.md`(農家)。
けいくん 2026-10-03「薬剤師の専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 6つ

### 1. 薬の 使いかたを 教える ゲームに しない(いちばん 大事)
- ❌ **書かない**: 薬の **量**(mg・錠・包・滴)・飲む **回数**・**最大量**・**飲みすぎ**の 話・
  「この しょうじょうなら この 薬を 飲めば よい」・**飲み合わせの 具体的な 組み合わせ**(◯◯と ◯◯は いっしょに 飲まない)・正常値の 数字・薬の **商品名**
- ⭕ **書く**: その ことばが **何を さすか**・**何の ために あるか**・**どんな しくみか**・薬剤師は どう かかわるか
  (例: 腸溶錠 = 胃では とけずに、腸に 着いてから とける ように 工夫した 錠剤です。胃を あらさない ためや、胃の 酸で こわれやすい 薬を 守る ために 使います)
- ⭐ **「正しく 使う ための 考えかた」は 書いて よい**(子どもの 安全に 役立つ): 「薬は 決められた 時間と 量を 守る」「人の 薬を 飲まない」
  「おかしいと 思ったら 大人と 薬剤師さんに 聞く」「お茶や ジュースでは なく 水で 飲む」「飲みきる ように 言われた 薬(抗菌薬など)は 自分で やめない」
- 薬は **グループの 名前と 目的と しくみだけ**(抗ヒスタミン薬 = アレルギーの もとに なる ヒスタミンの はたらきを ブロックする 薬)。
  どの 病気に どれを 何錠 使うかは 書かない
- **数字は なるべく 出さない**。制度で 決まっていて まちがいない もの(薬学部は 6年制・試験は 年1回・1928年の ペニシリン発見)だけ。まよったら 書かない

### 2. 小学生も あそぶ(こわく しない)
- ❌ **「死」「殺」「致死」「過量」の 字を 使わない**(台本が 止める)。中毒の ようす・苦しむ ようす・血が 出る ようすを 書かない
- 毒薬・劇薬・麻薬・向精神薬は **「法律で きびしく 管理される 薬」まで**。中身・ききめ・個別の 名前は 書かない
- 薬物乱用防止は **「ぜったいに 手を 出さない・さそわれたら はっきり 断って 大人に 言う」の 形**だけ。**乱用薬物の 名前の 一覧・効果は 書かない**(台本が 止める)
- 病気は **「何が 起きている 状態か」+「薬と お医者さん・薬剤師さんが 助ける」** だけ。**めずらしい 病気・こわい 病名の ならびは 入れない**
- **抗がん剤・麻薬・向精神薬の 個別の 成分名は 入れない**(グループの 名前は よい)
- 読んだ 子が **こわく ならない**・**「助けてくれる 人が いる」と 思える** 書きかたに する。**迷ったら その 語を 入れない**

### 3. 商品名・会社名を 出さない
- **実在の 薬の 商品名・製薬会社・薬局チェーン・ドラッグストアの 名前を 書かない**(台本が 止める)。「ロキソニン」では なく 一般名か「解熱鎮痛薬」
- **一般名(成分の 名前)は 有名な ものだけ**: アセトアミノフェン・イブプロフェン・アスピリン・ペニシリン・インスリン・アドレナリン・ヒスタミン・カフェイン・
  モルヒネは ❌(麻薬)。カタカナの 長い 成分名を ならべない(子どもが 読めない)
- ⭕ 公の 組織・制度の 名前は よい: 厚生労働省・PMDA(医薬品医療機器総合機構)・WHO・日本薬局方・薬剤師法・薬機法
- 人の 名前は 歴史として よい(フレミング・ジェンナー・長井長義・ヒポクラテス・パラケルスス・華岡青洲・北里柴三郎 など。**事実を 確かめて**。亡くなった 話は 書かない)

### 4. ⚠️ 年ごとに 変わる 数字を 書かない
- **薬価・合格率・薬剤師の 人数・%・円** は 書かない(台本が 止める)。試験の しくみは `tools/yakuzai/exam.txt` に 合わせる
- 条の 番号(第◯条)は 書かない

### 5. 薬剤師の 目線で 書く(ほかの ゲームと 同じ 語を 入れて よい)
- ✅ **医師・看護師・からだ旅行・理科(化学)・救急隊員・家事 など ほかの ゲームと 同じ ことばを 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)
- ⚠️ ただし 説明は **薬剤師の 目線**で 書きなおす(「薬が 安全に きく ように 確かめる」「患者さんに わかる ように 伝える」)。
  例: 副作用 … 医師「治療の ときに 気を つける」/ 薬剤師「薬の 説明で 患者さんに 伝え、起きていないか 話を 聞いて 確かめる」
- **読み(ひらがな)は 薬剤師の 9つの 旅の 中で かぶらない**(台本が 止める)。下の「旅ごとに 入れる 語」を 守る。**ほかの 旅の 欄に ある 語は 入れない**
- 文体は **はじめから「〜です・ます」**(体言止めで はじめない)

### 6. 事実を 正しく
- 事実が あやしい 語は 入れない。**自分の ことばで 書く**(教科書・添付文書・Wikipedia・公式の 文を 写さない)
- 理科の 化学(酸と アルカリ・中和)と 薬の 話(胃薬)を つなぐ と へえに なる。こういう「へえ」を 1文 入れると よい

## 1語の 形(JSON)

```json
{"id":"kh-shokkan","name":"食間","reading":"しょっかん","journey":"kihon","category":"飲む 時間","difficulty":1,
 "field":"実務","type":"concept","emoji":"⏰","mapNode":"kihon:jikan","relatedTerms":["kh-shokuzen","kh-shokugo"],
 "description":"食事と 食事の あいだの こと。食事の とちゅうに 飲む と いう 意味では ありません。おなかが すいている ときに 飲む ほうが よい 薬で 使われる 言いかたです。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(薬局・病院で ふつうに 使う 書きかた。漢字・カタカナ・英字の 略語)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)
  - カタカナ語は ひらがなで(カプセル → かぷせる)。英字の 略語は 下の「略語の 読み」の とおり
  - ゆれる ことばは いちばん ふつうの 読みを reading に、ほかを `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は 上級だけ・旅で 1〜2語まで
  - ⚠️ **読みを まちがえやすい ことば**(頓服 とんぷく・坐剤 ざざい・散剤 さんざい・顆粒 かりゅう・軟膏 なんこう・貼付剤 ちょうふざい/てんぷざい・
    鑑査 かんさ・疑義照会 ぎぎしょうかい・薬歴 やくれき・一包化 いっぽうか・拮抗薬 きっこうやく・受容体 じゅようたい・
    代謝 たいしゃ・排泄 はいせつ・徐放性 じょほうせい・腸溶錠 ちょうようじょう・生薬 しょうやく・本草学 ほんぞうがく・
    劇薬 げきやく・薬価 やっか・日本薬局方 にほんやっきょくほう)は **1語ずつ 確かめる**
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級(下の「3段の 分けかた」)
- **field**: 学ぶ 分野 = **薬剤師国家試験の 科目**。次の 7つの どれか(入門の 語でも いちばん 近い ものを 書く):
  `物理・化学・生物` `衛生` `薬理` `薬剤` `病態・薬物治療` `法規・制度・倫理` `実務`
  - めやす: 薬の 化学の 形・からだの しくみ・生薬の もとの 植物・酸と アルカリ → `物理・化学・生物` /
    感染予防・消毒・予防接種・食品・栄養・水・環境・たばこ・薬物乱用防止 → `衛生` /
    受容体・作用薬・拮抗薬・薬の グループと その しくみ・副作用の しくみ → `薬理` /
    剤形・製剤・吸収・分布・代謝・排泄・血中濃度・DDS・保管 → `薬剤` /
    病気の しくみと 薬で 治療する 考えかた → `病態・薬物治療` /
    法律・制度・保険・薬価・倫理・歴史 → `法規・制度・倫理` /
    処方箋・調剤・鑑査・服薬指導・お薬手帳・薬局の 仕事・OTCの 相談 → `実務`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(💀 ☠️ 🩸 🔫 🔪 は 使わない。💉 の 多用も さける)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / 何の ために あるか / 薬剤師は どう 見るか」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  専門用語を 専門用語だけで 説明しない。「1人」「2人」は ふりがなが 読みまちがえるので **ひとり・ふたり** と ひらがなで 書く
- **example**: なくてもよい

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | **くすりを 正しく 使える 人**。小学校・中学校の「くすりの 正しい 使い方」の 範囲(剤形・飲む 時間・保管・お薬手帳・副作用の ことば)。小学生でも 聞いた ことが ある |
| 2 | 中級 | **登録販売者・薬局で 働く 人**。**登録販売者試験の 範囲の めやす**(OTCの 分類・成分の グループ・セルフメディケーション・法律の 基本) |
| 3 | 上級 | **薬剤師**。**薬剤師国家試験の 範囲の めやす**(薬理・体内動態・薬物治療・調剤・法規・衛生) |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる
(ならんだ 順が そのまま ステージの 順に なる)。
