## フリック国語旅行(`kokugo/`。けいくん 2026-09-27「フリック国語旅行 / 3段でOK / 古文・漢文を入れる / 上級は よみを かくす / 年表」)

- 旅は 9つ(ことばの意味 `kkgoi` 180・カタカナ語 `kkatakana` 90・ことわざ 慣用句 `kkotowaza` 150・文法 `kbunpo` 60・古文単語 `kkobun` 90・古典文法 和歌 `kkoten` 60・漢文 `kkanbun` 60・文学史 `kbungaku` 90・評論のキーワード `khyoron` 150)+ マスター `kokumas`。**930語**
- ⚠️ **漢字の読み・四字熟語の 旅は 消した**(けいくん 2026-10-24「漢字の読みや四字熟語は漢字フリックにあるから削除して / 国語だからたくさんの言葉と意味を覚えられるようにしたい」)。
  かわりに **ことばの意味(語彙力。おもむろに・にべもない・確信犯 など)とカタカナ語(エビデンス・コンセンサス など)**を足し、ことわざ・評論を 90→150 に。
  ⚠️ **国語には 漢字の読み・四字熟語・対義語・類義語を 入れない**(フリック漢字の 役目)。かずともの `kyomi` / `kyoji` は 前の 記録の ため `FLICK_MODES` に 残してある
  ・`kokugo.js` は 手で 直した(`tools/kokugo/make_kokugo_js.py` は パティシエが 変わって もう 走らない)。⚠️ **社会・数学・英語の 台本が kokugo.js の MODE_OF / MODES_ALL / RANK_READY の 行を そのまま さがして 置きかえる**ので、その 行を 変えたら `tools/shakai/make_shakai_js.py` `tools/sugaku/make_sugaku_js.py` も そろえる(2026-10-24 に そろえた。できる shakai.js / sugaku.js は 1文字も 変わらない)
  ・⚠️ トップの 絵と アイコンには まだ「かんじの よみ」「よじじゅくご」の 札が 入っている(けいくんの 判断で 作りなおすかどうか)
- むずかしさは 3段: 入門(中学の 基本)→ 中級(高校受験)→ 上級(大学受験)。「〜の 範囲の めやす」で、入試センター・教育委員会とは 関係ない と ページに 書いてある
- ことばは `tools/kokugo/terms-<旅>.json`(決まりは `tools/kokugo/PROMPT.md`)→ `tools/kokugo/terms_js.py` → `kokugo/terms.js`。しくみは `kokugo/kokugo.js`(パティシエを 写した。作った 台本は `tools/kokugo/make_kokugo_js.py`)
- ~~漢字の読みの 上級は よみを かくす~~(旅ごと 消した。`hide` の しくみは kokugo.js に 残っているが 当たる 語は 無い。答えを かくすのは 土台の「ひらがな 無し」)
- 古文単語は 歴史的仮名遣い(をかし)を 見せて、現代仮名遣い(おかし)を 打つ。漢文の 句法は 書き下し文を 見せて その 読みを 打つ
- 図は 文学史の 年表だけ(`mapNode` = `nenpyo:<時代>`。ほかの 旅は mapNode なし)
- 読みは 9つの 旅 ぜんぶで かぶらない(`terms_js.py` が 止める)
- 2026-10-24 に 足した 390語も 作った 助手とは 別の 助手が 確かめた(直し 7つ)。ふりがなの 直し 21か所は `tools/ruby_fix.json` に context 付きで。⚠️ この 入れものの sudachi 辞書で `build_games.py` を 走らせると ほかの ゲームの terms.js も 変わる。**国語の ファイルだけ のこして ほかは もどした**
- 作った 助手とは 別の 助手が 1語ずつ 確かめた(読み・意味・作者・時代)。ふりがなの 読みまちがい 118か所は `tools/ruby_fix.json` に **context 付きで** 足した(ほかの ゲームに ひびかない)
- 近代の 作家は 作品名と 作者名だけ(本文を のせない)。古典は 書きだし 1行まで
- 絵(2026-09-27 に 2枚 届いた): アイコンは 四角い 絵(1254×1254)を 縮めた もの。題名は トップの 絵(1536×1024)から `tools/kokugo/logo_cut.py` で 切りぬいた(えんじの ふちで うめる。「フ」の 左上の インクびんは 落とす)
