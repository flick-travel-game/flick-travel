# フリック犬の気持ち(`inu/`)を 作る ための まとめ(2026-10-23。新しい セッション用)

けいくん 2026-10-23「新しいセッションで フリック犬の気持ちを作成したい。**犬の気持ちがわかるように なるために必要な知識**をフリック形式の問題にしてください」

⭐⭐⭐ **この ゲームは「ことばを おぼえる」で 終わらせない。遊んだ 子が きょう 家の 犬(または 散歩で 会う 犬)の 気持ちを 1つ 読めて、1つ やさしく できる ように する**(メンタリスト 2026-10-23「実践的に」と 同じ 考え)。
そのために ①ことばに **「🎯 やってみよう」の 観察・練習**を 付ける ②**🐶 犬からの 手紙(場面カード)**を 20枚 入れる ③**📅 きょうの 観察**を 出す(下の 1 と 2-2)

⭐ いちばん 近い 兄弟は **フリック獣医師(`jui/`。`docs/フリック獣医師-はじめかた.md`)**(ペットの 旅 `pet`・こわく しない・薬の 名前と 量を 書かない)と **フリック心理学(`shinri/`)**(決めつけない・科学で たしかめられた ことと 言い伝えを 分ける)。
写真の 出しかたは **フリック恐竜図鑑(`kyoryu/`)**、4択クイズの 型は **フリックパイロット(`pilot/`)** と かさなる。
⚠️ ほかの ゲームと ちがう 4つの 気をつけ:
① ⭐⭐⭐ **「犬が こわがっている サイン」を 教える ゲームは、子どもの 安全の ゲームでも ある**。かまれる 事故の 多くは「犬が 何度も 出していた やめて の サイン」を 人が 読めなかった ときに 起きる。だから **「やめて」の サイン(カーミングシグナル)を いちばん 大事な 旅**に する。⚠️ **でも こわく 書かない**(「かまれる」「事故」の 字は `BAN`。「犬が 安心する / 人も 安心」の 向きで)
② ⭐⭐ **「◯◯犬は ◯◯な 性格」と 決めつけない**(血液型占いと 同じ)。犬種の ちがいは **体の つくり・もともとの 役目**まで。「この 犬種は かむ」「この 犬種は おとなしい」は 書かない。**気持ちは 1匹ずつ ちがう**と くりかえす
③ ⭐⭐ **科学で たしかめられた ことと 言い伝えを 分ける**(心理学ゲームと 同じ)。「しっぽを ふる = うれしい」は **半分 まちがい**(ふりかたで ちがう)、「目を そらす = 反省」は **まちがい**(落ちつかせようと している)、「おなかを 見せる = なでて」も **ときどき ちがう**(こわくて 降参)。**よく 言われる こと**と **研究で わかった こと**を 札で 分ける
④ ⭐ **しつけは「ほめて のばす」だけ**。たたく・どなる・おさえつける・首輪で ひっぱる などの 罰の 方法は **1つも 書かない**(名前も 出さない)。動物愛護の 決まりとも 合う。**人も 犬も いやな 思いを しない やりかた**だけ

## 3. ⚠️⚠️⚠️ ぜったいの 決まり(獣医師・心理学と 同じ + この ゲームだけの もの)
- ⭐⭐⭐ **こわく しない**。「やめて」の サインの 旅は 子どもの 安全の 旅でも あるが、**「かまれる」「事故」は 1度も 書かない**(`BAN`)。書くのは「犬が 安心する / 人も 安心」「犬が やめてと 言っている」
- ⭐⭐⭐ **決めつけない**。「◯◯犬は ◯◯」「この しぐさ = かならず ◯◯」と 書かない。`kimochi` の 欄は **「たぶん」「ことが 多い」**を 付ける。画面の いちばん下に 1行「犬の 気持ちは 1匹ずつ ちがいます。この ゲームは 読みかたの ヒントです」
- ⭐⭐ **科学と 言い伝えを 分ける**(`kagaku` の 札)。⭐ しっぽ・おなか・目そらし・アルファ理論・「手を かがせる」は **かならず 付ける**
- ⭐⭐ **罰の しつけは 名前も 書かない**(④)。「ほめて のばす」だけ。**「しかる」は「ほめる との ちがい」の 説明に 1語だけ**
- ⭐ **知らない 犬に さわる 練習を 書かない**。`renshu` は **家の 犬 / はなれて 見る / 動画** の 3つの 形だけ。知らない 犬は「飼い主に 聞く」が 入口
- ⭐ **病気は 獣医師ゲームの 線**(こわい ようす・薬の 名前と 量は 書かない。「ようすが ちがったら 獣医さんへ」まで)
- ✅ **獣医師・心理学と 同じ 語を 入れて よい**。説明は **犬の 気持ちの 目線**で 書きなおす
- **読みは この ゲームの 9つの 旅の 中では かぶらない**(`terms_js.py`)。**先に 9つの 旅の 語の 一覧を 1人の 助手に 作らせて** 置き場所を 決める(`shigusa` と `yamete`(あくび・目そらし)、`kurashi` と `shitsuke`(トイレ・クレート)、`karada` と `kenshu`(大型・小型)が かさなりやすい。⭐ **やめての サインは `yamete` に 寄せる**)
- **カタカナ語を ならべない**。**ふつうの 言葉で 言いかえて から** 専門の 名前(「カーミングシグナル = 犬の『落ちついて』の 合図」)
- **別の 助手が 1語ずつ 確かめる**(意味・読み・**科学の 札が 合っているか**・**決めつけが ないか**・**こわく ないか**・**罰の 方法が まぎれていないか**・写真が その 犬種か)。手紙の 20枚は **1枚ずつ「こうして あげよう」が はなれる・そっと・ほめる・待つ の どれかか**を 見る
