# フリック犬の気持ち: ことばの 作りかた(助手に 分けて 頼むときの 決まり)

けいくん 2026-10-23「新しいセッションで フリック犬の気持ちを作成したい。**犬の気持ちがわかるように なるために必要な知識**をフリック形式の問題にしてください」
→ 同日「犬種と歴史を増やして トイプードルを入れてください」「しつけも増やしてください」→ 5つの 問いに「全部おすすめ」。
まとめは `docs/フリック犬の気持ち-はじめかた.md`。もとは `tools/mentalist/PROMPT.md`(実践の 型)・`tools/jui/PROMPT.md`(動物の 書きかた)・`tools/shinri/PROMPT.md`(科学と 言い伝え)

## ⚠️⚠️⚠️ いちばん 大事な 4つの 決まり(さいしょに 読む。けいくんの OK を もらった 約束)
1. **こわく しない**。「やめて」の サインを 教える この ゲームは 子どもの 安全の ゲームでも あるが、
   **「かまれる」「事故」「けが」「死」は 1度も 書かない**(台本が 止める)。書くのは「犬が 安心する / 人も 安心」「犬が『やめて』と 言っている」「そっと はなれよう」
2. **「◯◯犬は ◯◯な 性格」と 決めつけない**(血液型占いと 同じ)。犬種の ちがいは **体の つくり・もともとの 役目**まで。
   「この 犬種は おとなしい / かしこい / がんこ / かみやすい」は 書かない。**気持ちは 1匹ずつ ちがう**。
   もともとの 役目は「牧羊犬だった → 動く ものを 追いかけたがる 子も 多い」の 形(「多い」「〜も いる」)。「危険犬種」「闘犬」は 書かない
3. **科学で たしかめられた ことと 言い伝えを 分ける**。語に `kagaku`(🔬 かがく)の 札を 付ける:
   `kenkyu`=研究で わかっている / `iitsutae`=よく 言われるが たしかめられていない / `furui`=むかしの 考え。いまは ちがう / `kenkyuchu`=研究中(まだ はっきり しない)。
   ⭐ **しっぽ(ふる = うれしい は 半分 まちがい)・おなかを 見せる(2つの 意味)・目を そらす / 反省の 顔(反省では なく 落ちつこうと している / 人の 反応に 合わせている)・アルファ(ボス)理論(furui)・手を かがせる(見なおされている)** には かならず 付ける
4. **しつけは「ほめて のばす」だけ**。たたく・どなる・おさえつける・首輪で ひっぱる などの 罰の 方法は **1つも 書かない(名前も 出さない)**。
   困りごとの なおしかたは **「ほめる・環境を 整える・代わりの 行動を 教える・少しずつ 慣らす」の 4つ**の どれか。
   「しかる」は「ほめる との ちがい」の 説明に 1語だけ(うち消しと いっしょに)。「できない ときは かんたんな 段に もどる」。「もっと きびしく」は 書かない

## そのほかの 決まり
5. **知らない 犬に さわる 練習を 書かない**。`renshu` は **家の 犬 / はなれて 見る(散歩中の 犬・公園)/ 動画** の 3つの 形だけ。知らない 犬は「飼い主に 聞く」が 入口
6. **病気は 獣医師ゲームの 線**: 病気の こわい ようす・薬の 名前と 量・正常値・寿命は 書かない。「ようすが いつもと ちがったら 獣医さんへ」まで。
   食べては いけない もの(玉ねぎ・チョコレート・ぶどう・キシリトール)は「犬の 体に 合わない 成分が ある。食べたら すぐ 獣医さんへ」まで
7. **入れない もの**: ペットショップ・値段・ブリーダーの 話 / 商品名(フード・おもちゃ)/ 実在の 動物病院・トレーナー・団体の 宣伝 / 特定の 犬種を わるく 言う 書きかた /
   けが・病気・おりの 中の 話 / 実在の 有名な 犬の 私生活(ハチ公・タロと ジロ・バルト などの 名前と 事実は よい。いのちの 終わりの 話は 書かない)/ 存命の 研究者・トレーナーの 名前(考えだけ 書く。**トゥーリッド・ルーガスは カーミングシグナルの 名づけ親 として 1語だけ よい**)
8. **自分の ことばで 書く**。本・サイト・Wikipedia の 文を 写さない。数字は まちがいない ものだけ(下の「確かめた 事実」= WRITER.md)
9. **カタカナ語を ならべない**。ふつうの 言葉で 言いかえて から 専門の 名前(「カーミングシグナル = 犬の『落ちついて』の 合図」)

## ゲームの かたち
「表示された ひらがなを フリックで 打ち写す」タイピング。打ち終わると ことばの 説明(1〜3文)が 出る。遊ぶのは 小学生〜大人。
**この ゲームは「ことばを おぼえる」で 終わらせない。遊んだ 子が きょう 家の 犬(または 散歩で 会う 犬)の 気持ちを 1つ 読めて、1つ やさしく できる ように する**。
だから ほぼ 全部の 語に **🎯 やってみよう(renshu)** を 付ける

## 1語の 形(JSON)
{"id":"sg-tail-high","name":"しっぽが 高い","reading":"しっぽがたかい","journey":"shigusa","category":"しっぽ","difficulty":1,"type":"concept",
 "emoji":"🐕","mapNode":"shigusa:tail","field":"しぐさ","relatedTerms":["sg-tail-low","sg-wag-fast"],
 "description":"しっぽを いつもより 高く 上げている ようすです。気持ちが 高まって いる ことが 多く、うれしい ときも、まわりを 気に している ときも あります。しっぽの 高さは 犬種で ちがうので、その 犬の ふだんの 高さと くらべます。",
 "kimochi":"(しぐさ・声・やめての 語に)たぶん 気持ちが 高まって いる。うれしいか、気を はって いるかは 体 ぜんぶで 見る",
 "kagaku":"(任意)kenkyu / iitsutae / furui / kenkyuchu",
 "kagakuNote":"(kagaku を 付けたら なるべく)1文: 何が わかっていて 何が まちがいか",
 "renshu":"(⭐ できるだけ 全部)家の 犬の しっぽの ふだんの 高さを、朝・夕方・ごはんの 前の 3回 見てみよう。犬が いなければ 散歩中の 犬を はなれて 見よう。",
 "breed":"(犬種の 語だけ){\"kuni\":\"フランス\",\"group\":\"愛玩犬\",\"size\":\"超小型\",\"yakume\":\"もとは 水辺で 鳥を 回収する 猟犬の なかま\"}",
 "ei":"(英語から 来た 語・犬種だけ)Toy Poodle"}

- id: 旅の 頭文字 + "-" + 英小文字(sg- / nk- / ym- / kr- / st- / km- / kd- / ks- / rk- / az- / kk-)。英小文字・数字・- だけ
- name: 画面に 出す 名前(ふつうの 言いかた)
- reading: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白は ダメ)。英語・犬種は ふだんの カタカナ読みを ひらがなで(といぷーどる)。
  ゆれる ことばは 1つに 決め、別の 読みは "acceptedReadings":["よみ1","よみ2"](先頭は reading と 同じ)。⚠️ **読みは この ゲームの 11の 旅の 中で かぶらない**。読みは 20字まで
- difficulty: 1 = **入門(きょう 家の 犬を 1つ 読める)** / 2 = **中級(犬と 気持ちよく くらせる)** / 3 = **上級(犬の 専門家の 入口)**
- type: いつも "concept"
- category: 図鑑で しぼる 分類(短い 日本語。旅の 中で 4〜8種類)
- emoji: 1つ。⚠️ 😱 💀 🩸 🔪 💉 ⛓ など こわい・けが・注射の 絵文字は 使わない
- mapNode: その 旅の 図の 場所(下の 表から)
- field: **しぐさ / 声 / やめて / くらし / しつけ / 困りごと / 体 / 犬種 / 歴史 / 安全 / こころ** の どれか(ふつうは 旅と 同じ。ほかの 旅の 目線の 語は その field でも よい)
- relatedTerms: **同じ ファイルの 中の** id を 1〜3個(自分は ダメ)
- description: 1〜3文・**130字以内**。やさしい です・ます。**語と 語の あいだに 半角スペース**を 入れる 書きかた(上の 例のように)。
  **犬の 気持ちの 目線**で 書く(獣医師・心理学と 同じ 語でも 書きなおす)。⭐ ときどき「へえ」と 思える 事実を 1文(⚠️ 頭に「へえ:」とは 書かない)
- kimochi(💭 きもち): **しぐさ・声・やめての 語には かならず**、ほかの 旅でも 犬の 気持ちに かかわる 語には なるべく。1文・70字以内。
  ⚠️ **「たぶん」「ことが 多い」「〜かも」を かならず 入れる**(台本が 見る。1匹ずつ ちがうため)
- kagaku / kagakuNote(🔬 かがく): 上の 3。kagakuNote は 1文・70字以内
- renshu(🎯 やってみよう): ⭐⭐ **できるだけ 全部の 語に**。1〜2文・90字以内。「きょう できる 観察・練習」。
  ⚠️ **犬が いない 子**のために「散歩中の 犬を はなれた ところから 見てみよう」「動画で 見てみよう」の 形も まぜる(旅の 3分の1 くらい)。⚠️ 知らない 犬に さわる 練習は 書かない
- breed(🐕 犬種の 札): **犬種の 語だけ**。kuni(原産の 国。説が 分かれる ときは「フランス・ドイツ(説が 分かれる)」)・
  group(次の どれか: 牧羊犬・牧畜犬 / 使役犬 / テリア / ダックスフンド / スピッツ・原始的な 犬 / 嗅覚ハウンド / ポインター・セター / レトリーバー・水の 犬 / 愛玩犬 / 視覚ハウンド / 日本犬 / ミックス / グループに 入っていない)・
  size(超小型 / 小型 / 中型 / 大型 / 超大型 / 大きさ いろいろ)・yakume(もともとの 役目。⚠️ 性格は 書かない)。
  ⚠️ group は FCI の 10グループの 分けかたを 子どもの ことばに した もの(柴犬などの 日本犬は「スピッツ・原始的な 犬」の なかまだが、日本の 6犬種は group を「日本犬」に して よい)
- ei: 英語の 語・犬種だけ(任意)。英語の つづり(例 "Toy Poodle" / "calming signals")。🔊 で 英語の 音が 聞ける
- example: なくてもよい

## 旅ごとの 語数(1回目 = phase 1 / 2回目 = phase 2)
| 旅 | ぜんぶ(入門/中級/上級) | 1回目(入門/中級/上級) |
|---|---|---|
| shigusa・nakigoe・yamete・kurashi・karada・rekishi・anzen・kokoro | 110(30/40/40) | 70(20/25/25) |
| komari | 120(30/45/45) | 70(20/25/25) |
| kenshu・shitsuke | 150(50/50/50) | 100(30/35/35) |
**1回目 830語 / ぜんぶ 1,300語**。同じ difficulty の 中は 有名な・大事な 順。2回目は うしろに 足す(前の 語の 順番・中身は 変えない)。
⭐ **kenshu の いちばん 最初の 語は トイプードル**(日本で いちばん 多く 登録される 犬種)。

## 旅と 旅の さかいめ(読みが かぶりやすい ところ)
- **やめての サインは `yamete` に 寄せる**(あくび・鼻を なめる・目そらし・横を 向く・かたまる)。`shigusa` は しっぽ・耳・目・口・重心・毛・プレイバウ・おなか
- トイレ・クレート: **教えかたは `shitsuke`、くらしの 決まり(場所・数・かたづけ)は `kurashi`**
- ほえる・引っぱる: **教える 手順は `shitsuke`、理由と なおしかたは `komari`**。「ほえる(声の 種類)」は `nakigoe`(読みは かえる: 例 ほえる / ほえるりゆう / むだぼえ)
- 大型・小型: **体の しくみの ちがいは `karada`、犬種の 大きさ分けは `kenshu`**
- 盲導犬・そり犬: **犬種は `kenshu`、しごとは `rekishi`**
- 知らない 犬・あいさつの しかた: `anzen`。犬どうしの あいさつ(おしりを かぐ)は `nakigoe`
- 心理学(`shinri`)・獣医師(`jui`)と 同じ 語を 入れて よい(けいくん決定「復習になる」)。説明は **犬の 気持ちの 目線**で 書きなおす
