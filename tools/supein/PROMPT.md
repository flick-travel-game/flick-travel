# フリックスペイン語: ことばを 作る 決まり

子ども(小学生)〜大人が、**スペイン語を 見て 🔊 で 聞きながら、読みの ひらがなを フリックで 打つ** ゲーム
(「⌨️ 打ちかた」で ABC に すると スペイン語の つづりを 打つ。アクセント記号は 打たなくても 正解)。
打ち終わると「日本語の 意味・例文」が 出る。**ネイティブが ふだん 使う ことば・文法・活用・言いまわしを ひととおり 知る** のが ねらい。
⚠️ 「勉強っぽさ」は 出さない(DELE・検定・学年・「〜級」などの ことばは 書かない)。

## 出力(JSON の 配列だけ。指示された ファイルに 書く)

### ことば(単語の 旅・発音の 旅)
```json
{"text":"el libro","pos":"名詞","meaning":"本","emoji":"📕","category":"学校・勉強","example":"Leo un libro.","exampleJa":"本を読みます。","note":"男性名詞。英語の library(図書館)と なかま","difficulty":1}
```
### 文・フレーズ(文法と活用・日常会話・ネイティブの表現)
```json
{"text":"¿Cuánto cuesta esto?","meaning":"これはいくらですか?","scene":"shop","style":"usted","who":"お店の人に","reply":"Cuesta cinco euros.","replyJa":"5ユーロです。","tip":"指さして使える","difficulty":1}
```

### 各項目
- **text**: 画面に 出す スペイン語。**アクセント記号(á é í ó ú ñ ü)と ¿ ¡ を かならず 正しく**(RAE の 今の つづり。solo・este に 記号は つけない)
  - 単語: **名詞は かならず 冠詞を つける**(el libro / la mesa / los zapatos。性が 2つ ある 語は el estudiante など ふつうの 形)。動詞は 原形(-ar / -er / -ir)、形容詞は **男性形単数**。**24字まで**
  - 文: **40字まで**(空白・記号も 数える)。使える 記号は 空白 . , ? ! ¿ ¡ だけ(数字・かっこ・〜・「」は なし。数は 文字で: cinco euros)
  - 打つ ゲームなので、なるべく 短く 自然に
- **pron**(なくてよい・ほとんど 書かない): ゲームは text から 読みの ひらがなを **自動で** 作る(つづりどおりに 読む)。
  **つづりと 読みが ちがう 語だけ**、読みどおりの スペイン語の つづりを 書く(例: pizza → "pitsa"、sándwich → "sanguich"、hockey → "jokei")。
  México・mexicano・Oaxaca の x は 自動で は行に なる(書かなくてよい)。**ひらがなは 書かない**
- **meaning**: 日本語の 意味(単語は 20字まで・文は 30字まで)。辞書を 写さず 自分の ことばで
- **emoji**: 合う 絵文字 1つ(❔ は 使わない)
- **pos**(単語だけ): 名詞 / 動詞 / 形容詞 / 副詞 / 代名詞 / 数詞 / 前置詞 / 接続詞 / 感動詞 / 冠詞 / 表現 の どれか(ことわざ・慣用句は 表現)
- **category**(単語・発音・文法・ネイティブ): 指示された 分類から 1つ
- **scene**(日常会話だけ): 指示された 場面の id
- **style**(文だけ。かならず): その 文の 話しかけかた = `tú`(友だち・家族・年下に。ため口)/ `usted`(お店の人・年上・先生・知らない人に。ていねい)/
  `ustedes`(みんなに)/ `vosotros`(スペインで 友だち みんなに)/ `-`(だれかに 話しかける 形では ない。例: Hace calor.)
- **who**(文だけ。かならず): だれが だれに 言うか(15字まで)。例「店員さんに」「友だちに」「先生に」「お母さんが子どもに」。
  ⚠️ **お店の人・年上・先生・知らない人への 文は usted**。tú は 友だち・年下・家族だけ
- **region**(なくてよい): その 言いかたが **スペインで よく 使う**なら `ES`、**中南米で よく 使う**なら `LA`。どちらでも 通じるなら 書かない。
  ⭐ ちがう 言いかたが ある 語は note に もう一方を 書く(例: el coche(ES)の note「中南米では el carro」)。**どちらが 正しい とは 書かない**
- **example / exampleJa**(単語・発音): その 語を 使った 短い・自然な 例文(40字まで)と その 訳
- **reply / replyJa**(文): 相手が 言いそうな 返事(なるべく 入れる。40字まで)
- **note**(なくてよい): へえ に なる ひとこと(40字まで)。英語と にている 語は「英語の information と にている」の ように
- **tip**(文。なくてよい): いつ 使うか の ひとこと(25字まで)
- **difficulty**: 1 入門(発音が 読めて あいさつ)/ 2 初級(旅行で 困らない)/ 3 中級(友だちと ふつうに 話す。過去形・tú と usted)/ 4 上級(ネイティブ: 接続法・ことわざ・国ごとの 言いまわし・文化)

## ⚠️⚠️ ぜったいの 決まり
- **スペイン語は ネイティブが いま ふつうに 使う 形**。直訳・日本語の 語順を そのまま 置きかえた 文は ダメ。ふだんの 例文は **どこでも 通じる 形**(「あなたたち」は ustedes)
- **名詞の 性と、形容詞・冠詞の 性と 数を そろえる**(la casa blanca / los niños pequeños)。**動詞の 活用を 主語に 合わせる**
- **市販の 単語帳・DELE の 過去問・教科書の 文を 写さない**。例文・訳は ぜんぶ 自分で 書く
- 子どもが 見るので、**お酒(ワイン・サングリア・テキーラ・ビール)・たばこ・お金もうけ・こわい話・恋愛の 話**は 入れない。**闘牛は 入れない**。Te quiero は **家族に 言う 場面**なら よい
- **下品な 語・スラングの 悪口・からかいは 1語も 入れない**。⚠️ **国に よって 下品に なる 語は 入れない**(coger・concha・pisar・bicho・pinche・huevón・chingar・cachar など。**迷ったら 入れない**)。
  「つかむ」は agarrar / tomar、「バス」は el autobús で
- ⚠️ **アクセント記号を はずすと 子どもに 不向きな 語に なる 語は 入れない**(año → ano)。「年」は el año を 使わず 文の 中でも なるべく 別の 言いかたに(ゲームが 止める)
- **政治・歴史の あらそいの 話は 入れない**(内戦・独裁・植民地の よしあし・移民の 問題・国境)。**国や 人を 下げる 書きかたを しない**
- **実在の 芸能人・歌手・サッカー選手・クラブ・ドラマ・お店・会社・商品の 名前を 入れない**(「サッカー」「歌」「ドラマ」という ことばまでは よい)
- ✅ 食べもの・地名・行事の 名前は よい(パエリア・タコス・トルティーヤ・チュロス・マドリード・バルセロナ・メキシコシティ・ブエノスアイレス・フィエスタ・Día de Muertos(家族を 思い出す お祭り として))
- 人名を 使うなら Ana / Lucía / Pablo / Carlos / Sofía / Diego / Yuki / Ken くらい
- 同じ text を 2回 入れない(アクセント記号を はずして くらべる。ほかの 旅と かぶらないよう 指示された 一覧を 守る)
- 日本語は やさしく。小学生が 読める ていど(漢字は 使ってよい。あとで ふりがなを 付ける)。**日本語訳の 語の あいだに 半角スペースを 入れない**
- 「十分」(じゅうぶん と 読める)の ような 読みちがいを さける(→「10分」)
