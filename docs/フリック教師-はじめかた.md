# フリック教師(`kyoshi/`)を 作る ための まとめ(2026-09-30。新しい セッション用)

けいくん 2026-09-30「新しいセッションで フリック教師を作成したい。教師になれるレベルになるために必要な 知識をフリック形式の問題にしてください」

## 0. まず 読む もの(この 順で)
1. `CLAUDE.md`(この 入れものの 決めごと ぜんぶ。とくに **フリック保育士**・**フリック看護師** の 節)
2. `docs/フリック医師-はじめかた.md`(同じ日に 作った 兄弟の まとめ。型は 同じ)
3. `tools/hoiku/PROMPT.md`(ことばの 作りかたの 決まり。**教師は 保育士の を 土台に する**。保育士試験の 科目と 学校の 話が いちばん 近い)
4. `tools/hoiku/meta.json` / `tools/hoiku/terms-hoiku.json`(1語の 形の 見本)
5. `tools/build_games.py` の `"hoiku": dict(...)` の 段(ゲームの 登録の 形)
6. `kango/kango.js`(しくみ。**これを 写して `kyoshi/kyoshi.js` に する**。いちばん 新しい 写し元)

## 2. はじめに けいくんに 聞く 5つ(「全部おすすめで」と 返ってくる ことが 多い)
1. **名前**: 「フリック教師」で よいか(絵が 届いたら 絵の 題名に そろえる。フォルダ名 `kyoshi` は 変えない)
2. **旅の 分けかた**(おすすめ 7つ + 🏆 マスター):
   📚 教育の考えかた(教育の 目的・生きる力・主体的で 対話的な 学び・カリキュラム …)/ 🧠 子どもの心と育ち(発達段階・自己肯定感・動機づけ・愛着 …)/
   ✏️ 授業のつくりかた(学習指導要領・単元・めあて・発問・板書・評価・ICT …)/ 🏫 学級と学校のしくみ(学級経営・校務分掌・職員会議・PTA・学校行事 …)/
   🤝 支える指導(生徒指導・教育相談・特別支援・いじめ防止・不登校・スクールカウンセラー …)/
   ⚖️ 教育の法律と制度(教育基本法・学校教育法・教育委員会・教員免許・服務・守秘義務 …)/
   🌏 教育の歴史と世界(寺子屋・学制・ペスタロッチ・デューイ・モンテッソーリ・OECD の 学力調査 …)
3. **むずかしさの 3段**: 入門(学校で 聞く ことば)→ 中級(**教員採用試験の 教職教養の 範囲の めやす**)→ 上級(法律の 条文の 名前・こまかい 制度・教育史の 人物)
4. **1語に 持たせる 科目**(`field`): 教職教養の 大きな 分け(教育原理 / 教育心理 / 教育法規 / 教育史 / 教育時事 / 生徒指導・特別支援 の 6つ が めやす。**確かめてから 決める**)
5. **どの 学校の 先生か**: 小学校を 中心に、中学・高校に 共通する ことばも 入れる(教科の 中身(算数・国語 …)は 入れない。それは 数学旅行・国語旅行 の 役目)

## 3. ⚠️⚠️⚠️ ぜったいの 決まり
- ✅ **ほかの ゲーム(保育士・看護師・からだ旅行 など)と 同じ 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」。医師と 同じ)。
  ただし 説明は **教師の 目線**で 書きなおす(保育士の 文を そのまま 写さない)
- **読み(ひらがな)は 教師の 7つの 旅の 中では かぶらない**(ほかの ゲームとは かぶって よい)
- **小学生も あそぶ**: いじめ・虐待・不登校・体罰 などの ことばは 入れて よいが、**「先生と 学校が どう 守るか・助けるか」の 書きかた**だけ。
  つらい ようす・こわい 先を 書かない(保育士の「助ける しくみ として 事実だけ やさしく」と 同じ)。**迷ったら その 語を 入れない**
- **政治・宗教・特定の 教育方法の よしあし**を 書かない(教育基本法の 中立の 決まりと 同じ)。人物は **何を した 人か**だけ
- **やりかたの 決めうち**を 書かない(「この 子は こう 指導する」「この ときは この 対応」)。**名前と 目的だけ**
- 画面(ホームの 下・遊びかた)に「これは ことばを おぼえる ゲームです。本物の 試験問題では ありません。文部科学省・教育委員会とは 関係ありません」
- **作った 助手とは 別の 助手が 1語ずつ 確かめる**(意味・読み・決めうきを 書いていないか・こわくないか)。ふりがなも 全語 見る(`tools/ruby_fix.json`)

## 4. 試験の 事実は **その日に 文部科学省・都道府県教育委員会の ページで 確かめてから** 書く
`meta.json` の `exam` に 確かめた 日を つける。書く 中身(すべて 確かめる。**記憶で 書かない**):
教師に なる 道(大学で 教職課程 → **教員免許状**(普通免許状は 専修・一種・二種)→ **教員採用試験**(都道府県・政令市ごと))/
免許は 都道府県教育委員会が 出す / 採用試験の 中身(教職教養・一般教養・専門教養・論文・面接・模擬授業 など。**自治体で ちがう** と 書く)/
教員免許更新制は **2022年7月に 廃止** → 研修の 記録に 変わった(確かめる)/ 学習指導要領の いまの 版(小中は 2017年 告示・高校は 2018年 告示。**次の 改訂の 動きも 確かめる**)/
教員採用試験の 早期化(文部科学省が 6月ごろの 実施を すすめている 動き。確かめる)

## 5. 作りかたの 手順(看護師・医師の まとめと 同じ)
1. けいくんに 2 の 5つを 聞く → 返事を CLAUDE.md に 書く
2. `tools/kyoshi/PROMPT.md` `meta.json` を 作る → 旅ごとに 助手に 70語ずつ 頼む(`PROMPT.md` を そのまま わたす)→ `terms-<旅>.json`
3. `terms_js.py` で 止められた 語を 直す → 別の 助手が 1語ずつ 確かめる → ふりがな
4. `kyoshi/kyoshi.js`(kango.js を 写す)・`build_games.py`・`index.html` の SERIES → `python3 tools/build_games.py`
5. 手元で 通す: `python3 -m http.server 8765` → `node tools/play-all.mjs`(4とおりの 打ちかた)/ `node tools/click-all.mjs`(W=320 も)
6. PR は **rebase で 取りこむ**(この 入れもの)。speed-king は squash。コミットの 末尾は Co-Authored-By と Claude-Session の 2行
7. かずとも `speed-king`: `FLICK_MODES` / `FLICK_LINK_TARGETS` に `kyoshi`(PR → squash)。`HOME_GAMES` は 絵と OK の あと
8. けいくんに ChatGPT で 絵を 頼む 文を わたす(トップ 1536×1024 + 四角い 絵 1254px。**人物は 画面の 下 3分の1に 小さく**・指5本・首が 見える。
   絵の 中の 字は「フリック教師」だけ・ゲームに 無い 機能の 絵を 入れない)。届いたら **まず 字を 切り出して 読む**(「ごっかしけん」の 前例)
9. 絵を 入れたら CLAUDE.md に 節を 書く(名前・旅・語数・確かめた 日・入れなかった 語と 理由)

## 6. 気をつける 前例
- 看護師で 統合失調症 → 適応障害に 入れかえた(子どもが こわく 感じる)。教師でも 同じ 目で 見る(虐待・自殺 などの 語の 書きかた)
- 読みの かぶりは 片方を べつの 語に
- 絵は 1回目・2回目とも 字が ちがった → 絵の 中で 直した(`tools/kango/fix_text.py`)
- マイページ(右上の 1枚)は 土台の `index.html` に あるので、`SERIES` に 足すだけで 一覧の タイルにも 出る(絵は `kyoshi/apple-touch-icon.png`)
- 医師(`ishi/`)と 同じ日に 頼まれた。**2つ 同時に 作るなら フォルダ・id・modes 名を まぜない**(`ishi` / `kyoshi`)
