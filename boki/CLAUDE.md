## フリック日商簿記(`boki/`。けいくん 2026-11-07「フリック日商簿記を 3級から1級まで 合格レベルで」→ 6つの 問いに「ぜんぶ おすすめで」。まとめは `docs/フリック日商簿記-はじめかた.md`)

- 決まった こと(けいくん 2026-11-07):
  1. 名前は「**フリック日商簿記**」。画面に「**日本商工会議所とは 関係ありません**」。フォルダ `boki`・modes `BOKI`・シリーズの 絵文字 📒。
     かずともの 旅の 名前は **`bz` で はじめる**(⚠️ `bk` は 美容師)
  2. 旅は **級ごとに 9つ + 🏆 マスター**: 3級(📒 簿記の きほん `kihon` / 🧾 3級の 取引 `3shiwake` / 📊 3級の 決算 `3kessan`)→
     2級(🏢 2級の 商業簿記 `2shogyo` / 🌐 2級の 会社の 会計と 連結 `2kaisha` / 🏭 2級の 工業簿記 `2kogyo`)→
     1級(📚 1級の 商業簿記 `1shogyo` / 📖 1級の 会計学 `1kaikei` / ⚙️ 1級の 工業簿記・原価計算 `1genka`)
  3. むずかしさの 3段 = 入門 3級 / 中級 2級 / 上級 1級
  4. 分野(`field`)は 日本商工会議所の **出題区分表**の 分け
  5. 入れない もの: 実在の 会社の 数字・株価 / 節税の テクニック / 粉飾・脱税の やりかた(名前と「してはいけない」まで)/ 過去問・市販の 問題集の 写し / 会計ソフトの 名前 / 合格率を 決まった 数として
  6. ⭐ **❌ まちがえた 問題の 復習を 入れる**(運転免許・宅建士に つづく **3つめの 例外**)。⚠️ ほかの ゲームに 広げない
  7. ⭐ **範囲は 2027年度版の 出題区分表(2027年4月1日から)**(けいくん決定 2026-11-07。確かめた 事実は `tools/boki/facts.md`)。手形は 範囲外・定率法 / 除却 / 廃棄は 3級・2級の リースは 使用権資産 / リース負債・2級 以上の 家賃は 支払リース料

- ⭐⭐ **試験の ための しくみ**(`boki/boki.js`。宅建士 `takken.js` を 写した):
  ・**🧾 仕訳クイズ 1,500問**(`tools/boki/shiwake-<旅>.json`。決まり `SHIWAKE.md`)。① 借方・貸方の 勘定科目の くみあわせ → ② 金額 の 2段。まちがいの 科目は `ng`(正しい 科目と 入れかえる)、まちがいの 金額は `wa`(3つ)。答えたら T字の 形で 正しい 仕訳
  ・**🧮 計算問題 54しゅるい**(`tools/boki/calc.js` → `boki/calc.js`。数字が 毎回 かわる 4択・とき方つき)。確かめ `node tools/boki/calc_check.mjs`(1しゅるい 3,000回)
  ・**📝 ⭕❌ 600問**(`maru-<旅>.json`。決まり `MARU.md`。1級の 会計学が 180問)
  ・**🎯 級ごとの 模擬テスト**: 3級 = 仕訳 15問(3点)+ 計算 11問(5点)・60分 / 2級 = 商業簿記 + 工業簿記・90分 / 1級 = 「商業簿記・会計学」と「工業簿記・原価計算」の 2つの 時間(90分ずつ)。1級は 2つの 点を あわせて「70% 以上・1科目でも 40% 未満は 不合格」。⚠️ 問題の 数と 点は この ゲームの 形(`mkmeta.py` の `MOCK_LAYOUT`)。時間・合格の めやすは `mock.json`(確かめた 事実)。⚠️ **総合問題(精算表・財務諸表)は ゲームでは できない**と 画面に 書いた
  ・⭐ **❌ まちがえた 問題**(`flick-boki-miss`。⭕❌・仕訳・計算。2回 つづけて 正解で 消える。計算は 同じ しゅるいを 新しい 数字で)
  ・**🎓 級の 切りかえ**(3級だけ / 2級だけ / 1級だけ / 2級まで。`flick-boki-grade`)。図鑑は 📝 科目・🎓 級で しぼれる
  ・ホームに **📊 簿記の 図**(`<details>`): T字勘定・5つの 箱・取引から 決算書まで・精算表の 形・貸借対照表と 損益計算書・原価の 流れ・CVP・連結
