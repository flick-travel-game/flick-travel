# フリック教師: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
教職教養の どの 科目か・しくみ図の どこに あるか(📍)が 出る。あそぶのは **小学生〜先生を めざす 中高生・大学生・大人**。
**学校の 先生に なるための ことばと 意味を おぼえる ゲーム**(採用試験の 問題集でも、指導の 手引きでも ない)。
もとは `tools/hoiku/PROMPT.md`(保育士)と `tools/ishi/PROMPT.md`(医師)。
けいくん 2026-09-30「教師になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 4つ

### 1. 小学生も あそぶ(いちばん 大事)
- いじめ・虐待・不登校・体罰・差別 などの ことばは **入れて よい**。ただし **「先生と 学校が どう 守るか・助けるか」の しくみ** として、
  **事実だけを やさしく**(例: いじめ防止対策推進法 = いじめから 子どもを 守るために、学校や 先生が することを 決めた 法律)
- ❌ **書かない**: つらい ようす・こわい 先(「こう なって しまう」)・数の 多さで こわがらせる 書きかた・
  「あなたの まわりにも ある」と 思わせる 書きかた・子どもや 親を せめる 書きかた
- 読んだ 子が **「自分は だいじょうぶ」「助けてくれる 大人が いる」と 思える** 書きかたに する。**迷ったら その 語を 入れない**
- **「自殺」「死亡」「亡くなる」「殺」「暴力の ようす」は 使わない**(台本が 止める)

### 2. やりかたを 決めうちで 書かない
- ❌ 「この 子には こう 指導する」「こういう ときは こう 対応する」「こう すれば かならず うまく いく」
- ⭕ その ことばが **何を さすか**・**何の ために あるか**・どこで 出てくるか。**名前と 目的だけ**
- 法律は **法律の 名前と、何を 決めた 法律か** まで。**条文を 写さない**(やさしく 言いかえる)。
  条の 番号は、よく 知られていて まちがいない ものだけ(教育基本法 第1条 = 教育の 目的 など)。まよったら 書かない

### 3. かたよらない(教育基本法の 中立と 同じ)
- **政治・宗教・特定の 教育方法の よしあし**を 書かない。「◯◯主義は よい / わるい」と 言わない
- 人物は **何を した 人か・何を となえた 人か** だけ(「〜を となえた」「〜と 考えた」の 形)
- 日の丸・君が代・道徳の 教科化 など 意見が 分かれる 話は 入れない(入れるなら しくみの 名前だけ。**迷ったら 入れない**)

### 4. 教師の 目線で 書く(保育士・社会 など ほかの ゲームと 同じ 語を 入れて よい)
- ✅ **ほかの ゲームと 同じ ことばを 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)
- ⚠️ ただし 説明は **学校の 先生の 目線**で 書きなおす(保育士の 文を 写さない)。
  例: 愛着 … 保育士「赤ちゃんと おうちの 人の 心の きずな」/ 教師「安心できる 大人との きずな。学校でも 先生が 安心の 土台に なれる」
- **読み(ひらがな)は 教師の 7つの 旅の 中で かぶらない**(台本が 止める)。下の「旅ごとに 入れる / 入れない」を 守る
- **教科の 中身(算数の 計算・国語の 文法 など)は 入れない**(数学旅行・国語旅行の 役目)。入れるのは **教えかた・学校・子どもの ことば**
- 学校は **小学校を 中心に、中学・高校にも 共通する ことば**

## 1語の 形(JSON)

```json
{"id":"jg-hatsumon","name":"発問","reading":"はつもん","journey":"jugyo","category":"授業の進めかた","difficulty":2,
 "field":"教育原理","type":"concept","emoji":"❓","mapNode":"kyoshitsu:hatsumon","relatedTerms":["jg-meate"],
 "description":"授業の 中で 先生が 子どもに 考えて もらう ために する 問いかけ。答えを 聞くだけでなく、考えを 深める ための 問いです。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(学校・教育で ふつうに 使う 言いかた。漢字・カタカナ・英字の 略語)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白は ダメ)
  - カタカナ語は ひらがなに(かりきゅらむ)
  - 英字の 略語は 下の「略語の 読み」の とおり。ない ものは 日本の ふつうの 読み
  - 数字は ひらがな(6・3・3制 → ろくさんさんせい)
  - ゆれる ことばは 1つに 決め、別の 読みは `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は **上級だけ**に、旅で 1〜2語まで。長い 法律は 短い 呼びかたに
    (例: ×「義務教育の段階における普通教育に相当する教育の機会の確保等に関する法律」→ ○「教育機会確保法」)
  - ⚠️ **読みを まちがえやすい ことば**(校務分掌 こうむぶんしょう・服務 ふくむ・懲戒 ちょうかい・分限 ぶんげん・
    教諭 きょうゆ・学齢 がくれい・就学 しゅうがく・発問 はつもん・板書 ばんしょ・単元 たんげん・
    寺子屋 てらこや・藩校 はんこう・学制 がくせい・教育勅語 きょういくちょくご・昌平坂学問所 しょうへいざかがくもんじょ・
    内発的動機づけ ないはつてきどうきづけ・自己効力感 じこうりょくかん・輔導 は 使わない)は **1語ずつ 確かめる**
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級(下の「3段の 分けかた」)
- **field**: 教員採用試験の **教職教養の 大きな 分け**。つぎの 6つの どれか(入門の 語でも いちばん 近い ものを 書く):
  `教育原理` `教育心理` `教育法規` `教育史` `教育時事` `生徒指導・特別支援`
  - めやす: 教育の 目的・学習指導要領・授業・評価・学級経営・学校の しくみ → `教育原理` /
    発達・学習の しくみ・動機づけ・心理学者・心の テスト → `教育心理` /
    法律・制度・教育委員会・免許・服務 → `教育法規` / 日本と 世界の 教育の 歴史・人物 → `教育史` /
    いま すすんでいる 政策・答申・GIGAスクール・働き方改革・国の 計画 → `教育時事` /
    生徒指導・教育相談・いじめ防止・不登校・特別支援教育・インクルーシブ → `生徒指導・特別支援`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(こわい 絵文字(💀 ☠️ 🔪 🩸 👊)は 使わない)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / どこで 出てくるか / なぜ 大事か」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  専門用語を 専門用語だけで 説明しない。「1人」「2人」は ふりがなが 読みまちがえるので **ひとり・ふたり** と ひらがなで 書く
- **example**: なくてもよい

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | 学校で 聞く ことば。小学生でも 聞いた ことが ある / 絵が うかぶ(時間割・学級会・通知表・運動会・保健室・校長) |
| 2 | 中級 | **教員採用試験の 教職教養の 範囲の めやす**。教職課程で 学ぶと 出てくる ことば(学習指導要領・発問・形成的評価・校務分掌・教育委員会・ピアジェ) |
| 3 | 上級 | 法律の 名前・こまかい 制度・教育史の 人物・学説の めやす(地方教育行政法・分限・ヘルバルト・最近接領域・学校運営協議会) |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる
(ならんだ 順が そのまま ステージの 順に なる)。

## ぜったいに 守ること

- **自分の ことばで 書く**。過去問・問題集・教科書・生徒指導提要・法律の **本文を 写さない**
- **会社・塾・予備校・商品・教科書会社の 名前は 使わない**(商標)
- **数字は まちがいない ときだけ**(制度の「いつから」の 年は、確かに 知っている ものだけ。まよったら 書かない)
- 学者・歴史の 人の 話は **「〜を となえた」「〜と 考えた」「〜を 開いた」** の 形に
- 事実が あやしい 語は **入れない**(まちがいを 書くより 入れないほうが よい)
- 「100マス計算」「百ます計算」の 字を 使わない
