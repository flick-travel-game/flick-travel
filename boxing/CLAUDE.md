## フリックワールドボクシング(`boxing/`。けいくん 2026-10-12「ワールドボクシングの専門家(解説者)になれるレベルになるために必要な 知識、主要な団体、有名ボクシング選手、有名な技、ルールをフリック形式の問題にしてください」→ 5つの 問いに「すべておまかせ」。まとめは `docs/フリックワールドボクシング-はじめかた.md`)

- 名前は「フリックワールドボクシング」(絵が 届いたら 題名に そろえる。フォルダ名 `boxing` は 変えない)。シリーズの 絵文字は 🥊。`SERIES_ORDER` は **ベースボールの となり**
- 旅は 9つ(ボクシングのきほん `kihon`・ルール `rule`・世界の団体 `org`・階級と体重 `class`・いまのスター選手 `star`・伝説の選手 `legend`・技とテクニック `waza`・戦術と解説のことば `tactic`・世界の舞台と歴史 `cup`)+ マスター。
  **旅ごとに 70語(入門20・中級25・上級25)= 630語**。かずともの 旅の 名前は **`bx` で はじめる**(bxkihon / bxrule / bxorg / bxclass / bxstar / bxlegend / bxwaza / bxtactic / bxcup / bxmas)。
  ⚠️ はじめかたの 旅の 案では 団体と 階級が 1つの 旅(`org`)だったが、はじめかたの 名前の 一覧に `bxclass` が あったので **団体 `org` と 階級 `class` に 分けた**(17階級 + 体重 + 複数階級制覇 + オリンピックの 階級で 70語)
- むずかしさは 3段: 入門(ボクシングが すきな 小学生)→ 中級(ジムに 通う 人・ボクシング好きの 大人)→ 上級(解説者)。学ぶ 分野(`field`)7つ: ルール / パンチと防御 / 戦術 / 団体・階級 / 選手 / 大会・歴史 / 用具・練習
- ⭐ **国旗の 札**(`country` → `co`。31の 国・地域)と **⚖️ ルールの 札**(`ruleset` → `rs`。`プロ`(JBC・4団体)/ `アマ`(オリンピック・World Boxing)/ `共通`。「・」で 2つまで)。`rule` の 旅は 70語 ぜんぶに 付いている
- ことばは `tools/boxing/terms-<旅>.json`(決まりは `tools/boxing/PROMPT.md`)→ `tools/boxing/terms_js.py` → `boxing/terms.js` + `data/boxing.json`。しくみは `boxing/boxing.js`(ワールドベースボールを 写した)。図は `tools/boxing/mkmeta.py`(9つ。リングと ジムの 図・ルールの 地図・世界の 団体の 地図・**階級の はしご**・いまの スターの リング・伝説の 選手の 殿堂・技と テクニックの 道・作戦ボード・世界の 舞台と 歴史の 地図)
- ⚠️⚠️⚠️ **なぐられた 側の ようすを 1語も 書かない**。技は **出す 側の 動き**として だけ。ケガ・血・脳・意識・倒れた ようす・効く・ダメージは 台本 `BAN` が 止める。KO・TKO・ダウンは ルールの ことばの 意味だけ。名勝負は「名勝負の よび名」だけ(勝ち負け・相手の 名前を 書かない)
- ⚠️⚠️ **事件・逮捕・薬物・ドーピング・けんかで 知られる 人は 入れない**(けいくんの 「迷ったら 入れない」)。ボクシングは ここが とても 多く、書いた 助手と 確かめた 助手が **1人ずつ web で 調べて** 外した。
  一覧は `tools/boxing/exam.txt` の ⑩(マイク・タイソン・メイウェザー・カネロ・パッキャオ・マルシアノ・フォアマン・フレージャー・ハグラー・ハーンズ・カス・ダマト・クロフォード・ロマチェンコ・ガッツ石松・井岡一翔・寺地拳四朗・村田諒太・シャクール・スティーブンソン・ベテルビエフ・ダニエル・デュボア・ウシク など)。
  **説明の 中でも 名前を 出さない**(ピーカブー・フィリーシェル・フリッカージャブ・コークスクリュー・ボロパンチは 使い手の 名前なし)。よかれと 思って もどさない
- ⚠️⚠️ **いまの ベルト・戦績・無敗・防衛・ランキング・ファイトマネー・所属ジム・プロモーターは 書かない**(`STAR_BAN`)。いまの スターは「国・かまえ・異名・達成の 年・オリンピックの メダル」で 書く。`star` は 2026年10月に 現役と 確かめた 46人 + 異名 24語。⚠️ **計量・フェイスオフの もみあい・計量の 失敗・私生活の 報道も 外した**(ウシク・井上拓真・那須川天心・セラノ など。exam.txt ⑩ の いちばん下)。そのため 入門にも 少し 知られていない 名前が 入っている
- 事実は `tools/boxing/exam.txt`(→ meta.json の `exam`。meta に `rulesVersion` / `checkedOn` / `reviewEvery`)。**JBC と 4団体・World Boxing の 2026年の ルールで 確かめた(2026年10月12日)**:
  プロの 男子 世界戦は 3分 × 12ラウンド / JBC は 2016年から スリーノックダウン制 なし / IBF は 試合の 日の 朝に もう一度 はかる(リミットから 10ポンドまで)/
  アマ(World Boxing)は 3分 × 3ラウンド・5人の ジャッジ・10-7 まで・男子 エリートは ヘッドギア なし・女子は あり / World Boxing は 2023年 ローザンヌ・2025年に IOC が 仮に 認め、LA2028 で ボクシングを 行う(男子 7・女子 7階級)/
  4団体: WBA 1921年(NBA)・WBC 1963年 メキシコシティ・IBF 1983年 ニュージャージー・WBO 1988年 サンフアン / JBC 1952年・WBO と IBF に 2013年 加盟
- 書いた 助手(9人)とは **別の 助手(9人)が 1語ずつ 確かめた**。おもな 直し: 世界戦の 12回戦は「男子の」/ World Boxing は「仮に」認められた / フランチャイズ王者の 説明 / 15回戦 → 12回戦は WBC 1983年から / キンシャサの 奇跡などは「アリが 出た タイトルマッチ」(アリが 王者と 読めないように)/ 拳聖(ロビンソン)は 確かめられず 外した / 黄金のバンタムの ポルトガル語を 消した
- ふりがなは 確かめ役が `python3 tools/boxing/ruby_dump.py <旅>` で 全語 見た。`FIX` に 足した もの: 潤人(じゅんと)・月海(つきみ)・一発(いっぱつ)・2対1 の 対(たい)・手数(てかず)・両国(りょうごく)・原田(はらだ)。四すみ → よすみ・鏡・通る などは 文を 言いかえた
- **トップの 絵は 入れた**(2026-10-12。`boxing/hero.webp` 1536×1024・`hero=True`・`wordv` = 2)。けいくんの ChatGPT の 絵の **3回目**:
  1回目は 4択と「だうん」の 札に **たおれた 人**・本物の WBC に 似た 緑の ベルト・ゲームに 無い 札 13こ で 入れなかった。2回目は 「かうんと」の 札に まだ たおれた 人・札が ちがう 旅の 箱(⚠️ 5・6番は ぼくが 字だけ 入れかえさせた せい)・はんたむ・かんたー。
  3回目は 札 36こ ぜんぶ ゲームの その 旅に ある 読み。のこった ゜の まちがい 2つを **絵の 中で 直した**(`tools/boxing/fix_text.py`): はーどばんちゃー → はーどぱんちゃー / ちゃんびおんべると → ちゃんぴおんべると。
  ⚠️ 札の 地の 色は 白い ところだけで とる(上は 絵・下は 緑の ふちが かかる)。もとの 絵は 入れものに 入れていない。⚠️ 直す 文で「字だけ 入れかえて」と 頼む ときは **入れかえた 字が その 箱の 旅の ことばか**を 先に 見る
  人物は 大きな 男の子 1人(けいくん「絵は 変えないで」= この 絵の まま)
- **アイコンと 題名も 入れた**(2026-10-12)。アイコンは けいくんの 四角い 絵(1254px。男の子 1人)を 切らずに そのまま(`tools/boxing/art/square-src.png` → `python3 tools/icon_from_square.py boxing`。`iconv` = 2)。四角い 絵の 札にも ちゃんびおんべると・はーどばんちゃー の ゛゜の まちがいが あるが アイコンの 大きさでは 読めないので そのまま。
