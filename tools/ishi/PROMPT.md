# フリック医師: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
しくみ図の どこに あるか(📍)が 出る。あそぶのは **小学生〜医学部を めざす 中高生・医学生・大人**。
**医学の ことばと 意味を おぼえる ゲーム**(試験の 問題集でも、医療の 手引きでも ない)。
もとは `tools/kango/PROMPT.md`(看護師)。けいくん 2026-09-30「医師になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 3つ

### 1. やりかたを 書かない(いちばん 大事。医師は なおさら)
- ❌ **書かない**: 薬の 量・投与の しかた・注射や 手術の 手順・心臓マッサージの 回数や 深さ・
  「この しょうじょうなら この 病気」「こういう ときは こうする」の 言いかた・診断の 決めうち・**正常値の 数字**・薬の 商品名
- ⭕ **書く**: その ことばが **何を さすか**・**何の ために あるか**・どこで 出てくるか
  (例: 聴診 = 聴診器で からだの 中の 音を 聞いて、心臓や 肺の ようすを 調べる こと)
- **数字は なるべく 出さない**。制度で 決まっていて まちがいない もの(臨床研修は 2年 以上・医学部は 6年)だけ。まよったら 書かない
- 薬は **しゅるいの 名前と 目的だけ**(抗菌薬 = 細菌を やっつける くすり)。どの 病気に どれを 使うかは 書かない

### 2. 小学生も あそぶ
- 血・苦しむ ようす・死ぬ ようす・こわい 先(「この 病気に なると こうなる」)を **書かない**
- 病気は **「何が 起きている 状態か」+「お医者さんが 見つけて 助ける」** だけ
- **めずらしい 病気・こわい 病名の ならび**(がんの 種類の 名前・命に かかわる 病名の 一覧)は 入れない。
  「がん」「腫瘍」は **しくみの ことば**として 1〜2語だけ・おだやかに(早く 見つけて 治療する)
- 死に かかわる ことば(看取り・緩和ケア)は「その 人らしく すごせるように 支える」と おだやかに。
  **「死亡」「亡くなる」「脳死」「安楽死」「自殺」「虐待の ようす」は 使わない**
- 心の 病気は 子どもが 読んで こわく ならない ものだけ(看護師で 統合失調症 → 適応障害に 入れかえた 前例)
- 読んだ 子が **こわく ならない**・**「助けてくれる 人が いる」と 思える** 書きかたに する。**迷ったら その 語を 入れない**

### 3. 医師の 目線で 書く(からだ旅行・看護師と 同じ 語は 入れて よい)
- ✅ **からだ旅行・看護師と 同じ ことばを 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)
- ⚠️ ただし 説明は **医師の 目線**で 書きなおす(看護師の 文を 写さない)。
  例: 問診 … 看護師「患者さんの 話を 聞いて 看護に 生かす」/ 医師「病気の 手がかりを 集めて 診断を 考える 第一歩」
- **読み(ひらがな)は 医師の 7つの 旅の 中で かぶらない**(台本が 止める)。下の「旅ごとに 入れる / 入れない」を 守る

## 1語の 形(JSON)

```json
{"id":"sn-monshin","name":"問診","reading":"もんしん","journey":"shinsatsu","category":"話を聞く","difficulty":1,
 "field":"必修の基本的事項","type":"concept","emoji":"💬","mapNode":"shinsatsu:monshin","relatedTerms":["sn-shuso"],
 "description":"患者さんに いつから どこが どう つらいかを 聞く こと。病気の 手がかりを 集める、診察の 第一歩です。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(病院で ふつうに 使う 言いかた。漢字・カタカナ・英字の 略語)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白は ダメ)
  - カタカナ語は ひらがなに(れんとげん)
  - 英字の 略語は 下の「略語の 読み」の とおり。ない ものは 日本の ふつうの 読み
  - 数字は ひらがな(二次救急 → にじきゅうきゅう)
  - ゆれる ことばは 1つに 決め、別の 読みは `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は **上級だけ**に、旅で 1〜2語まで
  - ⚠️ **読みを まちがえやすい ことば**(打診 だしん・触診 しょくしん・聴診 ちょうしん・視診 ししん・既往歴 きおうれき・
    主訴 しゅそ・現病歴 げんびょうれき・鑑別診断 かんべつしんだん・予後 よご・寛解 かんかい・嚥下 えんげ・悪心 おしん・
    咳嗽 がいそう・喘鳴 ぜんめい・浮腫 ふしゅ・黄疸 おうだん・疼痛 とうつう・膠原病 こうげんびょう・塞栓 そくせん・
    梗塞 こうそく・潰瘍 かいよう・腫瘍 しゅよう・生検 せいけん・病理 びょうり・疫学 えきがく・
    罹患率 りかんりつ・有病率 ゆうびょうりつ・禁忌 きんき・頓服 とんぷく・輸液 ゆえき・輸血 ゆけつ・硬膜外 こうまくがい)は **1語ずつ 確かめる**
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級(下の「3段の 分けかた」)
- **field**: 医師国家試験出題基準(令和6年版)の 区分。つぎの 11の どれか(入門の 語でも いちばん 近い ものを 書く):
  `必修の基本的事項` `保健医療論` `予防と健康管理・増進` `人体の正常構造と機能` `生殖、発生、成長、発達、加齢`
  `病因、病態生理` `症候` `診察` `検査` `治療` `医学各論`
  - めやす: 医師の 心がまえ・医療面接・基本の 身体診察・救急の 初めの 対応 → `必修の基本的事項` / 法律・制度・保険・地域医療 → `保健医療論` /
    予防・健診・疫学・統計・母子・学校・職場・感染症対策 → `予防と健康管理・増進` / 妊娠・新生児・子ども・加齢 → `生殖、発生、成長、発達、加齢` /
    炎症・感染・免疫・腫瘍・循環障害 → `病因、病態生理` / しょうじょうの ことば → `症候` / 診察の ことば → `診察` / 検査 → `検査` /
    治療・くすり・手術・リハビリ・緩和ケア → `治療` / 病気の 名前・診療科の 専門の 病気 → `医学各論`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(🩸 💀 ☠️ など こわい 絵文字は 使わない。💉 の 多用も さける)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / どこで 出てくるか / なぜ 大事か」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  専門用語を 専門用語だけで 説明しない。「1人」「2人」は ふりがなが 読みまちがえるので **ひとり・ふたり** と ひらがなで 書く
- **example**: なくてもよい

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | 病院で 聞く ことば。小学生でも 聞いた ことが ある / 絵が うかぶ(問診・聴診器・レントゲン・点滴・内科・予防接種) |
| 2 | 中級 | **医師国家試験の 必修・一般の 範囲の めやす**。医学部で 学ぶと 出てくる ことば(主訴・鑑別診断・生検・抗菌薬・疫学・臨床研修) |
| 3 | 上級 | 専門・制度の こまかい ところの めやす(ブループリント・禁忌肢・硬膜外麻酔・インターベンショナルラジオロジー・EBM) |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる
(ならんだ 順が そのまま ステージの 順に なる)。

  ⚠️ **お金の 数字(保険料・自己負担の 割合)は 書かない**

## ぜったいに 守ること

- **自分の ことばで 書く**。過去問・問題集・教科書・診療ガイドライン・法律の **本文を 写さない**
- **病院・薬・会社の 名前は 使わない**(商標)。薬は「痛みどめ」の ような 一般の 言いかた
- **数字は まちがいない ときだけ**(制度の「いつから」の 年は 書かない。歴史の 人の 年は 書いて よいが まちがいない ものだけ)
- 学者・歴史の 人の 話は **「〜を 見つけた」「〜と 言われている」** の 形に
- 事実が あやしい 語は **入れない**(まちがいを 書くより 入れないほうが よい)
- 「100マス計算」「百ます計算」の 字を 使わない

`python3 tools/ishi/terms_js.py --only <旅id>` で 形を 確かめる(まちがいが あれば 止まる)。
