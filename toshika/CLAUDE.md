## フリック投資家(`toshika/`。けいくん 2026-10-02「投資家の専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください。日本一の投資家、竹田和平さんのように 好きな企業を応援する長期投資スタイルがメインの投資家に育ってほしいです」。まとめは `docs/フリック投資家-はじめかた.md`)

- 名前は「フリック投資家」(絵が 届いたら 題名に そろえる。フォルダ名 `toshika` は 変えない)。シリーズの 絵文字は 🌱。`SERIES_ORDER` は 株式旅行の となり(いちばん うしろ)
- ⚠️ **はじめの 5つの 問いは けいくんに 聞かずに `docs/フリック投資家-はじめかた.md` の おすすめの まま 作った**(ほかの ゲームで 毎回「全部おすすめで」だったため)。ちがう ところが あれば 直す
- 旅は 7つ(投資のきほん `kihon`・会社を知る `kaisha`・長期投資と応援 `choki`・決算書を読む `kessan`・市場としくみ `shijo`・投資家のこころ `kokoro`・投資の歴史と人びと `rekishi`)+ マスター。
  **旅ごとに 70語(入門20・中級25・上級25)= 490語**。かずともの 旅の 名前は **`tk` で はじめる**(tkkihon / tkkaisha / tkchoki / tkkessan / tkshijo / tkkokoro / tkrekishi / tkmas)。
  ⚠️ 教師の `tkangae` / `tkokoro` とは 別の 字(`tkkokoro` は k が 2つ)
- むずかしさは 3段: 入門(くらしや ニュースで 聞く お金と 会社の ことば)→ 中級(**証券外務員・FP の 範囲の めやす**)→ 上級(**証券アナリスト(CMA)の 範囲の めやす**: 企業分析・決算書の 指標・ポートフォリオ理論)。
  1語ごとに **学ぶ 分野**(`field`)7つ: 投資のきほん / 企業分析 / 財務・決算 / 市場と制度 / 長期投資 / 行動ファイナンス / 歴史
- ことばは `tools/toshika/terms-<旅>.json`(決まりは `tools/toshika/PROMPT.md`)→ `tools/toshika/terms_js.py` → `toshika/terms.js` + `data/toshika.json`。
  しくみは `toshika/toshika.js`(アドラーを 写した。4択クイズ あり。クイズの 文は「投資を すすめる ものでは ありません」)。
  しくみ図は コードで 描く 箱の 図 7つ(投資の地図・**会社と株主の図(お金を出す → 会社が育つ → 配当と優待で お返し)**・**長期投資の木(種 → 芽 → 大きな木 → 花咲爺の心)**・**決算書の3つの箱**・市場・こころ・歴史と人びと。`tools/toshika/mkmeta.py`)。ホームでは たたんで ある
- **国家資格は 無い**。専門家に なる 道は `tools/toshika/exam.txt`(→ meta.json の `exam`)に **確かめた日つき**(2026年10月2日):
  証券外務員(日本証券業協会。一種・二種。試験に 合格 + 外務員の 登録)/ FP(国家検定の FP技能士 1〜3級・日本FP協会の AFP / CFP)/ 証券アナリスト(日本証券アナリスト協会の CMA。基礎講座 → 1次 → 2次)/
  投資助言・代理業は 金融商品取引法で 登録が 要る(**だから この ゲームは 助言を しない**)/ NISA 2014年・新しい NISA 2024年(つみたて投資枠・成長投資枠。上限額は 書かない)/ 東証の 市場区分 2022年4月4日(プライム・スタンダード・グロース)/
  竹田和平さん(1933年 名古屋 生まれ・お菓子の 会社・100社 以上の 大株主「日本一の 個人投資家」・「平成の 花咲爺」・徳 / 貯徳・智徳・「恒産なくして 恒心なし」。紹介ページで 確かめた)。
  ⚠️「専門家に なれる レベル」は **証券アナリスト(CMA)の 範囲の ことばを ひととおり 知っている** めやす
- ⚠️⚠️⚠️ **投資・銘柄の すすめ・売り買いの 時期・「必ず もうかる」・投資相談の 答えを 書かない**(金融商品取引法の 投資助言に 見えない ように)。書くのは「何を さすか・何の ための しくみか・長く 応援する 投資家は どう 考えるか」だけ。
  心理の 語(狼狽売り・高値づかみ など)は「人の 心には こういう くせが ある」と 知る 書きかた。FX・暗号資産・信用取引・空売りは **名前と しくみ + 「会社を 応援する 投資とは 別の しくみ」**
- ⚠️⚠️⚠️ **株価・利回り・税率・金額・割合・倍率の 数字を 書かない**(税理士より きびしい。台本が %・割・円・倍 を 止める)。PER・PBR は「何を 見る ものさしか」だけ。NISA の 上限額・年数も 書かない
- ⚠️⚠️ **小学生も あそぶ**: 借金・破産・倒産・大損・暴落・崩壊・ギャンブル・賭け・くじ・ガチャは 台本が 止める。バブル・世界恐慌・リーマン・ショックは 名前と「大きく ゆれた」だけ。「72の法則」「ギャンブラーの誤謬」は 入れない
- ⚠️⚠️ **実在の 会社・生きている 人の 名前を 出さない**。台本が バフェット・ソロス・シラー・セイラー・ファーマ と 大きな 会社の 名前を 止める。
  人物は 歴史上の 人だけ(竹田和平・渋沢栄一・本間宗久・福沢諭吉・アダム・スミス・グレアム・ケインズ・フィッシャー・テンプルトン・ボーグル・マーコウィッツ・カーネマン)。亡くなった ことは 書かない。
  竹田和平さんの 会社名・商品名(竹田製菓・竹田本社・タマゴボーロ)・金(きん)の 商品・「和製ウォーレン・バフェット」は 書かない(参考の ページは 純金の 家宝を 売る ページ。**すすめない・リンクしない**)。
  能力の輪・ファイブフォース分析 などは 生きている 人の 考えだが **名前は 出していない**
- ✅ 株式旅行・税理士 など ほかの ゲームと 同じ 語を 入れて よい(説明は 長く 応援する 投資家の 目線)。読みは **投資家の 7つの 旅の 中で** かぶらない(`terms_js.py` が 止める。はじめから かぶりは 0。書く 途中で 2語 入れかえた)
- 作った 助手とは **別の 助手が 1語ずつ 確かめた**(7つの 旅 ぜんぶ。直しは 約45)。おもな 直し:
  きほん … 投資は「あずける」では ない・NISA は「NISA の 口座で えた 利益」・非課税(配当は 受けとりかたで 課税 される ことが ある)・iDeCo(原則として 引き出せない)・期待リターン(起こりやすさで 重みを つけた 平均)・CAPM(無リスク資産の 利回りも 入れる)/
  会社 … 市場シェア(何に たいする 割合か)・コーポレートガバナンス・コード(金融庁と 東証が 中心)/ 長期 … 竹田和平さんの 語(貯徳・智徳・花咲爺・恒産)を **確かめた 事実だけ**に・再投資(必ず ふえると 読めない)・売らない勇気(指図に しない)/
  決算 … 黒字・赤字(収益と 費用)・EPS / BPS(自己株式を のぞく)・のれん(時価で 見直した 純資産)/ 市場 … FX・暗号資産・信用取引・空売りに「応援する 投資とは 別」・気配値 /
