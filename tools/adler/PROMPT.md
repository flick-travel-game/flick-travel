# フリックアドラー心理学: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
分野・しくみ図の どこに あるか(📍)が 出る。あそぶのは **小学生〜心理を 学ぶ 高校生・大学生・子育て中の 大人・先生**。
**アドラー心理学の 専門家に なるための ことばと 意味を おぼえる ゲーム**(カウンセリングの 手引きでも、悩み相談でも ない)。
もとは `tools/kyoshi/PROMPT.md`(教師)と `tools/zeirishi/PROMPT.md`(税理士)。
けいくん 2026-10-02「アドラー心理学の専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」・
「劣等コンプレックス・神経症・不登校・ひきこもり」は「4つとも入れる」(アドラーは こう 考えた、の 書きかたで。ようすは 書かない)。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 6つ

### 1. やりかたを 書かない(心理療法・カウンセリングの 手順・台本)
- ❌ 「こう 言えば 相手が 変わる」「こういう ときは こう 声を かける」「この 順番で 聞く」「こう すれば かならず うまく いく」
- ⭕ その ことばが **何を さすか**・**何の ための 考えかたか**・アドラー心理学の どこに 出てくるか。**名前と ねらいだけ**
  - 例: 課題の分離 = その ことの 結末を 最後に 引きうけるのは だれかを 考えて、自分の 課題と 人の 課題を 分ける 考えかた。人の 課題に 勝手に 踏みこまない ための ものです
  - 例: 再方向づけ = カウンセリングの 中で、その 人が 自分の 目標や 見かたを 見なおし、新しい 方向を えらべるように する 段階の 名前です

### 2. 悩みの 相談の 答えに しない・人を 診断しない・決めつけない
- ❌「あなたの 場合は …」「◯◯な 人は 劣等コンプレックス」「長子は 〜な 性格」「〜は 甘え」「〜な 人は ダメ」
- ⭕ 出生順位・性格の 話は **「アドラーは 〜の 傾向が あると 考えた。決まりでは ない」**の ように 傾向の 話として
- 読んだ 人が **自分に あてはめて 傷つかない** 書きかた。価値判断を 1語も 入れない。
  アドラー心理学の 言いかた(「どの 人にも 価値が ある」「人は 変われる」)に そろえる

### 3. 小学生も あそぶ(こわく しない)
- ❌ **自殺・虐待・いじめの ようす・暴力・こころの 病気の くわしい 症状・こわい ことば**を 書かない
  (「死」「殺」「血」「虐待」「暴力」「体罰」「復讐」は 台本が 止める)
- 「不適切な行動の 4つの目的」は **注目を 得る・力を 示す(権力)・仕返し・あきらめ(無気力の 誇示)** と やわらかく。「復讐」の 字は 使わない
- ✅ **劣等コンプレックス・神経症・不登校・ひきこもり は 入れる**(けいくん決定 2026-10-02「4つとも入れる」)。ただし
  **「アドラー心理学では 〜と 考える / アドラーは 〜と 考えた」**の 書きかたで、**ようす(症状・つらさ)は 書かない**。
  不登校・ひきこもりは **「その 子・その 人を せめずに、まわりが 勇気づけで 支える」**向きで。だれかの せいに しない
- 病名(うつ病・統合失調症 など)は 入れない(台本が 止める)

### 4. ほかの 心理学・宗教・自己啓発の よしあしを 書かない
- フロイト・ユングとの ちがいは **考えかたの ちがい**として 書く(「フロイトは 過去の 原因を、アドラーは 目的を 重く 見た」)。どちらが 正しいかは 書かない
- 宗教・ほかの セラピー・自己啓発を けなさない

### 5. 実在の 本・講座・生きている 人を 売り文句に しない
- **生きている 人の 名前を 入れない**。人物は 歴史上の 人(アドラー・ドライカース・アンスバッハー・フロイト・ユング など)だけ。
  人物は **何を した 人か / 何を となえた 人か** だけ(生まれた 年は よいが、亡くなった ことは 書かない)
- 本の 書名・出版社・講座の 名前・民間団体の 名前を **語(name)に しない**。現代の 本の 書名は 説明にも 書かない(台本が 止める)。
  公の 学会の 名前(日本アドラー心理学会・国際個人心理学会)は 歴史の 旅で よい。アドラー本人の 本は 歴史の 旅で 1〜2語まで

### 6. アドラーの 目線で 書く(教師・保育士・看護師 など ほかの ゲームと 同じ 語を 入れて よい)
- ✅ **ほかの ゲームと 同じ ことばを 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)
- ⚠️ ただし 説明は **アドラー心理学の 目線**で 書きなおす。
  例: 自己肯定感 … 教師「自分を 大切に 思える 気持ち」/ アドラー「自己受容と、人の 役に 立てている 貢献感から 生まれる と 考える」
- **読み(ひらがな)は アドラーの 7つの 旅の 中で かぶらない**(台本が 止める)。下の「旅ごとに 入れる」を 守る

## 1語の 形(JSON)

```json
{"id":"ky-kadainobunri","name":"課題の分離","reading":"かだいのぶんり","journey":"kyodotai","category":"対人関係の考えかた","difficulty":1,
 "field":"対人関係","type":"concept","emoji":"✂️","mapNode":"taijin:bunri","relatedTerms":["ky-yokonokankei"],
 "description":"その ことの 結末を 最後に 引きうけるのは だれかを 考えて、自分の 課題と 人の 課題を 分ける 考えかた。人の 課題に 勝手に 踏みこまない ための ものです。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(アドラー心理学で ふつうに 使う 訳語。漢字・カタカナ・英字)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)
  - カタカナ語は ひらがなに(らいふすたいる)。ゆれる 読みは `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)。
    例: ドライカース どらいかーす / どらいくるす
  - 原語(ドイツ語・英語)の 語は **日本で ふつうに 書く カタカナ**の 読みで(ゲマインシャフツゲフュール → げまいんしゃふつげふゅーる)
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は 上級だけ・旅で 1〜2語まで
  - ⚠️ 読みを まちがえやすい ことば(補償 ほしょう・家族布置 かぞくふち・私的論理 してきろんり・早期回想 そうきかいそう・
    劣等性 れっとうせい・優越性 ゆうえつせい・全体論 ぜんたいろん・布置 ふち)は 1語ずつ 確かめる
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級(下の「3段の 分けかた」)
- **field**: つぎの 7つの どれか: `理論` `対人関係` `勇気づけ` `ライフスタイル` `子育て・教育` `カウンセリング` `歴史`
  (旅と ほぼ 同じだが、旅の 中でも いちばん 近い ものを えらぶ。例: 歴史の 旅の「目的論」を 名づけた 話 → 理論 でも よい)
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(こわい 絵文字(💀 ☠️ 🔪 🩸 👊 😭)は 使わない)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / どこで 出てくるか / なぜ 大事か」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  専門用語を 専門用語だけで 説明しない。「1人」「2人」は ふりがなが 読みまちがえるので **ひとり・ふたり** と ひらがなで 書く
- **example**: なくてもよい

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | 本や 講座で まず 出る ことば(勇気づけ・課題の分離・共同体感覚・劣等感・目的論・ほめる と 勇気づける) |
| 2 | 中級 | **日本アドラー心理学会の 基礎講座・心理療法の 入門書の 範囲の めやす**(ライフスタイル・早期回想・私的論理・家族布置・ライフタスク) |
| 3 | 上級 | 学会の 専門用語・原語(ドイツ語・英語)の 訳語・歴史の こまかい 人名(使用の心理学・創造的自己・ゲマインシャフツゲフュール・アンスバッハー) |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる
(ならんだ 順が そのまま ステージの 順に なる)。

## ぜったいに 守ること

- **自分の ことばで 書く**。本・講座の 資料の 本文を 写さない
- **会社・塾・民間団体・商品・本の 書名(現代の もの)は 使わない**
- **数字・年は まちがいない ときだけ**。事実が あやしい 語は **入れない**(まちがいを 書くより 入れないほうが よい)
- 学者・歴史の 人の 話は **「〜を となえた」「〜と 考えた」「〜を 開いた」** の 形に

## 出すもの

`tools/adler/terms-<旅id>.json` に JSON の 配列(70語)で 書く。書いたら
`python3 tools/adler/terms_js.py --only <旅id>` で 形を 確かめる(まちがいが あれば 止まる)。
