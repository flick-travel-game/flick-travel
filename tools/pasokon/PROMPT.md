# フリックパソコン: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
学ぶ 分野・しくみ図の どこに あるか(📍)・ときどき「💬 店員さんの ひとこと」「💻 やって みよう」・ショートカットの 旅では「⌨️ キーの ふだ」が 出る。
あそぶのは **小学生〜パソコンに くわしく なりたい 中高生・大人**。**パソコンの ことばと しくみと、お客さんへの 説明の しかたを おぼえる ゲーム**(取扱説明書でも 試験の 問題集でも ない)。
もとは `tools/sumaho/PROMPT.md`(フリックスマホ。いちばん 近い 兄弟)。
けいくん 2026-10-03「MacBookの専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください。ショートカットもたくさん出してください」
→ 同じ日「**ショートカットが目玉ではなく、Appleショップの店員さん並に MacBookのプロになれるようにしてください**」→ 5つの 問いに「全部おすすめで」。
名前は 商標の ため **「フリックパソコン」**。まとめは `docs/フリックパソコン-はじめかた.md`。
**中身は MacBook(macOS)が 中心**。ところどころ「Windows では 〜と いう 名前」と しくみの ちがいを 1文(どちらが よい は 書かない)。

## ⭐ この ゲームの ゴール = お店の パソコン担当の 店員さん
1. **えらぶ**: お客さんの「何に 使いたい?」を 聞いて、チップ・メモリ・ストレージ・画面の 大きさ の **考えかた**で 合う ものを すすめる
2. **はじめる**: はじめての 設定・データの 引っ越し・アカウント・家族で 使う 設定
3. **つなぐ**: スマホ・タブレット・時計・イヤホンとの 連携、外の 画面・プリンタ・ハブ などの 周辺機器
4. **使いこなす**: 操作・ファイル・アプリ・ショートカット・作品づくり・設定と アクセシビリティ
5. **直す・守る**: トラブルの 切りわけ・バックアップ・安全・修理と 保証
6. ⭐ **わかりやすく 説明する**: `setsumei`(💬 店員さんの ひとこと)で、専門の ことばを **お客さんに 伝わる たとえ**で 言いかえる。**この ゲームの いちばんの 目玉**

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 8つ

### 1. 商標を 1語の 答え(`name`)に しない(いちばん 大事)
- 「MacBook」「Mac」「macOS」も アップルの 機能の 名前の 多くも **商標**。かずともは お金を いただく サービスなので、商標を 答えの 名前に すると 商品名に 使った ことに なる
- ❌ `name` に 入れない(台本 `TM_NAME` が 止める): Mac・MacBook・macOS・Finder・Spotlight・Safari・Time Machine・Launchpad・Mission Control・Stage Manager・
  Handoff・Sidecar・Continuity・ユニバーサルクリップボード・ユニバーサルコントロール・Keynote・Pages・Numbers・GarageBand・iMovie・Final Cut・Logic Pro・
  Touch ID・AirDrop・AirPlay・iCloud・Siri・FaceTime・Thunderbolt・Magic Keyboard / Mouse / Trackpad・Force Touch・Touch Bar・Night Shift・True Tone・
  VoiceOver・Quick Look・FileVault・Gatekeeper・移行アシスタント・キーチェーン・Rosetta・Apple シリコン(チップの 名前)・iPhone・iPad・Apple Pencil・
  Windows・Microsoft・Excel・PowerPoint・Chrome・Intel・Linux・UNIX・Zoom・Teams・Adobe など
- ⭕ **一般の 言葉で 答えに する**: ファイル管理アプリ(Mac では Finder)/ 検索の 機能(Spotlight)/ 自動バックアップの 機能(Time Machine)/ 指紋認証(Touch ID)/
  近距離ファイル共有(AirDrop)/ 続きから 作業する 機能(Handoff)/ 共通の クリップボード / タブレットを 2台目の 画面に する 機能(Sidecar)/ 延長保証(AppleCare)/
  クラウド(iCloud)/ 画面の 読み上げ(VoiceOver)/ 中身を のぞく 機能(Quick Look)/ ディスクの 暗号化(FileVault)/ 高速の ポート(Thunderbolt)/ 夜の 色あい(Night Shift)
- ⭐ **説明文の 中では** 「Mac では『Finder』と いう 名前です」と **事実として 1回 ふれて よい**(どの 機械の 何の ことか わかる ため)。
  ただし **1語に 1回まで**・**ほめ言葉や 売り文句に しない**(「すごい」「いちばん」「おすすめ」を 商標と ならべない)
- ⚠️ **説明に「Apple Store」「ジーニアス」を 書かない**(台本が 止める)。「お店の 店員さん」「サポートの 人」と 書く
- ✅ Wi-Fi・Bluetooth・USB・USB-C・HDMI・SSD・PDF・JPEG・OS・CPU・GPU は **世界の 決まり(規格)や ふつうの ことば**として `name` に して よい
- ⚠️ ことばそのものが 一般の 言葉なら よい(デスクトップ・メニューバー・ドック・コントロールセンター・通知センター・ウィジェット・集中モード・ダークモード・ゴミ箱・エイリアス)

### 2. 機種名・チップの 商品名・OSの バージョン・値段・毎年 変わる ことを 書かない
- ❌ 「MacBook Air」「M4」「macOS Tahoe」「Windows 11」・新しい 機能の 名前・**設定の 道すじ**(設定 → 一般 → …)は 毎年 変わる
- ⭕ **何年たっても 正しい しくみ**で 書く。書くのは「設定の アプリで 変えられます」まで
- ❌ **数字を 書かない**: 値段・割引の 金額・容量(GB / TB)・画面の 大きさ(インチ)・電池の 時間・充電器の ワット数・コアの 数・速さ・解像度の 数字(4K など)・%(台本が 止める)
- ⭐ **えらびかたの 旅は「考えかた」で**(「写真や 動画を たくさん あつかう 方は ストレージを 大きめに」)。何年たっても 役に 立つ 提案の しかた
- 歴史の 年は **`exam.txt` で 確かめた もの だけ**(1946年・1968年・1984年・1985年・1995年・2005年・2006年・2020年)。ほかの 年は 台本が 止める

### 3. ショートカットは 公式の ページで 確かめた もの だけ
- `tools/pasokon/shortcuts.md`(アップルの 公式の ページ 5つを 2026-10-03 に 写した 一覧)に **ある もの だけ**。**ありもしない ショートカットを 作らない**
- ⌘ + ⇧ + T は Safari の ページだけに ある(「最後に 閉じた タブを 開く」= ブラウザの 話と して 書く)。F8 は「ローマ字に 変換(はじめの 設定)」
- キーは `keys` の 欄に「⌘ + C」の 形(⌘ ⌥ ⌃ ⇧ fn esc Tab Space Return Delete ← → ↑ ↓ 英数 かな F6 … と 大文字の 英字・数字・, . / - [ ] ; `)。答え(name)は **動きの 名前**(コピー)
- ときどき「Windows では Ctrl + C」と 1文(しくみの ちがい として)

### 4. 守る しくみを ぬける 方法を ぜったいに 書かない
- ❌ パスワードの ぬけ道・子ども用の 設定の 外しかた・**ターミナルの 命令**・守る 機能を 止める 方法・**ハッキングの やりかた**・人の パソコンを のぞく 方法
- ⭕ 安全と サポートの 旅は **守る がわ・直す がわ** だけ(「こう される かも しれない → こう 守る」)。初期化・OSの 入れなおしは「**おとなと いっしょに・バックアップを 取ってから**」

### 5. ほかの 会社を けなさない
- Windows・ほかの パソコンとの ちがいは **しくみの ちがい** として(「Windows では 〜と いう 名前」)。**どちらが よい は 書かない**(「〜より すぐれて いる」は ❌)

### 6. 実在の お店・会社・アプリの 商品名を 出さない
- ❌ 家電量販店・パソコンを 作る 会社・SNS・ゲームアプリ・アプリの 商品名(台本が 止める)。標準アプリも **一般名で**(Mac での 名前は 説明に 1回)
- ⭕ 人の 名前は 歴史として よい(エンゲルバート・スティーブ・ジョブズ・ビル・ゲイツ など。**事実を 確かめて**)
- ⭕ 公の 組織・制度は よい(IPA・総務省・警察・消費生活センター・家電製品協会)

### 7. ⭐ 店員さんの 目線で 書く
- 説明は「**何か + お客さんに とって 何が うれしいか**」
- ⭐ `setsumei`(💬 店員さんの ひとこと)= お客さんに 伝わる **たとえ**。例:
  メモリ →「作業する 机の 広さです。広いほど たくさんの アプリを 同時に 広げられます」/ ストレージ →「物を しまう 引き出しです。写真や 動画が 多い 方は 大きめを」
- **こわがらせない**。トラブルは「順に 確かめれば 直る ことが 多い」が 伝わる 書きかた

### 8. 事実を 正しく・自分の ことばで
- 公式の 説明・Wikipedia を 写さない。事実が あやしい 語は 入れない
- ✅ スマホ・プログラマー・AI旅行 など **ほかの ゲームと 同じ 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。説明は **パソコンの 目線**で 書きなおす
- **カタカナ語は ふつうの 言葉で 言いかえて から**
- **読み(ひらがな)は パソコンの 12の 旅の 中で かぶらない**(台本が 止める)。下の「旅ごとに 入れる 語」を 守る。**ほかの 旅の 欄に ある 語は 入れない**
- 文体は **はじめから「〜です・ます」**

## 1語の 形(JSON)

```json
{"id":"kh-memory","name":"メモリ","reading":"めもり","journey":"kihon","category":"中みの 部品","difficulty":1,
 "field":"ハードウェア","type":"concept","emoji":"📝","mapNode":"kihon:memory","relatedTerms":["kh-storage","kh-cpu"],
 "description":"パソコンが いま 使っている データを 一時的に おいて おく 場所です。電源を 切ると 中身は 消えます。",
 "setsumei":"作業する 机の 広さです。広いほど たくさんの アプリを 同時に 広げられます。",
 "yatte":"アプリを いくつか ひらいて、画面に ならべて みよう。"}
```

ショートカットの 旅だけ `"keys":"⌘ + C"` を 足す:
```json
{"id":"sc-copy","name":"コピー","reading":"こぴー","journey":"shortcut","category":"編集","difficulty":1,"field":"ショートカット","type":"concept","emoji":"📋",
 "mapNode":"shortcut:henshu","relatedTerms":["sc-paste","sc-cut"],"keys":"⌘ + C",
 "description":"えらんだ 文字や ファイルを 写して、あとで 貼りつけられる ように する 操作です。Windows では Ctrl + C です。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(漢字・カタカナ・英字の 略語。**商標は ダメ**)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)
  - ゆれる ことばは `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は 上級だけ・旅で 1〜2語まで
- **difficulty**: `1` 入門 20語 / `2` 中級 25語 / `3` 上級 25語(**1つの 旅に 70語**)。同じ difficulty の 中は **よく 知られている 順**(ならんだ 順が ステージの 順)
- **field**: 学ぶ 分野。次の 13の どれか:
  `ハードウェア` `えらびかた・提案` `設定・移行` `操作` `ファイル・アプリ` `ショートカット` `連携` `作品づくり` `アクセシビリティ` `周辺機器` `セキュリティ` `トラブル・サポート` `歴史`
  (ふつうは 旅の 分野。たとえば kihon の 歴史の 語は `歴史`、settei の アクセシビリティの 語は `アクセシビリティ`)
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**)
- **emoji**: 1つ(🍎 🍏 は 使わない = りんごの マークに 見える。💀 ☠️ 🔪 も 使わない)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。**語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体)。
  「1人」「2人」は **ひとり・ふたり** と ひらがなで
- **setsumei**(⭐ 💬 店員さんの ひとこと): **1文・60字以内**。お客さんに 話す 口調(「〜です」「〜ですよ」)で **たとえ**を。**1旅に 15〜25語**(専門の ことばほど 付ける。全部には 付けない)。
  値段・機種名・数字を 書かない
- **yatte**(任意。💻 やって みよう): 1文・60字以内。手元の パソコンで ためせる こと。**旅ごとに 5〜10語**。
  ⚠️ **ずっと 変わらない もの だけ**(2本指で スクロール・ウインドウを 2つ ならべる・設定の アプリを ひらいて みる)。お金・初期化・消す こと・人の パソコンを さわる ことは 書かない
- **keys**(ショートカットの 旅だけ): 上の 3
