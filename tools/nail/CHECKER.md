# フリックネイリスト: 確かめる 係への おねがい

あなたは **書いた 助手とは 別の 人**です。`tools/nail/terms-<旅>.json` を 1語ずつ 読んで、まちがいを **その場で 直して** ください。
さきに `tools/nail/PROMPT.md`(決まり)と `tools/nail/exam.txt`(確かめた 事実)を 読む。

## 見る こと(1語ずつ)
1. **意味が 正しいか**(ネイルの 技術・道具・皮膚と 爪の しくみとして。あやしい ときは WebSearch で 確かめる。確かめられない 事実は 文から 消す)
2. **読み(reading)が 正しいか**。ひらがなと ー だけ。カタカナの のばす 音・小さい 字(はいぽにきうむ・るぬーら・きゅーてぃくる)。甘皮=あまかわ・爪床=そうしょう・爪母=そうぼ など
3. ⭐ **医療に ふみこんで いないか**。診断・治療・薬の 名前・治しかた・「治る」「よくなる」「爪が 強く なる」の 約束が ないか。爪の トラブルは「見分けて 施術を ひかえ 医療機関を すすめる」で 終わっているか
4. ⭐ **やりかた・数字を 書いて いないか**。くすりの 量・時間・濃さ・%、ライトの 秒数、削る 手順・角度、「◯日 もつ」、金額
5. **ブランド名・商品名・サロン名・有名ネイリスト・予約サイトや SNS の サービス名・実在の キャラクター名**が ないか
6. **見た目を わるく 言って いないか**(爪の 形・長さ・手・肌の 色)。こわい けがの 話が ないか
7. **field(分野)と ruleset(技能検定 / ジェル検定 / 衛生 / サロン / 共通)が 合っているか**。上級は 札が あるか
8. 説明が 130字 以内・です・ます・語の あいだに 半角スペース。ネイリストの 目線か

## 直しかた
- その ファイルを 直接 直す。id は 変えない。語を 入れかえる ときは 読みが **9つの 旅の 中で かぶらない** ことを 確かめる(`python3 tools/nail/terms_js.py --check` が 教えて くれる)
- さいごに `python3 tools/nail/terms_js.py --check` が 通る ことを 確かめる(ほかの 旅の ファイルが 無くても 動く)
- 報告は 短く: 直した 数と、大きな 直し(事実の まちがい)を 5つほど
