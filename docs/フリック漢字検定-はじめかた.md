## 2. はじめに けいくんに 聞く 5つ

### 2-1. ⚠️⚠️ **名前**(商標。いちばん 先に 聞く)

- 登録されて いれば、**ゲームの 名前に 使うと 商標の もんだいに なる おそれ**が ある(プレプロ・かずとも は 自分の 商標を 出願して いる ので、人の 商標にも 気を つける)
- ⭐ おすすめの 名前の 案(けいくんに 出す):

  2. **フリック漢字マスター**
  3. **フリック常用漢字**(2級 = **常用漢字 ぜんぶ**(2136字)が 範囲 なので 中身と 合う)

### 2-2. ⭐⭐ **書き取り**(けいくんの 質問「漢字の書き取り機能は付けれる？」への 答え)
**付けられる**。ただし、ふつうの フリック(打って 変換)では **本当の 書き取りに ならない**。
⚠️ 「あたま」と 打って 変換すると **スマホが 漢字の 候補を 出して くれる**ので、**えらぶ だけ**に なる(書けなくても 正解できる)。だから **指で 書く 画面**を 作る。案は 3つ:

| 案 | しくみ | よい ところ | こまる ところ |
|---|---|---|---|
| **A** | **指で 書いて、お手本と 見くらべて 自分で ◯×**(書く → 「こたえ」→ お手本が 重なって 出る → 自分で ◯ か × を 押す) | すぐ 作れる・どの 字でも できる・スマホだけで 動く | 自分で きめる ので あまく なる。スピード勝負の 記録には しにくい |
| **B** | A + **書き順アニメ**(お手本が 1画ずつ 書かれて いく) | ⭐ 書き順も おぼえる(2級の 試験にも 書き順は 出ない が、字の 形が きれいに なる) | 字の 形の データが 要る(C と 同じ データ) |
| **C** | **書いた 線を 機械が しらべて 自動で ◯×**(画数・書き順・線の 向き・だいたいの 場所を お手本と くらべる) | 本物の 書き取り。スピード勝負・ランキングに できる | 作る 量が 多い・判定が きびしすぎ / あますぎ を 何回も 直す |

⭐ **おすすめ: まず A + B で 出して、あとで C**(韓国語を 半分で 出して ふやした のと 同じ 進めかた)。
- **字の 形の データ**は **KanjiVG**(⭐ 常用漢字 ぜんぶの 書き順つき の 線の データ。**ライセンスは CC BY-SA 3.0**(⚠️ 作る 前に 確かめる)。**出どころを 画面(遊びかた・法務の リンクの 近く)に 書く 決まり**が ある。⚠️ データを 直して 配る と 同じ ライセンスで 出す 決まり(SA)なので、`kanken/strokes.js` の あたまに ライセンスを 書く)。**2136字 ぜんぶ 入れると 大きい**(数MB)ので、**旅ごとに 使う 字だけ**に しぼる・字ごとに あとから 読みこむ
- ⚠️ **外の 手書き 認識サービス**(Google など)は **使わない**(子どもが 書いた ものを 外へ 送らない・お金が かかる・止まる かも)。ぜんぶ **スマホの 中**で
- 書く 画面: 正方形の マス(十字の 補助線)・**消す / 1画 もどす / こたえ**・指の 線は 太め。⚠️ 指で 書くと 画面が 動く(スクロール)ので **書く マスの 中は スクロールを 止める**(`touch-action: none`)
- 問題の 出しかた(書き取り): **文の 中の カタカナ を 漢字で 書く**(例:「試合に **イドむ**」→ 挑)。⭐ 本物の 試験と 同じ 形。答えの 字(`kanji`)を お手本に する
- ⚠️ **iPhone の 3本指の うごき・ピンチで 拡大** が 書く じゃまに なる → マスの 中では 止める。320px の 画面でも マスが 小さく なりすぎない ように(手元で W=320 で 見る)

### 2-3. **旅の 分けかた**(おすすめ 8つ + 🏆 マスター。**漢字検定2級の 出題の 分け**(⚠️ 4 で 確かめる)に そろえて、子どもにも わかる 名前に)
- 📖 **読み** `knyomi`(⭐ 2級の 中心: **常用漢字の 音読み・訓読み**・**高校で 習う 読み**(表外読みでは なく **常用漢字表の 中の 読み**)・**むずかしい 読み**(凡例・遵守・漸次・逐次 …)。フリックで **読みを 打つ**(国語の `kyomi` と 同じ 形)。⚠️ 国語の 読みと かぶって よい(説明は 2級の 目線)。上級は 国語と 同じ **`hide`**)
- ✍️ **書き取り** `knkaki`(⭐ 2-2 の 書く 画面。文の 中の カタカナを 漢字で 書く。**同じ 読みで ちがう 字**(同音異字)を 書きわける)
- 🧩 **部首** `knbushu`(⭐ 2級の 定番: その 字の 部首と **部首名**(さんずい・くさかんむり・れっか・しんにょう・まだれ …)。⚠️ **まちがいやすい 部首**(問 = 口、聞 = 耳、閉 = 門 など)は 上級。フリックで **部首名を 打つ**)
- ✏️ **送りがな** `knokuri`(**送りがなの 決まり**(活用語尾から 送る・例外)。文の 中の カタカナを **漢字と 送りがな**で。⚠️ 打つ ときは **送りがなの ひらがな だけ**を 打つ 形にする か、書き取りの 画面に するか は けいくんに 聞く)
- 🔗 **熟語の 組み立て** `knjukugo`(⭐ 5つの 型(上下が 反対 / 似た 意味 / 上が 下を 修飾 / 下が 上の 目的 / 上が 下を 打ち消す)。答えは **型の 名前**か **記号**(ア〜オ)。⚠️ 選ぶ 問題に なる ので、国語の **えらぶ 形**が あれば それを 使う)
- 🀄 **四字熟語** `knyoji`(⚠️ 国語の `kyoji` と かさなる。**2級で 出る もの**に しぼる。**意味と 読み**・空いた 2字を 書く)
- ⇔ **対義語・類義語** `kntaigi`(楽観 ⇔ 悲観・寄与 ≒ 貢献 など。フリックで **読みを 打つ** か 書き取り)
- 🔄 **同音・同訓異字 と 誤字訂正** `kndoon`(⭐ 2級の 定番: **同じ 音で ちがう 字**(保障 / 保証 / 補償)・**同じ 訓で ちがう 字**(早い / 速い)・**文の 中の まちがった 字を 見つけて 直す**)
3. **むずかしさの 3段**(国語と 同じ):
   ・入門 = **準2級 くらい まで**(中学 卒業 〜 高校 1年)
   ・中級 = **2級の よく 出る ところ**
   ・上級 = **2級の むずかしい ところ**(読みを かくす `hide`・まちがいやすい 部首・誤字訂正)
4. **語数**: ⚠️ 2級の 範囲は **常用漢字 2136字 ぜんぶ**。ぜんぶの 字を 1回ずつ 出すと とても 多い。⭐ **まず 8つの 旅 × 70語 = 560問**(国語と 同じ ぐらい)で 出して、**書き取りと 読みを あとから ふやす**(けいくんに 聞く)
5. **入れない もの**: **漢字検定の 過去問・市販の 問題集の 文を 写さない**(⚠️ 著作権。例文は ぜんぶ 自分で 書く)・**こわい・悲しい 例文**(事件・事故・病気・死)・**人を けなす 例文**・**実在の 人・会社・商品の 名前**・**常用漢字に 無い 字**(2級の 範囲の 外。⚠️ 準1級・1級の 字を まぜない)

## 3. ⚠️⚠️⚠️ ぜったいの 決まり(国語と 同じ + この ゲームだけの もの)
- ⭐⭐ **名前と 説明で 人の 商標を 使わない**(2-1)。**決まるまで 画面・ファイルの 字に「漢検」「漢字検定」を 書かない**(フォルダ名 `kanken` は よい)
- ⭐⭐ **範囲は 常用漢字表の 中だけ**(字も 読みも)。**常用漢字表は 文化庁**の もの(⚠️ 2010年 改定 2136字 の 見こみ。**4 で 確かめる**)。表に 無い 読み(表外読み)を 正解に しない
- ⭐ **字の 形は 教科書体の 形**(お手本・書き取りの 判定)。⚠️ スマホの 字(明朝・ゴシック)と 教科書体で 形が ちがう 字が ある(「令」「八」の はらい など)。**お手本の 字は KanjiVG の 線**を 使い、画面の 字(フォント)を お手本に しない
- **例文は ぜんぶ 自分で 書く**(過去問・問題集を 写さない)。子どもが 読む ので **やさしい 場面**(学校・家・スポーツ・自然)
- **読みは 1つに 決まる 語だけ**を 答えに する(国語の 決まり。2つ 読める 語は 読みを `alias` で 受ける か 入れない)
- ✅ **ほかの ゲーム(国語・英語・社会・歴史 など)と 同じ 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。説明は **漢字の 目線**(部首・成り立ち・使いわけ)で
- **読み(ひらがな)は この ゲームの 8つの 旅の 中では かぶらない**(ほかの ゲームとは かぶって よい。`terms_js.py` が 止める)。⚠️ `knyomi` と `knyoji`・`kntaigi` と `kndoon` は かさなりやすい。**先に 8つの 旅の 語の 一覧を 1人の 助手に 作らせて** 置き場所を 決めてから 頼む
- ⭐ **ふりがなを 全語 1つずつ 確かめる**(`tools/ruby_fix.json`。⭐ 🔊 よみあげで 読まれる。国語では 118か所 直した)
- 画面(ホームの 下・遊びかた)に「これは ことばを おぼえる ゲームです」・書き取りの 画面に **「字の 形の データ: KanjiVG(CC BY-SA 3.0)」**(⚠️ ライセンスを 確かめてから)・(2-1 で 決まれば)「(公財)日本漢字能力検定協会とは 関係ありません」
- **作った 助手とは 別の 助手が 1語ずつ 確かめる**(**読み**(常用漢字表に ある 読みか)・**部首**(⚠️ 辞書で 部首が ちがう 字が ある。**どの 辞書の 部首か を 1つに 決める**)・**送りがな**(内閣告示「送り仮名の付け方」)・**熟語の 型**・**同音異字の 使いわけ**・例文が やさしいか)
