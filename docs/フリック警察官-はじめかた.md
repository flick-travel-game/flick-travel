## 2. はじめに けいくんに 聞く 5つ(「全部おすすめで」と 返ってくる ことが 多い)
1. **名前**: 「フリック警察官」で よいか(絵が 届いたら 絵の 題名に そろえる。フォルダ名 `keisatsu` は 変えない)
2. **旅の 分けかた**(おすすめ 7つ + 🏆 マスター):
   🚓 交番と まちの ことば(交番・巡回・パトロール・落とし物・道案内・110番 …)/ 🚦 交通の ことば(交通整理・信号・標識・横断歩道・シートベルト・飲酒運転の 取りしまり …)/
   🔍 事件と 捜査の ことば(通報・現場・指紋・鑑識・聞きこみ・防犯カメラ … **名前と 役目だけ**)/ 🛡 まもる しくみ(防犯・見守り・特殊詐欺の 注意・サイバー・災害の ときの 警察 …)/
   ⚖️ 法律の ことば(憲法・刑法・刑事訴訟法・道路交通法・少年法・警察官職務執行法 … **法律の 名前と 何の ための 法律か** だけ)/
   🏢 警察の しくみ(警察庁・都道府県警察・警察署・交番・階級(巡査〜警視総監)・部門(地域・交通・刑事・生活安全・警備)…)/
   🧭 警察官の 心と からだ(公務員の 決まり・守秘義務・礼式・体力・柔道と 剣道・ことばづかい …)
3. **むずかしさの 3段**: 入門(まちで 見かける 警察の ことば)→ 中級(**警察官採用試験の 教養試験の 範囲の めやす**: 法律・時事・一般常識)→ 上級(法律の 条文の 名前・階級と 組織の こまかい ところ・専門の 部門)
4. **1語に 持たせる 科目**(`field`): 採用試験の 教養の 大きな 分け(社会科学(法律・政治・経済)/ 人文科学 / 自然科学 / 文章理解 / 数的処理 … の うち **警察の ことばに かかわる もの**)と、警察学校で 学ぶ 分け(警察法・刑法・刑事訴訟法・交通 …)。**確かめてから 決める**
5. **入れない もの**(下の 3 と かさなる): 犯罪の やりかた・武器の あつかい・取りしまりの 手順・事件の こわい 中身。**取りしまる 側の ことばでも、まねできる 形には 書かない**

## 3. ⚠️⚠️⚠️ ぜったいの 決まり(看護師の「やりかたを 書かない」と 同じ。警察官は なおさら)
- ✅ **ほかの ゲームと 同じ 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。ただし 説明は **警察官の 目線**で 書きなおす
- **読み(ひらがな)は 警察官の 7つの 旅の 中では かぶらない**(ほかの ゲームとは かぶって よい)
- **犯罪の やりかた・だましかた・にげかた・武器の あつかい・取りしまりの 手順・逮捕の しかた** を **ぜったいに 書かない**。
  書くのは **その ことばが 何を さすか・何の ための しくみか**だけ(例: 指紋 = 人によって ちがう 指の もよう。現場に 残った ものと くらべて 手がかりに する)
- **小学生も あそぶ**: 事件・事故・けが・死の ようすを 書かない。犯罪の 名前(詐欺・窃盗 …)は 入れて よいが、
  **「警察官が どう 守るか・助けるか」「どう 気をつければ よいか」の 書きかた**だけ。こわい 先・実際の 事件の 名前・実在の 人物は **入れない**
- **銃・けん銃・警棒・手錠**などの 装備は **名前と「決まりの 中でだけ 使う 道具」**まで。使いかた・しくみは 書かない。まよったら その 語を 入れない
- **政治・思想の よしあし**を 書かない。法律は **名前と 目的**だけ(条文の 中身の 決めうち・罰の 重さを 書かない)
- 画面(ホームの 下・遊びかた)に「これは ことばを おぼえる ゲームです。本物の 試験問題では ありません。警察庁・都道府県警察とは 関係ありません。こまった ときは 110番 か 近くの 交番へ」
- **作った 助手とは 別の 助手が 1語ずつ 確かめる**(意味・読み・やりかたを 書いていないか・こわくないか・まねできる 形に なっていないか)。ふりがなも 全語 見る(`tools/ruby_fix.json`)

## 4. 試験の 事実は **その日に 警察庁・都道府県警察の ページで 確かめてから** 書く
`meta.json` の `exam` に 確かめた 日を つける。書く 中身(すべて 確かめる。**記憶で 書かない**):
警察官は **地方公務員**(都道府県警察。警察庁の 警察官は 国家公務員)/ なりかたは **都道府県ごとの 警察官採用試験**(大卒程度の A区分・高卒程度の B区分 などの 区分名は **県で ちがう** と 書く)/
試験の 中身(教養試験・論文・面接・体力検査・身体検査・適性検査。**県で ちがう**)/ 受かったら **警察学校**(大卒 約6か月・高卒 約10か月 の めやす。確かめる)→ 交番 から はじまる /
階級は 9つ(巡査・巡査長(階級ではなく 呼び名。確かめる)・巡査部長・警部補・警部・警視・警視正・警視長・警視監・警視総監)/ 警察官の 人数の めやす / 110番の しくみ(通信指令室)/
警察の 部門(地域・交通・刑事・生活安全・警備・組織犯罪対策 など)/ 警察法・警察官職務執行法 の 名前と 目的

## 5. 作りかたの 手順(看護師・医師・教師・料理人の まとめと 同じ)
1. けいくんに 2 の 5つを 聞く → 返事を CLAUDE.md に 書く
2. `tools/keisatsu/PROMPT.md` `meta.json` を 作る → 旅ごとに 助手に 70語ずつ 頼む(`PROMPT.md` を そのまま わたす)→ `terms-<旅>.json`
3. `terms_js.py` で 止められた 語を 直す → 別の 助手が 1語ずつ 確かめる → ふりがな
4. `keisatsu/keisatsu.js`(kango.js を 写す)・`build_games.py`・`index.html` の SERIES → `python3 tools/build_games.py`
5. 手元で 通す: `python3 -m http.server 8765` → `node tools/play-all.mjs`(4とおりの 打ちかた)/ `node tools/click-all.mjs`(W=320 も)
6. PR は **rebase で 取りこむ**(この 入れもの)。speed-king は squash。コミットの 末尾は Co-Authored-By と Claude-Session の 2行
7. かずとも `speed-king`: `FLICK_MODES` / `FLICK_LINK_TARGETS` に `keisatsu`(PR → squash)。`HOME_GAMES` は 絵と OK の あと
8. けいくんに ChatGPT で 絵を 頼む 文を わたす(トップ 1536×1024 + 四角い 絵 1254px。**人物は 画面の 下 3分の1に 小さく**・指5本・首が 見える・**武器を 持たせない**(絵に 銃・警棒を 描かない。敬礼か 道案内の ポーズ)。
   絵の 中の 字は「フリック警察官」だけ・ゲームに 無い 機能の 絵を 入れない・**本物の 警察の 紋章(旭日章)や 実在の 県警の 名前を 描かない**)。届いたら **まず 字を 切り出して 読む**(「ごっかしけん」の 前例)
9. 絵を 入れたら CLAUDE.md に 節を 書く(名前・旅・語数・確かめた 日・入れなかった 語と 理由)

## 6. 気をつける 前例
- 看護師で 統合失調症 → 適応障害に 入れかえた(子どもが こわく 感じる)。警察官では **殺人・性犯罪・薬物の 具体名**などは 入れない(犯罪の 大きな 分け「凶悪犯」「知能犯」の ような 言いかたも、子どもには 重いので 入れるか けいくんに 聞く)
- 読みの かぶりは 片方を べつの 語に
- 絵は 1回目・2回目とも 字が ちがった → 絵の 中で 直した(`tools/kango/fix_text.py`)
- マイページ(右上の 1枚)は 土台の `index.html` に あるので、`SERIES` に 足すだけで 一覧の タイルにも 出る(絵は `keisatsu/apple-touch-icon.png`)
- 医師(`ishi/`)・教師(`kyoshi/`)・料理人(`chef/`)と 続けて 頼まれた。**同時に 作るなら フォルダ・id・modes 名を まぜない**(`ishi` / `kyoshi` / `chef` / `keisatsu`)
