# フリックITパスポート: 📝 本番形式の 4択(場面の 問題・擬似言語・表計算)の 作りかた

けいくん 2026-11-11「これで受かる?」→ ぼく「本番の 形(場面を 読んで えらぶ・プログラムを 読む)が 足りない」→ けいくん「3」(両方 足す)。
本番の ITパスポート試験は **小問 100問・4つから 1つ**。多くは「短い 場面(会社・学校・お店)+ 問い」の 形。⭕❌ の 組み合わせ(MARU.md)より 本番に 近い 問題を 作る。
🎯 模擬試験は この 問題を 中心に 出す(足りない ぶんを ⭕❌ の 組み合わせで うめる)。

## 旅ごとの 数
ぜんぶの 旅 30問(場面の 問題)。**kiso は +30問の 擬似言語**(合計 60)、**konpyuta は +20問の 表計算**(合計 50)= **350問**

## 決まり
1. `PROMPT.md` の「いちばん 大事な 決まり」を ぜんぶ 守る(中身は シラバス Ver.6.5 と facts-A/B/C.md の ものだけ・いまの 法律が 答え・攻撃の やりかたを 書かない・こわく しない・実在の 会社や 製品の 名前を 書かない)
2. ⭐ **場面は 自分で 作る**。IPA の 過去問・問題集の 文を 写さない(考えかたは 似て よいが、会社・数字・言いまわしは 自分の もの)。登場する 会社は「A社」「B高校」「C商店」の ように
3. 問い(`q`): **200字 以内**。最後は 試験と 同じ「〜として,最も適切なものはどれか。」「〜に該当するものはどれか。」「〜は幾らか。」の 形で よい。漢字は ふつうに 使う(ふりがなは 付かない)
4. 選択肢(`opts`): **ちょうど 4つ・ぜんぶ ちがう・1つ 60字 以内**。正解(`a`)は opts の 中の 1つと 1文字も ちがわない 文字列。
   ⭐ まちがいの 3つは **同じ なかまの 本物らしい もの**(SaaS を 聞くなら PaaS・IaaS・オンプレミス / 機密性を 聞くなら 完全性・可用性・真正性)。**答えが 2つ ある・どれも ちがう 問題を 作らない**。「すべて正しい」「どれでもない」は 使わない
5. `why`: **120字 以内**。なぜ 正解か + いちばん まちがえやすい 選択肢が なぜ ちがうか。やさしい です・ます
6. `law`: 法律名(条)か「シラバス 61 情報セキュリティ」の ような 小分類(MARU.md と 同じ)
7. `dv`: 2(基本)か 3(本番の 難しめ)。3 を 半分 以上
8. `rs`: 分野の 札(keiei・homu・senryaku・shisutemu = ストラテジ系 / kaihatsu・service = マネジメント系 / kiso・konpyuta・nettowaku・sekyuriti = テクノロジ系)。`term`: いちばん かかわる ことばの id(`terms-<旅>.json` に ある もの。無ければ 書かない)
9. 旅の 12の 図の 場所(mapNode)に **ちらして** 作る。同じ ことを 聞く 問題を 2つ 作らない。maru・num と 同じ 文を 使わない
10. ⭐ **計算の 問題は python で 計算して 答えを 確かめる**(稼働率・損益分岐点・クリティカルパス・転送時間・期待値 など)

## 💻 擬似言語(kiso の 30問)・📊 表計算(konpyuta の 20問)
- プログラムや 表は `code` に 書く(改行は \n。**14行 以内・1行 40字 以内**)。画面では 等幅の 字で 出る
- **擬似言語は IPA「試験で使用する情報技術に関する用語・プログラム言語など」別紙1(ITパスポート試験用)の 書きかた**(facts-B.md の 表に まとめて ある): `○手続名` / `整数型: x` / `x ← 1` / `if (条件) … elseif … else … endif` / `while (条件) … endwhile`(前判定)/ `for (i を 1 から 5 まで 1 ずつ増やす) … endfor` / 配列は `{3, 1, 4}`・**要素番号は 1 から** / `mod` / `and` `or` `not`。字下げは 全角スペース 2つ
- 問いは「プログラムを 実行した あとの x の 値」「空欄 a に 入る 字句」「出力される 数」など。⭐ **答えは かならず python で 同じ 手順を 動かして 確かめる**
- **表計算は 別紙3(ITパスポート試験用)の 書きかた**: セルは `A1`・範囲は `A1:B3`・`$` の 絶対参照・算術演算子 `+ − * / ^`・関数は 別紙3 に ある 名前(`合計(A1:A5)`・`平均(…)`・`IF(論理式, 式1, 式2)` など。**別紙3 を WebFetch で 開いて 関数名と 書きかたを 確かめる**。製品の 関数名(SUM など)は 使わない)。
  問いは「セル C2 の 式を C3〜C5 に 複写した ときの C5 の 値」「空欄に 入る 式」など。表は `code` に「   A     B     C」の ように 字で 書く
- `k`: 擬似言語は "code"、表計算は "sheet"(場面の 問題は 書かない)
