# フリック数学旅行: ことばの 作りかた(助手に 分けて 頼むときの 決まり)

ゲームは「表示された ひらがなを フリックで 打ち写す」タイピング。打ち終わると ことばの 説明(1〜3文)と、図が ある ときは 図(📍つき)が 出る。
遊ぶのは 小学生〜高校生・大人。**算数〜高校受験・大学受験の 数学で 要る 用語・公式・定理の 名前と 意味を おぼえる ゲーム**。
(けいくん 2026-09-27: 名前「フリック数学旅行」/ 4段 / 公式を 打つ 問題を 入れる / 図を コードで 描く / 数学者の 旅も 入れる / 受験に 要る 計算問題も 入れる(計算は ゲームの プログラムが 作るので ここでは 作らない))

## 1語の 形(JSON)
{"id":"zu-sanheiho","name":"三平方の定理","reading":"さんへいほうのていり","journey":"zukei","category":"三角形","difficulty":2,"grade":"中3",
 "type":"concept","emoji":"📐","figure":"right:hyp","relatedTerms":["zu-chokkaku"],
 "description":"直角三角形で、斜辺の 長さの 2乗は ほかの 2辺の 長さの 2乗の 和に 等しい という 定理です。a²+b²=c² と 書きます。ピタゴラスの定理とも いいます。"}

- id: 旅の 頭 + "-" + 英小文字(ka- / zu- / si- / fn- / de- / ad- / hi-)。英小文字・数字・- だけ。ぜんぶで かぶらない
- name: 画面に 出す 字(漢字・かな・数式)。**打つ 字(ひらがな)は 出さない**(name に ふりがなや かっこの 読みを 付けない)
- reading: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)。
  ゆれる 読みは 1つに 決め、別の 読みは "acceptedReadings":["よみ1","よみ2"](先頭は reading と 同じ)。例: 組合せ = くみあわせ
- difficulty(4段。**いまの 学習指導要領**(小中 平成29年告示・高校 平成30年告示。高校は 2022年度から)で 決める):
  - 1 = **入門**(小学校の 算数)
  - 2 = **初級**(中学の 数学 = 高校受験の めやす)
  - 3 = **中級**(高校 数学Ⅰ・数学A)
  - 4 = **上級**(高校 数学Ⅱ・数学B・数学Ⅲ・数学C = 大学受験の めやす)
- grade: はじめて 習う 学年・科目。"小1"〜"小6" / "中1"〜"中3" / "数学Ⅰ" "数学A" "数学Ⅱ" "数学B" "数学Ⅲ" "数学C"(Ⅰ Ⅱ Ⅲ は ローマ数字の 字)。difficulty と 合わせる(小→1 / 中→2 / 数学Ⅰ・A→3 / Ⅱ・B・Ⅲ・C→4)
  - 参考(いまの 課程): 小5 平均・割合・百分率・素数は 中1 / 小6 比・比例反比例・代表値(平均値・中央値・最頻値)・ドットプロット・並べ方組み合わせ方 / 中1 正負の数・文字式・一次方程式・比例反比例・平面図形(おうぎ形)・空間図形・ヒストグラム・相対度数・累積度数・素数・素因数分解 / 中2 式の計算・連立方程式・一次関数・平行と合同・三角形と四角形・確率・箱ひげ図・四分位範囲 / 中3 展開と因数分解・平方根・二次方程式・関数y=ax²・相似・円周角・三平方の定理・標本調査 / 数学Ⅰ 数と式(実数・絶対値・一次不等式・集合と命題)・図形と計量(三角比・正弦定理・余弦定理)・二次関数・データの分析(分散・標準偏差・相関係数・散布図・仮説検定の考え) / 数学A 図形の性質(三角形の五心・チェバ・メネラウス・方べき)・場合の数と確率(順列・組合せ・条件付き確率・期待値)・数学と人間の活動(ユークリッドの互除法・n進法・不定方程式) / 数学Ⅱ 式と証明・複素数と方程式・図形と方程式・指数対数・三角関数・微分積分の考え / 数学B 数列・統計的な推測(確率分布・二項分布・正規分布・推定・仮説検定)・数学と社会生活 / 数学Ⅲ 極限・微分法・積分法 / 数学C ベクトル・平面上の曲線と複素数平面・数学的な表現の工夫
- 数: difficulty ごとの 数は 下の 表。同じ difficulty の 中は **よく 出る・大事な 順**(ゲームは その 順に 10語ずつ ステージに する)
- type: いつも "concept"
- category: 図鑑で しぼる 分類(短い 日本語。旅の 中で 3〜8種類)。**公式を 打つ 語は category を かならず "公式を打つ"** に する
- emoji: 1つ
- figure: 図が 合う 語だけ(なくてよい。旅の 半分くらいに 付くと よい)。**下の「図の 一覧」に ある "図:部分" だけ** 使える。部分が 📍と 色で 目立つ
- relatedTerms: **同じ ファイルの 中の** id を 1〜3個(自分は ダメ)。いっしょに おぼえると よい ことば
- description: 1〜3文・**130字以内**。やさしい です・ます。「意味 / 使いかた・どこが 大事か」。
  語と 語の あいだに 半角スペースを 入れる 書きかた(この シリーズの 文体。上の 例のように)。数式は a²+b²=c² / √2 / π / x² / 1/2 / sin θ のように ふつうの 字で(LaTeX は 使わない)
  ⚠️ **説明の 中に その 語の 読みを ひらがなで 書かない**(答えが 見えて しまう)
  ⚠️ **説明の 中に その 語の name そのものを なるべく 書かない**(「〇〇とは〜」で 始めない)

## 公式を 打つ 語(category "公式を打つ")
- name は **公式そのもの**(例 "a²+b²=c²"・"S=πr²"・"x=(−b±√(b²−4ac))/2a")。reading は その **読みあげ**
- 読みあげの きまり(ぜんぶ ひらがな。ゆれを 出さない):
  足す → たす / 引く → ひく / 掛ける → かける / 割る → わる / = → いこーる / ² → のにじょう / ³ → のさんじょう / ⁿ → のえぬじょう /
  √ → るーと(√2 = るーとに)/ a/b → びーぶんのえー / π → ぱい / θ → しーた / ± → ぷらすまいなす / − が 符号(−b)→ まいなす /
  文字は 英語の 読み: a えー / b びー / c しー / d でぃー / h えいち / l える / n えぬ / r あーる / S えす / V ぶい / x えっくす / y わい /
  sin → さいん / cos → こさいん / tan → たんじぇんと / log → ろぐ / Σ → しぐま / ∫ → いんてぐらる / lim → りみっと / ′ → だっしゅ
  かっこは 読まない。数字は ひらがなの 読み(2 → に / 4 → よん / 1/2 → にぶんのいち)
  例: a²+b²=c² → えーのにじょうたすびーのにじょういこーるしーのにじょう / S=πr² → えすいこーるぱいあーるのにじょう
- 説明には「何の 公式か / 文字が 何を 表すか」を 書く
- 数は 旅ごとに 下の 表の とおり(むずかしさ 2〜4 に 散らす)。長すぎる 公式(読みが 40字を こえる)は 入れない

## ぜったいに 守ること
- **自分の ことばで 書く**。入試の 過去問・問題集・参考書・教科書・Wikipedia の 文を 写さない
- **意味・定義を 正しく**。とくに まちがえやすい ところ: 約数に 1と その数 じしんも 入る / 素数に 1は 入らない / 0は 自然数に 入れない(高校までの きまり)/ 平方根は 正と 負の 2つ(√ は 正の ほう)/ 中央値は データが 偶数個なら まんなか 2つの 平均 / 相関係数は −1〜1 / 三角比の 定義 など
- 事実は **まちがいない ときだけ**。あやしい 語・学年が はっきり しない 語は 入れない。数学者の 話で 伝わっている だけの ものは「〜と 言われています」
- 「合格できる」「共通テストに 出る」と 言いきらない。「受験で よく 見る」くらいに する
- 「100マス計算」「百ます計算」の 字は 使わない。お店・商品の 名前は 使わない
- ほかの 旅と かぶらない(下の「入れる / 入れない」)。**reading も ほかの 旅と かぶらない**
- 計算の しかた そのものの 練習(たし算の しかた など)は 入れない。**用語・公式・定理の 名前と 意味**
