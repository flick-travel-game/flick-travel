# フリックキャビンアテンダント: ことばの 作りかた(助手に 分けて 頼むときの 決まり)

けいくん 2026-10-20「キャビンアテンダントに受かるレベルになるために必要な知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」・デッドヘッドは「入れる」・並びは「パイロットのすぐあと」。
もとは `tools/pilot/PROMPT.md`(パイロット)と `tools/manner/PROMPT.md`(マナー)・`tools/kyukyutai/PROMPT.md`(救急隊)

## ⚠️⚠️⚠️ いちばん 大事な 決まり(さいしょに 読む)
1. **こわく しない**。客室乗務員の いちばんの しごとは **みんなを 安全に 守る こと**。緊急の ことばは
   **「そう ならない ように / なっても 早く 安全に する しくみ」の 向き**で 書く。
   「落ちる」「墜落」「事故」「死」「けが」「危険」「こわい」「爆発」「ハイジャック」「テロ」「炎上」の 字は **使わない**(`terms_js.py` が 止める)
   - 脱出スライド →「ドアを ひらくと ふくらむ すべり台。みんなが 早く 安全に 外へ 出られる ための しくみです。」まで
   - 乱気流 →「空気が ゆれて 飛行機が ゆれる こと。シートベルトを しめていれば 安全です。」まで
   - 緊急脱出の かけ声は 1語ずつ「こうして 早く 安全に 外へ」の 向きで(本物の かけ声の 文を ならべない)
2. **人を 見た目で 決めつけない**。「きれいな 人が なる しごと」「身長が ◯cm 以上」の ような 書きかたを **しない**。
   **だれでも めざせる しごと**。ひつような のは **安全を 守る 力・おもてなしの 心・語学・チームワーク**。⭐ 男性の 客室乗務員も いる。
   身だしなみは「せいけつ・安全・お客さまが 安心する」の 向きで
3. **実在の 航空会社の 名前・制服・社内の マニュアル・採用の コツ**を 書かない(商標・社外秘)。
   機体メーカー(ボーイング・エアバス)は **事実の 説明に 1回だけ**。今の 航空会社の 名前は 使わない
4. **事故・墜落・ハイジャック・テロ・こわい 病気の ようす・けがの ようす**は 入れない。**薬の 名前と 量は 書かない**。
   **お酒の すすめかた**は 書かない(「飲みすぎに 気を くばる」は よい)
5. **給料・合格率・身長 体重の 条件・TOEIC の 何点が 必要か**は 書かない(会社で ちがう)
6. **宗教・文化・国の 人を 決めつけない**。「◯◯の 国の 人は ◯◯」と 書かない。「こういう 決まりを 大事に する 人が いる」の 向きで
7. **人を 責めない**。「マナー違反」「非常識」「失礼」「はずかしい」は 人に 向けて 使わない
8. **数字は まちがいない ものだけ**(空港コード・時差は とくに 気をつける)。記憶で あやしい ものは 書かない・入れない
9. **自分の ことばで 書く**。会社の サイト・問題集・Wikipedia の 文を 写さない。長い アナウンスの 文を まるごと 写さない

## ゲームの かたち
「表示された ひらがなを フリックで 打ち写す」タイピング。打ち終わると ことばの 説明(1〜3文)が 出る。
遊ぶのは 小学生〜客室乗務員を めざす 学生・大人。**客室乗務員の ことばを おぼえる ゲーム**(面接・笑顔は ゲームの 外で)

## 1語の 形(JSON)
{"id":"ki-galley","name":"ギャレー","reading":"ぎゃれー","journey":"kihon","category":"客室の 場所","difficulty":1,"type":"concept",
 "emoji":"🍳","mapNode":"kihon:galley","field":"サービス","relatedTerms":["ki-cart","ki-jumpseat"],
 "description":"機内の 小さな 台所です。食事を あたためたり、飲みものを 用意したり します。ゆれても 物が 動かない ように、ロックが ついて います。",
 "settai":"(なくてもよい)お客さまに どう つかうか 1文","ei":"(英語の 語・ひとことだけ)英語の つづり","example":"(なくてもよい)たとえば〜"}

- id: 旅の 頭文字2つ + "-" + 英小文字(ki- / ho- / ky- / se- / ma- / ei- / sk- / ku- / sh-)。英小文字・数字・- だけ
- name: 画面に 出す 名前(漢字・カタカナ・英字。ふつうの 言いかた。英語の ひとことは 英字で「Welcome aboard」)
- reading: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白は ダメ)
  - 英語の 語(ギャレー・ボーディング)は **ふだんの カタカナ読みを ひらがなで**(ぎゃれー・ぼーでぃんぐ)
  - 英語の ひとこと(Welcome aboard)も カタカナ読みの ひらがな(うぇるかむあぼーど)。空白は 入れない
  - 英字の 略語は 日本の ふつうの 読み(AED → えーいーでぃー / CA → しーえー)。空港コード は 1字ずつ(HND → えいちえぬでぃー)
  - 数字は ひらがな
  - ゆれる ことばは 1つに 決め、別の 読みは "acceptedReadings":["よみ1","よみ2"](先頭は reading と 同じ)
  - ⚠️ **読みは この ゲームの 9つの 旅の 中で かぶらない**(同じ 読みの 語を 2つ 入れない)
- difficulty: 1 = 入門(飛行機・旅行が すきな 子) / 2 = 採用めやす(採用試験を うける 人) / 3 = 訓練めやす(入社後の 訓練)
- type: いつも "concept"
- category: 図鑑で しぼる 分類(短い 日本語。旅の 中で 4〜8種類)
- emoji: 1つ
- mapNode: その 旅の 図の 場所(下の 表から)
- field: **保安 / 救急 / サービス / 接遇 / 英語 / 世界の文化 / 空港 / しごと** の どれか
- relatedTerms: **同じ ファイルの 中の** id を 1〜3個(自分は ダメ)
- description: 1〜3文・**130字以内**。やさしい です・ます。語と 語の あいだに 半角スペースを 入れる 書きかた(上の 例のように)。
  **カタカナ語を ならべない**。ふつうの 言葉で 言いかえて から 専門の 名前(「ギャレー = 機内の 小さな 台所」)。
  **客室乗務員の 目線**で 書く(パイロット・マナー・救急隊・英会話・料理人と 同じ 語でも 書きなおす)。
  ⭐ ときどき「へえ」と 思える 事実を 1文(⚠️ 頭に「へえ:」とは 書かない。🔊 よみあげで 読まれる)
- settai: **任意**(⭐ 接遇・サービス・英語の 語には なるべく 付ける)。1文・60字以内で「お客さまに どう つかうか」
  (例: 「かしこまりました」→「たのまれた ことを うけとった ときの ていねいな 返事です。」)。画面では「🤝 おもてなし」と して 出る
- ei: **英語の 語・英語の ひとことだけ**(任意)。英語の つづり(例 "Welcome aboard." / "galley")。🔊 ボタンで 英語の 音を 聞ける
- example: なくてもよい

## 旅ごとの 語数
**110語: difficulty 1 を 30語、2 を 40語、3 を 40語**。同じ difficulty の 中は 有名な・大事な 順。
1回目は 70語 = 20 / 25 / 25(`tools/cabin/terms-<旅>.json`)。2回目に 40語 = 10 / 15 / 15(`tools/cabin/later/terms-<旅>.json`)を うしろに 足す。前の 語の 順番・中身は 変えない

## ほかの ゲームと かぶる 語
パイロット・マナー・救急隊・英会話・料理人・世界旅行と 同じ 語を 入れて よい(けいくん決定 2026-09-30「復習になるから」)。説明は **客室乗務員の 目線**で 書きなおす

## 入れなかった ことば(けいくん 2026-10-20 の えらび)
- ⭐ **デッドヘッド は 入れる**(けいくん「入れる」)。上級に 1語。「乗務は せずに、お客さまと 同じ 席に 乗って つぎの 空港へ 移動する こと」まで。⚠️ 名前の 由来・こわい 意味には ふれない
- 事故・墜落・ハイジャック・テロ・不時着・遭難・減圧の こわい ようす・有名な 事故の 名前と 日付
- 給料・合格率・身長 体重の 条件・TOEIC の 点数・実在の 会社の 採用の コツ・制服・社内の きまり
- 薬の 名前と 量・こわい 病気の ようす・お酒の すすめかた

## 出すもの
`tools/cabin/terms-<旅id>.json`(1回目 70語)と `tools/cabin/later/terms-<旅id>.json`(2回目 40語)に JSON の 配列で 書く。
書いたら `python3 tools/cabin/terms_js.py --check` で 確かめる(`--with-later` で 2回目も 合わせて 確かめる)
