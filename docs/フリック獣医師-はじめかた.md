## 3. ⚠️⚠️⚠️ ぜったいの 決まり(医師・薬剤師と 同じ。動物が すきな 子が あそぶ ので なおさら)

- ⚠️⚠️ **動物の いのちの 終わりの 話は 書かない**(安楽死・殺処分・と畜・寿命の 数字)。**子どもは 自分の ペットを 思いうかべる**。
  - **保護犬・保護猫**は「**新しい 家族を まって いる 犬や 猫。ゆずり受けて 家族に なれる**」と 前向きに
  - **食肉衛生検査**は「**お店に ならぶ お肉が 安全か、獣医師が 確かめて いる**」まで
  - **動物の 年をとる 話**は「シニア期 = 年を とった ころ。ゆっくり すごせる 工夫を する」まで
- **小学生も あそぶ**: 血・苦しむ ようす・こわい 先を 書かない。病気は「何が 起きている 状態か」+「獣医さんが 助ける」だけ。**めずらしい 病気・こわい 病名の ならびは 入れない**。**迷ったら 入れない**(看護師で 統合失調症を 外した 目で 見る)
- **人獣共通感染症・家畜伝染病は こわく 書かない**: 「**手洗い・予防注射・みんなで 防いで いる**」で 終わる。動物を こわがらせる・きらいに させる 書きかたを しない

- **読み(ひらがな)は 獣医師の 9つの 旅の 中では かぶらない**(ほかの ゲームとは かぶって よい。`terms_js.py` が 止める)。⚠️ `pet` と `yobo`(フィラリア・ノミ)、`byoki` と `yobo`(健康診断)、`sangyo` と `koshu`(家畜伝染病)、`koshu` と `hoki`(狂犬病予防法)は かさなりやすい。**先に 9つの 旅の 語の 一覧を 1人の 助手に 作らせて** 置き場所を 決めてから 頼む

## 5. 作りかたの 手順(医師・薬剤師の ときと 同じ)
1. けいくんに 2 の 5つを 聞く → 返事を CLAUDE.md に 書く
2. `tools/jui/PROMPT.md` `exam.txt` `mkmeta.py` → `meta.json` を 作る → **先に 9つの 旅の 語の 一覧を 1人の 助手に 作らせて 置き場所を 決める** → 旅ごとに 助手に 70語ずつ 頼む(`PROMPT.md` を そのまま わたす。**助手は 2人ずつ**)→ `terms-<旅>.json`
3. `terms_js.py` で 止められた 語を 直す → 別の 助手が 1語ずつ 確かめる(**治療の やりかた・いのちの 終わり・こわさ・商品名**)→ ふりがな
4. `jui/jui.js`(ishi.js を 写し、動物の 札を 足す)・`build_games.py`・`index.html` の PLUG と SERIES → `python3 tools/build_games.py`
5. 手元で 通す: `python3 -m http.server 8765` → `node tools/play-all.mjs jui/` / `node tools/click-all.mjs jui/`(W=320 も)
6. PR は **rebase で 取りこむ**(この 入れもの)。speed-king は squash。コミットの 末尾は Co-Authored-By と Claude-Session の 2行
7. かずとも `speed-king`: `FLICK_MODES` / `FLICK_LINK_TARGETS` に `jui`(PR → squash)。`HOME_GAMES` は 絵と OK の あと
8. けいくんに ChatGPT で 絵を 頼む 文を わたす。**3つ**:
   ・トップの 絵(1536×1024)。**人物は 画面の 下 3分の1に 小さく**・指5本・首が 見える。明るい 動物病院の 前で、白衣で 聴診器を 首に かけた 子どもと 白い 犬が 笑っていて、まわりに 猫・うさぎ・小鳥・ハムスター。遠くに 牧場の 牛と 動物園の キリン。
