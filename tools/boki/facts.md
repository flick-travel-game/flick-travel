## 1. 主催・受験資格

- 商工会議所の 検定は「『商工会議所法』という法律に基づいて、全国統一の基準により実施している『公的試験』」。
  申込は 各地の 商工会議所(申込の日時・方法は 商工会議所ごとに ちがう。試験日の 約2か月前に 問い合わせる)。
  — https://www.kentei.ne.jp/guide / https://www.kentei.ne.jp/bookkeeping (2026-11-07 確認)
- 受験資格:「DCプランナー1級や、日商マスターなど、一部の上級試験を除けば、誰でも受験することができます。」簿記は 除外の 例に 入っていない = だれでも 受けられる。
  — https://www.kentei.ne.jp/guide (2026-11-07 確認)
- 国税庁の 税理士試験の ページでは「日本商工会議所主催簿記検定試験1級」と 書かれている(主催 = 日本商工会議所)。
  — https://www.nta.go.jp/taxes/zeirishi/zeirishishiken/shikaku/shikaku.htm (2026-11-07 確認)

## 2. 3級・2級

### 試験の 形と 日
- ネット試験の 対象: 2級・3級・簿記初級・原価計算初級。
  — https://www.kentei.ne.jp/bookkeeping (2026-11-07 確認)
- 2026年度の 統一試験(ペーパー):
  第173回 2026年6月14日(日) 1〜3級 / 第174回 2026年11月15日(日) 1〜3級 / 第175回 2027年2月28日(日) 2〜3級 。
  → 2級・3級の 統一試験は 年3回(6月・11月・2月)。
- 2級・3級の ネット試験は 試験日を 各ネット試験会場が 決める(=随時)。統一試験の 前後に 休止期間あり
  (2026年度: 4/1〜4/13、6/8〜6/17、11/9〜11/18、2027/2/22〜3/3)。
  — https://www.kentei.ne.jp/calendar_2026 (2026-11-07 確認)

### 3級(https://www.kentei.ne.jp/bookkeeping/class3/exam 2026-11-07 確認)
- 科目: 商業簿記。出題: 3題以内。試験時間: 60分。合格基準: 70%以上。
- 2021年度から この 問題数・時間に なった。
- 電卓は 四則演算の みの もの(そろばんか 電卓 どちらか1つ)。

### 3級の 配点(大問ごと)
- **2027年4月1日以降**(ネット・統一・団体 すべて): 第1問 45点 / 第2問 25点 / 第3問 30点 = 100点、合格 70点以上。
  公表 2026年9月25日。**2027年3月31日までは「従来の配点」**(記事に 数字は 書いていない)。1級・2級・初級・原価計算初級は 配点・出題形式の 変更なし。
  — https://www.kentei.ne.jp/51504 (2026-11-07 確認)
- 公式サンプル問題(3級): 第1問は 仕訳 15問(勘定科目を ア〜カから えらぶ)/ 第2問(2)は 商品有高帳(移動平均法)/ 第3問は 決算整理前残高試算表+決算整理事項等。
  サンプルに 点数は 書いていない。
  — https://www.kentei.ne.jp/bookkeeping/sample/sample_3 とその PDF (2026-11-07 確認)

### 2級(https://www.kentei.ne.jp/bookkeeping/class2/exam 2026-11-07 確認)
- 科目: 商業簿記・工業簿記(原価計算を含む)。出題: 5題以内。試験時間: 90分。合格基準: 70%以上。
- 毎年4月1日現在 施行されている 法令に 準拠。
- 公式サンプル問題(2級): 第1問 = 仕訳 5問 / 第2問 / 第3問 / 第4問(1) = 工業簿記の 仕訳(サンプル1は 3問)/ 第4問(2) / 第5問。
  — https://www.kentei.ne.jp/bookkeeping/class-s/sample/sample-two とその PDF (2026-11-07 確認)
- **2級の 大問ごとの 配点は 公式ページに 見当たらない(未確認)**。

## 3. 1級(https://www.kentei.ne.jp/bookkeeping/class1/exam 2026-11-07 確認)
- 科目と 時間:「商業簿記・会計学」90分 /「工業簿記・原価計算」90分(途中休憩あり)。9時開始。片方だけの 受験は できない。
- 合格基準: 70%以上。ただし 1科目ごとの 得点は 40%以上。
- 回数: 2026年度は 第173回(6月14日)・第174回(11月15日)の 年2回(第175回 2月は 2〜3級のみ)。— https://www.kentei.ne.jp/calendar_2026
- 1級の ページ:「合格すると税理士試験の受験資格が得られる。」— https://www.kentei.ne.jp/bookkeeping/class1
- 国税庁: 令和5年度(第73回)税理士試験から 会計学に属する科目(簿記論・財務諸表論)は 受験資格の 制限なし(だれでも)。
  税法に属する科目は 学識・資格・職歴の どれか1つが 要り、「資格による受験資格 イ 日商簿記検定1級合格者」。
  → いま 日商1級が 意味を もつのは **税法科目の 受験資格**。
  — https://www.nta.go.jp/taxes/zeirishi/zeirishishiken/shikaku/shikaku.htm (2026-11-07 確認)

## ⚠️ 古いテキストと ちがう ところ
- **3級は 2021年度から 3題以内・60分**(公式の 文「2021年度から」。それより前の 形は 公式で 確かめていない)。2級は 5題以内・90分。
- **2027年4月1日から 区分表が 大きく 変わる**(紙の 手形・小切手の 廃止 + 新リース会計基準):
  - 手形の 項目(振出・裏書・割引・不渡・手形貸付金 など)は **区分表から すべて 削除**。受取手形・支払手形・不渡手形・手形売却損も 許容勘定科目表から 消えた。
  - 「普通預金」を 区分表に 明記。電子記録債権・電子記録債務は「売掛金および買掛金ならびに電子記録債権等」へ。営業外電子記録債権・債務も 明記。
  - クレジット売掛金は「キャッシュレス決済を含む」。売掛債権の譲渡(ファクタリング)※は 2級(勘定は 売掛債権売却損)。
  - **2級 → 3級 に 移る**: 販売のつど 売上原価勘定に 振り替える 方法 / 有形固定資産の 除却・廃棄(固定資産除却損・固定資産廃棄損)/ **定率法※**(償却率を 示す 簡易な 出題のみ。200%定率法の 保証率・改定償却率は 3級に 出ない)。
  - リース: 名前が「リース」に。2級は 借手のみ・利子込み法と 利子抜き法(定額法)の まま。**勘定が 使用権資産 / リース負債 / 使用権資産減価償却累計額 に**(前は リース資産 / リース債務)。短期リース・少額リース(支払リース料)を 2級に 新設。
  - 2級以上では 不動産の 賃借の 賃貸借処理は **支払リース料**(支払家賃・支払地代を 使わない)。3級は 支払家賃・支払地代・受取家賃・受取地代の まま。
  - 3級の 配点が 第1問45点・第2問25点・第3問30点 に。
- 税理士試験: 令和5年度から 簿記論・財務諸表論は だれでも 受けられる。日商1級は 税法科目の 受験資格として 残る。
