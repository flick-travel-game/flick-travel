# フリック映画評論家(`eiga/`)を 作る ための まとめ(2026-10-12。新しい セッション用)

けいくん 2026-10-12「新しいセッションで フリック映画評論家を作成したい。**映画評論家の世界トップレベル**になるために必要な 知識をフリック形式の問題にしてください」

⭐ **国家資格の 無い「文化・学問」の ゲーム**。いちばん 近い 兄弟は **フリック哲学(`tetsugaku/`)**(資格が 無い・立場が ならぶ・決めつけない)と **フリック歴史(`rekishi/`)**(実在の 人の 書きかた)、**ワールドサッカー / バスケ / ベースボール**(実在の 作品名・人名を 事実として 入れる 型)。
⚠️⚠️ ほかの ゲームに 無い 3つの 気をつけ: ① **映画の 題名・監督・俳優は 実在**(事実として 書いて よいが、**絵には 描かない**・あらすじは 1行まで・**結末(ネタバレ)を 書かない**)② **小学生が あそぶ**ので **こわい 映画・大人むけの 映画は 題名も 入れない**(下の 3)③ **評論は「意見」の 学問**。「名作」「傑作」を 事実のように 書かない(「よく 名作として 挙げられる」まで)。

4. **1語に 持たせる 分野**(`field`): 映画史 / 技法 / 物語 / 作品・人 / 賞・映画祭 / 評論 / 業界 の 7つ くらいで よい(資格の 科目は 無いので、**大学の 映画学科・映画史の 教科書の 章立て**を めやすに)
5. **入れない もの**(下の 3 と かさなる): **R15+ / R18+ の 作品**(題名も)・**ホラー / 暴力 / 戦争の 作品の 題名**(⚠️ 有名でも)・**結末(ネタバレ)**・**興行収入・観客数・歴代◯位**(⚠️ 変わる)・**俳優の 私生活・スキャンダル・事件**・**亡くなった 人の 亡くなった 話**・**映画を けなす ことば**(駄作・失敗作・ラジー賞)・**生きている 評論家の 名前**・**配信サービス・映画館チェーン・カメラの 商品名**・**映画の キャラクターの 絵・ロゴ**・**まんが・アニメの 登場人物の 名前を 答えに する**(⚠️ 作品名は よい。キャラクター名(トトロ・アトム)は **説明の 中で 1回まで**。答えに しない)

## 3. ⚠️⚠️⚠️ ぜったいの 決まり(哲学・ワールドサッカーと 同じ + この ゲームだけの もの)
- ⭐⭐⭐ **この ゲームだけの いちばん 大事な 決まり: 子どもが 見て よい 映画だけ**。題名を 入れるのは **G か PG12 の 作品だけ**(⚠️ 映倫の 区分を **確かめる**。海外の 作品は 日本公開時の 区分)。**R15+ / R18+ は 題名も 入れない**。PG12 でも **こわい・暴力・戦争が 中心の 作品は 入れない**。**迷ったら 入れない**。
  ⚠️ 「映画史に 残る 名作」でも ここは ゆずらない(『ゴッドファーザー』『時計じかけのオレンジ』『羊たちの沈黙』『セブン』『ジョーカー』『パラサイト』は **入れない**)。歴史の 流れ(ニューシネマ など)は **作品名を 出さずに** 書く
- ⭐⭐ **ネタバレを 書かない**。あらすじは **「どんな 話の はじまりか」1行まで**。**結末・どんでん返し・だれが 何者か**は 書かない。「どんでん返しで 有名な 作品」の **例の 題名も 書かない**(それ自体が ネタバレ)
- ⭐⭐ **数字が 変わる ものを 書かない**: 興行収入・観客動員・歴代◯位・配信の 再生数・いまの 評価点(⚠️ レビューサイトの 点)・**俳優の いまの 所属**・いまの 公開中の 作品。
  ✅ **変わらない 事実は よい**: 公開年・監督・**受賞と その 年**・映画祭の 開かれる 街・技法の 名前・「はじめての ◯◯」(**確かめて から**)
- ⭐ **評論は 意見**。「名作」「傑作」「最高」を **事実のように 書かない**。「名作として よく 挙げられる」「映画史の 教科書に 出る」「多くの 評論家が 高く 評価した」まで。**ランキング(◯位)を 書かない**。**映画を けなさない**(駄作・失敗作・つまらない)
- **実在の 人は 功績だけ**(歴史旅行と 同じ): 監督・俳優の **作品と 技法**で 書く。**私生活・事件・病気・亡くなった 話**は 書かない。⚠️ **俳優の 名前は 答えに しにくい**(作品が 多く、1人の 俳優 = 1つの 答えに ならない)。**答えは 監督・作品・技法・ことば**を 中心に、俳優は 説明の 中で
- ✅ **実在の 作品名・監督名・会社名・映画祭の 名前は 入れて よい**(事実として。ワールドサッカーと 同じ)。
  ❌ ただし **絵には 1つも 描かない**(キャラクター・ロゴ・ポスター・俳優の 顔)。**著作権**。旅の 図も **棒人間と 枠**だけ
- ⚠️ **キャラクターの 名前を 答えに しない**(トトロ・アトム・ゴジラ・ヨーダ)。作品名(『となりのトトロ』)は 答えに して よい。キャラクター名は 説明の 中で 1回まで
- **会社・サービスを 上に 書かない**(東宝 / 東映 / 松竹・ディズニー / ピクサー・配信サービス)。会社の 名前は 事実として。**配信サービス・映画館チェーン・カメラや 編集ソフトの 商品名は 書かない**(IMAX は 入れなくて よい)
- **生きている 評論家の 名前を 入れない**(評論は 意見なので 本人の 立場に かかわる)。亡くなった 評論家(淀川長治・水野晴郎・イーバート)は **功績だけ**
- **小学生も あそぶ**: こわい・暴力・戦争・事件・人の 死の 話は 入れない。映画史で 戦争に ふれる ときは 「戦争の 時代の くらしを えがいた」まで。**迷ったら 入れない**(看護師で 統合失調症を 外した 目で 見る)
- ✅ **ほかの ゲーム(国語の 物語の 作りかた・歴史の 人物・世界旅行の 街・ゲームクリエイターの 演出・AI の CG など)と 同じ 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。説明は **映画の 目線**(「スクリーンで どう 見えるか」)で 書きなおす
- **読み(ひらがな)は 映画評論家の 9つの 旅の 中では かぶらない**(ほかの ゲームとは かぶって よい。`terms_js.py` が 止める)。⚠️ `kihon` と `gyokai`(配給・興行・映画館)、`rekishi` と `sekai`(チャップリン・スピルバーグ)、`giho` と `hihyo`(モンタージュ・カメラの 位置)、`sho` と `nihon`(日本アカデミー賞)は かさなりやすい。**先に 9つの 旅の 語の 一覧を 1人の 助手に 作らせて** 置き場所を 決めてから 頼む
- **作品名の 書きかたを そろえる**(**『 』で かこむ**・日本公開時の 題名・『スター・ウォーズ』の ように 中点)。⚠️ **答えに する ときは 『 』を 外した 字**を 打つ(フリックで 打てない 記号を 答えに 入れない)。副題(『〜 エピソード4』)は **説明に**
- 画面(ホームの 下・遊びかた)に「これは ことばを おぼえる ゲームです。**映画の 感じかたは 人それぞれ**。自分の 目で 見て、自分の ことばで 書いて みよう」「映画は 作った 人の 作品です。**年れいに 合った 映画を えらんで、正しい 方法で 見よう**」「各映画会社・映画祭・団体とは 関係ありません」
- **作った 助手とは 別の 助手が 1語ずつ 確かめる**(**作品と 監督と 年の 組み合わせ**(⭐ いちばん まちがえやすい)・**映倫の 区分**・**ネタバレが 無いか**・**けなして いないか**・**変わる 数字が 無いか**・**キャラクター名を 答えに して いないか**・商品名)。ふりがなも 全語 見る(`tools/ruby_fix.json`)

## 4. めやすの 事実は **その日に 公式の ページで 確かめてから** 書く
映画評論家には **国家資格も 決まった 検定も 無い**(⚠️ 哲学・アドラー心理学と 同じ)。`meta.json` の `exam` には「評論家に なる 道」を 確かめた 日つきで 書く(**記憶で 書かない**):
**大学の 映画学科・映像学科**(日本大学芸術学部 など。⚠️ 学校名を 出すなら 確かめる)/ **専門学校**/ **映画雑誌・新聞・ウェブで 書く**/ **映画祭の 審査員**/ **本を 書く**/ **映画検定**(⚠️ 民間の 検定が あったか・いま あるか **確かめる**。無ければ 書かない)。
**確かめる 先**: 映倫(区分)・各映画祭の 公式(受賞と 年)・アカデミー賞の 公式(賞の 名前。⚠️ 2026年に 変わった 賞が ないか)・日本映画製作者連盟(公開の 事実)・作品の 公式サイト(公開年・監督)。
⚠️ 「世界トップレベル」= **映画史・技法・物語の 型・評論の ことばを ひととおり 知っている**こと、と けいくんに 伝える。評論家の 本当の 力は「**たくさん 見て、自分の ことばで 根拠を 書く こと**」。ゲームで つくのは その ための ことばの 土台

## 5. 作りかたの 手順(哲学の ときと 同じ)
1. けいくんに 2 の 5つを 聞く(⭐ **章の 場所も**)→ 返事を CLAUDE.md に 書く
2. `tools/eiga/PROMPT.md` `meta.json` を 作る → **先に 9つの 旅の 語の 一覧(とくに 作品名の 置き場所と 映倫の 区分)を 1人の 助手に 作らせて 決める** → 旅ごとに 助手に 70語ずつ 頼む(`PROMPT.md` を そのまま わたす。**助手は 2人ずつ**)→ `terms-<旅>.json`
3. `terms_js.py` で 止められた 語を 直す → 別の 助手が 1語ずつ 確かめる(**作品と 監督と 年・映倫・ネタバレ・けなし・変わる 数字・キャラクター名**)→ ふりがな
4. `eiga/eiga.js`(tetsugaku.js を 写し、国の 札・年代の 札・映画の 年表を 足す)・`build_games.py`・`index.html` の PLUG と SERIES と SERIES_ORDER → `python3 tools/build_games.py`
5. 手元で 通す: `python3 -m http.server 8765` → `node tools/play-all.mjs eiga/` / `node tools/click-all.mjs eiga/`(W=320 も)
6. PR は **rebase で 取りこむ**(この 入れもの)。speed-king は squash。コミットの 末尾は Co-Authored-By と Claude-Session の 2行
7. かずとも `speed-king`: `FLICK_MODES` / `FLICK_LINK_TARGETS` に `eiga`(PR → squash)。`HOME_GAMES`(けいくんが 決めた 章)は 絵と OK の あと
8. けいくんに ChatGPT で 絵を 頼む 文を わたす。**3つ**(**トップの 絵と 題名は いっしょに 頼む**):
   ・トップの 絵(1536×1024)。**人物は 画面の 下 3分の1に 小さく**・指5本・手首から 腕が 1本だけ・首が 見える。
     大きな 映画館の スクリーンの 前で、男の子が **カチンコ**を 持ち、女の子が **ポップコーン**と ノート(感想を 書く)を 持って 笑っていて、白い 犬も いっしょ。まわりに フィルムの リール・映写機の 光・星・**架空の 映画の ポスター**(字の 無い 絵だけ)。
     ⚠️⚠️ **実在の 映画の キャラクター・ロゴ・ポスター・俳優の 顔を 描かない**(ミッキー・トトロ・ゴジラ・スター・ウォーズの 人物 など ぜんぶ だめ。著作権)。**スクリーンの 中は 光と 空だけ**。
     絵の 中の 字は「フリック映画評論家」だけ・ゲームに 無い 機能の 絵を 入れない。届いたら **まず 字を 切り出して 読む**。⚠️ **スクリーンや ポスターの 中に 字が 入って いないか**も 見る
   ・四角い 絵(1254px)… **切らずに そのまま アイコンに する**ので、**小さく しても わかる 絵**(カチンコを 持つ 子と 犬 くらい。まわりに 字の 札を ならべない)で 頼む
   ・**題名だけの 透明 PNG**(CLAUDE.md「題名は ChatGPT に 切りぬいてもらう」の 文を そのまま。「フリック映画評論家」と **はっきり 書く**。⚠️ ChatGPT は 字を 変える(「映画評論」「映画批評家」「映画論評家」に なりやすい)。**届いた 字を かならず 読む**。かずともの 一覧・規約の 名前は **ロゴの 字に そろえる**)
9. 絵を 入れたら CLAUDE.md に 節を 書く(名前・旅・語数・確かめた 日・入れなかった 作品と 理由(⭐ 「有名だが R15+ なので」を 残す。次の 人が 足しもどさない ように))
10. ⭐ **毎年の 見直しの 予約**は **作らなくて よい**(ワールドサッカー・バスケ・ベースボールと ちがい、映画史・技法・評論の ことばは 年で 変わらない)。⚠️ ただし `sho`(映画祭と 賞)に **その年の 受賞**を 足したく なったら、**公式で 確かめて から**。アカデミー賞の 賞の 名前が 変わる ことが あるので、足す ときに 見る

## 6. 気をつける 前例
- 哲学(`tetsugaku/`)で「どちらが 正しい を 書かない」「決めつけない」に した。評論は **意見の 学問**なので なおさら(「名作」を 事実に しない)
- ワールドサッカー / バスケ / ベースボール(実在の 人・作品を 事実として 入れる 型)の 「変わる 数字を 書かない」「人を けなさない」を そのまま 使う。**興行収入は 選手の 年俸と 同じ**(変わる・書かない)
- 血液型・ボクシングで **「まんが・アニメの 登場人物を 入れない」**に した。映画評論家は **作品名は よい**が **キャラクター名を 答えに しない**(線引きが ちがうので 混ぜない)
- 看護師で 統合失調症 → 適応障害に 入れかえた ように、**こわく 感じる 作品は 有名でも 入れない**。映画で 迷ったら 入れない
- 国語旅行の 物語の 作りかた(起承転結・伏線)・ゲームクリエイターの 演出(カメラ・カット)と かさなる。**同じ 語で よい**が **スクリーンの 目線**で
- 世界旅行の 街(カンヌ・ヴェネツィア・ハリウッド)と つなぐと へえに なる
- **作品と 監督と 年の まちがい**が いちばん 多い(『E.T.』= スピルバーグ 1982、『羅生門』= 黒澤明 1950。⚠️ ぜんぶ 確かめる)。2人目の 助手は ここを 重く 見る
- **『 』の 中の 字を 答えに する とき、記号・副題・「。」を 外す**(『君の名は。』の「。」は 題名の 一部だが、答えは 「君の名は」で 受けて、説明に 正しい 題名を 書く)
- 2026-10-12 の 時点で 48ゲーム(フリック 47 + かずとも)+ まとめ(ボクシング・あん摩マッサージ指圧師まで。⚠️ あん摩マッサージ指圧師は 同日に 別の セッションが **作った**(`anma/`))。**フォルダ・id・modes 名を まぜない**(`eiga` / `EIGA` / `mv…`)
