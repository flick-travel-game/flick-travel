# フリックパイロット(`pilot/`)を 作る ための まとめ(2026-10-20。新しい セッション用)

けいくん 2026-10-20「新しいセッションで フリックパイロットを作成したい。**パイロットに受かるレベル**になるために必要な知識をフリック形式の問題にしてください」

⭐ いちばん 近い 兄弟は **フリック整備士(`seibi/`)**(乗り物の 部品と しくみ・資格の 級で むずかしさを 分ける 型)。
空の 天気は **フリック理科(`rika/` の 地学)**、英語の 交信は **フリック英会話(`eikaiwa/`)**、ロケット・宇宙は **フリック宇宙図鑑(`uchu/` の 宇宙開発と探査)** と かさなる。
⚠️ ほかの ゲームに 無い 3つの 気をつけ:
① **事故・墜落を こわく 書かない**(安全の しくみは 「こうして 守っている」の 向きで)
② **本物の 操縦・無線の 手順書に しない**(ゲームで おぼえても 飛べない。実際は 訓練校と 教官)
③ **実在の 航空会社・機体メーカーの 名前を 売り文句や 悪い 例に 使わない**(商標。説明に 出すときは 事実だけ)

⭐⭐ **学科試験に 近づける 3つ**(けいくん 2026-10-20「国家試験に受かるレベルの知識はつく？」→ ことばだけでは 土台まで、と 伝えて「3つとも足してください」):
① **ことばを 1,000語に**(9の 旅 × 約110語。整備士・映画評論家と 同じ くらい)
② **🧩 4択クイズ**(整備士の `seibi.js` の 4択クイズを そのまま 写す。試験の「えらぶ 問題」に なれる)
③ **🧮 計算問題**(整備士の 計算問題の しくみを 写す。**問題も 答えも プログラムが 作る**。下の 1 の 表)
⚠️ それでも **これだけで 合格とは 言わない**(画面にも 書かない)。本番には **試験の 過去問と 教科書** が いる。実地試験は 訓練校

## 3. ⚠️⚠️⚠️ ぜったいの 決まり(整備士と 同じ + この ゲームだけの もの)
- ⭐⭐⭐ **この ゲームだけの いちばん 大事な 決まり: こわく しない**。飛行機は **いちばん 安全な 乗り物の 1つ**。失速・乱気流・メーデー・ゴーアラウンド などは **「そう ならない ように / なっても 安全に する ための しくみ」**の 向きで 書く(「落ちる」「墜落」の 字を 使わない。`BAN` で 止める)
- ⭐⭐ **これで 飛べる わけでは ない** と 画面に 書く: 「これは ことばを おぼえる ゲームです。実際に 飛ぶには 訓練校で 教官と 練習し、国家試験に 受かる 必要が あります」「国土交通省・航空大学校とは 関係ありません」(⚠️ 団体名は 4 で 確かめる)
