# 確かめる 係への おねがい(フリック犬の気持ち)

あなたは **書いた 人とは 別の 目**で、ことばを 1語ずつ 確かめる 係です。決まりは `tools/inu/PROMPT.md` と `tools/inu/WRITER.md`(「確かめた 事実」も ある)。
見る ファイル: あなたの 旅の `tools/inu/terms-<旅>.json`。

1語ずつ 見る こと(⭐ 4つの 目 = **科学の 札・決めつけ・こわさ・罰**):
1. **科学の 札**(kagaku)が 合っているか。しっぽ・おなか・目そらし・反省の 顔・アルファ理論・手を かがせる に 付いているか。言い伝えを 事実の ように 書いていないか
2. **決めつけ**: 「◯◯犬は ◯◯な 性格」「この しぐさ = かならず ◯◯」が ないか。kimochi に「たぶん / ことが 多い」が あるか。犬種の 語に 性格が まぎれていないか(breed.yakume も)
3. **こわさ**: かまれる・事故・けが・死を にじませる 書きかたが ないか。こわがらせる 向きでなく「犬も 人も 安心」の 向きか
4. **罰**: たたく・どなる・おさえる・首輪で ひっぱる など 罰の 方法が まぎれていないか。困りごとの なおしかたが 「ほめる・環境・代わりの 行動・少しずつ 慣らす」の どれかか
5. **意味が 正しいか**(事実の まちがい・言いすぎ・犬種の 国と グループ・人名の 事実・獣医師ゲーム `tools/jui/` と 心理学 `tools/shinri/` と 食いちがわないか)
6. **読み**(reading)が 名前の ふつうの 読みか。ei の つづり
7. やさしい です・ます / 語の あいだの 半角スペース / 130字以内 / renshu が 具体的で 家で できるか / 知らない 犬に さわる 練習が ないか
8. difficulty は かえない(おかしい ときは 報告だけ)。relatedTerms が 意味の つながる 語か

直しかた: まちがいは **その ファイルを 直接 直す**(name・reading を かえた ときは 読みの かぶりに 気を つける)。
直したら `python3 tools/inu/terms_js.py --check` で あなたの 旅に ❌ が 0 に なる ことを 確かめる。⚠️ ほかの 旅の ファイルは さわらない。git の コミットは しない。
報告: 直した 語の id と「まえ → あと / 理由」を 一覧で(短く)。
