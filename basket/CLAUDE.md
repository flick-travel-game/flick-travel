## フリックワールドバスケットボール(`basket/`。けいくん 2026-10-10「ワールドバスケットボールの専門家(解説者)になれるレベルになるために必要な 知識、主要バスケリーグ、有名バスケ選手、有名な技、ルールをフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」。まとめは `docs/フリックワールドバスケットボール-はじめかた.md`)

- 名前は「フリックワールドバスケットボール」(縮めない。絵が 届いたら 題名に そろえる。フォルダ名 `basket` は 変えない)。シリーズの 絵文字は 🏀。`SERIES_ORDER` は **フリックワールドサッカーの となり**
- 旅は 9つ(バスケのきほん `kihon`・ルール `rule`・世界のリーグと大会 `league`・名門チームとライバル `team`・いまのスター選手 `star`・伝説の選手 `legend`・技とテクニック `move`・戦術と解説のことば `tactic`・世界大会と代表 `cup`)+ マスター。
  **旅ごとに 70語(入門20・中級25・上級25)= 630語**。かずともの 旅の 名前は **`wb` で はじめる**(wbkihon / wbrule / wbleague / wbteam / wbstar / wblegend / wbmove / wbtactic / wbcup / wbmas)。⚠️ `bk` は 別の ゲーム
- むずかしさは 3段: 入門(**バスケが すきな 小学生**)→ 中級(**ミニバスの コーチ・バスケ好きの 大人**)→ 上級(**解説者**)。学ぶ 分野(`field`)6つ: ルール / 技術 / 戦術 / リーグ・チーム / 選手 / 大会・歴史
- ⭐ **2つの 札**: 国旗の 札(`country` → `co`。国・地域 61。`terms_js.py` の `COUNTRY`)と **ルールの 札**(`ruleset` → `rs`: `FIBA` / `NBA` / `両方`。`basket.js` の `ruleTag`。図鑑で 📏 しぼれる)。ルールの 旅は 70語 ぜんぶに 札
- ことばは `tools/basket/terms-<旅>.json`(決まりと **どの 語を どの 旅に 入れるかの 一覧**は `tools/basket/PROMPT.md`)→ `tools/basket/terms_js.py` → `basket/terms.js` + `data/basket.json`。しくみは `basket/basket.js`(ワールドサッカーを 写した)。しくみ図 9つは `tools/basket/mkmeta.py`
- 事実は `tools/basket/exam.txt`(と 迷った ところの メモ `exam-notes.md`)。**ルールは FIBA Official Basketball Rules 2026(2026年10月1日から。日本では JBA「2027 バスケットボール競技規則」。B リーグ・W リーグは 2026-27 から 先に 使う)と NBA Official Rules 2026-27 で 確かめた(2026年10月10日)**。
  ⚠️ **FIBA 2026 で「アンスポーツマンライク・ファウル」は なくなり**「ディスラプティブ・ファウル」と「フラグラント・ファウル」に 分かれた(テクニカルも 2つの 種類に)。ゲームでは アンスポーツマンライクを「2024年版までの よび名」と して 残した。ノーチャージ・セミサークルは 1.30メートル
  2026年の NBA ファイナルは ニックス(53年ぶり。ファイナル MVP ブランソン)・MVP は 2025・2026年とも シェイ・ギルジャス＝アレクサンダー・2026年の 女子 W杯は アメリカ(ベルリン)・2030年の 女子 W杯は 東京(予定)・2027年の 男子 W杯は カタール(予定)
- ⚠️⚠️⚠️ **数字が 変わる ものを 書かない**: いまの 所属チーム・年俸・トレード・いまの 順位・通算記録・年齢(台本 `BAN` / `BAN_RE`)。優勝回数は「◯年までに」を 付ける。
  **いまの スター選手(`star`)は チーム名・所属・移籍・契約を 書かない**(`STAR_BAN` が NBA・WNBA・B リーグの チーム名ごと 止める。名前の 中に たまたま 入る ものは `OK_WORDS`: ギルジャス＝アレクサンダー・エイジャ・ウィルソン)
- ⭐ **レブロン・カリー・デュラントは 38歳を こえるが star に 入れた**(2026年10月に NBA で 現役と 確かめた。サッカーの メッシ・ロナウドと 同じ 例外)。⚠️ **毎年 10月の 見なおしで 引退を 確かめる**(引退したら legend へ)。
  入れていない: クリス・ポール・ハーデン(年)・ジャ・モラント・カワイ・レナード・ジミー・バトラー(念のため)・田臥勇太(現役なので legend にも 入れない)・吉田亜沙美と 五十嵐圭(引退を 確かめられなかった)・宮崎早織(引退)
- ⚠️⚠️ **人を けなさない・悲しい 場面・ケガ・死・乱闘・差別・賭け・商品名(エア・ジョーダン・ボールの 会社)・まんがの 登場人物を 入れない**(台本が 止める)。亡くなった 名選手は 功績だけ。技は「練習で 身に つける 技」・技の 名前の もとは「◯◯の 得意技として 有名」まで
