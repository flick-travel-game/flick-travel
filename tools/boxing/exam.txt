①プロの ルール
・日本の プロを まとめる ところは **JBC(日本ボクシングコミッション)**。1952年4月21日に できた(白井義男の 世界戦の 1か月 前)。日本で 行う 世界戦は JBC が 認めないと 世界戦に ならない。
・世界タイトルマッチは **12回**(1回 3分・あいだの 休み 1分)。採点は **3人の ジャッジ**。(日本タイトルが 10回戦で ある ことは 公式の 文で 確かめられなかった。東洋太平洋 / WBO アジアパシフィックの タイトル戦は 10回戦と 書かれて いる)。
・採点は **10点法(10ポイント・マスト・システム)**。1回ごとに 勝った ほうに 10点、負けた ほうに 9点 より 下。JBC は 2016年度の 改正で 「10対6」まで つけられる ように した(それまでは 10対7まで)。
・**3ノックダウン制**(1回に 3度 ダウンすると 負け): JBC は **2015年まで 使っていて、2016年度から やめた**(4回戦の 2ノックダウン制も やめた)。WBC・IBF・WBO の タイトル戦は 使わない(=**フリーノックダウン制**)。WBA は 自分の きまりに 書いて ある 試合も あるが、ふつうは 使われない ことが 多い(はっきり 1つに 決まって いない)。
・**スタンディング8カウント**を いまの JBC の プロで 使うかは (確かめられなかった)。
・判定の ことば: **ユナニマス・デシジョン**(3人 全員が 同じ 選手)/ **スプリット・デシジョン**(2人と 1人に 分かれる)/ **マジョリティ・デシジョン**(2人が 勝ち・1人が 引き分け)/ **負傷判定(テクニカル・デシジョン)**(とちゅうで 続けられなく なった とき、それまでの 採点で 決める)。
・グローブの 重さ(8オンス / 10オンス)と 階級の 分けかたは JBC の 公式の 文で (確かめられなかった)。
・**前日計量**: 世界戦も 日本タイトル戦も 試合の 前の 日に 体重を はかる(JBC で 行う ことが 多い)。計量の あとに 医師の 検診が ある。
・**IBF の 当日計量**: IBF の タイトル戦は 前日計量の あと、もう 1回 はかる。そのときの 体重は **リミットから 10ポンド(約4.5kg)まで**(どれだけ 早く はかるかの 書きかたは 記事で ちがう)。
・WBC にも 30日前・7日前などの 体重の 確認が あるが、いまの くわしい 中身は (確かめられなかった)。
・JBC の ルールブックの いまの 版・年は (確かめられなかった)。
・女子の プロは JBC が **2008年**から 認めた(2007年11月に 発表)。JBC が 認めた 女子の 世界王者 第1号は **富樫直美**(とがし なおみ)。

③4団体と ベルト
・**WBA**(世界ボクシング協会): **1921年**に アメリカで **NBA**(全米ボクシング協会)として できて、**1962年**に WBA に なった。本部は 長く **パナマ**。2017年に 会長の 部屋を コロンビアの メデジンに 移すと 発表(パナマにも 事務所を 残す)。いまの 本部の 場所は (確かめられなかった)。
・**WBC**(世界ボクシング評議会): **1963年2月14日**、**メキシコシティ**で 11か国が 集まって できた。
・**IBF**(国際ボクシング連盟): **1983年**、アメリカの **ニュージャージー州**で できた。
・**WBO**(世界ボクシング機構): **1988年**に できた。本部は **プエルトリコの サンフアン**。
・JBC は 長く WBA と WBC だけを 認めて いた。**2013年4月1日**から **WBO と IBF にも 加盟**(2013年2月18日に 発表)。
・WBA の 王者の よびかた: **スーパー王者**(5回 以上 防衛 / ほかの 団体と 統一した 人)・**レギュラー王者**・**暫定王者**(正規の 王者が 試合を できない ときの 王者)。
・WBC の 「フランチャイズ王者」の くわしい きまりは (確かめられなかった)。
・**4団体統一(アンディスピューテッド)**: WBA・WBC・IBF・WBO の ベルトを 1人で ぜんぶ 持つ こと。
・**ザ・リング**の ベルト: アメリカの ボクシング雑誌「ザ・リング」(1922年 創刊)が 出す ベルト。
・ほかの タイトル: **OPBF 東洋太平洋**・**WBO アジアパシフィック**(どちらも 10回戦)。
・**パウンド・フォー・パウンド(PFP)**: 体重の ちがいが なかったら だれが いちばん 強いか、という 考えかた。

⑥日本の 世界王者の 歴史
・ボクシングが 日本で 根づいた はじまり: **1921年**、アメリカから 帰った **渡辺勇次郎**が 東京・目黒に **日本拳闘倶楽部**(日倶)を 開いた。「日本ボクシングの父」と よばれる。1924年に はじめての 日本タイトルマッチ。
・**白井義男**: **1952年5月19日**、**後楽園球場**で ダド・マリノに 判定勝ちし **日本人 はじめての 世界王者**(フライ級)。この 日は「ボクシングの日」。
・**後楽園ホール**: **1962年4月16日**に 開業(はじめの 名前は 後楽園ジムナジアム。1967年に 後楽園ホール)。
・**ファイティング原田**: 1962年 フライ級、1965年 バンタム級(エデル・ジョフレに 勝つ)。**日本人 はじめての 2階級制覇**。
・**具志堅用高**: 1976年 WBA ライトフライ級。**13回 連続防衛**(日本の 男子の 最多。いまも やぶられて いない)。1981年まで。
・**ガッツ石松**: 1974年 WBC ライト級(日本人で はじめての ライト級 世界王者)。5回 防衛。
・**浜田剛史**: 1986年 WBC スーパーライト級。
・**辰吉丈一郎**: 1991年 WBC バンタム級。
・**長谷川穂積**: WBC バンタム級を 10回 防衛 → フェザー級 → **2016年 WBC スーパーバンタム級で 3階級制覇**。2016年に 引退。
・**山中慎介**: 「**神の左**」。2011年 WBC バンタム級。**12回 防衛**(日本 2位)。2018年 引退。
・**内山高志**: WBA スーパーフェザー級を **11回 防衛**(スーパー王者にも)。
・**井上尚弥**: よび名「**モンスター**」。**2022年12月** バンタム級で **4団体統一**(アジアで はじめて)。**2023年12月26日** スーパーバンタム級でも 4団体統一 → 4団体の 時代で **2階級 4団体統一は クロフォードに つぐ 2人目**。**2026年5月2日 東京ドーム**で 中谷潤人に 判定勝ち(約5万5千人)。**2026年10月 いまも 現役**(次は 2027年2月ごろと 話している)。
・**中谷潤人**: サウスポー。**2024年2月 WBC バンタム級で 3階級制覇**(2020年 WBO フライ級・2023年 WBO スーパーフライ級)。2025年に スーパーバンタム級へ。いまも 現役。
・**井上拓真**(井上尚弥の 弟): **2025年11月24日** WBC バンタム級 王座決定戦で 那須川天心に 判定勝ち。**2026年9月27日の 再戦も 勝つ**。元 WBA バンタム級 王者でも ある。現役。
・**那須川天心**: キックボクシングから ボクシングへ。**ボクシングの 世界王座は まだ とって いない**(2025年11月・2026年9月 どちらも 井上拓真に 判定負け)。サウスポー。現役。
