## 3. ⚠️⚠️⚠️ ぜったいの 決まり(医師・薬剤師・獣医師と 同じ。**歯医者さんを こわがって いる 子が あそぶ** ので なおさら)

  - **「キーン」「痛い」「ドリル」「抜く」「注射」の 字を 説明に 書かない**。麻酔は「**痛く ない ように する お薬**」、治療は「**悪い ところを きれいに して、つめる**」まで
  - **「早く 行けば 小さな 治療で すむ」「歯医者さんは 歯を 守る 味方」**の 向きで 書く
- **治療の やりかたを 書かない**: 薬の **量**・手術の **手順**・「この しょうじょうなら この 病気 / この 治療」・正常値の 数字・**家で できる 治療**。**名前と 目的だけ**
  - ⭐ ただし **「すぐ 歯医者さんへ」の 考えかたは 書いて よい**(子どもの 安全に 役立つ): 「歯が 抜けたら 乾かさずに すぐ 歯医者さんへ」「歯が いたい・ぐらぐら するときは 大人に 言う」「定期検診で 早く 見つける」
- ⚠️ **むし歯の 子・歯ならびの 子を 責めない・からかわない**。「あまい ものを 食べる 子は 悪い」と 書かない。**だらだら 食べ を しない・みがく** の 工夫として 書く。出っ歯・受け口 などの 名前は **「歯の ならびかたの 名前。矯正で ととのえられる」**まで
- **小学生も あそぶ**: 血・痛み・こわい 先を 書かない。病気は「何が 起きている 状態か」+「歯医者さんが 助ける」だけ。**迷ったら 入れない**(看護師で 統合失調症を 外した 目で 見る)
- ✅ **ほかの ゲーム(医師・看護師・薬剤師・獣医師・からだ図鑑・理科の 生物 など)と 同じ 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。説明は **歯科医師の 目線**(「お口は 食べる・話す・笑う の 入り口」)で 書きなおす
- **読み(ひらがな)は 歯科医師の 9つの 旅の 中では かぶらない**(ほかの ゲームとは かぶって よい。`terms_js.py` が 止める)。⚠️ `mushi` と `yobo`(歯こう・歯石)、`ha` と `kodomo`(乳歯・永久歯)、`chiryo` と `kodomo`(矯正)、`kuchi` と `koshu`(口腔ケア・誤嚥性肺炎)は かさなりやすい。**先に 9つの 旅の 語の 一覧を 1人の 助手に 作らせて** 置き場所を 決めてから 頼む
- **実在の 歯科医院・歯みがき粉・歯ブラシ・ガム・洗口液・材料の 商品名を 入れない**。キシリトール・フッ化物 など **成分の 名前は よい**。人の 名前は 歴史として よい(確かめる)
- **数字の 決めうちを 書かない**(フッ素の 濃さ・麻酔の 量・治療の 回数 / 期間・費用・保険の 点数・合格率)。
  ⭐ **歯の 本数**(乳歯・永久歯)は 変わらない からだの 事実なので **確かめてから 書いて よい**(へえに なる)。試験の しくみ(何年制・年1回)は 4 で 確かめて `meta.json` に
- 画面(ホームの 下・遊びかた)に「これは ことばを おぼえる ゲームです。**歯や お口が いたい・気になる ときは、大人に 言って 歯医者さんへ**」「厚生労働省とは 関係ありません」(医師と 同じ)
- **作った 助手とは 別の 助手が 1語ずつ 確かめる**(意味・読み・**治療の やりかたを 書いていないか**・**こわい 字(痛い・ドリル・抜く・注射)が 無いか**・からかう 書きかたが 無いか・商品名)。ふりがなも 全語 見る(`tools/ruby_fix.json`)

**歯科衛生士**(国家資格。歯科衛生士法)/ **歯科技工士**(国家資格。歯科技工士法)/ **歯科助手**(資格が いらない 仕事。確かめる)。

## 5. 作りかたの 手順(医師・薬剤師・獣医師の ときと 同じ)
1. けいくんに 2 の 5つを 聞く → 返事を CLAUDE.md に 書く
2. `tools/shika/PROMPT.md` `exam.txt` `mkmeta.py` → `meta.json` を 作る → **先に 9つの 旅の 語の 一覧を 1人の 助手に 作らせて 置き場所を 決める** → 旅ごとに 助手に 70語ずつ 頼む(`PROMPT.md` を そのまま わたす。**助手は 2人ずつ**)→ `terms-<旅>.json`
3. `terms_js.py` で 止められた 語を 直す → 別の 助手が 1語ずつ 確かめる(**治療の やりかた・こわい 字・からかい・商品名**)→ ふりがな
4. `shika/shika.js`(ishi.js を 写し、歯の 札を 足す)・`build_games.py`・`index.html` の PLUG と SERIES → `python3 tools/build_games.py`
5. 手元で 通す: `python3 -m http.server 8765` → `node tools/play-all.mjs shika/` / `node tools/click-all.mjs shika/`(W=320 も)
6. PR は **rebase で 取りこむ**(この 入れもの)。speed-king は squash。コミットの 末尾は Co-Authored-By と Claude-Session の 2行
7. かずとも `speed-king`: `FLICK_MODES` / `FLICK_LINK_TARGETS` に `shika`(PR → squash)。`HOME_GAMES` は 絵と OK の あと
8. けいくんに ChatGPT で 絵を 頼む 文を わたす。**3つ**(**トップの 絵と 題名は いっしょに 頼む**):
   ・トップの 絵(1536×1024)。**人物は 画面の 下 3分の1に 小さく**・指5本・手首から 腕が 1本だけ・首が 見える。
