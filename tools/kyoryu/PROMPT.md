# フリック恐竜図鑑: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その 恐竜・ことばの 説明(1〜3文)と、
**見つかった 場所(世界地図の 📍)**・**いた 時代(中生代の 年表の 📍)**が 出る。
あそぶのは **小学生〜大人**。けいくん 2026-09-29「**恐竜博士に なれる レベルに なるために 必要な 知識を フリック形式の 問題に**」。
写真は あとから 足す(いまは 絵文字の カード)。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 4つ

### 1. 古い 知識を 書かない(恐竜の 研究は どんどん 新しくなる)
- **羽毛**: 獣脚類には 羽毛が あった ものが 多い(ヴェロキラプトルは 腕の 骨に 羽の あと)。ティラノサウルスの 大人の 体の 羽毛は まだ 分かっていない(小さな うろこの 皮ふの あとが 見つかっている)→ 言いきらない
- **しっぽを ひきずらない**。体を 水平に して 歩いた
- **鳥は 恐竜の 仲間**(獣脚類から 生まれた)。「恐竜は ぜんぶ いなくなった」とは 書かない → 「鳥を のぞく 恐竜(非鳥類型恐竜)」
- **ブロントサウルス**は 2015年の 研究で また 別の 属として 使われる ように なった(まだ 話しあいは ある)
- **スピノサウルス**の くらし(水の 中で 泳いだか・岸で 魚を とったか)は 研究者の あいだで 話しあいが つづいている
- **ステゴサウルスの 板・トリケラトプスの えり・パラサウロロフスの とさか**の 役目は はっきりしない → 「〜と 考えられています」「まだ 分かっていません」
- ⚠️ **大きさ・重さ・年代の 数字は ひかえめに**。数字を 書くなら「約」「〜くらい」と、研究で ゆれない ものだけ。**分からない ものは 書かない**
- 言いきらず **「〜と 考えられています」「まだ 分かっていません」**。むりに 答えを 作らない。**「まだ 分かっていない」と 書けるのが 博士に 近い**

### 2. 恐竜では ない 生きものを「恐竜」と 書かない
- **恐竜では ない**: 翼竜(プテラノドン・ケツァルコアトルス)・首長竜(フタバサウルス・エラスモサウルス)・魚竜・モササウルス(トカゲの 仲間)・ディメトロドン(単弓類。恐竜より 前。ほ乳類に つながる 仲間)・ワニの 仲間
- これらは `notdino` の 旅に だけ 入れて、説明に **「恐竜では ありません」**と はっきり 書く。「恐竜の プテラノドン」と 書かない
- 恐竜 = 陸の 上で くらし、足が 体の **真下**に のびる は虫類の 仲間(鳥も ふくむ)

### 3. ほかの ゲームと かぶらせない
理科旅行・宇宙・世界旅行 … に もう ある 見出し(約1万語)は **入れない**。一覧は `tools/kyoryu/other-words.txt`。**同じ 字の 見出しは 台本が 止める**。
例: 化石・地層・示準化石・示相化石・中生代・古生代・新生代・アンモナイト・三葉虫・進化・は虫類・鳥類・ほ乳類・プレート・隕石・**始祖鳥・生痕化石・学名・骨格・放射年代** は **ダメ**。
→ 「足跡化石」「糞石」「全身骨格」「タイプ標本」のように **恐竜の ことばに する**。書いたら `grep -x '見出し' tools/kyoryu/other-words.txt` で 確かめる

### 4. 権利・安全
- 図鑑の 本・記事・Wikipedia の 文を **写さない**。自分の ことばで
- **映画・アニメ・ゲームの 恐竜の 名前や 設定を 出さない**(商標)。学問の 話だけ
- 博物館は 名前を 出すなら 正しく(福井県立恐竜博物館・むかわ町穂別博物館 など)。会社・商品の 名前は 出さない
- こわい 書きかた(血・かみちぎる・ざんこく)を しない。狩りは「つかまえて 食べた」くらいに

## 1語の 形(JSON)

```json
{"id":"ni-trex","name":"ティラノサウルス","reading":"てぃらのさうるす","journey":"niku","category":"ティラノサウルスの仲間",
 "difficulty":1,"kind":"dino","period":"白亜紀","diet":"肉","place":"アメリカ(モンタナ州)","lat":47.6,"lon":-106.7,
 "emoji":"🦖","relatedTerms":["ni-tarbo","ka-juukyaku"],
 "description":"白亜紀の 終わりごろ、北アメリカに いた 大きな 肉食恐竜。名前は「暴君の トカゲ」という 意味です。かむ 力が とても 強かったと 考えられています。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ。ほかの 旅の 語を つなぐときも この id
- **name**: 画面に 出す 名前。恐竜は 日本の 図鑑で ふつうの カタカナ(ティラノサウルス)。ことばは 漢字・カタカナ
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白は ダメ)
  - 「ヴ」は `ゔ` を 使い、`"acceptedReadings":["ゔぇろきらぷとる","べろきらぷとる"]` の ように **バ行の 読みも 通す**(先頭は reading と 同じ)
  - 小さい 字は そのまま(てぃ・でぃ・ふぁ)。のばす 音は ー
  - ⚠️ **20字を こえる 読みは 入れない**。13〜20字は **上級だけ**
  - ⚠️ 読みを まちがえやすい ことば: 獣脚類 じゅうきゃくるい・竜脚類 りゅうきゃくるい・鳥盤類 ちょうばんるい・竜盤類 りゅうばんるい・
    白亜紀 はくあき・三畳紀 さんじょうき・胃石 いせき・糞石 ふんせき・周飾頭類 しゅうしょくとうるい・装盾類 そうじゅんるい・鳥脚類 ちょうきゃくるい・
    首長竜 くびながりゅう・翼竜 よくりゅう・魚竜 ぎょりゅう・恐竜 きょうりゅう
- **journey**: 旅の id(下の 表)
- **category**: 小見出し(例: 「ティラノサウルスの仲間」「角竜」「時代」「化石の しゅるい」「空の は虫類」)。1つの 旅で 3〜8しゅるい
- **difficulty**: `1` 入門(だれでも 知っている・図鑑の 表紙)/ `2` 中級(図鑑に のっている)/ `3` 上級(恐竜博士)
- **kind**: `"dino"`(恐竜。鳥を のぞく)/ `"notdino"`(恐竜では ない 生きもの・鳥の 仲間)/ `"word"`(ことば)
- **period**: いた 時代。`"ペルム紀"` `"三畳紀"` `"ジュラ紀"` `"白亜紀"` `"新生代"` の どれか。ことばで 時代に むすびつかない ものは `""`
  (三畳紀・ジュラ紀 などの ことば そのものは その 時代を 入れる。境目の いきものは いた 時代の おもな ほう)
- **diet**: `"肉"` `"草"` `"雑食"` `"魚"` の どれか。分からない・ことばは `""`
- **place**: 見つかった おもな 場所(国と 州・県)。例「アメリカ(モンタナ州)」「モンゴル(ゴビ砂漠)」「日本(福井県勝山市)」。ことばは `""`
- **lat / lon**: place の だいたいの 緯度・経度(小数1けた)。**恐竜・生きもの(kind が dino / notdino)は かならず**。ことばは 書かない(はぶく)
- **emoji**: 1つ。🦖 🦕 🐊 🦴 🪶 🐾 🥚 🌿 🌋 ☄️ 🌊 🐢 🦅 🐦 🔬 ⛏ 🏛 など。**同じ 絵文字ばかりに しない**
- **relatedTerms**: 1〜3個。**同じ ファイルの id か、下の「ほかの 旅の 語」の id**。自分は 入れない
- **description**: 1〜3文・**130字以内**・です・ます。**語と 語の あいだに 半角スペース**(シリーズの 文体。上の 例を 見る)。
  恐竜なら「いた 時代・場所・体の とくちょう(1つ)・名前の 意味(分かれば)」。**name の 字を 説明の 中で 何度も くり返さない**
