## 3. ⚠️⚠️⚠️ ぜったいの 決まり(医師・看護師と 同じ。薬は なおさら)
- **薬の 使いかたを 教える ゲームに しない**: 薬の **量**・飲む **回数**・**最大量**・「この しょうじょうなら この 薬を 飲めば よい」・**飲み合わせの 具体的な 組み合わせ**・正常値の 数字・薬の **商品名** は 書かない。**名前と 目的と しくみだけ**
  - ⭐ ただし **「正しく 使う ための 考えかた」は 書いて よい**(子どもの 安全に 役立つ ため): 「薬は 決められた 時間と 量を 守る」「人の 薬を 飲まない」「おかしいと 思ったら 大人と 薬剤師さんに 聞く」「お茶や ジュースでは なく 水で」「飲みきる ように 言われた 薬(抗菌薬など)は 自分で やめない」
- **毒・中毒・乱用は おだやかに**: 毒薬・劇薬・麻薬は **「法律で きびしく 管理される 薬」**まで。**中毒の ようす・死ぬ ようす・薬物の 名前の 一覧・効果は 書かない**。薬物乱用防止は「ぜったいに 手を 出さない・さそわれたら 断って 大人に 言う」の 形で(台本で「死」「致死」「過量」を 止める)
- **小学生も あそぶ**: 血・苦しむ ようす・こわい 先を 書かない。病気は「何が 起きている 状態か」+「薬と お医者さん・薬剤師さんが 助ける」だけ。**めずらしい 病気・こわい 病名の ならびは 入れない**。**迷ったら 入れない**
- ✅ **ほかの ゲーム(医師・看護師・からだ旅行・理科の 化学・救急隊員・家事 など)と 同じ 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。説明は **薬剤師の 目線**(「薬が 安全に きく ように 確かめる」「患者さんに わかる ように 伝える」)で 書きなおす
- **読み(ひらがな)は 薬剤師の 9つの 旅の 中では かぶらない**(ほかの ゲームとは かぶって よい。`terms_js.py` が 止める)。⚠️ `kihon` と `dotai`(剤形・腸溶錠)、`chozai` と `otc`(お薬手帳・服薬指導)、`eisei` と `hoki`(学校薬剤師・薬物乱用)は かさなりやすい。**先に 9つの 旅の 語の 一覧を 1人の 助手に 作らせて** 置き場所を 決めてから 頼む
- **一般名は 有名な ものだけ**。カタカナの 長い 成分名を ならべない(子どもが 読めない・ゲームに ならない)。読みは カタカナ → ひらがなで `acceptedReadings` に ゆれを 入れる
- **実在の 薬の 商品名・製薬会社・薬局チェーンの 名前を 入れない**(「ロキソニン」ではなく 一般名か「解熱鎮痛薬」)。人の 名前(フレミング・ジェンナー・長井長義)は 歴史として よい(確かめる)
- **数字の 決めうちを 書かない**(薬価・合格率・薬剤師の 人数・薬の 量)。試験の しくみ(何年制・年1回)は 4 で 確かめて `meta.json` に
- 画面(ホームの 下・遊びかた)に「これは ことばを おぼえる ゲームです。**薬は かならず お医者さん・薬剤師さんの 言う とおりに**。具合が わるい ときは 大人に 言いましょう」「厚生労働省とは 関係ありません」(医師と 同じ)
- **作った 助手とは 別の 助手が 1語ずつ 確かめる**(意味・読み・**量や 使いかたを 書いていないか**・**商品名が 混ざって いないか**・こわくないか)。ふりがなも 全語 見る(`tools/ruby_fix.json`)

## 5. 作りかたの 手順(医師・看護師の ときと 同じ)
1. けいくんに 2 の 5つを 聞く → 返事を CLAUDE.md に 書く
2. `tools/yakuzai/PROMPT.md` `exam.txt` `mkmeta.py` → `meta.json` を 作る → **先に 9つの 旅の 語の 一覧を 1人の 助手に 作らせて 置き場所を 決める** → 旅ごとに 助手に 70語ずつ 頼む(`PROMPT.md` を そのまま わたす。**助手は 2人ずつ**)→ `terms-<旅>.json`
3. `terms_js.py` で 止められた 語を 直す → 別の 助手が 1語ずつ 確かめる(**量・商品名・こわさ**)→ ふりがな
4. `yakuzai/yakuzai.js`(ishi.js を 写す)・`build_games.py`・`index.html` の PLUG と SERIES → `python3 tools/build_games.py`
5. 手元で 通す: `python3 -m http.server 8765` → `node tools/play-all.mjs yakuzai/` / `node tools/click-all.mjs yakuzai/`(W=320 も)
6. PR は **rebase で 取りこむ**(この 入れもの)。speed-king は squash。コミットの 末尾は Co-Authored-By と Claude-Session の 2行
7. かずとも `speed-king`: `FLICK_MODES` / `FLICK_LINK_TARGETS` に `yakuzai`(PR → squash)。`HOME_GAMES` は 絵と OK の あと
8. けいくんに ChatGPT で 絵を 頼む 文を わたす。**3つ**:
   ・トップの 絵(1536×1024)。**人物は 画面の 下 3分の1に 小さく**・指5本・首が 見える。明るい 薬局の カウンターで、白衣の 子どもと 白い 犬が 笑っている 絵。うしろに 薬の 棚・薬の 形(錠剤・カプセル・目薬・ばんそうこう)・ハーブ(生薬)の 小さな 絵。
     **薬を 口に 入れる 絵・注射を 打つ 絵に しない**。**薬の 箱に 字や 商品名・ロゴを 描かない**。絵の 中の 字は「フリック薬剤師」だけ・ゲームに 無い 機能の 絵を 入れない。届いたら **まず 字を 切り出して 読む**
