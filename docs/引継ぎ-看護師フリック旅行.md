## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 3つ

### 1. **やりかたを 書かない**(いちばん 大事)
このゲームは **ことばと 意味を おぼえる** もの。**医療の やりかたは 書かない**。

- ❌ 書かない: 薬の 量・注射の しかた・心臓マッサージの 回数や 深さ・処置の 手順・
  「この しょうじょうなら この 病気」「こういう ときは こうする」の 言いかた
- ⭕ 書く: **その ことばが 何を さすか**(例: AED = 心臓が ふるえて いる ときに 電気を 流す 機械。使いかたは 音声が 教えてくれる)
- ⚠️ 画面の 下に かならず: **「これは ことばを おぼえる ゲームです。本当に 具合が わるい ときは、大人に 言って お医者さんへ」**
- ⚠️ **数字は なるべく 出さない**。体温・脈・血圧の 決まった 数は 本や 年れいで ちがう。
  出す ときは **「だいたいの めやす」** と 書き、**確かな 出どころで 確かめてから**

### 2. **子どもも あそぶ**
病気・けが・死・血・注射の 話が 入る。シリーズは **小学生も あそぶ**。

- こわい ようす(血・苦しむ ようす・死ぬ ようす)を **くわしく 書かない**
- 「看護師さんが どう 助けるか」を やさしく 書く(こわい ことでは なく、**助ける 仕事**として)
- ⚠️ 迷ったら けいくんに 聞く。子ども安全設計が シリーズの 土台(CLAUDE.md)

### 3. **からだ旅行と かぶらせない**
すでに **フリックからだ旅行(`karada/`)** に **骨・臓器・細胞・ツボ**が ある(`kbone` / `korgan` / `kcell` / `ktsubo`)。

- 看護師の 旅は **仕事の ことば・看護の 考えかた・病気と ケアの ことば**。からだの 部品の 名前は **入れない**

## 看護師だけの しくみ(整備士と ちがう ところ)

- **英字の 略語が 多い**。読みを 1つに 決めて `PROMPT.md` に 書く:
  ADL → えーでぃーえる / QOL → きゅーおーえる / AED → えーいーでぃー / CPR → しーぴーあーる /
  SpO2 → えすぴーおーつー / ICU → あいしーゆー / MRI → えむあーるあい
  ⚠️ 別の 読みは `acceptedReadings`。⚠️ **1問が 長く なりすぎない ように**(えすぴーおーつー は 9字で ちょうどよい)
- **とても 長い ことば**が ある(保健師助産師看護師法 = 16字、インフォームドコンセント = 13字)。
  ⚠️ **20字を こえる ものは 上級だけ**に 入れる
- **読みを まちがえやすい ことば**が 多い: 清拭(せいしき)・褥瘡(じょくそう)・喀痰(かくたん)・誤嚥(ごえん)・
  臥位(がい)・仰臥位(ぎょうがい)・体位(たいい)。⚠️ **1語ずつ 確かめる**
- **図**(決めてもらうこと 5): **病室・ナースステーションの 絵**に 📍(ベッド・点滴の スタンド・ナースコール・手あらい場・カルテ)。
  からだ旅行の `SVG_MAPS` と 同じ しくみ。⚠️ 絵は **ラベル(字)なし**・**こわくない 絵**で 作ってもらう
  (⚠️ 血・傷・注射針の アップは 入れない)

## ⚠️ 権利・安全の 注意(上の「いちばん 大事な 3つ」に くわえて)

## しくみ(整備士を 写す)

- ことば: `tools/kango/terms-<旅>.json`(旅ごと)→ `kango/terms.js`(`tools/seibi/terms_js.py` を 写した 台本)
- 遊びかた: `kango/kango.js`(`seibi/seibi.js` を 写す。旅・図鑑・称号・図)
- 決まりの 文書: `tools/kango/PROMPT.md`(`tools/seibi/PROMPT.md` を 写して 書きかえる)。1語の 形:
  `{"id":"ba-taion","name":"体温","reading":"たいおん","journey":"basic","category":"バイタルサイン","difficulty":1,"field":"基礎看護学","type":"concept","emoji":"🌡","mapNode":"...","relatedTerms":["ba-kenon"],"description":"..."}`
  - reading は **ひらがなと ー だけ**
  - `field`(試験の 分野)を 持って 図鑑で しぼれるように
  - 説明は 1〜3文・130字以内・です・ます。**語と 語の あいだに 半角スペース**(シリーズの 文体)
- **ことばを たくさん 作るときは** `PROMPT.md` を 決めて **助手(サブエージェント)に 旅ごとに 分けて 頼み**、形を 確かめる 台本で 確かめる。
  ⚠️ **作った 助手とは 別の 助手に 1語ずつ 確かめさせる**。見る ところは 4つ:
  ①意味は 正しいか ②読みは 正しいか ③**やりかた・数字を 書いていないか** ④**子どもが 読んで こわくないか**
