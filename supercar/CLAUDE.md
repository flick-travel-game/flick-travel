## フリックスーパーカー(`supercar/`。けいくん 2026-10-21「すべてのスーパーカー、ハイパーカーを 知っている 専門家レベルになるために必要な知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」・ブガッティは「両方に入れて歴史の説明を書く」・約1,000語+📷写真クイズ・並びは「サッカーのすぐあと」。まとめは `docs/フリックスーパーカー-はじめかた.md`)

- 名前は「フリックスーパーカー」(フォルダ `supercar`・modes `SUPERCAR`)。シリーズの 絵文字は 🏎。`SERIES_ORDER` は **ワールドサッカーの すぐ あと**(バスケの 前)。
  かずともの 旅の 名前は **`hc` で はじめる**(hckihon / hcgijutsu / hcitalia / hcdoitsu / hcigirisu / hcsekai / hcnihon / hchyper / hcdensetsu / hcmas。`sc` は 整備士・`kr` は 韓国語)。speed-king #440 で `FLICK_MODES` / `FLICK_LINK_TARGETS` に 足した
- 旅は 9つ(国ごとの メーカーが 柱): スーパーカーのきほん `kihon`・しくみと技術 `gijutsu`・イタリアのメーカー `italia`・ドイツのメーカー `doitsu`・イギリスのメーカー `igirisu`・世界のメーカー `sekai`・日本のスーパーカー `nihon`・ハイパーカーと記録 `hyper`・伝説の名車と人 `densetsu` + 🏆 マスター
- ⭐ **990語(旅ごとに 110語 = 入門30・中級40・上級40)を 1回で 出した**。はじめかたは「630語 → あとから 足す」だったが、110語 ぜんぶ 書いて 確かめ終わったので、**あとから 足すと ステージの 中身が 入れかわる**(宇宙図鑑の 前例)のを さけて はじめから ぜんぶ。`later/` は 無い
- むずかしさ 3段: 入門(車が すきな 小学生)→ 中級(車好きの 大人)→ 上級(専門家)。分野(`field`): メーカー / 車 / しくみ / デザイン / レース / 人 / 歴史
- ⭐ **3つの 札**(説明の 上): 国(`country` → `co`。**会社の 国**。人は 生まれた 国。28の 国・地域。`terms_js.py` の `COUNTRY` と `supercar.js` の `CO_ICON` を **両方** 直す)/ メーカー(`maker` → `mk`。**字だけ。ロゴ・エンブレムは 出さない**)/ 発表した 年(`year` → `y`。⚠️ 生産・日本発売の 年と まぜない。あやしい 車には 付けない)。図鑑で 🌍 国・🏭 メーカーで しぼれる
- ⭐ **🔤 つづり**(`ei`): Countach / Chiron など 本当の つづり。🔊 で 英語の 声で 読む(キャビンアテンダントの `enSay` を 写した)
- ⭐ **ブガッティ**(けいくん「両方に入れて歴史の説明を書く」): `sekai` に メーカー ブガッティ(フランス・モルスハイム)と 車(ヴェイロン・シロン …)。`doitsu` には **別の 読みで 歴史の 語 4つ**(ブガッティの復活 = 1998年に フォルクスワーゲングループが ブランドを 手に入れた 話・フェルディナント・ピエヒ・EB118・EB18/4 ヴェイロン。国は フランス・ドイツ)
- ことばは `tools/supercar/terms-<旅>.json`(決まり `PROMPT.md`・書く 係 `WRITER.md`・確かめる 係 `CHECKER.md`・置き場所 `plan.json` = 990語・読みの かぶり 0)→ `tools/supercar/terms_js.py` → `supercar/terms.js` + `data/supercar.json`。旅・図・称号は `tools/supercar/mkmeta.py` → `meta.json`(出どころの メモ `source.txt` → ホームの「📏 数字の 出どころ」)
  しくみは `supercar/supercar.js`(キャビンアテンダントを 写した)。ちがいは
  ・🧩 4択クイズに 2つの 形を 足した: **「◯◯を 作った メーカーは?」**(車の 名前から メーカー名を 外して 出す。`carName`)・**「◯◯(国)の メーカーは?」**(ほかの 国の メーカーから 3つ)。3問に 1回くらい
  ・⭐ **📷 写真クイズ**(この ゲームの 目玉): 写真が ある 車(field 車)だけ。写真を 見て 4つから 車名を えらぶ。まちがいは 同じ 旅・同じ メーカー → 同じ 旅 → ほか。**写真の 下に 撮った 人と ライセンス**(`creditOf`)
  ・🧮 計算問題 18しゅるい・6なかま(⚡ 馬力の 単位 / 🏁 速さの 単位 / ⚖️ パワーウェイトレシオ / 🔧 排気量 / 🌀 回転数 / 🔋 電気の 車)。**実在の 車の 数字は 使わない**(練習用の きりの よい 数)。速さの 問題は テストコース・サーキットの 話。3,000回ずつ 回して 選択肢 4つ・NaN なし・かぶり なし
  ・しくみ図(箱の 図)9つ。⚠️ 実在の 車の 形を 図で 写さない(うしろの 絵 `BG` は 使わない)
- ⚠️⚠️⚠️ **この ゲームの いちばん 大事な 決まり**(台本 `BAN` が 止める):
  ① **変わる 数字を 答えに しない**: 値段・オークション・順位・「世界最速」・いま 売っているか。馬力・最高速は「◯◯馬力 ほど(公表値)」と まるめて 説明の 中だけ。記録は「◯年に テストコースで ◯km/h を 出したと 発表」の 形(公道で 出した 記録(アゲーラ RS)は 入れなかった)
  ② **スピードを あおらない**: 公道・飛ばす・スピード違反・暴走・ゼロヨン・違法・峠 の 字は 使わない。画面と メモに「道路では 交通ルールを 守りましょう」
  ③ **お金の 話・事故・死・戦争 を 入れない**: 万円・億円・値段・価格・お金持ち・事故・死・亡・炎上・燃え・衝突・戦争・軍用・戦闘機・ナチ。亡くなった 人は 功績だけ。⚠️ 確かめ役が 外した もの: ローゼマイヤー(事故と ナチの 時代)→ ハンス・ヨアヒム・シュトゥックに 入れかえ / レヴェントンの「戦闘機が お手本」→ 形と 色の 説明 / 跳ね馬の バラッカの 話 / LM002 の 軍用の はじまり / ヴァンケルの 戦争の ころの 話 / 「007は二度死ぬ」(題名に 死)→「イギリスの スパイ映画」/ ボンドカーの 武器
  ④ **「いまも ◯◯して います」を 書かない**(変わる): F1で 戦う・社長を つとめる・作って いる → 過去の 形に 直した。GT-R R35 は 2025年8月に 生産終了なので 過去形
