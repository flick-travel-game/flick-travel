# フリック料理人: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
調理師試験の どの 科目か・しくみ図の どこに あるか(📍)が 出る。あそぶのは **小学生〜料理人を めざす 中高生・専門学校生・大人**。
**料理人(調理師)に なるための ことばと 意味を おぼえる ゲーム**(試験の 問題集でも、レシピ本でも ない)。
もとは `tools/patissier/PROMPT.md`(パティシエ)と `tools/kyoshi/PROMPT.md`(教師)。
けいくん 2026-09-30「料理人(調理師)になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」
+「ワイン・日本酒の 銘柄や 飲みかた・カクテルも入れてください」(8つめの 旅 🍷 お酒と飲みもの)。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 5つ

### 1. 小学生も あそぶ(いちばん 大事)
- 包丁・火・油・食中毒の ことばは **入れて よい**。ただし **「安全に 使う ための ことば」「食べる 人を 守る しくみ」** の 書きかただけ
- ❌ **書かない**: けがの ようす・やけどの ようす・こわい 先(「こう なって しまう」)・食中毒の つらい しょうじょう・命に かかわる 話
- ❌ **子どもが 家で 1人で まねを したく なる 書きかた**(「油を 熱して…」「包丁を こう 持って…」の 手順)を しない
- 刃物・火・油・高温が からむ ことばは、ときどき「火や 包丁を 使う ときは 大人と いっしょに」と 1言 そえて よい(毎回 書かなくて よい)
- **「死亡」「死ぬ」「亡くなる」「殺」「中毒死」「命を落と」は 使わない**(台本が 止める)。「殺菌」は **使って よい**(衛生の ことば)
- 読んだ 子が **こわく ならない** 書きかたに する。**迷ったら その 語を 入れない**

### 2. レシピの 数字を 書かない
- ❌ 分量(〜g・大さじ〜)・温度(〜℃で 揚げる)・時間(〜分 煮る)・カクテルの 配分 は **書かない**
- ⭕ その ことばが **何を さすか**・**何の ために あるか**・どんな 料理で 使うか
- ⭕ 例外: **法律・国の 手引きで 決まっている 数字**だけ 書いて よい(大量調理施設衛生管理マニュアルの 中心温度「75℃で 1分間 以上」・
  お酒は 20歳から・特定原材料 9品目 など)。**まよったら 書かない**

### 3. お酒の ことば(🍷 お酒と飲みもの の 旅)
- ✅ **入れて よい**(けいくん決定 2026-09-30): ワイン(ぶどうの 品種・産地・赤 白 ロゼ・スパークリング・テイスティング・デキャンタージュ …)/
  日本酒(純米・吟醸・大吟醸・本醸造・生酒・冷や・燗・酒米・麹・杜氏 …)/ 焼酎・泡盛 / ビール / ウイスキー・ブランデー・リキュール /
  カクテル(マティーニ・モヒート・ジントニック など **一般の 名前**)/ 飲みかた(ロック・水割り・ソーダ割り・燗 …)/ 料理との 相性(ペアリング・マリアージュ)
- ❌ **会社・蔵元・ワイナリー・商品の 名前(商標)は 入れない**。「銘柄」は **産地の 名前・種類・品種**で 表す
  (ボルドー・ブルゴーニュ・シャンパーニュ・リオハ・キャンティ などの **地名**は よい)
- ❌ **酔う 楽しさ・たくさん 飲む こと・一気飲みを すすめる 書きかた**を しない。カクテルの 作りかたの 配分を 書かない
- ⭕ お酒の 説明は **料理人・ソムリエが 知っておく ことば**の 目線。ときどき「お酒は 20歳に なってから」と そえて よい
- 20歳未満の 飲酒禁止は **法律の ことば**として 入れる(二十歳未満飲酒禁止法)

### 4. 商標・健康の 言いきりを しない
- **お店・会社・商品・ブランドの 名前は 使わない**。料理の 一般的な 名前(ブイヤベース・麻婆豆腐・肉じゃが)・地方の 名前・人の 名前(歴史の 人)は よい
- 「食べると やせる」「病気が 治る」など **健康の 言いきりを しない**(「〜に 役立つ と 言われる」「〜を ふくむ」の 形)

### 5. 料理人の 目線で 書く(パティシエ・からだ旅行・看護師と 同じ 語を 入れて よい)
- ✅ **ほかの ゲームと 同じ ことばを 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)
- ⚠️ ただし 説明は **料理人の 目線**で 書きなおす(パティシエの 文を 写さない)。
  例: 薄力粉 … パティシエ「ふんわり した スポンジに 向く」/ 料理人「天ぷらの 衣や ルウに 使う、ねばりの 出にくい 小麦粉」
- **読み(ひらがな)は 料理人の 8つの 旅の 中で かぶらない**(台本が 止める)。下の「旅ごとに 入れる / 入れない」を 守る

## 1語の 形(JSON)

```json
{"id":"kr-sengiri","name":"千切り","reading":"せんぎり","journey":"kiri","category":"基本の切りかた","difficulty":1,
 "field":"調理理論","type":"concept","emoji":"🥕","mapNode":"manaita:kihon","relatedTerms":["kr-tanzaku"],
 "description":"野菜を 細く 長く 切る 切りかた。キャベツや 大根で よく 使い、サラダや つけあわせ、あえものに なります。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(厨房で ふつうに 使う 言いかた。漢字・カタカナ・英字の 略語)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)
  - カタカナ語・フランス語・イタリア語・中国語は 日本の 厨房で ふつうに 言う 音を ひらがなに(そてー・あるでんて・ちゃーはん)
  - 数字は ひらがな(一汁三菜 → いちじゅうさんさい / 三枚おろし → さんまいおろし)
  - ゆれる ことばは 1つに 決め、別の 読みは `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)。例: ぶいやべーす / ぶやべーす
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は **上級だけ**に、旅で 1〜2語まで
  - ⚠️ **読みを まちがえやすい ことば**(面取り めんとり・隠し包丁 かくしぼうちょう・霜降り しもふり・湯むき ゆむき・
    向付 むこうづけ・八寸 はっすん・椀物 わんもの・強肴 しいざかな・香の物 こうのもの・吸い地 すいじ・
    昆布 こんぶ・鰹節 かつおぶし・味醂 みりん・麹 こうじ・杜氏 とうじ・吟醸 ぎんじょう・燗 かん・
    腸炎ビブリオ ちょうえんびぶりお・黄色ブドウ球菌 おうしょくぶどうきゅうきん・秋刀魚 さんま・鰆 さわら …)は **1語ずつ 確かめる**
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級(下の「3段の 分けかた」)
- **field**: 調理師試験の 6科目の どれか(入門の 語でも いちばん 近い ものを 書く):
  `公衆衛生学` `食品学` `栄養学` `食品衛生学` `調理理論` `食文化概論`
  - めやす: 食材の 種類・性質・加工品・調味料・お酒の 種類 → `食品学` / 切りかた・加熱・調理器具・調理の 科学・献立 → `調理理論` /
    栄養素・消化・食事摂取基準・年代の 食事 → `栄養学` / 食中毒・微生物・衛生管理・HACCP・添加物・食品衛生法・アレルギー表示 → `食品衛生学` /
    健康づくり・生活習慣病・健康増進法・調理師法・保健所・環境衛生 → `公衆衛生学` /
    和食・世界の 料理の 歴史・行事食・作法・郷土料理・お酒の 文化 → `食文化概論`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(🔪 の 多用は さける。🩸 💀 ☠️ など こわい 絵文字は 使わない)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / どんな 料理で 使うか・なぜ 大事か」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  専門用語を 専門用語だけで 説明しない。「1人」「2人」は ふりがなが 読みまちがえるので **ひとり・ふたり** と ひらがなで 書く
- **example**: なくてもよい

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | 台所で 聞く ことば。小学生でも 聞いた ことが ある / 絵が うかぶ(千切り・煮物・だし・手洗い・ワイン) |
| 2 | 中級 | **調理師試験の 6科目の 範囲の めやす**(面取り・霜降り・一汁三菜・腸炎ビブリオ・HACCP・五大栄養素・吟醸酒) |
| 3 | 上級 | プロの 厨房の ことば・**調理技術技能評価試験(専門調理師・調理技能士)**・フランス語 / 中国語の 厨房の ことば(強肴・八寸・コンソメ・ブイヨン・火候・デキャンタージュ) |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる
(ならんだ 順が そのまま ステージの 順に なる)。

- **お店・会社・商品・ブランド・蔵元の 名前は 使わない**(商標)
