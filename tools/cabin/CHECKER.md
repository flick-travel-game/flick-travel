# 確かめる 係への おねがい(フリックキャビンアテンダント)

あなたは **書いた 人とは 別の 目**で、ことばを 1語ずつ 確かめる 係です。決まりは `tools/cabin/PROMPT.md` と `tools/cabin/WRITER.md`(「確かめた 事実」の 一覧も ある)。
見る ファイル: あなたの 旅の `tools/cabin/terms-<旅>.json`(1回目)と `tools/cabin/later/terms-<旅>.json`(2回目)。

1語ずつ 見る こと:
1. **意味が 正しいか**(事実の まちがい・言いすぎ・古い 話・あやしい 数字。自信が 持てない 事実は 消すか ぼかす)
2. **読み**(reading)が 名前の ふつうの 読みか(英語は ふだんの カタカナ読みの ひらがな)。acceptedReadings も
3. **英語の つづり**(ei)・空港コード・時差が 正しいか
4. **こわく ないか**(事故・墜落・こわい ようす を 思わせないか。子どもが 読んで こわく ならないか)
5. **見た目・性別・国・宗教の 決めつけが ないか**、人を 責めて いないか
6. **会社名・制服・社内の マニュアル・給料・合格率・身長 体重の 条件・TOEIC の 点数** が 出て いないか
7. **客室乗務員の 目線**で 書いて あるか / やさしい です・ます / 語の あいだの 半角スペース / 130字以内 / settai は 60字以内・1文
8. difficulty が 合っているか(1 入門 = 飛行機・旅行が すきな 子 / 2 採用めやす / 3 訓練めやす)。⚠️ 動かすと 1回目・2回目の 数が かわるので、**difficulty は かえない**。おかしい ときは 報告だけ
9. relatedTerms が 意味の つながる 語か

直しかた: まちがいは **その ファイルを 直接 直す**(name・reading を かえた ときは 読みの かぶりに 気を つける)。
直したら `python3 tools/cabin/terms_js.py --check --with-later` で ❌ が 0(⚠️ も 0)に なる ことを 確かめる。⚠️ ほかの 旅の ファイルは さわらない。git の コミットは しない。
報告: 直した 語の id と「まえ → あと / 理由」を 一覧で(短く)。直さなかったが 気に なる ことも 書く。
