# フリックワールドサッカー: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
どの 国の 話か(国旗の 札)・学ぶ 分野・しくみ図の どこに あるか(📍)が 出る。
あそぶのは **サッカーが すきな 小学生〜中高生・少年団の コーチ・サッカーが すきな 大人・解説者を めざす 人**。
**サッカーの ことばと 意味を おぼえる ゲーム**(ニュースでも、試合の 記録集でも ない)。
もとは `tools/shika/PROMPT.md`(歯科医師)。けいくん 2026-10-09「ワールドサッカーの専門家(解説者)になれるレベルになるために必要な 知識、
主要サッカーリーグ、有名サッカー選手、有名なドリブル技(シャペウ、ルーレットなど)、ルールをフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」。
⭐ けいくんは **サッカースクールの 代表・コーチ**。サッカーの まちがいは すぐ 気づかれる。**選手と 国・技と 使い手・年と 大会 は かならず 確かめて から** 書く。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 8つ

### 1. ⭐⭐ 数字が 変わる ものを 書かない(いちばん 事故が 起きやすい)
- ❌ **いまの 所属クラブ**(移籍で 変わる)・年俸・移籍金・市場価値・いまの 順位・**通算ゴール数 / 出場数**・いまの 監督・いまの キャプテン・年齢(「◯歳」)
- ✅ **変わらない 事実は よい**: 国籍(代表)・ポジション・**得意な 技 / プレーの 特徴**・**過去の 受賞と その 年**(「2025年の バロンドール」)・
  **ワールドカップの 優勝の 年と 国**・**引退した 選手の 所属の 歴史**・大会の 優勝回数(国・クラブ)・人数(11人・交代の 人数)・生まれた 年
- リーグの **参加チーム数は 書かない**(変わる)。「イングランドの 1部リーグ」まで
- ⚠️ 台本 `terms_js.py` が「年俸・移籍金・通算・順位・◯歳・◯円・◯ゴール目」などを 止める

### 2. ⭐⭐ いまの スター選手(`star`)の 書きかた
- 「**◯◯代表の FW。速い ドリブルと 左足の シュートが 武器**」の ように **代表の 国・ポジション・プレーの 特徴**で 書く
- ❌ **クラブ名を 書かない**(説明にも 名前にも)。「所属」「在籍」「移籍」「加入」も 書かない(台本が 止める)
- ✅ 代表で 勝った 大会(「2022年 ワールドカップで 優勝した アルゼンチン代表の 一員」)・個人の 受賞と 年は よい
- ⚠️ **2026年10月の 時点で 現役か** を 1人ずつ web で 確かめる。引退した 選手は `legend` へ(ただし 旅を こえて 入れない。下の 表の 自分の 旅だけ)。
  **38歳を こえる 選手・引退が うわさの 選手**は 入れない(1年で 変わる)
- ⚠️ 選手の ケガ・不調・私生活・SNS・発言は 書かない

### 3. ⭐ ルールは いまの 版(IFAB 競技規則 2026/27・JFA サッカー競技規則 2026/27)
- 事実は `tools/soccer/exam.txt` の ①に 合わせる。ハンド・オフサイド・交代人数・VAR は **毎年 変わる ことが ある**
- 条の 番号(第◯条)は 書かない(台本が 止める)。「競技規則の『オフサイド』の 条」の ように 名前で
- 迷う 細かい ところ(例外の 例外)は 書かない。**4級審判の テキストで 習う ところ**を 中心に

### 4. 実在の 選手・クラブ・リーグ・大会の 名前は 入れて よい(事実として)
- ✅ 名前は よい。❌ **スポンサー名・クラブの エンブレムの 中身の 説明・ユニフォームの メーカー**は 書かない
- カタカナは **JFA・日本の 新聞で よく 使う 書きかた**に そろえる(例: ユヴェントス・ラ・リーガ・ブンデスリーガ・バイエルン・ミュンヘン・
  パリ・サンジェルマン・マンチェスター・シティ・リオネル・メッシ・キリアン・エムバペ(⚠️「ムバッペ」とも 書く → acceptedReadings に))
- 別の 書きかた・読みは `acceptedReadings` で 受ける

### 5. 人を けなさない・悲しい 場面を 入れない
- 「ダメな 選手」「負けた 国」の 書きかたを しない。**PK を 外した 話・オウンゴール・退場した 話・大敗**など 人が 悲しんだ 場面は 入れない(名場面は **いい ほう** だけ)
- ❌ マラドーナの「神の手」・ジダンの 頭突き・かみつき・乱闘・差別・八百長・賭け・薬物・ケガ・死・事故・私生活・スキャンダルは 入れない(台本が 止める)
- 亡くなった 名選手も 入れて よいが「亡くなった」とは 書かない(功績で 書く。歴史の 人物と 同じ)

### 6. ラフプレー・反則を すすめない・相手を ばかに しない
- 「シミュレーション」は **反則の 名前として**(「倒された ふりを する 反則。イエローカード」)。ずるい 技として 書かない
- ⭐ **ドリブル技は「練習で 身に つける 技」として**。シャペウ・股抜き・ラボーナは「相手の 動きを 見て ボールを 運ぶ 技」。
  ❌「相手を ばかに する」「なめた プレー」「挑発」の 書きかたを しない
- ⚠️ **技の 名前の もとは 説が 分かれる ものが 多い**。「◯◯が はじめた」と 言いきらず「◯◯の 得意技として 有名」「◯◯が 世界に 広めた」まで
  (例: クライフターン = 1974年 ワールドカップで クライフが 見せて 有名に なった / マルセイユルーレット = ジダンの 得意技として 有名 / エラシコ = ロナウジーニョの 得意技として 有名)

### 7. けいくんの 指導の ことばを 合わせると よい(⚠️ スクールの 名前は 出さない)
- **利き足**・**足に 吸いつく ドリブル**・**2軸シュート**・**ポジショニング**(ボールが 自分の もとに やってくる 位置を とる)・**ルックアップ**(顔を 上げて まわりを 見る)
- リフティングの 部位の 順: インステップ → モモ → アウトサイド → インサイド → 胸 → 頭

### 8. 事実を 正しく(⭐ かならず 確かめる)
- **選手と 国・技と 使い手・年と 大会・クラブと 町・ダービーの 組み合わせ**は 1語ずつ web で 確かめる(記憶で 書かない)
- ワールドカップ・大会・賞の 事実は `tools/soccer/exam.txt` に 合わせる。そこに 無い 年・大会を 書くときは web で 確かめてから
- 事実が あやしい 語は 入れない。**自分の ことばで 書く**(Wikipedia・公式の 文を 写さない)

## 1語の 形(JSON)

```json
{"id":"dr-chapeu","name":"シャペウ","reading":"しゃぺう","journey":"dribble","category":"浮かせる 技","difficulty":2,
 "field":"技術","type":"concept","emoji":"🎩","mapNode":"dribble:lift","relatedTerms":["dr-sombrero"],"country":"ブラジル",
 "description":"ボールを ふわりと 浮かせて 相手の 頭の 上を こえさせ、うしろで 受け取る 技です。ポルトガル語で「ぼうし」と いう 意味で、ブラジルで 生まれた よび名です。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(日本の 新聞・JFA で ふつうに 使う 書きかた。選手は「リオネル・メッシ」の ように ふつうに 知られた よび名)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)
  - カタカナ語は ひらがなで(マルセイユルーレット → まるせいゆるーれっと)。「・」は 取る(ラ・リーガ → らりーが)
  - 数字の 入る 名前は 読みで(4-4-2 → よんよんに。⭐ 解説者の 読み。⚠️ 4-3-3 → よんさんさん)
  - ゆれる ことばは いちばん ふつうの 読みを reading に、ほかを `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は 上級だけ・旅で 1〜2語まで(長い 名前の 選手は ふつうに 知られた よび名に する)
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級(下の「3段の 分けかた」)
- **field**: 学ぶ 分野。次の 6つの どれか: `ルール` / `技術` / `戦術` / `リーグ・クラブ` / `選手` / `大会・歴史`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(🩸 💀 ☠️ 🔪 🤕 🚑 😭 😱 は 使わない。⚽ ばかりに しない。国旗の 絵文字は 使わない(札で 出る ため))
- **country**(⭐ この ゲームだけの 欄。**関係が あれば 付ける**): その 選手・クラブ・技・大会・戦術が どの 国の 話か。
  `世界` `ヨーロッパ` `南アメリカ` `アジア` `アフリカ` `北中米` `日本` `韓国` `オーストラリア` `サウジアラビア` `カタール` `イラン`
  `ブラジル` `アルゼンチン` `ウルグアイ` `コロンビア` `チリ` `イングランド` `スコットランド` `ウェールズ` `北アイルランド` `アイルランド`
  `スペイン` `ポルトガル` `フランス` `ドイツ` `イタリア` `オランダ` `ベルギー` `クロアチア` `スイス` `オーストリア` `デンマーク` `スウェーデン` `ノルウェー`
  `ポーランド` `トルコ` `ハンガリー` `チェコ` `セルビア` `ギリシャ` `アメリカ` `カナダ` `メキシコ` `エジプト` `セネガル` `モロッコ` `ナイジェリア`
  `カメルーン` `ガーナ` `コートジボワール` `南アフリカ` `ジョージア` の どれか。2〜3つなら「・」で(`"アメリカ・カナダ・メキシコ"`)。
  選手は **代表の 国**。ルール・きほんの ことばなど 国と 関係ない 語は 付けない(⚠️ イングランドで 生まれた ことば・ブラジルで 生まれた 技名 などは 付けて よい = へえ)。
  ⚠️ イギリスは 使わない。サッカーでは **イングランド・スコットランド・ウェールズ・北アイルランドが 別の 代表**(へえ)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / どんな 特徴か / へえ」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  文体は **はじめから「〜です・ます」**(体言止めで はじめない)。「1人」「2人」は ふりがなが 読みまちがえるので **ひとり・ふたり** に 言いかえる
- **example**: なくてもよい
- 「へえ」を 1文 入れると よい(「ブラジルは ワールドカップで いちばん 多い 5回 優勝」「シャペウは ポルトガル語で ぼうし」)

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | **サッカーが すきな 小学生**。ポジション・きほんの ルール・だれでも 知っている 選手と 技と 大会の 名前 |
| 2 | 中級 | **少年団の コーチ・サッカーが すきな 大人**。**4級審判の 範囲の めやす**の ルール・リーグと クラブ・技の 中身 |
| 3 | 上級 | **解説者**。戦術の ことば・名監督・大会の 歴史・ルールの 細かい ところ |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる
(ならんだ 順が そのまま ステージの 順に なる)。

## 旅ごとに 入れる 語(⚠️ **読みが かぶると 台本が 止まる**。ほかの 旅の 欄に 書いてある 語は 入れない。ここに 無い 語を 足すのは よい)
