# フリック投資家(`toshika/`)を 作る ための まとめ(2026-10-02。新しい セッション用)

けいくん 2026-10-02「新しいセッションで フリック投資家を作成したい。投資家の専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください。
日本一の投資家、竹田和平さんのように **好きな企業を応援する長期投資スタイルがメインの投資家**に育ってほしいです。ホームページも確認して参考にしてください」
(参考: 竹田和平さんの ページ https://creek.jp.net/gold/about_takeda.html )

## 1. この ゲームの 芯(けいくんの ねがい)
- **めざす 投資家の すがた = 竹田和平さんの ような「好きな 会社を 応援する 長期投資」**。
  短く 売り買いして もうける 人では なく、**会社の 仕事・商品・人を 知って 好きに なり、株主として 長く 応援する 人**
- だから 旅の まん中は「会社を 知る」「長く 持つ」「株主として 応援する」。デイトレード・信用取引・FX・仮想通貨の 売り買いは **名前と しくみだけ**(すすめない)
- 竹田和平さんの ページで 確かめた こと(2026-10-02。**ほかの 事実は 書く前に もう一度 確かめる**):
  1933年(昭和8年)名古屋生まれ・2016年(平成28年)7月21日 逝去 / 竹田製菓(いまの 竹田本社)を つくり「タマゴボーロ」を 大ヒットに /
  100社 以上の 大株主として「日本一の 個人投資家」と 呼ばれた(平成12年ごろ)/「和製ウォーレン・バフェット」/ 自分で「平成の 花咲爺(はなさかじいさん)」と 名のった /
  「徳」を 大切に(貯徳・智徳)/「恒産なくして 恒心なし」の ことばを 大切に した。
  ⚠️ **亡くなった 日・死の ようすは ゲームに 書かない**(小学生も あそぶ。「1933年 生まれの 投資家」と 書けば よい)
- ⚠️ 参考の ページは **純金の 家宝を 売る ページ**(竹田本社 製作・クリークレンタリース 運営)。**金(きん)の 商品や その サイトを ゲームで すすめない・リンクしない**

## 3. はじめに けいくんに 聞く 5つ(「全部おすすめで」と 返ってくる ことが 多い)
1. **名前**: 「フリック投資家」で よいか(フォルダ名 `toshika` は 変えない。かずともの 旅の 名前は `tk` で はじめる: tkkihon / tkkaisha / tkchoki / tkkessan / tkshijo / tkkokoro / tkrekishi / tkmas。**作る 前に `build_games.py` で `tk` が 空いているか 確かめる**)
2. **旅の 分けかた**(おすすめ 7つ + 🏆 マスター):
   🌱 投資の きほん `kihon`(投資・貯金と 投資の ちがい・株式・株主・配当・株主優待・リスクと リターン・複利・分散・長期・NISA の 名前 …)/
   🏢 会社を 知る `kaisha`(事業・商品・ブランド・経営者・理念・競争力・お客さん・社員・地域・ESG・SDGs・**好きな 会社を 見つける**目線 …)/
   🌳 長期投資と 応援 `choki`(長期投資・バイアンドホールド・株主総会・議決権・株主の 応援・増配・再投資・ドルコスト平均法・**竹田和平さんの 考えかた**(花咲爺・徳・旦那)…)/
   📊 決算書を 読む `kessan`(決算・売上高・営業利益・純利益・貸借対照表・損益計算書・キャッシュフロー・自己資本比率・ROE・PER・PBR・配当利回り … **名前と 何を 見る 数字か**だけ)/
   🏛️ 市場と しくみ `shijo`(証券取引所・東証の 市場区分・証券会社・上場・株価・株価指数(日経平均・TOPIX)・投資信託・ETF・債券・金利・為替 …)/
   🧭 投資家の こころ `kokoro`(長い 目・あわてない・人の まねを しない・知らない 会社には 投資しない・失敗から 学ぶ・行動経済学の ことば(損失回避・群集心理)…)/
   📜 投資の 歴史と 人びと `rekishi`(東インド会社・株式会社の はじまり・堂島米会所・渋沢栄一・バフェット・グレアム・竹田和平・バブル の 名前 …)
3. **むずかしさの 3段**: 入門(くらしや ニュースで 聞く お金の ことば)→ 中級(**証券外務員・FP(ファイナンシャル・プランナー)の 範囲の めやす**)→ 上級(**証券アナリスト(日本証券アナリスト協会の CMA)の 範囲の めやす**: 企業分析・決算書の こまかい 指標・ポートフォリオ理論の ことば)
4. **1語に 持たせる 分野**(`field`): 投資の きほん / 企業分析 / 財務・決算 / 市場と 制度 / 長期投資 / 行動ファイナンス / 歴史 の どれか
5. **入れない もの**(下の 4 と かさなる): どの 株を 買えば よいか・売り時 買い時・「必ず もうかる」・FX・信用取引・仮想通貨の 売り買いの やりかた・ギャンブルに 見える もの・**実在の 会社を すすめる 言いかた**

## 4. ⚠️⚠️⚠️ ぜったいの 決まり(税理士と 同じ。投資は なおさら)
- ✅ **ほかの ゲーム(株式旅行・税理士 など)と 同じ 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。説明は **長期で 会社を 応援する 投資家の 目線**で 書きなおす
- **読み(ひらがな)は 投資家の 7つの 旅の 中では かぶらない**(ほかの ゲームとは かぶって よい)
- ⚠️⚠️ **投資の すすめ・銘柄の すすめ・売り買いの 時期を ぜったいに 書かない**(金融商品取引法の「投資助言」に 当たる 書きかたを しない)。
  ❌「◯◯の 株を 買うと よい」「いまが 買い時」「◯%もうかる」「必ず 上がる」/ ⭕ その ことばが **何を さすか・何の ための しくみか・長期の 投資家が どう 考えるか**
- **実在の 会社を 例に しない**(株式旅行には 会社が 出るが、こちらは **しくみの ゲーム**。「ある お菓子の 会社」の ように 書く)。
  人物は **歴史上の 人・亡くなった 人だけ**(竹田和平・渋沢栄一・ベンジャミン・グレアム など)。**生きている 投資家の 名前は 入れない**(⚠️ バフェットは 存命。入れるなら「和製ウォーレン・バフェット と 呼ばれた」の 形で 竹田和平さんの 説明の 中だけ に するか、けいくんに 聞く)
- ⚠️⚠️ **株価・利回り・税率・金額・割合の 数字を 書かない**(税理士と 同じ。NISA の 上限額・非課税の 年数も 書かない。**制度の 名前と 目的だけ**)
- **投資の 相談の 答えに なる 書きかたを しない**。画面に「これは ことばを おぼえる ゲームです。投資を すすめる ものでは ありません。お金の ことは おうちの 人や 専門の 人と 相談してください」
- **小学生も あそぶ**: 借金・破産・大損・倒産・自殺に つながる 話・バブルの 崩壊の こわい ようすを 書かない。リスクは「値段が 下がる ことも ある」と おだやかに。
  **お金の 価値で 人を くらべない**(「お金持ちは えらい」に しない。竹田和平さんの「徳」「花咲爺」= **まわりを 幸せに する** 目線を まん中に)
- **投資に「ギャンブル」の かおりを つけない**(ゲームの 演出・ことばの 選びかたも。ガチャ・くじ・賭けの 絵を 使わない)
- **作った 助手とは 別の 助手が 1語ずつ 確かめる**(意味・読み・すすめや 数字を 書いていないか・相談の 答えに なっていないか・実在の 会社が 出ていないか・こわくないか)。ふりがなも 全語 見る(`tools/ruby_fix.json`)

## 5. 資格・制度の 事実は **その日に 公式の ページで 確かめてから** 書く
「投資家」に **国家資格は 無い**(⚠️ アドラーと 同じ)。`meta.json` の `exam` には「専門家に なる 道」を 確かめた 日つきで 書く(**記憶で 書かない**):
証券外務員(日本証券業協会)/ FP(ファイナンシャル・プランニング技能士は 国家検定。AFP・CFP は 日本FP協会)/ 証券アナリスト(日本証券アナリスト協会 CMA)/
金融商品取引法(投資助言・代理業は 登録が 要る = **だから この ゲームは 助言を しない**)/ NISA(名前と「投資で えた もうけに 税金が かからない しくみ」だけ。上限額は 書かない)/
東証の 市場区分(プライム・スタンダード・グロース。確かめる)/ 竹田和平さんの 事実(上の 1 で 確かめた もの。足すなら その日に 確かめる)。
⚠️ 「専門家になれるレベル」は **証券アナリスト(CMA)の 範囲の ことばを ひととおり 知っている**こと、と けいくんに 伝える

## 6. 作りかたの 手順(税理士・アドラーの まとめと 同じ)
1. けいくんに 3 の 5つを 聞く → 返事を CLAUDE.md に 書く
2. `tools/toshika/PROMPT.md` `exam.txt` `mkmeta.py` → `meta.json` を 作る → 旅ごとに 助手に 70語ずつ 頼む(`PROMPT.md` を そのまま わたす。**助手は 2人ずつ**)→ `terms-<旅>.json`
3. `terms_js.py` で 止められた 語を 直す → 別の 助手が 1語ずつ 確かめる → ふりがな
4. `toshika/toshika.js`(zeirishi.js を 写す)・`build_games.py`・`index.html` の PLUG と SERIES → `python3 tools/build_games.py`
5. 手元で 通す: `python3 -m http.server 8765` → `node tools/play-all.mjs toshika/` / `node tools/click-all.mjs toshika/`
6. PR は **rebase で 取りこむ**(この 入れもの)。speed-king は squash。コミットの 末尾は Co-Authored-By と Claude-Session の 2行
7. かずとも `speed-king`: `FLICK_MODES` / `FLICK_LINK_TARGETS` に `toshika`(PR → squash)。`HOME_GAMES` は 絵と OK の あと(株式旅行と 同じ 章か、新しい 章かは けいくんに 聞く)
8. けいくんに ChatGPT で 絵を 頼む 文を わたす。**3つ**:
   ・トップの 絵(1536×1024)。**人物は 画面の 下 3分の1に 小さく**・指5本・首が 見える。**種から 大きな 木が 育つ 庭・商店街の お店を 応援する 子どもたち**の ような「長く 応援する」絵。
     **お札・金貨・コインの 山・株価の 矢印が 急に 上がる グラフ・ギャンブルの 絵を 描かない**。絵の 中の 字は「フリック投資家」だけ・ゲームに 無い 機能の 絵を 入れない・**実在の 会社の ロゴ・竹田和平さんの 顔を 描かない**
   ・四角い 絵(1254px)… **切らずに そのまま アイコンに する**(2026-10-02 の 決めごと)ので、**小さく しても わかる 絵**(人と 犬と 木 くらい。まわりに 字の 札を ならべない)で 頼む
   ・**題名だけの 透明 PNG**(CLAUDE.md「題名は ChatGPT に 切りぬいてもらう」の 文を そのまま。「フリック投資家」と **はっきり 書く**。⚠️ ChatGPT は 字を 変える(株式旅行 → 株式会社 など)。**届いた 字を かならず 読む**)
9. 絵を 入れたら CLAUDE.md に 節を 書く(名前・旅・語数・確かめた 日・入れなかった 語と 理由)

## 7. 気をつける 前例
- 株式旅行(`kabu/`)と **同じ 語が 多く 出る**(株主・配当・決算・上場・東証 など)。**同じ 語を 入れて よい**が、株式旅行 = 会社を 知る / 投資家 = 長く 応援する 投資の 考えかた、と 目線を 分ける
- 税理士(`zeirishi/`)とも かさなる(貸借対照表・損益計算書・NISA など)。同じ 語で よい。説明は 投資家の 目線で
- 税理士で「消費税 10%」も 書かない 決まりに した(税率が 変わる 予定)。投資家は **株価・利回り・NISA の 上限**が 毎年 変わるので、数字は **もっと きびしく** 書かない
- 2026-10-02 の 時点で 29ゲーム(アドラー心理学まで)。**フォルダ・id・modes 名を まぜない**(`toshika`)
- ⚠️ お金の ゲームは **大人(おうちの 人)が 見て 安心できる**ことが いちばん 大事。「子どもに 投資を すすめる ゲーム」に 見えない よう、画面の 文・絵・ことばの 選びかたを **「会社と 社会を 知る・長く 応援する 心を 育てる」** に そろえる
