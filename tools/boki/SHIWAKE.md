# 🧾 仕訳クイズの 作りかた(フリック日商簿記)

⭐⭐ **簿記は「ことば」より「手を 動かす」試験**。いちばん 大事な しくみ。取引の 文を 読んで、
① **借方・貸方の 勘定科目の くみあわせ**を 4つから えらぶ → ② **金額**を 4つから えらぶ(2段)。

## 1問の 形(JSON。`tools/boki/shiwake-<旅id>.json` に 配列で)
{"id":"001","dv":1,"rs":"商業簿記","f":"商品売買","q":"さくら商店は 商品 30,000円を 仕入れ、代金は 掛けと した。",
 "dr":[["仕入",30000]],"cr":[["買掛金",30000]],
 "ng":["未払金","商品","売掛金"],
 "wa":[[3000,3000],[33000,33000],[300000,300000]],
 "why":"商品を 仕入れたので 費用の「仕入」が ふえて 借方。代金を あとで はらう 約束(掛け)なので 負債の「買掛金」が ふえて 貸方。⚠️ 商品の 代金は 未払金では なく 買掛金。",
 "term":"s3-kaikakekin"}
- id: 旅の 中で "001" から 3けた(ゲームでは「<旅>-001」に なる)
- dv: 1 / 2 / 3(旅の 中の むずかしさ。1 = 基本の 型・2 = 試験の ふつう・3 = 差が つく・ひっかけ・諸口)
- rs: 商業簿記 / 工業簿記 / 会計学 / 原価計算(旅の 級に 合わせる)
- f: 分野(plan.json と 同じ 字: 簿記の きほん / 商品売買 / 債権債務 / 現金預金 / 固定資産 / 決算 / 株式会社 / 有価証券 / 連結 / 税効果 / 外貨 / 金融商品 / 収益認識 / 原価計算 / 標準原価 / 直接原価 / 会計基準 / 管理会計)
- q: 取引の 文(80字 くらい まで。長い 連結・工業簿記は 160字 まで)。**会社名は 架空**(さくら商店・あおば工業・ひかり製作所・つばさ物産・こだま電機 …。⚠️「みらい商事」は 使わない)。
  金額は 3けたごとに「,」。⚠️ **計算の 決まりが いる ときは 文に 書く**(「月割計算」「円未満 切り捨て」「消費税は 税抜方式・税率 10%」「決算日は 3月31日」「間接法で 記帳」「三分法」)
- dr / cr: 借方 / 貸方 の [勘定科目, 金額] の 配列。**勘定科目は 出題区分表・許容勘定科目の 名前**。⭐ **借方の 合計 = 貸方の 合計**(台本で 確かめる)。
  1行に 同じ 科目を 2回 書かない(まとめる)。金額は 正の 整数(円)
  ⭐ 3行 以上(諸口)・借方 2つ / 貸方 2つ の 問題も 入れる(dv 2〜3 で 3割 くらい)
- ng: **この 問題では 正しくない が、まちがえやすい 勘定科目**を 3つ 以上(正しい 科目の どれかと 入れかえて まちがいの 選択肢を 作る)。
  ⚠️ 入れかえても 正しく なって しまう 科目(どちらでも よい 科目)は 入れない。dr / cr に ある 科目も 入れない
- wa: **まちがいの 金額**を 3つ。それぞれ dr の 金額 → cr の 金額 の 順の 配列(長さ = dr の 行数 + cr の 行数)。
  よく ある まちがい(月割 わすれ・税込と 税抜・差額の 取りちがえ・率の 取りちがえ・けた)から 作る。正しい 金額と 同じ 配列は ダメ。3つとも ちがう 配列
- why: とき方 1〜3文・**160字 以内**。どの 箱(資産・負債・純資産・費用・収益)が ふえる / へるか → 借方か 貸方か。計算が あれば 式。⚠️ ひっかけを 1つ
- term: 関係する ことばの id(同じ 旅の terms-<旅>.json の id。無ければ 書かない)

## 決まり
- ⭐ **2027年度版の 出題区分表の 範囲**(facts.md。けいくん決定 2026-11-07)。⚠️ **手形・小切手の 仕訳は 出さない**(当座預金・普通預金・電子記録債権で)。2級の リースは 使用権資産 / リース負債(利子込み法・利子抜き法)、2級 以上の 家賃は 支払リース料(3級は 支払家賃)。定率法・除却・廃棄は 3級でも 出す。3級は 個人商店 では なく 小さな 株式会社(資本金・繰越利益剰余金・法人税等)
- 3級の 商品売買は **三分法**(仕入・売上・繰越商品)。⚠️ 分記法は 出さない(説明に「前は」も いらない)
- 消費税は **税抜方式**(仮払消費税・仮受消費税・未払消費税)
- 減価償却は 3級 = 定額法・定率法(償却率を 示す)・間接法、2級 = 200%定率法・生産高比例法 も、記帳は とくに ことわらなければ **間接法**
- 工業簿記は 勘定の 流れ(材料 → 仕掛品 → 製品 → 売上原価)。⚠️ 本社工場会計など 指定が いる ときは 文に 書く
- 1級 会計学の 旅は 仕訳が すくない(会計基準の 考えかたの 仕訳だけ)
- **過去問・問題集の 文を 写さない**。数字も 自分で 決める
- 2人の 別の 助手が 解いて 答えが 合うか 確かめる(`check_sw.py` で 借方 = 貸方 も 見る)
