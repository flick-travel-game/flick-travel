## C-1. 都市計画法

### C-1-1. 区域
| 事実 | 出どころ |
|---|---|
| 都市計画区域は **都道府県が 指定**(関係市町村・都道府県都市計画審議会の 意見を聴き、国土交通大臣に 協議・同意)。**2つ以上の 都府県に またがる ものは 国土交通大臣が 指定**。市町村の 区域外に わたって 指定できる | 都計法5条1項・3項・4項 |
| 準都市計画区域は **都市計画区域外**で、そのままでは 将来 一体の 都市としての 整備に 支障が 出る おそれが ある 区域を **都道府県が 指定できる** | 都計法5条の2第1項 |
| 区域区分(線引き)= 市街化区域 と 市街化調整区域 に 分ける こと。都市計画区域に「定めることができる」(三大都市圏の 一部・政令の 大都市は「定めるものとする」) | 都計法7条1項 |
| 市街化区域 = **すでに 市街地を 形成している 区域 及び おおむね 十年以内に 優先的かつ計画的に 市街化を 図るべき 区域** | 都計法7条2項 |
| 市街化調整区域 = **市街化を 抑制すべき 区域** | 都計法7条3項 |
| 市街化区域には **少なくとも 用途地域を 定める**。市街化調整区域には **原則として 用途地域を 定めない** | 都計法13条1項7号 |
| 区域区分の 都市計画は **都道府県が 定める**(指定都市の 区域は 指定都市) | 都計法15条1項2号・87条の2 |

### C-1-2. 用途地域と 地域地区
| 事実 | 出どころ |
|---|---|
| 用途地域は **13種類**: 第一種低層住居専用・第二種低層住居専用・第一種中高層住居専用・第二種中高層住居専用・第一種住居・第二種住居・準住居・**田園住居**・近隣商業・商業・準工業・工業・工業専用 | 都計法8条1項1号 |
| 田園住居地域 = 農業の 利便の 増進を 図りつつ、これと 調和した 低層住宅に 係る 良好な 住居の 環境を 保護する 地域 | 都計法9条8項 |
| ⚠️ 田園住居地域が 加わった「2018年」(平成30年4月施行)という 年は **未確認**(この日は 条文に 入っている ことだけ 確かめた) | — |
| 準住居地域 = 道路の 沿道として ふさわしい 業務の 利便と 調和した 住居の 環境を 保護 | 都計法9条7項 |
| 工業専用地域 = 工業の 利便を 増進する 地域 / 工業地域 = 主として 工業の 利便 / 準工業地域 = 主として 環境の 悪化を もたらす おそれの ない 工業の 利便 | 都計法9条11〜13項 |
| 特別用途地区 = **用途地域内**の 一定の 地区で、用途地域の 指定を **補完**して 定める | 都計法9条14項 |
| 特定用途制限地域 = **用途地域が 定められていない 土地の 区域(市街化調整区域を 除く)**で 定める | 都計法9条15項 |
| 高度地区 = 用途地域内で 建築物の **高さの 最高限度 又は 最低限度** | 都計法9条18項 |
| 高度利用地区 = 用途地域内で **容積率の 最高限度 及び 最低限度・建蔽率の 最高限度・建築面積の 最低限度・壁面の位置の 制限** | 都計法9条19項 |
| 防火地域 又は 準防火地域 = 市街地に おける 火災の 危険を 防除する 地域 | 都計法9条21項 |
| 地区計画 = 一体として その 区域の 特性に ふさわしい 良好な 環境の 各街区を 整備・開発・保全するための 計画 | 都計法12条の5第1項 |
| 地区計画の 区域(地区整備計画などが 定められた 区域)で 土地の 区画形質の 変更・建築などを する 人は **着手の 30日前までに 市町村長に 届出** | 都計法58条の2第1項 |

### C-1-3. 開発許可
| 事実 | 出どころ |
|---|---|
| 開発行為 = 主として 建築物の 建築 又は 特定工作物の 建設の 用に 供する 目的で 行う **土地の 区画形質の 変更** | 都計法4条12項 |
| 第一種特定工作物 = コンクリートプラント など / 第二種特定工作物 = ゴルフコース など 大規模な 工作物 | 都計法4条11項 |
| 許可を 出すのは **都道府県知事**(**指定都市・中核市の 区域は その 長** = 指定都市等) | 都計法29条1項 |
| 許可が 要らない 規模(未満): **市街化区域 1,000㎡**・**区域区分が 定められていない 都市計画区域 と 準都市計画区域 3,000㎡** | 都計法29条1項1号・都計令19条1項 |
| 条例で 小さく できる 範囲: 市街化区域 300㎡以上1,000㎡未満 / 非線引き・準都市 300㎡以上3,000㎡未満 | 都計令19条1項(表) |
| **三大都市圏の 一部**(首都圏の 既成市街地・近郊整備地帯、近畿圏の 既成都市区域・近郊整備区域、中部圏の 都市整備区域)と 東京23区の 市街化区域は **500㎡** | 都計令19条2項 |
| ⚠️ **市街化調整区域には 規模の 例外が ない**(29条1項1号は 市街化区域・非線引き・準都市 だけ) | 都計法29条1項1号 |
| 都市計画区域 及び 準都市計画区域 **外**: **1ヘクタール以上**の 開発行為は 知事の 許可 | 都計法29条2項・都計令22条の2 |
| **農林漁業用の 建築物**(畜舎・温室・サイロ・農機具等収納施設・建築面積 90㎡以内 など)や 農林漁業者の 住宅の ための 開発行為は 許可不要。ただし 対象は **市街化調整区域・非線引き・準都市**(⚠️ **市街化区域は 含まない**)と 区域外 | 都計法29条1項2号・2項1号・都計令20条 |
| 駅舎・図書館・公民館・変電所 など 公益上 必要な 建築物の ための 開発行為は 許可不要 | 都計法29条1項3号 |
| 都市計画事業・土地区画整理事業・市街地再開発事業 などの 施行として 行う もの、非常災害の 応急措置、通常の 管理行為・軽易な 行為 は 許可不要 | 都計法29条1項4〜11号 |
| 許可申請の 前に 関係する **公共施設の 管理者と 協議し 同意**を 得る | 都計法32条1項 |
| 工事完了 → 知事に 届出 → 検査 → 検査済証 → **工事完了の 公告** | 都計法36条 |
| **工事完了の 公告が あるまで**は 原則 建築物を 建築できない(例外: 工事用の 仮設建築物・知事が 支障ないと 認めた とき・同意を していない 権利者の 権利行使) | 都計法37条 |
| 公告の **あと**は 予定建築物 以外の 建築・用途変更は 原則 できない(知事の 許可 / 用途地域等が 定められている とき は 別) | 都計法42条1項 |
| 市街化調整区域の 開発許可を 受けた 区域 **以外**で 建築物を 新築・改築・用途変更する には 知事の 許可(農林漁業用・公益上 必要な 建築物・仮設建築物 などは 除く) | 都計法43条1項 |

### C-1-4. 都市計画事業の 制限
| 事実 | 出どころ |
|---|---|
| 都市計画施設の 区域 又は 市街地開発事業の 施行区域で 建築物を 建築する には **都道府県知事等の 許可**(軽易な 行為・非常災害の 応急措置 などは 除く) | 都計法53条1項 |
| 許可しなければ ならない 例: **階数 2以下・地階なし・主要構造部が 木造・鉄骨造・コンクリートブロック造 など で、容易に 移転・除却できる** もの | 都計法54条3号 |
| 事業の 認可等の 告示の あとは、事業地内で 事業の 障害と なる おそれの ある **土地の 形質の 変更・建築物の 建築・工作物の 建設・移動の 容易でない 物件の 設置や 堆積** に 都道府県知事等の 許可 | 都計法65条1項 |

## C-2. 建築基準法

### C-2-1. 道路と 接道
| 事実 | 出どころ |
|---|---|
| 道路 = 幅員 **4m以上**(特定行政庁が 指定する 区域は 6m)の 道路法の 道路 など | 建基法42条1項 |
| **2項道路**: 適用の 際 現に 建築物が 立ち並んでいる 幅員 4m未満の 道で 特定行政庁が 指定した もの。**中心線から 水平距離 2m の 線**を 道路の 境界線と みなす(片側が 崖地・川・線路敷地 などなら その 境界線から 4m) | 建基法42条2項 |
| 敷地は 道路に **2m以上 接しなければ ならない**(自動車のみの 交通の 用に 供する 道路 などを 除く) | 建基法43条1項 |

### C-2-2. 建蔽率
| 事実 | 出どころ |
|---|---|
| 用途地域ごとの 建蔽率(都市計画で えらぶ): 低層住専・中高層住専・田園住居・工業専用 = 3/10・4/10・5/10・6/10 / 第一種・第二種住居・準住居・準工業 = 5/10・6/10・8/10 / 近隣商業 = 6/10・8/10 / **商業 = 8/10** / 工業 = 5/10・6/10 / 用途地域の 指定の ない 区域 = 3/10〜7/10 | 建基法53条1項 |
| 敷地が 2つ以上の 地域に またがる とき は **面積の 割合で 加重平均** | 建基法53条2項 |
| **+1/10**: ① 防火地域(建蔽率 8/10 の 地域を 除く)内の **耐火建築物等**、又は 準防火地域内の **耐火建築物等・準耐火建築物等** / ② **角地**(特定行政庁が 指定)。**両方なら +2/10** | 建基法53条3項 |
| **建蔽率 制限 なし**: 建蔽率 8/10 の 地域で **防火地域内の 耐火建築物等**・巡査派出所・公衆便所・公共用歩廊 など | 建基法53条6項 |
| 敷地が 防火地域の 内外に わたり、建築物の 全部が 耐火建築物等 なら 全部 防火地域内と みなす | 建基法53条7項 |

### C-2-3. 容積率
| 事実 | 出どころ |
|---|---|
| 前面道路(2つ以上なら 最大の もの)の 幅員が **12m未満** の とき: 幅員(m)× **住居系 4/10**(低層住専・田園住居 は 4/10。中高層住専・住居・準住居 は 4/10、特定行政庁の 指定区域は 6/10)/ **その他 6/10**(指定区域は 4/10 又は 8/10) | 建基法52条2項 |
| 敷地が 2つ以上の 地域に またがる とき は 容積率も **加重平均** | 建基法52条7項 |
| 地階で 天井が 地盤面から 1m以下の 住宅・老人ホーム等の 部分は、住宅等の 床面積の 合計の **1/3まで** 延べ面積に 算入しない | 建基法52条3項 |
| 用途など ほかの 制限は、敷地の **過半**が 属する 地域の 規定を 全部に 適用(建蔽率・容積率・高さ制限・防火地域 などは この ルールの 外) | 建基法91条 |
| 建築物が 防火地域 又は 準防火地域と その外に わたる とき は **全部に 防火地域(準防火地域)の 規定**(防火壁で 区画された 外の 部分は 別)。防火地域と 準防火地域に わたる とき は 全部 防火地域 | 建基法65条 |

### C-2-5. 防火地域・準防火地域
| 事実 | 出どころ |
|---|---|

### C-2-7. 単体規定
| 事実 | 出どころ |
