# ことばを 書く 係への おねがい(フリック犬の気持ち。旅を 書く)

1. まず `tools/inu/PROMPT.md` を ぜんぶ 読む(4つの いちばん大事な 決まり・1語の 形・mapNode の 表・旅の さかいめ)。
   手本の 書きぶりは `tools/mentalist/terms-kansatsu.json`(renshu の 書きかた)・`tools/jui/terms-pet.json`(動物の 書きかた)・`tools/shinri/terms-kihon.json`(科学の 書きかた)。
   ⚠️ 心理学・獣医師と 同じ 語(オキシトシン・社会化 など)は `grep -r` して 中身が 食いちがわない ように
2. `tools/inu/plan.json` の あなたの 旅の 語を、**plan の 順番の まま**(name・reading・difficulty・mapNode は plan の とおり。直したい ときは 下の 6)で 書く
   - phase 1 の 語 → `tools/inu/terms-<旅>.json`
   - phase 2 の 語 → `tools/inu/later/terms-<旅>.json`(⚠️ 頼まれた ときだけ)
   - relatedTerms は **同じ ファイルの 中の** id だけ
3. description は **犬の 気持ちの 目線**、やさしい です・ます、語と 語の あいだに 半角スペース、130字以内
4. ⭐⭐ **renshu(🎯 やってみよう)を 全部の 語に**(90字以内)。家の 犬 / はなれて 見る / 動画 の 3つの 形。犬が いない 子むけを 3分の1 くらい まぜる。⚠️ 知らない 犬に さわる 練習は 書かない。
   ⭐ **kimochi(💭)** を しぐさ・声・やめての 語には かならず(「たぶん」「ことが 多い」入り)。**kagaku(🔬)** は PROMPT の 3。**breed** は 犬種の 語だけ。ei は 英語から 来た 語・犬種に
5. ⚠️ **事実は たしかな ものだけ**。下の「確かめた 事実」は 使って よい。自信が ない 数字・年・名前は 書かない(ぼかすか 意味だけに)
6. plan の 語が 決まりに 合わない(こわい・決めつけ・罰・あやしい 事実)と 思ったら、**同じ difficulty・同じ mapNode の 別の 語に かえて よい**。
   ⚠️ その ときは `python3 tools/inu/terms_js.py --check --with-later` で 読みの かぶり(11の 旅 ぜんぶ)が 0 か 確かめ、報告に「かえた 語」を 書く
7. 書いたら `python3 tools/inu/terms_js.py --check` を 走らせて、**あなたの 旅の 語**に ❌ が 出ない ことを 確かめる(ほかの 旅の ❌ は 気に しない。⚠️ ほかの 旅の ファイルは さわらない)。⚠️ の 長さの 注意も 直す。
   BAN(使えない 字)に 当たったら 言いかえる(「しかる」「反省」「ボス」は そばに うち消し(ない・ません・ではなく・古い 考え …)が あれば 通る)
8. git の コミットは しない。報告は みじかく: 書いた 語数・かえた 語と 理由・自信が なくて ぼかした 事実

## 確かめた 事実(2026-10-23 に ネットで 確かめた。使って よい)
- **カーミングシグナル**: ノルウェーの ドッグトレーナー **トゥーリッド・ルーガス**が 名づけた(本は 1997年。英語の 題「On Talking Terms with Dogs: Calming Signals」)。
  犬どうしが けんかを さけ、相手を 落ちつかせる ための 体の 合図。あくび・地面の においを かぐ・顔を そむける・プレイバウ など 30ほど あげている
- **しっぽの 左右の かたより**: 2007年 イタリアの 研究(クアランタ・シニスカルキ・ヴァロルティガラ)。飼い主を 見た ときは 右より、知らない 強そうな 犬を 見た ときは 左よりに ふる 犬が 多かった。
  2013年の 研究では、犬は ほかの 犬の しっぽの 左右を 見て 気持ちが 変わった。⚠️「〜と いう 研究が ある」の 形で(まだ 研究が 進んでいる)
- **目を 合わせると オキシトシン**: 2015年 麻布大学(菊水健史 教授ら)の 研究。犬と 飼い主が 見つめ合うと、**両方**の オキシトシン(なかよしの ホルモン)が 増えた(Science 誌)。⚠️ 存命の 人の 名前は 出さず「日本の 大学の 研究」で よい
- **アルファ(ボス)理論**: 「犬の 群れには ボスが いて、人が ボスに ならないと いけない」と いう 考えは **むかしの 考え(furui)**。もとに なった オオカミの 研究者(デイビッド・ミック)自身が 1999年の 論文で、野生の オオカミの 群れは **家族**だと 見なおした。⚠️「取りさげた」とは 書かず「見なおした」
- **社会化期**: 子犬が いろいろな 人・音・場所に 慣れやすい 時期。**生後 3〜12週ごろ**(1960年代の 研究から。本に よって 14〜16週 までと する ものも ある →「ごろ」で 書く)
- **日本の 決まり**: 「動物の 愛護及び 管理に 関する 法律」(動物愛護管理法)。**マイクロチップ**: 2022年6月1日から、販売される 犬・猫には 装着が 義務。一般の 飼い主は 努力義務(できるだけ つけよう)。⚠️ ペットショップ・ブリーダーの 話には しない
- **犬の 祖先**: オオカミ。いつ 分かれたかは **説が 分かれる**(1万5千年前 ごろ と いう 説から、もっと 古い 説まで)→「1万年以上 前と 言われる」の 形
- **人と 犬の いちばん 古い くらし**: ドイツの ボン・オーバーカッセルの お墓(約1万4千年前)から、人と いっしょに 犬が 見つかった。⚠️ 子犬が 病気だった 話は 書かず「人が 大切に 世話を していた と 考えられている」まで
- **FCI**(国際畜犬連盟)の **10グループ**: 1 牧羊犬・牧畜犬 / 2 使役犬(ピンシャー・シュナウザー・モロシアン・スイスの 山の 犬)/ 3 テリア / 4 ダックスフンド / 5 スピッツ・原始的な 犬 / 6 嗅覚ハウンド / 7 ポインター・セター / 8 レトリーバー・水の 犬(鳥を 追い出す 犬も)/ 9 愛玩犬 / 10 視覚ハウンド。
  日本の JKC(ジャパンケネルクラブ)も この 分けかたを 使う
- **トイプードル**: JKC の 犬種別の 登録で **長い あいだ 1位**(2008年ごろから)。⚠️ 順位の 数字・頭数は 書かず「日本で いちばん 多く 登録される 犬種」「人気の 上位」まで。
  プードルは **スタンダード・ミディアム・ミニチュア・トイ**の 4つの 大きさ(JKC)。もとは 水辺で 鳥を 回収する 猟犬。原産は フランス(ドイツ 説も ある)。FCI では 愛玩犬(9グループ)
- **日本犬 6種**(国の 天然記念物): 柴犬・秋田犬・甲斐犬・紀州犬・四国犬・北海道犬。⚠️ 指定の 年は 書かない
- **指さし**: 犬は 人の 指さしを 見て ものの 場所が わかる。チンパンジーより 上手 と いう 研究(2002年 ほか)。オオカミより 上手
- **反省の 顔(ギルティルック)**: 2009年の 研究。犬が しかられると「反省した ような 顔」を するが、本当に いたずらを したかどうか では なく、**人の 反応に 合わせて** 出る ことが 多い(→ kagaku: kenkyu)
- **だっこ・ぎゅっ**: 「ぎゅっと だきしめられるのが 苦手な 犬が 多い」は 写真を 見た 調べが 話題に なったが、**しっかりした 研究では まだ たしかめられていない**(→ kenkyuchu)。体を 横に 向ける・目を そらす なら やめる
- **手を かがせる**: 「知らない 犬には まず 手の においを かがせる」は よく 言われるが、手を 顔の 前に さし出すのが 苦手な 犬も いる と 見なおされている。飼い主に 聞いて、横向きで しゃがんで 犬から 来るのを 待つ(→ kagaku: iitsutae)
- **身体障害者補助犬法**(2002年 成立・同年10月 施行): 盲導犬・介助犬・聴導犬を まとめて「ほじょ犬」。公共の 施設・乗りもの・多くの 人が 使う 店などは ほじょ犬を ことわれない。⚠️ はたらいている ほじょ犬には 声を かけない・さわらない・食べ物を あげない
- **有名な 犬**(事実だけ・いのちの 終わりは 書かない): **ハチ公**(渋谷駅で 飼い主の 帰りを 待ちつづけた 秋田犬。駅前に 像)/ **タロと ジロ**(1959年、南極で 1年後に 生きて 見つかった 樺太犬の 兄弟)/
  **バルト**(1925年 アラスカ。そり犬の リレーで 遠い 町に 薬を 届けた チームの 最後の 犬。ニューヨークに 像)/ **ボビー**(スコットランドの エディンバラで 知られる テリア。像が ある)/ **ライカ**(1957年、宇宙へ 行った 犬。⚠️「むかしの ことで、いまは 犬を 宇宙に 送らない」と やさしく。帰れなかった 話は 書かない)
- **犬の 目**: 色は 青と 黄色の なかまが 見えやすく、赤と 緑の ちがいは わかりにくい(2色型)。暗い ところと 動く ものに 強い。⚠️ 「白黒の 世界」は まちがい(furui)
- **鼻**: においを 感じる 細胞が 人より ずっと 多く、においの 力は 人の 何千〜何万倍 と 言われる(→「ずっと すぐれている」の 形。倍の 数は「と 言われる」)
- **汗**: 体の 汗は ほとんど かかない。肉球に 汗の 出る ところが ある。体の 熱は ハッハッ(パンティング)で 出す
- **食べては いけない もの**: 玉ねぎ・ねぎの なかま・チョコレート・ぶどう・レーズン・キシリトール(ガム など)。⚠️ 量・症状は 書かない。「犬の 体に 合わない 成分が ある。食べたら すぐ 獣医さんへ」
- ⚠️ 存命の 研究者・トレーナー・有名人の 名前は 出さない(ルーガスだけ 例外)
