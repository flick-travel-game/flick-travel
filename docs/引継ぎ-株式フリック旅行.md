### リンクを 四季報ではなく 公式サイトにした理由
- 会社四季報オンラインは **日本の上場会社だけ**(Google・Apple には ページが無い)。くわしい中身は 有料会員むけで、子どもが押しても 読めない
- 公式サイトなら **日本も世界も 同じ形**で、無料で、いちばん正しい
- 「📖 Wikipedia で くわしく」のリンクは ほかのゲームと同じく 残してよい(リンクを貼るだけなら 写していない)

## ⚠️ やってはいけないこと
- **四季報・Wikipedia の文を 写さない**。四季報の文は 東洋経済新報社のもの(著作権)。説明は 公開されている情報をもとに **自分の言葉で 短く**(90字まで。`check_series_tsv.py` と同じ長さ)
- **会社のロゴを 使わない**(商標)。写真は 本社ビル・代表的な製品などで、ライセンスは ほかの写真と同じ(PD / CC0 / CC BY / CC BY-SA だけ。`fetch_series_photos.py` の道)。見つからなければ 絵文字のまま
- **「買いましょう」「もうかる」と 書かない**。子どもが見るゲーム。時価総額は「会社の大きさの めやす」として出すだけ
- 時価総額は **日付を かならず付ける**。世界の会社は 円に直すときの レート(例: 1ドル=◯円)も 日付といっしょに書く
- 公式サイトの URL は **1つずつ ひらいて 確かめてから** 入れる(想像で書かない。つながらない URL を子どもに押させない)

## 作る順番
1. TSV を作る: `tools/companies-japan.tsv` / `tools/companies-world.tsv`。列は 宇宙・からだの 11列に **緯度・経度・公式サイト・時価総額** を足した形を 新しく決めて、`tools/check_series_tsv.py` と同じような 確かめる台本も作る
   - よみは ひらがな と ー だけ(「トヨタ自動車」→ とよたじどうしゃ、「Apple」→ あっぷる)
2. `index.html`(土台)に 新しい kind(`company`)と 2つの MODES を足す。カードに 時価総額(日付つき)と「🏢 公式サイトを見る」
3. `tools/build_games.py` の `GAMES` に `kabu` を足す。はじめは 絵が無いので `logo:false` `hero:false`(文字の題名)
4. `SERIES`(いちばん下の「🧭 フリック旅行シリーズ」)に 株式フリック旅行を足す。**4つの ゲームぜんぶに出る**ので build_games.py を走らせなおす
5. 写真を取る(`fetch_series_photos.py` と同じ道)
6. **かずとも(speed-king)の 受けつける旅の一覧に 足す**: `FLICK_MODES` に 2つ。⚠️ 表の check `flick_mode_ok` も直す SQL が要る → **データベースなので けいくんに聞いてから**。SQL を流すまでは 記録が ランキングに のらないだけ(ゲームは こわれない)
7. `kazutomo.app/flick-link` の `?to=kabu` で もどってこられるか(おうちの方の アカウントと つなぐ)
8. Playwright で 390px の画面を撮って けいくんに見せる
