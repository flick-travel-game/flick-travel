# フリック日商簿記: ことばの 作りかた(助手に 分けて 頼むときの 決まり)

けいくん 2026-11-07「フリック日商簿記を **3級から1級まで 合格レベル**で」→ 6つの 問いに「ぜんぶ おすすめで」。
**990語(9つの 旅 × 110語 = 入門20・中級30・上級60)**。ほかに 🧾 仕訳クイズ(`SHIWAKE.md`)・📝 ⭕❌(`MARU.md`)・🧮 計算問題(`calc.js`)が ある。

## ⚠️⚠️⚠️ いちばん 大事な 決まり(さいしょに 読む)
1. ⭐⭐ **勘定科目は 日本商工会議所の 出題区分表・許容勘定科目の 名前**で 書く(売掛金・仮払法人税等・繰越商品・減価償却累計額・貸倒引当金繰入・繰越利益剰余金 …)。会社ごとの 呼びかたは 説明の 中で「◯◯とも いいます」
2. ⭐⭐ **2027年度版の 出題区分表(2027年4月1日から)が 答え**(けいくん決定 2026-11-07)。⚠️ **手形・小切手は 範囲外**(受取手形・支払手形・不渡手形・手形売却損 などを 語に しない)。定率法・除却・廃棄・販売のつど 売上原価に 振り替える 方法は **3級**。2級の リースは **使用権資産・リース負債・使用権資産減価償却累計額**、2級 以上の 不動産の 賃料は **支払リース料**(3級は 支払家賃)。`tools/boki/facts.md` の「⚠️ 古いテキストと ちがう ところ」を かならず 読む。古い 範囲の 科目・やりかたは **name に しない**。説明に「前は ◯◯」の 1文だけ
3. ⭐ **会計基準は 名前と 考えかた**まで。番号(「第◯号」)は 書かない(変わる)
4. **借方 = 左 / 貸方 = 右**。説明で 借方・貸方を 書くときは 逆に しない(仕訳クイズと 図が 正しく ならない)
5. **実在の 会社・会計ソフト・銀行・商品の 名前を 書かない**。会社名は 架空(さくら商店・あおば工業・ひかり製作所 など。⚠️「みらい商事」は 使わない)。実在の 会社の 財務の 数字・株価も 書かない
6. **節税の テクニック・粉飾・脱税の やりかたを 書かない**。粉飾決算 などは「してはいけない」まで(`terms_js.py` の `BAN`)
7. **本物の 試験問題・過去問・問題集・テキストの 文を 写さない**。自分の ことばで
8. **小学生も あそぶ**。入門(difficulty 1)は お店や お金の くらしの ことばで 書ける ものを。やさしい です・ます
9. 「**仕訳**」(仕分け では ない)・「**簿記**」(薄記 では ない)

## ゲームの かたち
「表示された ひらがなを フリックで 打ち写す」タイピング。打ち終わると 説明(1〜3文)が 出る。説明の 下に 📘 分野・📝 科目・🎓 級の 札。

## 1語の 形(JSON)
{"id":"s3-urikakekin","name":"売掛金","reading":"うりかけきん","journey":"3shiwake","category":"債権と 債務","difficulty":1,"type":"concept",
 "emoji":"🧾","mapNode":"3shiwake:kake","field":"債権債務","ruleset":"商業簿記","grade":"3級","relatedTerms":["s3-kaikakekin"],
 "description":"商品を 売って、代金を あとで もらう 約束に した ときの、もらう 権利です。資産なので ふえたら 借方に 書きます。"}
- id / name / reading / mapNode / field / ruleset / grade は **`plan.json` の とおり**(勝手に 変えない。どうしても 直す ときは 報告する)
- reading: **ひらがなと ー だけ**。ゆれは "acceptedReadings":["よみ1","よみ2"](先頭は reading)。⚠️ 読みは 9つの 旅の 中で かぶらない
- difficulty: 1 = 入門(用語として やさしい)/ 2 = 中級(その 級の 基本)/ 3 = 上級(その 級で 差が つく・ひっかけ・例外)
- type: いつも "concept"
- category: 図鑑で しぼる 分類(短い 日本語。旅の 中で 4〜8種類)
- emoji: 1つ。⚠️ お金の 札束(💸💰)を 多用しない・こわい 絵文字を 使わない
- relatedTerms: **同じ ファイルの 中の** id を 1〜3個
- formula(あれば): 公式の 見本 40字 以内(例 "売上原価 = 期首商品 + 当期仕入 − 期末商品")
- description: 1〜3文・**130字以内**。やさしい です・ます。語と 語の あいだに 半角スペース(上の 例のように)。
  **簿記の 目線**(どの 箱(資産・負債・純資産・収益・費用)か・ふえたら 借方か 貸方か・どの 場面の 仕訳で 出るか)。
  ⭐ 上級は **ひっかけ**(「未払金」と「買掛金」・「前払金」と「前払費用」・「定額法」と「定率法」・「直接法」と「間接法」・「価格差異」と「数量差異」の ちがい など)に 気づける 1文を 入れる
