# フリック農家: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
学ぶ 分野・しくみ図の どこに あるか(📍)が 出る。あそぶのは **小学生〜農家を めざす 高校生・大人**。
**農業の ことばと 意味を おぼえる ゲーム**(試験の 問題集でも、農作業の 教科書でも ない)。
もとは `tools/daiku/PROMPT.md`(大工)と `tools/chef/PROMPT.md`(料理人)。
けいくん 2026-10-03「農家の専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 7つ

### 1. ✅ 機械の 使いかたは 書く(大工・整備士とは ちがう 決まり)
けいくん決定 2026-10-03「機械の使いかたも書いてください。農家が大変な仕事だと思われているから、機械を使い効率的に仕事が出来ることを使える方が良い」
- ⭕ **機械で 何が できて、どの 作業が らくに・速く なるか** を いちばん 大事に 書く
  - 例: コンバイン = 稲を 刈りながら もみを 外して、タンクに ためていく 機械です。むかしは 何日も かかった 稲刈りと 脱穀が、1台で いっぺんに できます。
  - 例: 田植え機 = 苗を 何列も いっぺんに 植えて いく 機械です。人の 手で 1本ずつ 植えていた 田植えが、ずっと 早く 終わります。
  - 例: ドローン = 空から 田畑の ようすを 見たり、肥料を まいたり する 小さな 飛ぶ 機械です。
- 目線は「農業は 大変・きつい」では なく **「機械と 工夫で 効率よく できる、かっこいい 仕事」**。むかしの 手作業と くらべる 書きかたは よい
- ❌ **刃や 回る ところに さわる 話・子どもが 運転する 話は 書かない**。運転・操作する 機械には「講習を 受けた おとなが 使います」の ように そえる
  (トラクターなどで 公道を 走るには 大きさに 合った 運転免許が 要る。これは 書いて よい)
- 手の 道具(くわ・かま など)も **何の ための 道具か** を 書く。刃物には「おとなが 使う 道具です」と そえる

### 2. ⚠️⚠️ 農薬の 名前・量・まきかたを ぜったいに 書かない
- 農薬は「作物を 病気や 作物を 食べる 虫から 守る ために、決まりに そって 使う 薬」**まで**。農薬の 商品名・成分名・量・うすめかた・まきかたは 書かない
- **農薬・肥料・遺伝子組換えの よしあし(安全か 危険か・体に よいか 悪いか)を 書かない**。有機農業も 慣行農業も「育てかたの ちがい」として ならべる
- 肥料は 何の ための ものか・どんな 養分か(窒素・リン酸・カリウム)まで。**まく 量は 書かない**

### 3. 小学生も あそぶ(こわく しない)
- ❌ **「殺」「死」「血」の 字を 使わない**(台本が 止める)。殺虫 → 「虫を ふせぐ」、殺菌 → 「菌を おさえる」、枯死 → 「枯れる」、血統 → 「家系」
- 害虫は「作物を 食べる 虫」、駆除は「追いはらう・ふせぐ」の ように おだやかに(「害虫」という ことば そのものは 名前として よい)
- ❌ **と畜・家畜の 病気で 処分・事故(機械・熊・はち)・災害の こわい ようす** は 書かない。畜産は「牛乳や 卵・お肉に なる 動物を 大切に 育てる 仕事」と おだやかに
  - 「お肉に なる」までは よい。どう そう なるかは 書かない(「肉牛 = お肉に なる ために 育てる 牛です」は よい)
- けが・事故・「命に かかわる」も 使わない(台本が 止める)

### 4. ⚠️⚠️ 年ごとに 変わる 数字を 書かない
- **食料自給率・収穫量・値段・農家の 数・面積・%・円・kg・トン・ヘクタール** は 書かない(台本が 止める)
- ⭕ 変わらない ことは よい: 二十四節気の 名前・旬の 季節・八十八夜(立春から 数えて 88日目)・法律や 制度が できた 年(まちがいない ときだけ)
- ⭕ 単位の 名前と 意味は よい(反・町・石 など。「1反は 約10アール」は アールの 字を 台本が 止めるので、「むかしの 田んぼの 広さの 単位」の ように 書く)
- 条の 番号(第◯条)は 書かない

### 5. 実在の 会社・ブランドの 名前を 出さない
- **実在の 農機具メーカー・肥料や 種の 会社・食品会社・農協の 個別名(◯◯農協・全農 など)・お店の 名前を 書かない**(台本が 止める)
- **品種名は 商標で ない もの だけ**。⭕ よい 例: コシヒカリ・ひとめぼれ・あきたこまち・ササニシキ・ふじ(りんご)・つがる・温州みかん・デラウェア・シャインマスカット・
  男爵いも・メークイン・ホルスタイン・ジャージー・黒毛和種
  ❌ 入れない: あまおう・巨峰・とちおとめ・ゆめぴりか・つや姫 など **ブランド・商標の 名前**、松阪牛・神戸ビーフ・夕張メロン・魚沼産 など **地域ブランド**。あやしい ものは 入れない
- ⭕ 公の 組織・制度の 名前は よい: 農林水産省・JA(農業協同組合 という しくみ)・日本農業技術検定・有機JAS・GAP・農地法・食料・農業・農村基本法
- 歴史上の 人は **亡くなった 人だけ**(二宮尊徳・宮沢賢治 など)

### 6. 政治の よしあしを 書かない
- 減反・輸入・自由貿易・補助金の よしあしは 書かない。制度は **名前と 何の ための しくみか** だけ

### 7. 農家の 目線で 書く(ほかの ゲームと 同じ 語を 入れて よい)
- ✅ **料理人・理科・社会 など ほかの ゲームと 同じ ことばを 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。説明は **育てる 人の 目線**で 書きなおす
  (例: トマト = 料理人では 食材 / 農家では「夏に 実る 野菜で、支柱を 立てて 育てます」)
- **読み(ひらがな)は 農家の 8つの 旅の 中で かぶらない**(台本が 止める)。下の「旅ごとに 入れる 語」を 守る。**ほかの 旅の 欄に ある 語は 入れない**
- 文体は **はじめから「〜です・ます」**(体言止めで はじめない)
- 事実が あやしい 語は 入れない。**自分の ことばで 書く**(教科書・Wikipedia・公式の 文を 写さない)

## 1語の 形(JSON)

```json
{"id":"dg-combine","name":"コンバイン","reading":"こんばいん","journey":"dogu","category":"収穫の 機械","difficulty":1,
 "field":"作物","type":"concept","emoji":"🌾","mapNode":"dogu:combine","relatedTerms":["dg-kansoki"],
 "description":"稲や 麦を 刈りながら、もみを 外して タンクに ためていく 機械です。むかしは 何日も かかった 稲刈りが、1台で いっぺんに できます。講習を 受けた おとなが 運転します。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(農業で ふつうに 使う 書きかた。漢字・カタカナ)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)
  - カタカナ語は ひらがなで(トラクター → とらくたー)。英字の 略語は 読みで(JA → じぇいえー、GAP → ぎゃっぷ、GPS → じーぴーえす)
  - ⚠️ **農業の ことばは 読みが ゆれる**(苗代 なわしろ/なえしろ・畝 うね・堆肥 たいひ・摘果 てきか・花き かき・圃場 ほじょう など)。
    ゆれる 語は **いちばん ふつうの 読みを reading** に、ほかを `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は 上級だけ・旅で 1〜2語まで
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級
- **field**: 学ぶ 分野。次の 8つの どれか(日本農業技術検定の 科目に そろえた):
  `農業一般` `作物` `野菜` `果樹` `花き` `畜産` `食品` `環境`
  - めやす: 農業の きほん・植物の しくみ・土と 肥料・暦と 天気・機械・経営・制度・歴史 → `農業一般` / 稲・麦・大豆・いも などの 作物 → `作物` /
    野菜 → `野菜` / 果樹 → `果樹` / 花・観葉植物 → `花き` / 家畜・酪農・飼料 → `畜産` / 食品の 加工・流通・食の 安全・六次産業化 → `食品` /
    生きもの・生態系・環境を 守る 農業・里山・水 → `環境`
  - 機械の 語は その 機械が 使われる 作物の 分野か `農業一般`(コンバイン → 作物、ビニールハウス → 野菜、トラクター → 農業一般)
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(💀 🔫 🩸 💣 ⚔️ 🔪 は 使わない。🌱🌾🥕🍅🍎🐄🐔🚜🪱🐝💧☀️ など)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / 何の ために あるか / 農家は どう 見るか・どう 役立つか」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  専門用語を 専門用語だけで 説明しない。「1人」「2人」は ふりがなが 読みまちがえるので **ひとり・ふたり** と ひらがなで 書く
- **example**: なくてもよい
