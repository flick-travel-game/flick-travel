# フリック自動車運転免許: ことばの 作りかた(助手に 分けて 頼むときの 決まり)

けいくん 2026-11-05「フリック自動車運転免許を **免許が受かるレベル**で 作成したい」→「すべてお願いします」。
**990語(9つの 旅 × 110語 = 入門20・中級30・上級60)**。ほかに ⭕❌ もんだい(`MARU.md`)・危険予測(`KIKEN.md`)が ある。

## ⚠️⚠️⚠️ いちばん 大事な 決まり(さいしょに 読む)
1. ⭐⭐ **数字は 法律で 決まった ものを 書く**(この ゲームの いちばん 大事な ところ)。合図の 30m・駐停車禁止の 5m / 10m・法定速度・初心運転者期間 1年 など。
   **`tools/menkyo/facts.md`(確かめた 事実の 一覧)に ある 数字だけ**を 使う。facts.md に 無い 数字は、WebSearch で 警察庁・都道府県警察・e-Gov(道路交通法・施行令)・「交通の教則」の ページで 確かめてから。**記憶で 書かない**。確かめられない ものは 入れない
   ❌ 書かない 数字: 反則金・罰金の 金額・事故の 件数・合格率・お酒の 量の めやす
2. ⭐⭐ **2026年に 変わった ところを いまの 答えに する**: 生活道路(中央線・車両通行帯などの ない 一般道路)の 法定速度は **30km/h(2026年9月1日から)** / 自動車が 自転車の 右側を 通るとき 十分な 間隔が なければ 間隔に 応じた 安全な 速さ(2026年4月1日から)/ 自転車の 青切符(16歳以上・2026年4月1日から)など(くわしくは facts.md)。
   古い 答えは **name に しない**。説明に「前は ◯◯でした」の 1文だけ
3. **事故・飲酒を こわく しない**。「どう 起きるか」と「どう 防ぐか」だけ。亡くなる 話・けがの ようす・血は 書かない(`terms_js.py` の `BAN`)。応急救護は しくみ(呼びかけ・119番・AED・続けて 走らない)まで
4. **飲酒は「少しでも 飲んだら 運転しない」**。「◯杯なら 平気」のような めやすは ぜったいに 書かない。車を 貸した 人・お酒を 出した 人・のせて もらった 人も 罰せられる、は よい
5. **つかまらない 方法・抜け道は 書かない**。実在の 車の 名前・メーカー・教習所・保険会社・カー用品の 名前も 書かない
6. **都道府県ごとの 決まり(公安委員会規則)は 入れない**(地域で ちがう)
7. **教則の ことばづかいに そろえる**(徐行・一時停止・進路変更・停止表示器材・初心運転者標識 …)。くだけた 名前(若葉マーク・三角板)は `acceptedReadings` ではなく 説明の 中で「若葉マークとも いいます」と 書く(名前が ちがう 語は 別の 読み なので)
8. **本物の 試験問題・問題集・教本・Wikipedia の 文を 写さない**。自分の ことばで
9. **小学生も あそぶ**。入門は「歩く 人・自転車に のる 人」として 知っておく こと。やさしい です・ます。迷ったら 入れない

## ゲームの かたち
「表示された ひらがなを フリックで 打ち写す」タイピング。打ち終わると 説明(1〜3文)が 出る。説明の 下に 📘 分野 と 📝 試験の 札(仮免 / 本免 / 共通)。
あそぶのは 小学生〜運転免許を とる 人

## 1語の 形(JSON)
{"id":"sg-kiiro","name":"黄色の灯火","reading":"きいろのとうか","journey":"shingo","category":"信号の色","difficulty":2,"type":"concept",
 "emoji":"🟡","mapNode":"shingo:kiiro","field":"信号","ruleset":"仮免","relatedTerms":["sg-aka","sg-teishisen"],
 "description":"停止位置から 先へ 進んでは いけない 合図です。ただし 黄色に 変わった とき 停止位置に 近づいていて 安全に 止まれない ときは、そのまま 進めます。"}
- id: 旅の 頭文字2つ + "-" + 英小文字(sg- / hs- / hj- / hk- / sd- / ks- / kk- / kn- / sm-)
  (shingo=sg / hyoshiki=hs / hyoji=hj / hoko=hk / sokudo=sd / kosaten=ks / kosoku=kk / kiken=kn / seido=sm)
- name: 画面に 出す 名前(教則の ことば)。数字入りも よい(「交差点の 側端から 5m 以内」は 長いので 「交差点から5m」など 短く)
- reading: **ひらがなと ー だけ**。数字は ひらがな(30m → さんじゅうめーとる)。ゆれは "acceptedReadings":["よみ1","よみ2"](先頭は reading)
  ⚠️ 読みまちがい注意: 徐行=じょこう / 軌道敷=きどうしき / 路側帯=ろそくたい / 路肩=ろかた / 導流帯=どうりゅうたい / 停止表示器材=ていしひょうじきざい / 空走距離=くうそうきょり / 制動距離=せいどうきょり / 幅寄せ=はばよせ / 転回=てんかい / 右折=うせつ / 左折=させつ / 灯火=とうか / 警音器=けいおんき / 積載=せきさい / 牽引=けんいん / 初心運転者=しょしんうんてんしゃ / 反則金=はんそくきん / 酒気帯び=しゅきおび / 酒酔い=さけよい / 妨害運転=ぼうがいうんてん / 環状交差点=かんじょうこうさてん / 二段階右折=にだんかいうせつ / 自賠責=じばいせき / 内輪差=ないりんさ / 側端=そくたん
  ⚠️ **読みは この ゲームの 9つの 旅の 中で かぶらない**(plan.json の とおり)
- difficulty: 1 = 入門(小学生。歩く 人・自転車の 人) / 2 = 中級(仮免許の 学科試験の 範囲) / 3 = 上級(本免許の 学科試験の 範囲)
- type: いつも "concept"
- category: 図鑑で しぼる 分類(短い 日本語。旅の 中で 4〜8種類)
- emoji: 1つ。⚠️ 事故・けがの 絵文字は 使わない(💥🩸🚨 は 使わない。🚑 は 緊急自動車の 語だけ)
- mapNode: その 旅の 図の 場所(下の 表から)
- field: 「交通の教則」の 章: 運転者の心得 / 信号 / 標識・標示 / 通行する場所 / 歩行者の保護 / 速度 / 追い越し / 交差点 / 駐車・停車 / 踏切 / 危険な場所 / 高速道路 / 夜間・悪天候 / 事故・故障 / 免許制度 / 車の管理 の どれか
- ruleset: 試験の どこで 出るか: 仮免 / 本免 / 共通(入門の くらしの ことば)。**中級は ふつう 仮免、上級は ふつう 本免**(高速道路・危険予測・応急救護・二輪・けん引は 本免)
- relatedTerms: **同じ ファイルの 中の** id を 1〜3個
- description: 1〜3文・**130字以内**。やさしい です・ます。語と 語の あいだに 半角スペース(上の 例のように)。
  **運転する 人の 目線**(「どう するか」「なぜ そう するか」)で 書く。⭐ 上級は **ひっかけ**(「徐行」と「一時停止」・「追い越し」と「追い抜き」・「駐車」と「停車」・「以内」と「以上」・「歩道」と「路側帯」)に 気づける 1文を 入れる
- example: なくてもよい
