# フリックワールドバレーボール(`volley/`)を 作る ための まとめ(2026-10-24。新しい セッション用)

けいくん 2026-10-24「新しいセッションで フリックワールドバレーボールを作成したい。**ワールドバレーボールの専門家(解説者)になれるレベル**になるために必要な 知識、**主要なバレーボールリーグ、有名バレーボール選手、有名な技、ルール**をフリック形式の問題にしてください」

⭐ **フリックワールドサッカー(`soccer/`)・バスケットボール(`basket/`)・ベースボール(`baseball/`)・ボクシング(`boxing/`)と 兄弟の ゲーム**(5つめ)。まとめの 型・決まりは `docs/フリックワールドバスケットボール-はじめかた.md` と **ほぼ 同じ**。ちがう ところ(**6人制 / ビーチの 2人制 / 9人制 / シッティング**・**ローテーションと リベロ**・**日本が 強い**・**SV.LEAGUE が できたばかり**)だけ 気を つける。

## 0. まず 読む もの(この 順で)
1. `CLAUDE.md`(この 入れものの 決めごと ぜんぶ。とくに **フリックワールドバスケットボール・ベースボール・ボクシング**の 節(兄弟の 作りかた・入れなかった 語)と、
   **「🧭 ゲームを えらぶ は 章ごと」「🙈 答えの ひらがな あり / 無し」「題名の 絵は ChatGPT に 切りぬいてもらう」「アイコンは 四角い 絵を 切らずに そのまま」** の 節)
2. ⭐ `docs/フリックワールドバスケットボール-はじめかた.md`(**この ゲームの 手本**。決まり・旅の 作りかた・毎年の 見直し)と `docs/フリックワールドボクシング-はじめかた.md`(いちばん 新しい 兄弟。予約の 作りかた)
3. ⭐ `basket/basket.js` と `tools/basket/`(PROMPT.md・meta.json・mkmeta.py・terms_js.py・exam.txt・fix_text.py)… **これを 写して `volley/volley.js`・`tools/volley/` に する**。国旗の 札(`country`)と ルールの 札(`ruleset`)の しくみが もう ある
4. `tools/rekishi/` と `tools/people-world.tsv` / `tools/people-japan.tsv`(**実在の 人物の 書きかた**の 前例)
5. 世界旅行の 国の データ(国名・首都)… 代表チーム・開催国と つなぐと へえに なる
6. `tools/build_games.py` の `"boxing": dict(...)` の 段(ゲームの 登録の 形。いちばん 新しい 兄弟)
7. `tools/title_from_art.py`(題名)と `tools/icon_from_square.py`(アイコン)。**どちらも けいくんの ChatGPT の 絵を そのまま 使う**(自分で 切らない)
8. `tools/fetch_game_photos.py`(ことばの 写真。`GAMES` に `volley` を 足す。写真が ことばと 合わない ものは `NO_GAME_PHOTO` に)

- 兄弟の まとめと 同じ 決まり。**選手と 国と ポジションを まちがえない**(けいくんは スポーツの 人。まちがえると すぐ 気づく)

- **サッカーの「リベロ」と バレーの「リベロ」は 別物**(ゲームを またいで 同じ 語でも、説明は バレーの 目線で)

- 長い 名前なので 題名の 絵の 字の 抜けに 気を つける
- 2026-10-24 の 時点で 58ゲーム + まとめ(犬の気持ち・メンタリスト・スーパーカーまで)。**フォルダ・id・modes 名を まぜない**(`volley` / `VOLLEY` / `vb…`)。⚠️ `ba` は ベースボール・`bx` は ボクシング・`wb` は バスケが 使っている
