## 🔀 英会話との 書き分け

⚠️ **ことばが かぶるのは よい(復習に なる)**(けいくん決定 2026-09-29。`CLAUDE.md` の 同じ 名前の 節)。
同じ 単語が 出ても かまわない。**説明の 目線を 変える**。

| | 英会話(`eikaiwa/`) | フリック英語(`eigo/`) |
|---|---|---|
| ねらい | 話す・通じる | **入試で 点を 取る** |
| 打つもの | 単語 1語 / 会話の 1文 | **文法の 代表例文** |
| 説明 | 意味と 返事の 例 | **日本語訳 + 文法の ポイント** |
| have | 「持っている」 | 「I have lived here for ten years.(現在完了・継続)」 |
| to | 「〜へ」 | 「It is easy for me to swim.(for + 人 + to 不定詞)」 |
| as | 「〜として」 | 「He is as tall as my brother.(as 〜 as)」 |

- **単語だけの 旅は 作らない**。英会話に もう 1000語 あるので、同じ ものを もう一度 作る 必要は ない
- ⚠️ ただし **熟語・句動詞の 旅は 作る**(look forward to / put up with など)。
  1語ずつ 知っていても 意味が 分からない ものなので、英会話の 単語とは 別のもの

## 打つもの ─ 英会話の しくみを そのまま

- 打つのは **英字だけ**。大文字・小文字は 区別しない。空白・`' , . ? ! -` は 打たなくても すすむ
  (`eikaiwa/eikaiwa.js` の `norm`。`NFKC` → 小文字 → `[^a-z0-9]` を 消す)
- 打ち終わると 次の 問題の 上に **日本語訳 + 文法の ポイント**が 出る
- **🔊 発音**(ブラウザの 読み上げ)も 英会話と 同じ しかけで 付けられる。サーバーも お金も 要らない
- ⚠️ **入れないもの**: 発音記号・アクセントの 位置・リスニング・長文読解。
  **フリックで 打てない**ので この ゲームには 向かない。かわりに「よく 出る 言いかた」を 例文で 覚える

### 問題の 例(1問 = 英文 1つ。打つのは 英字)

**🔁 不規則動詞**(3つを つづけて 打つ。`go went gone` → `gowentgone` = 10字)
| 出す 字 | 打つ 字 | 説明(めやす) |
|---|---|---|
| go - went - gone | gowentgone | 行く。have gone to 〜 は「行って しまって いない」 |
| write - wrote - written | writewrotewritten | 書く。受動態で よく 出る(was written by 〜) |
| buy - bought - bought | buyboughtbought | 買う。bring / think / teach / catch も おなじ ought の なかま |
| lie - lay - lain | lielaylain | 横に なる。**lay - laid - laid(横たえる)と ちがう**。入試で よく ねらわれる |
| rise - rose - risen | riseroserisen | 上がる。**raise - raised - raised(上げる)と ちがう** |
| find - found - found | findfoundfound | 見つける。**found - founded - founded(設立する)と ちがう** |
| read - read - read | readreadread | 読む。字は 同じでも 過去形の 読みかたは 変わる |

**⏳ 時制**
| 出す 字 | 説明(めやす) |
|---|---|
| I have lived here for ten years. | 現在完了(継続)。「ずっと 住んでいる」。for + 期間 / since + 起点 |
| Have you ever been to Kyoto? | 現在完了(経験)。ever は「これまでに」 |
| I have just finished my homework. | 現在完了(完了)。just / already / yet と いっしょに 使う |
| She has gone to London. | 「行って しまった」= いま ここに いない。has been to は「行った ことが ある」 |
| It has been raining since morning. | 現在完了進行形。ずっと 続いている 動きを あらわす |
| I had finished dinner when he came. | 過去完了。過去の ある ときより 前に 終わっていた こと |
| He said he would come soon. | 時制の 一致。said に あわせて will が would に なる |
| If it rains, I will stay home. | 時や 条件の 文の 中では **未来の ことでも 現在形** |

**🔄 受動態**
| 出す 字 | 説明(めやす) |
|---|---|
| This book was written by Soseki. | be + 過去分詞 + by 〜。「〜に よって 書かれた」 |
| English is spoken all over the world. | だれが するかを 言わない ときは by 〜 を 付けない |
| The room must be cleaned every day. | 助動詞の あとは be + 過去分詞 |
| He was given a watch by his father. | 目的語が 2つの 文の 受動態。もう 1つの 目的語が うしろに 残る |
| I was surprised at the news. | by ではない 受動態。be interested in / be filled with も おなじ |
| I was spoken to by a stranger. | 句動詞の 受動態。to を 落とさない |
| What is this flower called in English? | 疑問文の 受動態。call A B の B が 残る |

**🎯 不定詞・動名詞**
| 出す 字 | 説明(めやす) |
|---|---|
| I want to be a doctor. | 名詞の はたらき。「〜する ことを のぞむ」 |
| It is easy for me to swim. | **for + 人**。人の ようすを 言う 形容詞(easy / hard)は for |
| It is kind of you to help me. | **of + 人**。人の 性格を 言う 形容詞(kind / careless)は of |
| I have something to tell you. | 形容詞の はたらき。名詞を うしろから くわしく する |
| She is too young to drive. | too 〜 to …。= so young that she cannot drive |
| He is rich enough to buy a car. | enough は **形容詞の うしろ**に 置く |
| I enjoy reading books. | enjoy / finish / stop は 動名詞だけ。to 不定詞は 取らない |
| I forgot to lock the door. | to 不定詞は「これから する ことを 忘れた」。locking なら「したことを 忘れた」 |
| I am looking forward to seeing you. | to の あとが **動名詞**。to 不定詞では ない |
| I made him carry the bag. | 原形不定詞。make / let / have + 人 + 原形 |

**🧩 分詞・分詞構文**
| 出す 字 | 説明(めやす) |
|---|---|
| Look at the sleeping baby. | 現在分詞 1語は 名詞の 前 |
| The boy running over there is my brother. | 2語以上に なると 名詞の うしろ |
| The language spoken in Brazil is Portuguese. | 過去分詞。「話されている 言語」 |
| Walking along the street, I met Ken. | 分詞構文。= While I was walking 〜 |
| Written in easy English, the book sells well. | 受け身の 分詞構文。Being が 省かれている |
| I had my hair cut yesterday. | have + もの + 過去分詞。「〜して もらう」 |
| It was an exciting game. | もの が ing、人 が ed。I was excited. と くらべる |

**🔗 関係詞**
| 出す 字 | 説明(めやす) |
|---|---|
| I know a boy who can play the piano. | 人 + who。who は 主語の はたらき |
| This is the book which I bought yesterday. | もの + which。目的語の はたらきなので 省ける |
| The girl whose hair is long is Yumi. | whose + 名詞。「その 人の 〜が」 |
| This is the house where he lives. | 場所 + where。= in which |
| I remember the day when we first met. | 時 + when。= on which |
| He gave me all that he had. | all / every / the only の あとは that を 使う |
| This is what I want. | what は「〜する もの・こと」。前に 名詞を 置かない |
| Tokyo, which is the capital of Japan, is large. | コンマ + which(非制限用法)。付けたし の 説明。that は 使えない |

**⚖️ 比較**
| 出す 字 | 説明(めやす) |
|---|---|
| He is as tall as my brother. | as + 原級 + as。「同じくらい」 |
| She is not as old as she looks. | not as 〜 as。「見えるほど 〜ではない」 |
| This book is more interesting than that one. | 長い 語は more を 付ける |
| Mt. Fuji is the highest mountain in Japan. | 最上級 + in + 場所 / of + 仲間 |
| He runs faster than any other boy. | 比較級で 最上級を あらわす 言いかえ |
| No other mountain is higher than Mt. Fuji. | これも 最上級の 言いかえ |
| The more you read, the more you learn. | the + 比較級, the + 比較級。「〜するほど ますます」 |
| It is getting warmer and warmer. | 比較級 and 比較級。「だんだん 〜」 |
| She is one of the best singers in Japan. | one of the + 最上級 + **複数**の 名詞 |

**🌙 仮定法**
| 出す 字 | 説明(めやす) |
|---|---|
| If I were a bird, I could fly to you. | 仮定法過去。いまの ことの 反対を 言う。be動詞は were |
| If I had money, I would buy a car. | 主語が I でも 動詞は 過去形。would / could / might を 使う |
| If I had known it, I would have told you. | 仮定法過去完了。過去の ことの 反対 |
| I wish I could speak English well. | I wish + 過去形。「〜だったら いいのに」 |
| I wish I had studied harder. | I wish + 過去完了。「〜して いれば よかった」 |
| He talks as if he knew everything. | as if + 過去形。「まるで 〜のように」 |
| Without water, we could not live. | without = If it were not for。「〜が なければ」 |
| It is time you went to bed. | It is time + 過去形。「もう 〜する 時間だ」 |

**💡 熟語・句動詞**
| 出す 字 | 説明(めやす) |
|---|---|
| look forward to | 〜を 楽しみに する。to の あとは 動名詞 |
| put off | 延ばす。= postpone |
| put up with | 我慢する。= endure。前置詞が 2つ つづく |
| get along with | 〜と 仲よく やる |
| come up with | (考えを)思いつく |
| run out of | 〜を 使いきる・切らす |
| make up one's mind | 決心する。= decide |
| be used to | 〜に 慣れている。**used to + 原形(昔は 〜した)と ちがう** |
| had better | 〜した ほうが よい。あとは 原形。否定は had better not |
| would rather | むしろ 〜したい。あとは 原形 |

| while | 〜する あいだ(接続詞)。**during は 前置詞**で あとは 名詞 |

⚠️ 上の 説明は **例**。本番の 文は 下の 決まりで 書きなおし、英文が **正しいか 別の 助手に 確かめさせる**

## 英語だけの しくみ(国語と ちがう ところ)

- **打つ字と 出す字が ちがう**: `name` に 英文を そのまま 入れ、`reading` は **小文字の 英字だけに した 形**。
  ⚠️ `reading` は **手で 書かない**。`terms_js.py` が `name` から `norm` と 同じ やりかたで 作る(打ち写しと ずれないように)
- **日本語訳の 欄を 足す**: `ja`(日本語訳)と `description`(文法の ポイント)を 分けて 持つ。
  英会話の `m`(意味)と 同じ 役目。画面では 訳 → ポイント の 順に 出す
- **文法の 名前で しぼれるように**: `category` に 文法の 名前(現在完了・関係代名詞・仮定法過去 など)。
  図鑑で「この 文法だけ 見る」が できる
- **不規則動詞の 旅だけ 打つ 字が 長く なる**(writewrotewritten = 17字)。
  上限 35字の 中なので だいじょうぶだが、**4つ 以上の 語を つなげない**
- 🔊 **発音**は 英会話の しかけを 写す。⚠️ 長い 例文でも 読み上げは そのまま 使える

## ⚠️ 受験・権利の 注意

- 画面の 言いかたは **「高校受験・大学受験の 範囲の めやす」**。「合格できる」「共通テスト 公式」とは 書かない。
  ページの 下に「大学入試センター・各都道府県の 教育委員会とは 関係ありません」
- ⚠️ **英検・TOEIC の めやすは 出さない**(けいくん 2026-09-26「勉強してる感が強くなるので表記しない方がいい」。英会話と 同じ)
- **入試の 過去問・問題集・参考書・教科書の 英文を 写さない**。例文は **自分で 作る**。
  ⚠️ 英語は「よく 出る 例文」が 参考書で 決まり文句に なっている ものが ある。
  意味が 同じでも **語を 変えて 自分の 文に する**(名前・場所・数を 変える)
- **小説・歌の 歌詞を 引かない**(権利)
- 例文に 出す 名前は **架空**(Ken / Yumi / Tom のような ありふれた もの)。実在の 人を 出さない
- ⚠️ 「100マス計算」「百ます計算」の 字は 使わない(シリーズの 決まり)

## しくみ(英会話 + 国語を 写す)

- ことば: `tools/eigo/terms-<旅>.json`(旅ごと)+ `tools/eigo/meta.json`
  → `tools/eigo/terms_js.py` が `data/eigo.json` と `eigo/terms.js` を 作る(`tools/kokugo/terms_js.py` を 写す)
- 遊びかた: `eigo/eigo.js`。**判定と 🔊 は `eikaiwa/eikaiwa.js` から**、旅・図鑑・称号は `kokugo/kokugo.js` から 写す
- 決まりの 文書: `tools/eigo/PROMPT.md`(`tools/kokugo/PROMPT.md` を 写して 書きかえる)。1問の 形:
  `{"id":"ji-havelived","name":"I have lived here for ten years.","ja":"わたしは 10年 ここに 住んでいます。","journey":"jisei","category":"現在完了(継続)","difficulty":2,"type":"pattern","emoji":"⏳","relatedTerms":["ji-haveever"],"description":"..."}`
  - `reading` は 台本が 作る(手で 書かない)
