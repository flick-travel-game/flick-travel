## D-1. 労務管理と 労働の 一般常識(労一)

### 労働契約法
| 事実 | 出どころ |
|---|---|
| 目的: 労働契約が **合意により 成立し、又は 変更される という 合意の 原則** その他 基本的 事項を 定める | 労契1 |
| 労働契約の 原則: **対等の 立場に おける 合意**・就業の 実態に 応じた **均衡**・**仕事と 生活の 調和**への 配慮・**信義誠実**・権利の **濫用 禁止** | 労契3①〜⑤ |
| 使用者は 労働条件・契約内容の **理解を 深める** ように する。労使は 契約内容を できる限り **書面で 確認** する | 労契4①② |
| **安全配慮**: 使用者は 労働者が 生命・身体等の 安全を 確保しつつ 労働できるよう **必要な 配慮を する** ものとする | 労契5 |
| 労働契約は 労働者が 使用されて 労働し、使用者が 賃金を 支払う ことに ついて **合意する ことで 成立** | 労契6 |
| **合理的な 労働条件の 就業規則を 周知** させていた とき、労働契約の 内容は 就業規則の 労働条件による。ただし 就業規則と **ちがう 労働条件を 合意した 部分**は その 合意(12条に 当たる 場合を 除く) | 労契7 |
| 合意により 労働条件を 変更できる(8条)。合意なく 就業規則の 変更で **不利益に 変更することは できない**(9条)。ただし 10条の 場合は 別 | 労契8・9 |
| 就業規則の 変更で 労働条件を 変える とき: **変更後の 就業規則を 周知** + 変更が **不利益の 程度・変更の 必要性・内容の 相当性・労働組合等との 交渉の 状況** その他に 照らして **合理的** なら、変更後の 就業規則による | 労契10 |
| 就業規則の 変更の 手続は **労基法 89条・90条** による | 労契11 |
| **就業規則で 定める 基準に 達しない 労働条件の 労働契約は その部分 無効**。無効の 部分は 就業規則の 基準による(最低基準効) | 労契12 |
| 就業規則が **法令 又は 労働協約に 反する** 部分は、7条・10条・12条を 適用しない | 労契13 |
| **出向**: 出向を 命じられる 場合でも、必要性・対象労働者の 選定 その他の 事情に 照らして **権利の 濫用** なら 無効 | 労契14 |
| **懲戒**: 行為の 性質・態様 その他の 事情に 照らして **客観的に 合理的な 理由を 欠き、社会通念上 相当で ない** ときは 権利の 濫用 として 無効 | 労契15 |
| **解雇**: **客観的に 合理的な 理由を 欠き、社会通念上 相当で あると 認められない** 場合は 権利の 濫用 として **無効** | 労契16 |
| 有期労働契約: **やむを得ない 事由が なければ 契約期間の 途中で 解雇できない**(17①)。必要 以上に **短い 期間で 反復更新** しない よう 配慮(17②) | 労契17 |
| **無期転換**: 同じ 使用者との 2以上の 有期労働契約の **通算契約期間が 5年を 超える** 労働者が、いまの 契約の 満了日までに 無期契約の 締結を **申し込むと、使用者は 承諾した ものと みなす**。労働条件は 別段の 定めが なければ いまと 同じ(契約期間を 除く) | 労契18① |
| **クーリング**: 契約と 契約の あいだの **空白期間が 6か月以上**(直前の 契約期間が **1年 未満**なら その **2分の1** を もとに 省令で 定める 期間 以上)なら、それより 前の 期間は 通算しない | 労契18②、通算契約期間に関する基準を定める省令 1・2 |
| **雇止め法理**: ① 反復更新されて 雇止めが 無期契約の 解雇と **社会通念上 同視できる** もの ② 更新されると **期待する ことに 合理的な 理由** が ある もの — の どちらかで、労働者が 更新を 申し込んだ ときに 拒むのが **客観的に 合理的な 理由を 欠き、社会通念上 相当で ない** なら、**従前と 同一の 労働条件で 承諾した ものと みなす** | 労契19 |
| 国家公務員・地方公務員、**同居の 親族のみを 使用する 場合**には 適用しない | 労契21 |

### 労働組合法
| 事実 | 出どころ |
|---|---|
| 「労働組合」= 労働者が **主体と なって 自主的に** 労働条件の 維持改善 その他 経済的地位の 向上を **主たる 目的** として 組織する 団体 又は その 連合団体 | 労組2 本文 |
| 労働組合に 当たらない もの: ① 役員・人事に 直接の 権限を 持つ 監督的地位の 者 など **使用者の 利益を 代表する 者の 参加を 許す** もの ② 運営経費に **使用者の 経理上の 援助** を 受ける もの(労働時間中の 協議・交渉で 賃金を 失わない こと・福利の 基金への 寄附・**最小限の 広さの 事務所の 供与** は 除く)③ **共済事業 その他 福利事業のみ** を 目的 ④ **主として 政治運動 又は 社会運動** を 目的 | 労組2但し書 1〜4号 |
| **不当労働行為**(使用者が しては ならない): ① 組合員である こと・加入・結成・正当な 行為を 理由とする **不利益取扱い**、組合に 入らない / 脱退を 雇用条件に する こと(**黄犬契約**。過半数を 代表する 組合との ユニオン・ショップ 協定は 別) ② **正当な 理由の ない 団体交渉の 拒否** ③ 組合の 結成・運営への **支配介入**・**経費援助** ④ 労働委員会への 申立て・証拠の 提示・発言を 理由とする **不利益取扱い** | 労組7 1〜4号 |
| **労働協約は 書面に 作成し、両当事者が 署名 又は 記名押印** して 効力を 生ずる | 労組14 |
| 労働協約の 有効期間は **3年を こえて 定められない**(こえたら 3年と みなす)。期間の 定めが ない 協約は 署名 又は 記名押印 した 文書で **少なくとも 90日前に 予告** して 解約できる | 労組15①〜④ |
| 協約の 労働条件 その他の 待遇の 基準に 違反する 労働契約の 部分は 無効(規範的効力) | 労組16 |
| **一般的拘束力**: 1つの 工場事業場で 常時使用される 同種の 労働者の **4分の3 以上** が 1つの 協約の 適用を 受けると、他の 同種の 労働者にも 適用 | 労組17 |
| **地域的の 一般的拘束力**: 1つの 地域の 同種の 労働者の **大部分** が 適用を 受けると、当事者の 申立て → **労働委員会の 決議** → **厚生労働大臣 又は 都道府県知事** が 決定(公告) | 労組18 |
| **労働委員会**は **使用者委員・労働者委員・公益委員 各同数**(三者構成)。**中央労働委員会**(厚生労働大臣の 所轄。各 **15人**)と **都道府県労働委員会** | 労組19・19の2・19の3 |
| 不当労働行為の 申立ては **行為の 日(継続する 行為は 終了した 日)から 1年** を 過ぎると 受けられない | 労組27② |
| 使用者は 都道府県労働委員会の 救済命令等を 受けた とき **15日以内** に 中央労働委員会に **再審査** を 申し立てられる(命令の 効力は 止まらない) | 労組27の15① |

### 労働関係調整法
| 事実 | 出どころ |
|---|---|
| 「労働争議」= 労働関係の 当事者間で 主張が 一致せず、**争議行為が 発生している 状態 又は 発生する おそれが ある 状態** | 労調6 |
| 「争議行為」= **同盟罷業(ストライキ)・怠業・作業所閉鎖** その他、主張を 通す 目的の 行為と 対抗する 行為で、業務の 正常な 運営を 阻害する もの | 労調7 |
| **斡旋(あっせん)**: 労働委員会の 会長が 当事者の 双方 若しくは 一方の 申請 又は **職権** で 斡旋員を 指名 | 労調12① |
| **調停**: 双方の 申請・労働協約に もとづく 申請・**公益事業は 一方の 申請 や 職権** ・大臣 / 知事の 請求 で 行う。調停委員会が **調停案を 作り 受諾を 勧告**(公表できる) | 労調18・26① |
| **仲裁**: **双方の 申請**、又は 労働協約の 定めに もとづく 申請で 行う。**仲裁裁定は 労働協約と 同一の 効力** | 労調30・34 |
| **緊急調整**: **内閣総理大臣** が、あらかじめ **中央労働委員会の 意見を 聴いて** 決定。公表の 日から **50日間 は 争議行為が できない** | 労調35の2①②・38 |
| 公益事業の 争議行為は **少なくとも 10日前までに** 労働委員会 及び 厚生労働大臣 又は 都道府県知事に 通知 | 労調37① |

### 最低賃金法
| 事実 | 出どころ |
|---|---|
| 使用者は 最低賃金の 適用を 受ける 労働者に **最低賃金額 以上** の 賃金を 支払う。最低賃金額に 達しない 賃金を 定める 契約は その部分 **無効**、無効の 部分は 最低賃金と 同様の 定めを した ものと みなす | 最賃4①② |
| 最低賃金に **算入しない** 賃金: 1か月を こえる 期間ごとに 支払う 賃金(賞与 など)・通常の 労働時間 / 労働日の 賃金 以外(時間外割増 など)で 省令で 定める もの・その最低賃金で 算入しないと 定めた 賃金 | 最賃4③ |
| **減額の 特例**: **都道府県労働局長の 許可** を 受けた とき、① 精神 又は 身体の 障害で 著しく 労働能力の 低い 者 ② **試の 使用期間中** の 者 ③ 認定職業訓練を 受ける 者(省令で 定める もの)④ **軽易な 業務** に 従事する 者 など は、省令の 率を かけた 額を 減額できる | 最賃7 |
| **地域別最低賃金** は **あまねく 全国 各地域** に ついて 決定。**労働者の 生計費・賃金・通常の 事業の 賃金支払能力** を 考慮。生計費は **生活保護に 係る 施策との 整合性** に 配慮 | 最賃9①〜③ |
| 地域別最低賃金は **厚生労働大臣 又は 都道府県労働局長** が **最低賃金審議会**(中央 / 地方)の 調査審議を 求め、意見を 聴いて 決定。意見の 要旨の 公示から **15日以内** に 異議を 申し出られる | 最賃10①・11① |
