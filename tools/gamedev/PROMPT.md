# フリックゲームクリエイター: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
しくみ図の どこに あるか(📍)が 出る。あそぶのは **小学生〜ゲームクリエイターを めざす 学生・大人**。
**ゲームを 作る ことばと 意味を おぼえる ゲーム**(作りかたの 手引きでも、コードの 教科書でも ない)。
(けいくん 2026-09-29「ゲームクリエイターになるために必要な 知識をフリック形式の問題にしてください」。
 決めたこと: 4段(入門・中級・上級・プロ)/ プログラムの 旅は 入れる(考えかたの 名前だけ)/ 課金・ガチャは 入れない・CERO などの 守る ことばは 入れる / 図は 作る)

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 4つ

### 1. AIフリック旅行と ことばを かぶらせない
AI旅行に もう ある 314語(`tools/gamedev/ai-words.txt`)と **名前か 読みが 同じ ことばは 入れない**(台本が 止める)。
とくに ゲーム作りでも 出てくる この 語は **ぜったいに 見出しに しない**:
アルゴリズム / クラウド / サーバー / アップデート / バグ / API / データベース / UI / UX / オープンソース / Git /
フレームワーク / テスト / ライセンス / リリース / バージョン / ログ / ビルド / エラー / プログラム / プログラミング /
ソースコード / エディタ / ライブラリ / コマンド / ツール / ベクトル / 課金 / 年齢制限 / 著作権 / 商標 / 保存 / 入力 / 出力 / ベータ版 / アイコン / フォント / パソコン / アプリ / スマホ
→ **ゲーム作りに しかない ことば**を えらぶ(当たり判定・スプライト・フレームレート・レベルデザイン・ゲームループ・デバッグ など)。
「テストプレイ」「バグ報告」「アップデートパッチ」の ように **字が ちがえば よい**が、中身が AI旅行の 語と 同じに ならない ように **ゲームの 話として** 書く

### 2. 本当の ゲームの 題名・会社・キャラ・ゲーム機・ストアの 名前を 出さない(商標)
- ❌ ゲームの 題名 / ゲーム会社 / キャラクター / ゲーム機の 商品名 / ゲームを 売る ストアの 名前 / ロゴ
- ⭕ **ジャンルの 名前**(アクション・パズル・RPG)・**ゲームを 作る 道具の 名前**(Scratch・Unity・Unreal Engine・Godot・Blender。
  AI旅行で ChatGPT を 出しているのと 同じ あつかい)。**道具を 見出しに するのは 🛠 作る道具の 旅だけ**、ほかの 旅の 説明の 中で 名前を 出さない
- 道具は **どれが 一番と 順位を つけない**・**悪く 言わない**・**値段を 書かない**(「むりょうで 使える」も 書かない。変わる ため)
- 「〜と いう 有名な ゲームが ある」の ように 本物の ゲームを たとえに しない。たとえは「ジャンプして 足場を わたる ゲーム」の ように 作った 形で

### 3. お金の ことばを 出さない(けいくん決定「A」)
- ❌ 見出しにも 説明にも 出さない: 課金・ガチャ・基本無料・マネタイズ・売上・値段・給料・円・もうけ
- ⭕ **守る ための ことば**は 入れる: CERO(せろ)・年れい区分・プレイ時間の めやす・休けいの よびかけ・ペアレンタルコントロール など
- 仕事の 説明でも お金に ふれない(プロデューサー = 「人や 予定を そろえて、ゲーム作り ぜんたいを すすめる 人」)

### 4. 「作ってみたい」を じゃましない
- あそぶ 子は **自分も ゲームを 作りたい 子**かもしれない。むずかしい 言いかたで こわがらせない。「プロで ないと むり」と 思わせない
- ことばによっては **はじめの 一歩が 見える** 一言を そえる(「紙と えんぴつでも 作れます」「小さく 作って ためすのが 大事です」)
- ⚠️ **7つの 旅では** やりかたの 手順・コードの 書きかたは 書かない(`if` や `for` の 形・関数の 名前・キーの 押しかた)。
  **コードと 作りかたは 8つめの 旅「⌨️ コードと作りかた」だけ**に まとめる(けいくん 2026-09-29「コードの書きかたや作りかたはゲームクリエイターに必要? 必要なら追加してください」。下の 節)
- 暴力の ようす・こわい 表現は 書かない(「てきを たおす」は よい。血・ざんこくな ようすは 書かない)
- 自分の 宣伝(かずとも・フリック旅行の 名前)を 書かない

## 1語の 形(JSON)

```json
{"id":"pu-atarihantei","name":"当たり判定","reading":"あたりはんてい","journey":"prog","category":"ぶつかる","difficulty":2,
 "role":"プログラマー","type":"concept","emoji":"💥","mapNode":"program:atari","relatedTerms":["pu-zahyo"],
 "description":"もの どうしが ぶつかったかを 調べる しくみ。これが ないと、キャラが かべを すりぬけて しまいます。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(ゲームを 作る 人が ふつうに 使う 言いかた。漢字・カタカナ・英字)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白は ダメ)
  - カタカナ語は ひらがなに(すぷらいと)
  - 英字は 下の「英字の 読み」の とおり。ない ものは 日本の ふつうの 読み
  - 数字は ひらがな(2D → つーでぃー)
  - ゆれる ことばは 1つに 決め、別の 読みは `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は **上級だけ**に、旅で 1〜2語まで
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級 / `4` プロ(下の「4段の 分けかた」)
- **role**: どの 仕事の 人の ことばか。つぎの 9つの どれか:
  `あそぶ人`(あそぶ 人も ふだん 使う ことば)`プランナー` `ディレクター` `プログラマー` `グラフィッカー` `サウンド` `シナリオ` `デバッガー` `プロデューサー`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(🔫 💣 🩸 など こわい・武器の 絵文字は 使わない。お金の 絵文字 💰 💴 も 使わない)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / どこで 出てくるか / なぜ 大事か」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  カタカナの 専門用語を カタカナだけで 説明しない。**説明の 中に 英語を まぜない**(「material」ではなく「素材」)
- **example**: なくてもよい

Blender → ぶれんだー / CERO → せろ / 2D → つーでぃー / 3D → すりーでぃー / RPG → あーるぴーじー /
FPS(フレームレートの 単位) → えふぴーえす(入れる なら 1つだけ・上級。一人称の ゲームの 意味では 入れない) /
NPC → えぬぴーしー / HP → えいちぴー(別: ひっとぽいんと)/ MP → えむぴー / QA → きゅーえー / VR → ぶいあーる / AR → えーあーる /
BGM → びーじーえむ / SE → えすいー / CG → しーじー / GUI・HUD → 入れる なら HUD = はっど

## 4段の 分けかた(けいくん 2026-09-29「本当にゲームクリエイターになれるレベルに作成してください」)

| 2 | 中級 | **作りはじめると 出てくる ことば**(当たり判定・スプライト・企画書・プロトタイプ・ゲームエンジン・デバッグ) |

(ならんだ 順が そのまま ステージの 順に なる)。

## ⌨️ コードと作りかた(`code`。2026-09-29 に 足した 8つめの 旅)

- **打つのは ことば**(if文 → いふぶん / for文 → ふぉーぶん / 代入 → だいにゅう / 関数の呼び出し …)。**コードを 打たせない**(フリックで 記号は 打てない)
- **`example` に 短い コードの 見本を 1〜2行**(「たとえば」の ところに 出る)。この 旅は **かならず example を 書く**
  - ⚠️ 見本は **どの 言語でも 読める 形**を めざす(`if (score >= 100) { clear() }` のような C系の 形)。言語 だけの 書きかた(Python の インデントなど)は その 言語の 語の ときだけ
  - 変数名・関数名は **英語の かんたんな 名前**(score / life / jump() / enemy)。日本語の 変数名は 使わない
  - 見本は **動く 正しい 書きかた**で。まちがいを 見せる 語(構文エラー など)は「まちがい → 直した 形」を 2行で
  - 1行 40字くらいまで(スマホで はみ出さない)。**本物の ゲームの コードを 写さない**(自分で 作った 見本)
- 説明(description)は いままでどおり やさしい 日本語。コードの 記号は 説明に 入れない(記号は example だけ)
- **作りかたの 流れ**(category「作る順番」)も 入れる: 企画 → 試作 → 本作り → 仕上げ → とどける の 順番・だれが 何を するか・ゲームジャムで 1本 作る 流れ など。
  example は 「1. ◯◯ → 2. ◯◯ → 3. ◯◯」の ような 手順の 見本で よい
- 言語の 名前は 入れて よい(C#・C++・Lua・GDScript など。AI旅行の Python・JavaScript・TypeScript・SQL・HTML・CSS・JSON は **入れない**)
- ほかの 旅と かぶる 語(変数・条件分岐・関数・配列・ループ・引数・戻り値・オブジェクト指向・インスタンス・スクリプト・デバッグ …)は **入れない**。
  この 旅では **書きかたの 名前**(if文・for文・while文・else・return文・宣言・代入・演算子・比較演算子・論理演算子・文字列・整数・小数・真偽値・コメント・インデント・波かっこ・セミコロン・構文エラー・null・クラス・継承・メソッド・コンストラクタ・リスト・辞書・再帰・イベントハンドラ …)を 使う
- 旅の 図は `code:`(kaku 書きかたの 決まり / atai 数と 文字 / keisan 計算・くらべる / bunki if文 / loop for文・while文 / kansu 関数 /
  class クラス・オブジェクト / hairetsu リスト・配列 / error まちがいと 直しかた / gengo プログラミング言語 / junban 作る 順番 / kanryo できあがり)

## ぜったいに 守ること

- **自分の ことばで 書く**。本・記事・Wikipedia・道具の 説明書の **本文を 写さない**
- **ゲームの 題名・会社・キャラ・ゲーム機・ストアの 名前を 使わない**(台本の BAN が 止める)
- **お金の ことばを 使わない**(台本の BAN が 止める)
- **数字は まちがいない ときだけ**(「1秒に 60回」など よく 使われる めやすは「〜が よく 使われます」と 書く)
- 人の 話は「〜と 言われている」の 形に。事実が あやしい 語は **入れない**
- ほかの 旅と **読みが かぶらない**(上の 入れる / 入れない を 守る)。**AI旅行の ことばと 同じ 名前・読みの 見出しは 作らない**
- 「100マス計算」「百ます計算」の 字を 使わない

## 出すもの

`tools/gamedev/terms-<旅id>.json` に JSON の 配列(100語)で 書く。書いたら
`python3 tools/gamedev/terms_js.py --only <旅id>` で 形を 確かめる(まちがいが あれば 止まる)。
