けいくん 2026-10-03「新しいセッションで フリック救急隊員を作成したい。救急隊員の専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください」

## 1. 作る もの(消防士・医師と まったく 同じ 型)
| もの | 場所 |
|---|---|
| ことばの 決まり | `tools/kyukyutai/PROMPT.md`(shobo の PROMPT.md を 写して、ishi・kango の「処置・薬を 書かない」を 足す) |
| 旅・資格の 説明 | `tools/kyukyutai/meta.json`(`mkmeta.py` + `exam.txt` の 型。`exam` は **確かめた 日つき**で) |
| ことば | `tools/kyukyutai/terms-<旅>.json`(旅ごとに 1ファイル。**旅ごとに 70語 = 入門20・中級25・上級25**) |
| 変換 | `tools/kyukyutai/terms_js.py`(shobo の を 写す。`BAN`・**救急隊員の 中での** 読みの かぶりを 止める。⚠️ ほかの ゲームとの かぶりは **止めない**)→ `kyukyutai/terms.js` + `data/kyukyutai.json` |
| しくみ | `kyukyutai/kyukyutai.js`(shobo.js を 写す。旅の 図は コードで 描く 箱の 図。**救命の連鎖(気づく → 119番 → 胸骨圧迫と AED → 救急隊 → 病院)**・**119番から 病院までの 流れ(指令センター → 出動 → 現場 → 搬送 → 引きつぎ)**・**救急車の 中の 図**・**からだの 図(医師・看護師と 同じ 箱の 図)** を 入れると よい) |
| 登録 | `tools/build_games.py` に `"kyukyutai": dict(name="フリック救急隊員", modes="KYUKYUTAI", ...)`、`index.html` の `const PLUG` に `KYUKYUTAI`・`SERIES` に `{id:"kyukyutai", name:"フリック救急隊員", icon:"🚑", dir:"kyukyutai/"}`・`SERIES_ORDER`(消防士の となり) |
| 絵 | トップ `kyukyutai/hero.webp`(1536×1024)。**アイコンは 四角い 絵(1254px)を `tools/kyukyutai/art/square-src.png` に 置いて `python3 tools/icon_from_square.py kyukyutai`(切らない)**。**題名は 透明 PNG を `tools/kyukyutai/art/title-src.png` に 置いて `python3 tools/title_from_art.py kyukyutai`**。届くまでは 仮の 絵で よい |
| かずとも 側 | `speed-king` の `src/lib/flick.ts` の `FLICK_MODES` と `FLICK_LINK_TARGETS` に `kyukyutai` を 足す(**旅を 足したら かならず**)。販売ページ `HOME_GAMES`(`src/lib/games.ts`)と 規約の 文(`FLICK_SERIES_GAMES`)は **絵と けいくんの OK を もらってから**(「夢のしごと」の 章の 説明 `lead` にも 名前を 足す) |
| 法務の リンク | 土台の `index.html` の `.legal-links` が 全ゲームに 出るので **何も しなくて よい** |

⚠️ フォルダ名は `kyukyutai`(`kyukyu` に しない)。消防士の 旅の id が もう `kyukyu` なので、まぎらわしく しない

## 3. ⚠️⚠️⚠️ ぜったいの 決まり(医師・看護師・消防士と 同じ。命の ことばは なおさら)
- ✅ **ほかの ゲーム(消防士・医師・看護師 など)と 同じ 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。説明は **救急隊員の 目線**(現場で 見て・手当てし・病院へ つなぐ)で 書きなおす
- **読み(ひらがな)は 救急隊員の 7つの 旅の 中では かぶらない**(ほかの ゲームとは かぶって よい。`terms_js.py` が 止める)
- ⚠️⚠️ **手当て・処置の やりかたを ぜったいに 書かない**(医師の「やりかた・こういう ときは こうする を 書かない」と 同じ)。
  ❌「胸骨圧迫は ◯cm の 深さで 1分間に ◯回」「止血は ◯◯して」/ ⭕ その ことばが **何を さすか・何の ための 手当てか**。
  かわりに 画面と ゲームの 説明に「**手当ての やりかたは 消防署の 救命講習で 習おう**」と 書く(本当の 救命講習への 道案内。ゲームで 覚えさせない)
- **薬の 名前の 量・使いかた**は 書かない(アドレナリン・ブドウ糖 などは 「救急救命士が 医師の 指示で 使う ことが ある 薬」まで)
- **診断の 答えに なる 書きかたを しない**(「こういう ようすなら ◯◯病」)。画面に「これは ことばを おぼえる ゲームです。からだの ぐあいが わるい ときは おうちの 人に 知らせて、こまったら 119番や #7119 に 相談してください」
- **小学生も あそぶ**: 大けが・出血の ようす・亡くなる 場面・事故の 現場の ようすを 書かない。「心肺停止」は「心臓と 呼吸が 止まった 状態」と 事実だけ。
  「死亡」「死ぬ」「血まみれ」の ような ことばを 使わない(台本で 止める。医師・税理士の `BAN` を 見る)。**こわさより「助けかたを 知っている 安心」** を まん中に
- **数字の 決めうちを 書かない**(救急車の 到着時間・搬送人数・救命率 など 年ごとに 変わる 数字は 書かない。**119番・#7119** の ような だれでも 知っている 番号は よい)
- **実在の 病院・消防本部・事故・人の 名前を 入れない**(歴史上の 人・できごとは 確かめて から)
- **作った 助手とは 別の 助手が 1語ずつ 確かめる**(意味・読み・手当ての やりかたを 書いていないか・薬の 量・こわくないか)。ふりがなも 全語 見る(`tools/ruby_fix.json`)

## 5. 作りかたの 手順(消防士・税理士の まとめと 同じ)
1. けいくんに 2 の 5つを 聞く → 返事を CLAUDE.md に 書く
2. `tools/kyukyutai/PROMPT.md` `exam.txt` `mkmeta.py` → `meta.json` を 作る → 旅ごとに 助手に 70語ずつ 頼む(`PROMPT.md` を そのまま わたす。**助手は 2人ずつ**)→ `terms-<旅>.json`
3. `terms_js.py` で 止められた 語を 直す → 別の 助手が 1語ずつ 確かめる → ふりがな
4. `kyukyutai/kyukyutai.js`(shobo.js を 写す)・`build_games.py`・`index.html` の PLUG と SERIES → `python3 tools/build_games.py`
5. 手元で 通す: `python3 -m http.server 8765` → `node tools/play-all.mjs kyukyutai/` / `node tools/click-all.mjs kyukyutai/`
6. PR は **rebase で 取りこむ**(この 入れもの)。speed-king は squash。コミットの 末尾は Co-Authored-By と Claude-Session の 2行
7. かずとも `speed-king`: `FLICK_MODES` / `FLICK_LINK_TARGETS` に `kyukyutai`(PR → squash)。`HOME_GAMES` は 絵と OK の あと
8. けいくんに ChatGPT で 絵を 頼む 文を わたす。**3つ**:
   ・トップの 絵(1536×1024)。**人物は 画面の 下 3分の1に 小さく**・指5本・首が 見える。救急車の 前で 救急隊の 服の 子どもと 白い 犬が 笑っている 絵。
     **けが人・病人・血・事故の 現場を 描かない**。**AED や 担架を 手に 持たせない**(手が 崩れやすい。救急車の 中や 横に 置く)。
     絵の 中の 字は「フリック救急隊員」だけ・ゲームに 無い 機能の 絵を 入れない・**実在の 消防本部の 名前や マーク・赤十字の しるしを 描かない**(赤十字の マークは 法律で 使える 人が 決まっている)。届いたら **まず 字を 切り出して 読む**
   ・四角い 絵(1254px)… **切らずに そのまま アイコンに する**ので、**小さく しても わかる 絵**(救急車と 人と 犬 くらい。まわりに 字の 札を ならべない)で 頼む
   ・**題名だけの 透明 PNG**(CLAUDE.md「題名は ChatGPT に 切りぬいてもらう」の 文を そのまま。「フリック救急隊員」と **はっきり 書く**。⚠️ ChatGPT は 字を 変える。**届いた 字を かならず 読む**)
9. 絵を 入れたら CLAUDE.md に 節を 書く(名前・旅・語数・確かめた 日・入れなかった 語と 理由)

## 6. 気をつける 前例
- 看護師で 統合失調症 → 適応障害に 入れかえた(子どもが こわく 感じる)。救急でも **心肺停止・大量出血・多数傷病者** などは 入れるか けいくんに 聞く(入れるなら 事実だけ・おだやかに)
- 医師の 監査で「こまめな 水分補給で 防げます」の ような **行動の 指示**を 外した(2026-10-01)。救急でも「◯◯すれば 防げる」と 書かない
- 消防士(`shobo/`)の「救急と救助のことば」70語と **かさなる 語が 多い**(119番・AED・救急救命士・トリアージ・ドクターヘリ など)。**同じ 語を 入れて よい**が、説明は 救急隊員の 目線で もっと くわしく
- 読みの かぶりは 片方を べつの 語に(例: 「意識」と「医師」はちがう読みで OK。「脈拍」「動脈」など)。英字の 略語(AED・SpO2・JCS・GCS)は 読みを ひらがなで(えーいーでぃー)
- 2026-10-03 の 時点で 30ゲーム(投資家まで。大工は まとめだけ)。**フォルダ・id・modes 名を まぜない**(`kyukyutai`)
