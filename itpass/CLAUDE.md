# itpass/ の メモ(この ゲームだけの 決めごと・いきさつ)

> シリーズ共通の きまりは 入れものの いちばん上の `CLAUDE.md`。

## フリックITパスポート(`itpass/`。けいくん 2026-11-11「ITパスポートに 受かるレベルに フリック問題で なれるように」。まとめは `docs/フリックITパスポート-はじめかた.md`)

- 名前は「**フリックITパスポート**」(スペース なし。正式名は「ITパスポート試験(iパス)」= 情報処理推進機構(IPA)の 国家試験)。フォルダ `itpass`・modes `ITPASS`。シリーズの 絵文字は 🪪。色は `#1864ab`。`SERIES_CHAPTERS` の 夢のしごとの 章、**衛生管理者の となり**。
  かずともの 旅の 名前は **`ip` で はじめる**(ipkeiei / iphomu / ipsenryaku / ipshisutemu / ipkaihatsu / ipservice / ipkiso / ipkonpyuta / ipnettowaku / ipsekyuriti / ipmas)
- 旅は 10 = 試験の 3つの 分野を シラバスの 大分類・中分類で 分けた: ストラテジ系 = 🏢 企業活動と会計 `keiei` / ⚖️ 法務と情報倫理 `homu` / 📈 経営戦略とマーケティング `senryaku` / 🗂 システム戦略と企画 `shisutemu`・マネジメント系 = 🛠 開発技術とプロジェクト `kaihatsu` / 🧰 サービスマネジメントと監査 `service`・テクノロジ系 = 🔢 基礎理論とアルゴリズム `kiso` / 🖥 コンピュータとソフトウェア `konpyuta` / 🌐 ネットワークとデータベース `nettowaku` / 🔐 情報セキュリティ `sekyuriti` + 🏆 マスター。
  **1,000語**(旅ごとに 入門15・中級30・上級55)。1語ごとに `field`(シラバスの 中分類 23こ)と **📝 分野の 札**(`ruleset`: ストラテジ系 / マネジメント系 / テクノロジ系)。札は field で 決まる(`terms_js.py` の `FIELD_RS` が 止める)
- ⭐⭐ **シラバスは Ver.6.5(2026-01-08 掲載)が 答え**。まとめ(はじめかた.md)は Ver.6.4 と 書いて いたが、作る 日に IPA を 見たら 6.5 が 出て いた(6.4 からの ちがいは「下請法」→「中小受託取引適正化法(取適法。2026-01-01 施行)」だけ。facts-B が 全文 くらべた)。シラバスの PDF は IPA の 著作物なので 入れものに 入れて いない(pdftotext で 読んだ)
- ⭐⭐ **試験の ための しくみ**(`itpass/itpass.js`。衛生管理者 `eisei.js` を 写した。見た目の class は `ai-…` / `ip-…`):
  ・**⭕❌ 一問一答**(`tools/itpass/maru-<旅>.json`。決まり `MARU.md`。⭕ 40〜60%・上級が 半分 以上・とき方 + 📚 どこの 話か(`law`)・`rs` = 分野)
  ・**🔢 数字・計算クイズ**(`tools/itpass/num-<旅>.json`。決まり `NUM.md`。ITパスポートは 数字より **計算**(2進数・稼働率・損益分岐点・表計算・転送時間・クリティカルパス)なので 計算を 半分 以上。答えは python で 確かめた)
  ・**🎯 模擬試験**: 本番と 同じ **4つから 1つ・100問・120分**。1問 = 同じ 分野の ⭕❌ の 文を 4つ ならべて「正しい / 誤っている ものは どれか」(ときどき 数字クイズ)。分野の 問題数は ストラテジ系 35・マネジメント系 20・テクノロジ系 45(IPA 試験要綱 Ver.5.6 で 確かめた。`tools/itpass/mock.json`)。
    合格の きまりも 本番と 同じ形: **総合 60% 以上 かつ 分野ごとに 30% 以上**(本番は 1,000点満点で 600点 / 300点)。⚠️ 本番は **IRT(項目応答理論)**で 点を 出し、100問の うち 8問は 評価に 入らない。ゲームの 1問 10点とは 同じでは ない と 画面に 書いた。合格を 約束しない
  ・⭐ **❌ まちがえた 問題**(`flick-itpass-miss`。2回 つづけて 正解で 消える)。運転免許・宅建士・衛生管理者に つづく 例外。⚠️ ほかの ゲームに 広げない
  ・ホームに **📊 ITパスポートの 図**(`<details>`): 3つの 分野・開発の 工程・TCP/IP の 4つの 層・共通鍵 / 公開鍵・直列 / 並列の 稼働率・SWOT
- ⭐⭐ **事実は 確かめた ものだけ**: `tools/itpass/facts-A.md`(試験の しくみ・ストラテジ系の 数字と 式)・`facts-B.md`(マネジメント系・テクノロジ系の 基礎)・`facts-C.md`(法務・セキュリティ。e-Gov 法令API v2 の いまの 条文)。2026-11-11 に 確かめた。
  いまの 答えに した おもな もの: 取適法(2026-01-01。委託事業者・中小受託事業者)/ 情報流通プラットフォーム対処法(2025-04-01。前の プロバイダ責任制限法)/ 拘禁刑(2025-06-01)/ 意匠権 出願から 25年 / 著作権 死後 70年 / 統合テスト(結合テスト では ない)/ MTBF = 平均故障間動作時間 / 内部統制の「報告の信頼性」(2023年 改訂)/ スクラムの「開発者」/ リスク対応の 字は 2つ(プロジェクト = 回避・軽減・受容・転嫁、セキュリティ = 回避・共有(移転・分散)・保有)
  ⚠️ シラバスで 問わない: SQL の くわしい 文法・正規化の くわしい 中身・PMBOK の 知識エリア・待ち行列の 理論。ROE・ROA・自己資本比率・減価償却・QC七つ道具 という 名前は 用語例に 無い
  ⚠️ 成立したが まだ 始まって いない 改正(個人情報保護法 令和8年改正・著作権法 令和8年改正)は 答えに しない
  ❌ 書かない もの: 合格率・応募者数・実在の 会社の 事故・製品の 値段・過去問の 文・攻撃や 不正の やりかた(「何の 脅威で、どう 守るか」だけ)
- ⭐⭐⭐ **2027年度から 新しい 試験**(facts-A。IPA 2026年の 発表): いまの 試験制度は **2026年度の 試験で 終わる 予定**。**2026-12-28 〜 2027年1月下旬は CBT が お休み**。新しい ITパスポートは **2027年度の 春ごろ** から、**120分・100問**(いまと 同じ)、分野は「**ビジネス**」「**テクノロジ**」「**セキュリティ・倫理**」の 3つに 組みなおし(シラバス案 Ver.0.1 は 2026-08-31 掲載)。採点・合格基準・分野ごとの 問題数は まだ 出て いない。
  → **新しい 要綱が 出たら 分野の 札(`FIELD_RS`・`mock.json`・`maru_check.py` の `RS_OF`)を 3つの 新しい 分野に 付けかえる**。ことばと 問題の 多くは そのまま 使える はず
- ことばは `tools/itpass/terms-<旅>.json`(決まり `PROMPT.md`・確かめる係 `CHECKER.md`・置き場所 `plan.json`)→ `tools/itpass/terms_js.py` → `itpass/terms.js` + `data/itpass.json`。旅・図・称号・模擬試験は `mkmeta.py`(+ `exam.txt`・`mock.json`)→ `meta.json`。
  確かめ `python3 tools/itpass/terms_js.py --check` / `python3 tools/itpass/maru_check.py`。⚠️ 10字を こえる 読みは 旅ごとに 10語まで(`LONG_READ`)。ふりがなの 見かたは `python3 tools/itpass/ruby_dump.py <旅>`
- **トップの 絵は 入れた**(2026-11-11。`itpass/hero.webp` 1536×1024・`hero=True`・`wordv` = 1)。けいくんの ChatGPT の 絵の **2回目**。1回目は 箱が 9こ(コンピュータと ネットワークが 1つ)・札 36こ中 14こが ゲームに 無い ことば・「まーけていんぐ」「えるえー(SLA)」で 入れなかった。2回目は 10の 箱 × 4こ = 40こ ぜんぶ ゲームの 読み(プログラムで 確かめた)。
  ⚠️ 2回目にも 字の まちがいが 2つ: 6番「へるぶですく」(正しくは へるぷ)・10番の 見出し「じょうほうせきゅりてい」(正しくは せきゅりてぃ)。直した 絵が 届いたら 差しかえて `wordv` を +1(かずともの `games.ts` の `art` の `?v=` も)
- **アイコンと 題名も 入れた**(2026-11-11)。四角い 絵 1254px → `tools/itpass/art/square-src.png` → `python3 tools/icon_from_square.py itpass`(`iconv` = 2)。題名の 透明 PNG 2172×724 → `tools/itpass/art/title-src.png` → `python3 tools/title_from_art.py itpass` → `itpass/logo-word.webp` 900×211(`logo=True`・`wordv` = 2)。「フリックITパスポート」11字を 読んで 確かめた(T・パ・ト も くずれて いない)。
  ⚠️ 四角い 絵の 中の 小さな 札には 字の まちがいが いくつか ある(しするむ・あるうりずむ・でーどうぇあ・ふぁいあうぇうる・へるぶ・せきゅりてい)。アイコンの 大きさでは 読めないので そのまま 入れた。直した 絵が 届いたら 差しかえて iconv +1
