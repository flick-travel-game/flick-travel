## 3. ⚠️⚠️⚠️ ぜったいの 決まり
- ⭐⭐ **数字が 変わる ものを 書かない**(この ゲームで いちばん 事故が 起きやすい):
  - ❌ いまの 所属クラブ(**移籍で 変わる**)・年俸・移籍金・いまの 順位・**通算ゴール数**(いまの 選手)・市場価値・いまの 監督・いまの キャプテン
  - ✅ **変わらない 事実は よい**: 国籍(代表)・ポジション・**得意な 技 / プレーの 特徴**・**過去の 受賞と その 年**(「◯◯年の バロンドール」)・**ワールドカップの 優勝の 年と 国**・**引退した 選手の 所属の 歴史**
- ⚠️⚠️ **いまの 選手の 書きかた**(`star` の 旅): 「**◯◯代表の FW。速い ドリブルと 左足の シュートが 武器**」の ように **国・ポジション・プレーの 特徴**で 書く。**クラブ名を 答えの 手がかりに しない**。
  答えに した 選手は `meta.json` に **確かめた 日**を つけて、**1年に 1回 見なおす** と メモに 書く(引退・国籍変更が あるため)
- **ルールは かならず その日の 版を 確かめる**(**IFAB の 競技規則 / JFA の 日本語版**)。ハンド・オフサイド・交代人数・VAR は **毎年 変わる ことが ある**。`meta.json` に 「◯年版で 確かめた」と 書く
- ✅ **実在の 選手・クラブ・リーグ・大会の 名前は 入れて よい**(事実として。プレプロの 見本でも 実在の 選手・チームを 使っている。2026-09-07)。
  ❌ ただし **絵には 描かない**(実在の 選手の 顔・エンブレム・ユニフォーム・スポンサー・大会の ロゴ)
- **人を けなさない**: 「ダメな 選手」「負けた 国」の 書きかたを しない。**PK を 外した 話・オウンゴール・退場**など 人が 悲しんだ 場面は 入れない(名場面は **いい ほう** だけ)
- **ラフプレー・反則を すすめない**: 「シミュレーション(ダイブ)」は **反則の 名前として**(「倒された ふりを する 反則。イエローカード」)。ずるい 技としては 書かない
- **ドリブル技は 「練習で 身に つける 技」として**。⚠️ **相手を ばかに する ための 技としては 書かない**(シャペウ・股抜きは 「相手の 動きを 見て ボールを 運ぶ 技」)
- **小学生も あそぶ**: ケガ・乱闘・差別・賭けの 話は 入れない。**迷ったら 入れない**
- ✅ **ほかの ゲーム(世界旅行の 国・歴史の 人物・英語 など)と 同じ 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。説明は **サッカーの 目線**で
- **読み(ひらがな)は ワールドサッカーの 9つの 旅の 中では かぶらない**(ほかの ゲームとは かぶって よい。`terms_js.py` が 止める)。⚠️ `legend` と `dribble`(クライフ と クライフターン)、`club` と `league`(チャンピオンズリーグ)、`kihon` と `tactic`(ポジション)、`legend` と `cup`(伝説の 試合)は かさなりやすい。**先に 9つの 旅の 語の 一覧を 1人の 助手に 作らせて** 置き場所を 決めてから 頼む
- **カタカナの 書きかたを そろえる**(JFA・日本の 新聞で よく 使う 書きかたに。例: 「ユヴェントス」「ラ・リーガ」「ブンデスリーガ」)。⚠️ 答えの 字が ゆれると フリックで 打てない。**別の 書きかたは `alias`(読み)で 受ける**
- 画面(ホームの 下・遊びかた)に「これは ことばを おぼえる ゲームです。**選手の 所属や 記録は 変わる ことが あります**」「FIFA・各リーグ・各クラブとは 関係ありません」
- **作った 助手とは 別の 助手が 1語ずつ 確かめる**(**選手と 国・技と 使い手・年と 大会・ルールの 版**・変わる 数字が 無いか・人を けなして いないか)。ふりがなも 全語 見る(`tools/ruby_fix.json`)

## 5. 作りかたの 手順(医師・獣医師の ときと 同じ)
1. けいくんに 2 の 5つを 聞く → 返事を CLAUDE.md に 書く
2. `tools/soccer/PROMPT.md` `mkmeta.py` → `meta.json` を 作る → **先に 9つの 旅の 語の 一覧を 1人の 助手に 作らせて 置き場所を 決める** → 旅ごとに 助手に 70語ずつ 頼む(`PROMPT.md` を そのまま わたす。**助手は 2人ずつ**)→ `terms-<旅>.json`
3. `terms_js.py` で 止められた 語を 直す → 別の 助手が 1語ずつ 確かめる(**選手と 国・技と 使い手・年・ルール・変わる 数字**)→ ふりがな
4. `soccer/soccer.js`(ishi.js を 写し、国の 札と ピッチの 図を 足す)・`build_games.py`・`index.html` の PLUG と SERIES → `python3 tools/build_games.py`
5. 手元で 通す: `python3 -m http.server 8765` → `node tools/play-all.mjs soccer/` / `node tools/click-all.mjs soccer/`(W=320 も)
6. PR は **rebase で 取りこむ**(この 入れもの)。speed-king は squash。コミットの 末尾は Co-Authored-By と Claude-Session の 2行
