# フリック国語旅行: ことばの 作りかた(助手に 分けて 頼むときの 決まり)

ゲームは「表示された ひらがなを フリックで 打ち写す」タイピング。打ち終わると ことばの 説明(1〜3文)が 出る。
遊ぶのは 中学生〜高校生・大人。**高校受験・大学受験の 国語で 要る 知識を おぼえる ゲーム**。
(けいくん 2026-09-27: 名前「フリック国語旅行」/ 3段 / 古文・漢文を 入れる / 漢字の読みの 上級は よみを かくす / 文学史は 年表に 📍)

## 1語の 形(JSON)
{"id":"yo-sousai","name":"相殺","reading":"そうさい","journey":"yomi","category":"まちがえやすい読み","difficulty":2,
 "type":"concept","emoji":"⚖️","relatedTerms":["yo-hanrei"],
 "description":"たがいに 打ち消しあって、差し引き ゼロに する ことです。「そうさつ」と 読むのは まちがいです。"}

- id: 旅の 頭文字 + "-" + 英小文字(yo- / yj- / ko- / bu- / kb- / kg- / kn- / bs- / hy-)。英小文字・数字・- だけ。ぜんぶで かぶらない
- name: 画面に 出す 字(漢字・かな)。**打つ 字は 出さない**(name に ふりがなや かっこの 読みを 付けない)
- reading: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」「〜」は ダメ)。
  ゆれる 読みは 1つに 決め、別の 読みは "acceptedReadings":["よみ1","よみ2"](先頭は reading と 同じ)。例: 貼付 = ちょうふ / てんぷ
  ⚠️ 本当に どちらも 正しいと 辞書で 認められる ときだけ。まちがい読み(そうさつ)は 入れない
- difficulty(どの 旅も 3段):
  - 1 = **入門**(中学の 基本。教科書に 出る)
  - 2 = **中級**(高校受験の めやす)
  - 3 = **上級**(大学受験 = 共通テスト・二次試験の めやす)
- 数: 旅ごとに 決まっている(下の 表)。difficulty ごとに **同じ 数ずつ**。同じ difficulty の 中は よく 出る 順
- type: いつも "concept"
- category: 図鑑で しぼる 分類(短い 日本語。旅の 中で 3〜8種類)
- emoji: 1つ
- relatedTerms: **同じ ファイルの 中の** id を 1〜3個(自分は ダメ)。いっしょに おぼえると よい ことば(反対語・似た 語・同じ 作者 など)
- mapNode: **文学史(bungaku)だけ**。年表の 時代(下)。ほかの 旅は 書かない
- description: 1〜3文・**130字以内**。やさしい です・ます。「意味 / 使いかた・どこが 大事か」。
  語と 語の あいだに 半角スペースを 入れる 書きかた(この シリーズの 文体。上の 例のように)。
  ⚠️ **説明の 中に その 語の 読みを ひらがなで 書かない**(答えが 見えて しまう。まちがい読みの 注意は「〜と 読むのは まちがい」の 形で よい)
- example: なくてもよい(ある ときは 使いかたの 例文 1つ。自分で 作った 文)

## ぜったいに 守ること
- **自分の ことばで 書く**。入試の 過去問・問題集・参考書・国語辞典・教科書・Wikipedia の 文を 写さない
- **作品の 本文を 長く のせない**。古典(源氏物語・枕草子・方丈記・徒然草・平家物語・奥の細道・論語 など)は 書きだしの 1行まで よい。
  ⚠️ **近代・現代の 作家は 作品名と 作者名だけ**。本文(書きだしも)は のせない(1956年より あとに 亡くなった 作家が いるため)
- 意味が 2つ ある 言葉(情けは人の為ならず・気が置けない・役不足 など)は **本来の 意味を 先に**、よく ある まちがいを あとに
- 事実(読み・意味・作者・時代・成立)は **まちがいない ときだけ**。説が 分かれる ものは「〜と 言われます」。あやしい 語は 入れない
- 「合格できる」「共通テストに 出る」と 言いきらない。「受験で よく 見る」くらいに する
- 「100マス計算」「百ます計算」の 字は 使わない。お店・商品の 名前は 使わない
- 人を 傷つける 言葉・差別の 言葉は 入れない
- ほかの 旅と かぶらない(下の「入れる / 入れない」)。**reading も ほかの 旅と かぶらない**

## 旅ごとに 入れる / 入れない
- yomi: 熟語の 読みだけ。**四字熟語・ことわざ・古語・評論語は 入れない**(それぞれの 旅へ)。人名・地名も 入れない
- yoji: 四字熟語だけ
- kotowaza: ことわざ・慣用句・故事成語(矛盾・推敲・蛇足・杞憂・漁夫の利 など)。**四字熟語は 入れない**
- bunpo: いまの 日本語の 文法用語だけ。**古典の 文法(係り結び・已然形・けり)は koten へ**。「連用形」など 両方で 使う 用語は bunpo に 入れて、koten では 已然形・係り結び など 古典だけの ものを
- kobun: 古語の 単語。**文法用語・助動詞(けり・べし)は koten へ**
- koten: 古典文法と 和歌の 技法。単語の 意味は kobun へ
- kanbun: 漢文の 句法・重要語・用語。**故事成語は kotowaza へ**
- bungaku: 作品名・作家名・文学の 流派(白樺派・自然主義 など)。上代〜昭和(戦後)。**生きている 作家は 入れない**
- hyoron: 評論語。**文法用語・文学の 流派は 入れない**
