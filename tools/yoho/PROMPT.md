# フリック養蜂家: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
🐝 西洋 / 日本 の 札・学ぶ 分野・しくみ図の どこに あるか(📍)が 出る。
あそぶのは **小学生〜農業高校の 生徒・はじめて 巣箱を 持つ 大人・養蜂家を めざす 人**。
**ミツバチと 養蜂の ことばと 意味を おぼえる ゲーム**(飼いかたの 手引きでも、薬の 使いかたの 本でも ない)。
もとは `tools/jui/PROMPT.md`(獣医師)と `tools/noka/PROMPT.md`(農家)。まとめは `docs/フリック養蜂家-はじめかた.md`。
けいくん 2026-11-01「プロの養蜂家レベルになるために必要な 知識をフリック形式の問題にしてください。西洋蜜蜂(セイヨウミツバチ)が メイン」→ 5つの 問いに「全部おすすめで」。

## ⚠️⚠️⚠️ いちばん 大事な 8つ

### 1. ハチを こわく しない
- ミツバチは **「めったに 刺さない、おとなしい 生きもの」**として 書く。働き蜂は 刺すと 針が 抜けて しまうので、巣を 守る ときだけ 刺す
- 刺された 話は **身の 守りかただけ**(近づかない・さわがない・手で はらわない・黒い 服を さける・刺されたら 針を はらって 冷やす・息が 苦しい ときは すぐ 病院へ)
- ❌ 腫れた ようす・救急の 話・亡くなる 話・「死」「死がい」「大量死」「毒」「惨」(台本が 止める)。「蜂毒」は「ハチの 針の 成分」と 言いかえる
- 一生を 終える ことは「一生を 終える」「役目を 終える」と おだやかに(「死ぬ」と 書かない)
- スズメバチ・ダニ・病気は **「どう 守るか」で 終わる**。「殺」の 字は 止まるので、ニホンミツバチの 守りは「蜂球(ほうきゅう)」と 書く(熱で 包んで 追いはらう)
- **迷ったら その 語を 入れない**

### 2. 薬の 名前・量・使いかたを 書かない(農家の 農薬・薬剤師の 薬と 同じ)
- ダニの 薬は「**獣医師や 指導員の 指示で、決まりどおりに 使う 薬**」まで。ギ酸・シュウ酸・チモールは **名前だけ**(濃度・回数・季節・入れかたを 書かない)
- 農薬は「ネオニコチノイド系」の 一般名まで。**商品名は 1つも 書かない**。台本が「希釈・濃度・散布・mL・mg」を 止める
- 抗生物質(抗菌薬)の 名前も 書かない。腐蛆病は「見つけたら 届け出る 決まり」として

### 3. はちみつは 食べもの
- ⭐ **「1歳未満の 赤ちゃんには はちみつを あげない」(乳児ボツリヌス症を 防ぐ)は かならず 入れる**。こわく しない 書きかたで「1歳に なるまでは あげません」(seihin の 旅)
- ❌ **医学的な 効きめを 書かない**(のどに よい・効く・治る・殺菌・免疫力・風邪に。薬機法・健康増進法に ふれる)。台本が 止める
- ⭕「おいしい」「あまい」「料理に 使う」「ブドウ糖と 果糖が おもな 成分」「ビタミン・ミネラルが 少し ふくまれる」まで

### 4. セイヨウミツバチが メイン(けいくん指定)
- 答えの ことば・しごとの 手順は **セイヨウミツバチの 養蜂**(ラングストロス式 巣箱・巣枠・遠心分離機)で 書く
- ニホンミツバチは **ちがいが わかる ぶんだけ**(旅ごとに 5〜10語。重箱式 巣箱・逃去しやすい・蜜は 少なめ・蜂球・アカリンダニに 弱い など)
- ⚠️ **「どちらが よい」は 書かない**(ちがいとして)
- ⭐ すべての 語に **`bee`** を 付ける: `西洋`(セイヨウミツバチの 養蜂の 話)/ `日本`(ニホンミツバチの 話)/ `共通`(どちらにも あてはまる・ミツバチ ぜんぱん・花・法律)

### 5. 数字は「変わらない 自然の 決まり」だけ
- ⭕ 生きものの 数(あし 6本・はね 4枚・女王 およそ 16日・働き蜂 およそ 21日・雄蜂 およそ 24日・はちみつの 糖度 およそ 78〜80%・飛ぶ 範囲 およそ 2〜3km)は よい。**「およそ」を 付ける**。年は 歴史の 年(1851年・1973年)
- ❌ **変わる 数字を 書かない**: 生産量・輸入量・養蜂家の 数・群の 数・価格・1群あたりの とれる 量・%・円・人・戸(台本が 止める)
- 条の 番号(第◯条)は 書かない

### 6. 実在の 名前
- ⭕ 法律・公の 団体・品種(亜種)・歴史の 人: 養蜂振興法・家畜伝染病予防法・食品表示法・農林水産省・都道府県・家畜保健衛生所・一般社団法人 日本養蜂協会・全国はちみつ公正取引協議会・イタリアン・カーニオラン・コーカシアン・バックファスト・ラングストロス・フォン・フリッシュ
- ❌ 養蜂場・はちみつの 商品・道具の メーカー・産地ブランドの はちみつ名・薬や 農薬の 商品名(台本が 止める)。マヌカの ような 産地の 名前の はちみつも 入れない

### 7. 小学生も あそぶ・ほかの ゲームと 同じ 語 OK
- 血・けが・死・こわい 先を 書かない。交尾飛行は「空で 雄蜂と 出会う」まで
- ✅ 理科の 昆虫・受粉、農家の 果樹・受粉、獣医師の 家畜伝染病、料理人の はちみつ と 同じ 語を 入れて よい(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。説明は **養蜂家の 目線**(巣箱で どう 見えるか・どう 世話するか)
- **養蜂 = ミツバチを 大切に 育てて、花と 作物を 助ける 仕事** の 形で 書く
- ✅ **道具の 使いかたは 書く**(農家と 同じ 決まり。けいくん決定 2026-10-03)。分離機で 何が らくに なるか・燻煙器の 煙で ハチが おだやかに なる しくみ。燻煙器・蜜刀・ハイブツールには「**おとなが 使う 道具です**」

### 8. 事実を 正しく・自分の ことばで
- 事実が あやしい 語は 入れない。教科書・Wikipedia・公式の 文を 写さない。法律・制度は `tools/yoho/exam.txt` に 合わせる
- **打ちまちがいに 気を つける**: 蜂 = 虫へん(峰 ではない)・蜜 = うかんむり(密 ではない)。「養峰家」「養蜂士」「密蜂」「蜜峰」に しない

## 1語の 形(JSON)

```json
{"id":"kr-hanakago","name":"花粉かご","reading":"かふんかご","journey":"karada","category":"あしと はね","difficulty":2,
 "field":"からだ","type":"concept","emoji":"🦵","mapNode":"karada:ashi","relatedTerms":["kr-kuchifun"],"bee":"共通",
 "description":"働き蜂の 後ろあしに ある、花粉を ためる くぼみです。花粉を だんごに して のせ、巣まで はこびます。巣箱の 前で 黄色や オレンジの だんごを つけた ハチが 見えたら、花粉を 運んで いる ところです。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(養蜂の 本で ふつうに 使う 書きかた)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**。ゆれる 読みは `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)。20字まで(16字 こえは 上級で 旅に 1〜2語)
  - 読みを まちがえやすい 語(1語ずつ 確かめる): 養蜂(ようほう)・蜜源(みつげん)・蜜蝋(みつろう)・蜜胃(みつい)・蜜刀(みつがたな)・巣房(すぼう)・巣礎(すそ)・巣脾(すひ)・巣枠(すわく)・巣門(すもん)・継箱(つぎばこ)・隔王板(かくおうばん)・燻煙器(くんえんき)・面布(めんぷ)・王台(おうだい)・王籠(おうかご)・移虫(いちゅう)・分蜂(ぶんぽう)・逃去(とうきょ)・建勢(けんせい)・内検(ないけん)・給餌(きゅうじ)・合同(ごうどう)・転飼(てんし)・腐蛆病(ふそびょう)・蜂球(ほうきゅう)・雄蜂(おばち。acceptedReadings に ゆうほう)・口吻(こうふん)・花粉荷(かふんか)・流蜜期(りゅうみつき)
- **journey**: 旅の id / **difficulty**: `1` 入門 / `2` 中級 / `3` 上級
- **field**: 学ぶ 分野。次の どれか: `生態` / `からだ` / `道具` / `飼育管理` / `蜜源` / `生産物` / `病気・害敵` / `繁殖` / `法律・しごと`
- **bee**: `西洋` / `日本` / `共通`(上の 4)
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。旅の 中で 4〜8種類)
- **emoji**: 1つ(💀 ☠️ 🩸 🔪 💉 は 使わない)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下)
- **relatedTerms**: **同じ 旅の ファイルの 中の** id を 1〜3個(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます(はじめから「〜です・ます」。体言止めで はじめない)。**語と 語の あいだに 半角スペース**(上の 例)。
  専門用語を 専門用語だけで 説明しない。「1人」「2人」は ふりがなが 読みまちがえるので ひとり・ふたり。「へえ」を 1文 入れると よい(「巣房が 六角形なのは、すきまなく ならべられて ろうが 少なくて すむから」)

## どの 語を どの 旅に 入れるか

**`tools/yoho/plan.json` が 正本**(はじめの 630語の 置き場所。足した 360語は `plan2.json`。読みの かぶり 0 で 決めてある)。書く 助手は plan の 語を **そのまま**(id・name・reading・difficulty・mapNode・field・bee・順番)使い、説明・category・emoji・relatedTerms を 書く。
どうしても あやしい 語(事実が 確かめられない・こわい・決まりに ふれる)は 同じ 旅・同じ difficulty の 別の 語に 入れかえて よい(読みが **9つの 旅の 中で かぶらない** ことを `--check` で 確かめる)。

## ぜったいに 守ること

- **自分の ことばで 書く**。法律・制度の 事実は `tools/yoho/exam.txt` に 合わせる
- 台本が 止める ことば(`terms_js.py` の `BAN` / `BAN_RE`)を 使わない
- 「100マス計算」「百ます計算」の 字を 使わない

## 出すもの

`tools/yoho/terms-<旅id>.json` に JSON の 配列(110語)で 書く。書いたら `python3 tools/yoho/terms_js.py --only <旅id>` で 形を 確かめる(まちがいが あれば 止まる)。
