## 🎯 なぜ 作るのか ─ 受験5科目の 穴を うめる

けいくんの ねらいは **「夢を かなえる ために 必要な 受験主要5科目」**。しらべたら こうだった(2026-09-29):

| 科目 | いまある ゲーム | ことばの数 | 足りているか |

| 国語 | フリック国語(9旅) | 690 | ✅ |
| 算数・数学 | フリック数学(7旅) | 520 | ✅ |
| 理科 | フリック理科(物理・化学・生物・地学) | 667 | ✅ |

社会は 3つに 分かれる。**足りないのは 公民と 地理**:

- **歴史** … ✅ 歴史旅行(`rekishi/`)に 487語。日本史 中心 + 世界史 少し
- **地理** … ⚠️ 世界旅行(`/`)は「世界の 名所 100」なので、**受験の 地理とは 別のもの**。
  都道府県・気候・農業・工業・貿易・地図の 読みかたが **1つも ない**
- **公民** … ❌ 憲法・三権分立・選挙・裁判・税金・社会保障・国連 … **まるごと ない**。
  公民は 中学3年で ぜんぶ 習って、入試にも 毎年 出る。**ここが いちばん 大きい 穴**

## 🕘 歴史の 旅は 作らない(でも ことばが かぶるのは よい)

- **歴史の 旅は 作らない**。歴史旅行(`rekishi/`)に もう 487語 あるので、同じ ものを もう一度 作る 必要は ない
- ⚠️ でも **公民・地理の 中に 歴史と 同じ ことばが 出るのは よい**(けいくん決定 2026-09-29。`CLAUDE.md`「ことばが かぶるのは よい(復習に なる)」)。
  例: 大日本帝国憲法・四大公害病・京都議定書 は 歴史旅行にも 出るが、**説明の 目線を 変える**:
  - 歴史旅行 …「いつ・だれが・なにが 起きたか」
