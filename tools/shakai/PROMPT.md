# フリック社会旅行: ことばの 作りかた(助手に 分けて 頼むときの 決まり)

ゲームは「表示された ひらがなを フリックで 打ち写す」タイピング。打ち終わると ことばの 説明(1〜3文)が 出る。
遊ぶのは 中学生〜高校生・大人。**高校受験・大学受験の 社会(公民・地理)で 要る 知識を おぼえる ゲーム**。
(けいくん 2026-09-29「すべておすすめで」: 名前「フリック社会」→ 絵の 題名に そろえて「フリック社会旅行」/ 7つの 旅 / 3段 / 領土は 島の 名前と 場所だけ / 日本地図に 📍)
⚠️ **歴史の 旅は 作らない**(歴史旅行 `rekishi/` が ある)。歴史と 同じ ことばが 出るのは よいが、説明は **「いまの しくみの どこに つながっているか」**の 目線で 書く。

## 1語の 形(JSON)
{"id":"ke-kokuminshuken","name":"国民主権","reading":"こくみんしゅけん","journey":"kenpo","category":"三大原則","difficulty":1,
 "type":"concept","emoji":"👥","relatedTerms":["ke-heiwashugi"],
 "description":"国の ことを 決める いちばん 上の 力は 国民が 持つ という 考えです。日本国憲法の 三つの 原則の 1つです。"}

- id: 旅の 頭文字 + "-" + 英小文字(ke- / se- / ki- / ko- / jp- / wo- / zu-)。英小文字・数字・- だけ。ぜんぶで かぶらない
- name: 画面に 出す 字(漢字・かな・カタカナ)。**打つ 字は 出さない**(name に ふりがなや かっこの 読みを 付けない)。
  英字の 略語(PKO・ODA・SDGs)は name に しない。name は 日本語の 正式な 言いかた(平和維持活動)にして、略語は 説明に 書く
- reading: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」「〜」は ダメ)。カタカナ語は ひらがなに(プランテーション → ぷらんてーしょん)。
  数字の 入る 語は 読みで(第9条 → だいきゅうじょう / 18歳選挙権 → じゅうはっさいせんきょけん)。
  ゆれる 読みは 1つに 決め、別の 読みは "acceptedReadings":["よみ1","よみ2"](先頭は reading と 同じ)。例: 日本銀行 = にっぽんぎんこう / にほんぎんこう
  ⚠️ 本当に どちらも 正しい ときだけ
- difficulty(どの 旅も 3段):
  - 1 = **入門**(中学の 基本。教科書の 太字)
  - 2 = **中級**(高校受験の めやす)
  - 3 = **上級**(大学受験 = 共通テスト・二次試験の めやす。高校の 公共・政治経済・地理総合・地理探究)
- 数: 下の 表。difficulty ごとに **同じ 数ずつ**。同じ difficulty の 中は よく 出る 順
- type: いつも "concept"
- category: 図鑑で しぼる 分類(短い 日本語。旅の 中で 3〜8種類)
- emoji: 1つ(国旗の 絵文字は 使わない)
- relatedTerms: **同じ ファイルの 中の** id を 1〜3個(自分は ダメ)。いっしょに おぼえると よい ことば(対に なる 語・同じ しくみ など)
- mapNode: **日本の地理(japan)だけ**。その ことばが 1つの 地方に 決まる ときだけ 書く(下の 地方)。決まらない 語(季節風・過疎 など)は 書かない。**ほかの 旅は 書かない**
- description: 1〜3文・**130字以内**。やさしい です・ます。「意味 / しくみの どこが 大事か」。
  語と 語の あいだに 半角スペースを 入れる 書きかた(この シリーズの 文体。上の 例のように)。
  ⚠️ **説明の 中に その 語の 読みを ひらがなで 書かない**(答えが 見えて しまう)
- example: なくてもよい(ある ときは 身近な 例 1つ。自分で 作った 文)

## ぜったいに 守ること
- **自分の ことばで 書く**。入試の 過去問・問題集・参考書・教科書・Wikipedia の 文を 写さない。統計の 表を のせない
- **事実は まちがいない ときだけ**(条文の 番号・年・数・名前)。あやしい 語は 入れない。説が 分かれる ものは「〜と 言われます」
- ⚠️ **古い しくみを いまの ことと して 書かない**(2026年9月の 時点):
  選挙権・成人年齢は 18歳 / 減反政策は 2018年に 終わった / 中国の 一人っ子政策は 終わった /
  京都議定書の あとに パリ協定(2015年)/ 地形図の 工場・桑畑・発電所の 記号などは 2万5千分の1で 使われなくなった(「使われなくなった」と 書く)/
  裁判員制度は 2009年から / 18歳・19歳は 特定少年 など
- ⚠️ **年で 変わる 数字(人口・生産量の 順位・%)は なるべく 出さない**。出すなら「およそ」と 書く
- ⚠️ **政治の 主張を 書かない**。「どの 政党が よい」「この 政策は 正しい / まちがい」は 書かない。制度の しくみと 決まっている 事実だけ。
  いま 意見が 分かれている こと(憲法改正・原発・死刑 など)は「〜という 意見と 〜という 意見が あります」の 形で、どちらにも かたよらない
- ⚠️ **領土**(北方領土・竹島・尖閣諸島)は **島の 名前と 場所だけ**。どちらの 国の ものか・だれが 正しいかは 書かない
- 税・お金の しくみは 説明して よい(社会の 勉強なので)。**お店・会社・商品の 名前は 使わない**
- 「合格できる」「共通テストに 出る」「かならず 出る」と 言いきらない。「受験で よく 見る」くらいに する
- 「100マス計算」「百ます計算」の 字は 使わない。人を 傷つける 言葉・差別の 言葉は 入れない
- **reading は 7つの 旅 ぜんぶで かぶらない**。同じ 語を 2つの 旅に 入れない(下の「入れる / 入れない」)

## 旅ごとに 入れる / 入れない
- kenpo: 憲法と 人権。**国会・内閣・裁判の しくみは seiji へ**(違憲審査権は seiji)
- seiji: 日本の 政治の しくみ。**国連・条約は kokusai へ**
- keizai: 経済と 社会保障・環境。**国と 国の 貿易の しくみ(自由貿易・保護貿易・WTO)は kokusai へ**。円高・円安は keizai
- kokusai: 国際政治と 地球の 課題。**国ごとの 気候・農業・資源は sekai へ**。領土の 島の 名前は japan へ(kokusai は「領土」「領海」など しくみの 用語だけ)
- japan: 日本の 地理だけ。**世界の 気候区分は sekai へ**
- sekai: 世界の 地理だけ。**地図の 図法・記号は chizu へ**。時差・日付変更線は sekai
- chizu: 地図の 読みかたと 道具。緯度・経度そのものは sekai、**地図記号・等高線・縮尺・図法は chizu**

## 出すもの
`tools/shakai/terms-<journey>.json` に JSON の 配列で 書く。書いたら
`python3 tools/shakai/terms_js.py --only <journey>` で 形を 確かめる(❌ が 出たら 直す。⚠️ も できるだけ 直す)
