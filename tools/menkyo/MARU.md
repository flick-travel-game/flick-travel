# フリック自動車運転免許: ⭕❌ もんだいの 作りかた

本物の 学科試験は ぜんぶ「文を 読んで 正しければ ⭕・まちがいなら ❌」(仮免 50問・本免 95問)。**90点 以上で 合格 = 1割しか まちがえられない**。
合否を 分けるのは **言いまわしの ひっかけ**。この ゲームで それを 練習する。**約1,200問**(9つの 旅 × 約130問)。

## 決まり
1. `PROMPT.md` の「いちばん 大事な 決まり」を ぜんぶ 守る(数字は facts.md / 法律で 確かめた ものだけ・こわく しない・2026年の 改正が いまの 答え)
2. **答えが 1つに 決まる 文**だけ。地域や 場合で 答えが 変わる 文・あいまいな 文は 作らない
3. **⭕ と ❌ は おおよそ 半分ずつ**(各旅 ⭕ 45〜55%)
4. **ひっかけを 多く**(上級は とくに): 「かならず」「すべて」「どんな ときでも」「〜しなければ ならない」「〜しても よい」「◯m 以内 / 以上」「徐行 / 一時停止」「追い越し / 追い抜き」「駐車 / 停車」「歩道 / 路側帯」「警音器を 鳴らす / 鳴らさない」「青 / 青の 矢印」「黄の 点滅 / 赤の 点滅」
   ❌ の 文は **本物らしく 少しだけ ちがう**(数字を 1つ 変える・例外を 消す・主語を 入れかえる)
5. **とき方**(`why`): なぜ ⭕/❌ か 1〜2文・**90字 以内**。❌ なら 正しい 形を 書く。やさしい です・ます
6. 問題文(`q`): **70字 以内**。「です・ます」でなく 試験と 同じ「〜する。」「〜してよい。」「〜しなければならない。」の 形で よい(漢字は ふつうに 使う)
7. 同じ ことを 聞く 問題を 2つ 作らない(同じ 事実の ⭕版と ❌版も 作らない)
8. 問題集・教本・過去問の 文を 写さない。自分の ことばで
9. `dv`: 1 = 入門(小学生にも わかる 歩行者・自転車の きまり。各旅 15問ほど)/ 2 = 仮免の 範囲(各旅 50問ほど)/ 3 = 本免の 範囲(各旅 65問ほど)
10. `term`: その 問題に いちばん かかわる ことばの id(`terms-<旅>.json` に ある もの。無ければ 書かない)
