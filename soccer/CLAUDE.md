## フリックワールドサッカー(`soccer/`。けいくん 2026-10-09「ワールドサッカーの専門家(解説者)になれるレベルになるために必要な 知識、主要サッカーリーグ、有名サッカー選手、有名なドリブル技(シャペウ、ルーレットなど)、ルールをフリック形式の問題にしてください」→ 5つの 問いと「いまの スター選手は クラブ名を 書かない」に「全部おすすめで」。まとめは `docs/フリックワールドサッカー-はじめかた.md`)

- 名前は「フリックワールドサッカー」(絵が 届いたら 題名に そろえる。フォルダ名 `soccer` は 変えない)。シリーズの 絵文字は ⚽。`SERIES_ORDER` は **世界旅行の となり**
- 旅は 9つ(サッカーのきほん `kihon`・ルール `rule`・世界のリーグと大会 `league`・名門クラブとダービー `club`・いまのスター選手 `star`・伝説の選手 `legend`・ドリブルとテクニック `dribble`・戦術と解説のことば `tactic`・ワールドカップと代表 `cup`)+ マスター。
  **旅ごとに 70語(入門20・中級25・上級25)= 630語**。かずともの 旅の 名前は **`ws` で はじめる**(wskihon / wsrule / wsleague / wsclub / wsstar / wslegend / wsdribble / wstactic / wscup / wsmas。speed-king #368 で 足した)
- むずかしさは 3段: 入門(**サッカーが すきな 小学生**)→ 中級(**少年団の コーチ = 4級審判の 範囲の めやす**)→ 上級(**解説者**)。1語ごとに **学ぶ 分野**(`field`)6つ: ルール / 技術 / 戦術 / リーグ・クラブ / 選手 / 大会・歴史
- ⭐ **国旗の 札**(`country` の 欄 → terms.js の `co`): 世界・ヨーロッパ・南アメリカ・アジア・アフリカ・北中米 と 国 53(`terms_js.py` の `COUNTRY`。「・」で 3つまで)。
  ⚠️ **イギリスは 使わない**(サッカーでは イングランド・スコットランド・ウェールズ・北アイルランドが 別の 代表 = へえ)。図鑑は **🌍 国・地域で しぼれる**(`soccer.js` の `countryTag` / `CO_ICON`)
- ことばは `tools/soccer/terms-<旅>.json`(決まりは `tools/soccer/PROMPT.md`。**どの 語を どの 旅に 入れるかの 一覧**も ここ)→ `tools/soccer/terms_js.py` → `soccer/terms.js` + `data/soccer.json`。
  しくみは `soccer/soccer.js`(歯科医師を 写して 🦷 を 国旗に した。4択クイズ あり)。しくみ図は コードで 描く 箱の 図 9つ(`tools/soccer/mkmeta.py`): **ピッチと ポジション**・**競技規則の 地図**・世界の リーグの 地図・名門クラブの 町・いまの スターの ピッチ・伝説の 選手の 殿堂・**ドリブルと テクニックの 道**・**戦術ボード**・ワールドカップと 代表の 地図
- 事実は `tools/soccer/exam.txt`(→ meta.json の `exam`。meta に `rulesVersion` / `checkedOn` / `reviewEvery` も):
  **ルールは IFAB 競技規則 2026/27(JFA サッカー競技規則 2026/27)で 確かめた(2026年10月10日)**。17条の 名前 / GK の 8秒(→ 相手の CK)/ 2026/27 の 5秒の カウントダウン・交代の 10秒・手当ての あと 1分・VAR の 見なおしの ひろがり。
  ワールドカップ 1930〜2026 の 優勝国と 開催国(**2026年は スペインが 2回目の 優勝。決勝 7月19日 アルゼンチンに 1-0(延長)**)/ 女子 W杯 / ユーロ・コパ・アジアカップ / AFCON 2025 = セネガル / バロンドール(2025 = デンベレ・ボンマティ。**2026年は 10月26日 発表**)
- ⚠️⚠️⚠️ **数字が 変わる ものを 書かない**: いまの 所属クラブ・年俸・移籍金・いまの 順位・通算ゴール数・年齢(台本 `BAN` / `BAN_RE`)。
  **いまの スター選手(`star`)は クラブ名・所属・移籍を 書かない**(`STAR_BAN` が クラブの 名前ごと 止める)。「◯◯代表の FW。〜が 武器」と 代表の 国・ポジション・プレーの 特徴・代表での 大会・受賞と 年で 書く

  **ドリブル技は「練習で 身に つける 技」**・技の 名前の もとは「◯◯の 得意技として 有名」まで(説が 分かれる)
