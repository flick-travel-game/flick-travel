## B-1. 労働者災害補償保険法(労災)

### 適用(適用事業・暫定任意適用)
| 事実 | 出どころ |
|---|---|
| **労働者を 使用する 事業**は 適用事業(1人でも)。ただし **国の 直営事業** と **官公署の 事業**(労基法 別表第一の 事業を 除く)には 適用しない | 労災法3①② |
| **暫定任意適用事業** = 個人経営で **常時5人以上の 労働者を 使用する 事業 以外**(= 5人未満)の **農林の 事業**・**畜産・養蚕・水産の 事業**。都道府県・市町村 などの 事業・**法人**の 事業・船員を 使う 船舶所有者の 事業・業務災害の おそれが 多いとして 大臣が 定める 事業は 除く | 整備政令17 |
| 暫定任意適用事業は 事業主が **加入の 申請 → 厚生労働大臣の 認可** が あった 日に 労災の 保険関係が 成立。**労働者の 過半数が 希望** するときは 申請 **しなければ ならない** | 整備法5①② |
| 暫定任意適用で 加入した 保険関係の 消滅(脱退)の 申請は **労働者の 過半数の 同意** + **成立から 1年を 経過** していること(特別保険料の 期間の 条件も ある)。認可の **翌日** に 消滅 | 整備法8①② |
| 労災の 保険関係は 事業が **開始された 日** に 成立する(届出は 10日以内。B-3) | 徴収法3 |

### 業務災害・複数業務要因災害・通勤災害
| 事実 | 出どころ |
|---|---|
| 保険給付は 4つ: **業務災害**(業務上の 負傷・疾病・障害・死亡)/ **複数業務要因災害**(複数事業労働者の 2以上の 事業の 業務を 要因と する もの)/ **通勤災害** / **二次健康診断等給付** | 労災法7① |
| **通勤** = 就業に 関し、①**住居と 就業の場所の 往復** ②**就業の場所から 他の 就業の場所への 移動** ③①に 先行・後続する **住居間の 移動**(単身赴任 など 省令の 要件)を **合理的な 経路 及び 方法** で 行うこと。**業務の 性質を 有するものは 除く** | 労災法7② |
| **逸脱・中断** した ときは その **間 と その後** の 移動は 通勤と しない。ただし **日常生活上 必要な 行為**(省令)を **やむを得ない 事由** で 行う **最小限度** の ものは、**逸脱・中断の 間を 除き** 通勤と する | 労災法7③ |
| 日常生活上 必要な 行為(5つ): ①**日用品の 購入** その他 これに 準ずる 行為 ②**職業訓練・学校教育** など 職業能力の 開発向上に 資する 教育訓練を 受ける 行為 ③**選挙権の 行使** など ④**病院・診療所で 診察・治療** を 受ける こと など ⑤**要介護状態の 配偶者・子・父母・孫・祖父母・兄弟姉妹・配偶者の 父母の 介護**(継続的・反復して 行う もの) | 労災則8 |
| ②の「他の 就業の場所」= 労災の 適用事業(暫定任意適用で 保険関係が 成立している 事業 を 含む)・特別加入者の 就業の場所 など | 労災則6 |
| ③の 住居間の 移動は **転任** に 伴い **配偶者**(要介護の 家族の 介護・子の 学校 など やむを得ない 事情)・**子**(配偶者が ない とき)・**要介護の 父母 や 親族** と 別居する ことに なった 労働者 など | 労災則7 |

### 保険給付の 種類(業務災害 / 複数業務要因災害 / 通勤災害)
| 事実 | 出どころ |
|---|---|
| 業務災害の 給付 7つ: **療養補償給付・休業補償給付・障害補償給付・遺族補償給付・葬祭料・傷病補償年金・介護補償給付**(「補償」が つく。葬祭は「葬祭料」) | 労災法12の8① |
| 複数業務要因災害の 給付 7つ: **複数事業労働者 療養給付・休業給付・障害給付・遺族給付・葬祭給付・傷病年金・介護給付** | 労災法20の2 |
| 通勤災害の 給付 7つ: **療養給付・休業給付・障害給付・遺族給付・葬祭給付・傷病年金・介護給付**(「補償」が つかない) | 労災法21 |
| 療養補償給付は **療養の給付**(現物)が 原則。範囲は 診察・薬剤 又は 治療材料・処置 手術・居宅の 看護・入院 と 看護・**移送**。療養の 給付が 困難な とき などは **療養の費用** を 支給できる | 労災法13 |
| 通勤災害の 療養給付を 受ける 労働者から **一部負担金 200円**(日雇特例被保険者は 100円)を 徴収。**第三者の 行為** による 事故・**療養開始後 3日以内に 死亡** した 者 など **休業給付を 受けない 者**・同じ 通勤災害で 納付ずみの 者 は 除く。休業給付から 控除できる | 労災法31②③・労災則44の2 |
| 年金たる 保険給付は 支給事由が 生じた 月の **翌月から** 権利が 消滅した 月 まで。支払期月は **2月・4月・6月・8月・10月・12月** の 年6回(前月分 まで) | 労災法9①③ |

### 休業(補償)給付・休業特別支給金
| 事実 | 出どころ |
|---|---|
| 休業補償給付は 療養の ため 労働できず 賃金を 受けない 日の **第4日目から**(= **待期 3日**)、**1日に つき 給付基礎日額の 100分の60** | 労災法14① |
| 一部だけ 労働した 日(部分算定日)は 給付基礎日額 から その日の 賃金を 引いた 額の 100分の60 | 労災法14①ただし書 |
| **刑事施設 などに 拘禁** されている とき・**少年院 などに 収容** されている とき(省令の 場合)は 休業補償給付を 行わない | 労災法14の2 |
| **休業特別支給金** = 第4日目から、**1日に つき 休業給付基礎日額の 100分の20**(社会復帰促進等事業として 支給)。申請は 対象日の 翌日から **2年以内**。休業(補償)給付の 請求と **同時に** 行う | 特支則3①⑤⑥ |
| 傷病(補償)年金を 受ける 者には 休業(補償)給付を 行わない | 労災法18② |
| ⚠️ 待期 3日間は 業務災害なら **労基法の 休業補償**(平均賃金の 60%。使用者)で うめる(労基法76。A-1 の 表) | 労災法12の8②(労基法76条の 事由) |

| 一時金の 日数: **8級 503日・9級 391日・10級 302日・11級 223日・12級 156日・13級 101日・14級 56日** | 労災法 別表第二 |
| 障害の 程度が 変わって 他の 等級に 該当した ときは 新しい 等級の 年金 又は 一時金(**変更は 年金の 受給者に ついて**) | 労災法15の2 |
| **障害特別支給金**(一時金): 1級 **342万円**・2級 320万・3級 300万・4級 264万・5級 225万・6級 192万・7級 159万・8級 65万・9級 50万・10級 39万・11級 29万・12級 20万・13級 14万・14級 **8万円**。申請は 治った 日の 翌日から **5年以内** | 特支則4・別表第一 |

### 遺族(補償)給付
| 事実 | 出どころ |
|---|---|
| 遺族補償給付は **遺族補償年金 又は 遺族補償一時金** | 労災法16 |
| 年金の 受給資格者 = 配偶者・子・父母・孫・祖父母・兄弟姉妹 で 死亡の 当時 **その 収入で 生計を 維持** していた 者。**妻 以外** は 要件が ある: **夫・父母・祖父母 = 60歳以上** / **子・孫 = 18歳に 達する 日 以後の 最初の 3月31日 まで** / **兄弟姉妹 = 18歳年度末 まで 又は 60歳以上** / それ以外でも **障害の 状態**(省令) | 労災法16の2① |
| 受ける 順位: **配偶者 → 子 → 父母 → 孫 → 祖父母 → 兄弟姉妹** | 労災法16の2③ |
| 死亡の 当時 **胎児** だった 子が 生まれた ときは 将来に 向かって 生計維持の 子と みなす | 労災法16の2② |
| 年金の 日数は 受給権者 と 生計を 同じく する 受給資格者の **人数** で: **1人 153日**(**55歳以上の 妻 又は 障害の 状態の 妻 は 175日**)・**2人 201日・3人 223日・4人以上 245日** | 労災法 別表第一 |
| 受給権者が 2人以上の ときは 人数で 割る。人数が 増減した ときは **翌月から** 額を 改定。妻が 55歳に なった ときなども 翌月から 改定 | 労災法16の3②〜④ |
| 権利の 消滅: **死亡**・**婚姻**(事実婚 を 含む)・直系血族 又は 直系姻族 以外の 者の **養子** に なった・**離縁**・子 孫 兄弟姉妹が **18歳年度末を 過ぎた**(障害の 状態を 除く)・障害の 事情が なくなった。⚠️ 同順位者が なくて 後順位者が いる ときは **次順位者に 支給(転給)** | 労災法16の4① |
| 当分の間の 特例: 死亡の 当時 **55歳以上 60歳未満** の 夫・父母・祖父母・兄弟姉妹 も 受給資格者。**60歳に 達する 月 まで 支給停止**(若年停止)。順位は 本来の 遺族の 次で、その 中は 夫 → 父母 → 祖父母 → 兄弟姉妹 | 昭和40年法律第130号 附則43①〜③(e-Gov の 労災法の 附則の 中) |
| **遺族補償一時金** は ①死亡の 当時 **年金を 受ける 遺族が いない** とき ②年金の 権利が 消滅して ほかに 受ける 遺族が なく、支給ずみの 年金の 合計が 一時金の 額に 満たない とき | 労災法16の6① |
| 一時金の 額: ①の とき **給付基礎日額の 1,000日分** / ②の とき 1,000日分 から 支給ずみの 年金の 合計を 引いた 額 | 労災法 別表第二 |
| 一時金の 順位: **①配偶者 ②生計維持の 子・父母・孫・祖父母 ③それ以外の 子・父母・孫・祖父母 と 兄弟姉妹**(②③の 中は その 順) | 労災法16の7 |
| 労働者を **故意に 死亡** させた 者は 遺族補償給付を 受ける 遺族と しない(先順位・同順位の 遺族を 故意に 死亡させた 者 も) | 労災法16の9 |
| **遺族特別支給金 300万円**(2人以上は 人数で 割る)。申請は 死亡の 日の 翌日から **5年以内** | 特支則5③⑧ |

### 葬祭料・傷病(補償)年金・介護(補償)給付
| 事実 | 出どころ |
|---|---|
| 葬祭料 = **33万円 + 給付基礎日額の 30日分**。それが **60日分に 満たない ときは 60日分** | 労災法17・労災則17 |
| **傷病補償年金** = 療養の 開始後 **1年6か月を 経過した 日** に(又は その後に)①**治っていない** ②障害の 程度が **傷病等級(1〜3級)** に 該当 の 両方に あてはまる とき、その 状態が 続く 間 | 労災法12の8③ |

| **延納**(継続事業): 概算保険料が **40万円 以上**(労災 又は 雇用の **片方 だけ** の 事業は **20万円 以上**)か **労働保険事務組合に 委託** して いる とき。**10月1日 以降に 成立** した ものは 除く。**3回**(4/1〜7/31・8/1〜11/30・12/1〜翌3/31)に 分ける | 徴収則27① |

### 労働保険事務組合
| 事実 | 出どころ |
|---|---|
| 事業協同組合 など の **事業主の 団体**(代表者の 定めが ない 法人でない 団体を 除く)が **厚生労働大臣の 認可** を 受けて、事業主の 委託で 保険料の 納付 など の 労働保険事務を 処理 | 徴収法33①② |

| 業務を **廃止** する ときは **60日前** までに 大臣に 届け出る。法令違反 などで **認可の 取消し** が ある | 徴収法33③④ |

| 事務組合は 帳簿(労働保険事務の 事項)を 事務所に 備える | 徴収法36 |

### 追徴金・督促・延滞金・時効
| 事実 | 出どころ |
|---|---|
| **追徴金** = 確定保険料の **認定決定** で 納付する 額(**1,000円 未満 切捨て**)の **100分の10**。**天災 など やむを得ない 理由** の とき と **1,000円 未満** の とき は 徴収しない | 徴収法21①② |
| ⚠️ 追徴金は **確定保険料**(19条5項)の 認定決定 だけ。**概算保険料の 認定決定 には 追徴金は ない** | 徴収法21①(19条5項 だけを 指す) |
| **督促**: 期限を 指定して **督促状**。指定する 期限は 督促状を 発する 日から **10日以上 経過した 日**。期限 までに 納めなければ **国税滞納処分の 例** で 処分 | 徴収法27①〜③ |
| **延滞金**(法の 字): 納期限の 翌日から 完納 又は 差押えの 日の 前日 まで、**年14.6%**(納期限の 翌日から **2か月** は **年7.3%**)。保険料が **1,000円 未満** なら 徴収しない。延滞金が **100円 未満** なら 徴収しない | 徴収法28①⑤三 |
| 延滞金の 割合の 特例(当分の間): **延滞税特例基準割合** が 7.3% に 満たない 年は、14.6% → 特例基準割合 + **7.3%** / 7.3% → 特例基準割合 + **1%**(7.3% が 上限) | 徴収法 附則12 |
| 延滞金を 徴収しない とき: **督促状の 期限まで に 完納**・**公示送達** で 督促・延滞金 **100円 未満**・滞納処分の 執行停止 又は 猶予(その 期間分)・**やむを得ない 理由** | 徴収法28⑤ |
| 徴収金の 先取特権の 順位は **国税 及び 地方税 に 次ぐ** | 徴収法29 |
| 労働保険料 その他の 徴収金を 徴収し、又は **還付を 受ける 権利** は **2年** で 時効。政府の **徴収の 告知 又は 督促** は **時効の 更新** の 効力 | 徴収法41①② |
| 被保険者の 負担(雇用保険分): (雇用保険率の 部分 − 二事業の 部分)の **2分の1**。事業主は 賃金から **控除できる**(控除の 計算書を 作り 知らせる)| 徴収法31①・32① |
| 徴収法の 処分には 行政手続法の 第2章・第3章を 適用しない(事務組合の 認可 と その 取消し を 除く) | 徴収法37 |
