## 3. ⚠️⚠️⚠️ ぜったいの 決まり(試験の 兄弟と 同じ。災害の 話は なおさら)
- ⭐⭐ **災害を こわく しない**: 台風・豪雨・竜巻・なだれは「**どう 起きるか**」と「**どう 身を 守るか**」だけ。**被害の ようす・人が 亡くなる 話・泣いている 人の 話は 書かない**(台本で「死」「死者」「遺体」「犠牲」「惨」を 止める)。「早めに 逃げれば 守れる」の 形で 終わる
- ⭐ **数字は「変わらない 自然の 決まり」だけ 書いて よい**: 1気圧 ≒ 1013hPa・気温減率 およそ 6.5℃/km・乾燥断熱減率 およそ 10℃/km・対流圏は およそ 11km まで、など **物理の 数**は よい(⚠️ 1つずつ 確かめる。「およそ」を 付ける)。
  ❌ **変わる 数字は 書かない**: 地域ごとの 警報の 基準・いまの 気候の 記録・猛暑日の 日数・台風の 年間の 数・試験の 合格率(**`meta.json` に 確かめた 日つきで 入れる ときだけ**)
- ⭐ **試験の 科目が 3つ ある**(学科一般・学科専門・実技)。**どの 科目の 話か `ruleset` の 札で 分ける**。⚠️ 出題範囲・試験の 形(問題数・時間・合格基準)は **その年の 版を 確かめて から**。`meta.json` に「気象業務支援センターの ◯年の 案内で 確かめた」と 書く
- **計算の 公式は 読みあげで 打つ**(数学ゲームと 同じ 型。読みかたの きまりは `tools/sugaku/PROMPT.md`)。式は **試験で 本当に 使う もの**だけ(静力学平衡・気温減率・コリオリ力・地衡風・温位)。**数字の 代入・計算問題は 入れない**(ことばの ゲームなので)
- ✅ **実在の 道具・衛星・制度の 名前は 入れて よい**(アメダス・ひまわり・キキクル・気象庁)。❌ **民間の 気象会社・天気アプリ・気象キャスターの 名前は 入れない**。人の 名前は **歴史として**(渋川春海・岡田武松・中谷宇吉郎・藤田哲也(藤田スケール。確かめる))
- **気象庁の ことばづかいに そろえる**(「大雨警報」「線状降水帯」「キキクル」「警戒レベル」「早期注意報」など **気象庁の 公式の 名前**)。⚠️ 名前が 変わった もの(「避難勧告」→ 2021年から「避難指示」に 一本化 など。確かめる)は **いまの 名前を 答えに**、古い 名前は `alias` と 説明の 中に
- **小学生も あそぶ**: 血・けが・人の 死・こわい 先を 書かない。**迷ったら 入れない**
