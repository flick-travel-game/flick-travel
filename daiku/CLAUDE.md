## フリック大工(`daiku/`。けいくん 2026-10-03「大工の専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」。まとめは `docs/フリック大工-はじめかた.md`)

- 名前は「フリック大工」(絵が 届いたら 題名に そろえる。フォルダ名 `daiku` は 変えない)。シリーズの 絵文字は 🪚。`SERIES_ORDER` は **整備士の となり**
- 旅は 8つ(家づくりのきほん `kihon`・木と材料 `ki`・道具 `dogu`・家のしくみ `kozo`・継手と仕口・墨付け `tsugite`・内装と仕上げ `shiage`・大工の種類 `shurui`・大工の歴史と伝統 `rekishi`)+ マスター。
  **旅ごとに 70語(入門20・中級25・上級25)= 560語**。かずともの 旅の 名前は **`dk` で はじめる**(dkkihon / dkki / dkdogu / dkkozo / dktsugite / dkshiage / dkshurui / dkrekishi / dkmas)。
  ⚠️ 恐竜図鑑の `dkaseki`(d + kaseki)とは 別の 字。作る 前に ぶつからない ことを 確かめた
- むずかしさは 3段: 入門(家や 道具で 聞く ことば)→ 中級(**建築大工技能士 2級・3級の 範囲の めやす**)→ 上級(**建築大工技能士 1級・二級建築士の 構造の 範囲の めやす**)。
  1語ごとに **学ぶ 分野**(`field`)8つ: 建築一般 / 木材 / 道具 / 構造 / 規矩・墨付け / 造作・仕上げ / 安全 / 歴史(建築大工技能検定の 学科の 科目 = 建築構造・規矩術・施工法・材料・製図・関係法規・安全衛生 を めやすに した)
- ことばは `tools/daiku/terms-<旅>.json`(決まりは `tools/daiku/PROMPT.md`)→ `tools/daiku/terms_js.py` → `daiku/terms.js` + `data/daiku.json`。
  しくみは `daiku/daiku.js`(投資家を 写した。4択クイズ あり。クイズの 文は「道具の 使いかたや 作業の 手順では ありません」)。
  しくみ図は コードで 描く 箱の 図 8つ(`tools/daiku/mkmeta.py`): **家が できるまでの 流れ(大工・棟梁・工務店 → 設計 → 地鎮祭 → 基礎工事 → 建て方 → 上棟 → 内装 → 引き渡し)**・木と 材料・**道具箱**・
  **家の 骨組みの 断面図(屋根 → 棟木と 垂木 → 小屋組 → 梁と 桁 → 柱 → 壁と 筋かい → 床組 → 土台 → 基礎)**・**継手と 仕口**・内装と 仕上げ・大工と 職人・歴史と 伝統
- 資格の 事実は `tools/daiku/exam.txt`(→ meta.json の `exam`)に **確かめた日つき**(2026年10月2日):
  建築大工技能士(技能検定 = 国家検定。1級・2級・3級(と 基礎級)。学科と 実技。問題は 中央職業能力開発協会・試験は 都道府県職業能力開発協会。受検資格は 実務経験などで 決まる)/
  大工に なる 道(見習い・職業能力開発校・専門学校・工業高校の 建築科)/ 建築士(二級・木造は 都道府県知事、一級は 国土交通大臣の 免許)/ 建築基準法 1950年 /
  伝統建築工匠の技 = ユネスコ無形文化遺産 2020年12月。学科の 科目は 厚生労働省「建築大工技能検定試験の試験科目及びその範囲並びにその細目」(令和2年2月)で 見た。
  ⚠️「専門家に なれる レベル」は **建築大工技能士 1級の 学科の 範囲の ことばを ひととおり 知っている** めやす
- ⚠️⚠️⚠️ **道具の 使いかた・作業の 手順・刻みかた・墨の 付けかたを 書かない**。書くのは「何を さすか・何の ための 道具や 部材か・家の どこに あるか」だけ。
  刃物・電動工具・木工機械の 説明には **「おとなの 大工さんが 使う 道具です」**。台本が「ひきかた・切りかた・削りかた・研ぎかた・打ちかた・使いかた」を 止める
- ⚠️⚠️ **小学生も あそぶ**: けが・事故・落ちる・切る ようす・死・血・「命に かかわる」は 台本が 止める。安全の 道具は「みんなで 安全を 守る しくみ」。
  「墜落」の 字は **「墜落制止用器具」の 名前の 中だけ**(台本が 見る)。そのため **死節**・**地獄ほぞ** は 入れていない
- ⚠️⚠️ **寸法・強さ・値段の 数字を 書かない**(mm・cm・kg・kN・円・%・割・倍 を 台本が 止める)。単位は 名前と 単位どうしの 関係だけ(「1間は 6尺で、約1.8m」「10寸で 1尺」)
- ⚠️ **実在の 工務店・ハウスメーカー・ゼネコン・道具メーカー・お店の 名前を 書かない**(台本が 止める。金剛組 も)。人物は 亡くなった 歴史上の 人だけ
  (千利休・聖徳太子・西岡常一・中井正清・重源)。左甚五郎・聖徳太子と 大工の 守り神の 話は **言い伝え**と 書いた。宗教の よしあしは 書かない
- ✅ 整備士・社会・理科 など ほかの ゲームと 同じ 語を 入れて よい。読みは **大工の 8つの 旅の 中で** かぶらない(`terms_js.py` が 止める)。
  書く 途中で かぶった 2つ: 通り芯(kihon と tsugite → tsugite は「大入れ蟻掛け」に)/ ちょうげん(継手の 長玄 と 歴史の 重源 → 長玄を「表目」に)。桐は 錐(きり)と かぶるので 入れていない
- 作った 助手(4人・2つずつ)とは **別の 助手(4人)が 1語ずつ 確かめた**。差しかえは 2語(長玄 → 表目 / 尻挟み継ぎ → 丸目。尻挟み継ぎは 中身も 読みも 確かめられなかった)。おもな 直し:
  匠明(1608年に 平内家が まとめ、のちに 幕府の 大工棟梁の 家に 伝わった)・正倉院(もとは 東大寺の くら)・堂宮大工(宮大工の べつの よび名)・出雲大社(いずもおおやしろ)・
  剛床(根太の ある 剛床も ある)・鴨居(戸を「支える」→「みちびく」)・平勾配・返し勾配・裏目の 説明・米松(マツ属では ない)・釘抜き(使いかたに 近い 文を しくみの 説明に)
