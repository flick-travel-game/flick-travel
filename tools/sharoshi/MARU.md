# フリック社労士: ⭕❌ 一問一答の 作りかた

本物の 社労士試験の 択一式は **5つから 1つ えらぶ 70問・210分**。5つの 文の 正しい / まちがいを 見分けられれば 解ける。
この ゲームでは 1つの 文ずつ ⭕❌ で 練習し、🎯 模擬試験では ⭕❌ の 文を 同じ 科目から 5つ ならべて「正しい(誤っている)ものは どれか」の 5択に する。
合否を 分けるのは **数字**(日数・年数・%・人数)と **似た 制度の 区別**。**約1,300問**。

## 旅ごとの 問題数
roki 150 / anei 100 / rosai 130 / koyo 130 / choshu 100 / roichi 130 / shaichi 120 / kenpo 150 / kosei 150 / kokunen 140(= 1,300)

## 決まり
1. `PROMPT.md` の「いちばん 大事な 決まり」を ぜんぶ 守る(数字は facts の ものだけ・いまの 法令が 答え・こわく しない・実在の 会社を 書かない・過去問を 写さない)
2. **答えが 1つに 決まる 文**だけ。判例・通達で 説が 分かれる 文は 作らない(条文で 決まる ことを 中心に)。主語(使用者・労働者・常時10人以上の 使用者 など)を はっきり
3. **⭕ と ❌ は おおよそ 半分ずつ**(各旅 ⭕ 40〜60%)
4. **ひっかけを 多く**(上級は とくに): 「30日前 / 30日分」「14日以内 / 7日以内」「6時間を こえる / 6時間以上」「45分 / 1時間」「意見を 聴く / 同意を 得る」「届出 / 許可 / 認定」「労使協定 / 就業規則 / 労使委員会の 決議(5分の4)」「5年(当分 3年)/ 2年」「2割5分 / 3割5分 / 5割」「請求したら / 請求が なくても」「行政官庁 / 所轄労働基準監督署長」
   ❌ の 文は **本物らしく 少しだけ ちがう**(数字を 1つ 変える・例外を 消す・主語を 入れかえる・要件を 1つ 足す / 消す)
5. **とき方**(`why`): なぜ ⭕/❌ か 1〜2文・**90字 以内**。❌ なら 正しい 形を 書く。やさしい です・ます
6. **どの 条か**(`law`): 「労基法20条」「労基則5条」の ように。**facts に ある 条だけ**
7. 問題文(`q`): **80字 以内**。試験と 同じ「〜しなければならない。」「〜できる。」の 形で よい(漢字は ふつうに 使う)
8. 同じ ことを 聞く 問題を 2つ 作らない(同じ 事実の ⭕版と ❌版も 作らない)
9. **過去問・問題集・テキストの 文を 写さない**。自分の ことばで
10. `dv`: 1 = 入門(各旅 10問ほど)/ 2 = 中級 / 3 = 上級。上級を 半分 以上
11. `term`: その 問題に いちばん かかわる ことばの id(`terms-<旅>.json` に ある もの。無ければ 書かない)
12. `rs`: 科目。roki・anei = 労基・安衛 / rosai = 労災 / koyo = 雇用 / choshu = 徴収 / roichi = 労一 / shaichi = 社一 / kenpo = 健保 / kosei = 厚年 / kokunen = 国年

## 形(JSON。`tools/sharoshi/maru-<旅>.json` に 配列で)
{"id":"rk-m001","q":"使用者は、労働者を解雇しようとする場合、少なくとも30日前にその予告をしなければならない。","a":true,
 "why":"解雇予告は 少なくとも 30日前。予告しない ときは 30日分 以上の 平均賃金を 払います。","law":"労基法20条","dv":1,"term":"rk-kaikoyokoku","rs":"労基・安衛"}
- id: 旅の 頭文字 + "-m" + 3けた(rk / an / rs / ko / ch / ri / si / kp / ks / kn)
- a: true = ⭕ / false = ❌
- 確かめは `python3 tools/sharoshi/maru_check.py`
