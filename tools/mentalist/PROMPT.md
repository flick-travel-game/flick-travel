# フリックメンタリスト: ことばの 作りかた(助手に 分けて 頼むときの 決まり)

けいくん 2026-10-23「**世界トップレベルのメンタリスト**になるために必要な知識をフリック形式の問題にしてください」→ 同日「**メンタリストになれるように 実践的にしてほしい**」→ 5つの 問いに「全部おすすめで」(名前 フリックメンタリスト・旅 9つ + マスター・約1,000語・並びは アドラー心理学の あと)。
まとめは `docs/フリックメンタリスト-はじめかた.md`。もとは `tools/shinri/PROMPT.md`(心理学)・`tools/manner/PROMPT.md`(マナー)・`tools/cabin/PROMPT.md`(しくみ)

## ⚠️⚠️⚠️ いちばん 大事な 4つの 決まり(さいしょに 読む)
1. **メンタリストは「超能力者」では ない**。心理学・観察・記憶・話しかた・数学を つかって、**こころを 読んだ ように 見せる 芸(パフォーマンス)**。
   「本当に こころが 読める」「未来が 見える」「霊が」とは **1度も 書かない**。書くのは「〜のように 見せる」「〜と 感じさせる」「〜と 感じやすい」
2. **人を あやつる 道具に しない**。「相手に 気づかれずに 〜させる」「買わせる」「うそを 見ぬいて 追いつめる」は 書かない。
   向きは **「おどろかせて 楽しませる」「相手を よく 見て 大切に する」**。⭐ **同意(やってもいい? / いやなら やめる)が いちばん 大事な ことば**
3. **「教えて よい もの」と「明かさない もの」の 線**:
   - ✅ 手順まで 書いて よい: **数学の 性質**(1089・魔方陣・カレンダー・曜日・サイコロ・2進数)/ **記憶の 技**(記憶の 宮殿・ペグ法・チャンキング …)/
     **心理の 傾向**(心理学の 本に 載っている 範囲。多くの 人が えらびやすい 答え)/ **コールドリーディングの 型**(科学の 本で 公開されている もの)/ **観察・話しかた・舞台の 技**
   - ❌ 書かない: **道具の しかけ(ギミック・仕込みの カード・のぞき見の 道具・仕込みの 協力者)**・**特定の 人や 商品の 演目の たね**・**カードの 並べかたの しかけ(スタック)の 中身**。
     迷ったら「心理学・数学の 本に 載っているか」で 決める(載っていれば 書いて よい)
4. **「体の 動きで うそが 分かる」と 書かない**。腕組み・目の 動き・しぐさで うそを 見ぬける は **科学では 支持されていない**(研究では 当たる 率は ほぼ 半分)。
   しぐさ・表情の 語は「よく 言われるが、科学では 支持されていない / 研究中」を **セットで** 書く

## そのほかの 決まり
5. **「かならず 当たる」と 書かない**。心理の 傾向(1〜10 なら 7 が 多い など)は **「多くの 人が」であって「かならず」では ない**。外れた ときの 切りかえし(アウト)を いっしょに 教える。「外れても 楽しい」が メンタリストの 芸
6. **実在の 人は 事実だけ**。**いま 活動している 日本の 人(テレビの メンタリストなど)は 出さない**。海外の 人も「〜と 公言している」「〜で 知られる」の 形で。しかけ・私生活・論争・訴訟は 書かない。生まれた 年・亡くなった 年は 書かない
7. **心理学ゲームと 同じ 線**: 心の 病気の 名前を 出さない / 科学で たしかめられた ことと 言い伝えを 分ける / 自分や 友だちを 診断する 道具に しない / 人や 動物が つらい 思いを する 実験は 書かない
8. **占い・霊感商法を すすめない**。お金・進路・健康の 話を 読心の 芸に 使わない(「お金を だまし取る 人が いるので 気を つけよう」は よい)。賭け・ギャンブル・カードの いかさまは 書かない
9. **催眠で 病気が 治る**の ような 医療の 話は 書かない
10. **自分の ことばで 書く**。本・サイト・Wikipedia の 文を 写さない。数字は まちがいない ものだけ

## ゲームの かたち
「表示された ひらがなを フリックで 打ち写す」タイピング。打ち終わると ことばの 説明(1〜3文)が 出る。
遊ぶのは 小学生〜大人。**この ゲームは「ことばを おぼえる」で 終わらせない。遊んだ 子が 本当に 1つ 演じられる ように する**。だから ほぼ 全部の 語に **🎯 やってみよう(renshu)** を 付ける

## 1語の 形(JSON)
{"id":"kk-palace","name":"記憶の宮殿","reading":"きおくのきゅうでん","journey":"kioku","category":"記憶術","difficulty":1,"type":"concept",
 "emoji":"🏰","mapNode":"kioku:palace","field":"記憶","relatedTerms":["kk-peg","kk-story"],
 "description":"よく 知っている 家や 道の 場所に、おぼえたい 物を 1つずつ 置いていく 記憶の 技です。思い出す ときは 頭の 中で その 道を 歩きます。むかしの ギリシャから 伝わる 方法で、場所法とも いいます。",
 "shikumi":"(任意)人は 場所と 絵を おぼえるのが とくい、と いう 心理の しくみ 1文",
 "butai":"(任意)舞台で どう 使われるか 1文",
 "renshu":"(⭐ できるだけ 全部)家の 玄関から 自分の 部屋まで 10の 場所を 決めて、毎日 同じ 順に 思い出してみよう。",
 "ei":"(英語の 語だけ)memory palace"}

- id: 旅の 頭文字 + "-" + 英小文字(ki- / sr- / ka- / kk- / kt- / su- / bu- / js- / ko-)。英小文字・数字・- だけ
- name: 画面に 出す 名前(ふつうの 言いかた。カタカナ語は ふつうの 書きかた)
- reading: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白は ダメ)。英語の 語は ふだんの カタカナ読みを ひらがなで(みすでぃれくしょん)。数字は ひらがな(1089 → せんはちじゅうきゅう)
  - ゆれる ことばは 1つに 決め、別の 読みは "acceptedReadings":["よみ1","よみ2"](先頭は reading と 同じ)
  - ⚠️ **読みは この ゲームの 9つの 旅の 中で かぶらない**
  - 読みは 20字まで(長いと 子どもが 飽きる)
- difficulty: 1 = **入門(きょう 1つ 演じられる)** / 2 = **中級(家族・友だちの 前で 10分 できる)** / 3 = **上級(世界の トップを めざす)**
- type: いつも "concept"
- category: 図鑑で しぼる 分類(短い 日本語。旅の 中で 4〜8種類)
- emoji: 1つ。⚠️ 👻 🔮 🧿 💀 😱 など こわい・占い・霊の 絵文字は 使わない
- mapNode: その 旅の 図の 場所(下の 表から)
- field: **観察 / 記憶 / 心理 / ことば / 数 / 舞台 / 歴史 / 倫理** の どれか
- relatedTerms: **同じ ファイルの 中の** id を 1〜3個(自分は ダメ)
- description: 1〜3文・**130字以内**。やさしい です・ます。語と 語の あいだに 半角スペースを 入れる 書きかた(上の 例のように)。
  **カタカナ語を ならべない**。ふつうの 言葉で 言いかえて から 芸の 名前(「ミスディレクション = 注意を 別の ところへ 向ける こと」)。
  **メンタリストの 目線**で 書く(心理学・アドラー・マナーと 同じ 語でも 書きなおす)。⭐ ときどき「へえ」と 思える 事実を 1文(⚠️ 頭に「へえ:」とは 書かない)
- shikumi(🧠 しくみ): **任意**(心理・観察・ことばの 語には なるべく)。1文・60字以内。「どんな 心理の しくみが はたらいているか」(例: バーナム効果 →「だれにでも 当てはまる ことを、自分の ことだと 感じる しくみ」)
- butai(🎩 ぶたい): **任意**。1文・60字以内。「舞台で どう 使われるか」
- renshu(🎯 やってみよう): ⭐⭐ **できるだけ 全部の 語に**。1〜2文・70字以内。「きょう できる 練習」。
  ⚠️ **友だち・家族に 使う 練習には かならず「やってもいい? と 聞いてから」を 入れる**。人を ためして 追いつめる 練習は 書かない
- ei: **英語の 語だけ**(任意)。英語の つづり(例 "misdirection" / "cold reading")。🔊 で 英語の 音が 聞ける
- example: なくてもよい

## 旅ごとの 語数
**110語: difficulty 1 を 30語、2 を 40語、3 を 40語**。同じ difficulty の 中は 有名な・大事な 順。
1回目は 70語 = 20 / 25 / 25(`tools/mentalist/terms-<旅>.json`)。2回目に 40語 = 10 / 15 / 15(`tools/mentalist/later/terms-<旅>.json`)を うしろに 足す。前の 語の 順番・中身は 変えない

## ほかの ゲームと かぶる 語
心理学・アドラー心理学・マナー・算数・哲学と 同じ 語を 入れて よい(けいくん決定 2026-09-30「復習になるから」)。説明は **メンタリストの 目線**で 書きなおす。
⚠️ 心理学ゲームと 同じ 効果は **同じ 中身で**(ちがう 説明で 書かない)。バーナム効果・ピグマリオン効果・マジカルナンバー7 の 書きかたは `tools/shinri/terms-*.json` を 見て そろえる

## 入れない ことば(けいくん 2026-10-23 の えらび = 全部おすすめ)
- トリックの しかけ(たね)・仕込み・のぞき見の 道具・カードの スタックの 中身
- 超能力・霊・予知が 本当に ある と 読める 書きかた / 占い・霊感商法の すすめ
- 人を あやつる・だます・買わせる 向き / 「うそを 見ぬける」と 言いきる 書きかた
- 催眠で 病気を 治す / 心の 病気の 名前 / 人や 動物が つらい 思いを する 実験
- いま テレビに 出ている 人の 名前 / 実在の 人の 顔写真 / 賭け・ギャンブル・カードの いかさま

## 出すもの
`tools/mentalist/terms-<旅id>.json`(1回目 70語)と `tools/mentalist/later/terms-<旅id>.json`(2回目 40語)に JSON の 配列で 書く。
書いたら `python3 tools/mentalist/terms_js.py --check --with-later` で 確かめる
