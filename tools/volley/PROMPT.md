# フリックワールドバレーボール: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
どの 国の 話か(国旗の 札)・種目の 札(6人制 / ビーチ / 9人制 / シッティング / 共通)・学ぶ 分野・しくみ図の どこに あるか(📍)が 出る。
あそぶのは **バレーが すきな 小学生〜中高生・ママさんバレーや 部活の コーチ・バレーが すきな 大人・解説者を めざす 人**。
**バレーの ことばと 意味を おぼえる ゲーム**(ニュースでも、試合の 記録集でも ない)。
もとは `tools/basket/PROMPT.md`(ワールドバスケットボール)。けいくん 2026-10-24「ワールドバレーボールの専門家(解説者)になれるレベルになるために必要な 知識、
主要なバレーボールリーグ、有名バレーボール選手、有名な技、ルールをフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめ」。
⭐ けいくんは **スポーツの 人**(サッカースクールの 代表・コーチ)。まちがいは すぐ 気づかれる。**選手と 国と ポジション・技と 使い手・年と 大会・ルールと 種目は かならず 確かめて から** 書く。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 10こ

### 1. ⭐⭐ 数字が 変わる ものを 書かない(いちばん 事故が 起きやすい)
- ❌ **いまの 所属チーム**(日本の 選手は イタリア・ポーランドの クラブと 日本を 行き来する。SV.LEAGUE の チーム名も 変わる)・年俸・契約金・いまの 順位・**通算得点**(いまの 選手)・**いまの 決定率**・いまの 監督・**いまの 世界ランキング**・年齢(「◯歳」)
- ✅ **変わらない 事実は よい**: 国籍(代表)・ポジション・**得意な 技 / プレーの 特徴**・**過去の 受賞と その 年**(「2023年の VNL で ベストアウトサイドヒッター」)・
  **オリンピック / 世界選手権の 優勝の 年と 国**・**引退した 選手の 所属の 歴史**・春高の 優勝校と 年(確かめて)・ルールの 点・秒・距離・高さ
- リーグの **参加チーム数は 書かない**(変わる)
- ⚠️ 台本 `terms_js.py` が「年俸・移籍金・通算・順位・世界ランキング・◯歳・◯円・◯%」などを 止める(⚠️ **「%」「パーセント」も 止まる**。スタッツの 説明は「決まった 割合」「成功した 割合」と 書く)

### 2. ⭐⭐ いまの スター選手(`star`)の 書きかた
- 「**日本代表の アウトサイドヒッター。高い 打点からの スパイクと サーブレシーブの 両方が 武器**」の ように **代表の 国・ポジション・プレーの 特徴**で 書く
- ❌ **チーム名を 書かない**(説明にも 名前にも。SV.LEAGUE・イタリア・ポーランド・トルコの クラブ名ぜんぶ)。「所属」「在籍」「移籍」「加入」「契約」も 書かない(台本が 止める)
- ✅ 代表で 勝った 大会(「2024年 VNL で 銀メダルの 日本代表の 一員」)・個人の 受賞と 年・オリンピックの メダルは よい
- ⚠️ **2026年10月の 時点で 現役か** を 1人ずつ web で 確かめる。引退した 選手は 入れない(legend の 担当が 入れる)。
  **引退が うわさの 選手**は 入れない(1年で 変わる)
- ⚠️ 選手の ケガ・不調・私生活・SNS・発言・結婚は 書かない

### 3. ⭐⭐ 種目が いくつか ある。**どの 種目の 話か かならず 書く**
- **6人制**(インドア。オリンピック・世界選手権・VNL・SV.LEAGUE・春高・部活)/ **ビーチ**(2人制・砂の コート)/ **9人制**(日本の ママさんバレー・実業団・家庭婦人)/ **シッティング**(パラリンピック)
- ルールの 語には **`ruleset` の 欄**を 付ける: `"6人制"` / `"ビーチ"` / `"9人制"` / `"シッティング"` / `"共通"`(どの 種目も 同じ)。2つなら「・」で(`"6人制・ビーチ"`)
  ⚠️ 数字が ちがう ルール(セットの 点数・コートの 大きさ・ブロックの 触りの 数えかた・コートチェンジ)は、説明に **両方の 数字を 書いて `"6人制・ビーチ"`**、または **片方の 数字だけ 書いて その 片方**
- 事実は `tools/volley/exam.txt` の ①②③に 合わせる。**そこに 無い 数字は 書かない**(web で 確かめられた ときだけ)
- ⭐⭐ **いまの 版は FIVB Official Volleyball Rules 2025-2028**(日本では JVA の 6人制競技規則)。⚠️ 版で 変わった ところは exam.txt を 見る。
  テクニカルタイムアウトは 大会で 使う / 使わないが 変わるので「むかし あった」「大会に よって」まで
- 条の 番号(第◯条)は 書かない(台本が 止める)
- 迷う 細かい ところ(例外の 例外)は 書かない。**審判の 学ぶ 範囲**を 中心に
- ⚠️ **6人制と ビーチを まぜない**(「ブロックの 触りは 3回に 数えない」は 6人制。ビーチは **1回に 数える**)

### 4. 実在の 選手・チーム・リーグ・大会の 名前は 入れて よい(事実として)
- ✅ 名前は よい。❌ **スポンサー名・チームの ロゴの 中身の 説明・ユニフォームの メーカー**は 書かない。会社名が 入る アリーナの 名前は 入れない
- ❌ **商品の 名前**(ボール・シューズの 会社。「公式球」まで)。❌ **まんが・アニメの 登場人物・作品名**(バレーの まんがは とても 有名だが 入れない。台本が 止める)
- ⚠️ 日本の チームは **会社の 名前が 入る**ものが 多い。歴史の 話として「日本鋼管」「日立」「ユニチカ」などの 実業団の 名門は よい(team の 旅)。**宣伝の 書きかたを しない**
- カタカナは **JVA・SV.LEAGUE・日本の 新聞で よく 使う 書きかた**に そろえる(アウトサイドヒッター・オポジット・ミドルブロッカー・レセプション・ディグ)
- 古い よびかた(レフト・ライト・センター・サーブレシーブ)は `acceptedReadings` と 説明の 中で 受ける。**答えは いまの よびかた**

### 5. 人を けなさない・悲しい 場面を 入れない
- 「ダメな 選手」「負けた チーム」の 書きかたを しない。**サーブミスで 負けた 話・判定で もめた 話・大敗**など 人が 悲しんだ 場面は 入れない(名場面は **いい ほう** だけ)
- ❌ 乱闘・差別・八百長・賭け・薬物・ケガ・死・事故・私生活・スキャンダルは 入れない(台本が 止める)
- 亡くなった 名選手・名監督も 入れて よいが「亡くなった」とは 書かない(功績で 書く。歴史の 人物と 同じ)

### 6. ⚠️⚠️ 指導の 暴力・体罰・ハラスメントの 話は ぜったいに 入れない
- バレーは この 話題が 多い。**1語も 書かない**。「鬼の ◯◯」「しごき」の よび名も 書かない(台本が 止める)
- 東洋の魔女の 練習は「**毎日 長い 時間 練習した**」まで。きびしさを ほめない
- ⚠️ 事件・不祥事の 報道が ある 選手・監督は **名前ごと 入れない**(`exam.txt` の ⑩。アーヴィン・ヌガペト・ジバ・佐藤駿一郎。台本が 止める)

### 7. ラフプレー・反則を すすめない・相手を ばかに しない
- 反則は **反則の 名前として**。審判を だます 書きかた(ワンタッチを かくす など)は しない
- ⭐ **技は「練習で 身に つける 技」として**。❌「相手を ばかに する」書きかたを しない
- ⚠️ **技の 名前の もとは 説が 分かれる ものが 多い**。「◯◯が はじめた」と 言いきらず「◯◯の 得意技として 有名」「◯◯で 生まれたと 言われる」まで
  (例: 回転レシーブ = 東洋の魔女で 有名 / 時間差攻撃 = 1970年代の 日本男子で 生まれたと 言われる)

### 8. ほかの ゲームと 同じ 語は 入れて よい(けいくん決定 2026-09-30)
- フリックワールドサッカー・バスケットボール・世界旅行 などと 同じ 語(リベロ・ブロック・アタック・ポジション など)は、**バレーでの 意味**で 書く
- ⚠️ **サッカーの リベロと バレーの リベロは まったく 別の 意味**(バレーは 守り専門・ちがう 色の ユニフォーム)
- 読みが かぶっては いけないのは **ワールドバレーボールの 9つの 旅の 中だけ**(台本が 止める)

### 9. 事実を 正しく(⭐ かならず 確かめる)
- **選手と 国と ポジション・技と 使い手・年と 大会・チームと 町・ライバルの 組み合わせ・ルールの 数字と 種目** は 1語ずつ web で 確かめる(記憶で 書かない)
- 大会・賞の 事実は `tools/volley/exam.txt` に 合わせる。そこに 無い 年・大会を 書くときは web で 確かめてから
- 事実が あやしい 語は 入れない。**自分の ことばで 書く**(Wikipedia・公式の 文を 写さない)

### 10. 小学生も あそぶ
- ケガ・暴力・差別・賭け・人の 死の 話は 入れない。**迷ったら 入れない**

## 1語の 形(JSON)

```json
{"id":"wz-jikansa","name":"時間差攻撃","reading":"じかんさこうげき","journey":"waza","category":"コンビ攻撃","difficulty":2,
 "field":"技術","type":"concept","emoji":"⏱️","mapNode":"waza:combo","relatedTerms":["wz-aquick"],"country":"日本","ruleset":"6人制",
 "description":"ひとりが 跳ぶ ふりを して ブロックを 先に 跳ばせ、少し おくれて 別の 選手が 打つ 攻撃です。1970年代の 日本男子で 生まれたと 言われ、世界に 広まりました。"}
```
ルールの 語の 例:
```json
{"id":"rl-touchnet","name":"タッチネット","reading":"たっちねっと","journey":"rule","category":"ネットの 反則","difficulty":1,
 "field":"ルール","type":"concept","emoji":"🥅","mapNode":"rule:netfoul","relatedTerms":["rl-overnet"],"ruleset":"共通",
 "description":"プレーの とちゅうで ネットに さわって しまう 反則です。ボールを さわる 動きの 中で アンテナの あいだの ネットに ふれると、相手の 点に なります。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(日本の 新聞・JVA で ふつうに 使う 書きかた。選手は「石川祐希」「ウィルフレド・レオン」の ように ふつうに 知られた よび名)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)
  - カタカナ語は ひらがなで(ブロード → ぶろーど)。「・」「&」は 取る
  - 数字・英字の 入る 名前は 読みで(Aクイック → えーくいっく、VNL → ぶいえぬえる、SV.LEAGUE → えすぶいりーぐ、3枚ブロック → さんまいぶろっく)
  - ゆれる ことばは いちばん ふつうの 読みを reading に、ほかを `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は 上級だけ・旅で 1〜2語まで
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級(下の「3段の 分けかた」)
- **field**: 学ぶ 分野。次の 6つの どれか: `ルール` / `技術` / `戦術` / `リーグ・チーム` / `選手` / `大会・歴史`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(🩸 💀 ☠️ 🔪 🤕 🚑 😭 😱 は 使わない。🏐 ばかりに しない。国旗の 絵文字は 使わない(札で 出る ため))
- **country**(関係が あれば 付ける): その 選手・チーム・技・大会が どの 国の 話か。次の どれか。2〜3つなら「・」で(`"イタリア・ポーランド"`):
  `世界` `ヨーロッパ` `アジア` `アフリカ` `南アメリカ` `北中米` `オセアニア`
  `日本` `中国` `韓国` `タイ` `イラン` `カザフスタン` `フィリピン`
  `アメリカ` `カナダ` `キューバ` `ドミニカ共和国` `プエルトリコ` `メキシコ` `ブラジル` `アルゼンチン`
  `イタリア` `ポーランド` `セルビア` `フランス` `トルコ` `ロシア` `ソ連` `ユーゴスラビア` `オランダ` `ドイツ` `スロベニア`
  `ブルガリア` `スウェーデン` `ノルウェー` `ベルギー` `チェコ` `スペイン` `ウクライナ` `イギリス`
  `オーストラリア` `エジプト` `チュニジア` `カメルーン`。
  選手は **代表の 国**。ルール・きほんの ことばなど 国と 関係ない 語は 付けない(⚠️ アメリカで 生まれた ことば・日本で 生まれた 技 などは 付けて よい = へえ)
- **ruleset**(⭐ ルール・種目の 話の 語。`rule` の 旅は **70語 ぜんぶ**、ほかの 旅でも 種目の 話なら): `"6人制"` / `"ビーチ"` / `"9人制"` / `"シッティング"` / `"共通"`(上の 3.)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / どんな 特徴か / へえ」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  文体は **はじめから「〜です・ます」**(体言止めで はじめない)。「1人」「2人」は ふりがなが 読みまちがえるので **ひとり・ふたり** に 言いかえる
- **example**: なくてもよい
- 「へえ」を 1文 入れると よい(「はじめの 名前は ミントネット」「バスケットボールの 4年後に 生まれた」)

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | **バレーが すきな 小学生**。ポジション・きほんの ルール・だれでも 知っている 選手と 技と 大会の 名前・春高 |
| 2 | 中級 | **ママさんバレー・部活の コーチ・バレーが すきな 大人**。**審判の 学ぶ 範囲の めやす**の ルール・リーグと チーム・技の 中身・6人制と ビーチの ちがい |
| 3 | 上級 | **解説者**。戦術の ことば・スタッツの ことば・名監督・大会の 歴史・ルールの 細かい ところ |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる
(ならんだ 順が そのまま ステージの 順に なる)。

## 旅ごとに 入れる 語(⚠️ **読みが かぶると 台本が 止まる**。ほかの 旅の 欄に 書いてある 語は 入れない。ここに 無い 語を 足すのは よい)

### 読み(ひらがな)の 決まり(⚠️ 9つの 旅で そろえる)

- ヴ は **ぶ** で 読む(ヴァキフバンク → **ばきふばんく**)。小さい ぃ・ぇ は 残す
- 選手は **ふつうに 知られた よび名**を reading に(⚠️ **20字 以内**)。名字だけの よび名・愛称は acceptedReadings か 別の 語(愛称の 語は legend の nickname)

- **指導の 暴力・ハラスメントの 話・まんがの 登場人物・商品名は 書かない**
- 「100マス計算」「百ます計算」の 字を 使わない
