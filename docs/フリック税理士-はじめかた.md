## 2. はじめに けいくんに 聞く 5つ(「全部おすすめで」と 返ってくる ことが 多い)
1. **名前**: 「フリック税理士」で よいか(絵が 届いたら 絵の 題名に そろえる。フォルダ名 `zeirishi` は 変えない)
2. **旅の 分けかた**(おすすめ 7つ + 🏆 マスター):
   🧾 税金の きほん(税金・国税・地方税・納税・申告・税務署・確定申告・源泉徴収・年末調整 …)/
   💴 くらしの 税金(消費税・所得税・住民税・ふるさと納税・控除・扶養・年金と 保険料・マイナンバー …)/
   🏢 会社の 税金(法人税・決算・事業年度・固定資産税・インボイス・軽減税率・赤字の くりこし … **名前と 何の ための 決まりか**)/
   📒 簿記と 会計(仕訳・借方と 貸方・貸借対照表・損益計算書・減価償却・売上・経費・利益・帳簿・領収書 …)/
   🏠 相続と 贈与(相続税・贈与税・遺言・遺産分割・基礎控除・生前贈与 … **こわく ない 書きかた**)/
   📋 税理士の 仕事(税務代理・税務書類の 作成・税務相談・記帳代行・税務調査の 立ち会い・顧問・税理士会・守秘義務 …)/
   🌏 税の 歴史と 世界(租・庸・調・年貢・地租改正・シャウプ勧告・消費税の はじまり・世界の 税の しくみ …)
3. **むずかしさの 3段**: 入門(くらしや ニュースで 聞く 税の ことば)→ 中級(**税理士試験の 簿記論・財務諸表論・税法の 範囲の めやす**: 大きな ことば)→ 上級(税法の こまかい 制度の 名前・会計基準・国際税務の ことば)
4. **1語に 持たせる 科目**(`field`): 税理士試験の 科目(簿記論 / 財務諸表論 / 所得税法 / 法人税法 / 相続税法 / 消費税法 / 固定資産税 / 国税徴収法 / 住民税 / 事業税 / 酒税法 + 税の きほん)の どれか。**確かめてから 決める**
5. **入れない もの**(下の 3 と かさなる): 節税の テクニック・脱税の やりかた・「こうすれば 税金が 安くなる」の 言いかた・税率や 金額の 決めうち・実在の 会社や 人の 事件。**制度の 名前と 目的だけ**

## 3. ⚠️⚠️⚠️ ぜったいの 決まり(弁護士と 同じ。お金は なおさら)
- ✅ **ほかの ゲーム(株式旅行・弁護士・社会旅行 など)と 同じ 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。ただし 説明は **税理士の 目線**で 書きなおす
- **読み(ひらがな)は 税理士の 7つの 旅の 中では かぶらない**(ほかの ゲームとは かぶって よい)
- **節税の テクニック・脱税の やりかた・抜け道・「こうすれば 税金が 安くなる/かからない」の 決めうち** を **ぜったいに 書かない**。
  書くのは **その ことばが 何を さすか・何の ための 制度か**だけ(例: ふるさと納税 = 応援したい 自治体に 寄付すると、決まりの 中で 税金の 一部が 差し引かれる しくみ。くわしい 計算は 国税庁の ページで)
- **税率・金額・上限の 数字を 書かない**(消費税 10% の ような **だれでも 知っている 数字**は 書いて よいが、**毎年 変わる 控除額・税率の 表は 書かない**。**まよったら 書かない**)
- **税務の 相談の 答えに なる 書きかたを しない**(「あなたの 場合は …」「この 条件なら …」)。画面に「これは ことばを おぼえる ゲームです。本当の 税金の ことは 税務署や 税理士に 相談してください」
- **小学生も あそぶ**: 借金の とりたて・差し押さえ・脱税の 事件・相続の あらそいの ようすを 書かない。相続は「家族が のこしたものを 受けつぐ ときの 決まり」の ように おだやかに
- **政治の よしあし**(増税・減税の 是非)を 書かない。制度は **何の ための 決まりか**だけ
- **実在の 会社・人・事件の 名前を 入れない**(株式旅行の 会社の 名前は 株式旅行の 中だけ)
- **作った 助手とは 別の 助手が 1語ずつ 確かめる**(意味・読み・節税の テクニックや 数字を 書いていないか・相談の 答えに なっていないか・こわくないか)。ふりがなも 全語 見る(`tools/ruby_fix.json`)

## 4. 試験の 事実は **その日に 国税庁・日本税理士会連合会の ページで 確かめてから** 書く
`meta.json` の `exam` に 確かめた 日を つける(弁護士の `exam.txt` + `mkmeta.py` の 型)。書く 中身(すべて 確かめる。**記憶で 書かない**):
税理士は **国家資格**(税理士法。日本税理士会連合会に 登録。**免許は 国が 出すのでは なく 税理士会への 登録**。確かめる)/
なりかた(①税理士試験に うかる(**5科目 合格**。科目合格は **一生 有効**)②弁護士・公認会計士は 登録できる ③税務署に 一定年数 勤めた 人の 免除 … 確かめる)/
試験は **年 1回・8月**(国税審議会が 行う。**2023年から 受験資格が ゆるんだ**(簿記論・財務諸表論は だれでも)。確かめる)/
科目: **会計 2科目(簿記論・財務諸表論。必須)+ 税法 3科目**(所得税法か 法人税法の **どちらかは 必須**。相続税法・消費税法か 酒税法・国税徴収法・住民税か 事業税・固定資産税 から えらぶ)/
合格の めやす(各科目 60点。確かめる)/ 合格のあと **2年の 実務経験**が 登録に 要る(確かめる)/ 税理士の 人数の めやす /
**税理士と 公認会計士の ちがい**(税務 / 監査)・**税理士で ないと できない 仕事**(税務代理・税務書類の 作成・税務相談 = 独占業務。確かめる)/
インボイス制度(2023年10月〜)・電子帳簿保存法 は 名前と 目的だけ(**中身は 変わるので 書かない**)

## 5. 作りかたの 手順(弁護士・警察官・医師・教師・料理人・消防士の まとめと 同じ)
1. けいくんに 2 の 5つを 聞く → 返事を CLAUDE.md に 書く
2. `tools/zeirishi/PROMPT.md` `exam.txt` `mkmeta.py` → `meta.json` を 作る → 旅ごとに 助手に 70語ずつ 頼む(`PROMPT.md` を そのまま わたす)→ `terms-<旅>.json`
3. `terms_js.py` で 止められた 語を 直す → 別の 助手が 1語ずつ 確かめる → ふりがな
4. `zeirishi/zeirishi.js`(bengoshi.js を 写す)・`build_games.py`・`index.html` の SERIES → `python3 tools/build_games.py`
5. 手元で 通す: `python3 -m http.server 8765` → `node tools/play-all.mjs`(4とおりの 打ちかた)/ `node tools/click-all.mjs`(W=320 も)
6. PR は **rebase で 取りこむ**(この 入れもの)。speed-king は squash。コミットの 末尾は Co-Authored-By と Claude-Session の 2行
7. かずとも `speed-king`: `FLICK_MODES` / `FLICK_LINK_TARGETS` に `zeirishi`(PR → squash)。`HOME_GAMES` は 絵と OK の あと(題の 数は 自動)
8. けいくんに ChatGPT で 絵を 頼む 文を わたす(トップ 1536×1024 + 四角い 絵 1254px。**人物は 画面の 下 3分の1に 小さく**・指5本・首が 見える・
   会計事務所か 税務署の 前。**電卓や 書類を 手に 持たせない**(手が 崩れやすい。机の 上に 置く)。
   絵の 中の 字は「フリック税理士」だけ・ゲームに 無い 機能の 絵を 入れない・**本物の 税理士バッジ(日輪に 桜)や 実在の 税務署の 名前を 描かない**・**お札の 絵は 描かない**(本物の お札の 絵は 法律の 決まりが ある))。届いたら **まず 字を 切り出して 読む**(「ごっかしけん」の 前例)
9. 絵を 入れたら CLAUDE.md に 節を 書く(名前・旅・語数・確かめた 日・入れなかった 語と 理由)

- 読みの かぶりは 片方を べつの 語に
