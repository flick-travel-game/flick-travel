# ことばを 書く 係への おねがい(フリックキャビンアテンダント。1つの 旅を 書く)

1. まず `tools/cabin/PROMPT.md` を ぜんぶ 読む(決まり・1語の 形・mapNode の 表)。手本の 書きぶりは `tools/pilot/terms-kuko.json`(パイロット)と `tools/manner/terms-keigo.json`(マナー)
2. `tools/cabin/plan.json` の あなたの 旅の 110語を、**plan の 順番の まま**(name・reading・difficulty・mapNode は plan の とおり。直したい ときは 下の 6 を 見る)で 書く
   - phase 1 の 70語 → `tools/cabin/terms-<旅>.json`
   - phase 2 の 40語 → `tools/cabin/later/terms-<旅>.json`
   - relatedTerms は **同じ ファイルの 中の** id だけ(phase 1 の 語は phase 1 の 語に、phase 2 の 語は 自分の ファイル か phase 1 の ファイルの 語に つないで よい。⚠️ phase 1 の 語から phase 2 の 語へは つながない)
   - id は 旅の 頭文字(PROMPT.md)+ "-" + 英小文字。かぶらない ように
3. description は **客室乗務員の 目線**で、やさしい です・ます、語と 語の あいだに 半角スペース、130字以内。⭐ 説明は 「何か → なぜ 大事か / お客さまの ために どう するか」
4. settai(🤝 おもてなし)は 接遇・サービス・英語・空港で お客さまと 話す 語に なるべく 付ける(60字以内・1文)。ei(英語の つづり)は 英語の 語・ひとこと・英語から 来た カタカナ語(ギャレー → "galley")に 付ける
5. ⚠️ **事実は たしかな ものだけ**。下の「確かめた 事実」は 使って よい。それ以外で 自信が ない 数字・年・名前は **書かない**(数字を ぼかすか、説明を その ことの 意味だけに する)。
   ⚠️ **おじぎの 角度の 数字・電話の コール数など マナーの 数字は 書かない**(「かるく」「ふかく」で)。メラビアンの 法則は「話の 中身より 見た目や 声が 大事」と まちがえて 広まった ことに 気を つけ、「気持ちと 表情・声が ちぐはぐだと 表情や 声の ほうが 伝わりやすい、と いう 実験」の 範囲で
6. plan の 語が 決まりに 合わない(こわい・決めつけ・会社名・あやしい 事実)と 思ったら、**同じ difficulty・同じ mapNode の 別の 語に かえて よい**。⚠️ その ときは かならず `python3 tools/cabin/terms_js.py --check --with-later` で 読みの かぶり(9つの 旅 ぜんぶ)が 0 か 確かめ、さいごの 報告に「かえた 語」を 書く
7. 書いたら `python3 tools/cabin/terms_js.py --check --with-later` を 走らせて、**あなたの 旅の 語**に ❌ が 出ない ことを 確かめる(ほかの 旅の ファイルが まだ 無い / 書きかけ の ことによる ❌ は 気に しない。⚠️ ほかの 旅の ファイルは さわらない)。⚠️ 長い 説明の ⚠️ も 直す
8. 報告は みじかく: 書いた 語数・かえた 語と 理由・自信が なくて ぼかした 事実

## 確かめた 事実(公式の ページで 2026-10-20 に 確かめた。使って よい)
- 客室乗務員に 国の 資格は 要らない。航空会社の 採用試験 → 入社後の 会社の 訓練と 審査(国土交通省の 運航規程審査要領で、各社が 訓練・審査の きまりを 定めて 国が 認可する)。いちばん 大切な 訓練は 保安(緊急脱出・非常用の 道具の あつかい)
- 採用試験に よく ある もの: エントリーシートなどの 書類・何回かの 面接(グループ面接も)・適性検査・英語の 試験(または スコアの 提出)・健康診断。⚠️ グループディスカッション・体力測定は「行う 会社も ある」と 書く(どの 会社も する とは 書かない)。航空の 学校に 通っていなくても 受けられる 会社が ある
- TOEIC など 英語の 力は 役に 立つ ことが ある(必須とは 書かない。点数は 書かない)。普通救命講習(心肺蘇生・AED・止血などを 学ぶ。消防署の 講習で 3時間が きほん)も 役に 立つ ことが ある。サービス接遇検定・秘書検定は「公益財団法人 実務技能検定協会の 検定」で、役に 立つ かは「接遇の 知識の 勉強に なる」まで
- エレン・チャーチ: 看護師で、1930年に アメリカで 世界で はじめての 客室乗務員(スチュワーデス)と して 乗った 人
- 日本: 1931年に 東京航空輸送が「エア・ガール」を 乗せたのが はじまり(国立国会図書館の 展示)。⚠️ 何人 合格 などの 数は 書かない
- 呼び名: 男女の 区別を しない「客室乗務員」「キャビンアテンダント」「フライトアテンダント」に かわってきた。⚠️ かわった 年は 書かない
- 酸素マスク: **まず 自分が つけてから 子どもなどを 手伝う**(FAA・EASA)
- エコノミークラス症候群の 予防(厚生労働省): こまめに 水分を とる・ときどき 足を 動かす(かかとの 上げ下げ・ふくらはぎを もむ)・ゆったりした 服・お酒を ひかえる
