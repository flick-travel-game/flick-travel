# フリック指圧師(資格の 正式な 名前は あん摩マッサージ指圧師): ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
からだの どこの 話か(札)・どの 経絡か(札)・学ぶ 分野(国家試験の 科目)・しくみ図の どこに あるか(📍)が 出る。
あそぶのは **小学生〜あん摩マッサージ指圧師を めざす 中高生・専門学校生・理療科の 生徒・からだの 健康が 気に なる 大人**。
**あん摩マッサージ指圧師(医療の 国家資格)の ことばと 意味を おぼえる ゲーム**(試験の 問題集でも、手技の 手引きでも ない)。
もとは `tools/shika/PROMPT.md`(歯科医師)。けいくん 2026-10-12「あん摩マッサージ指圧師の国家資格に受かるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめ」。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 8つ

### 1. ⭐⭐⭐ 「マッサージ」は 医療の 国家資格の 話として だけ 書く(いちばん 大事)
- 「マッサージ」の 字は 医療と 関係ない お店にも 使われる。**小学生が あそぶ**。保護者が 見て「え?」と 思う 字が 1つでも あったら 失敗
- 場所は **施術所・治療院・病院・介護施設・患者さんの 家(訪問)・スポーツの 現場** だけ
- ❌ **書かない 字**(台本が 止める): お店・店員・サロン・お客さん・エステ・個室・密着・オイル・アロマ・裸・下着・服を ぬぐ・ホテル・出張・癒やし・性的 など
  - 人は **「患者さん」「利用者さん」「選手」**。マッサージの 説明は「素肌に 直接 ふれる」まで。ベッド・着る ものの 話は 書かない
- **からだの 部位は 首・肩・背中・腰・腕・手・脚・足・頭・顔・おなか まで**。それ以外の 部位(胸・おしり・ももの 内がわ など)は 説明に 書かない
  - ⭕ 解剖の 正式な 名前は よい: 胸椎・胸鎖乳突筋・大胸筋・股関節・骨盤・大殿筋(説明は「腕を 前に 動かす 筋肉」「脚の 付け根の 関節」の ように **はたらき**で 書く)
- ⚠️ **迷ったら 入れない**

### 2. ⭐⭐ やりかたの 数字を 書かない(家で まねして けがを しない ように)
- ❌ **圧の 強さ(kg・「強く 押す」)・時間(分・秒)・回数・順番**を 書かない(台本が 数字+分/秒/回/kg を 止める)
- 手技は **名前と 動きの 種類**(なでる・もむ・押す・たたく・ふるわせる・うごかす)だけ。叩打法は「リズムよく 軽く たたく」まで
- ❌ 「この ツボを 押すと ◯◯が 治る」「効く」と 書かない(台本が「治る・治す・効く」を 止める)。
  ⭕「◯◯の とき よく 使われる ツボです」「肩の 施術で よく ふれる ツボです」まで
- 手技の はたらきは 「治る」でなく **「血の めぐりを 助ける」「筋肉の こわばりを ゆるめる」「リラックスを 助ける」「ととのえる」**

### 3. 治療・診断を 書かない・こわく 書かない
- ❌ 薬の 量・「この しょうじょうなら この 病気」・正常値の 数字・家で できる 治療・手術・骨折や 脱臼の ようす・血・がん・死
- 不調は **「何が 起きている 状態か」+「あん摩マッサージ指圧師が ととのえる 手伝いを する / 病院と いっしょに」** だけ
- ⭐ 書いて よい(子どもの 安全に 役立つ): **「こんな ときは 施術より 先に 病院へ」**(熱が ある とき・けがの すぐ あと・骨折の 疑い が ある とき)
  - 「骨折の 疑い」「骨折かも」は 台本が 通す。それ以外の「骨折」「脱臼」は 止まる
- 「痛い」は 書かない(台本が 止める)。炎症の 4つの しるしは「赤く なる・熱を もつ・はれる・痛む」まで(「痛む」は 1語の 中で 1回まで)

### 4. 東洋医学と 西洋医学を くらべない
- どちらが 上とも 書かない。「からだを 全体で 見る 考えかた」「病院の 医学と いっしょに 使われる」の 向き
- 「気」「経絡」「経穴」は **東洋医学の 考えかたとして** 書く(「〜と 考えます」「〜と されます」)。「科学で 証明された」とも「迷信」とも 書かない

### 5. ほかの 仕事を けなさない・19条に ふみこまない
- はり師・きゅう師・柔道整復師・理学療法士・作業療法士・整体・リラクゼーション は **「べつの 資格 / 国家資格では ない 仕事」という 事実だけ**。「無資格は あぶない」と 書かない
- **視覚に 障害の ある 人の 仕事の 話は 前向きに**(「目が 見えなくても 手の 感覚で 人を 助ける 仕事として 長く 大切に されて きた」)。
  法律の 19条は「視覚に 障害の ある 人の 仕事を 守る しくみが ある」の 1行まで(養成施設の 話・裁判には ふみこまない)

### 6. 実在の 名前・商品・年ごとに 変わる 数字を 出さない
- **実在の 治療院・お店・マッサージ機・オイル・サプリ・商品名・会社名**を 書かない
- ⭕ 公の 組織・制度の 名前は よい: 厚生労働省・文部科学省・保健所・WHO・東洋療法研修試験財団(試験の 説明で)
- 人の 名前は 歴史として よい(**`tools/anma/exam.txt` に ある 事実だけ**。杉山和一・浪越徳治郎 など)
- **合格率・人数・%・円・回数・費用・療養費の 金額**は 書かない。条の 番号(第◯条)も 書かない
- ⭐ **変わらない からだの 事実は 書いて よい**: 頸椎 7・胸椎 12・腰椎 5(書くときは「頸椎は 7つ」の ように「つ」で。数字+個 は 避ける)・14の 経脈・
  WHO の 標準経穴部位(361の ツボ。exam.txt で 確かめた ものだけ)

### 7. 字の きまり
- **「あん摩」は ひらがな+漢字**(「按摩」と 書かない。台本が 止める)。**「マッサージ」は 小さい ッ**。**「きゅう師」は 小さい ゅ**。
  法律の 正式な 名前の 中だけ「あん摩マツサージ指圧師、はり師、きゆう師等に関する法律」(大きい ツ・ゆ)。略して「あはき法」
- 「指圧士」「あん摩師」と 書かない(台本が 止める)
- **「施術」**(せじゅつ)を 使う。あん摩マッサージ指圧師の 仕事を「治療」とは 書かない

### 8. あん摩マッサージ指圧師の 目線で 書く(ほかの ゲームと 同じ 語を 入れて よい)
- ✅ **医師・看護師・歯科医師・からだ図鑑・理科の 生物 など ほかの ゲームと 同じ ことばを 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)
- ⚠️ 説明は **「手で ふれて ととのえる 目線」**: 「肩の いちばん 外がわを おおう 大きな 筋肉です。肩の 施術で よく ふれます」
- **読み(ひらがな)は あん摩マッサージ指圧師の 9つの 旅の 中で かぶらない**(台本が 止める)。下の「旅ごとに 入れる 語」を 守る。**ほかの 旅の 欄に ある 語は 入れない**
- 文体は **はじめから「〜です・ます」**(体言止めで はじめない)
- 「へえ」を 1文 入れると よい(「マッサージは フランス語の 名前が 多い」「背骨の 首の 部分は 7つ」「ツボの 場所は 自分の 指の 幅で はかる」)
- 事実が あやしい 語は 入れない。**自分の ことばで 書く**(教科書・Wikipedia・公式の 文を 写さない)

## 1語の 形(JSON)

```json
{"id":"kr-goukoku","name":"合谷","reading":"ごうこく","journey":"keiraku","category":"手と 腕の ツボ","difficulty":1,

 "description":"手の 甲で、親指と 人さし指の 骨が 合わさる ところの 近くに ある ツボです。大腸経の ツボで、肩や 首の 施術でも よく 使われます。"}
```

- **name**: 画面に 出す 名前(教科書・国家試験で ふつうに 使う 書きかた)。経絡は **短く「肺経」**(長い「手の 太陰肺経」は 説明に)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)
  - カタカナ語は ひらがなで(エフルラージュ → えふるらーじゅ)。英字の 略語は 下の「略語の 読み」

  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は 上級だけ・旅で 1〜2語まで
  - ⚠️ **ツボ・東洋医学の 読みは 1語ずつ 確かめる**(合谷 ごうこく・足三里 あしさんり・肩井 けんせい・百会 ひゃくえ・湧泉 ゆうせん・三陰交 さんいんこう・内関 ないかん・

- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級(下の「3段の 分けかた」)
- **field**: 学ぶ 分野 = **国家試験の 科目**。次の どれか(入門の 語でも いちばん 近い ものを):
  `医療概論` / `衛生学・公衆衛生学` / `関係法規` / `解剖学` / `生理学` / `病理学概論` / `臨床医学`(臨床医学総論・各論を まとめた もの)/ `リハビリテーション医学` /

  (めやす: kihon → 医療概論 か あん摩マッサージ指圧理論 / kaibo → 解剖学 / seiri → 生理学 / rinsho → 臨床医学 か 病理学概論 / toyo → 東洋医学概論 か 東洋医学臨床論 /
   keiraku → 経絡経穴概論 / shugi → あん摩マッサージ指圧理論 / riha → リハビリテーション医学 か 衛生学・公衆衛生学 / hoki → 関係法規 か 医療概論)
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(💀 ☠️ 🩸 🔪 💉 💋 🍑 🛏️ 🛁 は 使わない。😱 😭 などの こわがる 顔も 使わない)
- **part**(⭐ この ゲームの 欄。**からだの 場所が ある 語には 付ける**): `首` `肩` `背中` `腰` `腕` `手` `脚` `足` `頭` `顔` `おなか` `全身` の どれか。
  2〜3つなら「・」で つなぐ(`"首・肩"`)。法律・考えかたなど 場所の 無い 語には 付けない
- **meridian**(⭐ この ゲームの 欄。**ツボと 経絡の 語に 付ける**): `肺経` `大腸経` `胃経` `脾経` `心経` `小腸経` `膀胱経` `腎経` `心包経` `三焦経` `胆経` `肝経` `督脈` `任脈` の どれか 1つ。
  ⚠️ 合っているか 確かめて 付ける(合谷=大腸経・足三里=胃経・肩井=胆経・百会=督脈・湧泉=腎経・三陰交=脾経・内関=心包経・曲池=大腸経・天柱=膀胱経・風池=胆経・
  命門=督脈・関元=任脈・中脘=任脈・太衝=肝経・委中=膀胱経・腎兪=膀胱経)。分からない ときは 付けない
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。**語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  専門用語を 専門用語だけで 説明しない。「1人」「2人」は **ひとり・ふたり**、「1日」は 「いちにち」と 読める 書きかたに
- **example**: 入れない

## ぜったいに 守ること
- **自分の ことばで 書く**。教科書・問題集・Wikipedia・公式の 文を 写さない
- **数字(%・円・回・分・秒・kg・歳・℃・点)は 書かない**(頸椎 7つ などの からだの 事実・14経脈・exam.txt の 事実は よい)
- 「あん摩」「マッサージ」「きゅう」の 字を そろえる(上の 7)
- 「100マス計算」「百ます計算」の 字を 使わない
