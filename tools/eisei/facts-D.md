## D-1. 睡眠ガイド2023

| 事実 | 出どころ |
|---|---|
| **成人**: 適正な 睡眠時間には 個人差が あるが、**6時間以上を 目安**として 必要な 睡眠時間を 確保する | 睡眠ガイド RECOMMENDATION 1 成人版 推奨事項 |
| **高齢者**: 長い 床上時間は 健康リスクと なるため、**床上時間が 8時間以上に ならない ことを 目安**に 必要な 睡眠時間を 確保する。長い 昼寝は 避ける(30分以上の 昼寝習慣で 将来の 死亡リスク 1.27倍 の 報告。数字は ゲームに 使わない) | 睡眠ガイド RECOMMENDATION 3 高齢者版 |
| **こども**: **小学生は 9〜12時間、中学・高校生は 8〜10時間**を 参考に 睡眠時間を 確保する(幼い こどもの 時間の 記載も あるが 確かめて いないので 使わない)。小・中・高校生は 1日 60分以上 からだを 動かし、スクリーンタイムは 2時間以下 が 推奨と 紹介 | 睡眠ガイド こども版 |
| **光**: 起床後に 朝日の 強い 光を 浴びると 体内時計が リセット。日中に 光を 多く 浴びると 夜間の メラトニン分泌量が 増え 入眠が 促進。**これらの 効果は 1,000ルクス以上の 照度の 光を 日中に 浴びる ことで 得られる** | 睡眠ガイド「良質な睡眠のための環境づくり」1 |
| **メラトニン**: **就寝の 約2時間前から** 分泌が 始まる。それ以降に 照明や スマートフォンの 強い 光を 浴びると 分泌が 抑制され、睡眠・覚醒リズムが 遅れる | 同 |
| 体内時計の 中枢は **視床下部の 視交叉上核**(主に 光の 情報で 同期) | 同 ショートコラム「光の波長と体内時計」 |
| **カフェイン**: 1日 **400mg(コーヒー 約700cc)**を 超えると 夜 眠りにくく なる 可能性。**1日の 摂取量 合計は 400mgを 超えない ように**。夕方以降の 摂取は 睡眠に 影響しやすい | 睡眠ガイド「睡眠と嗜好品について」ポイント |
| **交替制勤務の 仮眠**: 夜勤中の 仮眠は 仕事の 効率を 改善。**0〜4時に 開始する 20〜50分間の 仮眠**は 眠気・仕事効率・疲労を 改善と 報告。**仮眠を 60分間と 長めに した 研究では かえって 効率が 低下**(睡眠慣性) | 睡眠ガイド「就業形態(交替制勤務)と睡眠の課題について」3 |
| 休日の 寝だめ: 平日 6時間以上 寝ている 人に 限り 休日 1時間 程度の 寝だめは リスク低下、平日 6時間未満 では 寝だめしても リスクが 高まる(細かい 数字は ゲームに 使わない) | 睡眠ガイド 成人版 解説 |

## D-2. 身体活動・運動ガイド2023

| 事実 | 出どころ |
|---|---|
| **成人(身体活動)**: 強度が **3メッツ以上**の 身体活動を **週23メッツ・時以上**。具体的には 歩行 又は それと 同等以上の 強度の 身体活動を **1日60分以上**(**1日 約8,000歩以上**に 相当) | 運動ガイド 本体 成人版 推奨事項 / INFO3 |
| **成人(運動)**: 強度が 3メッツ以上の 運動を **週4メッツ・時以上**。具体的には **息が弾み 汗を かく 程度の 運動を 週60分以上** | 運動ガイド 本体 成人版 推奨事項 |
| **筋力トレーニングを 週2〜3日**(週4メッツ・時の 運動に 含めて よい) | 運動ガイド 本体 成人版・高齢者版 / INFO3 |
| **高齢者**: 強度が 3メッツ以上の 身体活動を **週15メッツ・時以上**。具体的には 歩行 又は それと 同等以上の 身体活動を **1日40分以上**(**1日 約6,000歩以上**に 相当)。体力の ある 高齢者は 成人と 同量(週23メッツ・時以上)で さらに 効果 | 運動ガイド 本体 高齢者版 推奨事項 |
| **高齢者**: 筋力・バランス運動・柔軟性 など **多要素な 運動を 週3日以上** | 運動ガイド 本体 高齢者版 / INFO3 |
| 座位行動(座りっぱなし)の 時間が 長く なりすぎない ように 注意(INFO3 の 例: 30分に 1回 短時間でも 中断して 体を 動かす) | 運動ガイド 本体・INFO3 |
| 慢性疾患(高血圧・2型糖尿病・脂質異常症・変形性膝関節症)が あっても、身体活動を 制限する 状態で なければ 成人・高齢者と 同じ 推奨(週23メッツ・時 / 1日60分 ・ 高齢者や 体力の 低い 人は 1日40分) | INFO3 ポイント |
