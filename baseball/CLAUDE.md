## フリックワールドベースボール(`baseball/`。けいくん 2026-10-10「ワールドベースボールの専門家(解説者)になれるレベルになるために必要な 知識、主要な野球リーグ、有名野球選手、有名な技、ルールをフリック形式の問題にしてください」→ 5つの 問いと「いまの スター選手は チーム名を 書かない」に「全部おすすめで」。まとめは `docs/フリックワールドベースボール-はじめかた.md`)

- 名前は「フリックワールドベースボール」(けいくん決定。絵が 届いたら 題名に そろえる。フォルダ名 `baseball` は 変えない)。シリーズの 絵文字は ⚾。`SERIES_ORDER` は **バスケットボールの となり**
- 旅は 9つ(野球のきほん `kihon`・ルール `rule`・世界のリーグと大会 `league`・名門チームとライバル `team`・いまのスター選手 `star`・伝説の選手 `legend`・技とテクニック `waza`・戦術と解説のことば `tactic`・世界大会と代表 `cup`)+ マスター。
  **旅ごとに 70語(入門20・中級25・上級25)= 630語**。かずともの 旅の 名前は **`bb` で はじめる**(bbkihon / bbrule / bbleague / bbteam / bbstar / bblegend / bbwaza / bbtactic / bbcup / bbmas。speed-king #370)
- むずかしさは 3段: 入門(野球が すきな 小学生)→ 中級(少年野球の コーチ・野球好きの 大人)→ 上級(解説者)。学ぶ 分野(`field`)7つ: ルール / 投手の技 / 打撃・守備・走塁の技 / 戦術 / リーグ・チーム / 選手 / 大会・歴史
- ⭐ **国旗の 札**(`country` → `co`。27の 国・地域。⚠️ プエルトリコは WBC では アメリカと 別の 代表)と **⚖️ ルールの 札**(`ruleset` → `rs`。`NPB` / `MLB` / `高校` / `共通`。「・」で 3つまで)。
  ルールの 札は この ゲームだけの 欄(`baseball.js` の `rulesetTag`。オレンジの 札)。`rule` の 旅は 70語 ぜんぶに 付いている
- ことばは `tools/baseball/terms-<旅>.json`(決まりは `tools/baseball/PROMPT.md`。**どの 語を どの 旅に 入れるかの 一覧**も ここ)→ `tools/baseball/terms_js.py` → `baseball/terms.js` + `data/baseball.json`。
  しくみは `baseball/baseball.js`(ワールドサッカーを 写して ⚖️ ルールの 札を 足した。4択クイズ あり)。しくみ図は コードで 描く 箱の 図 9つ(`tools/baseball/mkmeta.py`): **グラウンドと 守備番号**(1 投手 〜 9 右翼手。6-4-3 が 読める)・野球規則の 地図・世界の リーグの 地図・名門チームの 町・いまの スターの ダイヤモンド・伝説の 選手の 殿堂・技と テクニックの 道・作戦ボード・世界大会と 代表の 地図
- 事実は `tools/baseball/exam.txt`(→ meta.json の `exam`。meta に `rulesVersion` / `checkedOn` / `reviewEvery`):
  **ルールは 公認野球規則 2026年版・NPB 2026年・MLB 2026年度・日本高野連 2026年度で 確かめた(2026年10月10日)**。
  MLB: ピッチクロック 15秒 / 18秒・牽制は 1打席 2回まで・ベース 18インチ・シフト制限 2023年・延長の 自動走者(ふだんの 試合だけ。ポストシーズンは なし)・ユニバーサルDH 2022年・**ABS チャレンジ 2026年から**(1チーム 2回・当たれば へらない)。
  NPB: **セ・リーグの DH は 2027年から**・延長は 12回まで・引き分け あり・リクエスト 2018年・コリジョンルール 2016年・ピッチクロックは まだ 無い。
  高校: **DH 制 2026年春の 選抜から**・タイブレーク 2023年から 10回・投球数 1週間 500球・低反発バット 2024年・7イニング制は 決まっていない。
  **2026年 WBC は ベネズエラが はじめて 優勝**(3月17日 マイアミ 3-2 アメリカ。MVP マイケル・ガルシア。日本は ベスト8)。日本の 優勝は 2006・2009・2023 の 3回で いちばん 多い
- ⚠️⚠️⚠️ **数字が 変わる ものを 書かない**: いまの 所属チーム・年俸・契約金・いまの 順位・いまの 選手の 通算記録・年齢(台本 `BAN` / `BAN_RE`)。
  **いまの スター選手(`star`)は チーム名・所属・移籍・契約・通算を 書かない**(`STAR_BAN` が MLB 30球団・NPB 12球団の 名前ごと 止める)。引退した 選手の 記録(王 868本塁打 など)は よい
- ⚠️ 台本の `BAN` は「死」「殺」「下手」を 止めるが、**死球・無死・一死・二死・三死・盗塁死・走塁死・牽制死・憤死・併殺・刺殺・補殺・封殺・挟殺・下手投げ**は `OK_WORDS` で 通す(野球の ことば)。⚠️ 新しく 止めたい 字を 足すときは この 一覧と ぶつからないか 見る
- ⚠️⚠️ **人を けなさない・悲しい 場面を 入れない**(エラーで 負けた・サヨナラ負け・ビーンボール・乱闘・黒い霧・薬物・賭け・サイン盗み・隠し球)。**日本代表が 負けた 場面を 相手の 名場面として 書かない**。
  **薬物・賭けで 知られる 人は 入れない**(ボンズ・ローズ・クレメンス・A・ロッド・ソーサ・マグワイア / 書く 途中で 江夏豊・デビッド・オルティス / 確かめ役が アロザレーナ(2020年の 逮捕の 報道)→ アレハンドロ・カーク、タティス・ジュニア(2022年 薬物の 出場停止)→ ケテル・マルテ に 入れかえた)。
  ジャッキー・ロビンソンは「壁を こえた 前向きな 話」(差別・人種の 字は 使わない)。ルー・ゲーリッグは 病気と 結びつけない。亡くなった 選手は 功績だけ(張本勲も)
