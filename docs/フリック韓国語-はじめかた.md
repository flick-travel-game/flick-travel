## 2. はじめに けいくんに 聞く 5つ(「全部おすすめで」と 返ってくる ことが 多い)

### 2-1. ⭐⭐ いちばん 大事: **何を 打つか**(英会話との いちばん 大きな ちがい)
英会話は 日本語キーボードの「ABC」で **英字を そのまま 打ち写す**。韓国語の ハングルは **日本語キーボードでは 打てない**(iPhone に 韓国語キーボードを 足せば 打てるが、子どもの スマホには まず 入っていない)。だから 3つの 案を 出す:

| 案 | 打つ もの | よい ところ | こまる ところ |
|---|---|---|---|
| **A(おすすめ)** | **読みの ひらがな**(안녕하세요 → `あんにょんはせよ`) | 日本語の フリックの まま あそべる。**ハングルを 大きく 見せて 🔊 で 聞きながら 打つ**ので 発音が 身に つく | 読みの かな が 1とおりに 決まらない ことが ある(→ 下の 決まりで ふせぐ) |
| B | **ハングル**(韓国語キーボード) | 本当の 韓国語の 打ちかた。ネイティブに いちばん 近い | キーボードを 足す 手間。小学生には むずかしい |
| C | A が はじめ + **「ハングルで 打つ」の 切りかえ**(設定) | 両方 できる | 作る 量が 少し ふえる |

⭐ **おすすめは C**(はじめは A。韓国語キーボードを 入れた 人だけ B に 切りかえ)。⚠️ まず **A だけ 作って**、B は あとから 足しても よい(けいくんに 聞く)

**A の 読みの かな の 決まり**(⚠️ ここが 事故の もと):
- **読みは 手で 書かない**。助手には **発音どおりの ハングル**(`pron`。例: 한국어 → `한구거`、같이 → `가치`)を 書かせ、`korean_js.py` が **1つの 表で** かな に する(英会話・英語の「`reading` は 手で 書かない」と 同じ 考え)
- 表は `tools/kankoku/kana_table.py` の 1か所。**パッチム**(받침)の かな(ㄴ = ん / ㅁ = む / ㅇ = ん / ㄹ = る / ㄱ = く / ㅂ = ぷ / ㅅ・ㄷ = っ など)は **作る 前に けいくんに 見せて 決める**
- ⚠️ **ん が 2つ ある**(ㄴ と ㅇ)。どちらも「ん」で 打てる ように する(打ちわけを 求めない)
- 打つ ときは **長音・小さい字の ゆれを 許す**(`norm`: カタカナ → ひらがな・「ー」を 消す・小さい っ を 消して くらべる など。英会話の `norm` と 同じ 考え)
- 画面には **ハングル(大きく)+ 読みの かな(小さく)+ 🔊**。打つ のは かな、目で 見るのは ハングル

### 2-2. **名前**
「フリック韓国語」で よいか(フォルダ名 `kankoku` は 変えない。かずともの 旅の 名前は **`kr`** で はじめる: krhan / krw1 / krw2 / krw3 / krw4 / krgram / krtalk / krnative / krmas。**作る 前に `build_games.py` と speed-king の `flick.ts` で `kr` と `"kankoku"` が 空いているか 確かめる**。2026-10-10 には 空いていた(⚠️ `kt` は からだ図鑑の ツボ `ktsubo`、`ko` は 国語))

### 2-3. **旅の 分けかた**(おすすめ 8つ + 🏆 マスター。英会話の「単語 4段 + 日常会話」に、韓国語に 要る **ハングル・文法・ネイティブ表現**を 足した)

- 💬 **日常会話** `krtalk`(英会話の 場面を 写す: あいさつ・自己紹介 / 気持ち・あいづち / 聞き返す・たのむ / **食堂・カフェ** / 買い物 / 道案内・地下鉄 / 空港・ホテル / 病院・困ったとき / 電話・約束 / 仕事。⭐ **韓国らしい 場面**: **年上と 話す**(年を 聞く・言葉づかいを 変える)・**「ご飯 食べた?」**(밥 먹었어? = あいさつ)…)

⚠️ 英会話と 同じく **1回は かならず 10問・いつも 同じ 10問**(スピード記録勝負)。苦手克服・ふくしゅうは 作らない(けいくん 2026-09-27「苦手克服と復習は無しにして スピード記録勝負に揃えてください」)

### 2-4. **むずかしさの 4段**(英会話と 同じ `difficulty` 1〜4)

## 3. ⚠️⚠️⚠️ ぜったいの 決まり(英会話の PROMPT.md と 同じ + 韓国語だけの もの)
- **韓国語は ソウルの 標準語で、ネイティブが いま ふつうに 使う 形**。古い 言いかた・直訳・日本語の 語順を そのまま 置きかえた 文は ダメ
- **市販の 単語帳・TOPIK の 過去問・教科書の 文を 写さない**。例文・訳は ぜんぶ 自分で 書く
- **敬語の 段を まちがえない**: 例文ごとに **どの 段か**(합니다 / 해요 / 반말)を そろえる。⚠️ **年上・店員さんへの 例文で 반말を 使わない**
- **読みは 手で 書かない**(2-1)。`pron`(発音どおりの ハングル)だけ 書かせる
- 子どもが 見るので、**お酒(焼酎・マッコリ)・たばこ・お金もうけ・こわい話・恋愛の 話**は 例文に 入れない(英会話と 同じ)。⚠️ 사랑해(愛してる)は **家族に 言う 場面**なら よい
- ⚠️⚠️ **政治・歴史の あらそいの 話は 入れない**(日本と 韓国の 歴史問題・領土・北朝鮮・戦争)。**国や 人を 下げる 書きかたを しない**
- **悪口・スラング・からかいの ことばは 入れない**(若者ことばは **やさしい ものだけ**。迷ったら 入れない)
- **実在の 芸能人・アイドル・グループ・ドラマの 名前を 入れない**(⚠️ K-POP の 名前は 子どもが 喜ぶが、商標・肖像の 心配が ある。**「K-POP」「ドラマ」と いう ことばまで**)。店・会社・商品の 名前も 入れない
- ✅ **食べもの・地名・行事の 名前は よい**(キムチ・ビビンバ・トッポッキ・ソウル・釜山・済州島・ソルラル・チュソク)
- ✅ **ほかの ゲーム(英会話・英語・国語・世界旅行 など)と 同じ 意味の 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。⭐ **日本語と 音が にている 漢字語**は「日本語では ◯◯」と 説明に そえると へえ
- **同じ ハングルを 2回 入れない**(`korean_js.py` が 止める)
- 日本語は やさしく。小学生が 読める ていど(漢字は 使ってよい。あとで ふりがなを 付ける)。**日本語訳の 語の あいだに 半角スペースを 入れない**(英会話と 同じ)
- 画面に「これは ことばを おぼえる ゲームです」・🔊 は「端末の 読み上げ機能を 使うので、端末に よって 声が ちがいます」(英会話の `note` と 同じ)
- **作った 助手とは 別の 助手が 1語ずつ 確かめる**(意味・**敬語の 段**・**発音(`pron`)**・自然な 韓国語か・子どもに よいか)。⚠️ **ネイティブの 目で 見てくれる 人**が いれば いちばん よい(けいくんに 聞く)

## 4. 事実は **その日に 確かめてから** 書く
- **ハングルの 歴史**(世宗大王・訓民正音・ハングルの日)… 年は 確かめる
- **ローマ字・発音の 決まり** … 韓国の 国立国語院の 決まり(表記法)で 確かめる
- ⚠️ 「ネイティブに なれる レベル」= **ネイティブが ふだん 使う ことば・文法・敬語・言いまわしを ひととおり 知っている**こと、と けいくんに 伝える。**話す・聞く 力**は 🔊 と 実際の 会話で 身に つく もの。ゲームは その 土台(英会話と 同じ 伝えかた)

## 5. 作りかたの 手順(英会話の ときと 同じ)
1. けいくんに 2 の 5つを 聞く(**とくに 2-1 の 打つ 字と パッチムの かな の 表**)→ 返事を CLAUDE.md に 書く
2. `tools/kankoku/PROMPT.md`・`kana_table.py`・`korean_js.py` を 作る → **先に 8つの 旅の 語の 一覧を 1人の 助手に 作らせて 置き場所を 決める**(単語の 段の かぶり・文法と 会話の かぶりを ふせぐ)→ 旅ごとに 助手に 頼む(`PROMPT.md` を そのまま わたす。**助手は 2人ずつ**)→ `data/korean.json`
3. `korean_js.py` で 止められた 語を 直す → 別の 助手が 1語ずつ 確かめる(**意味・敬語の 段・発音・子どもに よいか**)→ ふりがな(日本語訳)
4. `kankoku/kankoku.js`(eikaiwa.js を 写し、**ハングルを 大きく・かな を 小さく・🔊 は ko-KR**)・`build_games.py`・`index.html` の PLUG と SERIES → `python3 tools/build_games.py`
5. 手元で 通す: `python3 -m http.server 8765` → `node tools/play-all.mjs kankoku/` / `node tools/click-all.mjs kankoku/`(W=320 も)。⚠️ **🔊 の 韓国語の 声**は Playwright では 鳴らないので、**けいくんの iPhone で 1回 聞いてもらう**
6. PR は **rebase で 取りこむ**(この 入れもの)。speed-king は squash。コミットの 末尾は Co-Authored-By と Claude-Session の 2行
7. かずとも `speed-king`: `FLICK_MODES` / `FLICK_LINK_TARGETS` に `kr…` と `kankoku`(PR → squash)。`HOME_GAMES` は 絵と OK の あと
8. けいくんに ChatGPT で 絵を 頼む 文を わたす。**3つ**(**トップの 絵と 題名は いっしょに 頼む**):
   ・トップの 絵(1536×1024)。**人物は 画面の 下 3分の1に 小さく**・指5本・手首から 腕が 1本だけ・首が 見える。
     英会話の 絵と 同じ 雰囲気で、ソウルの 町なみ(伝統の 宮殿の 屋根と 高いビル)と ハングルの ふきだしの 中を、男の子と 白い 犬が 飛んで 旅する 絵。トッポッキ・キンパの 屋台、韓服(ハンボク)の 色の リボン。
     **実在の 芸能人・お店・会社の 名前や ロゴを 描かない**。**国旗以外の 政治の しるしを 描かない**。
