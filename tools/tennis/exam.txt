①ルールの 版
・いまの ITF の 規則書は **2026 Rules of Tennis**(ITF 公式 PDF。規則 1〜31 + 車いすテニス + 付録 I〜XII)。
  英語版が 正本(ほかの 言葉と ちがう ときは 英語版が 勝つ)。
  2026年の 変更(ITF「2026 amendments」): 規則18(フットフォールト)に ダブルスで 立てる 場所の ことわり / 規則27(まちがいの 直しかた)に タイブレークで エンドを まちがえた ときの ことわり / 付録V(広告)/ ビーチテニスの ラケットは 光らない 面。
・JTA(日本テニス協会)「テニスルールブック」の いまの 年度版は (確かめられなかった)。→ 未確認(書かない)。
・**タイブレーク**: 先に **7点**。**2点差**が つくまで つづく(ITF 規則 5b)。最初の 1点を 打ったら あとは **2点ずつ** 交代で サーブ。タイブレークは **6点ごとに エンドを かえる**(規則 10)。
・セット: 先に **6ゲーム**・2ゲーム差(規則 6)。6-6 で タイブレーク(タイブレークセット)か、2ゲーム差まで つづける(アドバンテージセット)。どちらに するかは 大会が 先に 決める。
・**4大大会の 最終セット**: **6-6 で 10点 タイブレーク**(先に 10点・2点差)。2022年3月16日に Grand Slam Board が 4大会 そろえると 発表、**2022年 全仏から** ためし で 始めた(tennis365 / BusinessLive)。それまでは 全豪=10点 / 全米=7点 / ウィンブルドン=12-12で 7点 / 全仏=タイブレーク なし。ずっと(本決まり)かは (確かめられなかった)が、2026年も 使われて いる(2026年 全仏 男子決勝 6-1 4-6 6-4 6-7 6-1 は 最終セット 6-1)。→「2022年から 4大会 そろって 10点」は 書いて よい。
・**ポイントの あいだは 最大 25秒**(ITF 規則 29a)。
・**エンドを かえる とき(チェンジコート)は 最大 90秒**。**ただし 各セットの 1ゲームめの あとと タイブレーク中は 休まずに かえる**。**セットの あいだは 最大 120秒**(規則 29a)。
・メディカルタイムアウトは **3分**(1回。規則 29c)。ウォームアップは **最大 5分**(規則 29e)。
・**コーチング**(ITF 規則 30 + 付録 IV):
  ・コートの 外から(Off-Court Coaching)は **大会を 持つ 団体が 認めれば よい**。
  ・コートの 中(On-Court)は **団体戦で キャプテンが ベンチに すわる ときだけ**(デビスカップ など)。
  ・**ポイント中は 禁止**。ポイントの あいだ・チェンジコート・セットの あいだ に よい。
  ・**ことばは コーチと 選手が 同じ エンドに いる ときだけ**、**手の 合図は いつでも**(認められて いる とき)。**短く・目立たないように**(休けい中は 長くて よい)。
  ・ITF が 2024年10月に 決め、2025年から(AP / アルジャジーラ)。**2025年 全豪から 4大大会で はじめての「コーチング・ポッド」**(コートの すみの 席。4人まで)。
・**電子の ライン判定(ELC)**:
  ・**ATP は 2025年から すべての 大会で ELC Live**(「アウト」は 機械。線審 なし。主審は いる)。クレーも ふくむ(ATP 2023年4月の 発表・ESPN / AP)。ほんとうに 全大会で そうなったかの 2025年の まとめ記事は (確かめられなかった)。
  ・**ウィンブルドンは 2025年から 線審を やめて 電子判定**(2024年10月 オールイングランドクラブ 発表。1877年から つづいた 線審が いなくなった)。ホークアイは 2007年から 使っていた。
  ・**全仏(ローランギャロス)は 2026年も 線審を 残した**(FFT。モーレスモ 大会責任者「機械は 100% では ない」)。4大大会で ただ1つ。クレーでは **ボールの あと(マーク)を 主審が 見に いく**(2026年 ルード対フォンセカで 話題 — 話は 書かない)。
  ・全豪・全米は もう 電子判定(Sky Sports / Wimbledon の 記事)。
  ・**チャレンジ(ホークアイの 選手の ためし)の 回数**: いま どこで 何回かは (確かめられなかった)→ 未確認(書かない)。
・**レット**: サーブが ネット(ストラップ・バンド)に ふれて 正しい サービスコートに 入れば **レット(やりなおし)**(ITF 規則 22)。「ノーレット」は 付録 VI の **選べる 方式**に すぎない。ATP/WTA ツアーの ふつうの 試合は いまも レット あり と 読めるが、ツアー規則の 本文は (確かめられなかった)。
・**車いすテニス**: **2バウンドまで**よい(3回め の 前に 返す。2回めは コートの 外でも よい)。**車いすは 体の 一部**。サーブの 前に **1回 こいで よい**(ITF 車いすテニス規則)。
・**ノーアド**: デュースで 次の 1点を とった 方が ゲーム(付録 VI)。
・**マッチタイブレーク(10点)**: 最後の セットの かわりに 先に 10点・2点差(付録 VI)。**ATP Finals の ダブルスは 2セット(ノーアド)+ マッチタイブレーク**(Wikipedia 2026 ATP Finals)。ツアーの ふだんの ダブルスの 本文は (確かめられなかった)。
・**アンダーサーブ(下から 打つ サーブ)**: 規則 16 は「手から ボールを はなし、地面に つく 前に 打つ」だけ。上から 打てとは 書いて いない → 反則 では ない。
・**フットフォールト**(規則 18): サーブ中に ①歩く・走る(少し 動くのは よい)②ベースラインや コートに 足が ふれる ③サイドラインの のばした 線の 外に ふれる ④センターマークの のばした 線に ふれる。**両足とも 地面から はなれても よい**。シングルスで シングルスと ダブルスの サイドラインの あいだに 立つのは だめ(ダブルスは よい)。
・トスを 上げて 打たずに **つかむ のは フォルトでは ない**(規則 19 ケース1)。
・**ボールの 交換**: 「決めた 奇数の ゲーム ごと」(最初は ウォームアップの 分 2ゲーム 早い)か「セットの はじめ」(規則 3)。**「7ゲームめ・その あと 9ゲーム ごと」は ツアーの ならわし**で、ITF 規則の 本文には 数字は ない → 数字は 未確認(書かない)。
・**5セットマッチ**: 4大大会の 男子シングルス だけ と いう 公式の 一覧は (確かめられなかった)。**デビスカップ ファイナルは 2セット先取(3セットマッチ)**(2026年 ファイナル8 の 説明)。
・**Next Gen ATP Finals(2025年 ジッダ・12月17〜21日)の ためし ルール**(ATP 公式): **1セット 4ゲーム先取**(2ゲーム差)・**3-3 で 7点 タイブレーク**・**5セットマッチ(3セット先取)**・**ノーアド**(サーブを うける 方では なく サーブする 方が サービスボックスを えらぶ)・1ゲームめの あと エンドを かえない・セットの あいだ 90秒・**1本め と 2本め の サーブの あいだ 8秒**・3打 より 短い ラリーの あとは 15秒・ウォームアップ 3分・7ゲームごとに ボール交換。

③歴史
・**1877年 第1回 ウィンブルドン**(Wikipedia)。
・**1968年 オープン化**(プロも 4大大会に 出られる ように)。ロッド・レーバーは 1963年に プロに なって 4大大会に 出られなく なり、オープン化の あと 1969年に また 年間グランドスラム(tennishead)。
・**デビスカップ**: はじまりの 年(1900年)は この 調べでは 公式で (確かめられなかった)→ 年は 未確認(書かない)。いまの ファイナル は **8チームの 勝ちぬき**・1試合は シングルス2 + ダブルス1・**3セットマッチ**。2026年は **ボローニャ**(11月24〜29日)。ロシア・ベラルーシは 団体戦に 出られない(ITF)。
・**ジュ・ド・ポーム**(手のひらの 遊び)が もと と される。「テニス」は フランス語の **「tenez(テネ:さあ 受けて)」から と 言われる**(オックスフォード英語辞典 / OUP ブログ。説の 1つ)。
・**ITF**: **1913年3月1日 パリで「国際ローンテニス連盟(ILTF)」として できた**。1977年に「ローン」を とった(Tennis Majors)。いまの 本部は **ロンドン(ローハンプトン)**(Tennis Majors。1998年から と 書くが 公式で 未確認 → 年は 書かない)。
・**国際テニス殿堂**: アメリカ **ロードアイランド州 ニューポート**の **ニューポート・カジノ**。**1954年**に ジミー・ヴァン・アレン夫妻が つくった(tennisfame.com / ivy-style)。1986年に ITF が みとめた。カジノでは 1881年に 芝の 大会(全米の はじまり)。
・**JTA(日本テニス協会)**: **1922年 設立**(任意団体)。1980年 財団法人、2012年 公益財団法人。**ITF に 1923年3月12日 加盟**。初代会長 朝吹常吉。1921年に デビスカップに はじめて 出て 決勝まで 進み、その 分配金で できた と される(JTA 資料)。
・**熊谷一弥**(くまがえ いちや): **1920年 アントワープ五輪 男子シングルス 銀**・**ダブルスも 柏尾誠一郎と 銀**。**日本の 五輪メダル 第1号**(JTA 資料 / コトバンク)。慶應義塾 出身。
・**佐藤次郎**: 1933年 ウィンブルドン ベスト8(松岡修造の「62年ぶり」から 逆に 数えた もの。ウィキ系 サイトの 書きかた)→ くわしい 成績は 未確認(書かない)。
・**沢松和子**: **1975年 ウィンブルドン 女子ダブルス 優勝**(**アン清村**と。決勝 デュール / ストーブに 7-5 1-6 7-5)。日本の 女性で はじめて ウィンブルドンの トロフィーに 名前(Number Web / Wikipedia)。
