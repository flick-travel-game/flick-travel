# フリックワールドテニス(`tennis/`)を 作る ための まとめ(2026-10-24。新しい セッション用)

けいくん 2026-10-24「新しいセッションで フリックワールドテニスを作成したい。**ワールドテニスの専門家(解説者)になれるレベル**になるために必要な 知識、**主要なテニスリーグ、有名テニス選手、有名な技、ルール**をフリック形式の問題にしてください」

⭐ **フリックワールドサッカー(`soccer/`)・バスケットボール(`basket/`)・ベースボール(`baseball/`)・ボクシング(`boxing/`)・バレーボール(`volley/`。まとめだけ)と 兄弟の ゲーム**(6つめ)。まとめの 型・決まりは `docs/フリックワールドバスケットボール-はじめかた.md` と **ほぼ 同じ**。ちがう ところ(**個人の スポーツ**(リーグではなく **ツアー**と **4大大会**)・**サーフェス(コートの 面)が 3つ**・**日本人が 世界の 上位に いる**・**車いすテニスが とても 強い**)だけ 気を つける。

## 0. まず 読む もの(この 順で)
1. `CLAUDE.md`(この 入れものの 決めごと ぜんぶ。とくに **フリックワールドバスケットボール・ベースボール・ボクシング**の 節(兄弟の 作りかた・入れなかった 語)と、
   **「🧭 ゲームを えらぶ は 章ごと」「🙈 答えの ひらがな あり / 無し」「題名の 絵は ChatGPT に 切りぬいてもらう」「アイコンは 四角い 絵を 切らずに そのまま」** の 節)
2. ⭐ `docs/フリックワールドバスケットボール-はじめかた.md`(**この ゲームの 手本**。決まり・旅の 作りかた・毎年の 見直し)と `docs/フリックワールドボクシング-はじめかた.md`(個人の スポーツの 兄弟。**団体 → ツアー**に 読みかえる)
3. ⭐ `basket/basket.js` と `tools/basket/`(PROMPT.md・meta.json・mkmeta.py・terms_js.py・exam.txt・fix_text.py)… **これを 写して `tennis/tennis.js`・`tools/tennis/` に する**。国旗の 札(`country`)と ルールの 札(`ruleset`)の しくみが もう ある
4. `tools/rekishi/` と `tools/people-world.tsv` / `tools/people-japan.tsv`(**実在の 人物の 書きかた**の 前例)
5. 世界旅行の 国の データ(国名・首都)… 選手の 国・大会の 開催地と つなぐと へえに なる
6. `tools/build_games.py` の `"boxing": dict(...)` の 段(ゲームの 登録の 形)
7. `tools/title_from_art.py`(題名)と `tools/icon_from_square.py`(アイコン)。**どちらも けいくんの ChatGPT の 絵を そのまま 使う**(自分で 切らない)
8. `tools/fetch_game_photos.py`(ことばの 写真。`GAMES` に `tennis` を 足す。合わない ものは `NO_GAME_PHOTO` に。**人の 顔が 写る 写真は 入れない**ので 選手の 旅は `SKIP_PREFIX` で とばす)

## 1. 作る もの(兄弟と まったく 同じ 型)
| もの | 場所 |
|---|---|
| ことばの 決まり | `tools/tennis/PROMPT.md`(バスケの PROMPT.md を 写して テニスむけに) |
| 旅・ルールの 説明 | `tools/tennis/meta.json`(`mkmeta.py` の 型。ルールは **ITF「Rules of Tennis」の 何年版か**・**JTA(日本テニス協会)の テニスルールブックの 何年度か**・**確かめた 日**を 入れる) |
| ことば | `tools/tennis/terms-<旅>.json`(旅ごとに 1ファイル。**9の 旅 × 70語 = 630語**。旅ごとに 入門20・中級25・上級25) |
| 国の しるし | ⭐ 語に **`country` の 欄**(任意。選手・大会・技が どの 国の 話か: 日本 / スペイン / セルビア / スイス / アメリカ / イタリア / イギリス / フランス / オーストラリア / ポーランド など)。説明の 上に 小さな 国旗の 札(バスケと 同じ `COUNTRY`) |
| サーフェスの しるし | ⭐ 語に **`ruleset` の 欄**(任意: `ハード` / `クレー` / `グラス` / `共通`)。バスケの FIBA / NBA の 札の しくみを **コートの 面の 札**に 使う。**4大大会は 面が ちがう**(全豪・全米 = ハード / 全仏 = クレー / ウィンブルドン = グラス)ので、札で 分けると へえに なる。図鑑で 🎾 しぼれる |
| 変換 | `tools/tennis/terms_js.py`(バスケの を 写す。`BAN`・**ワールドテニスの 中での** 読みの かぶりを 止める。⚠️ ほかの ゲームとの かぶりは **止めない**)→ `tennis/terms.js` + `data/tennis.json` |
| しくみ | `tennis/tennis.js`(旅の 図は コードで 描く 箱の 図。**コートの 図**(ベースライン・サービスライン・センターマーク・**シングルスと ダブルスの サイドライン**(アレー)・ネット・サービスボックス・デュースサイド / アドサイド)・**スコアの 図**(0 = ラブ → 15 → 30 → 40 → ゲーム・デュース・アドバンテージ・タイブレーク)・**サーフェスの 表**(ハード / クレー / グラスの 球足と 大会)・**4大大会の 表**(時期・場所・面)・**世界地図に 4大大会と マスターズ** を 入れると よい) |
| 登録 | `tools/build_games.py` に `"tennis": dict(name="フリックワールドテニス", modes="TENNIS", ...)`、`index.html` の `const PLUG` に `TENNIS`・`SERIES` に `{id:"tennis", name:"フリックワールドテニス", icon:"🎾", dir:"tennis/"}`・⭐ **`SERIES_CHAPTERS` の「スポーツ」の 章の ボクシング(バレーが あれば バレー)の となり**(2026-10-24 から 章ごと。`SERIES_ORDER` は もう 無い) |
| 絵 | トップ `tennis/hero.webp`(1536×1024)。**アイコンは 四角い 絵(1254px)を `tools/tennis/art/square-src.png` に 置いて `python3 tools/icon_from_square.py tennis`(切らない)**。**題名は 透明 PNG を `tools/tennis/art/title-src.png` に 置いて `python3 tools/title_from_art.py tennis`**。届くまでは 仮の 絵で よい |
| かずとも 側 | `speed-king` の `src/lib/flick.ts` の `FLICK_MODES` と `FLICK_LINK_TARGETS` に `tennis` を 足す(**旅を 足したら かならず**)。販売ページ `HOME_CHAPTERS`(`src/lib/games.ts`。**「スポーツ」の 章**)と 規約の 一覧 `FLICK_SERIES_GAMES`(`src/lib/flick-url.ts` = **題名の ロゴの 字の まま**)は **絵と けいくんの OK を もらってから** |
| 法務の リンク・ひらがな 無し・ゲームを えらぶ | 土台の `index.html` が 全ゲームに 出すので **何も しなくて よい** |

## 2. はじめに けいくんに 聞く 5つ(兄弟は「全部おすすめで」「すべておまかせ」だった)

## 3. ⚠️⚠️⚠️ ぜったいの 決まり(兄弟と 同じ)
- ⭐⭐ **数字が 変わる ものを 書かない**(この ゲームで いちばん 事故が 起きやすい):
