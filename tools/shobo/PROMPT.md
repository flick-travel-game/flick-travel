# フリック消防士: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
学ぶ 分野・しくみ図の どこに あるか(📍)が 出る。あそぶのは **小学生〜消防士を めざす 中高生・大学生・大人**。
**消防士に なるための ことばと 意味を おぼえる ゲーム**(試験の 問題集では ない)。
もとは `tools/kango/PROMPT.md`(看護師)と `tools/keisatsu/PROMPT.md`(警察官)。
けいくん 2026-10-01「消防士になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめ」。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 5つ

### 1. やりかたを 書かない(看護師の「処置の やりかたを 書かない」と 同じ。火は なおさら)
- ❌ **書かない**: 火の つけかた・広げかた / 燃えやすい ものの 組みあわせ / 危険物の あつかいかた・まぜかた /
  救命処置の 手順(胸を 押す 回数・深さ・人工呼吸の やりかた)/ はしご・ロープ・結びかたの 使いかた / 消火器の 細かい 使いかた /
  温度・時間・回数の 決めうち(**法律・手引きの 数字なら よい。まよったら 書かない**)
- ⭕ **書くのは**: その ことばが **何を さすか**・**何の ための しくみか**・**消防士が どう 守るか・助けるか**・**みんなが どう 気をつければ よいか**
  - 例: 消火器 = 小さな 火を 消す ための 道具。使いかたは 本体に 書いてあり、地域の 訓練で 大人と いっしょに 練習します
  - 例: 心肺蘇生 = 心臓や 呼吸が 止まった 人の 命を つなぐ ための 手当て。くわしい やりかたは 消防署の 救命講習で 学べます
- 消火の しくみ(燃える 3つの 条件 など)は **「火を 消す 側」**の 書きかたで(「酸素を 断つと 火は 消えます」)。**「こう すると よく 燃える」は 書かない**
- **子どもが 家で 1人で まねを したく なる 書きかた(火・コンロ・ライター・花火)を しない**。火を 使う 話は「かならず 大人と いっしょに」

### 2. 小学生も あそぶ(こわく しない)
- ❌ 火事・事故・けが・死の ようすを 書かない。焼死・やけどの 度合い・一酸化炭素中毒の ようす・血の 話を しない
- ⭕ 防災教育で 教える こと は よい(「けむりを すわない ように 低い 姿勢で にげる」「おさない・かけない・しゃべらない・もどらない」)
- ⭕ **実際の 火災・事故の 名前・実在の 人物は 入れない**。ただし **東日本大震災・阪神・淡路大震災 など 防災教育で 学ぶ 大きな 災害は 名前だけ** 入れて よい(中身の ようすは 書かない)
- 読んだ 子が **「助けて くれる 人が いる」「火事や けがの ときは 119番」** と 思える 書きかたに する。**迷ったら その 語を 入れない**
- 「死亡」「死ぬ」「亡くなる」「焼死」「遺体」「血」「熱傷」「窒息」「犠牲」「悲惨」「放火」「爆弾」は 使わない(台本が 止める)。
  「◯センチ」「◯cm」も 書かない(処置の 深さに 見えるため。台本が 止める)

### 3. 法律は 名前と 目的だけ
- 法律は **「名前」と「何の ための 法律か」** だけ。**条文を 写さない**・**罰の 重さを 書かない**
- 条の 番号は **まちがいない ときだけ**(消防法 第1条 = 目的 など)。あやしければ 番号を 書かない

### 4. 試験・制度の 事実は 下と `tools/shobo/exam.txt` に 合わせる(2026年10月1日に 消防庁・東京消防庁の ページで 確かめた)
- 消防士(消防吏員)の ほとんどは **市町村の 消防本部・消防署の 地方公務員**。東京23区は **東京消防庁(東京都)**。**総務省消防庁の 職員は 国家公務員**
- 採用試験は **市町村・東京消防庁 ごと**。区分の 名前(Ⅰ類・Ⅲ類・大卒・高卒 …)は **ところで ちがう** と 書く。中身(教養試験・論文・面接・体力検査・身体検査・適性検査)も ところで ちがう
- 受かると **消防学校**で **初任教育**(東京消防庁は 全寮制)。消防庁告示「消防学校の教育訓練の基準」で 標準 800時間。期間の 月数は **書かない**(ところで ちがう)
- 階級は **10**(下から 消防士・消防副士長・消防士長・消防司令補・消防司令・消防司令長・消防監・消防正監・消防司監・消防総監)。**消防総監は 東京消防庁の 消防長 だけ**(全国に ひとり)
- 119番は **消防本部の 指令センター**へ。救急救命士は **国家資格(厚生労働大臣の 免許)**
- 消防団員は **ふだん ほかの 仕事を しながら 活動する 非常勤の 特別職の 地方公務員**
- 消防設備士・危険物取扱者は **国家資格**(試験は 都道府県知事が 行い、**消防試験研究センター**が 実施)
- 数字・年・条は **まちがいない ときだけ**。あやしい 語は **入れない**

### 5. 消防士の 目線で 書く(からだ旅行・看護師・警察官 など ほかの ゲームと 同じ 語を 入れて よい)
- ✅ **ほかの ゲームと 同じ ことばを 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)
- ⚠️ ただし 説明は **消防士の 目線**で 書きなおす。例: AED … からだ旅行「心臓の リズムを 整える 機械」/ 消防士「救急隊が 着く 前に まわりの 人も 使える ように、駅や 学校に 置いて あります。使いかたは 救命講習で 学べます」
- **読み(ひらがな)は 消防士の 7つの 旅の 中で かぶらない**(台本が 止める)。下の「旅ごとに 入れる / 入れない」を 守る

## 1語の 形(JSON)

```json
{"id":"sy-pumpsha","name":"ポンプ車","reading":"ぽんぷしゃ","journey":"sharyo","category":"消防車","difficulty":1,
 "field":"消防機械","type":"concept","emoji":"🚒","mapNode":"sharyo:pump","relatedTerms":["sy-hose"],
 "description":"水を 送る ポンプを のせた 消防車。消火栓や 防火水槽から 水を すいあげて、ホースで 火事の 場所まで 送ります。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(ふつうに 使う 言いかた。漢字・カタカナ・英字の 略語・数字 119番 など)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)
  - 数字は ひらがな(119番 → ひゃくじゅうきゅうばん / #7119 → しゃーぷななひゃくじゅうきゅう は 長いので 名前を「救急安心センター事業」に)
  - 英字の 略語は 読みかた(AED → えーいーでぃー)
  - ゆれる ことばは 1つに 決め、別の 読みは `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は **上級だけ**に、旅で 1〜2語まで(長い 名前は 短い 呼び名に。説明に 正式な 名前)
  - ⚠️ **読みを まちがえやすい ことば**(防火 ぼうか・延焼 えんしょう・水利 すいり・筒先 つつさき・吏員 りいん・警防 けいぼう・査察 ささつ・
    残火 ざんか・初任 しょにん・礼式 れいしき・操法 そうほう・指令 しれい・司令補 しれいほ・防ぎょ ぼうぎょ・消防司監 しょうぼうしかん・
    消防正監 しょうぼうせいかん・危険物 きけんぶつ・引火点 いんかてん・発火点 はっかてん・可燃物 かねんぶつ・防炎 ぼうえん …)は **1語ずつ 確かめる**
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級(下の「3段の 分けかた」)
- **field**: 学ぶ 分野。次の 13の どれか(消防庁告示「消防学校の教育訓練の基準」の 初任教育の 教科目を もとに した 分け。入門の 語でも いちばん 近い ものを 書く):
  `法学基礎・消防法` `消防組織制度` `服務と倫理` `理化学` `予防` `危険物` `火災防ぎょ` `救急` `救助` `防災` `消防機械` `訓練と体育` `採用試験と教養`
  - めやす: 消防法・法律の 名前 → `法学基礎・消防法` / 消防庁・消防本部・消防署・階級・消防団の しくみ → `消防組織制度` /
    公務員の 決まり・勤務・ことばづかい・倫理 → `服務と倫理` / 燃焼・酸素・けむり・熱・水の 性質 → `理化学` /
    火災予防・防火管理・消防用設備・立入検査(査察)・建物・広報 → `予防` / 危険物・危険物取扱者・引火点 → `危険物` /
    消火の 活動・放水・延焼・火災調査・安全管理 → `火災防ぎょ` / 119番・救急隊・救急救命士・AED・応急手当 → `救急` /
    救助隊・救助の 道具の 名前・特別な 救助 → `救助` / 地震・水害・土砂・緊急消防援助隊・避難所 → `防災` /
    消防車・ポンプ・ホース・空気呼吸器 などの 機械と 装備 → `消防機械` / 礼式・訓練・体力・操法 → `訓練と体育` /
    採用試験・教養試験・論文・面接・消防学校の 入り口 → `採用試験と教養`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(💀 ☠️ 🩸 💣 🔪 など こわい 絵文字は 使わない。🔥 の 多用も さける)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / 何の ために あるか・消防士は どう 守るか・どう 気をつけるか」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  専門用語を 専門用語だけで 説明しない。「1人」「2人」は ふりがなが 読みまちがえるので **ひとり・ふたり** と ひらがなで 書く
- **example**: なくてもよい

## ぜったいに 守ること

- **自分の ことばで 書く**。過去問・問題集・教科書・Wikipedia の 文を 写さない
- **実在の 火災・事故・人物・会社・商品の 名前**は 使わない(消防庁・東京消防庁など **役所の 名前は よい**)
- **数字は まちがいない ときだけ**
- 画面には「これは ことばを おぼえる ゲームです。本物の 試験問題では ありません。消防庁・市町村の 消防とは 関係ありません。火を 使う ときは かならず 大人と いっしょに。火事や けがの ときは 119番」が 出る
- 「100マス計算」「百ます計算」の 字を 使わない
