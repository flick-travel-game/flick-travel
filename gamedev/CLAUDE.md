# gamedev/ の メモ(この ゲームだけの 決めごと・いきさつ)

> シリーズ共通の きまりは 入れものの いちばん上の `CLAUDE.md`。2026-11-10 に そこから 1文字も 変えずに 移した。

## フリックゲームクリエイター(`gamedev/`。けいくん 2026-09-29「ゲームクリエイターになるために必要な 知識をフリック形式の問題にしてください」)

- 決めたこと: 課金・ガチャは **入れない**(「A」)。CERO・年れい区分・ペアレンタルコントロールなど **守る ことば**は 入れる。
  名前・段・プログラムの 旅・図は おすすめのまま(名前は 仮。絵が 届いたら 題名に そろえる。フォルダ名 `gamedev` は 変えない)
- ⚠️ **「本当にゲームクリエイターになれるレベルに」**(けいくん 同日)→ **4段**: 入門(あそぶ 人でも 知っている)→ 中級(作りはじめる)→
  上級(専門学校・大学で 学ぶ めやす)→ **プロ(ゲーム会社の 現場の めやす)**。**旅ごとに 100語(20/30/30/20)= 700語**。
  プロの 段は 行列・クォータニオン・ロールバック・PBR・リトポロジー・ドローコール・回帰テスト・スクラム・バーティカルスライス など。説明は 子どもにも 読める ことばで
- 旅は 8つ(ゲームのきほん `ggame`・考えて決める `gkikaku`・うごかすしくみ `gprog`・絵と音 `gart`・作る道具 `gtool`・直して仕上げる `gtest`・みんなにとどける `gtodoke`・コードと作りかた `gcode`)+ マスター `gmas`。**800語**
- ことばは `tools/gamedev/terms-<旅>.json`(決まりは `tools/gamedev/PROMPT.md`)→ `tools/gamedev/terms_js.py` → `gamedev/terms.js`。しくみは `gamedev/gamedev.js`(看護師を 写した。4択クイズ あり)。
  1語ごとに **どの 仕事の 人の ことばか**(`role`。プランナー・プログラマー・グラフィッカー・サウンド・デバッガー …)を 持ち、図鑑で しぼれる
- ⚠️⚠️ **AI旅行と 同じ 名前・読みの ことばは 入れない**(`tools/gamedev/ai-words.txt`。`terms_js.py` が 止める)。バグ・テスト・アップデート・リリース・バージョン などは 入っていない
- ⚠️⚠️ **本当の ゲームの 題名・会社・ゲーム機・ストア・キャラの 名前と お金の ことばを 出さない**(`terms_js.py` の `BAN`)。道具の 名前は Scratch・Unity・Unreal Engine・Godot・Blender だけ(作る道具の 旅だけ・順位や 値段を 書かない)
- ⌨️ **8つめの 旅「コードと作りかた」`gcode`**(けいくん 2026-09-29「コードの書きかたや作りかたはゲームクリエイターに必要? 必要なら追加してください」)。100語。
  打つのは ことば(if文・for文・代入・継承・コルーチン …)で、**「たとえば」に 1〜2行の コードの 見本**(`example`。等幅の 黒い 箱。ふりがな なし)。
  作る順番(企画 → 試作 → 本作り → 仕上げ → とどける)も ここ。**ほかの 7つの 旅には コードを 書かない**。見本は 別の 助手が 1行ずつ 確かめた(C# で 通らない `for (i = 0` などを 直した)
- しくみ図は コードで 描く 箱の 図 8つ。1つめは **ゲームの 画面の 地図**。
  ⚠️ **10問の あとの 説明・図鑑には 出さない**(けいくん 2026-09-29「地図スクロールが大変になるからいらない / 必要なら 10問終わったあとの説明にはのせないで」)。
  **ホームでは「🗺 しくみ図を ひらく」で たたんで ある**(`<details>`)
- 説明の ひとつだけの「数」は ふりがなの 道具が「すう」に するので、`terms_js.py` の `KAZU` が「かず」に 直す(**ruby_fix.json に 入れると 数学旅行など ほかの ゲームまで 変わる**ので ここだけ)
- 作った 助手とは **別の 助手が 1語ずつ 確かめた**(意味・読み・段・AI旅行とのかぶり・本物の 名前・お金)。ふりがなの 読みまちがい 6つを `tools/ruby_fix.json` に context 付きで 足した(宝物・床・音色・間近・画面端・中割り)。
  説明の「1人」「2人」は ふりがなが「ひと」に なるので ひらがなで 書く
- 絵(2026-09-29): けいくんの ChatGPT の 絵。トップ `gamedev/hero.webp`(1536×1024)・四角い 絵(1254px)から アイコン・題名は `tools/gamedev/logo_cut.py`(GrabCut で 白と 青の ふちごと)。
  **名前は 絵の 題名と 同じ「フリックゲームクリエイター」**なので 変えていない
  - ⚠️ **1回目の 絵は 入れなかった**: 7つの わくの 見本の ことばが AI旅行の ことば(ぷろぐらむ・ばぐ・てすと・あっぷでーと・ぱそこん・あぷり)や ゲームに 無い ことば /
    四角い 絵の「げーむえんじん」が 本物の ゲームエンジンの ロゴに そっくり / 4択に 正しい 答えが 無い。ゲームに ある 28語を わたして 作りなおして もらった
  - 2回目の 絵の「ぷ」(ぷろとたいぷ・てすとぷれい・ぷらんなー)は 丸が 2〜3画素で ぷ/ぶ が 見分けられない。ゲームでは 読めない 大きさなので そのまま 入れた
  - 四角い 絵の 小さい しくみ図には まだ「ぷろぐらむ・でーた・てすと」の 字が 残っているが、アイコンの 大きさでは 読めない
- かずともの `FLICK_MODES` / `FLICK_LINK_TARGETS` には 足した。販売ページ(`HOME_GAMES`)と 規約の 文(`FLICK_SERIES_GAMES`)は **絵と けいくんの OK を もらってから**
