# shobo/ の メモ(この ゲームだけの 決めごと・いきさつ)

> シリーズ共通の きまりは 入れものの いちばん上の `CLAUDE.md`。2026-11-10 に そこから 1文字も 変えずに 移した。

## フリック消防士(`shobo/`。けいくん 2026-10-01「消防士になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめ」。まとめは `docs/フリック消防士-はじめかた.md`)

- 名前は「フリック消防士」(絵が 届いたら 題名に そろえる。フォルダ名 `shobo` は 変えない)。シリーズの 絵文字は 🚒
- 旅は 7つ(消防車と道具のことば `sharyo`・火と消火のことば `shoka`・救急と救助のことば `kyukyu`・火事をふせぐことば `yobo`・災害と消防のことば `saigai`・消防の法律としくみ `shikumi`・消防士の心とからだ `kokoro`)+ マスター。
  **旅ごとに 70語(入門20・中級25・上級25)= 490語**。かずともの 旅の 名前は **`fr` で はじめる**(frsharyo / frshoka / frkyukyu / fryobo / frsaigai / frshikumi / frkokoro / frmas)。⚠️ `f` だけは 料理人が 使っている
- むずかしさは 3段: 入門(まちで 見かける 消防の ことば)→ 中級(**消防官採用試験の 教養試験 + 消防学校で 学ぶ ことばの めやす**)→ 上級(法律の 名前・設備の 専門用語・階級と 組織・**消防設備士・危険物取扱者**の 資格の ことば)。
  1語ごとに **学ぶ 分野**(`field` → 画面では 📘 学ぶ 分野)。消防庁告示「消防学校の教育訓練の基準」の 初任教育の 教科目を もとに した 13: 法学基礎・消防法 / 消防組織制度 / 服務と倫理 / 理化学 / 予防 / 危険物 / 火災防ぎょ / 救急 / 救助 / 防災 / 消防機械 / 訓練と体育 / 採用試験と教養
- ことばは `tools/shobo/terms-<旅>.json`(決まりは `tools/shobo/PROMPT.md`)→ `tools/shobo/terms_js.py` → `shobo/terms.js` + `data/shobo.json`。
  しくみは `shobo/shobo.js`(警察官を 写した。4択クイズ あり)。しくみ図は コードで 描く 箱の 図 7つ(**消防車の図**・火と消火・救急と救助・家とまち・災害・**消防署の地図**・心とからだ。`tools/shobo/mkmeta.py` が meta.json を 作る)
  ⚠️ エンジン(`index.html`)の `const PLUG = …` の 列に `SHOBO` を 足した(足さないと ページが「reading 'time'」で 止まる。新しい ゲームを 足す ときは ここも)
- 試験・制度の いまの形は `tools/shobo/exam.txt`(→ meta.json の `exam`)に **確かめた日つき**(2026年10月1日に 消防庁告示「消防学校の教育訓練の基準」の PDF と 東京消防庁の ページで 確かめた):
  ほとんどは 市町村の 地方公務員(東京23区は 東京消防庁 = 東京都・消防庁の 職員は 国家公務員)/ 採用試験は 市町村・東京消防庁 ごと・区分名は ところで ちがう(東京消防庁は 消防官Ⅰ類・Ⅲ類・専門系 など。Ⅰ類は 教養試験か 適性検査+論文を えらべる)/
  初任教育の 標準は 800時間(東京消防庁は 全寮制。**月数は 書かない**)/ 階級は 10(消防総監は 東京消防庁の 消防長 だけ)/ 119番は 消防本部の 指令センター / 救急救命士は 国家資格 / 消防団員は 非常勤の 特別職の 地方公務員。⚠️ 文を 直すときは その日に 確かめて `exam` の 日付も 上げる
- ⚠️⚠️⚠️ **やりかたを 書かない**: 火の つけかた・燃えやすい 組みあわせ・危険物の あつかい・救命処置の 手順(回数・深さ)・機材の あやつりかた。**名前と「何の ための ものか」「消防士が どう 守るか」「どう 気をつけるか」だけ**。
  画面(ホームの 下・遊びかた)に「本物の 試験問題では ありません」「火を 使う ときは かならず 大人と いっしょに」「火事や けがの ときは 119番」「総務省消防庁・市町村の 消防とは 関係ありません」
- ⚠️⚠️ **小学生も あそぶ**: 焼死・やけどの 度合い・中毒の ようす・被害の 数を 書かない。大きな 災害(東日本大震災・阪神・淡路大震災)は 名前と「防災を 学ぶ きっかけ」まで。
  `terms_js.py` の `BAN` が こわい ことば・放火・「◯センチ」(処置の 深さに 見える)などを 止める
- ✅ 看護師・警察官 など ほかの ゲームと 同じ 語を 入れて よい。読みは **消防士の 7つの 旅の 中で** かぶらない(`terms_js.py` が 止める)。
  はじめ かぶったのは 4つ: 火元(火と消火 に のこし、予防は「火の元(ひのもと)」)/ 火災予防条例・消防同意(予防 に のこし、しくみは 建築基準法・消防水利の基準 に)/
  **消防監(階級)と 消防官 が どちらも しょうぼうかん**(階級を のこし、心とからだは「消防の仕事」)。消防庁 と 消防長 も 同じ 読みなので 庁は「総務省消防庁」で 入れた。3月7日は「消防の日」ではなく **消防記念日**
- ふりがなの 読みまちがいは **消防士の 中だけで** 直す(`terms_js.py` の `FIX`): ひとつだけの 数 → かず / 1日中 / 4月1日 / 局 / **避難所 → ひなんじょ**(ひなんしょ に なる)。
  ほかは 説明を 言いかえて 直した(通って → とおって・入れない → はいれない・札 → ふだ・箱 → 入れもの・給油取扱所 は 説明から 外した など)
- 作った 助手とは **別の 助手が 1語ずつ 確かめた**(7つの 旅 ぜんぶ。直しは 50ほど)。大きな 直しは ノズル(筒先 と 同じ ものでは ない)・化学消防車(空港の 消防車は 空港の もの)・
  消防設備士の 甲種(工事も 整備も / 乙種は 整備だけ)・消防同意(建築の「確認」の とき)・救急救命士法の 目的・緊急地震速報(ゆれの「前に」とは かぎらない)・119番の日の 目的・
  防炎カーテン(ストーブの 近くには 置かない)・分岐金具の 読み(ぶんきかなぐ)
- 絵(2026-10-01): けいくんの ChatGPT の 絵。トップ `shobo/hero.webp`(1536×1024)・題名は `tools/shobo/logo_cut.py`(紺の ふちに かこまれた 字を 種に GrabCut。下の 帯は 弓なりなので 2次式で なぞって 切る・「士」の ヘルメットは のこす)・
  アイコンは 正方形の 絵(1254px)を 縮めた もの(`art.iconv` = 2。仮の 赤い アイコンを おぼえた 端末の ため)。**名前は 絵の 題名と 同じ「フリック消防士」**なので 変えていない
  - ⚠️ **1回目の 絵は 入れなかった**: 札の ことば 28こ中 8こが ゲームに 無い(きゅうじょ・かさいほうちき・すいがい・きゅうえん・いちいちきゅう・ゆうき・れんけい・おもいやり)/
    たおれた 人の 胸を おす 絵(けが人と 手当て)/ こわれた 家と がれきの 地震の 絵。ゲームに ある 読みを 指定して 作りなおして もらった(AEDの 箱・ゆれる 家だけ)
  - 2回目は 28こ ぜんぶ ゲームに ある ことを 読みで 確かめた。図鑑の 見本の 説明「くるいの あるい人」だけ 絵の 中で「ぐあいの わるい人」に 直した(`tools/shobo/fix_text.py`。Noto Sans CJK JP Bold で 1行 書きなおし)
  - 四角い 絵の 札には ゲームに 無い ことば(へるめっと・ろーぷ・ぼうかひょうしき・よていひなん・くみしき など)と 答えの 合わない 4択(水を ためる 設備 → 消火栓)が あるが、**アイコンの 大きさでは 読めないので そのまま**(医師・教師・料理人と 同じ 判断)
  - 絵を 頼む ときは 燃えている 建物や けが人を 描かない・**本物の 消防の 紋章や 実在の 消防本部の 名前を 描かない**・人物は 画面の 下 3分の1に 小さく。届いたら まず 字を 切り出して 読む
