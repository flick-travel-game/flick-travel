# フリック養蜂家(`yoho/`)を 作る ための まとめ(2026-11-01。新しい セッション用)

けいくん 2026-11-01「新しいセッションで フリック養蜂家を作成したい。**プロの養蜂家レベル**になるために必要な 知識をフリック形式の問題にしてください。**西洋蜜蜂(セイヨウミツバチ)が メイン**にしてください」

⭐ **試験の 無い 専門職(農家・獣医師・スーパーカー)と 同じ 型**。まとめの 型・決まりは `docs/フリック農家-はじめかた.md`(機械・農薬・動物の 決まり)と `docs/フリック獣医師-はじめかた.md`(生きものと 病気の 書きかた)と ほぼ 同じ。ちがう ところ(**主役が 虫(セイヨウミツバチ)**・**刺す 生きものを こわく しない**・**病気と 薬の 話が 多い**・**法律(養蜂振興法・家畜伝染病予防法)が ある**・**はちみつは 食べもの = 食の 安全の 決まり**)だけ 気を つける。
