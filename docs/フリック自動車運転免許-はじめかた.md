# フリック自動車運転免許(`menkyo/`)を 作る ための まとめ(2026-11-05。新しい セッション用)

けいくん 2026-11-05「フリック自動車運転免許を **免許が受かるレベル**で 作成したいので まとめてください」

⭐ **試験の ある ゲーム(気象予報士・税理士・薬剤師・パイロット)と 同じ 型**。いちばん 近い 手本は **`docs/フリック気象予報士-はじめかた.md`**(「受かる レベル」で 作った いちばん 新しい 兄弟)。
ちがう ところは 3つだけ:
① **試験が ⭕❌ の 2択**(ことばを 打つだけでは「ひっかけ」に 弱い)→ **⭕❌ もんだい を 足す**(気象予報士の 🧮 計算問題と 同じ 考え)
② **標識が 絵の 問題**(📷 写真クイズの しくみ = スーパーカー `supercar/` と 同じ)
③ **数字(30m・5m・60km/h など)が 試験の 中心**。気象予報士では「変わる 数字は 書かない」だったが、ここでは **法律で 決まった 数字は 書く**(確かめた 日つき・毎年 見直す)

3. **むずかしさの 3段**:
   ・入門 = **小学生**(歩く 人・自転車に のる 人として 知っておく 交通の きまり: 信号・横断歩道・標識の 色と 形・左側通行)
   ・中級 = **仮免許の 学科試験**(教習所の 第1段階。基本の 交通ルール)
   ・上級 = **本免許の 学科試験**(第2段階まで ぜんぶ。高速道路・危険予測・応急救護・車の しくみ・**ひっかけ**の 言いまわし)

5. **入れない もの**: **事故の むごい ようす**(亡くなった 人の 数・けがの ようす)・**実在の 車の 名前・メーカー**(スーパーカーで やる)・**教習所・保険会社・カー用品の 名前**・**反則金の 金額**(変わる。試験にも 出ない)・**都道府県ごとの 決まり**(公安委員会規則。地域で ちがう)・**「お酒は ◯杯なら 平気」のような 目安**(ぜったいに 書かない)・**つかまらない 方法・抜け道**・**いまの 事故の 数字**
6. ⭐ **⭕❌ もんだい を 足すか**(おすすめ: **足す**)。本物の 試験は **ぜんぶ ⭕❌**(仮免 50問・本免 95問。確かめる)。合否を 分けるのは **言いまわしの ひっかけ**(「かならず」「〜しなければ ならない」「〜しても よい」「◯m 以内」と「◯m 以上」)。ことばを 打つ だけでは ここが 練習できない。

7. ⭐ **シリーズの どの 章に 置くか**(おすすめ: **「くらしと心」の マナーの となり**。運転は しごとでは なく くらしの 力なので)。ほかの 案は「夢のしごと」の **整備士の となり**(車つながり)

## 3. ⚠️⚠️⚠️ ぜったいの 決まり
- ⭐⭐ **数字は 法律で 決まった ものを 書く**(この ゲームの いちばん 大事な ところ): 合図の 30m・駐停車禁止の 5m / 10m・徐行・法定速度・初心運転者期間 1年 など。
  ⚠️ **1つずつ「交通の教則」(最新版)と 道路交通法・施行令の 条文(e-Gov)で 確かめる**。記憶で 書かない。`exam.txt` に 確かめた 日を 書く。
  ❌ **書かない 数字**: 反則金の 金額・罰金の 金額・事故の 件数・合格率(**`meta.json` に 確かめた 日つきで 入れる ときだけ**)
- ⭐⭐ **2026年に 変わった ところを いまの 答えに する**(古い 本の 答えを 書かない):
  ・**生活道路の 法定速度 30km/h**(中央線などの ない 一般道路。**2026年9月1日から**。標識で 決まっていれば そちらが 先)
  ・**自動車が 自転車の 右を 通る ときの 間隔**(十分な 間隔が ない ときは その間隔に 合った 安全な 速さで。自転車も できるだけ 左に 寄る。**2026年4月1日から**。警察庁の めやすは 1m ほど ⚠️ 法律の 数字では ない)
  ・**自転車の 青切符**(16歳以上。**2026年4月1日から**)
  ・ほかにも 確かめる: 新基準原付(125cc 以下・出力 4kW 以下を 原付免許で。2025年4月)/ マイナ免許証(2025年3月)/ 自転車の ながらスマホ・酒気帯びの 罰(2024年11月)/ 特定小型原動機付自転車(電動キックボード。2023年7月)/ 自転車の ヘルメット 努力義務(2023年4月)/ 運転技能検査・サポカー限定免許(2022年5月)/ 妨害運転(あおり運転。2020年6月)/ ながら運転の 罰を 重く(2019年12月)。
  ⚠️ **古い 答えは name に しない**。説明に「前は 60km/h でした」だけ(気象予報士の `OLD_NAMES` と 同じ しくみ)
- ⭐ **教則の ことばづかいに そろえる**(「徐行」「一時停止」「進路変更」「停止表示器材」「初心運転者標識」など **教則の 名前**)。くだけた 名前(若葉マーク・三角板)は `alias` に
- ⭐ **ひっかけの ことば**は 上級で しっかり 入れる(「徐行」と「一時停止」・「追い越し」と「追い抜き」・「駐車」と「停車」・「◯m 以内」と「◯m 以上」・「歩道」と「路側帯」)
