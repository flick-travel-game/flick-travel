## フリック農家(`noka/`。けいくん 2026-10-03「農家の専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」。まとめは `docs/フリック農家-はじめかた.md`)

- 名前は「フリック農家」(絵が 届いたら 題名に そろえる。フォルダ名 `noka` は 変えない)。シリーズの 絵文字は 🌾。`SERIES_ORDER` は **料理人の となり**
- 旅は 8つ(農業のきほん `kihon`・野菜 `yasai`・お米 `kome`・果物と花 `kudamono`・土と肥料と虫 `tsuchi`・農機具とスマート農業 `dogu`・畜産と酪農 `chikusan`・農家の仕事としくみ `shigoto`)+ マスター。
  **旅ごとに 70語(入門20・中級25・上級25)= 560語**。かずともの 旅の 名前は **`nk` で はじめる**(nkkihon / nkyasai / nkkome / nkkudamono / nktsuchi / nkdogu / nkchikusan / nkshigoto / nkmas)。
  ⚠️ かずともの `nkansen` / `nkangaku` とは 別の 字。作る 前に ぶつからない ことを 確かめた
- むずかしさは 3段: 入門(スーパーや 学校の 畑・家庭菜園で 聞く ことば)→ 中級(**日本農業技術検定 3級・2級の 範囲の めやす**)→ 上級(**日本農業技術検定 1級・農業高校〜大学の 農学の めやす**)。
  1語ごとに **学ぶ 分野**(`field`)8つ: 農業一般 / 作物 / 野菜 / 果樹 / 花き / 畜産 / 食品 / 環境(日本農業技術検定の 科目 = 共通の 農業の 基礎 + 作物・野菜・花き・果樹・畜産・食品、3級は 環境系も、に そろえた)
- ことばは `tools/noka/terms-<旅>.json`(決まりは `tools/noka/PROMPT.md`)→ `tools/noka/terms_js.py` → `noka/terms.js` + `data/noka.json`。
  しくみは `noka/noka.js`(大工を 写した。4択クイズ あり。クイズの 文は「農薬の 使いかたや 作業の 手順では ありません」)。
  しくみ図は コードで 描く 箱の 図 8つ(`tools/noka/mkmeta.py`): **1年の 農業カレンダー(春の 種まき → 夏の 育ち → 秋の 収穫 → 冬の 土づくり + 植物の からだ・光合成)**・野菜畑の 地図・
  **田んぼの 1年(田おこし → 苗代 → 代かき → 田植え → 水の 管理 → 稲刈り → 乾燥と もみすり → 精米)**・果樹園と 花畑・土の 中と 畑の 生きもの・**農業の 機械の 地図**・牧場の 地図・
  **畑から 食卓までの 流れ(育てる → 収穫と 選別 → 出荷 → JA → 市場 → お店 → 食卓)**
- 資格・制度の 事実は `tools/noka/exam.txt`(→ meta.json の `exam`)に **確かめた日つき**(2026年10月2日):
  **農家に 国家資格は 要らない** / 日本農業技術検定(日本農業技術検定協会。事務局は 全国農業会議所。3級・2級・1級。3級は 共通 + 栽培系・畜産系・食品系・環境系、2級・1級は 共通 + 作物・野菜・花き・果樹・畜産・食品)/
  農家に なる 道(農業高校・農業大学校・農学部・農業法人・研修・新規就農の 相談)/ 有機JAS(登録認証機関が 認めた ものだけ マークを 付けられる)/ GAP(農業生産工程管理)/ JA /
  トラクターで 公道を 走るには 大きさに 合った 運転免許(小型特殊 / 大型特殊)。
  ⚠️「専門家に なれる レベル」は **日本農業技術検定 1級の 範囲の ことばを ひととおり 知っている** めやす
- ✅ **機械の 使いかたは 書く**(けいくん決定 2026-10-03「機械の使いかたも書いてください。農家が大変な仕事だと思われているから、機械を使い効率的に仕事が出来ることを使える方が良い」)。
  **整備士・大工の「使いかたを 書かない」とは ちがう 決まり**。機械で 何が できて、どの 作業が らくに・速く なるかを 書いた(むかしの 手作業と くらべる 書きかたも)。
  運転・操作する 機械には **「講習を 受けた おとなが 使います」**、刃の ある 手の 道具には **「おとなが 使う 道具です」**。刃や 回る ところに さわる・子どもが 運転する 話は 書かない。
  ⚠️ よかれと思って「使いかたを 書かない」に もどさない
- ⚠️⚠️ **農薬の 名前・量・まきかたを 書かない**。農薬は「決まりに そって 使う 薬」まで。農薬・肥料・有機の **よしあしを 書かない**(育てかたの ちがいとして)。
  ジベレリン(たねなしぶどうの 薬)・噴霧器・スピードスプレーヤーも 入れていない。台本が「まきかた・希釈・散布量」を 止める
- ⚠️⚠️ **小学生も あそぶ**: 「殺」「死」「血」の 字を 台本が 止める(殺菌 → 熱を くわえて 安心して 飲める ように、血統 → 家系)。と畜・処分・事故・けがの 話は 書かない。
  畜産は「動物を 大切に 育てる 仕事」(「お肉に なる」までは よい)
- ⚠️⚠️ **年ごとに 変わる 数字を 書かない**(%・円・kg・トン・ヘクタール・人・戸 を 台本が 止める)。食料自給率は「しめす 割合」と 意味だけ
- ⚠️ **実在の 会社・農協の 個別名・商標の 品種名・地域ブランドを 書かない**(台本が 止める: 農機具・種・肥料・乳業の 会社、あまおう・巨峰・とちおとめ・ゆめぴりか・つや姫・松阪牛・夕張メロン・魚沼産 など)。
  入れた 品種名は 商標で ない もの だけ: コシヒカリ・ひとめぼれ・あきたこまち・ササニシキ・ふじ・つがる・王林・幸水・二十世紀・温州みかん・デラウェア・シャインマスカット・ラ・フランス・男爵いも・メークイン・ホルスタイン・ジャージー・黒毛和種。
  キャタピラ(商標)は「クローラ」と 書いた
- ✅ 料理人・理科・社会 など ほかの ゲームと 同じ 語を 入れて よい(説明は 育てる 人の 目線)。読みは **農家の 8つの 旅の 中で** かぶらない(`terms_js.py` が 止める)。
  かぶって 入れなかった 語: 柿(花き かき と)・摘花(摘果 てきか と)・気候(気孔 きこう と)・箕(実 み と)。台木は 野菜、受粉・人工授粉は 果物と花、休眠は きほん、カメムシは お米、堆肥は 土 に まとめた
