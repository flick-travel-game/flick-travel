# フリック起業家(`kigyo/`)を 作る ための まとめ(2026-10-04。新しい セッション用)

けいくん 2026-10-04「新しいセッションで フリック起業家を作成したい。**起業家の専門家になれるレベル**になるために必要な 知識をフリック形式の問題にしてください」

## ⭐ このゲームの 心
- **起業 = 「だれかの 困りごと」を 見つけて、新しい しくみで 解決する こと**。お金もうけの ゲームでは なく、**「人の 役に 立つ ことを 自分で はじめる 力」**が わかる ゲームに する
- 説明は「**それは 何か + 起業した 人が どんな 場面で 使うか**」。例: MVP =「いちばん 小さな 形の 商品。まず 作って お客さんに 使って もらい、反応を 見て 直す」
- ⭐ **失敗は はずかしく ない**。「ピボット(方向を 変える)」「失敗から 学ぶ」を 前向きに。**挑戦する ことを ほめる** 書きかた
- ⚠️ **「かならず 成功する」「すぐ お金持ちに なれる」と 書かない**(子どもに まちがった 期待を させない・あやしい もうけ話と 見分けが つかなく なる)

## 3. ⚠️⚠️⚠️ ぜったいの 決まり(投資家・税理士と 同じ。お金の 話は なおさら)
- ⚠️⚠️ **「かならず 成功」「楽して もうかる」を 書かない**(台本で 止める)。起業は **挑戦**。成功も 失敗も ある、と 書く。**失敗を 笑わない**
- ⚠️⚠️ **金額・割合の 決めうちを 書かない**(資本金・税率・補助金・起業の 成功率)。書くのは **ことばの 意味と 考えかた**。**🍋 レモネード屋さんの たとえ**で 数字の かわりに しくみを 伝える
- ⚠️⚠️ **投資・借金を すすめない**。資金の 旅は **しくみの 説明**(「VC = 大きく 育つ 会社に お金を 出す 会社」)。お金の 話は **「おとなと 相談」**
- **あやしい もうけ話から 守る**: マルチ商法・投資詐欺は **「見分けかた」として だけ**(「かならず もうかる と 言われたら あやしい」「人を さそうと お金が もらえる しくみ に 注意」)。やりかたは 書かない
- **手続きの 手順・期限を 書かない**(登記・開業届・申告)。**名前と 何の ための ものか**まで。「くわしくは 税務署・法務局・専門家に」
- **人の 名前は 故人 だけ**(渋沢栄一・松下幸之助・本田宗一郎・井深大・盛田昭夫・稲盛和夫・スティーブ・ジョブズ など。⚠️ 生まれた / 亡くなった 年は 書かず「◯◯年代に 〜を 作った」。**確かめる**)。**会社名は 答えに しない**(説明の 中で「〜を 作った 人」と 1回 ふれるのは よい)
- **人を 上下で 見ない**: 「部下」「使う」「動かす」より「仲間」「いっしょに」「まかせる」
- ✅ **ほかの ゲーム(投資家・税理士・弁護士・花屋の 経営・株式・マナーの 仕事 など)と 同じ 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。説明は **起業家の 目線**(「自分の 会社では どう 使うか」)で 書きなおす
- **読み(ひらがな)は 起業家の 10の 旅の 中では かぶらない**(ほかの ゲームとは かぶって よい。`terms_js.py` が 止める)。⚠️ `okane` と `chotatsu`(資金・株式)、`hojin` と `chotatsu`(資本金)、`idea` と `model`(価値提案)、`shijo` と `hanbai`(ターゲット・ブランド)、`kihon` と `team`(ミッション)は かさなりやすい。**先に 10の 旅の 語の 一覧を 1人の 助手に 作らせて** 置き場所を 決めてから 頼む
- **カタカナ語・英語の 略語は ふつうの 言葉で 言いかえて から**(「KPI = 目標に 近づいて いるか を 見る ための 数字」)。読みは カタカナ → ひらがな、英字の 略語は 読みかた(けーぴーあい)を `acceptedReadings` に
- 画面(ホームの 下・遊びかた)に「これは ことばを おぼえる ゲームです。**お金の ことは おとなと 相談しましょう**」の 1行(投資家と 同じ)
- **作った 助手とは 別の 助手が 1語ずつ 確かめる**(意味・読み・**「かならず もうかる」が 無いか**・**金額 / 割合が 無いか**・**投資を すすめて いないか**・**生きて いる 人の 名前が 無いか**・人を 上下で 見て いないか)。ふりがなも 全語 見る(`tools/ruby_fix.json`)

## 4. めやすの 事実は **その日に 公式の ページで 確かめてから** 書く
起業に **資格は 要らない**(だれでも 起業できる)。`meta.json` の `exam` には「専門家に なる 道」を 確かめた 日つきで 書く(**記憶で 書かない**):
**中小企業診断士**(国家資格。経営の 専門家。1次の 7科目・2次。確かめる)/ **日商簿記**(お金の 記録。確かめる)/ **ビジネス実務法務検定**(確かめる)/ **ファイナンシャル・プランニング技能士**(確かめる)/
**中小企業庁・商工会議所・よろず支援拠点**(起業の 相談の 場所。名前と 役わりを 確かめる)/ **創業支援**(自治体の 取り組み。名前だけ)/ 学校の **アントレプレナーシップ教育**(確かめる)。
⚠️ 「専門家になれるレベル」= **中小企業診断士の 範囲の 起業・経営の ことばを ひととおり 知っていて、レモネード屋さんで たとえて 説明できる**こと、と けいくんに 伝える。⭐ 起業の 本当の 力は **小さく はじめて、お客さんの 声で 直す こと**。ゲームで つくのは その ための 知識の 土台

## 5. 作りかたの 手順(投資家の ときと 同じ)
1. けいくんに 2 の 5つを 聞く → 返事を CLAUDE.md に 書く
2. `tools/kigyo/PROMPT.md` `meta.json` を 作る → **先に 10の 旅の 語の 一覧を 1人の 助手に 作らせて 置き場所を 決める** → 旅ごとに 助手に 70語ずつ 頼む(`PROMPT.md` を そのまま わたす。**助手は 2人ずつ**。🍋 レモネード屋さんの たとえは **旅を こえて 同じ お店** に なるよう、お店の せってい(名前は つけない・小学生が 夏休みに 公園の そばで はじめた 屋台)を PROMPT に 書く)→ `terms-<旅>.json`
3. `terms_js.py` で 止められた 語を 直す → 別の 助手が 1語ずつ 確かめる(**必勝・金額・投資の すすめ・人の 名前・上下**)→ ふりがな
