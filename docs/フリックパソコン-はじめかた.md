# フリックパソコン(`pasokon/`)を 作る ための まとめ(2026-10-03。新しい セッション用)

けいくん 2026-10-03「新しいセッションで フリックパソコンを作成したい。**MacBookの専門家になれるレベル**になるために必要な 知識をフリック形式の問題にしてください。ショートカットもたくさん出してください」
→ 同じ日に けいくん「**ショートカットが目玉ではなく、Appleショップの店員さん並に MacBookのプロになれるようにしてください**」。
**ショートカットは 3旅 → 1旅**(70語)に へらし、**お店の 店員さんの 力**(えらぶ・はじめる・つなぐ・直す・わかりやすく 説明する)を 中心に 組みなおした。

## ⭐ このゲームの ゴール = お店の パソコン担当の 店員さん
お店の 店員さんが できる こと を 旅に した:
1. **えらぶ**: お客さんの「何に 使いたい?」を 聞いて、チップ・メモリ・ストレージ・画面の 大きさ の **考えかた**で 合う ものを すすめる
2. **はじめる**: はじめての 設定・前の パソコンや スマホからの **データの 引っ越し**・アカウント・家族で 使う 設定
3. **つなぐ**: スマホ・タブレット・時計・イヤホン との **連携**、外の 画面・プリンタ・ハブ などの **周辺機器**
4. **使いこなす**: 操作・ファイル・アプリ・ショートカット・作品づくり(写真・動画・音楽・発表資料)・設定と アクセシビリティ
5. **直す・守る**: トラブルの **切りわけ**(何が 原因か 順に 確かめる)・バックアップ・安全・修理と 保証
6. ⭐ **わかりやすく 説明する**: 語に **`setsumei` の 欄**(「💬 店員さんの ひとこと」)。専門の ことばを **お客さんに 伝わる たとえ**で 言いかえる(例: メモリ →「作業する 机の 広さ。広いほど たくさんの アプリを 同時に 広げられます」/ ストレージ →「物を しまう 引き出し。写真や 動画が 多い 方は 大きめを」)。**このゲームの いちばんの 目玉**
