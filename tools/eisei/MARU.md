# フリック衛生管理者: ⭕❌ 一問一答の 作りかた

本物の 衛生管理者試験は **5つから 1つ えらぶ**(第一種 44問・第二種 30問・どちらも 3時間)。5つの 文の 正しい / まちがいを 見分けられれば 解ける。
この ゲームでは 1つの 文ずつ ⭕❌ で 練習し、🎯 模擬試験では ⭕❌ の 文を 同じ 科目から 5つ ならべて「正しい(誤っている)ものは どれか」の 5択に する。
合否を 分けるのは **数字**(人数・期間・濃度)と **ひっかけ**(専属 / 専任・選任 / 届出・義務 / 努力義務)。**約1,270問**。

## 旅ごとの 問題数
taisei 140 / kenko 130 / rokiho 130 / yugaiho 150 / kankyo 130 / shokugyo 120 / shokuba 130 / kyukyu 100 / seiri1 120 / seiri2 120(= 1,270)

## 決まり
1. `PROMPT.md` の「いちばん 大事な 決まり」を ぜんぶ 守る(数字は facts-A/B/C.md の ものだけ・いまの 法令が 答え・こわく しない・手当ての やりかたを 書かない・実在の 会社を 書かない)
2. **答えが 1つに 決まる 文**だけ。あいまいな 文・学説が 分かれる 文は 作らない。主語(事業者・衛生管理者・産業医・常時 50人以上の 事業場 など)を はっきり 書く
3. **⭕ と ❌ は おおよそ 半分ずつ**(各旅 ⭕ 40〜60%)
4. **ひっかけを 多く**(上級は とくに): 「50人以上 / 50人を こえる」「6月以内ごと / 1年以内ごと」「毎週 1回 / 毎月 1回」「専属 / 専任」「選任 / 届出 / 報告」「義務 / 努力義務」「遅滞なく / 14日以内」「所轄労働基準監督署長 / 都道府県労働局長」「事業者 / 衛生管理者」「3年 / 5年 / 30年 / 40年 の 保存」「ppm / mg/m3 / % の 数字」「上がる / 下がる」(労働生理)
   ❌ の 文は **本物らしく 少しだけ ちがう**(数字を 1つ 変える・例外を 消す・主語や 役目を 入れかえる・増える ↔ 減る)
5. **とき方**(`why`): なぜ ⭕/❌ か 1〜2文・**90字 以内**。❌ なら 正しい 形を 書く。やさしい です・ます
6. **どの 法令の 話か**(`law`): 「安衛法12条」「安衛則13条」「事務所則5条」「労基法36条」の ように 法令名 + 条(わかる とき)。**facts に ある 条だけ**。わからなければ 法令名だけ。労働衛生・労働生理の 問題は 出どころの 資料名(「腰痛予防対策指針」「WBGT 指針」)か 空でも よい
7. 問題文(`q`): **80字 以内**。試験と 同じ「〜しなければならない。」「〜である。」の 形で よい(漢字は ふつうに 使う。ふりがなは 付かない)
8. 同じ ことを 聞く 問題を 2つ 作らない(同じ 事実の ⭕版と ❌版も 作らない)
9. **過去問・問題集・テキストの 文を 写さない**。自分の ことばで(「よく 出る 考えかた」を 自分の 文に)
10. `dv`: 1 = 入門(働く 人が 知っておく こと。各旅 10問ほど)/ 2 = 中級(第二種の 基本)/ 3 = 上級(第一種: 数字・例外・有害業務)。上級を 半分 以上
11. `term`: その 問題に いちばん かかわる ことばの id(`terms-<旅>.json` に ある もの。無ければ 書かない)
12. `rs`: 試験の 科目(関係法令(有害以外) / 関係法令(有害業務) / 労働衛生(有害以外) / 労働衛生(有害業務) / 労働生理)。
    **taisei・kenko は 原則 関係法令(有害以外)**だが、作業主任者・特別教育の 有害業務・特殊健康診断 の 問題は 関係法令(有害業務)。yugaiho = 関係法令(有害業務) / kankyo・shokugyo = 労働衛生(有害業務) / shokuba・kyukyu = 労働衛生(有害以外) / seiri1・seiri2 = 労働生理
