# フリックあん摩マッサージ指圧師(`anma/`)を 作る ための まとめ(2026-10-12。新しい セッション用)

> ✅ **作った**(2026-10-12)。名前は 同じ日に けいくん「フリック指圧師にして / 説明のなかで あん摩マッサージ指圧師と書こう」で **「フリック指圧師」**。いまの ようすは `CLAUDE.md` の「フリック指圧師」の 節を 見る

けいくん 2026-10-12「新しいセッションで フリックあん摩マッサージ指圧師を作成したい。**あん摩マッサージ指圧師の国家資格に受かるレベル**になるために必要な 知識をフリック形式の問題にしてください」

⭐ **フリック歯科医師(`shika/`)・医師(`ishi/`)・看護師(`kango/`)・薬剤師(`yakuzai/`)と 兄弟の「医療の 資格」の ゲーム**。まとめの 型・決まりは `docs/フリック歯科医師-はじめかた.md` と **ほぼ 同じ**。
ちがう ところは 3つ: ① **東洋医学(経絡・ツボ)が 半分を しめる**(ほかの 医療の ゲームに 無い 分野)② **手技(手で する 技)の ゲーム**なので「やりかたの 数字(圧の 強さ・時間)」を 書かない 線引きが 要る ③ ⚠️ **「マッサージ」の 字は 医療と 関係ない お店にも 使われる**ので、**医療の 国家資格の 話として だけ** 書く(下の 3)。
