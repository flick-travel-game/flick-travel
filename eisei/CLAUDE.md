## フリック衛生管理者(`eisei/`。けいくん 2026-11-10「衛生管理者に 受かるレベルに なれるように フリック問題で まとめてください」。まとめは `docs/フリック衛生管理者-はじめかた.md`)

- 名前は「**フリック衛生管理者**」(第一種衛生管理者 免許試験の 範囲。第二種は その 中の 一部)。フォルダ `eisei`・modes `EISEI`。シリーズの 絵文字は 🩺。`SERIES_CHAPTERS` の 夢のしごとの 章、**宅建士の となり**。
  かずともの 旅の 名前は **`ek` で はじめる**(ektaisei / ekkenko / ekrokiho / ekyugaiho / ekkankyo / ekshokugyo / ekshokuba / ekkyukyu / ekseiri1 / ekseiri2 / ekmas)。speed-king の `FLICK_MODES` / `FLICK_LINK_TARGETS` / `HOME_GAMES` / `FLICK_SERIES_GAMES` に 2026-11-10 に 足した
- 旅は 10 = 試験の 5つの 科目を 2つずつ: 関係法令(有害以外)= 🏢 安全衛生管理のしくみ `taisei` / 🩺 健康診断と健康管理 `kenko` / 📜 労働基準法 `rokiho`(taisei・kenko には 作業主任者・特殊健診 など 有害業務の 法令も 少し)・関係法令(有害業務)= ☣️ 有害業務の法令 `yugaiho`・労働衛生(有害業務)= 🌡 作業環境と有害要因 `kankyo` / 🧪 職業性疾病 `shokugyo`・労働衛生(有害以外)= 🏠 職場の衛生と快適さ `shokuba` / 🍱 食中毒・感染症・応急手当 `kyukyu`・労働生理 = 🫀 からだのしくみ1 `seiri1` / 🧠 からだのしくみ2 `seiri2` + 🏆 マスター。
  **1,000語**(旅ごとに 入門15・中級30・上級55)。段: 入門 = 働く 人なら 知っておく(小学生も)/ 中級 = 第二種の 基本 / 上級 = 第一種に 受かる 人(数字・例外・有害業務)。1語ごとに `field`(安衛法・事務所則 … 循環・血液・くらし)と **📝 科目の 札**(`ruleset`: 5つの 科目)
- ⭐⭐ **試験の ための しくみ**(`eisei/eisei.js`。宅建士 `takken.js` を 写した。見た目の class は `ai-…` / `ek-…`):
  ・**⭕❌ 一問一答**(`tools/eisei/maru-<旅>.json`。決まり `MARU.md`。⭕ 40〜60%・上級が 半分 以上・とき方 + 📚 条(`law`)・`rs` = 科目)
  ・**🔢 数字クイズ**(`tools/eisei/num-<旅>.json`。決まり `NUM.md`。数字を 4つから)
  ・**🎯 模擬試験**: 本番と 同じ **5つから 1つ・3時間**。1問 = 同じ 科目の ⭕❌ の 文を 5つ ならべて「正しい / 誤っている ものは どれか」(ときどき 数字クイズ。こちらは 4択の まま)。
    **第一種(44問 400点)/ 第二種(30問 300点)**の 切りかえ。科目ごとの 問題数と **配点**(第一種の 有害業務の 2科目だけ 1問 8点・ほかは 10点)は 安全衛生技術試験協会の 公式ページで 確かめた(`tools/eisei/mock.json`・`facts-A.md`)。
    合格の きまりも 本番と 同じ: **科目ごとに 40% 以上 かつ 合計 60% 以上**。結果は「クリア / 合計は 届いたが 科目で 足りない / もう少し」+ 科目の 表(40% 未満は 赤)。⚠️ 合格を 約束しない。宅建士の「過去の 合格点の はば」は 衛生管理者には 無い(合格の きまりが 決まっているため)
  ・⭐ **❌ まちがえた 問題**(`flick-eisei-miss`。2回 つづけて 正解で 消える)。運転免許・宅建士に つづく 例外。⚠️ ほかの ゲームに 広げない
  ・ホームに **📊 衛生管理者の 図**(`<details>`): 衛生管理者の 人数の 表・産業医・定期の しごと(巡視 毎週 / 委員会 毎月 / 健診 1年・6月)・事務所則の 数字・労働衛生の 3管理・WBGT
