## フリック英語(`eigo/`。けいくん 2026-09-29「0はOK / A / すべておすすめで」)

- 決めたこと: 名前「**フリック英語**」(絵が 届いたら 題名に そろえる。フォルダ名 `eigo` は 変えない)/ **9旅** / **3段**(入門=中学の基本・中級=高校受験・上級=大学受験)/
  打つ字は **35字まで** / **日本語訳は 打ち終わってから** 出す(打つ 前に 見えるのは 文法の 名前と むずかしさだけ)。社会より 先に 作ってよい(0 = OK)
- 英会話(`eikaiwa/`)=「話す・通じる」、こちら=「**入試で 点を 取る 文法**」。単語だけの 旅は 作らない。例文が かぶるのは よい(復習)
- 旅: 🔁不規則動詞 60 / ⏳時制 90 / 🔄受動態 60 / 🎯不定詞・動名詞 90 / 🧩分詞・分詞構文 60 / 🔗関係詞 60 / ⚖️比較 60 / 🌙仮定法 60 / 💡熟語・句動詞 90 = **630問**
- 例文は `tools/eigo/terms-<旅>.json`(決まりは `tools/eigo/PROMPT.md`)→ `tools/eigo/terms_js.py` が `data/eigo.json` と `eigo/terms.js`。
  ⚠️ **`reading`(打つ 字)は 手で 書かない**。name から 英会話の `norm` と 同じ やりかたで 作る。**数字・" : ; ( ) は name に 使わない**
- しくみは `eigo/eigo.js`(**`tools/eigo/make_eigo_js.py` が `kokugo/kokugo.js` から 作る。手で 直さない**)。英字を 打つ しくみ(`norm`・`tgtHtml`)と 🔊 発音は 英会話から。
  4択クイズの ②は「英文 → 正しい 訳は どれ?」。年表・しくみ図は ない(ホームには 🔊 読みあげの 切りかえ)
- ⚠️ **ふりがなの 読みまちがい**: 「過去形の」の 形 が かたち、「that 節」の 節 が ふし、「A-B-A型」が かた に なった。
  `terms_js.py` の `GRAM` で 文法の ことばの 読みを 先に 決めてある。**新しい 文法の ことばを 説明に 書いたら 出てきた ふりがなを 見る**
- 英文は 作った 助手とは **別の 助手に 1文ずつ 確かめさせた**(9旅 ぜんぶ。決まり文句の 例文・子どもに いじわるな 文・不自然な 文を 直した)

- **打ちかたは はじめ「ひらがな」= 英語の 読み**(けいくん 2026-10-10「解答方法、デフォルトはひらがなで打つ / アルファベットに 切り替えも」)。
  英文を 見て、**英語の 読みを ひらがなで** 打つ(I have lived here … → あいはぶりぶどひあ …)。書きかたは **フリック英会話と 同じ**(data/english.json の reading)。
