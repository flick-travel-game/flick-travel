> 理科旅行(`rika/`)… pH / 酸性 / 中性 / 還元 / 酸化 / 水素結合 / 静電気
> からだ旅行(`karada/`)… たんぱく質 / アミノ酸 / 細菌 / ウイルス / アレルギー

- ⚠️ **かぶっても よい**(けいくん決定 2026-09-29「被るのは 復習に なるから いい」。CLAUDE.md の 節)。
  ただし **説明は 美容の 目線で 書きなおす**(例: pH → 理科旅行は 酸とアルカリ / 美容師は 髪と 肌への はたらき)
  (シスチン結合・キューティクル・ブリーチ・ワインディング・レイヤー など)
- ⚠️ 作る前に **`rika/index.html` と `karada/index.html` の `{n:"..."` を ぜんぶ 出して 見くらべる**

### 2. **やりかたを 書かない**
このゲームは **ことばと 意味を おぼえる** もの。**薬や はさみの 使いかたは 書かない**。

- ❌ 書かない: パーマ液・カラー剤の 混ぜかた・置く 時間・薬の 濃さ・カットの 手順・ブリーチの やりかた
- ⭕ 書く: **その ことばが 何を さすか**(例: パッチテスト = 染める 前に、うでの 内がわで かぶれないか 調べる こと)
- ⚠️ **自分の 髪や 人の 髪で ためしたく なる**書きかたを しない。画面の 下に
  **「これは ことばを おぼえる ゲームです。薬を 使う ことは、美容師さんに おまかせ」**
- ⚠️ **数字は なるべく 出さない**(薬の 濃さ・置く 時間)。出す ときは「だいたいの めやす」と 書く

### 3. **見た目の ことを わるく 言わない**
美容は「きれいに なる」話。**子どもも あそぶ**ので、気にしている 子が いる。

- ❌ 書かない: くせ毛・うすい 髪・肌の ことを **こまった もの**として 書く 言いかた。
  「◯◯は かっこわるい」「なおす」のような 言いかた
- ⭕ 書く: **その 人に 合う ものを えらぶ 仕事**として(例: くせ毛 = うまれつき うねりの ある 髪。いかした 形も できる)

## 美容師だけの しくみ

- **カタカナの 長い ことば**が 多い(ワインディング = 8字、グラデーション = 8字、ヘアマニキュア = 8字、キューティクル = 8字)。
  ⚠️ **20字を こえる ものは 上級だけ**に 入れる(数学旅行の 公式と 同じ 決まり)
- **読みを まちがえやすい ことば**: 皮脂(ひし)・毛根(もうこん)・毛周期(もうしゅうき)・頭皮(とうひ)・
  香粧品(こうしょうひん)・美容所(びようじょ)。⚠️ **1語ずつ 確かめる**
- **図**(決めてもらうこと 5)は 2つ:
  ・**髪の 毛の 断面**(キューティクル → コルテックス → メデュラ)… からだ旅行の `SVG_MAPS` と 同じ しくみ
  ・**お店の 絵**(シャンプー台・セット面・鏡・道具の ワゴン)
  ⚠️ 絵は **ラベル(字)なし**。お店・道具の **ロゴや メーカーが 分かる 形に しない**
- ⚠️ **お店・メーカー・商品の 名前を 使わない**(商標)。「シャンプー」のような 一般の 言いかたで

## ⚠️ 権利・安全の 注意(上の「大事な 3つ」に くわえて)

- **過去問・問題集・教科書・美容の 本の 文を 写さない**。説明は 自分の ことばで
- **薬・道具の 使いかたを 書かない**(上の 2)。はさみ・かみそりは **刃物**。子どもが まねしない 書きかたに
- ⚠️ **顔そりは 美容師の 仕事では ない**(理容師の 仕事)。まちがえて 書かない。**確かめてから**
- 「この 髪型が 一番」「この 商品が よい」と 順位を つけない
- ⚠️ 「100マス計算」「百ます計算」の 字を 使わない(シリーズの 決まり)
