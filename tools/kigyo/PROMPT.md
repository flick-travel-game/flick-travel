# フリック起業家: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
学ぶ 分野・しくみ図の どこに あるか(📍)・**🍋 たとえば レモネード屋さんなら**(ある 語だけ)が 出る。
あそぶのは **小学生〜起業を 学ぶ 高校生・大学生・大人**。
**自分で 何かを はじめて、人の 役に 立つ ための ことばと 意味を おぼえる ゲーム**(試験の 問題集でも、お金もうけの 方法でも、投資の すすめでも ない)。
もとは `tools/toshika/PROMPT.md`(投資家)と `tools/hanaya/PROMPT.md`(花屋の 開業と 経営)。
けいくん 2026-10-04「起業家の専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」。

## ⭐ この ゲームの 心
- **起業 = 「だれかの 困りごと」を 見つけて、新しい しくみで 解決する こと**。お金もうけの ゲームでは なく、**「人の 役に 立つ ことを 自分で はじめる 力」**が わかる ゲーム
- 説明は「**それは 何か + 起業した 人が どんな 場面で 使うか**」。例: MVP =「いちばん 小さな 形の 商品です。まず 作って お客さんに 使って もらい、反応を 見て 直します。」
- ⭐ **失敗は はずかしく ない**。「ピボット(方向を 変える)」「失敗から 学ぶ」を 前向きに。**挑戦する ことを ほめる** 書きかた
- ⚠️ **「かならず 成功する」「すぐ お金持ちに なれる」と 書かない**(子どもに まちがった 期待を させない・あやしい もうけ話と 見分けが つかなく なる)

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 7つ

### 1. 「かならず 成功」「楽して もうかる」を 書かない
- ❌「もうかる」「儲かる」「必ず」「かならず」「絶対」「必勝」「楽して」「すぐ お金持ち」「一攫千金」(台本が 止める)
- ⭕ 起業は **挑戦**。うまく いく ことも、いかない ことも ある。**失敗を 笑わない**。失敗は「学びに なる」「次に 生かす」

### 2. ⚠️⚠️ 金額・割合・数字の 決めうちを 書かない
- **%・割・円・倍の 数字は 書かない**(台本が 止める)。資本金・税率・補助金の 額・「起業の ◯%が 失敗」・「ふつうは ◯%」も 書かない
- 書くのは **ことばの 意味と 考えかた**。数字の かわりに **🍋 レモネード屋さんの たとえ**で しくみを 伝える
- 条の 番号(第◯条)・手続きの 期限(◯日以内)は 書かない

### 3. ⚠️⚠️ 投資・借金を すすめない
- 資金の 旅は **しくみの 説明**だけ(「VC = 大きく 育ちそうな 会社に お金を 出す 会社です」)。「借りると よい」「投資すると よい」を 書かない
- 必要なら「お金の ことは おとなと 相談」で しめる

### 4. あやしい もうけ話から 守る(見分けかた だけ)
- マルチ商法・ねずみ講・投資詐欺は **「見分けかた・気を つける ところ」として だけ**(「かならず もうかる と 言われたら あやしい」「人を さそうと お金が もらえる しくみ に 注意」)。**やりかたは 書かない**
- 「詐欺」の 字は 使って よいが、こわい ようす・人が こまった ようすは 書かない

### 5. 手続きの 手順・期限を 書かない
- 登記・開業届・申告・社会保険は **名前と 何の ための ものか** まで。「くわしくは 税務署・法務局・専門家に」
- 法律の 名前(会社法・特定商取引法・個人情報保護法 など)は よい。条の 番号は 書かない

### 6. ⚠️⚠️ 人の 名前は 故人(歴史の 人)だけ・会社名は 答えに しない
- ⭕ 人物は **亡くなった 歴史の 人だけ**: 渋沢栄一・岩崎弥太郎・松下幸之助・本田宗一郎・井深大・盛田昭夫・稲盛和夫・安藤百福・豊田佐吉・
  スティーブ・ジョブズ・トーマス・エジソン・ヘンリー・フォード・ウォルト・ディズニー・ピーター・ドラッカー(経営学者)・ヨーゼフ・シュンペーター(経済学者。イノベーション) など。⚠️ 社会起業で 有名な ムハマド・ユヌス は **生きているので 入れない**
  - 亡くなった ことは 書かない。生まれた / 亡くなった 年も 書かない。「◯◯年代に 〜を 作った 人」「明治の 実業家」くらいに
  - ⚠️ 書く 事実は **まちがいない ことだけ**(渋沢栄一 = 明治から 大正に かけて 500ほどの 会社の 設立に かかわった、と されて いる → 数字は 書かない「たくさんの 会社」)
- ❌ **生きている 起業家・経営者の 名前は 入れない**(評価が 変わる・商標の 心配。台本が 止める)
- ❌ **実在の 会社名・サービス名・商品名を 答え(name)に しない**。説明の 中で「〜を 作った 人」として 会社を 1回 ふれるのは よい(例:「電気の 家電の 会社を おこした 人」と 書けば 会社名も 要らない。なるべく 会社名を 書かない)
- ⭕ 公の 組織・制度の 名前は よい: 中小企業庁・経済産業省・商工会議所・商工会・よろず支援拠点・日本政策金融公庫(機関の 名前と 役わりだけ)・税務署・法務局・特許庁・東京証券取引所・日本取引所グループ・国連(SDGs)

### 7. 人を 上下で 見ない・小学生も あそぶ
- 「部下」「使う」「動かす」「人を 使う」より **「仲間」「いっしょに」「まかせる」**
- ❌ 借金で こまる・倒産・破産・夜逃げ・こわい ようす・死・ギャンブル・くじ・ガチャ(台本が 止める)。
  「黒字倒産」は 名前だけ 入れて よい(説明は「利益は 出て いるのに、手元の お金が 足りなく なって 払えなく なる こと」と おだやかに。「倒産」の 字は name に だけ。説明では「お店を 続けられなく なる」)
- 🎰🎲🃏💸💀 は 使わない。💴💵💰 の 多用も さける
- 「起業家」と「企業家」の 打ちまちがいに 気を つける(**この ゲームの 名前は 起業家**)。「企業」は 会社の 意味の ときだけ

## 🍋 たとえば(`tatoeba` の 欄。任意)
- **ぜんぶ 同じ 1つの お店の たとえ**: **小学生が 夏休みに 公園の そばで はじめた レモネードの 屋台**(お店の 名前は つけない・実在の お店では ない)。
  白い 犬も いっしょ(出しても 出さなくても よい)。友だち・家族・近所の 人が お客さん。材料は レモン・砂糖・水・氷・紙コップ。屋台は 借りた 小さな テーブルと パラソル
- 書きかた: **1文**(60字くらいまで。80字を こえない)。「たとえば」「レモネード屋さんなら」の 前置きは **書かない**(画面が「🍋 たとえば レモネード屋さんなら」を 出す)。数字(%・円・倍)は 書かない(「1日 何杯」は よい)
  - 例(損益分岐点): 「レモネードを 1日に 何杯 売れば、材料代と 屋台を 借りる お金を 取りもどせるか、の 分かれ目です。」
  - 例(MVP): 「まず 1種類の レモネードだけ 作って、友だちに 飲んで もらい、感想を 聞きます。」
  - 例(ピボット): 「レモネードより 冷たい お茶の ほうが 喜ばれたので、お茶の 屋台に 変えます。」
- **1つの 旅に 10〜20語**(たとえで わかりやすく なる 語だけ。入門〜上級に ちらす)。むりに つけない
- 旅を こえて 同じ お店なので、**話が つながって いて よい**(はじめは 1人で 屋台 → 友だちと チーム → 夏祭りに 出店 → 2つめの 屋台 …)

## 1語の 形(JSON)

```json
{"id":"ok-bunki","name":"損益分岐点","reading":"そんえきぶんきてん","journey":"okane","category":"利益の 考えかた","difficulty":2,
 "field":"財務・会計","type":"concept","emoji":"🎯","mapNode":"okane:bunki","relatedTerms":["ok-koteihi","ok-rieki"],
 "description":"売上と 費用が ちょうど 同じに なり、利益も 損も ない 分かれ目です。起業家は ここを 知って、どれだけ 売れば 続けられるかを 考えます。",
 "tatoeba":"レモネードを 1日に 何杯 売れば、材料代と 屋台を 借りる お金を 取りもどせるか、の 分かれ目です。"}
```

- **id**: `<旅の 頭>-<ローマ字>`(下の 表)。英小文字・数字・- だけ
- **name**: 画面に 出す 名前(ふつうに 使う 言いかた。漢字・カタカナ・英字の 略語)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)
  - カタカナ語は ひらがなに(スタートアップ → すたーとあっぷ)。英字の 略語は 読みかたで(KPI → けーぴーあい、MVP → えむぶいぴー、VC → ぶいしー、M&A → えむあんどえー、IPO → あいぴーおー、SNS → えすえぬえす、LTV → えるてぃーぶい、CAC → きゃっく(しーえーしー も 認める))
  - ゆれる ことばは 1つに 決め、別の 読みは `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は 上級だけ・旅で 1〜2語まで
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級
- **field**: 学ぶ 分野。**中小企業診断士の 第1次試験の 7科目**(2026年10月4日に 確かめた)の どれか:
  `経済学・経済政策` `財務・会計` `企業経営理論` `運営管理` `経営法務` `経営情報システム` `中小企業経営・政策`
  - めやす: 起業家精神・戦略・マーケティング・組織・リーダー・ビジネスモデル・市場分析 → `企業経営理論` /
    売上・利益・決算書・資金繰り・資金調達・企業価値 → `財務・会計` / 店の 運営・仕入れ・在庫・品質・店づくり・接客の 流れ → `運営管理` /
    会社の 形・登記・契約・知的財産・特定商取引法・個人情報・株式の しくみ → `経営法務` / ネット・SNS・データ・IT・EC → `経営情報システム` /
    市場の しくみ・需要と 供給・景気・独占 → `経済学・経済政策` / 起業の 支援・補助金・個人事業主・中小企業・事業承継・創業支援・よろず支援拠点・起業家の 歴史 → `中小企業経営・政策`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(💀 🔫 🔪 🩸 💣 ⚔️ 🎰 🎲 🃏 💸 は 使わない。💴💵💰 の 多用も さける。🍋🚀💡🧩🗺️📣🌱🤝📈🏢📘 など)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか + 起業した 人が どんな 場面で 使うか」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  専門用語を 専門用語だけで 説明しない。カタカナ語・英語の 略語は **ふつうの 言葉で 言いかえて から**(「KPI は、目標に 近づいて いるかを 見る ための 数字です。」)。
  「1人」「2人」は ふりがなが 読みまちがえるので **ひとり・ふたり** と ひらがなで 書く
- **tatoeba**: なくても よい(上の 🍋 の 決まり)

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | **お店屋さんごっこが すきな 子**: 困りごと・アイデア・売上と 利益・お客さん・チームの きほん(小学生でも 聞いた ことが ある) |
| 2 | 中級 | **起業を 考えはじめた 人**: 中小企業庁の 創業の 手引き・高校の「公共」「商業」の 範囲の めやす(ビジネスモデル・市場・マーケティング・会社の つくりかた・資金の 集めかた) |
| 3 | 上級 | **起業の 専門家**: 中小企業診断士の 範囲の めやす(財務・資本政策・ユニットエコノミクス・組織・成長の 戦略) |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる
(ならんだ 順が そのまま ステージの 順に なる)。

## 旅ごとに 入れる 語(⚠️ **読みが かぶると 台本が 止まる**。**起業家の 10の 旅の 中で** 同じ 読みは 1回だけ)

`tools/kigyo/WORDS.md`(10の 旅 × 70語の 置き場所の 一覧)に 書いて ある 語を 入れる。
**ほかの 旅の 一覧に ある 語は 入れない**。一覧の 語が どうしても 書けない ときは、**どの 旅の 一覧にも 無い** 語に 入れかえて、報告に 書く。

## ぜったいに 守ること
- **自分の ことばで 書く**。教科書・問題集・Wikipedia・公式の 文を 写さない
- **数字(%・円・割・倍)は 書かない**。資格・制度の 事実は `tools/kigyo/exam.txt` に 合わせる
- ✅ 投資家・税理士・弁護士・花屋(開業と 経営)・株式旅行 など **ほかの ゲームと 同じ 語を 入れて よい**(けいくん決定 2026-09-30)。説明は **起業家の 目線**(「自分の 会社や お店では どう 使うか」)で 書きなおす。同じ 文を 写さない
