# フリック税理士: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
学ぶ 分野・しくみ図の どこに あるか(📍)が 出る。あそぶのは **小学生〜税理士を めざす 高校生・大学生・大人**。
**税理士に なるための 税と 会計の ことばと 意味を おぼえる ゲーム**(試験の 問題集でも 税務相談でも ない)。
もとは `tools/bengoshi/PROMPT.md`(弁護士)。
けいくん 2026-10-01「税理士になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いと「差し押さえ・脱税は 入れるか」に「すべておすすめで」。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 6つ

### 1. 節税の テクニック・脱税・抜け道を 書かない(お金は なおさら)
- ❌ **書かない**: 「こうすれば 税金が 安くなる / かからない / 得を する」/ 節税の こつ / 税の 抜け道 / ごまかしかた / 調査で どう 答えるか
- ⭕ **書くのは**: その ことばが **何を さすか**・**何の ための 制度か**・**税理士が どう かかわるか**
  - 例: ふるさと納税 = 応援したい 自治体に 寄附を すると、決まりの 中で その ぶんの 税の 一部が 差し引かれる しくみ。くわしい 計算は 国税庁の ページで 確かめます
  - 例: 医療費控除 = 1年に 払った 医療費が 多い ときに、決まりに そって 所得から 差し引ける しくみ。申告して うけます
- 「節税」「脱税」「租税回避」の 字そのものも 使わない(台本が 止める)

### 2. 税務相談の 答えに しない
- ❌「あなたの 場合は …」「この 条件なら …できます」「◯月までに 出せば …」のような、読んだ 人が 自分の 問題に あてはめる 書きかたを しない
- ⭕ 一般的な しくみの 説明だけ。必要なら「くわしい 決まりは 法律で 決まっています」「こまったら 税務署や 税理士に 相談」で しめる

### 3. ⚠️⚠️ 税率・金額・上限・割合の 数字を 書かない(弁護士より きびしく)
- **%・割・円の 数字は ぜんぶ 書かない**(台本が 止める)。「消費税 10%」も 書かない。
  ⚠️ 飲食料品の 消費税率は 2027年4月から 2年間 引き下げの 予定(2026年9月 閣議決定)。**軽減税率は「飲食料品などに 低い 税率を 使う しくみ」とだけ**書き、数字を 書かない
- 控除の 金額・基礎控除の 額・申告の 期限の 日にち(◯月◯日まで)・◯年以内 なども 書かない(年ごとに 変わる)。
  「申告の 期限が 決まっています」のように 書く
- 条の 番号(第◯条)は 書かない
- 年(できごとの 年)は **まちがいない ときだけ**: 大宝律令 701年・地租改正 1873年・所得税の はじまり 1887年・シャウプ勧告 1949年・
  税理士法 1951年・消費税の はじまり 1989年4月・インボイス制度 2023年10月・税理士記念日 2月23日・税を考える週間は 11月 など。あやしい ときは 年を 書かない

### 4. 小学生も あそぶ(こわく しない)
- ❌ **差し押さえ・滞納処分・公売・脱税の 事件・査察・自己破産・借金の 取り立て**は 入れない(けいくん決定 2026-10-01「すべておすすめで」= 入れない)。
  国税徴収法の 語は「納税の猶予」「換価の猶予」「延納」のような **納める 人を 助ける しくみ**だけ。延滞税・督促は「期限を すぎると 知らせが 来る・税が ふえる しくみ」と おだやかに
- 相続・遺言・遺産は「家族が のこした 財産を 受けつぐ ときの 決まり」と、**人が 亡くなる ようすを 書かずに** 説明する。
  「死亡」「死ぬ」「亡くなっ」「殺」(相殺も)「血」「逮捕」「破産」は 使わない(台本が 止める)。「死亡保険金」も 入れない
- 相続の あらそい・家族の けんかの ようすを 書かない

### 5. 政治の よしあしを 書かない
- 増税・減税の 是非・ある 税が 正しい / まちがい を 書かない。制度は **何の ための 決まりか**だけ

### 6. 税理士の 目線で 書く(株式旅行・弁護士・社会など ほかの ゲームと 同じ 語を 入れて よい)
- ✅ **ほかの ゲームと 同じ ことばを 入れて よい**(けいくん決定 2026-09-30)。説明は **税理士の 目線**で 書きなおす。
  株式旅行 = 会社を 知る / 税理士 = 税と 会計で 会社や 人を 支える
- **読み(ひらがな)は 税理士の 7つの 旅の 中で かぶらない**(台本が 止める)。下の「旅ごとに 入れる」を 守る
- **実在の 会社・人・事件・会計事務所の 名前**は 使わない(国税庁・財務省・日本税理士会連合会 など **役所・公の 団体の 名前**、歴史上の 人物は よい)

## 1語の 形(JSON)

```json
{"id":"kh-zeikin","name":"税金","reading":"ぜいきん","journey":"kihon","category":"税のしくみ","difficulty":1,
 "field":"税のきほん","type":"concept","emoji":"🧾","mapNode":"kihon:yakuwari","relatedTerms":["kh-nozei"],
 "description":"国や 都道府県・市町村が、学校や 道路・ごみの 回収など みんなの ための 仕事を する お金として、みんなで 出しあう お金です。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(ふつうに 使う 言いかた。漢字・カタカナ・英字の 略語)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)
  - 英字・カタカナの 語は ひらがなで(インボイス → いんぼいす、e-Tax → いーたっくす)
  - ゆれる ことばは 1つに 決め、別の 読みは `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)。例: 遺言 ゆいごん / いごん
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は 上級だけ・旅で 1〜2語まで
  - ⚠️ **読みを 1語ずつ 確かめる**: 租税 そぜい・賦課 ふか・徴収 ちょうしゅう・源泉 げんせん・控除 こうじょ・扶養 ふよう・還付 かんぷ・
    更正 こうせい・課税 かぜい・益金 えききん・損金 そんきん・欠損金 けっそんきん・仕訳 しわけ・借方 かりかた・貸方 かしかた・
    勘定 かんじょう・元帳 もとちょう・試算表 しさんひょう・棚卸 たなおろし・引当金 ひきあてきん・減価償却 げんかしょうきゃく・
    被相続人 ひそうぞくにん・遺言 ゆいごん・路線価 ろせんか・物納 ぶつのう・延納 えんのう・暦年 れきねん・庸 よう・調 ちょう・
    雑徭 ぞうよう・年貢 ねんぐ・検地 けんち・地租 ちそ・冥加 みょうが・運上 うんじょう
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級
- **field**: 学ぶ 分野。次の 13の どれか(入門の 語でも いちばん 近い ものを 書く):
  `税のきほん` `簿記論` `財務諸表論` `所得税法` `法人税法` `相続税法` `消費税法` `酒税法` `国税徴収法` `住民税` `事業税` `固定資産税` `税理士法`
  - めやす: 税の しくみ・国税通則・申告と 納付・不服申立て・税の 歴史・国際課税 → `税のきほん` / 仕訳・勘定・帳簿・決算整理 → `簿記論` /
    貸借対照表・損益計算書・会計の 原則・会計基準 → `財務諸表論` / 個人の 所得・控除・年末調整 → `所得税法` / 会社の 所得・決算と 申告 → `法人税法` /
    相続・贈与・財産の 評価 → `相続税法` / 消費税・インボイス・軽減税率 → `消費税法` / お酒の 税 → `酒税法` /
    納税の 猶予・延滞税・督促・納付の しくみ → `国税徴収法` / 住民税・ふるさと納税 → `住民税` / 事業税・外形標準課税 → `事業税` /
    固定資産税・都市計画税・償却資産 → `固定資産税` / 税理士の 仕事・税理士会・試験と 登録 → `税理士法`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(💀 🔫 🔪 🩸 💣 ⚔️ などは 使わない。💴💵💰の お札の 絵文字の 多用も さける)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / 何の ために あるか・税理士は どう かかわるか」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  専門用語を 専門用語だけで 説明しない。「1人」「2人」は ふりがなが 読みまちがえるので **ひとり・ふたり** と ひらがなで 書く
- **example**: なくてもよい

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | くらしや ニュースで 聞く 税の ことば。小学生でも 聞いた ことが ある(税金・消費税・確定申告・給料・売上) |
| 2 | 中級 | **税理士試験の 簿記論・財務諸表論・税法の 範囲の めやす**(大きな ことば) |
| 3 | 上級 | 税法の こまかい 制度の 名前・会計基準・国際税務の ことば |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる
(ならんだ 順が そのまま ステージの 順に なる)。

## ぜったいに 守ること

- **自分の ことばで 書く**。過去問・問題集・教科書・Wikipedia・国税庁の 文を 写さない
- **数字(%・円・割)は 書かない**。試験・制度の 事実は `tools/zeirishi/exam.txt` に 合わせる
- 「100マス計算」「百ます計算」の 字を 使わない

## 出すもの

`tools/zeirishi/terms-<旅id>.json` に JSON の 配列(70語)で 書く。書いたら
`python3 tools/zeirishi/terms_js.py --only <旅id>` で 形を 確かめる(まちがいが あれば 止まる)。
