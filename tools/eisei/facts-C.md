## C-1. 有害業務の 法令(関係法令・有害業務)

### 有機則(有機溶剤)
| 事実 | 出どころ |
|---|---|
| 有機溶剤は **令 別表第6の2** の 物(アセトン・キシレン・トルエン・ノルマルヘキサン・メタノール・二硫化炭素 など)。「有機溶剤等」= 有機溶剤 + 有機溶剤を **重量の 5%を 超えて** 含む 混合物 | 有機則1①一・二、令 別表第6の2 |
| **第1種有機溶剤等** = 別表第6の2 の **28号(1,2-ジクロルエチレン)と 38号(二硫化炭素)** と それを 5%超 含む 物 | 有機則1①三 |
| **第2種** = アセトン・キシレン・トルエン・ノルマルヘキサン・メタノール・酢酸エチル など 多くの 物 / **第3種** = 第1種・第2種 以外(**ガソリン・コールタールナフサ・石油エーテル・石油ナフサ・石油ベンジン・テレビン油・ミネラルスピリット** など 48〜55号の 石油系) | 有機則1①四・五、令 別表第6の2 |
| **区分の 表示は 色分け + 色分け以外の 方法**: **第1種 = 赤 / 第2種 = 黄 / 第3種 = 青** を 見やすい 場所に | 有機則25①② |
| 屋内作業場等で 第1種・第2種の 業務 → 発散源を **密閉する 設備・局所排気装置・プッシュプル型換気装置** の どれか。第3種は **タンク等の 内部**の 業務で 必要(吹付けでなければ 全体換気装置も 可) | 有機則5・6 |
| **局所排気装置の 制御風速**: **囲い式フード 0.4m/s / 外付け式 側方吸引型 0.5 / 下方吸引型 0.5 / 上方吸引型 1.0m/s**。囲い式は 開口面の **最小風速**、外付け式は 吸引範囲で 開口面から **最も 離れた 作業位置**の 風速 | 有機則16①(表と 備考) |
| フードは **発散源ごと**、外付け式は 発散源に **できるだけ 近く**。**ダクトは 長さ できるだけ 短く・ベンドの 数 できるだけ 少なく** | 有機則14①② |
| **排風機は 空気清浄装置で 清浄にした 後の 空気が 通る 位置**(爆発・ファン腐食の おそれが なければ 例外)。全体換気の 送風機・排風機は 発散源に できるだけ 近く | 有機則15①② |
| 排気口は 直接 外気に 開放。空気清浄装置の ない 局排・プッシュプル(屋内)の 排気口は **屋根から 1.5m以上** | 有機則15の2 |
| **有機溶剤作業主任者 = 技能講習**。職務: 作業方法の 決定・指揮 / 局排・プッシュプル・全体換気を **1月を 超えない 期間ごとに 点検** / 保護具の 使用状況の 監視 / タンク内作業の 措置の 確認。⚠️ **試験・研究の 業務は 作業主任者 不要** | 有機則19・19の2 |
| 局所排気装置の **定期自主検査 1年以内ごとに1回**、記録 **3年** | 有機則20②・21 |
| **掲示**(屋内作業場等): ①生じる おそれの ある 疾病の 種類と 症状 ②取扱い上の 注意 ③中毒が 起きた ときの 応急処置 ④呼吸用保護具が 要る 場所なら その旨 | 有機則24 |
| **タンク内作業**: 作業開始前に マンホール 等を 全部 開放 / 汚染・作業終了時に 直ちに 身体を 洗浄 / 退避の 設備 / 有機溶剤等を 入れた タンクは 排出・洗浄 + **タンク容積の 3倍以上の 空気を 送気・排気**(または 水を 満たして 排出) | 有機則26 |
| 作業環境測定 **6月以内ごとに1回**(屋内作業場。第1種・第2種)、記録 3年 → facts-B の 表 | 有機則28②③ |
| **特殊健康診断**: 屋内作業場等(**第3種は タンク等の 内部だけ**)で 常時 従事する 者に **雇入れ・配置替え・その後 6月以内ごとに1回**。個人票 **5年**保存。医師の 意見は **3月以内**。定期の 結果は 遅滞なく 監督署長へ 報告(電子) | 有機則29①②・30・30の2・30の3 |
| ⚠️ **健診の 1年への 緩和**: その 場所の 作業環境測定の 評価が **連続 3回 第1管理区分**、直近の 健診後に 作業方法を 変えていない、**直近 連続 3回の 健診で 新たな 異常所見なし** → 定期健診は **1年以内ごとに1回** で よい(特化則39④・鉛則53④も 同じ 形) | 有機則29⑥ |
| 送気マスクを 使わせる 業務: **有機溶剤等を 入れた ことの ある タンクの 内部**の 業務 など。保護具は **同時に 就業する 労働者の 人数と 同数以上** | 有機則32・33・33の2 |
| 屋内 貯蔵は 栓を した 堅固な 容器 + 関係者以外の 立入防止 + 蒸気を 屋外に 出す 設備。**空容器は 密閉 か 屋外の 一定の 場所に 集積** | 有機則35・36 |
| ⚠️ トリクロロエチレン・テトラクロロエチレン・スチレン・エチルベンゼン・ジクロロメタン などは 有機則ではなく **特化則の「特別有機溶剤」(第2類物質)**。古い テキストの「有機溶剤の 一覧」に 入っている ことが ある。いまの 令 別表第6の2 では 該当の 号が **削除** | 特化則2①三の2、令 別表第6の2(削除の 号) |
