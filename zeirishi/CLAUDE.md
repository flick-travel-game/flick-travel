## フリック税理士(`zeirishi/`。けいくん 2026-10-01「税理士になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いと「差し押さえ・脱税は 入れるか」に「すべておすすめで」。まとめは `docs/フリック税理士-はじめかた.md`)

- 名前は「フリック税理士」(絵が 届いたら 題名に そろえる。フォルダ名 `zeirishi` は 変えない)。シリーズの 絵文字は 🧾
- 旅は 7つ(税金のきほん `kihon`・くらしの税金 `kurashi`・会社の税金 `kaisha`・簿記と会計 `boki`・相続と贈与 `sozoku`・税理士の仕事 `shigoto`・税の歴史と世界 `rekishi`)+ マスター。
  **旅ごとに 70語(入門20・中級25・上級25)= 490語**。かずともの 旅の 名前は **`zr` で はじめる**(zrkihon / zrkurashi / zrkaisha / zrboki / zrsozoku / zrshigoto / zrrekishi / zrmas)
- むずかしさは 3段: 入門(くらしや ニュースで 聞く 税の ことば)→ 中級(**税理士試験の 簿記論・財務諸表論・税法の 範囲の めやす**)→ 上級(税法の こまかい 制度の 名前・会計基準・国際税務)。
  1語ごとに **学ぶ 分野**(`field` → 📘 学ぶ 分野)。税理士試験の 11科目 + 2つの 13: 税のきほん / 簿記論 / 財務諸表論 / 所得税法 / 法人税法 / 相続税法 / 消費税法 / 酒税法 / 国税徴収法 / 住民税 / 事業税 / 固定資産税 / 税理士法
- ことばは `tools/zeirishi/terms-<旅>.json`(決まりは `tools/zeirishi/PROMPT.md`)→ `tools/zeirishi/terms_js.py` → `zeirishi/terms.js` + `data/zeirishi.json`。
  しくみは `zeirishi/zeirishi.js`(弁護士を 写した。4択クイズ あり)。しくみ図は コードで 描く 箱の 図 7つ(税の地図・くらし・**お金の流れの図(売上 → 経費 → 利益 → 税金)**・帳簿・引きつぎ・**会計事務所と税務署の地図**・歴史と世界。`tools/zeirishi/mkmeta.py`)
  エンジン(`index.html`)の `const PLUG` に `ZEIRISHI`・`SERIES` と `SERIES_ORDER`(弁護士の となり)に 足した
- 試験・制度の いまの形は `tools/zeirishi/exam.txt`(→ meta.json の `exam`)に **確かめた日つき**(2026年10月1日に 国税庁(税理士試験の概要・受験資格・令和8年度税理士試験公告・税理士制度)と 日本税理士会連合会(税理士の資格取得・税理士とは・登録者数・税理士記念日)で 確かめた):
  資格は 試験合格・試験免除・弁護士・公認会計士(合格と 免除は 実務経験 通算2年)/ 日税連の 名簿に 登録 / 試験は 国税審議会・年1回 8月(令和8年は 8月4〜6日・発表 11月27日予定)/
  会計学 2科目(必須)+ 税法 9科目から 3科目(所得税法か 法人税法を かならず)= 5科目・科目合格は 一生 有効・各科目 満点の 60% / 令和5年から 簿記論・財務諸表論は だれでも 受けられる /
  独占業務は 税務代理・税務書類の作成・税務相談 / 税理士会 15・登録者 82,682人(令和8年9月末)/ 税理士法 1951年 / 税理士記念日 2月23日。⚠️ 文を 直すときは その日に 確かめて `exam` の 日付も 上げる
- ⚠️⚠️⚠️ **節税の テクニック・脱税・抜け道・税務相談の 答えを 書かない**。書くのは「何を さすか・何の ための 制度か・税理士が どう かかわるか」だけ。
  画面に「本物の 試験問題でも、税務相談の 答えでも ありません」「税率や 金額は 年ごとに 変わるので のせていません」「国税庁・税務署・日本税理士会連合会とは 関係ありません」
- ⚠️⚠️⚠️ **税率・金額・割合の 数字を 書かない**(弁護士より きびしい。台本が %・割・円 の 数字を ぜんぶ 止める。「消費税 10%」も 書かない)。
  理由: **飲食料品の 消費税率を 2027年4月から 2年間 引き下げる 予定**(2026年9月15日 閣議決定・国税庁の 特設サイト)。軽減税率は「飲食料品などに 低い 税率を 使う しくみ」とだけ。控除の 額・申告の 期限の 日にちも 書かない
- ⚠️⚠️ **小学生も あそぶ**: **差し押さえ・滞納処分・公売・脱税の 事件・査察・自己破産・取り立ては 入れない**(けいくん決定 2026-10-01「すべておすすめで」= A)。
  国税徴収法の 語は 納税の猶予・換価の猶予 など **納める 人を 助ける しくみ**だけ。延滞税・督促は おだやかに。相続は「家族などが のこした 財産を 受けつぐ こと」(死の 字を 使わない。相殺 も「殺」で 止まる)
- `terms_js.py` の `BAN` が 節税・脱税・差し押さえ・破産・こわい ことば・「安くなる / お得」・相談の 答えの 言いかたを 止める
- ✅ 株式旅行・弁護士 など ほかの ゲームと 同じ 語を 入れて よい。読みは **税理士の 7つの 旅の 中で** かぶらない(`terms_js.py` が 止める)。
  ことばの 受けもちは PROMPT.md の「旅ごとに 入れる 語」(確定申告 = きほん / 消費税 = くらし / 売上・経費・利益 = 会社 / 減価償却 = 簿記 / 基礎控除 = くらし・相続は「遺産に係る基礎控除」/ 科目の 名前 = 仕事)。はじめから かぶりは 0 だった
- ふりがなの 読みまちがいは **税理士の 中だけで** 直す(`terms_js.py` の `FIX`): 弁護士と 同じ 4つ + **国税不服審判所 → しんぱんじょ**。
  ほかは 説明を 言いかえて 直した(年 → とし の ところ・何年 → なん年・庸 → 調・庸の 順に・口分田 → くぶんでん・石 → こく・博士 → 経済学者・印 → はんこ・得る → える など)
- 作った 助手とは **別の 助手が 1語ずつ 確かめた**(7つの 旅 ぜんぶ。直しは 約60)。大きな 直しは 国税庁(財務省の 外局)・青色申告(届け出 → 承認)・源泉徴収(会社「など」)・
  消費税(負担するのは 買う 人・納めるのは 事業者)・ふるさと納税(寄附の 一部が 計算で 差し引かれる)・固定資産税(おもに 市町村。23区は 都)・山林所得(立木の まま)・
  予定申告 / 中間申告・電子帳簿保存法(書きなおした あとが 分かる)・同族会社・移転価格税制 と 外国子会社合算税制(書き分けた)・のれん(時価の 純資産)・重要性の原則(注解)・
  法定相続人(父母や 祖父母)・税理士法人・独占業務(無料でも 同じ)・継続研修・租(地方の 役所へ)・BEPS(OECD と G20)
