## フリック弁護士(`bengoshi/`。けいくん 2026-10-01「弁護士になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いと 死刑の 問いに「全部おすすめで」。まとめは `docs/フリック弁護士-はじめかた.md`)

- 名前は「フリック弁護士」(絵が 届いたら 題名に そろえる。フォルダ名 `bengoshi` は 変えない)。シリーズの 絵文字は ⚖️
- 旅は 7つ(法律のきほん `kihon`・憲法のことば `kenpo`・民法とくらし `minpo`・刑法と刑事のてつづき `keiji`・裁判所とてつづき `saiban`・弁護士の仕事 `shigoto`・法律の歴史と世界 `rekishi`)+ マスター。
  **旅ごとに 70語(入門20・中級25・上級25)= 490語**。かずともの 旅の 名前は **`lw` で はじめる**(lwkihon / lwkenpo / lwminpo / lwkeiji / lwsaiban / lwshigoto / lwrekishi / lwmas)
- むずかしさは 3段: 入門(ニュースや くらしで 聞く ことば)→ 中級(**法学部・予備試験の 短答式の 範囲の めやす**)→ 上級(商法・民事訴訟法・刑事訴訟法・行政法・選択科目の ことば)。
  1語ごとに **学ぶ 分野**(`field` → 📘 学ぶ 分野)。司法試験の 科目 + 2つの 10: 法律のきほん / 憲法 / 行政法 / 民法 / 商法 / 民事訴訟法 / 刑法 / 刑事訴訟法 / 選択科目 / 法曹倫理
- ことばは `tools/bengoshi/terms-<旅>.json`(決まりは `tools/bengoshi/PROMPT.md`)→ `tools/bengoshi/terms_js.py` → `bengoshi/terms.js` + `data/bengoshi.json`。
  しくみは `bengoshi/bengoshi.js`(警察官を 写した。4択クイズ あり)。しくみ図は コードで 描く 箱の 図 7つ(法律・憲法・くらし・刑事・**法廷の地図**・**法律事務所の地図**・歴史と世界。`tools/bengoshi/mkmeta.py`)
  エンジン(`index.html`)の `const PLUG` に `BENGOSHI`・`SERIES` と `SERIES_ORDER`(消防士の となり)に 足した
- 試験・制度の いまの形は `tools/bengoshi/exam.txt`(→ meta.json の `exam`)に **確かめた日つき**(2026年10月1日に 法務省(司法試験・予備試験の Q&A と 令和7年の 採点結果)・最高裁判所(司法修習・裁判員)・日弁連・法テラスで 確かめた):
  受験資格は 法科大学院修了・予備試験合格・法科大学院在学中 / 資格を 得てから 5年(**回数の 制限は もう 無い**。まとめの「5年で 5回」は 古い)/ 令和8年の 司法試験は 7月15・16・18・19日 / 短答は 憲法・民法・刑法の 3科目 /
  論文は 公法系・民事系・刑事系 + 選択科目(7つから 1つ)/ 予備試験は 受験資格の 制限 なし・短答・論文・口述 / 令和7年 合格 1,581人(受験 3,837人)/ 司法修習 約1年 → 考試(二回試験)/
  弁護士は 弁護士会に 入り 日弁連の 名簿に 登録(弁護士会 52・弁護士 48,057人 2026年9月1日)/ 法テラスは 2006年 / 裁判員は 2009年5月21日〜・2023年から 18歳 以上。⚠️ 文を 直すときは その日に 確かめて `exam` の 日付も 上げる
- ⚠️⚠️⚠️ **やりかた・抜け道を 書かない / 法律相談の 答えに しない**: 犯罪の 手口・「こうすれば 罪に ならない」・取り調べの 答えかた・「あなたの 場合」「◯日 以内なら」は のせない。
  正当防衛・緊急避難は「あたるか どうかは きびしい 条件で 裁判所が 判断」の 書きかた。画面に「本物の 試験問題でも、法律相談の 答えでも ありません。本当に 困った ときは 大人に 言って、弁護士や 法テラスに 相談」「法務省・裁判所・日弁連とは 関係ありません」
- ⚠️⚠️ **条の 番号・罰の 重さ・金額は 書かない**(台本が「第◯条」「◯年以下」を 止める)。**懲役・禁錮は 2025年6月から 拘禁刑**なので 字ごと 止めてある
- ⚠️⚠️ **小学生も あそぶ**: **死刑は 入れない**(けいくん決定 2026-10-01「全部おすすめで」)。殺人・強盗・誘拐・放火・性犯罪・薬物・暴力団・テロも 入れない。
  入れた 犯罪の 名前は 窃盗・詐欺・横領・器物損壊・名誉毀損・侮辱 だけ。相続・遺言は 人が 亡くなる ようすを 書かずに「財産を 家族などが 引きつぐ」。過失相殺 は「殺」の 字で 止まるので 入れていない
- 政治の よしあしは 書かない(戦争の放棄・象徴天皇制・憲法改正は しくみだけ。戦争の放棄は「いろいろな 考えかたが あります」)
- ✅ 警察官・社会 など ほかの ゲームと 同じ 語を 入れて よい。読みは **弁護士の 7つの 旅の 中で** かぶらない(`terms_js.py` が 止める)。
  同じ 読みの 別の 語は 片方だけ: 勾留(拘留は 無し)・科料(過料は 無し)・控訴(公訴は「公訴時効」「公訴の提起」の 形)・私法(司法 単体は 無し)
- 作った 助手とは **別の 助手が 1語ずつ 確かめた**(7つの 旅 ぜんぶ。直しは 41)。大きな 直しは 条(いちばん 大きな 単位では ない)・戦争の放棄(武力の 行使も)・戸籍(市区町村が 記録)・
  遺留分(2019年の 改正後の 形)・離婚(2026年4月からの 共同親権)・知財高裁(東京高裁の 特別の 支部)・支払督促(書記官は 中身を 調べない)・傍聴(抽選も)・宣誓(16歳未満は しない)・
  裁判員(重い 事件だけ)・取り調べの可視化(一部の 事件)・公訴時効(時効の ない 罪も)・再審(きびしい 条件)・治外法権 → 領事裁判権・墾田永年私財法 → 問注所(法の 歴史に 近い 語へ)。
  ふりがなは 三大(みおう)・長(なが)・表(ひょう)・行った(いった)を 言いかえで 直した
