# フリック血液型: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
どの 血液型の 話か(🩸 血液型の 色の 札)・学ぶ 分野・しくみ図の どこに あるか(📍)が 出る。
あそぶのは **小学生〜高校で 生物・保健を 学ぶ 人・臨床検査技師を めざす 人・血液型が すきな 大人**。
**血液型の しくみの ことばと 意味を おぼえる ゲーム**(占いでも、輸血や 検査の 手引きでも ない)。
もとは `tools/jui/PROMPT.md`(獣医師)。まとめは `docs/フリック血液型-はじめかた.md`。
けいくん 2026-10-04「血液型の専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください。血液型の特徴をめちゃくちゃ詳しくお願いします」
→ 同じ日「このまま」= **科学 8旅 + 性格の うわさ(日本の 文化)1旅**。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 7つ

### 1. ⚠️⚠️ 性格は 事実として 書かない(いちばん 大事)
- 「A型は きちょうめん」の ような **血液型と 性格の 関係は、科学の 調べでは 確かめられて いない**(日本と アメリカの 1万人を こえる データで「関係は ほぼ 無い」と した 研究が ある)。
  日本・韓国など 一部の 国で 人気の **文化・遊び**
- 性格の 話は **`bunka` の 旅だけ**。ほかの 旅では「性格」を 書かない(台本が 止める。「血液型で 性格は 決まりません」は よい)
- `bunka` の 旅でも かならず **「日本で 〜と 言われる イメージ」「〜と いう イメージが ある」** の 形。「A型の 人は 〜だ」と 言い切らない(台本が「◯型の 人は」を 止める)
- 書く イメージは **いい ところ だけ**:
  A型 = ていねい・まじめ・まわりに 気を くばる・計画を 立てる / B型 = 自分の ペースを 大切に する・好きな ことに 夢中・ひらめき・明るい /
  O型 = おおらか・まとめ役・仲間を 大切に する・がんばりや / AB型 = 落ちついて いる・アイデアが ゆたか・いろいろな 見かたが できる
- ⚠️⚠️ **悪口に なる イメージは 書かない**(自己中・わがまま・神経質・大ざっぱ・二重人格・変わり者・ずぼら・気まぐれ・マイペース など。台本が 止める)。その 血液型の 子が 笑われない ように
- ⚠️ **相性を 決めつけない**(「◯型と ◯型は 合う / 合わない」は 書かない)。相性占いは「そう いう 占いが ある」まで
- `bunka` の 説明の どこかで 「人の 性格は 一人ひとり ちがう」「決めつけない」が 伝わる ように する(全部の 語で なくて よい)

### 2. ⚠️⚠️ 家族を うたがわせない
- 遺伝の 旅は **しくみの 表** として 書く。「この 親から この 子は 生まれない」「親と 子の 型が 合わない のは おかしい」と 読める 文を 書かない(台本が「生まれない」「本当の 親」「実の子」を 止める)
- 「ふつうの 組み合わせ表では 出ない 型が 出る ことも ある」と **例外(シスAB型・ボンベイ型・検査の まちがい)** を そえる

### 3. 病気と 血液型を 結びつけない
- 「◯型は ◯◯に なりやすい」は 研究が あっても **入れない**(子どもに 不安を あたえる。台本が「なりやすい」「かかりやすい」を 止める)

### 4. 医療の やりかたを 書かない
- 輸血・検査・献血は **名前と 目的と しくみ だけ**。量・手順・期限の 日数・年れいの 数字は 書かない
- ⚠️⚠️ 「O型は 赤血球を ほかの 型に あげられる / AB型は ほかの 型から 受けられる」を 書くときは、**かならず「今は 同じ 型を 使う のが 原則」を そえる**(「だれにでも あげられる」「万能」は 台本が 止める)
- 献血は **人を 助ける すてきな こと** と 伝わる 書きかた。輸血は「病気や けがの 人を 助ける」と 前向きに

### 5. 小学生も あそぶ(こわく しない)
- 血が 流れる ようす・けが・事故・手術の 中みを 書かない。**「死」は 使わない**(台本が 止める)。
  「凝集」は「赤血球が くっついて かたまる こと。だから 合う 血液を えらぶ」まで(からだが どう なるかの こわい 話は 書かない)
- 読んだ 子が **こわく ならない**・**「知って 楽しい」と 思える** 書きかたに する

### 6. 数字と 名前
- **割合(%)・人数・年れい・量・日数・回数は 書かない**(台本が 止める)。割合は「いちばん 多い と される」「とても 少ない」の ように ことばで
- 年(1900年 など)・世紀・「9番 染色体」は 書いて よい。ただし **下の「確かめた 事実」に ある もの だけ**
- **実在の 団体・会社の 名前を 答えに しない**(「日本赤十字社」は 語に しない。説明で「献血は 赤十字の 血液センターが 集めて いる」と ふれるのは よい)。
  一般名(血液センター・献血ルーム)は よい。人の 名前(ランドシュタイナー・古川竹二)は 歴史として よい
- 本の 題名・作者は 説明で 1回 ふれる くらい。売り文句に しない

### 7. 血液型の 目線で 書く(ほかの ゲームと 同じ 語を 入れて よい)
- ✅ からだ旅行・理科の 生物・医師・看護師・獣医師 などと 同じ ことば(赤血球・遺伝子・輸血)を 入れて よい(けいくん決定 2026-09-30)。説明は **血液型の 目線**で
- **読み(ひらがな)と 名前は 血液型の 9つの 旅の 中で かぶらない**(台本が 止める)。`plan.json` の 置き場所を 守る
- 文体は **はじめから「〜です・ます」**。語と 語の あいだに 半角スペース(この シリーズの 文体)
- 「へえ」を 1文 入れると よい(「赤血球には 核が ありません」「Rhの 名前は アカゲザルから」「猫の AB型は 人の AB型と しくみが ちがいます」)
- 事実が あやしい 語は 入れない。**自分の ことばで 書く**(Wikipedia・公式の 文を 写さない)

## 1語の 形(JSON)

```json
{"id":"ab-kogen","name":"抗原","reading":"こうげん","journey":"abo","category":"しるし","difficulty":2,
 "field":"免疫(抗原と抗体)","type":"concept","emoji":"🏷️","mapNode":"abo:kogen","relatedTerms":["ab-kotai"],"blood":"4つの型",
 "description":"からだが「自分の もの か どうか」を 見分ける ための しるしの ことです。赤血球の 表面に ある A抗原や B抗原の ちがいが、血液型の ちがいに なります。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(教科書で ふつうに 使う 書きかた)。**かぶらない**(bunka では「A型の イメージ」の ように 分ける)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)。**20字まで**(16字を こえるのは 上級だけ・旅で 1〜2語)
  - 英字は 読みで: A型 = えーがた / B型 = びーがた / O型 = おーがた / AB型 = えーびーがた / Rh = あーるえいち / DNA = でぃーえぬえー / MN式 = えむえぬしき / H抗原 = えいちこうげん
  - ゆれる ことばは `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
- **journey**: その 旅の id
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級
- **field**(📘 学ぶ 分野): 次の どれか
  `血液とからだ` / `免疫(抗原と抗体)` / `ABO式血液型` / `Rh式とそのほかの血液型` / `遺伝` / `輸血と献血` / `血液型の検査` /
  `めずらしい血液型` / `世界の血液型と人類学` / `動物の血液型` / `血液型の歴史` / `文化と心理学`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**)
- **emoji**: 1つ(💀 ☠️ 🔪 🩻 は 使わない。💉 の 多用は さける)
- **blood**(⭐ この ゲームだけの 欄。その 語が どの 血液型の 話か。**合う ときだけ** 付ける):
  `A` `B` `O` `AB` `Rh+` `Rh-` `ボンベイ型` `シスAB型` `Rhヌル` `4つの型` の どれか。2〜4つなら「・」で つなぐ(`"A・AB"`)。
  説明の 上に **血液型の 色の 札**(A 赤・B 青・O 黄・AB 紫)で 出る。⚠️ 色に 意味は 無い。動物の 血液型には 付けない
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の 表)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / 何の ために あるか / 血液型の 目線で どう 大事か」。
  「1人」「2人」は ふりがなが 読みまちがえるので **ひとり・ふたり** などに 言いかえる

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | **自分の 血液型を 知って いる 子**。4つの 型・赤血球・献血・遺伝の きほん・よく 言われる イメージ。小学生でも 聞いた ことが ある |
| 2 | 中級 | **高校の 生物・保健を 学ぶ 人**。抗原と 抗体・凝集・Rh式・遺伝子型・輸血の しくみ・バーナム効果 |
| 3 | 上級 | **血液型の 専門家**。**認定輸血検査技師の 範囲の めやす**: 亜型・めずらしい 血液型・ほかの 血液型の しくみ・交差適合試験・動物の 血液型 |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる(その 順が ステージの 順に なる)。

## どの 語を どの 旅に 入れるか

`tools/ketsueki/plan.json`(先に 1人の 助手が 決めた 置き場所。名前と 読みが 9つの 旅の 中で かぶらない)を 守る。
⚠️ 「A型」「B型」「O型」「AB型」の 語は `abo` に 1回ずつ。`bunka` は「A型の イメージ」、`iden` は「AA型(遺伝子型)」の ように 分ける

## 確かめた 事実(`tools/ketsueki/exam.txt`。これに 無い 年・数・人名は 書かない)

`exam.txt` を 読んでから 書く。あやしい ときは その 語を 入れない。

## ぜったいに 守ること

- **自分の ことばで 書く**。公式の 文・Wikipedia を 写さない
- **数字(%・人数・歳・量・日数・回数)は 書かない**
- 書いたら `python3 tools/ketsueki/terms_js.py --only <旅id>` で 形を 確かめる(まちがいが あれば 止まる)

## 出すもの

`tools/ketsueki/terms-<旅id>.json` に JSON の 配列(70語)で 書く。
