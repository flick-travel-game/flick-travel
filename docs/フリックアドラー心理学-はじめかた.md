## 3. ⚠️⚠️⚠️ ぜったいの 決まり(教師・保育士・看護師と 同じ。こころは なおさら)
- ✅ **ほかの ゲーム(教師・保育士・看護師 など)と 同じ 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。ただし 説明は **アドラー心理学の 目線**で 書きなおす(例: 自己肯定感 = 教師では 子どもの 育ち / アドラーでは 自己受容と 貢献感から 生まれる)
- **読み(ひらがな)は アドラーの 7つの 旅の 中では かぶらない**(ほかの ゲームとは かぶって よい)
- **心理療法の やりかた・カウンセリングの 台本・「こう 言えば 相手が 変わる」の 決めうち** を **ぜったいに 書かない**。書くのは **その ことばが 何を さすか・何の ための 考えかたか**だけ(例: 課題の分離 = それは だれの 課題かを 分けて 考え、人の 課題に 踏みこまない 考えかた)
- **悩みの 相談の 答えに なる 書きかたを しない**(「あなたの 場合は …」「この 性格なら …」)。画面に「これは ことばを おぼえる ゲームです。こころの ことで こまったら 家族や 先生・専門の 人に 相談してください」
- **人を 診断する・決めつける 書きかたを しない**(「◯◯な 人は 劣等コンプレックス」「長子は 〜な 性格」)。出生順位は「アドラーは 〜の 傾向が あると 考えた。決まりでは ない」の ように **傾向の 話**として
- **小学生も あそぶ**: 自殺・虐待・いじめの ようす・こころの 病気の くわしい 症状・こわい 言葉を 書かない。「不適切な行動の 4つの目的」の「復讐」は「仕返し」の ように やわらかく。「無気力」は「あきらめ」など
- **ほかの 心理学・宗教・自己啓発の よしあしを 書かない**(フロイトとの ちがいは **考えかたの ちがい**として 書く。どちらが 正しいかは 書かない)
- **実在の 本の 書名・出版社・講座の 名前を 売り文句に しない**(『嫌われる勇気』の ような 本は 歴史の 旅で「日本で 広まった きっかけの 本」と **事実として** 1語 入れるのは よいが、書名を 読みの 答えに しない。著者の 名前は 歴史上の 人(アドラー・ドライカース など)だけ。**生きている 人の 名前は 入れない**)
- **作った 助手とは 別の 助手が 1語ずつ 確かめる**(意味・読み・診断や 相談の 答えに なっていないか・こわくないか・ほかの 学派を けなしていないか)。ふりがなも 全語 見る(`tools/ruby_fix.json`)

## 5. 作りかたの 手順(税理士の まとめと 同じ)
1. けいくんに 2 の 5つを 聞く → 返事を CLAUDE.md に 書く
2. `tools/adler/PROMPT.md` `exam.txt` `mkmeta.py` → `meta.json` を 作る → 旅ごとに 助手に 70語ずつ 頼む(`PROMPT.md` を そのまま わたす。**助手は 2人ずつ**。いっぺんに 出すと 回数の 上限に あたる)→ `terms-<旅>.json`
3. `terms_js.py` で 止められた 語を 直す → 別の 助手が 1語ずつ 確かめる → ふりがな
4. `adler/adler.js`(zeirishi.js を 写す)・`build_games.py`・`index.html` の PLUG と SERIES → `python3 tools/build_games.py`
5. 手元で 通す: `python3 -m http.server 8765` → `node tools/play-all.mjs adler/` / `node tools/click-all.mjs adler/`
6. PR は **rebase で 取りこむ**(この 入れもの)。speed-king は squash。コミットの 末尾は Co-Authored-By と Claude-Session の 2行
7. かずとも `speed-king`: `FLICK_MODES` / `FLICK_LINK_TARGETS` に `adler`(PR → squash)。`HOME_GAMES` は 絵と OK の あと(「夢のしごと」の 章か、新しい 章「こころ」かは けいくんに 聞く)
8. けいくんに ChatGPT で 絵を 頼む 文を わたす。**2つ**:
   ・トップの 絵(1536×1024)+ 四角い 絵(1254px)。**人物は 画面の 下 3分の1に 小さく**・指5本・首が 見える。カウンセリングルームか 教室で 先生と 子どもたちが 対等に 話している 絵(**縦の 関係に 見えない 構図**。だれかが 上に 立たない)。絵の 中の 字は「フリックアドラー心理学」だけ・ゲームに 無い 機能の 絵を 入れない・**実在の 本の 表紙や 人の 顔を 描かない**。届いたら **まず 字を 切り出して 読む**
   ・**題名だけの 透明 PNG**(2026-10-02 の 決めごと。CLAUDE.md「題名は ChatGPT に 切りぬいてもらう」の 文を そのまま 使う。「フリック◯◯」の ところは「フリックアドラー心理学」と **はっきり 書く**。⚠️ ChatGPT は「旅行」を 落としたり「株式旅行」を「株式会社」に 変えたり 字の 順を 入れかえたり する。**届いた 字を かならず 読む**)
9. 絵を 入れたら CLAUDE.md に 節を 書く(名前・旅・語数・確かめた 日・入れなかった 語と 理由)

## 6. 気をつける 前例
- 看護師で 統合失調症 → 適応障害に 入れかえた(子どもが こわく 感じる)。アドラーでは **劣等コンプレックス・神経症・不登校・ひきこもり**などを 入れるか けいくんに 聞く(入れるなら「アドラーは こう 考えた」の 書きかたで、症状の ようすは 書かない)
- 読みの かぶりは 片方を べつの 語に(例: 「勇気づけ」と「勇気」は 別の 旅に 置けば よいが 読みが ちがうので OK。「補償」と「保証」の ような 同音は アドラーの 中で 1つだけ)
- 絵は 1回目・2回目とも 字が ちがった(税理士)→ 絵の 中で 直した(`tools/*/fix_text.py`)。題名は 2026-10-02 から ChatGPT の 切りぬきを そのまま 使う
- マイページ(右上の 1枚)は 土台の `index.html` に あるので、`SERIES` に 足すだけで 一覧の タイルにも 出る(絵は `adler/apple-touch-icon.png`)
- 2026-10-02 の 時点で 28ゲーム(税理士まで)。**フォルダ・id・modes 名を まぜない**(`adler`。かずともの 旅の 名前は `ad` で はじめる: adkihon / adkyodotai / adyuki / adlifestyle / adkosodate / adenjo / adrekishi / admas)
- 教師(`kyoshi/`)・保育士(`hoiku/`)と **同じ 語が 多く 出る**(自己肯定感・発達・愛着・自立 など)。**同じ 語を 入れて よい**が、説明は アドラーの 目線で
- ⚠️ こころの ことばは **読んだ 人が 自分に あてはめて 傷つく**ことが ある。「〜な 人は ダメ」「〜は 甘え」の ような 価値判断を 1語も 入れない。アドラー心理学の 言いかた(「勇気づけ」「どの 人にも 価値が ある」)に そろえる
