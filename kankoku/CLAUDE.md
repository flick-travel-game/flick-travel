  日常会話は 場面ごとに データの 順で 10問ずつ「まわり」に 分け、まわり → 場面 の 順に ならべる(`kankoku.js` の krtalk の ところ)。

- 4段: 1 入門 = ハングルが 読めて あいさつ / 2 初級 = 旅行で 困らない / 3 中級 = 友だちと ふつうに 話す(敬語と ため口)/ 4 上級 = ネイティブ。画面に TOPIK・検定の ことばは 出さない
- ことばは `tools/kankoku/src/<旅>.json`(決まりは `tools/kankoku/PROMPT.md`)+ `tools/kankoku/meta.json` → `tools/kankoku/korean_js.py` が `data/korean.json` と `kankoku/korean.js`。
  ⚠️ **id は korean_js.py が はじめて 通したときに src に 書きこむ**(`krw1-12` の 形)。きろくが id で おぼえているので **変えない・並べかえても id は そのまま**
- ⭐⭐ **読みの ひらがなは 手で 書かない**。src の `pron`(**発音どおりの ハングル**。連音化・鼻音化・濃音化・激音化・ㅎ脱落・流音化・口蓋音化・ㄴ添加を すませた 形)から
  `tools/kankoku/kana_table.py` の **1つの 表**で 作る。表(けいくんに 見せて 決めた): パッチム ㄱ=く / ㄴ=ん / ㄷ・ㅅ=っ / ㄹ=る / ㅁ=む / ㅂ=ぷ / ㅇ=ん、ㅓとㅗ=お、ㅡとㅜ=う、ㅐとㅔ=え、
  ㄱㄷㅂㅈ は 母音・ㄴㄹㅁㅇ の あとで が・だ・ば・じゃ、濃音は 母音の あとで 前に っ(오빠 → おっぱ)。単語の あいだで 子音が つながる ときは pron の 空白を 消す(이 옷 어때요 → 이 오더때요)
- 打つときの ゆるし(`norm` = korean_js.py の `typed` と 同じ): 空白・っ・ー は 打たなくて よい / か↔が・た↔だ・ぱ↔ば・ち↔じ は どちらでも。
  ⚠️ **ち/じ は「じ」に、っ は つ ごと 消す**。フリックで じ を 打つと とちゅうで し、っ は つ を 通るので、反対向きに すると 打っている とちゅうで 赤く なった(手元の 台本で 見つけた)。読みに つ は 出てこない(表に つ が 無い)
- 文の 旅(文法・会話・ネイティブ)は **`style`(합니다/해요/반말)と `who`(だれが だれに)を かならず 書く**。画面に「ていねい(해요体)」「👤 近所のおばさんに」の ふだが 出る。⚠️ **年上・先生・店員さんへの 文で 반말を 使わない**
- しくみは `kankoku/kankoku.js`(KANKOKU。`eikaiwa/eikaiwa.js` を 写した)。🔊 は ko-KR の 声(iPhone は Yuna)。**韓国語の 声が 無い 端末では 🔊 を 出さない**。⚠️ **Playwright では 声が 鳴らないので けいくんの iPhone で 1回 聞いてもらう**
- 🔊 の 声(けいくん 2026-10-12「発音はあっているの? もっとネイティブに」): 読みあげるのは **ハングルそのもの**(`q.t`)なので、連音化などの 発音の 決まりは 端末の 韓国語の 声が 正しく 当てる。声は **プレミアム > 拡張・Natural > Google > ふつう** の 順に えらぶ(`pickVoice` の `score`)。速さは ふつう 1.0・🐢 0.7。
  ⚠️ 声の よさは **端末に 入っている 声しだい**。iPhone は 設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 韓国語 で「Yuna(拡張)」か「プレミアム」を ダウンロードすると ずっと 自然に なる(無料)
- ⭐ **🔊 は 音声ファイル**(2026-10-12。けいくん「1だとぼくのiPhoneだけ発音が良くなる」→ だれが 聞いても 同じ 声に)。Google Cloud Text-to-Speech の **ko-KR-Chirp3-HD-Leda**(けいくんが 見本 7つから「もっと可愛い女性の声」で えらんだ)。
  `kankoku/audio/<sha1の頭12字>.mp3` と `map.json`(ハングル → ファイル)。1560問 + 안녕하세요 = 1561こ・12MB。`kankoku.js` の `playFile` が 先に ファイル、無ければ 端末の 声(`sayTTS`)。🐢 は playbackRate .75
  ・作るのは GitHub Actions の **kankoku-tts**(手で 押す。鍵は リポジトリの Secrets `GOOGLE_TTS_KEY`。⚠️ 鍵を チャット・ファイルに 出さない)。入力: limit / only(旅)/ voice / redo(1 = 作りなおす)/ samples(見本だけ)
  ・⚠️ **問題を 足したら kankoku-tts を 1回 押す**(足りない ぶんだけ 作る)。声を 変えるときは voice と redo=1
  ・台本は `tools/kankoku/tts_audio.py`
