## B-1. 民法 総則(能力・意思表示・代理)

### 能力
| 事実 | 出どころ |
|---|---|
| 意思表示を した 時に **意思能力が なかった** 法律行為は **無効** | 民3の2 |
| **18歳で 成年** | 民4 |
| 未成年者の 法律行為は 法定代理人の 同意が 要る。ただし **単に 権利を 得る・義務を 免れる 行為**は いらない。同意の ない 行為は **取り消せる** | 民5①② |
| 法定代理人が 目的を 定めて 処分を 許した 財産は、その 範囲で 自由に 処分できる(目的を 定めない ものも 同じ) | 民5③ |
| 成年被後見人の 法律行為は 取り消せる。ただし **日用品の 購入 その他 日常生活に 関する 行為**は 取り消せない | 民9 |
| 被保佐人は 13条1項の 行為(借財・保証・**不動産 その他 重要な 財産の 権利の 得喪**・訴訟・贈与・相続の 承認や 放棄・新築や 増改築・602条の 期間を こえる 賃貸借 など)に 保佐人の 同意が 要る。同意 なしは 取り消せる | 民13①④ |
| 被補助人は 家庭裁判所の 審判で 決めた「13条1項の 行為の 一部」だけ 補助人の 同意が 要る。本人以外の 請求なら 本人の 同意が 要る | 民17①② |
| 制限行為能力者の 相手方は、行為能力者に なった 本人に **1か月以上の 期間を 定めて** 追認するか 催告できる。返事が なければ **追認したものと みなす** | 民20① |
| 行為能力者に なる 前に 法定代理人・保佐人・補助人へ 催告して 返事が なければ **追認とみなす** / 被保佐人・被補助人 本人に「保佐人(補助人)の 追認を 得よ」と 催告して 通知が なければ **取り消したものと みなす** | 民20②④ |
| 取消権は **追認できる時から 5年**、**行為の時から 20年**で 消える | 民126 |

### 意思表示
| 事実 | 出どころ |
|---|---|
| **心裡留保**: 原則 有効。相手方が 真意で ないと **知り、又は 知ることが できた** ときは 無効。無効は **善意の 第三者**に 対抗できない | 民93①② |
| **虚偽表示**(相手方と 通じた うその 意思表示): **無効**。無効は **善意の 第三者**に 対抗できない | 民94①② |
| **錯誤**: 重要な 錯誤は **取り消せる**(無効では ない)。動機の 錯誤(基礎事情の 錯誤)は その 事情が **表示されていた** ときに 限る | 民95①② |
| 表意者に **重大な過失**が あると 取り消せない。ただし 相手方が 錯誤を 知り・重過失で 知らなかった とき、相手方も 同じ 錯誤の ときは 取り消せる | 民95③ |
| 錯誤の 取消しは **善意でかつ過失が ない 第三者**に 対抗できない | 民95④ |
| **詐欺・強迫**: 取り消せる。**第三者の 詐欺**は、相手方が 知り、又は 知ることが できた ときに 限り 取り消せる | 民96①② |
| **詐欺**の 取消しは **善意でかつ過失が ない 第三者**に 対抗できない(**強迫には この 第三者保護の 規定が ない**) | 民96③ |
| 相手方が 意思表示を 受けた 時に 意思能力が ない・未成年者・成年被後見人なら、その 意思表示を 対抗できない(法定代理人が 知った 後などは 別) | 民98の2 |

### 代理
| 事実 | 出どころ |
|---|---|
| 代理人が 権限内で **本人の ためにする ことを 示して** した 意思表示は 本人に 直接 効力 | 民99① |
| 表見代理 3つ: **代理権授与の 表示**(相手方が 悪意・有過失なら ×)/ **権限外の 行為**(正当な 理由が ある とき)/ **代理権 消滅後**(消滅を 知らなかった 第三者。過失で 知らなければ ×) | 民109・110・112 |
| **無権代理**の 契約は 本人が 追認しなければ 本人に 効力が ない | 民113① |
| 相手方は 本人に 相当の 期間を 定めて 追認するか 催告できる。返事が なければ **追認を 拒絶したものと みなす**(⚠️ 制限行為能力者の 20条と 逆) | 民114 |
| 相手方は 本人が 追認しない 間、**契約の 時に 代理権が ない ことを 知らなかった** なら 取り消せる | 民115 |
| 追認は 別段の 意思表示が なければ **契約の 時に さかのぼって** 効力(第三者の 権利は 害せない) | 民116 |
| 無権代理人は 相手方の 選択で **履行 または 損害賠償**の 責任。相手方が 知っていた・過失で 知らなかった(無権代理人が 自分で 知っていた ときを 除く)・無権代理人が 制限行為能力者 の ときは 負わない | 民117 |

## B-2. 時効
| 事実 | 出どころ |
|---|---|
| 所有権の 取得時効: 所有の 意思・平穏・公然に **20年** 占有。占有の はじめに **善意・無過失**なら **10年** | 民162 |
| 債権の 消滅時効: 権利を 行使できる ことを **知った 時から 5年** / 行使できる **時から 10年** | 民166① |
| 債権・所有権 以外の 財産権: 行使できる 時から 20年 | 民166② |
| **人の 生命・身体の 侵害**の 損害賠償(債務不履行): 10年の ところが **20年** | 民167 |
| 裁判上の 請求・支払督促・和解や 調停・破産手続参加: 終わるまで **完成猶予**。判決などで 権利が 確定すれば その 時から **更新**(新たに 進む)。確定せずに 終われば 終わってから 6か月 猶予 | 民147 |
| 強制執行・担保権の 実行 など: 終わるまで 完成猶予、終われば 更新(取下げ等なら 6か月の 猶予だけ) | 民148 |
| **催告**: その 時から **6か月** 完成猶予。猶予中の **再度の 催告は 効力なし** | 民150 |
| **協議を 行う 旨の 合意(書面・電磁的記録)**: 合意から 1年(1年未満の 期間を 定めれば その 期間・続行拒絶の 通知から 6か月)の 早い 時まで 猶予。くりかえしても 通じて **5年**まで | 民151 |
| **承認**が あれば その 時から **更新**。承認には 処分の 行為能力・権限が 要らない | 民152 |

## B-3. 債権(債務不履行・解除・売買・賃貸借・請負・委任・不法行為)

### 債務不履行と 解除
| 事実 | 出どころ |
|---|---|
| 履行遅滞: 確定期限 → 期限の 到来した 時 / 不確定期限 → 到来後に 請求を 受けた 時 か 到来を 知った 時の 早い ほう / 期限の 定めなし → 請求を 受けた 時 | 民412 |
| 債務不履行の 損害賠償は、債務者の **責めに 帰する ことが できない 事由**なら 請求できない(ただし書) | 民415① |
| 損害賠償は **通常損害**。**特別の 事情**の 損害は 当事者が **予見すべきであった** とき | 民416 |
| **催告解除**: 相当の 期間を 定めて 催告し 期間内に 履行が なければ 解除。不履行が **軽微**なら 解除できない | 民541 |
| **無催告解除**: 全部の 履行不能・明確な 履行拒絶 など | 民542 |
| 解除の 効果: **原状回復**(第三者の 権利は 害せない)。金銭は **受領の 時から 利息**。**損害賠償の 請求も できる** | 民545 |
| **危険負担**: 双方に 責任の ない 事由で 履行できなく なった とき、債権者は **反対給付の 履行を 拒める**(⚠️ 当然 消滅では ない) | 民536① |
| 引渡し **後**に 双方の 責任なく 滅失・損傷 → 買主は 追完・減額・損害賠償・解除を 請求できず、**代金の 支払を 拒めない**(危険の 移転) | 民567① |

### 弁済・相殺・保証
| 事実 | 出どころ |
|---|---|
| 第三者も 弁済できる。**正当な 利益が ない** 第三者は 債務者の 意思に 反して 弁済できない(債権者が それを 知らなかった ときは 有効)/ 債権者の 意思にも 反して できない | 民474①〜③ |
| 相殺: 互いに 同種の 債務・**双方が 弁済期** → 対当額で 相殺 | 民505① |
| 相殺の 禁止(受働債権): **悪意に よる 不法行為**の 損害賠償債務・**人の 生命・身体の 侵害**の 損害賠償債務 | 民509 |
| **保証契約は 書面**(電磁的記録も可)で しなければ 効力が ない | 民446②③ |
| 保証人には **催告の 抗弁・検索の 抗弁**。**連帯保証人には ない** | 民452・453・454 |
| **個人根保証契約**は **極度額**を 定めなければ 効力が ない(書面で) | 民465の2②③ |
| 委託を 受けた 保証人が 請求すれば、債権者は 主たる 債務の 履行状況を 情報提供しなければ ならない | 民458の2 |

### 売買(手付・契約不適合)
| 事実 | 出どころ |
|---|---|
| **手付**: 買主は 手付を **放棄**、売主は **倍額を 現実に 提供**して 解除できる。ただし **相手方が 契約の 履行に 着手した 後は** できない | 民557① |
| 手付解除では 損害賠償(545条4項)は 使わない | 民557② |
| **契約不適合**(種類・品質・数量): 買主は **追完**(修補・代替物・不足分)を 請求できる。買主の 責めに よる 不適合なら できない | 民562 |
| 追完の 催告を しても 追完が なければ **代金減額**。追完不能・明確な 拒絶などは 催告 なしで 減額 | 民563 |
| **種類・品質**の 不適合は、買主が **不適合を 知った 時から 1年以内に 売主に 通知**しないと 追完・減額・損害賠償・解除が できない。ただし 売主が 引渡しの 時に **知り、又は 重大な過失で 知らなかった** ときは この 制限なし(⚠️ 数量は この 1年の 制限の 対象外) | 民566 |

### 賃貸借(民法)
| 事実 | 出どころ |
|---|---|
| 存続期間は **50年を こえられない**(長く 定めても 50年)。更新も 更新の 時から 50年まで | 民604 |
| 不動産賃貸借は **登記**すれば 第三者に 対抗できる | 民605 |
| 対抗要件を 備えた 不動産が 譲渡されると **賃貸人の 地位は 譲受人に 移る**。移転を 賃借人に 対抗するには **所有権移転の 登記**が 要る。**敷金返還債務も 引き継ぐ** | 民605の2①③④ |
| 賃貸人は 必要な **修繕義務**(賃借人の 責めに よる ものを 除く) | 民606① |
| 賃借人が 修繕できる とき: 通知したのに 賃貸人が 相当の 期間 修繕しない / 急迫の 事情 | 民607の2 |
| **無断の 譲渡・転貸は できない**。無断で 第三者に 使わせたら 賃貸人は **解除できる** | 民612 |
| 適法な 転貸: 転借人は 賃貸人に 直接 義務を 負う(賃料の 前払は 対抗できない)。賃貸人は **合意解除**を 転借人に 対抗できない(債務不履行解除権が あった ときを 除く) | 民613①③ |
| 賃料は 建物・宅地は **毎月末**(後払い)が 原則 | 民614 |
| 期間の 定めなし: いつでも 解約申入れ。土地 **1年**・建物 **3か月**・動産 1日 で 終わる | 民617① |
| 原状回復: **通常の 損耗・経年変化は 除く** | 民621 |
| **敷金**(名目を 問わない): 賃貸借が 終わり **返還を 受けた とき**(明渡し後)に 債務を 引いた 残りを 返す。賃借人から「敷金を 充てて」とは 請求できない | 民622の2①② |
| 処分の 権限が ない 者の 短期賃貸借の 上限(602条)。具体的な 年数は 本文から 切れて 読めなかった → **未確認**(13条1項9号が 602条を 指す) | 民602 |

### 請負・委任
| 事実 | 出どころ |
|---|---|
| 請負 = 仕事の **完成**と 報酬 | 民632 |
| 注文者の 材料・指図に よる 不適合は 原則 請求できない | 民636 |
| 請負の 不適合も **知った 時から 1年以内に 通知**(請負人が 知り・重過失なら 制限なし) | 民637 |
| 仕事が 完成しない 間、注文者は **いつでも 損害を 賠償して 解除**できる | 民641 |
| 受任者は **善良な 管理者の 注意**(善管注意義務) | 民644 |
| 委任は **各当事者が いつでも 解除**できる。相手に 不利な 時期の 解除などは 損害賠償(やむを得ない 事由が あれば 不要) | 民651 |

### 不法行為
| 事実 | 出どころ |
|---|---|
| 故意・過失で 他人の 権利・利益を 侵害 → 損害賠償 | 民709 |
| 使用者責任(事業の 執行に ついて)。使用者から 被用者への **求償**も できる | 民715①③ |
| 被害者に 過失が あれば 裁判所は 額を 定める(**過失相殺**) | 民722② |
| 消滅時効: 損害 **及び 加害者を 知った 時から 3年** / **不法行為の 時から 20年** | 民724 |
| **人の 生命・身体**を 害する 不法行為は 3年が **5年** | 民724の2 |

## B-4. 物権(対抗要件・共有・相隣・担保物権・地役権)
| 事実 | 出どころ |
|---|---|
| **不動産**の 物権の 得喪・変更は **登記**しなければ 第三者に 対抗できない | 民177 |
| **動産**の 譲渡は **引渡し**で 対抗 | 民178 |
| 即時取得: 取引で 平穏・公然に 動産の 占有を 始め、善意・無過失 | 民192 |
| **共有物の 変更**: 他の 共有者の **同意**(全員)が 要る。ただし **形状又は効用の 著しい 変更を 伴わない もの(軽微な 変更)は 除く** | 民251① |
| 所在等が わからない 共有者が いれば、裁判所の 裁判で その 人 以外の 同意で 変更できる | 民251② |
| **共有物の 管理**(軽微な 変更・管理者の 選任解任を ふくむ): **持分の 価格の 過半数**。使っている 共有者が いても 同じ | 民252① |
| 所在等不明 や 催告しても 賛否を 明らかに しない 共有者を 除いて、裁判所の 裁判で 管理を 決められる | 民252② |
| 管理の 決定で 設定できる 賃借権等の 上限: 樹木の 山林 10年 / ほかの 土地 **5年** / **建物 3年** / 動産 6か月 | 民252④ |
| **保存行為**は 各共有者が できる | 民252⑤ |
| 共有物の 管理者(選任できる。変更は 共有者 全員の 同意) | 民252の2 |
| **所在等不明共有者の 持分の 取得**(不動産。裁判所の 裁判。時価相当額を 支払う。相続財産なら 相続開始から 10年 たたないと 不可) | 民262の2 |
| 所有者不明建物管理命令(土地も 同じ しくみ 264の2〜) | 民264の8 |
| 隣地の 使用: 境界付近の 工事・**境界標の 調査や 測量**・枝の 切取り の ため 必要な 範囲で 使える。住家は 居住者の **承諾が ないと 立ち入れない**。あらかじめ 通知 | 民209①③ |
| 公道に 通じない 土地の 通行権 | 民210 |
| **継続的給付**(電気・ガス・水道 など)の ため 他の 土地に 設備を 設置・他人の 設備を 使用できる(事前通知・償金) | 民213の2 |
| 越境した **枝**: 竹木の 所有者に 切除させる。**催告しても 相当の 期間 切らない・所有者 不明・急迫** なら 土地の 所有者が **自分で 切り取れる**。**根**は 切り取れる | 民233①③④ |
| 地役権: 他人の 土地を 自己の 土地の 便益に 使う 権利 | 民280 |
| 留置権: 物に 関して 生じた 債権。弁済期前・不法行為で 始まった 占有には 使えない | 民295 |
| 先取特権と **物上代位**(払渡し・引渡しの **前に 差押え**)| 民303・304 |
| 抵当権: **占有を 移さない** 担保。地上権・永小作権も 目的に できる | 民369 |
| 抵当権は 付加一体物に 及ぶ(**土地の 抵当権は 建物に 及ばない**) | 民370 |
| 抵当権にも **物上代位**(304条を 準用) | 民372 |
| 第三取得者の **抵当権消滅請求** | 民379 |

1. **区分所有法(令和8年4月1日 施行・令和7年法律第47号)** — 古い 本は ぜんぶ 古い
   - 集会の 決議が **出席者の 多数決**に(普通決議 = 出席者 及び 議決権の 各過半数)。**特別決議(共用部分の 変更・規約・管理組合法人・使用禁止 など)は「区分所有者と 議決権の 各過半数の 出席(定足数)+ 出席者の 各 3/4 以上」**(古い 本は「区分所有者 全員の 3/4」)
   - **所在等不明区分所有者**を 裁判所の 裁判で **決議の 母数から 除外**できる(新設 38条の2)
   - 共用部分の 変更は 規約で **過半数まで 下げられる**(古い 本は「区分所有者の 定数だけ 過半数まで」)。瑕疵の 除去・バリアフリーは **2/3**
   - 大規模滅失(1/2を こえる)の 復旧決議は **3/4 → 2/3**(出席者の 多数決)
   - 建替え決議は **各 4/5 の まま**(出席者では なく 全体。所在等不明者は 除外)。**耐震性 不足など**の 客観的 事由が あれば **3/4**(新設)
   - 新しい 決議: 建物更新(一棟リノベーション)・建物敷地売却・建物取壊し敷地売却・取壊し(各 4/5)/ 建替え時の 賃貸借の 終了請求
   - 招集通知 1週間前・建替えは 2か月前・説明会 1か月前 は 変わっていない
2. **不動産登記法**
   - **相続登記の 申請義務**(令和6年4月1日〜。知った 日から 3年・10万円以下の 過料・施行前の 相続は 令和9年3月31日まで)と **相続人申告登記**
   - **住所等変更登記の 申請義務**(令和8年4月1日〜。2年以内・5万円以下の 過料・施行前の 変更は 令和10年3月31日まで)と 職権の 変更登記(スマート変更登記)
3. **民法の 共有・相隣(令和5年4月1日〜)**
   - **軽微な 変更は 持分の 過半数**(古い 本は「変更は 全員の 同意」だけ)/ 管理者の 選任 / 管理で 設定できる 短期の 賃借権等(建物 3年・土地 5年)
   - **所在等不明共有者**: 裁判所の 裁判で 変更・管理・**持分の 取得**
   - 隣地の 使用(承諾 → 「使用できる」。住家は 居住者の 承諾)/ **越境した 枝を 自分で 切れる 場合**が できた / 継続的給付(ライフライン)の 設備設置権
4. **民法(債権法 改正後の 形。古い 本と ちがう ところ)**
   - 錯誤は **無効 → 取消し**。錯誤・詐欺の 第三者は **善意無過失**(心裡留保・虚偽表示は **善意**)
   - 債権の 消滅時効は **知った 時から 5年 / 行使できる 時から 10年**(職業別の 短期時効は ない)。生命・身体は 20年 / 不法行為は 5年
   - 時効の「中断・停止」→ **「更新・完成猶予」**。**協議を 行う 旨の 合意**の 猶予が ある
   - **瑕疵担保責任 → 契約不適合責任**(追完・代金減額・損害賠償・解除。種類・品質は **知った 時から 1年以内に 通知**)
   - 危険負担は **反対給付の 履行を 拒める**(債権者主義の 規定は ない)/ 敷金の 定義(622条の2)/ 原状回復から 通常損耗を 除く(621条)
   - 個人根保証は **極度額が ないと 無効**(貸金等 だけで なく すべての 個人根保証)
5. **相続法 改正後の 形**: 自筆証書の **財産目録は 自書 不要** / **法務局の 遺言書保管(検認 不要)** / **配偶者居住権・配偶者短期居住権** / 遺留分は **金銭請求(遺留分侵害額請求)** / **特別の 寄与**(相続人で ない 親族)
