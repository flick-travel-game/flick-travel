## 2. はじめに けいくんに 聞く 5つ(「全部おすすめで」と 返ってくる ことが 多い)
1. **名前**: 「フリック弁護士」で よいか(絵が 届いたら 絵の 題名に そろえる。フォルダ名 `bengoshi` は 変えない)
2. **旅の 分けかた**(おすすめ 7つ + 🏆 マスター):
   ⚖️ 法律の きほん(法律・条文・権利・義務・契約・判例・六法 …)/ 📜 憲法の ことば(基本的人権・三権分立・国民主権・平和主義・表現の自由・裁判を受ける権利 …)/
   🏠 民法と くらし(契約・売買・貸し借り・相続・結婚・未成年・消費者契約・損害賠償 … **名前と 何の ための 決まりか**)/
   🔍 刑法と 刑事の てつづき(犯罪と 刑罰の しくみ・無罪推定・弁護人・取り調べ・起訴・裁判員 … **名前と 役目だけ**)/
   🏛 裁判所と てつづき(地方裁判所・高等裁判所・最高裁判所・原告・被告・証人・判決・控訴・調停・和解 …)/
   💼 弁護士の 仕事(依頼人・相談・守秘義務・弁護士会・法テラス・国選弁護人・企業法務・弁護士倫理 …)/
   🌏 法律の 歴史と 世界(十七条の憲法・大宝律令・大日本帝国憲法・日本国憲法・国際法・国連・子どもの権利条約 …)
3. **むずかしさの 3段**: 入門(ニュースや くらしで 聞く 法律の ことば)→ 中級(**法学部・予備試験の 短答式の 範囲の めやす**: 憲法・民法・刑法の 大きな ことば)→ 上級(商法・民事訴訟法・刑事訴訟法・行政法の ことば・法律用語の こまかい 言いかた)
4. **1語に 持たせる 科目**(`field`): 司法試験の 科目(憲法 / 行政法 / 民法 / 商法 / 民事訴訟法 / 刑法 / 刑事訴訟法 + 法曹倫理・法律の きほん)の どれか。**確かめてから 決める**
5. **入れない もの**(下の 3 と かさなる): 犯罪の やりかた・法律の 抜け道・「こうすれば 罪に ならない」の 言いかた・実際の 事件の 名前・実在の 人物・こわい 犯罪の 中身。**法律の 名前と 目的だけ**

## 3. ⚠️⚠️⚠️ ぜったいの 決まり(警察官と 同じ。法律は なおさら)
- ✅ **ほかの ゲーム(警察官・社会旅行・歴史旅行 など)と 同じ 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。ただし 説明は **弁護士の 目線**で 書きなおす
- **読み(ひらがな)は 弁護士の 7つの 旅の 中では かぶらない**(ほかの ゲームとは かぶって よい)
- **犯罪の やりかた・法律の 抜け道・だましかた・「こうすれば 罪に ならない」「この ときは こうする」の 決めうち** を **ぜったいに 書かない**。
  書くのは **その ことばが 何を さすか・何の ための 決まりか**だけ(例: 時効 = 決まった 年月が すぎると 権利や 罰の あつかいが 変わる 決まり。くわしくは 法律で 決まっています)
- **法律の 相談の 答えに なる 書きかたを しない**(「あなたの 場合は …」「この 条件なら …」)。画面に「これは ことばを おぼえる ゲームです。本当に 困った ときは 大人に 言って、弁護士や 法テラスに 相談してください」
- **条文の 番号・罰の 重さ(懲役 何年 など)・金額は 書かない**(法律は 変わる。**まよったら 書かない**)。法律の 名前と 目的・何の ための 制度かだけ
- **小学生も あそぶ**: 殺人・性犯罪・薬物の 具体名・虐待の ようす・死の ようすを 書かない。犯罪の 名前(窃盗・詐欺 …)は 入れて よいが、
  **「法律が どう 守るか」「弁護士が どう 助けるか」の 書きかた**だけ。実際の 事件・裁判・実在の 人物は 入れない
- **政治・思想・宗教の よしあし**を 書かない(憲法の ことばは **何を 守る 決まりか**だけ。ある 判決・ある 法律の 是非は 書かない)
- **弁護士の ほかにも「法律の 仕事」が ある**ことは 旅「弁護士の 仕事」の 中で ふれて よい(裁判官・検察官・司法書士・行政書士 … **名前と 役目だけ**)
- **作った 助手とは 別の 助手が 1語ずつ 確かめる**(意味・読み・やりかた/抜け道を 書いていないか・こわくないか・相談の 答えに なっていないか)。ふりがなも 全語 見る(`tools/ruby_fix.json`)

## 4. 試験の 事実は **その日に 法務省・日本弁護士連合会・法テラスの ページで 確かめてから** 書く
`meta.json` の `exam` に 確かめた 日を つける(警察官の `exam.txt` + `mkmeta.py` の 型)。書く 中身(すべて 確かめる。**記憶で 書かない**):
弁護士に なる 道(①法科大学院(ロースクール)を 出る or ②予備試験に うかる → **司法試験** → **司法修習**(約1年)→ 二回試験 → 弁護士会に 登録)/
司法試験の 中身(短答式・論文式。科目は 憲法・行政法・民法・商法・民事訴訟法・刑法・刑事訴訟法 + 選択科目。年 1回・7月ごろ。**回数の 制限(5年で 5回)も 確かめる**)/
2023年から 法科大学院の **在学中 受験**が できる ように なった(確かめる)/ 合格者数・合格率の めやす(確かめた 年を 書く)/
弁護士は **国家資格**(弁護士法。日本弁護士連合会に 登録。**免許は 国が 出すのでは なく 弁護士会への 登録**。確かめる)/ 裁判官・検察官も 同じ 司法試験から(法曹三者)/
法テラス(日本司法支援センター)の 役目 / 裁判員制度(2009年〜。18歳以上。確かめる)/ 弁護士の 人数の めやす

## 5. 作りかたの 手順(警察官・医師・教師・料理人・消防士の まとめと 同じ)
1. けいくんに 2 の 5つを 聞く → 返事を CLAUDE.md に 書く
2. `tools/bengoshi/PROMPT.md` `exam.txt` `mkmeta.py` → `meta.json` を 作る → 旅ごとに 助手に 70語ずつ 頼む(`PROMPT.md` を そのまま わたす)→ `terms-<旅>.json`
3. `terms_js.py` で 止められた 語を 直す → 別の 助手が 1語ずつ 確かめる → ふりがな
4. `bengoshi/bengoshi.js`(keisatsu.js を 写す)・`build_games.py`・`index.html` の SERIES → `python3 tools/build_games.py`
5. 手元で 通す: `python3 -m http.server 8765` → `node tools/play-all.mjs`(4とおりの 打ちかた)/ `node tools/click-all.mjs`(W=320 も)
6. PR は **rebase で 取りこむ**(この 入れもの)。speed-king は squash。コミットの 末尾は Co-Authored-By と Claude-Session の 2行
7. かずとも `speed-king`: `FLICK_MODES` / `FLICK_LINK_TARGETS` に `bengoshi`(PR → squash)。`HOME_GAMES` は 絵と OK の あと(26 → 27 ゲーム。題の 数は 自動)
8. けいくんに ChatGPT で 絵を 頼む 文を わたす(トップ 1536×1024 + 四角い 絵 1254px。**人物は 画面の 下 3分の1に 小さく**・指5本・首が 見える・
   法廷か 法律事務所の 前で 本や 六法を 持つ(**手で 小さく 持つ 本は 崩れやすいので 持たせない ほうが よい**)。
   絵の 中の 字は「フリック弁護士」だけ・ゲームに 無い 機能の 絵を 入れない・**本物の 弁護士バッジ(ひまわりと 天秤)や 実在の 裁判所の 名前を 描かない**)。届いたら **まず 字を 切り出して 読む**(「ごっかしけん」の 前例)
9. 絵を 入れたら CLAUDE.md に 節を 書く(名前・旅・語数・確かめた 日・入れなかった 語と 理由)
