# ことばを 書く 係への おねがい(フリックメンタリスト。旅を 書く)

1. まず `tools/mentalist/PROMPT.md` を ぜんぶ 読む(4つの いちばん大事な 決まり・1語の 形・mapNode の 表)。
   手本の 書きぶりは `tools/shinri/terms-kioku.json`(心理学)と `tools/cabin/terms-manner.json`(キャビンアテンダント)。⚠️ 心理学と 同じ 効果は `tools/shinri/terms-*.json` の 中身と 食いちがわない ように(grep して 見る)
2. `tools/mentalist/plan.json` の あなたの 旅の 110語を、**plan の 順番の まま**(name・reading・difficulty・mapNode は plan の とおり。直したい ときは 下の 6)で 書く
   - phase 1 の 70語 → `tools/mentalist/terms-<旅>.json`
   - phase 2 の 40語 → `tools/mentalist/later/terms-<旅>.json`
   - relatedTerms は **同じ ファイルの 中の** id だけ(phase 2 の 語は 自分の ファイル か phase 1 の 同じ旅の ファイルの 語に つないで よい。⚠️ phase 1 → phase 2 へは つながない)
3. description は **メンタリストの 目線**、やさしい です・ます、語と 語の あいだに 半角スペース、130字以内。「何か → なぜ 大事か / どう 使うか」
4. ⭐⭐ **renshu(🎯 やってみよう)を 全部の 語に**(90字以内)。きょう 家で できる 具体的な 練習。人に ためす ものは かならず「やってもいい? と 聞いてから」。
   shikumi(🧠 しくみ)は 心理・観察・ことばの 語に なるべく、butai(🎩 ぶたい)は 舞台で 使う 語に(どちらも 70字以内・1文)。ei は 英語から 来た 語に
5. ⚠️ **事実は たしかな ものだけ**。下の「確かめた 事実」は 使って よい。自信が ない 数字・年・名前は 書かない(ぼかすか 意味だけに)。
   ⚠️ **数の 演目(1089・魔方陣・曜日・カレンダー・2進数)の 手順を 書く ときは、自分で 数を 3とおり 入れて 計算して 確かめる**
6. plan の 語が 決まりに 合わない(たねあかし・超能力と 読める・あやつる 向き・うそが 分かる・あやしい 事実・存命の 日本の 芸人)と 思ったら、**同じ difficulty・同じ mapNode の 別の 語に かえて よい**。
   ⚠️ その ときは `python3 tools/mentalist/terms_js.py --check --with-later` で 読みの かぶり(9つの 旅 ぜんぶ)が 0 か 確かめ、報告に「かえた 語」を 書く
7. 書いたら `python3 tools/mentalist/terms_js.py --check --with-later` を 走らせて、**あなたの 旅の 語**に ❌ が 出ない ことを 確かめる(ほかの 旅の ❌ は 気に しない。⚠️ ほかの 旅の ファイルは さわらない)。⚠️ の 長さの 注意も 直す。
   BAN(使えない 字)に 当たったら 言いかえる(「超能力」「だます」「うそを 見ぬく」は うしろに「ない/ません/しない」などの うち消しが あれば 通る)
8. git の コミットは しない。報告は みじかく: 書いた 語数・かえた 語と 理由・自信が なくて ぼかした 事実

## 確かめた 事実(2026-10-23。使って よい)
- メンタリストに 国の 資格は 無い(芸の 世界)。「メンタリズム」は 心理学・観察・暗示・ミスディレクション・ショーマンシップで こころを 読んだ ように 見せる 芸
- 1089: 3けたの 数(はじめと おわりの 数字が 2以上 ちがう)→ 逆に ならべて 大きい ほうから 引く → 答えが 2けたなら 前に 0 を 付けて 3けたに(99 → 099)→ それを 逆に して 足す → いつも 1089
- 2けたの 数 − その 各けたの 和 = いつも 9の 倍数。9の 倍数は 各けたを 足すと 9の 倍数
- カレンダーの 3×3 の 9つの 数の 合計 = まん中の 数 × 9
- サイコロの 向かい合う 面の 和は 7(ふつうの サイコロ)
- 3×3 の 魔方陣(1〜9)の 1列の 合計は 15、まん中は 5。4×4(1〜16)は 34
- 2進数の 封筒・カード: 1・2・4・8・16 の カードで 1〜31 を 表せる(お客さんが 数の ある カードを 言うと、その カードの いちばん 小さい 数を 足すと 当たる)
- 曜日の 計算: ツェラーの 公式。2000年1月1日は 土曜日
- 1〜10 の 数を 思いうかべて と 言うと 7 を えらぶ 人が 多い と いう 調査が ある(「多い」まで。割合の 数は 書かない)。1〜4 では 3 が 多い と いう 調査も ある
- 短期記憶の 量は 7±2(ミラー 1956)、いまは 4前後 と いう 説も(心理学ゲームと 同じ 書きかた)。忘却曲線は エビングハウス
- 記憶の 宮殿(場所法・loci)は 古代ギリシャの 詩人 シモニデスの 話で 知られる
- 世界記憶力選手権(World Memory Championships)は 1991年に はじまった。種目に 数・トランプ・名前と 顔 など。⚠️ 記録の 数字は 書かない
- バーナム効果(フォアラー効果): 1948年 フォアラーの 実験(だれにでも 当てはまる 性格の 文を 学生が 自分に よく 当たる と 感じた)。名前は 興行師 P・T・バーナムから
- ゴリラの 実験(見えないゴリラ): 1999年 シモンズと チャブリス。ボールの パスを 数えていると、まん中を 横切る ゴリラの 着ぐるみに 気づかない 人が 多い(選択的注意・非注意性盲目)
- 確証バイアス・アンカリング・プライミング・ハロー効果・返報性・同調(アッシュ)・権威・希少性(チャルディーニの 本で 知られる)
- 微表情(マイクロエクスプレッション): ポール・エクマンの 研究で 知られる。⚠️ 「うそを 見ぬける とは 言えない(研究中・当たる 率は 高くない)」と 書く
- 人が うそを 見ぬく 率は 研究で ほぼ 半分(54% ほど)と いう まとめ(ボンドと デパウロ 2006)。⚠️ 数は「ほぼ 半分」まで
- コールドリーディング: 相手を 前もって 知らずに、だれにでも 当てはまる ことや 反応を 見ながら それらしく 話す 技。占いや 霊感が 当たった と 感じる しくみとして 心理学の 本で 説明されている(イアン・ロウランドの 本など)
