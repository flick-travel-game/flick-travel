# 整備フリック旅行: ことばの 作りかた(助手に 分けて 頼むときの 決まり)

ゲームは「表示された ひらがなを フリックで 打ち写す」タイピング。打ち終わると 部品の 説明(1〜3文)と、しくみ図の どこに あるか(📍)が 出る。
遊ぶのは 小学生〜整備士を めざす 学生・大人。**部品の 名前と しくみを おぼえる ゲーム**。

## 1語の 形(JSON)
{"id":"en-piston","name":"ピストン","reading":"ぴすとん","journey":"engine","category":"ピストン・クランク","difficulty":1,
 "type":"concept","emoji":"⚙️","mapNode":"engine:crank","relatedTerms":["en-cylinder","en-crankshaft"],
 "description":"シリンダーの 中を 上下に 動く 筒の ような 部品。燃えた ガスに おされて、エンジンの ちからを 生みだします。",
 "example":"(なくてもよい)たとえば〜"}

- id: 旅の 頭文字 + "-" + 英小文字(en- / ch- / br- / el- / bk- / tl-)。英小文字・数字・- だけ
- name: 画面に 出す 名前(カタカナ・漢字・英字。整備の 現場の ふつうの 言いかた)
- reading: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白は ダメ)。
  カタカナ語は ひらがなに(でぃふぁれんしゃる)。英字の 略語は 日本の ふつうの 読み(ABS → えーびーえす / ECU → いーしーゆー)。
  数字は ひらがな(4サイクル → よんさいくる)。ゆれる ことばは 1つに 決め、別の 読みは "acceptedReadings":["よみ1","よみ2"](先頭は reading と同じ)
- difficulty: 1 = 入門(身近・小学生でも 聞いたことがある) / 2 = 3級 自動車整備士の 試験範囲の めやす / 3 = 2級の めやす
- **旅ごとに 60語: difficulty 1 を 20語、2 を 20語、3 を 20語**。同じ difficulty の 中は 有名な 順
- type: いつも "concept"
- category: 図鑑で しぼる 分類(短い 日本語。旅の 中で 4〜8種類)
- emoji: 1つ
- mapNode: 下の しくみ図の 場所(その 旅の 図から えらぶ)
- relatedTerms: **同じ ファイルの 中の** id を 1〜3個(自分は ダメ)。いっしょに おぼえると よい 部品
- description: 1〜3文・**130字以内**。やさしい です・ます。「何を する 部品か / どこに あるか / なぜ 大事か」。
  語と 語の あいだに 半角スペースを 入れる 書きかた(この シリーズの 文体。上の 例のように)。
  専門用語を 専門用語だけで 説明しない
- example: なくてもよい(ある ときは 身近な たとえ 1文)

## ぜったいに 守ること
- **自分の ことばで 書く**。過去問・問題集・教科書・Wikipedia の 文を 写さない
- **整備・分解・修理の やりかた(手順・締めつけ・ブレーキの 作業・高電圧の あつかい)は 書かない**。
  高電圧は「さわると 危ない」ことだけ。点検は「何を 見るか」まで(手順は 書かない)
- 数字(規定値・トルク・圧縮比の 値・年数)は **まちがいない ときだけ**。車ごとに ちがう 値は 書かない
- **メーカー名・車種名・商品名・ブランドは 使わない**
- 事実が あやしい 語は 入れない。まちがいを 書くより 入れないほうが よい
- ほかの 旅と かぶらない(下の「この旅に 入れる / 入れない」を 守る)

## しくみ図の 場所
- engine: intake 吸気 / fuel 燃料 / ignition 点火 / valve 動弁・バルブ / cyl 燃焼室・シリンダー / exhaust 排気 / turbo 過給 / crank ピストン・クランク / clean 排出ガス / lube 潤滑・オイル / cool 冷却 / basic エンジンの基本
- car: cool 冷却 / engine エンジン / body 車体・灯火 / battery バッテリー・電源 / trans トランスミッション / ecu ECU・センサー / steer ステアリング / drive 駆動・デフ / hv モーター・高電圧 / sus サスペンション / brake ブレーキ / tire タイヤ・ホイール
- bike: handle ハンドル・操作 / fuel 燃料・吸気 / elec 電装・灯火 / fork フロントフォーク / engine エンジン / frame フレーム・車体 / fbrake ブレーキ / clutch クラッチ・変速 / rsus スイングアーム・リヤサス / tire タイヤ・ホイール / chain チェーン・駆動 / exhaust マフラー・排気
- tool: tools 工具 / measure はかる道具 / lift ジャッキ・リフト / daily 日常点検 / periodic 定期点検 / inspect 車検 / fluid 油脂・液 / shop 整備工場・資格 / law 法令・保安基準 / safety 安全・環境 / basics 整備の基本の数 / doc 書類・記録

## 旅ごとに 入れる / 入れない
- engine(en-。図は engine): エンジン本体・4サイクル・吸気・燃料(インジェクター・燃料ポンプ)・点火(点火プラグ・イグニッションコイル)・バルブ・カム・ピストン・クランク・潤滑(エンジンオイル・オイルポンプ)・冷却(ラジエーター・サーモスタット・クーラント・ウォーターポンプ)・排気・触媒・ターボ・ジーゼル(グロープラグ・コモンレール)。
  **入れない**: キャブレター・2ストローク(bike)/ オルタネーター・スターター・センサー類(elec)
- chassis(ch-。図は car): タイヤ・ホイール・クラッチ(クルマ)・トランスミッション(MT・AT・CVT)・プロペラシャフト・ドライブシャフト・デフ・4WD・ステアリング・パワーステアリング・サスペンション・ショックアブソーバー・スプリング・アライメント(トー・キャンバー・キャスター)・フレーム・ボディ。**入れない**: ブレーキ全部(brake)
- brake(br-。図は car。場所は brake が 中心、tire・ecu も 可): ブレーキペダル・マスターシリンダー・倍力装置・ブレーキフルード・ディスク・パッド・キャリパー・ドラム・シュー・パーキングブレーキ・ABS・横すべり防止・ベーパーロック・フェード現象 など
- elec(el-。図は car。battery / ecu / hv / body / engine): バッテリー・オルタネーター・スターター・ヒューズ・リレー・配線・アース・ヘッドランプ・ウインカー・センサー(O2センサー・ノックセンサー など)・ECU・CAN通信・故障診断(OBD)・ハイブリッド・EV・インバーター・モーター・充電・回生ブレーキ・高電圧・運転支援のカメラ・レーダー。**入れない**: 点火プラグ・イグニッションコイル(engine)
- bike(bk-。図は bike): **二輪ならではの ことばだけ**。フロントフォーク・スイングアーム・チェーン・スプロケット・キャブレター・2ストローク・単気筒・空冷・クラッチレバー・シフトペダル・キックスターター・カウル・ステップ・センタースタンド・リヤサスペンション・トップブリッジ など。
  **入れない**: ほかの 旅と 同じ 一般の 語(エンジン・タイヤ・ブレーキパッド・ピストン・点火プラグ・バッテリー など)
- tool(tl-。図は tool): 工具(スパナ・メガネレンチ・ソケットレンチ・トルクレンチ・ドライバー・プライヤー)・はかる道具(ノギス・マイクロメーター・ダイヤルゲージ・シックネスゲージ・テスター・タイヤゲージ)・ジャッキ・リフト・ウマ・日常点検・定期点検・車検・保安基準・道路運送車両法・認証工場・指定工場・整備記録簿・油脂(グリス・ウォッシャー液)・安全(保護めがね)・単位(ニュートンメートル・キロパスカル)。
  **入れない**: エンジンオイル・クーラント(engine)/ ブレーキフルード(brake)

## 出すもの
`tools/seibi/terms-<旅id>.json` に JSON の 配列(60語)で 書く。書いたら `python3 -c "import json;d=json.load(open('<file>'));print(len(d))"` で 読めるか 確かめる
