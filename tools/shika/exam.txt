「歯科医師」に なるには、厚生労働大臣の 免許が 要ります(歯科医師法。歯科医師国家試験に 合格した 人に 与えられる)。⭐ 獣医師は 農林水産大臣。①なりかた: 大学の 歯学の 正規の 課程(6年制。学校教育法)で 学び、臨床実習の 前に 共用試験(知識を はかる CBT と、技能と 態度を はかる OSCE)を 受ける。令和3年に 歯科医師法が 変わり、令和6年4月から 共用試験に 合格した 学生は 臨床実習で 歯科医業が できる ように なり、令和8年4月からは この 合格が 国家試験を 受ける 条件に なった。②歯科医師国家試験: 毎年 少なくとも 1回 行う。第119回は 2026年1月31日・2月1日。第120回は 2027年1月30日・31日(合格発表 2027年3月16日)。問題は 必修 80題・総論 100題・各論 80題・臨床実地 100題の あわせて 360題(一般問題 1問 1点・臨床実地問題 1問 3点)。第119回の 合格基準は 領域A(総論)99点中 67点以上・領域B(各論)352点中 235点以上・必修問題 77点中 62点以上(採点から のぞいた 問題が ある ため)。③出題基準: 最新は 令和9年版(第120回から)。必修の基本的事項(医の倫理と プロフェッショナリズム・社会と歯科医療・予防と健康管理・人体の正常構造と機能 など 12項目)と、総論(Ⅰ 保健・医療と健康増進 / Ⅱ 正常構造と機能、発生、成長、発達、加齢変化 / Ⅲ 病因、病態 / Ⅳ 主要症候 / Ⅴ 診察 / Ⅵ 検査 / Ⅶ 治療 / Ⅷ 歯科材料と歯科医療機器)と、各論(Ⅰ 成長・発育に関連した疾患・病態 / Ⅱ 歯・歯髄・歯周組織の疾患 / Ⅲ 顎・口腔領域の疾患 / Ⅳ 歯質・歯・顎顔面欠損と機能障害 / Ⅴ 配慮が必要な高齢者・有病者・障害者等に関連した疾患・病態・予防ならびに歯科診療)。この ゲームの「試験の 区分」は この 14の 分け。④臨床研修: 合格した あと 診療を する 歯科医師は 1年以上の 臨床研修を 受ける。⑤歯科衛生士: 国家資格(歯科衛生士法・厚生労働大臣の 免許)。歯科医師の 指導の もとで 予防処置(歯の よごれを 取る・薬を ぬる)・歯科診療の 補助・歯科保健指導を する。⑥歯科技工士: 国家資格(歯科技工士法・厚生労働大臣の 免許)。歯科医師か 歯科技工士で なければ 仕事として 歯科技工(入れ歯・かぶせ物を 作る)は できない。⑦歯科助手: 法律で 決まった 免許は ない(日本歯科医師会が 自前の 認定を している)。⑧8020運動: 80歳に なっても 自分の 歯を 20本 以上 保とう という 運動。1989年(平成元年)に 厚生省(当時)と 日本歯科医師会が 始めた。⑨歯の 本数: 乳歯は 20本、永久歯は 親知らずを ふくめて 32本(親知らずは 4本 ぜんぶ 生えるとは かぎらない)。⑩日本の 木の 入れ歯: 日本では 木を 彫った 入れ歯(木床義歯)が 作られ、いま 残る いちばん 古い 総入れ歯は 和歌山市の 願成寺を 開いた 中岡テイ(仏姫)の もので、16世紀(戦国時代)の もの。ツゲの 木で できている。⑪小幡英之助: 1875年(明治8年)に 医術開業試験を「歯科」で 受けて 合格し、日本で はじめて 歯科の 開業免許を 受けた 人(日本歯科医師会の 歯科医学史)。この ゲームの「専門家に なれる レベル」は、歯科医師国家試験の 範囲の ことばを ひととおり 知っている こと の めやす。実際の 診察や 治療は 歯学部と 臨床研修で 身に つける。厚生労働省(第119回 合格発表・第120回 施行・令和9年版 出題基準・共用試験の 資料・e-ヘルスネット)・e-Gov法令(歯科医師法・歯科衛生士法・歯科技工士法・学校教育法)・日本歯科医師会(歯の 本数・日本の 最古の 入れ歯・歯科医学史)の ページで 2026年10月9日に 確かめた
