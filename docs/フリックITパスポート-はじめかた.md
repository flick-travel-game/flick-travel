# フリックITパスポート(`itpass/`)を 作る ための まとめ(2026-11-11。別の セッション用)

けいくん 2026-11-11「ITパスポートに **受かるレベル**に フリック問題で なれるように 別セッション用に まとめてください」

⭐ **いちばん 近い 手本は フリック宅建士(`takken/`)と フリック衛生管理者の まとめ**。`docs/フリック宅地建物取引士-はじめかた.md`・`docs/フリック衛生管理者-はじめかた.md`・`takken/CLAUDE.md` の 作りかたを そのまま なぞる(⭕❌ 一問一答・数字クイズ・模擬試験・❌ 復習 の 4つ)。
ことばは **フリックパソコン(`pasokon/`)・フリックスマホ(`sumaho/`)・フリックプログラマー(`code/`)・フリックゲームクリエイター(`gamedev/`)・フリック起業家(`kigyo/`)・フリック投資家(`toshika/`)・フリック弁護士(`bengoshi/`)** と たくさん かさなる(かさなって よい。説明は **ITパスポートの 目線 = 「会社で ITを 使う 人が 何を 知っておくか」**で 書きなおす)。

⭐⭐ **「受かる レベル」の ための 決めごと**(宅建士・衛生管理者と 同じ 5つ):
ITパスポートは **4つから 1つ えらぶ 100問・120分・CBT(パソコンで いつでも)・合格は 1,000点満点で 総合 600点以上 かつ 3つの 分野(ストラテジ系・マネジメント系・テクノロジ系)それぞれ 300点以上**(下の 3)。
ことばを 打つ だけでは **「略語の 意味」「計算」「文を 読んで えらぶ」に 弱い**。宅建士と 同じく **ことば + 問題 + 模擬試験**:
① **ことば 1,000語**(10の 旅 × 100語 = 入門15・中級30・上級55)。⚠️ ITパスポートは **英語の 略語**(SaaS・RPA・BCP・SLA・DX …)が とても 多い。読みは 日本での 読み(下の 2)
② **⭕❌ 一問一答 約1,200問**(自分の 文で 書く。⚠️ 公開されている 過去問の 文を **写さない**。考えかただけ 自分の 文に)
③ **🔢 数字・計算クイズ 約220問**(2進数・稼働率・損益分岐点・ROI・減価償却・SQL の 結果・表計算の 式・ネットワークの 速さ・ビット と バイト など。4つから えらぶ)
④ **🎯 模擬試験**(本番と 同じ 4択 100問・120分・分野の 問題数も 本番どおり。総合 600 / 分野 300 の 合格の きまり)
⑤ **❌ まちがえた 問題の 復習**(運転免許・宅建士・衛生管理者に つづく 例外。けいくんの 宅建士の 決定の まま)

- 宅建士・衛生管理者で「数字が 合否を 分ける」と 数字クイズを 作った。ITパスポートは **数字 より 計算と 略語**。数字クイズに **計算の 問題**(2進数・稼働率・損益分岐点・表計算の 式)を 入れる(気象予報士の 🧮 計算問題の 形も 参考)
