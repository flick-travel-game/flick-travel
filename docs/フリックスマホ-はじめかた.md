## 6. 気をつける 前例
- 農家で キャタピラ → クローラ、花屋で オアシス → 吸水スポンジ、家事で 断捨離 を 外した。**商標は 一般の 言葉に**
- プレプロ(`prepro-saas`)で「LINE」の 名前を 売り文句に 使わない と 決めた(道具として「LINEで 送る」は よい)。**スマホも 同じ**: 「iPhone で 撮る」は 事実、「フリックiPhone」は 商品名に 使う ことに なる
- AI旅行(`ai/`)・プログラマー(`code/`)と 語が かさなる(クラウド・Wi-Fi・アプリ・2ファクタ認証)。**同じ 語で よい**が **スマホを 使う 目線**で
- 理科の 物理(電波・電池・レンズ)と つなぐと へえに なる(「スマホの カメラも 理科の レンズ」)
- ⭐ **このゲームの 名前の もと は スマホの「フリック入力」**。`sosa` の 旅で 1語 入れると いちばんの へえに なる
- **フォルダ・id・modes 名を まぜない**(`sumaho`)。作る 前に `tools/build_games.py` の 先頭の 一覧で いまの ゲームを 見る
