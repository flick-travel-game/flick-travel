# フリック心理学(`shinri/`)を 作る ための まとめ(2026-10-15。新しい セッション用)

けいくん 2026-10-15「新しいセッションで フリック心理学を作成したい。**心理学の専門家になれるレベル**になるために必要なことをフリック形式の問題にしてください」

⭐ いちばん 近い 兄弟は **フリックアドラー心理学(`adler/`)**(心理学の 1つの 学派)と **フリック哲学(`tetsugaku/`)**(立場が ならぶ・決めつけない)。医療の 線引きは **フリック看護師(`kango/`)・医師(`ishi/`)**。
⚠️ ほかの ゲームに 無い 3つの 気をつけ:
① **心の 病気の 名前を あつかう**ので、こわく しない・決めつけない・**自分や 友だちを 診断する 道具に しない**
② **「◯◯な 人は ◯◯」の 決めつけ**(血液型・性格占い の ような もの)を 心理学と して 書かない。**科学で たしかめられた こと**と **昔 有名だった 考え**を 分ける
③ アドラー心理学と かさなる。**アドラーは 1語・1人として だけ**(くわしくは フリックアドラー心理学へ)

## 3. ⚠️⚠️⚠️ ぜったいの 決まり(アドラー心理学・哲学・看護師と 同じ + この ゲームだけの もの)
- ⭐⭐⭐ **この ゲームだけの いちばん 大事な 決まり: 診断の 道具に しない**。子どもが「ぼく ADHD かも」「あの子 うつ病だ」と **人に ラベルを はる** ように ならない 書きかた。病気・障害は **「そういう 状態が ある」「専門家が 時間を かけて 判断する」「相談すれば 助けが ある」**まで。**チェックリスト(当てはまれば ◯◯)は 書かない**
- ⭐⭐ **科学で 確かめられた ことと、そうで ない ことを 分ける**。血液型性格・右脳型 / 左脳型・「人は 脳の 10%しか 使って いない」・学習スタイル(視覚型 / 聴覚型)は **「よく 言われるが、研究では 確かめられて いない」**と 書く(⭐ これ自体が へえ に なる。上級の 語に)。**有名な 実験で のちに 結果が ゆらいだ もの**(マシュマロ実験・自我消耗・パワーポーズ など)は **「のちの 研究で 結果が 弱まった」**と そえる(⚠️ **再現性の 問題** は 上級の 1語 と して 入れて よい)
- ⭐ **人を 動かす・だます 道具と して 書かない**。返報性・単純接触効果・ハロー効果 などは **「自分が 気づく ため」「だまされない ため」**の 向きで(「こうすれば 人を あやつれる」と 書かない)
- **こわく しない**(看護師の 前例)。病気は「何が 起きている 状態か」+「支える 人と しくみが ある」だけ。**相談先**(スクールカウンセラー・保健室・おうちの人)の ことばは **入れて よい**(子どもの 安全に 役立つ)
