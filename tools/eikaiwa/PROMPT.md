# 英会話フリック旅行: ことばを 作る 決まり

子ども(小学生)〜大人が、フリック入力で 英語を 打ち写して あそぶ ゲーム。
打ち終わると「日本語の 意味・例文」が 出る。**外国の人と ふつうに 話せる 英語**を 身につける のが ねらい。
⚠️ 「勉強っぽさ」は 出さない(英検・TOEIC・学年・「〜級」などの ことばは 書かない)。

## 出力(JSON の 配列だけ。ファイルに 書く)

### 英単語(kind = "word")
```json
{"text":"apple","pos":"名詞","meaning":"りんご","emoji":"🍎","category":"食べもの・飲みもの","example":"I eat an apple every morning.","exampleJa":"わたしは 毎朝 りんごを 食べます。","difficulty":1}
```
- text: 英単語 1語(小文字。I・Monday・Japan のような 決まった 大文字だけ そのまま)。
  使える字は a-z A-Z と ' と - だけ(数字・空白は なし)。
- pos: 名詞 / 動詞 / 形容詞 / 副詞 / 前置詞 / 代名詞 / 接続詞 / 助動詞 / 間投詞 / 数 のどれか
- meaning: 日本語の 意味。**いちばん よく使う 意味を 1〜2個**(「/」で 区切る)。20字 まで。辞書を 写さず 自分の ことばで
- emoji: その ことばに 合う 絵文字 1つ(むずかしい ことばは 近い イメージで。❔ は 使わない)
- category: 下の「分類」から 1つ
- example: その 単語を 使った **短い・自然な 英文**(3〜10語・60字まで)。ネイティブが ふつうに 言う 形。
  ⚠️ 教科書っぽい 不自然な 文(This is a pen. など)は ダメ。人名は 使わない か、Tom / Emma / Ken / Yuki くらい
- exampleJa: 例文の 自然な 日本語訳。**ことばの あいだに 半角スペースは 入れない**(ふつうの 日本語の 文)
- difficulty: 1 入門 / 2 初級 / 3 中級 / 4 上級(指示された 数)

### 日常英会話(kind = "phrase")
```json
{"text":"Could you say that again?","meaning":"もう一度 言ってもらえますか?","scene":"basic","example":"Sorry, could you say that again?","exampleJa":"すみません、もう一度 言ってもらえますか?","reply":"Sure. I said, turn left at the bank.","replyJa":"いいですよ。銀行で 左に 曲がって と 言いました。","tip":"聞きとれなかったときの いちばん 大事な ひとこと","difficulty":1}
```
- text: 実際に 使う 短い 文(**40字まで**・2〜8語くらい)。使える字は a-z A-Z 空白 ' , . ? ! だけ(数字・" ・ - ・ : は なし)
- meaning: 自然な 日本語訳(30字まで)
- scene: 指示された 場面の id
- example / exampleJa: その フレーズを 使う 1場面の ミニ会話(なくてもよい。あれば text と ちがう 文に する)
- reply / replyJa: **相手が 言いそうな 返事**(中級・上級では なるべく 入れる。入門でも あれば よい)。50字まで
- tip: いつ 使うか・言いかえ の ひとこと(25字まで。なくてもよい)。例「お店で 見ているだけの とき」
- difficulty: 1〜4(やさしい 順)

## 大事な 決まり
- **英語は アメリカ英語で、ネイティブが いま ふつうに 使う 形**。古い 言いかた・直訳英語・和製英語は ダメ
  (✖ How do you do? ✖ I'm fine thank you, and you? を 最初に 教える ✖ Let's go to shopping.)
- **市販の 単語帳・英検や TOEIC の 過去問・教科書の 文を 写さない**。例文・訳は ぜんぶ 自分で 書く
- 同じ text を 2回 入れない(大文字・小文字の ちがいも 同じと みなす)
- 子どもが 見るので、お酒・たばこ・お金もうけ・こわい話・恋愛の 話は 例文に 入れない
- 日本語は やさしく。小学生が 読める ていど(漢字は 使ってよい。あとで ふりがなを 付ける)
