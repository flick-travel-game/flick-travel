# フリック血液型(`ketsueki/`)を 作る ための まとめ(2026-10-04。新しい セッション用)

けいくん 2026-10-04「新しいセッションで フリック血液型を作成したい。**血液型の専門家になれるレベル**になるために必要な 知識をフリック形式の問題にしてください。
**血液型の特徴をめちゃくちゃ詳しくお願いします**」

## ⚠️⚠️ まず「血液型の 特徴(性格)」の こと(けいくんに いちばん はじめに 伝える)
- 「A型は きちょうめん」「B型は マイペース」の ような **血液型と 性格の 関係は、科学の 調べでは 確かめられて いない**(大きな 調べで「関係は ほぼ 無い」と いう 結果が 出て いる。⚠️ 出どころを 確かめて、`meta.json` に 書く)。
  日本・韓国など 一部の 国で とても 人気の **文化・遊び**。
- そして **「◯型だから 〜」と からかう・決めつける いじめ(ブラッドタイプ・ハラスメント、ブラハラ)** の もとに なって きた(⚠️ 確かめる)。**小学生が あそぶ ゲーム**なので、ここが いちばん 気を つける ところ。
- ⭐ だから **こう する**:
  1. **血液型の「本当の 特徴」= からだの しくみ** を めちゃくちゃ くわしく(抗原・抗体・遺伝・輸血・めずらしい 血液型・動物の 血液型・世界の 分布)。**これが 専門家の 知識**
  2. **性格の 話は 1つの 旅**「🔮 血液型と 性格の うわさ(日本の 文化)」に まとめて、**けいくんの ねがい どおり くわしく**。ただし **「日本で 〜と 言われて いる イメージ」** として 書き、**事実と して 書かない**
  3. **よく 言われる イメージは「いい ところ」だけ**(A型 = ていねい・まじめ / B型 = 自分の ペース・好きな ことに 夢中 / O型 = おおらか・まとめ役 / AB型 = 落ちついて いる・アイデアが ゆたか)。⚠️ **悪口に なる イメージ**(自己中・神経質・大ざっぱ・二重人格 など)は **書かない**(その 血液型の 子が 笑われない ように)
  4. 旅の はじめと マスターの 終わりに「**血液型で 人を 決めつけない。人の 性格は 一人ひとり ちがう**」の 1行
- ⚠️ けいくんが「性格を もっと 事実の ように 書いて」と 言ったら、**上の 理由を もう一度 伝えて 止める**(まちがった ことを 子どもに 本当の ように 教える ことに なる)

## 3. ⚠️⚠️⚠️ ぜったいの 決まり(医師・獣医師と 同じ。血液型は 人を 決めつけやすい ので なおさら)
