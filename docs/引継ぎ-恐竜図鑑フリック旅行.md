## ⚠️⚠️ この ゲームだけの 大事な 4つ

### 1. **写真は Wikimedia Commons から。1枚ずつ 目で 見る**
シリーズの 決まり(CLAUDE.md):
> 写真は Wikimedia Commons の PD / CC0 / CC BY / CC BY-SA だけ。1枚ずつ 目で 確かめる。
> 手を 加えたら 作者名に「(文字を消して使用)」など

- しくみは もう ある: **`photos.js`**(`PHOTOS` に 作者・ライセンス・もとの ページ)+ `tools/fetch_photos.py`。
  画面に 出すのは `index.html` の `pic(q)` が `PHOTO_LIST[q.art]` を 見て 出す
- ⚠️ 恐竜の 写真は **2しゅるい ある**。どちらを 使うか 決めて `PROMPT.md` に 書く:
  ・**骨の 標本**(博物館の 全身骨格)… 本物。まちがいが ない
  ・**復元図(生きている ようすの 絵)**… 見ばえは よいが、**古い 姿の 絵が 多い**(羽毛が ない・しっぽを ひきずる)
  → おすすめ: **骨の 写真を 主に**、復元図は **新しくて 正しい もの**だけ
- ⚠️ 写真が 見つからない ものは、世界旅行と 同じで **絵文字の カード**で よい(`q.e`)。
  ⚠️ **AIの 絵は 使わない**(シリーズの 決まり)

### 2. **恐竜の 話は どんどん 新しくなる**
「恐竜博士」に なる ゲームなら、**古い 知識を 書かない**ことが いちばん 大事。

- ⚠️ 気をつける ところ(いまの 考えを **確かめてから** 書く):
  ・**羽毛**が あった 恐竜が たくさん いる こと(ティラノサウルスの 仲間も)
  ・しっぽを **ひきずらない**(体を 水平に して 歩く)
  ・**鳥は 恐竜の 仲間**(獣脚類から 生まれた)
  ・**ブロントサウルス**の ように、名前が 復活した ものが ある
  ・**ステゴサウルスの 板**・**トリケラトプスの えり**の 役目は まだ はっきり しない
- 言いきらず **「〜と 考えられています」「まだ 分かっていません」**の 形に する。
  ⚠️ **「まだ 分かっていない」と 書ける ことが、博士に 近い**。むりに 答えを 作らない
- `tools/kyoryu/meta.json` の `note` に **「2026年◯月に 確かめた ものです。恐竜の 研究は 毎年 新しく なります」**と 日付つきで 書く

### 3. **理科旅行と ことばが かぶる**
`rika/` の 地学・生物に、恐竜の 勉強で 出る ことばが もう ある。調べたら **15語 かぶった**:

> 化石 / 地層 / 示準化石 / 示相化石 / 中生代 / 古生代 / 新生代 / アンモナイト / 三葉虫 /
> 進化 / ほ乳類 / は虫類 / 鳥類 / プレート / 堆積岩(ほかに 隕石 も どこかに ある)

- ⚠️ **同じ ことばを もう一度 出さない**。恐竜だけの ことばに する
  (獣脚類・竜脚類・鳥盤類・生痕化石・足跡化石 など)
- ⚠️ 作る前に **`rika/index.html` の `{n:"..."` を ぜんぶ 出して 見くらべる**

### 4. **恐竜では ない 生きものを 混ぜない**
博士に なる うえで いちばん 大事な 見分け。**これを 1つの 旅に する**と 強い。

- **恐竜では ない**: 翼竜(プテラノドン)・首長竜(フタバサウルス)・魚竜・モササウルス・
  ディメトロドン(恐竜より 前の 生きもの)
- **恐竜**: 陸の 上で、足が 体の **真下**に のびる 仲間。**鳥も 恐竜の 仲間**
- ⚠️ 説明で「恐竜の プテラノドン」のように 書かない。**「恐竜では ありません」と はっきり 書く**
