# フリック弁護士: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
学ぶ 分野・しくみ図の どこに あるか(📍)が 出る。あそぶのは **小学生〜弁護士を めざす 中高生・大学生・大人**。
**弁護士に なるための 法律の ことばと 意味を おぼえる ゲーム**(試験の 問題集でも 法律相談でも ない)。
もとは `tools/keisatsu/PROMPT.md`(警察官)。
けいくん 2026-10-01「弁護士になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 6つ

### 1. やりかた・抜け道を 書かない(警察官と 同じ。法律は なおさら)
- ❌ **書かない**: 犯罪の やりかた・だましかた・にげかた / 法律の 抜け道 / 「こうすれば 罪に ならない」「この ときは こうする」「◯◯なら 払わなくて よい」の 決めうち /
  裁判で 勝つ こつ / 取り調べで どう 答えるか
- ⭕ **書くのは**: その ことばが **何を さすか**・**何の ための 決まり・制度か**・**弁護士・裁判所が どう 守るか・助けるか**
  - 例: 時効 = 決まった 年月が すぎると、権利や 罪の あつかいが 変わる しくみ。くわしい 長さは 法律で 決まっています
  - 例: 黙秘権 = 取り調べや 裁判で、言いたく ない ことを 言わなくて よい 権利。憲法が 守っています

### 2. 法律相談の 答えに しない
- ❌「あなたの 場合は …」「この 条件なら …できます」「◯日 以内なら 取り消せます」のような、読んだ 人が 自分の 問題に あてはめる 書きかたを しない
- ⭕ 一般的な しくみの 説明だけ。必要なら「くわしくは 法律で 決まっています」「こまったら 大人や 弁護士・法テラスに 相談」で しめる
- 画面には「これは ことばを おぼえる ゲームです。法律相談の 答えでは ありません。本当に 困った ときは 大人に 言って、弁護士や 法テラスに 相談してください」が 出る

### 3. 条文の 番号・罰の 重さ・金額を 書かない
- **条の 番号(第◯条)は 書かない**(台本が 止める)。「憲法第9条」は 名前に せず「戦争の放棄」「平和主義」で
- **罰の 重さ(◯年以下・◯円以下)・金額・日数**を 書かない。法律は 変わる。**まよったら 書かない**
- ⚠️ **刑罰の 名前は 2025年6月から 変わった**: 懲役・禁錮は **拘禁刑**に 一つに なった。「懲役」「禁錮」は 使わない(台本が 止める)。
  刑罰は 拘禁刑・罰金・科料・拘留・執行猶予 などの **名前と 役目だけ**
- 数字・年は **まちがいない ときだけ**(日本国憲法の 公布 1946年11月3日・施行 1947年5月3日、成年年齢は 2022年4月から 18歳、裁判員制度は 2009年5月 から、など)。あやしい 語は **入れない**

### 4. 小学生も あそぶ(こわく しない)
- ❌ 事件・事故・けが・死の ようすを 書かない。「死刑」は **入れない**(けいくん決定 2026-10-01)
- ❌ **殺人・強盗・誘拐・放火・性犯罪・薬物の 具体名・暴力団・テロ** などは **入れない**。実際の 事件・裁判・実在の 人物(歴史上の 人物は よい。聖徳太子・北条泰時 など)は 入れない
- ⭕ 入れて よい 犯罪の 名前は 窃盗・詐欺・器物損壊・名誉毀損・侮辱 など、子どもが 気をつけられる もの。書きかたは「法律が どう 守るか」「弁護士が どう 助けるか」
- ⭕ 離婚・借金・いじめ・ハラスメントは 入れて よい。「法律が 守る しくみ」「相談できる ところが ある」の 書きかたで
- 相続・遺言は「ある人の 財産を 家族などが 引きつぐ こと」の ように、**人が 亡くなる ようすを 書かずに** 説明する
- 「死亡」「死ぬ」「亡くなっ」「殺」「遺体」「血」「銃」「撃」は 使わない(台本が 止める)。**迷ったら その 語を 入れない**

### 5. 政治・思想・宗教の よしあしを 書かない
- 憲法の ことばは **何を 守る 決まりか**だけ。憲法改正・自衛隊・天皇の 地位なども **中立に、しくみだけ**
- ある 判決・ある 法律が 正しい / まちがい、を 書かない

### 6. 弁護士の 目線で 書く(警察官・社会など ほかの ゲームと 同じ 語を 入れて よい)
- ✅ **ほかの ゲームと 同じ ことばを 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)
- ⚠️ ただし 説明は **弁護士の 目線**で 書きなおす。例: 黙秘権 … 警察官「取り調べで 守られる 権利」/
  弁護士「弁護人は この 権利が 守られて いるかを 見まもり、依頼人に 知らせます」。
  警察官 = 調べる 側 / 弁護士 = 守る 側・ことばで 解決を 手伝う 側
- **読み(ひらがな)は 弁護士の 7つの 旅の 中で かぶらない**(台本が 止める)。下の「旅ごとに 入れる / 入れない」を 守る

## 1語の 形(JSON)

```json
{"id":"kh-kenri","name":"権利","reading":"けんり","journey":"kihon","category":"権利と義務","difficulty":1,
 "field":"法律のきほん","type":"concept","emoji":"🙋","mapNode":"kihon:kenri","relatedTerms":["kh-gimu"],
 "description":"法律が みとめて 守って くれる「◯◯して よい」「◯◯を もとめて よい」という 力の ことです。弁護士は 依頼人の 権利が 守られる ように 手伝います。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(ふつうに 使う 言いかた。漢字・カタカナ・英字の 略語)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)
  - 数字は ひらがな(十七条の憲法 → じゅうしちじょうのけんぽう)
  - ゆれる ことばは 1つに 決め、別の 読みは `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)。
    例: 遺言 ゆいごん / いごん、競売 けいばい / きょうばい、十七条の憲法 じゅうしちじょう / じゅうななじょう
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は **上級だけ**に、旅で 1〜2語まで(長い 法律名は 略した 呼び名に。説明に 正式な 名前)
  - ⚠️ **法律の 読みは まちがえやすい。1語ずつ 確かめる**: 遺言 ゆいごん・競売 けいばい・定款 ていかん・瑕疵 かし・債権 さいけん・
    債務 さいむ・抵当権 ていとうけん・勾留 こうりゅう・拘留 こうりゅう(かぶるので 片方だけ)・科料 かりょう・過料 かりょう(かぶる)・
    被疑者 ひぎしゃ・控訴 こうそ・公訴 こうそ(かぶる)・上告 じょうこく・抗告 こうこく・訴追 そつい・示談 じだん・弁論 べんろん・
    口頭弁論 こうとうべんろん・既判力 きはんりょく・遺留分 いりゅうぶん・嫡出 ちゃくしゅつ・親権 しんけん・後見 こうけん・御成敗式目 ごせいばいしきもく・
    律令 りつりょう・大宝律令 たいほうりつりょう・武家諸法度 ぶけしょはっと・罪刑法定主義 ざいけいほうていしゅぎ
  - ⚠️ **同じ 読みの 別の 語**(控訴/公訴・勾留/拘留・科料/過料・私法/司法・詐欺/(なし))は **どちらか 1つだけ**入れる
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級(下の「3段の 分けかた」)
- **field**: 学ぶ 分野。次の 10の どれか(入門の 語でも いちばん 近い ものを 書く):
  `法律のきほん` `憲法` `行政法` `民法` `商法` `民事訴訟法` `刑法` `刑事訴訟法` `選択科目` `法曹倫理`
  - めやす: 法の しくみ・法の 歴史・六法・法の 解釈 → `法律のきほん` / 人権・統治・憲法の 歴史 → `憲法` /
    行政の しくみ・役所への 不服・地方自治の 法・情報公開 → `行政法` / 契約・家族・相続・損害賠償・物と お金 → `民法` /
    会社・手形・商売 → `商法` / 民事裁判の 手続き・調停・強制執行 → `民事訴訟法` / 罪と 刑罰の 考えかた・罪の 名前 → `刑法` /
    捜査・起訴・公判・裁判員・少年事件の 手続き → `刑事訴訟法` /
    労働法・知的財産法・倒産法・租税法・経済法・環境法・国際関係法(国際法・条約)→ `選択科目` /
    弁護士の 仕事・弁護士法・弁護士会・守秘義務・法テラス・司法試験と 修習 → `法曹倫理`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(🔫 🔪 🩸 💀 ☠️ 💣 💊 ⚔️ など こわい・武器の 絵文字は 使わない。⚖️ の 多用も さける)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / 何の ために あるか・弁護士は どう かかわるか」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  専門用語を 専門用語だけで 説明しない。「1人」「2人」は ふりがなが 読みまちがえるので **ひとり・ふたり** と ひらがなで 書く
- **example**: なくてもよい

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | ニュースや くらしで 聞く 法律の ことば。小学生でも 聞いた ことが ある(法律・憲法・裁判・弁護士・契約・権利) |
| 2 | 中級 | **法学部・予備試験の 短答式の 範囲の めやす**(憲法・民法・刑法の 大きな ことば・裁判の しくみ) |
| 3 | 上級 | 商法・民事訴訟法・刑事訴訟法・行政法の ことば・法律用語の こまかい 言いかた・選択科目の 名前 |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる
(ならんだ 順が そのまま ステージの 順に なる)。

## ぜったいに 守ること

- **自分の ことばで 書く**。過去問・問題集・教科書・Wikipedia の 文を 写さない
- **実在の 事件・裁判・人物(歴史上の 人物は よい)・会社・法律事務所の 名前**は 使わない(法務省・最高裁判所・日弁連・法テラス など **役所・公の 団体の 名前は よい**)
- **数字は まちがいない ときだけ**。試験・制度の 事実は `tools/bengoshi/exam.txt` に 合わせる
- 「100マス計算」「百ます計算」の 字を 使わない

## 出すもの
