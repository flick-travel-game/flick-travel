## フリック獣医師(`jui/`。けいくん 2026-10-03「獣医師の専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」。まとめは `docs/フリック獣医師-はじめかた.md`)

- 名前は「フリック獣医師」(絵が 届いたら 題名に そろえる。フォルダ名 `jui` は 変えない)。シリーズの 絵文字は 🐾。`SERIES_ORDER` は **薬剤師の となり**
- 旅は 9つ(獣医さんのきほん `kihon`・動物のからだ `karada`・ペットとくらす `pet`・動物の病気と治療 `byoki`・予防とワクチン `yobo`・牧場の動物 `sangyo`・野生動物と動物園 `yasei`・動物と人の健康 `koshu`・法律と歴史・動物福祉 `hoki`)+ マスター。
  **旅ごとに 70語(入門20・中級25・上級25)= 630語**。かずともの 旅の 名前は **`ju` で はじめる**(jukihon / jukarada / jupet / jubyoki / juyobo / jusangyo / juyasei / jukoshu / juhoki / jumas)。作る 前に ぶつからない ことを 確かめた
- むずかしさは 3段: 入門(**ペットを 正しく 飼える 人**)→ 中級(**動物病院で 働く 人 = 愛玩動物看護師の 範囲の めやす**)→ 上級(**獣医師国家試験の 範囲の めやす**)。

  ⚠️ まとめの 案に あった「基礎・病態・応用・臨床 獣医学」は **大学の 分けかたで、試験の 分けでは ない**(農水省の 資料で 確かめた)ので 使っていない
- ⭐ **🐾 動物の 札**(`animal` の 欄 → terms.js の `an`): 犬 / 猫 / うさぎ / ハムスター / 小鳥 / 爬虫類 / 魚 / 牛 / 豚 / 鶏 / 馬 / 羊 / やぎ / 野生動物 / 動物園の動物 / 人と動物 / いろいろな動物(「・」で 3つまで)。

- ⚠️⚠️⚠️ **治療の やりかたを 書かない**: 薬の 量・手術の 手順・家で できる 手当て・「この しょうじょうなら この 病気」・正常値・寿命・ワクチンの 回数や 時期・**商品名(フード・動物の 薬)・実在の 動物病院 / 動物園 / 水族館・動物の 個体名**(台本 `BAN` / `BAN_RE` が 歳・℃・回・頭・か月 の 数字・商品名・園の 名前を 止める)。

- ⚠️⚠️ **動物の いのちの 終わりの 話を 書かない**(台本が「死」「殺」「安楽」「と畜」「処分」「寿命」「動物実験」「虐待」「捨て」を 止める)。保護犬・保護猫は「新しい 家族を まって いる」、食肉衛生検査は「お肉が 安全か 確かめる」まで。殺菌は 入れず 除菌・滅菌・消毒。
