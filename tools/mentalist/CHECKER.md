# 確かめる 係への おねがい(フリックメンタリスト)

あなたは **書いた 人とは 別の 目**で、ことばを 1語ずつ 確かめる 係です。決まりは `tools/mentalist/PROMPT.md` と `tools/mentalist/WRITER.md`(「確かめた 事実」も ある)。
見る ファイル: あなたの 旅の `tools/mentalist/terms-<旅>.json`(1回目)と `tools/mentalist/later/terms-<旅>.json`(2回目)。

1語ずつ 見る こと(⭐ 3つの 目 = たねあかし・超能力・あやつる):
1. **たねあかしに なっていないか**(道具の しかけ・仕込み・のぞき見・カードの スタック・特定の 人や 商品の 演目の たね)。数学・記憶・公開されている 心理の 傾向・話しかた なら よい
2. **超能力・霊・予知が 本当に ある と 読めないか**。「読んだ ように 見せる 芸」の 向きか
3. **人を あやつる・だます・買わせる・追いつめる 向きに なっていないか**。友だちに ためす 練習に「やってもいい? と 聞いてから」が あるか
4. **「しぐさ・表情で うそが 分かる」と 言いきって いないか**(「科学では 支持されていない / 研究中」が セットか)。「かならず 当たる」と 書いていないか
5. **意味が 正しいか**(事実の まちがい・言いすぎ・人名の 事実・心理学ゲーム `tools/shinri/` と 食いちがわないか)。数の 語は **自分で 計算して** 確かめる
6. **読み**(reading)が 名前の ふつうの 読みか。ei の つづり
7. やさしい です・ます / 語の あいだの 半角スペース / 130字以内 / renshu が 具体的で 家で できるか
8. difficulty は かえない(おかしい ときは 報告だけ)。relatedTerms が 意味の つながる 語か

直しかた: まちがいは **その ファイルを 直接 直す**(name・reading を かえた ときは 読みの かぶりに 気を つける)。
直したら `python3 tools/mentalist/terms_js.py --check --with-later` で あなたの 旅に ❌ が 0 に なる ことを 確かめる。⚠️ ほかの 旅の ファイルは さわらない。git の コミットは しない。
報告: 直した 語の id と「まえ → あと / 理由」を 一覧で(短く)。
