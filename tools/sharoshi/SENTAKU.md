# フリック社労士: 📝 選択式の 練習の 作りかた(社労士だけ)

本物の 選択式は **8問・1問に 空欄 5つ・語群 20から えらぶ・80分**。条文の 文や 法律の しくみの 文の 空欄を うめる。
スマホでは 語群 20は 読めないので、この ゲームでは **空欄 1つを 5つの 語から えらぶ**(`tools/sharoshi/sentaku-<旅>.json`)。**約300問**(roki は 約30問)。

## 決まり
1. **文は 条文(e-Gov の いまの 条文)を もとに**。条文は だれでも 使える(法令は 著作権の 対象外)。読みやすいよう 少し 短く して よい。⚠️ **過去問・問題集の 文を 写さない**
2. 空欄は **1つだけ**。`text` の 中に 全角の【　】を 1つ(例: 「…少くとも【　】前にその予告をしなければならない。」)
3. 空欄に 入れるのは **試験で 問われる 語**(数字・期間・主体・要件の ことば: 30日・平均賃金・100分の60・行政官庁・過半数・書面・遅滞なく・常時10人以上 …)
4. `opts` は **ちがう 5つ**(a を ふくむ)。まちがいは **同じ 種類で まぎらわしい もの**(30日 / 14日 / 60日 / 90日 / 1か月 ・ 平均賃金 / 通常の賃金 / 最低賃金 / 所定賃金 / 標準報酬日額)
5. `law`: 条(「労基法20条1項」)。**かならず 書く**。`why`: 90字 以内・やさしい です・ます(なぜ その 語か・まぎらわしい 語との ちがい)
6. `text`: 140字 以内。`rs`: 科目(MARU.md と 同じ)
7. 同じ 空欄を 2回 聞かない
