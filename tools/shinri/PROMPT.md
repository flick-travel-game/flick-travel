# フリック心理学: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
分野・しくみ図の どこに あるか(📍)が 出る。ときどき「🧪 じっけん」「💡 くらしで」も 出る。
あそぶのは **こころに 興味の ある 小学生〜高校生・大学で 心理学を 学ぶ 人・公認心理師を めざす 人・大人**。
**心理学の 専門家に なるための ことばと 意味を おぼえる ゲーム**(こころの 診断や 悩みの 相談の 答えでは ない)。
もとは `tools/tetsugaku/PROMPT.md`(哲学)と `tools/adler/PROMPT.md`(アドラー心理学)。まとめは `docs/フリック心理学-はじめかた.md`。
けいくん 2026-10-15「心理学の専門家になれるレベルになるために必要なことをフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 8つ

### 1. ⭐⭐⭐ 診断の 道具に しない(この ゲームだけの いちばん 大事な 決まり)
- 子どもが「ぼく ADHD かも」「あの子 うつ病だ」と **人に ラベルを はる** ように ならない 書きかた
- 病気・障害は **「そういう 状態が ある」「専門家が 時間を かけて 判断する」「相談すれば 助けが ある」**まで
- ❌ **チェックリスト・症状の ならび(「〜なら ◯◯」「〜が あれば ◯◯の サイン」)は 書かない**。❌ 診断の しかた・診断基準の 中身・薬の 名前と 量
- ⭕ 相談先の ことば(スクールカウンセラー・保健室・おうちの人・先生)は 入れて よい
- 発達障害は **「生まれつきの 脳の はたらきかたの ちがい。得意と 苦手の かたより」**。❌「普通 / 異常」「欠点」「治す」

### 2. ⭐⭐ 科学で 確かめられた ことと、そうで ない ことを 分ける
- 血液型性格判断・右脳型 / 左脳型・「人は 脳の 10%しか 使って いない」・学習スタイル(視覚型 / 聴覚型)は
  **「よく 言われるが、研究では 確かめられて いない」**と 書く(これ自体が へえ に なる)
- 血液型性格判断は フリック血液型と 同じ 立場:「血液型と 性格の 結びつきは、科学の 研究では 確かめられて いない」
- 有名な 実験で **のちに 結果が ゆらいだ もの**(マシュマロ実験・自我消耗・パワーポーズ など)は **「のちの 研究で 結果が 弱まった」**と そえる
- マジカルナンバー7 は「いまは 4前後と いう 説も ある」と そえる

### 3. 人を 動かす・だます 道具と して 書かない
- 返報性・単純接触効果・ハロー効果・フット・イン・ザ・ドア などは **「自分が 気づく ため」「だまされない ため」**の 向きで
- ❌「こうすれば 人を あやつれる」「人を 動かす 心理術」。❌ マインドコントロール・洗脳

### 4. こわく しない(小学生も あそぶ)
- ❌ **入れない ことば**: 自殺・自傷・摂食障害・依存症・統合失調症・虐待・暴力(台本が 止める)
- ❌ **人や 動物が つらい 思いを する 実験は 入れない**: ミルグラムの 服従実験・スタンフォード監獄実験・アルバート坊や・ハーロウの サル・学習性無力感の 犬の ようす
  ・ボボ人形実験は **「見て まねる」まで**(たたく ようすは 書かない)
  ・学習性無力感は「何を しても 変わらないと 思うと、動けなく なる ことが ある と いう 考え」まで(実験の ようすは 書かない)
- 病気は「何が 起きている 状態か」+「支える 人と しくみが ある」だけ:
  うつ病「気もちが 長い あいだ しずむ 病気。治療や 休むことで よく なる」/ 不安症 / 適応障害 / PTSD(名前だけ。何が あったかは 書かない)
- こわい 絵文字(💀 ☠️ 🔪 🩸 ⚰️ 🪦 😱)は 使わない

### 5. 人を 決めつけない
- 性格・知能は **「1つの ものさし」「人の 価値では ない」**。IQ は「頭の よさの 1つの ものさし。人の 価値では ない」
- ❌「◯◯な 人は ◯◯」「◯◯型の 人は」。ステレオタイプは「決めつけに 気づく ための ことば」と して

### 6. 学派の よしあしを 書かない(アドラー心理学・哲学と 同じ)
- フロイト・行動主義・認知・人間性 は **「〜と 考えた」**で ならべる。❌「〜は まちがい」「〜を のりこえた」
- ⚠️ アドラーの 語(勇気づけ・課題の分離・共同体感覚 …)は **入れない**。「アドラー」の 1語だけ(歴史の 旅。「個人心理学を ひらいた。くわしくは フリックアドラー心理学で」)

### 7. やさしい ことばで 言いかえて から 専門の 名前
- ⭕「メタ認知 = 自分の 考えを、もう ひとりの 自分が 見る こと」の ように **ふつうの ことばが 先**。カタカナ語を ならべない
- **生きている 人の 名前は 入れない**(人物は 歴史上の 人だけ。plan.json の とおり)。今の 心理学者・カウンセラー・病院・アプリ・本の 商品名も 書かない
- **人の 生まれた 年・亡くなった 年は 書かない**。「19世紀の おわりごろ ドイツで 活やく した 心理学者」の 形で
- 実験の 年・人数・数字は **確かめた ものだけ**。数字の 決めうち(「◯%の 人が」・IQ の 数・合格率)は 書かない

### 8. 心理学の 目線で 書く(ほかの ゲームと 同じ 語を 入れて よい)
- ✅ アドラー心理学・哲学・からだ図鑑・理科・看護師・血液型 と 同じ 語や 人を 入れて よい。説明は **心理学の 目線**(「こころの はたらきを どう しらべたか」)で
- ⚠️ **だれの 実験か の まちがいが いちばん 多い**: 同調 = アッシュ / 傍観者効果 = ラタネと ダーリー / 古典的条件づけ = パブロフ / オペラント条件づけ = スキナー /
  観察学習 = バンデューラ / 忘却曲線 = エビングハウス / マジカルナンバー7 = ミラー / 認知的不協和 = フェスティンガー / 社会的手抜き = リンゲルマン /
  欲求の 5段階 = マズロー / 来談者中心療法 = ロジャーズ / フロー = チクセントミハイ / 成長マインドセット = ドゥエック / 内発的動機づけ・アンダーマイニング効果 = デシ / PM理論 = 三隅二不二 /
  ピグマリオン効果 = ローゼンタール / 心の理論(サリーとアン課題)= バロン=コーエンら / 箱庭療法 = カルフが まとめ、河合隼雄が 日本に 紹介
  ⚠️ 名前が 生きている 人(ドゥエック・チクセントミハイ(2021年 没)の ように わかれる)は plan.json の 決めに したがう。**あやしい ものは 人の 名前を 書かずに 考えだけ**
- **読み(ひらがな)は 心理学の 9つの 旅の 中で かぶらない**(台本が 止める)。**人の 名前の 語は 1回だけ**(plan.json の 旅に)。ほかの 旅では 考えの 名前で

## 1語の 形(JSON)

```json
{"id":"gk-pavlov","name":"パブロフの犬","reading":"ぱぶろふのいぬ","journey":"gakushu","category":"条件づけ","difficulty":1,
 "field":"学習・言語","type":"concept","emoji":"🔔","mapNode":"gakushu:koten","relatedTerms":["gk-kotentekijokenzuke"],
 "description":"ロシアの 学者 パブロフの 有名な 実験。ベルの 音の すぐ あとに えさを もらう ことを くりかえした 犬は、ベルの 音だけで よだれが 出る ように なりました。",
 "jikken":"ベルの 音の あとに えさ → くりかえすと ベルだけで よだれが 出る",
 "kurashi":"給食の 時間の チャイムで おなかが すく のも にた しくみ"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(心理学の 教科書で ふつうに 使う 書きかた)。⚠️ 年表の 人の 名前は plan.json と 1文字も ちがえない
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」「=」は ダメ)
  - カタカナ語は ひらがなに。ゆれる 読みは `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)。「ヴ」は `ゔ` で 書き、バ行の 読みも acceptedReadings に(ヴント → ゔんと / ぶんと)
  - 英字の 名前(IQ・EQ・ADHD・PTSD)は ひらがなの 読み(あいきゅー)か、日本語の 名前の 読みに
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は 上級だけ・旅で 1〜2語まで
- **journey** / **difficulty**(`1` 入門 / `2` 中級 / `3` 上級)
- **field**: つぎの 17の どれか(公認心理師 試験の 出題基準の 分けに そろえた):
  `心理学の成り立ち` `研究法・統計` `知覚・認知` `学習・言語` `感情・人格` `脳・神経` `社会・集団` `発達` `障害` `アセスメント` `心理支援` `健康・医療` `福祉` `教育` `司法・犯罪` `産業・組織` `法と制度`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の 表)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / だれが 考えたか・しらべたか / なぜ 大事か」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(上の 例のように)。「1人」「2人」は **ひとり・ふたり** と ひらがなで
- **jikken**(任意): **🧪 じっけん**。有名な 実験・効果の 語に **1文で「どんな 実験か」**(50字まで・句点なしで よい)。**人が つらい 思いを する 実験は 書かない**。**1旅に 0〜15語**
- **kurashi**(任意): **💡 くらしで**。**1文で「くらしの どこで 見られるか」**(50字まで)。**1旅に 10〜20語**(台本が 数を 見る)。
  ⚠️ 人を あやつる 使いかたは 書かない(「〜に 気づけると だまされにくい」の 向き)
- **example**: なくてもよい

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | **こころに 興味の ある 子**: 錯視・有名な 実験の 名前・記憶の コツ・ストレスの ことば |
| 2 | 中級 | **高校生・大学で 心理学を 学ぶ 人**: 心理学の 教科書の ことば・学派と 人・研究の しかた |
| 3 | 上級 | **公認心理師・臨床心理士を めざす 人**: 公認心理師 試験の 出題基準の めやす(統計・発達・臨床・法と 制度・支援の しかた) |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる。

## 旅ごとに 入れる 語

**`tools/shinri/plan.json` に 9つの 旅 × 70語の 置き場所(name・reading・difficulty・mapNode)が 決めてある**。その とおりに 書く。
どうしても 事実が あやしい 語は 入れかえて よいが、**ほかの 旅の 語・読みと かぶらない**ように(plan.json を 見る)。入れかえたら 報告する

## ぜったいに 守ること

- **自分の ことばで 書く**。教科書・事典の 本文を 写さない
- **数字・年は まちがいない ときだけ**。事実が あやしい 語は **入れない**(まちがいを 書くより 入れないほうが よい)
- 人物の 話は **「〜を となえた」「〜と 考えた」「〜を しらべた」** の 形に
- **人と 実験の 組み合わせ**を 1つずつ 確かめる

## 出すもの

`tools/shinri/terms-<旅id>.json` に JSON の 配列(70語)で 書く。書いたら
`python3 tools/shinri/terms_js.py --only <旅id>` で 形を 確かめる(まちがいが あれば 止まる)。
