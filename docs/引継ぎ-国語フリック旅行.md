## 国語だけの しくみ(整備士と ちがう ところ)

- **打つ字と 出す字が ちがう 旅が ある**: 古文単語は 歴史的仮名遣い(をかし)を 出して 現代仮名遣い(おかし)を 打つ。
  データに `display`(出す 字)と `reading`(打つ 字)を 分けて 持つ。古語の ほうは 学ぶ ための 見せかた
- **漢文の 句法**は「〜」が 入る → 出す 字は「未(いまだ〜ず)」の 形に して、打つのは **「いまだず」ではなく 全文の 読み下し例**(「いまだかえらず」など)に するか、けいくんと 決める
- **よみを かくす レベル**(決めてもらうこと 4): 上級だけ、出す 字の 上の よみ(ひらがな)を かくして **読みを 思い出して 打つ**。
  ⚠️ いまの 土台は「出た ひらがなを 打ち写す」形なので、かくすなら `index.html` に 小さな 切りかえを 足す(ほかの 旅には ひびかせない)。
  ⚠️ かくす レベルでは **説明の ふりがなで 答えが 見えない**ように、打ち終わるまで 説明を 出さない(いまも 打ち終わってから 出る)
- **ゆれる 読み**は `acceptedReadings`(例: 貼付 = ちょうふ / てんぷ、依存 = いぞん / いそん)。先頭は reading と 同じ
- **図**: 地図や 体の 絵の かわりに、**時代の 年表**(奈良・平安・鎌倉・室町・江戸・明治・大正・昭和)に 文学史の 📍を 立てる案。絵に しなくても コードで 描ける(シリーズの 決まり「図は AI の 絵に しない」)
