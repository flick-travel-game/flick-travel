# フリックワールドベースボール: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
どの 国の 話か(国旗の 札)・どの ルールの 話か(NPB / MLB / 高校 の 札)・学ぶ 分野・しくみ図の どこに あるか(📍)が 出る。
あそぶのは **野球が すきな 小学生〜中高生・少年野球の コーチ・野球が すきな 大人・解説者を めざす 人**。
**野球の ことばと 意味を おぼえる ゲーム**(ニュースでも、記録集でも ない)。
もとは `tools/soccer/PROMPT.md`(ワールドサッカー)。けいくん 2026-10-10「ワールドベースボールの専門家(解説者)になれるレベルになるために必要な 知識、
主要な野球リーグ、有名野球選手、有名な技、ルールをフリック形式の問題にしてください」→ 5つの 問いと「いまの スター選手は チーム名を 書かない」に「全部おすすめで」。
⭐ けいくんは **スポーツの 指導者**。まちがいは すぐ 気づかれる。**選手と 国・技と 使い手・年と 大会・ルールと NPB / MLB / 高校** は かならず 確かめて から 書く。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 9つ

### 1. ⭐⭐ 数字が 変わる ものを 書かない(いちばん 事故が 起きやすい)
- ❌ **いまの 所属チーム**(移籍・トレード・ポスティングで 変わる)・年俸・契約金・いまの 順位・**いまの 選手の 通算記録**・いまの 打率 / 防御率 / 本塁打数・いまの 監督・年齢(「◯歳」)
- ✅ **変わらない 事実は よい**: 国籍(代表)・ポジション・投げる手 / 打つ手(右投げ左打ち など)・**得意な 球種 / 打ちかた / プレーの 特徴**・**過去の 受賞と その 年**(「2023年の MVP」)・
  **WBC / オリンピックの 優勝の 年と 国**・**引退した 選手の 所属の 歴史と 記録**(王貞治の 868本塁打 など。⚠️ `exam.txt` で 確かめた ものだけ)・人数(9人)・球速の めやす(「160キロを こえる ストレート」)
- リーグの **参加チーム数は 長く 変わらない ものだけ**(NPB 12球団・MLB 30球団)
- ⚠️ 台本 `terms_js.py` が「年俸・契約金・トレード・順位・◯歳・◯円・%」などを 止める

### 2. ⭐⭐ いまの スター選手(`star`)の 書きかた
- 「**日本代表の 投手。160キロを こえる ストレートと 落ちる スプリットが 武器**」の ように **代表の 国・ポジション・プレーの 特徴**で 書く
- ❌ **チーム名を 書かない**(説明にも 名前にも。MLB 30球団・NPB 12球団の 名前 ぜんぶ)。「所属」「在籍」「移籍」「契約」「球団」「通算」も 書かない(台本が 止める)
- ✅ 代表で 勝った 大会(「2023年 WBC で 優勝した 日本代表の 一員」)・個人の 受賞と 年(「2024年の MVP」)は よい
- ⚠️ **2026年10月の 時点で 現役か** を 1人ずつ web で 確かめる(`exam.txt` ⑫ も 見る)。引退した 選手は `legend` へ(ただし 旅を こえて 入れない。下の 表の 自分の 旅だけ)。
  **39歳を こえる 選手・引退が うわさの 選手**は 入れない(1年で 変わる)
- ❌ 選手の ケガ・不調・私生活・SNS・発言・**賭け・薬物・事件に かかわった 選手**は 入れない(2025年に 賭けの 事件で 名前が 出た 投手など)

### 3. ⭐⭐ ルールは 3つの 立場が ある(`ruleset` の 札)
- **NPB**(日本の プロ野球。公認野球規則 + NPB の 決まり)・**MLB**・**高校**(日本高野連の 決まり)。どれにも 同じなら **共通**
- ルールの 語には **`ruleset` の 欄**を 付ける(「NPB・MLB」の ように「・」で 3つまで)。**説明にも どの 立場の 話か 書く**(書いて いない 説明は まちがいに なる)
- ⚠️ **DH・ピッチクロック・タイブレーク・延長・申告敬遠・ベースの 大きさ・牽制の 制限・ABS(自動判定)・投球数制限・低反発バット** は **ここ数年で よく 変わった**。
  事実は `tools/baseball/exam.txt` の ① に 合わせる。そこに 無い 細かい 数字は 書かない
- 規則の 番号(「5.09」「第◯条」)は 書かない(台本が 止める)。名前で
- 迷う 細かい ところ(例外の 例外)は 書かない。**少年野球の コーチ・審判講習で 習う ところ**を 中心に

### 4. 実在の 選手・チーム・リーグ・大会の 名前は 入れて よい(事実として)
- ✅ 名前は よい。❌ **グラブ・バット・シューズの 商品名・メーカー名・スポンサー名**は 書かない
- 球場の 名前に **会社名(命名権)**が 入る ものは 書かない。「◯◯の 本拠地の 球場」「◯◯ドーム」まで、か もとの よび名で(`exam.txt` ⑨)
- カタカナは **日本の 新聞・NPB で よく 使う 書きかた**に そろえる(ニューヨーク・ヤンキース・ロサンゼルス・ドジャース・ベーブ・ルース・ジャッキー・ロビンソン)
- ⭐ 野球は **漢字と カタカナの 両方が ある** ことばが 多い(四球 / フォアボール・本塁打 / ホームラン・投手 / ピッチャー・併殺 / ダブルプレー)。
  **答え(name / reading)は 1つに 決めて、もう片方の 読みは `acceptedReadings` で 受ける**(フリックで 打てない ことが 無いように)

### 5. 人を けなさない・悲しい 場面を 入れない
- 「ダメな 選手」「負けた チーム」の 書きかたを しない。**エラーで 負けた・サヨナラ負け・押し出しで 負けた** など 人が 悲しんだ 場面は 入れない(名場面は **いい ほう** だけ)
- ⚠️ **高校野球は 子ども・学生**。負けた 学校の 話・名前を 書かない(優勝した 話も 学校名は 書かなくて よい)
- ❌ ビーンボール・乱闘・死球で ケガを する ようす・八百長(黒い霧事件)・賭け・薬物(ステロイド)・差別の 事件・ケガ・死・事故・私生活・スキャンダルは 入れない(台本が 止める)
- ⭐ **ジャッキー・ロビンソン**は「**壁を こえた 前向きな 話**」として(「はじめての アフリカ系 アメリカ人の メジャーリーガー」「4月15日は 全員が 背番号42」)。「差別」「人種」の 字は 使わない
- 亡くなった 名選手も 入れて よいが「亡くなった」とは 書かない(功績で 書く)。⚠️ **ルー・ゲーリッグを 病気の 名前と むすびつけない**(「鉄の 馬」「連続出場」で)。⚠️ 沢村栄治・ロベルト・クレメンテも 亡くなった いきさつを 書かない
- ❌ **バリー・ボンズ・ピート・ローズ・ロジャー・クレメンス・アレックス・ロドリゲス・サミー・ソーサ・マーク・マグワイア**など 薬物・賭けで 知られる 人は **入れない**

### 6. ラフプレー・ずるい 技を すすめない
- ボーク・守備妨害・走塁妨害・打撃妨害は **反則の 名前として**。❌ **隠し球・サイン盗み**は 入れない
- ⭐ **技は「練習で 身に つける 技」として**
- ⚠️ **技の 名前の もとは 説が 分かれる ものが 多い**。「◯◯が はじめた」と 言いきらず「◯◯の 得意技として 有名」「◯◯が 広めた」まで
  (例: 一本足打法 = 王貞治の 打ちかたとして 有名 / トルネード投法 = 野茂英雄 / 振り子打法 = イチロー / スイーパー = 2020年代に MLB で 広まった よび名)

### 7. デッドボール(死球)は **名前と ルールだけ**
- 「投球が 打者の からだに 当たると、打者は 一塁へ 進める」まで。ぶつかる ようす・痛み・ケガは 書かない
- 台本は「死」「殺」を 止めるが、**死球・無死・一死・二死・併殺・刺殺・補殺・封殺・挟殺・盗塁死・憤死・下手投げ**は 通す(野球の ことば)

### 8. 事実を 正しく(⭐ かならず 確かめる)
- **選手と 国・技と 使い手・年と 大会・球団と 町・ライバルの 組み合わせ・ルールの 立場**は 1語ずつ web で 確かめる(記憶で 書かない)
- 大会・賞・ルールの 事実は `tools/baseball/exam.txt` に 合わせる。そこに 無い 年・大会を 書くときは web で 確かめてから
- 事実が あやしい 語は 入れない。**自分の ことばで 書く**(Wikipedia・公式の 文を 写さない)

### 9. ほかの ゲームと 同じ 語は よい(説明は 野球の 目線)
- ワールドサッカーと かさなる 語(アシスト(野球では 守備の 補殺)・ダブルプレー・MVP・キャプテン など)は **野球での 意味**で 書く

## 1語の 形(JSON)

```json
{"id":"wz-sweeper","name":"スイーパー","reading":"すいーぱー","journey":"waza","category":"曲がる 球","difficulty":2,
 "field":"投手の技","type":"concept","emoji":"🧹","mapNode":"waza:breaking","relatedTerms":["wz-slider"],"country":"アメリカ",
 "description":"横に 大きく すべるように 曲がる 変化球です。スライダーの なかまで、ほうきで はく ように 曲がる ことから この 名前が つきました。2020年代の MLB で 広まった よび名です。"}
```
```json
{"id":"rl-pitchclock","name":"ピッチクロック","reading":"ぴっちくろっく","journey":"rule","category":"新しい ルール","difficulty":2,
 "field":"ルール","type":"concept","emoji":"⏲️","mapNode":"rule:modern","relatedTerms":["rl-disengage"],"country":"アメリカ","ruleset":"MLB",
 "description":"投手が ボールを 受けてから 投げるまでの 時間を 時計で はかる MLB の ルールです。2023年に はじまり、試合の 時間が 短く なりました。(…秒数は exam.txt に 合わせる)"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(日本の 新聞・NPB で ふつうに 使う 書きかた)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)
  - カタカナ語は ひらがなで(ナックルボール → なっくるぼーる)。「・」は 取る(ベーブ・ルース → べーぶるーす)
  - 英字の 名前は 読みで(WBC → だぶりゅーびーしー / OPS → おーぴーえす / DH → でぃーえいち)
  - ゆれる ことばは いちばん ふつうの 読みを reading に、ほかを `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は 上級だけ・旅で 1〜2語まで
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級(下の「3段の 分けかた」)
- **field**: 学ぶ 分野。次の 7つの どれか: `ルール` / `投手の技` / `打撃・守備・走塁の技` / `戦術` / `リーグ・チーム` / `選手` / `大会・歴史`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(🩸 💀 ☠️ 🔪 🤕 🚑 😭 😱 💢 は 使わない。⚾ ばかりに しない。国旗の 絵文字は 使わない(札で 出る ため))
- **country**(**関係が あれば 付ける**): その 選手・チーム・技・大会・リーグが どの 国の 話か。
  `世界` `北アメリカ` `中南米` `アジア` `ヨーロッパ` `オセアニア` `日本` `アメリカ` `カナダ` `メキシコ` `ドミニカ共和国` `ベネズエラ` `キューバ` `プエルトリコ`
  `パナマ` `コロンビア` `ニカラグア` `キュラソー` `韓国` `台湾` `中国` `オーストラリア` `オランダ` `イタリア` `イギリス` `チェコ` `イスラエル` の どれか。
  2〜3つなら「・」で(`"アメリカ・カナダ"`)。選手は **代表の 国**(⚠️ プエルトリコは 野球では アメリカと 別の 代表 = へえ)。きほんの ことばなど 国と 関係ない 語は 付けない
- **ruleset**(**ルールの 語だけ**。`rule` の 旅は ほぼ ぜんぶ・ほかの 旅でも ルールに かかわる 語は 付けて よい): `NPB` `MLB` `高校` `共通` の どれか(「・」で 3つまで)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / どんな 特徴か / へえ」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  文体は **はじめから「〜です・ます」**(体言止めで はじめない)。「1人」「2人」は ふりがなが 読みまちがえるので **ひとり・ふたり** に 言いかえる
- **example**: なくてもよい
- 「へえ」を 1文 入れると よい(「甲子園球場は 1924年 = 甲子(きのえね)の 年に できたので この 名前」「プエルトリコは WBC では アメリカと 別の 代表」)

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | **野球が すきな 小学生**。ポジション・きほんの ルール・だれでも 知っている 選手と 球種と 大会の 名前 |
| 2 | 中級 | **少年野球の コーチ・野球が すきな 大人**。公認野球規則の きほん・リーグと チーム・技の 中身・NPB と MLB の ちがい |
| 3 | 上級 | **解説者**。作戦の ことば・セイバーメトリクス・名監督・大会の 歴史・ルールの 細かい ところ |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる
(ならんだ 順が そのまま ステージの 順に なる)。

## ぜったいに 守ること

- **自分の ことばで 書く**。Wikipedia・公式の 文を 写さない
- **お金・年齢・いまの 選手の 通算記録・いまの 順位は 書かない**。年と 大会・優勝回数・人数・引退した 選手の 記録は よい。事実は `tools/baseball/exam.txt` と web で 確かめる
- 「100マス計算」「百ます計算」の 字を 使わない

## 出すもの

`tools/baseball/terms-<旅id>.json` に JSON の 配列(70語)で 書く。書いたら
`python3 tools/baseball/terms_js.py --only <旅id>` で 形を 確かめる(まちがいが あれば 止まる)。
