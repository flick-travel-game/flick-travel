# フリック衛生管理者: 🔢 数字クイズの 作りかた

衛生管理者は **数字が 合否を 分ける**(人数・日数・期間・濃度・ルクス・℃・%・保存年数・からだの 数値)。数字を 4つから えらぶ クイズ。**約220問**。旅ごとの `tools/eisei/num-<旅>.json` に 配列で(id は 旅の 中で n001 から)。

## 決まり
1. **facts-A/B/C.md に ある 数字だけ**。条文・公式の 資料で 確かめた もの。合格率・統計は 入れない
2. 正解 1つ + まちがい 3つ。まちがいは **試験で まぎらわしい 数字**(50人 → 30人・100人・300人 / 毎週 1回 ↔ 毎月 1回 ↔ 2か月に 1回 / 6月以内ごと ↔ 1年以内ごと / 3年 ↔ 5年 ↔ 30年 / 10立方メートル ↔ 8 ↔ 15 / 300ルクス ↔ 150 ↔ 70 / 18% ↔ 16% ↔ 20% / 80時間 ↔ 45 ↔ 100)。同じ 単位で そろえる
3. 問い(`q`): 70字 以内。「〜は 何人以上?」「〜は 何か月以内ごと?」の ように 答えが 数字に なる 形。主語と 条件を はっきり(常時 50人以上・事務所則・空気調和設備を 使う 部屋 など)
4. `why`: 90字 以内・やさしい です・ます。`law`: 法令名 + 条(労働衛生・労働生理は 資料名でも 空でも よい)
5. `j`: どの 旅か(taisei … seiri2)。`rs`: 科目(MARU.md と 同じ)
6. 同じ 数字を 2回 聞かない

## 形
{"id":"n001","j":"taisei","rs":"関係法令(有害以外)","q":"衛生管理者を 選任しなければ ならないのは、常時 何人以上の 労働者を 使う 事業場?","a":"50人","opts":["10人","30人","50人","100人"],"why":"常時 50人以上の 事業場で 選任します(10〜49人は 衛生推進者)。","law":"安衛令4条"}
- opts の 中に a が かならず 1つ・4つ ぜんぶ ちがう
