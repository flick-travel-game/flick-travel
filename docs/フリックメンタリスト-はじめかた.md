# フリックメンタリスト(`mentalist/`)を 作る ための まとめ(2026-10-23。新しい セッション用)

けいくん 2026-10-23「新しいセッションで フリックメンタリストを作成したい。**世界トップレベルのメンタリスト**になるために必要な知識をフリック形式の問題にしてください」

⭐ いちばん 近い 兄弟は **フリック心理学(`shinri/`。`docs/フリック心理学-はじめかた.md`)**(こころの しくみ・決めつけない・診断の 道具に しない)と **フリックアドラー心理学(`adler/`)**。
人前の ふるまいは **フリックマナー(`manner/`)**、考えの 立場が ならぶ 書きかたは **フリック哲学(`tetsugaku/`)**、4択クイズ・計算問題の 型は **フリックパイロット(`pilot/`)/ キャビンアテンダント(`cabin/`)** と かさなる。
⚠️ ほかの ゲームと ちがう 4つの 気をつけ:
① ⭐⭐⭐ **メンタリストは「超能力者」では ない**。**心理学・観察・記憶・話しかたを つかって、こころを 読んだ ように 見せる 芸(パフォーマンス)**。この ゲームでは **「本当に こころが 読める」「未来が 見える」とは 1度も 書かない**。「〜のように 見せる」「〜と 感じさせる」の 向きで 書く
② ⭐⭐⭐ **人を あやつる 道具に しない**。「相手に 気づかれずに 買わせる」「うそを 見ぬいて 追いつめる」の ような 書きかたを しない。ことばは **「おどろかせて 楽しませる」「相手を よく 見て 大切に する」**の 向きで。**同意(いやなら やめる)**を いちばん大事な ことばに する
③ ⭐⭐ **トリックの 中身(しかけ)は 書かない**。マジシャンの 世界の 決まり(たねを 明かさない)を 守る。書くのは **「こういう 現象(効果)が ある」「こういう 心理の しくみが はたらいている」「こういう ことばで 呼ぶ」**まで。⭐ **けいくんにも はじめに 伝える**: 「たねあかしの ゲームには しません。ことばと 心理の しくみを おぼえる ゲームです」
④ ⭐ **「体の 動きで うそが 分かる」と 書かない**。腕組み・目の 動きで うそを 見ぬける、は **科学では たしかめられていない**(心理学の 研究では 当たる 率は ほぼ 半分)。「よく 言われるが 科学では 支持されていない」と **はっきり 書く**。心理学ゲームの「科学か どうかを 分ける」と 同じ

## 3. ⚠️⚠️⚠️ ぜったいの 決まり(心理学・哲学と 同じ + この ゲームだけの もの)
- ⭐⭐⭐ **「本物の 超能力」とは 書かない**。「こころを 読む **芸**」「読んだ **ように 見せる**」。画面の いちばん下に 1行「メンタリズムは 心理学と 観察を つかった パフォーマンスです。本当に こころが 読める わけでは ありません」
- ⭐⭐⭐ **たねを 明かさない**(マジシャンの 世界の 決まり。⚠️ 子どもが 友だちに 使って トラブルに なるのも 防ぐ)。語に 書くのは **現象の 名前・心理の しくみ・歴史**まで。`butai` の 欄に 手順を 書かない。**別の 助手が 1語ずつ「これは たねあかしに なっていないか」を 見る**
- ⭐⭐ **人を あやつる 向きに しない**。ことばの 旅(`kotoba`)は とくに 気をつける。「〜させる」「〜に 気づかれずに」を `BAN` で 止める。書くのは「〜と 感じやすい」「〜を 大切に する」
- ⭐⭐ **「うそが 分かる」と 書かない**(上の ④)。しぐさの 語は「よく 言われる」+「科学では 支持されていない」を セットで
- ⭐ **同意が いちばん**。どの 旅にも「やってもいい?」「いやなら やめる」が 出てくる ように。倫理の 旅(`kokoro`)は **けいくんに 見せる 1番目の 旅**に する
- ⭐ **実在の 人は 事実だけ**(サッカーと 同じ)。**いま 活動している 日本の 人は 出さない**。海外の 人も「〜と 公言している」「〜年に 〜した」の 形で。しかけ・私生活・論争・訴訟は 書かない
- **心理学ゲームと 同じ 線**: 心の 病気の 名前を 出さない / 科学で たしかめられた ことと 言い伝えを 分ける / 自分や 友だちを 診断する 道具に しない
- ✅ **心理学・アドラー・マナーと 同じ 語を 入れて よい**。説明は **メンタリストの 目線**で 書きなおす
- **読みは この ゲームの 9つの 旅の 中では かぶらない**(`terms_js.py`)。**先に 9つの 旅の 語の 一覧を 1人の 助手に 作らせて** 置き場所を 決める(`shinri` と `kotoba`(暗示・同調)、`kansatsu` と `kokoro`(コールドリーディング)、`suuji` と 🧮 計算問題 が かさなりやすい)
- **カタカナ語を ならべない**。**ふつうの 言葉で 言いかえて から** 芸の 名前(「ミスディレクション = 注意を 別の ところへ 向ける こと」)
- **別の 助手が 1語ずつ 確かめる**(意味・読み・つづり・**たねあかしに なっていないか**・**超能力と 読めないか**・**あやつる 向きに なっていないか**・人名の 事実)。計算問題は **1しゅるいずつ 手で 答えを 確かめる**

## 4. 事実は **その日に 確かめてから** 書く
`meta.json` の `note` に 確かめた 日を つける。**記憶で 書かない**:
・メンタリストに **国家資格は 無い**(芸の 世界。確かめる)。「世界トップレベル」= **6つの 力の ことばを ひととおり 知っていて、こころの 決まりを 守れる** こと、と けいくんに 伝える。**人前で 演じる 力は ゲームの 外で**(ゲームは その 土台)
・歴史の 人物の 生まれた 年・国・代表的な 活動(⚠️ 「〜が はじめた」は 説が 分かれるので「〜で 知られる」まで)
・心理学の 効果の 名前と 由来(心理学ゲームの `tools/shinri/` の 語と そろえる。**同じ 効果を ちがう 説明で 書かない**)
・記憶力 選手権などの 事実(大会の 名前・種目。⚠️ 記録の 数字は 変わるので 書かない)
