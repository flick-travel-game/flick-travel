# フリック救急隊員: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
試験の 科目・しくみ図の どこに あるか(📍)が 出る。あそぶのは **小学生〜救急隊員・救急救命士を めざす 中高生・学生・大人**。
**救急の ことばと 意味を おぼえる ゲーム**(試験の 問題集でも、救命の 手引きでも ない)。
もとは `tools/shobo/PROMPT.md`(消防士)に、`tools/ishi/PROMPT.md`(医師)・`tools/kango/PROMPT.md`(看護師)の「やりかた・薬の 量を 書かない」を 足した もの。
けいくん 2026-10-03「救急隊員の専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」。
重い ことば(心肺停止・大量出血・多数傷病者)は「事実だけ おだやかに 入れる」。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 4つ

### 1. 手当て・処置の やりかたを 書かない(いちばん 大事。命の ことばは なおさら)
- ❌ **書かない**: 胸骨圧迫の 深さ・回数・速さ / 人工呼吸の 回数 / 止血の しかた / AED の パッドの 貼りかた・手順 /
  気道確保の 手の 置きかた / 特定行為の 手順 / **薬の 量・使いかた**(mg・mL・何回) / 診断の しかた(「こういう ようすなら ◯◯病」) /
  **正常値・ものさしの 数字**(脈拍は いくつ・血圧は いくつ・SpO2 は 何%・JCS の 点の 中身 など) / 「こういう ときは こうする」の 指図
- ⭕ **書く**: その ことばが **何を さすか**・**何の ための 手当て・しくみか**・**救急隊員は 現場で どう 見て、手当てし、病院へ つなぐか**
  - 例: 胸骨圧迫 = 心臓が 止まった 人の 胸を 押して、からだに 血を めぐらせる ための 手当て。やりかたは 消防署の 救命講習で 習います
  - 例: JCS = 意識の ようすを 決まった ものさしで あらわす しかた。救急隊は これで 病院に 意識の ようすを 伝えます
  - 例: アドレナリン = 救急救命士が 医師の 指示を 受けて 使う ことが ある 薬の 名前(**ここまで。量・使う 場面は 書かない**)
- 手当ての 説明の さいごは「やりかたは 救命講習で 習います」「くわしくは 救命講習で」と そえて よい(ゲームで 覚えさせない)
- **数字は なるべく 出さない**。法律・制度で 決まっていて まちがいない もの(119番・#7119・救急の日 9月9日・救急救命士法 1991年)だけ

### 2. 小学生も あそぶ(こわく しない)
- ❌ 大けが・出血の ようす・事故の 現場の ようす・亡くなる 場面・苦しむ ようす・「この 病気に なると こうなる」を 書かない
- 病気・けがは **「何が 起きている 状態か」+「救急隊が 見つけて 病院へ つなぐ」** だけ
- 重い ことばは **事実だけ おだやかに**(けいくん決定):
  心肺停止 =「心臓と 呼吸が 止まった 状態。すぐに 胸骨圧迫と AED で 命を つなぎます」/
  大量出血 → 名前は「出血」「止血」で。「たくさんの 血が 出る ようす」は 書かない /
  多数傷病者 =「けがを した 人や 病気の 人が 一度に 大ぜい いる 事故や 災害。トリアージで 順番を 決めて 助けます」
- 「死亡」「死ぬ」「亡くなる」「遺体」「血まみれ」「殺」「自殺」「虐待」「脳死」は 使わない(台本が 止める)。殺菌 → 消毒・除菌 と 書く
- **こわさより「助けかたを 知っている 安心」**を まん中に。読んだ 子が **「助けて くれる 人が いる」「こまったら 119番・#7119」** と 思える 書きかた
- **実在の 事故・事件・病院・消防本部・人の 名前は 入れない**(歴史上の 人・できごとは 確かめた もの だけ。国・役所の 名前は よい)
- **行動の 指示**(「◯◯すれば 防げます」「こまめに 水を 飲みましょう」)は 書かない(医師の 監査 2026-10-01 と 同じ)
- 絵文字は 💀 ☠️ 🩸 💉 🔪 など こわい ものを 使わない
- **迷ったら その 語を 入れない**

### 3. 法律・資格の 事実は `tools/kyukyutai/exam.txt` に 合わせる(2026年10月2日に 厚生労働省・消防庁の ページで 確かめた)
- 救急隊員 = 消防職員で、**救急業務に関する講習**(消防学校の **救急科**。標準 250時間)を 終えた 人。救急隊は ふつう 3人で 1隊
- 救急救命士 = **国家資格**(救急救命士法 1991年。厚生労働大臣の 免許)。**医師の 指示の もとで** 救急救命処置を 行う。国家試験は 年1回・3月
- 特定行為 = 救急救命士が **医師の 具体的な 指示を 受けて** 行う 処置(器具を 用いた 気道確保・静脈路確保と 輸液・アドレナリンの 投与・ブドウ糖の 投与 など。血糖測定は 特定行為では ない)。**名前と「医師の 指示が いる 処置」まで**
- メディカルコントロール = 医師が 救急隊の 活動の 質を 支える しくみ(指示・指導・助言 / 事後検証 / 教育)
- 救急の日 = 9月9日、救急医療週間 = その 日を ふくむ 1週間。#7119 は「多くの 地域で」と 書く(地域で ちがう)
- 法律は **名前と 目的だけ**。条文を 写さない・罰を 書かない。数字・年は **まちがいない ときだけ**

### 4. 救急隊員の 目線で 書く(消防士・医師・看護師・からだ旅行と 同じ 語を 入れて よい)
- ✅ **ほかの ゲームと 同じ ことばを 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)
- ⚠️ ただし 説明は **救急隊員の 目線**(現場で 見て・手当てし・病院へ つなぐ)で 書きなおす。ほかの ゲームの 文を 写さない。
  例: AED … 消防士「駅や 学校に 置いて ある」/ 救急隊員「救急隊が 着く 前に まわりの 人が 使えば、命が つながる 見こみが 高まる 機械。救急隊は 着いたら 自分たちの 機械に つなぎかえます」
- **読み(ひらがな)は 救急隊員の 7つの 旅の 中で かぶらない**(台本が 止める)。下の「旅ごとに 入れる / 入れない」を 守る

## 1語の 形(JSON)

```json
{"id":"kh-kyukyutai","name":"救急隊","reading":"きゅうきゅうたい","journey":"kihon","category":"救急の人","difficulty":1,
 "field":"臨床救急医学総論","type":"concept","emoji":"🚑","mapNode":"nagare:shutsudo","relatedTerms":["kh-kyukyusha"],
 "description":"119番の 知らせを 受けて 救急車で かけつける チーム。ふつう 救急隊員 3人で 1つの 隊を つくり、現場で 手当てを して 病院へ 運びます。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(救急の 現場で ふつうに 使う 言いかた。漢字・カタカナ・英字の 略語・数字 119番 など)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)
  - 数字は ひらがな(119番 → ひゃくじゅうきゅうばん / 二次救急 → にじきゅうきゅう / #7119 は 名前を「救急安心センター事業」に)
  - 英字の 略語は 読みかた(AED → えーいーでぃー / SpO2 → えすぴーおーつー / JCS → じぇーしーえす / GCS → じーしーえす / CPA → しーぴーえー)
  - ゆれる ことばは 1つに 決め、別の 読みは `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は **上級だけ**、旅で 1〜2語まで(長い 名前は 短い 呼び名に。説明に 正式な 名前)
  - ⚠️ **読みを まちがえやすい ことば**(傷病者 しょうびょうしゃ・搬送 はんそう・頸椎 けいつい・嚥下 えんげ・誤嚥 ごえん・喘息 ぜんそく・
    梗塞 こうそく・瞳孔 どうこう・脈拍 みゃくはく・痙攣 けいれん・熱傷 ねっしょう・溺水 できすい・吐血 とけつ・喀血 かっけつ・
    心肺蘇生 しんぱいそせい・胸骨圧迫 きょうこつあっぱく・除細動 じょさいどう・気道確保 きどうかくほ・吸引 きゅういん・
    口頭指導 こうとうしどう・聴取 ちょうしゅ・転院搬送 てんいんはんそう・特定行為 とくていこうい・事後検証 じごけんしょう)は **1語ずつ 確かめる**
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級(下の「3段の 分けかた」)
- **field**: 救急救命士 国家試験の 5科目の どれか(入門の 語でも いちばん 近い ものを 書く):
  `基礎医学` `臨床救急医学総論` `臓器器官別臨床医学` `病態別臨床医学` `特殊病態別臨床医学`
  - めやす: からだの しくみ・社会保障・患者搬送(運ぶ ことの きほん)→ `基礎医学` /
    救急医療体制・救急隊・観察・処置の 名前・資器材・法律・メディカルコントロール・感染対策 → `臨床救急医学総論` /
    脳・心臓・肺・おなか など からだの 場所ごとの 病気(脳卒中・心筋梗塞・ぜんそく)→ `臓器器官別臨床医学` /
    心肺停止・ショック・意識の 障害・けいれん・外傷(けが・骨折)など 状態ごと → `病態別臨床医学` /
    子ども・高齢の 人・妊娠と 出産・熱中症・低体温症・溺水・中毒・やけど・アナフィラキシー・こころの 病気 → `特殊病態別臨床医学`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  専門用語を 専門用語だけで 説明しない。「1人」「2人」は ふりがなが 読みまちがえるので **ひとり・ふたり** と ひらがなで 書く
- **example**: なくてもよい

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | くらしや ニュースで 聞く 救急の ことば・学校の 救命講習の ことば(119番・救急車・AED・熱中症・やけど) |
| 2 | 中級 | **消防学校の 救急課程(救急隊員の 資格)の 範囲の めやす**(観察の ことば・資器材の 名前・病気の 名前・搬送の しくみ) |
| 3 | 上級 | **救急救命士 国家試験の 範囲の めやす**(観察の 指標の 名前・病態の 名前・特定行為・メディカルコントロール・法律) |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる
(ならんだ 順が そのまま ステージの 順に なる)。

## ぜったいに 守ること

- **自分の ことばで 書く**。過去問・問題集・教科書・Wikipedia の 文を 写さない
- **実在の 病院・消防本部・事故・人物・会社・商品(薬の 商品名)の 名前**は 使わない(厚生労働省・消防庁 など **役所の 名前は よい**)
- **数字は まちがいない ときだけ**
- 画面には「これは ことばを おぼえる ゲームです。本物の 試験問題では ありません。手当ての やりかたは 消防署の 救命講習で 習おう。からだの ぐあいが わるい ときは おうちの 人に 知らせて、こまったら 119番や #7119 に 相談してください」が 出る
- 「100マス計算」「百ます計算」の 字を 使わない
