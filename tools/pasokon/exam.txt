パソコンに 国家資格は ありません。「お店の パソコン担当の 店員さん」や「パソコンの 専門家」に なる おもな 道は 次の とおりです。①アップルの 公式の トレーニング(Apple Training): 講座「Apple Device Support」(機器の 相談に こたえる 人むけ。受かると「Apple Certified Support Professional」の 認定)と「Apple Deployment and Management」(機器を まとめて 導入・管理する IT の 人むけ。受かると「Apple Certified IT Professional」)。講座は 無料で オンライン・試験は 有料(この ゲームの 上級の めやすの 中心)。②家電製品アドバイザー(家電製品協会): お店で 家電を 説明する 人の 資格。科目は「AV情報家電」「生活家電」「CSと関連法規」で、AV情報家電の 範囲に パソコン・プリンター・スマートフォン・インターネットが 入る。CBT方式で 年2回の 受験期間。両方 受かると「家電製品総合アドバイザー」。③ITパスポート試験(IPA が 行う 国家試験): CBT方式で 随時・100問・120分・4つから えらぶ 形。ストラテジ系・マネジメント系・テクノロジ系の 3分野で、テクノロジ系に ハードウェア・ソフトウェア・ネットワーク・セキュリティが 入る。④高校の「情報Ⅰ」: 2022年度の 入学生から 必ず 学ぶ 科目に なり、2025年1月の 大学入学共通テストから「情報」が 加わった。⑤P検(ICTプロフィシエンシー検定)は 2025年7月に 高校生が 学校で 受ける 形に 変わった。⑥歴史: 1946年 ENIAC の 公開 / 1968年 エンゲルバートが マウスと 画面の 操作を 見せた 発表 / 1984年1月 アップルが Macintosh を 発表 / 1985年 Windows の はじめての 版・東芝 T1100(持ち歩ける パソコンの はじまりの 一つ)/ 1995年 Windows 95 / 2005年 アップルが インテルの チップへの 切りかえを 発表(2006年から)/ 2020年 アップルが 自社の チップへの 切りかえを 発表。⚠️ 試験の 中身・名前は 変わる ことが ある。この ゲームの「専門家に なれる レベル」は、アップルの サポートの 認定と 家電製品アドバイザーの パソコンの 範囲の ことばを ひととおり 知っていて、お客さんに たとえで 説明できる こと の めやす。⭐ 本当の 接客の 力は 人と 話して 身に つく。ゲームで つくのは その ための 知識と 説明の ことばの 土台。ショートカットは アップルの「Macのキーボードショートカット」「Macでスクリーンショットを撮る」「Macの日本語変換用のキーボードショートカット」の ページで 確かめた。Apple Training・家電製品協会 認定センター・IPA・大学入試センター / 文部科学省・Computer History Museum・Apple Newsroom・情報処理学会 コンピュータ博物館 の ページで 2026年10月3日に 確かめた
