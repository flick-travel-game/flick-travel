# フリックワールドベースボール(`baseball/`)を 作る ための まとめ(2026-10-10。新しい セッション用)

けいくん 2026-10-10「新しいセッションで フリックワールドベースボールを作成したい。**ワールドベースボールの専門家(解説者)になれるレベル**になるために必要な 知識、**主要な野球リーグ、有名野球選手、有名な技、ルール**をフリック形式の問題にしてください」

⭐ **フリックワールドサッカー(`soccer/`)・フリックワールドバスケットボール(`basket/`)と 兄弟の ゲーム**。まとめの 型・決まりは `docs/フリックワールドサッカー-はじめかた.md` と `docs/フリックワールドバスケットボール-はじめかた.md` と **ほぼ 同じ**。ちがう ところ(ルールが 日本と アメリカで ちがう・球種・高校野球)だけ 気を つける。

## 3. ⚠️⚠️⚠️ ぜったいの 決まり(サッカー・バスケと 同じ)
- ⭐⭐ **数字が 変わる ものを 書かない**(この ゲームで いちばん 事故が 起きやすい):
  - ❌ いまの 所属チーム(**移籍・トレード・ポスティングで 変わる**)・年俸・契約金・いまの 順位・**通算記録**(いまの 選手)・いまの 打率 / 防御率・いまの 監督
  - ✅ **変わらない 事実は よい**: 国籍(代表)・ポジション・**得意な 球種 / 打ちかた / プレーの 特徴**・**過去の 受賞と その 年**(「◯◯年の MVP」)・**WBC / オリンピックの 優勝の 年と 国**・**引退した 選手の 所属の 歴史と 記録**(王貞治の 868本 など)
- ⚠️⚠️ **いまの 選手の 書きかた**(`star` の 旅): 「**◯◯代表の 投手。速い ストレートと スプリットが 武器**」の ように **国・ポジション・プレーの 特徴**で 書く。**チーム名を 答えの 手がかりに しない**。
  答えに した 選手は `meta.json` に **確かめた 日**を つけて、**1年に 1回 見なおす**(引退・代表の 変更が あるため)
- ⭐ **ルールは 3つの 立場が ある**: **NPB**(日本の プロ野球。「公認野球規則」+ NPB の 決まり)・**MLB**・**高校野球**(日本高野連の 決まり)。**どちらの 話か 説明に かならず 書く**。⚠️ **DH・ピッチクロック・タイブレーク・延長・申告敬遠・ベースの 大きさ・牽制の 制限**は **ここ数年で よく 変わった**。かならず **その年の 版を 確かめて から**。`meta.json` に 「公認野球規則 ◯年版 / MLB ◯年度 / 高野連 ◯年度で 確かめた」と 書く
- ✅ **実在の 選手・チーム・リーグ・大会の 名前は 入れて よい**(事実として。サッカー・バスケと 同じ)。
  ❌ ただし **絵には 描かない**(実在の 選手の 顔・球団の ロゴ・ユニフォーム・スポンサー・大会の ロゴ)。**商品名**(グラブ・バット・シューズの 名前など)は 説明にも 入れない
- **人を けなさない**: 「ダメな 選手」「負けた チーム」の 書きかたを しない。**エラー・サヨナラ負け・押し出し**など **人が 悲しんだ 場面は 入れない**(名場面は **いい ほう** だけ)。⚠️ **高校野球は 子ども・学生**なので なおさら(負けた 学校の 話を 書かない)
- **ラフプレー・ずるい 技を すすめない**: ボーク・守備妨害・走塁妨害は **反則の 名前として**。隠し球・サイン盗みは 入れない
- **技は 「練習で 身に つける 技」として**

- ✅ **ほかの ゲーム(世界旅行の 国・歴史の 人物・英語・フリックワールドサッカー / バスケットボール など)と 同じ 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。説明は **野球の 目線**で
