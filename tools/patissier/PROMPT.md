# パティシエフリック: ことばの 作りかた(助手に 分けて 頼むときの 決まり)

ゲームは「表示された ひらがなを フリックで 打ち写す」タイピング。打ち終わると ことばの 説明(1〜3文)と、しくみ図の どこに あるか(📍)が 出る。
遊ぶのは 小学生〜パティシエを めざす 学生・大人。**お菓子の ことばと しくみを おぼえる ゲーム**。

## 1語の 形(JSON)
{"id":"za-hakurikiko","name":"薄力粉","reading":"はくりきこ","journey":"zairyo","category":"小麦粉・粉","difficulty":1,
 "type":"concept","emoji":"🌾","mapNode":"pantry:flour","relatedTerms":["za-kyorikiko"],
 "description":"たんぱく質が 少なめの 小麦粉です。ねばりが 出にくいので、ふんわり した スポンジや さくっと した クッキーに 向いています。"}

- id: 旅の 頭文字 + "-" + 英小文字(za- / ki- / cr- / se- / wa- / do-)。英小文字・数字・- だけ
- name: 画面に 出す 名前(カタカナ・漢字。お菓子の 現場の ふつうの 言いかた)
- reading: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)。
  カタカナ語・フランス語は ひらがなに(ぱーとしゅくれ)。数字は ひらがな(3つ → みっつ)。
  ゆれる ことばは 1つに 決め、別の 読みは "acceptedReadings":["よみ1","よみ2"](先頭は reading と 同じ)。例: ぱーたしゅー / ぱーとあしゅー
- difficulty:
  - 1 = 入門(身近・小学生でも 聞いたことが ある)
  - 2 = **製菓衛生師の 試験範囲の めやす**(衛生法規・公衆衛生学・食品学・食品衛生学・栄養学・製菓理論)
  - 3 = **菓子製造技能士 2級の 試験範囲の めやす**(菓子一般・菓子製造・材料・製法・包装保存)
  - 4 = **菓子製造技能士 1級の 試験範囲の めやす**(高度な 製法・材料の 科学・品質管理・製造計画・官能検査・デザイン・工芸菓子)
  - ⚠️ 菓子製造技能士には **3級は ない**(1級・2級だけ。2026-09-27 に 中央職業能力開発協会の ページで 確かめた)
- **旅ごとに 80語: difficulty 1 を 20語、2 を 20語、3 を 20語、4 を 20語**。同じ difficulty の 中は 有名な 順
- type: いつも "concept"
- category: 図鑑で しぼる 分類(短い 日本語。旅の 中で 4〜8種類)
- emoji: 1つ
- mapNode: 下の しくみ図の 場所(その 旅の 図から えらぶ。"図:場所" の 形)
- relatedTerms: **同じ ファイルの 中の** id を 1〜3個(自分は ダメ)。いっしょに おぼえると よい ことば
- description: 1〜3文・**130字以内**。やさしい です・ます。「何か / どう 使うか・どこが 大事か」。
  語と 語の あいだに 半角スペースを 入れる 書きかた(この シリーズの 文体。上の 例のように)。
  専門用語を 専門用語だけで 説明しない
- example: なくてもよい

## ぜったいに 守ること
- **自分の ことばで 書く**。過去問・問題集・教科書・レシピ本・Wikipedia の 文を 写さない
- **レシピ(分量・温度・時間)は 書かない**。「〜度で 〜分 焼く」「砂糖 〜g」は ダメ。
  ただし しくみの 数字で まちがいない もの(例: 卵白は 約90%が 水分 / チョコの テンパリングで 温度を 上げ下げ する こと)は 数字を 出さずに 書く。**温度の 数字は 書かない**
- 火・油・刃物・あめの 高温が からむ ことばは「熱くて 危ないので おとなと いっしょに」と 1言 そえてよい(毎回 書かなくて よい)
- **お店・メーカー・商品・ブランドの 名前は 使わない**(商標)。お菓子の 一般的な 名前(マカロン・ザッハトルテ・カステラ など)は よい
- 「食べると 体に よい」「やせる」「病気が 治る」など 健康の 言いきりを しない
- 国・由来・年・人の 名前は **まちがいない ときだけ**。説が いくつも ある ものは「〜と 言われます」「説が あります」。あやしい 語は 入れない
- アレルギー表示の 数・品目は 2026年9月の 決まり: 特定原材料(表示の 義務)9品目 = えび・かに・くるみ・小麦・そば・卵・乳・落花生・カシューナッツ / 特定原材料に 準ずるもの(表示が すすめられる)20品目
- 「100マス計算」「百ます計算」の 字は 使わない
- ほかの 旅と かぶらない(下の「この旅に 入れる / 入れない」を 守る)。**読み(reading)も ほかの 旅と かぶらない**

## 旅ごとに 入れる / 入れない
- zairyo(za-。図は pantry): 洋菓子の 材料と 材料の 科学。小麦粉の 種類・グルテン・でんぷん・卵(卵黄・卵白)・砂糖の 種類・転化糖・水あめ・はちみつ・牛乳・生クリーム・乳脂肪・バター・ショートニング・チョコ(カカオマス・カカオバター・クーベルチュール)・ナッツ・アーモンドプードル・果物・ピューレ・洋酒・ゼラチン・寒天(材料として)・ペクチン・ベーキングパウダー・重曹・イースト・バニラ・色素・乳化・メイラード反応・カラメル化・糖度(ブリックス)など。
  **入れない**: 和菓子だけの 材料(上新粉・白玉粉・葛粉・あずき・寒天の 和菓子 → wagashi)/ 栄養素・食品学の 分類(→ dogu)/ 完成した お菓子の 名前(→ sekai)
- kiji(ki-。図は cake。場所は sponge / butter / pastry / choux / meringue / bake / method): 生地と 製法の 名前。スポンジ生地・共立て・別立て・ジェノワーズ・ビスキュイ・パウンド生地・シュガーバッター法・フラワーバッター法・パイ生地(折り込み・練り込み)・パートシュクレ・パートブリゼ・パートサブレ・パータシュー・メレンゲ(フレンチ・イタリアン・スイス)・空焼き・重石・焼成・ふるう・さっくり まぜる・きめ・ダクワーズ生地・ロールケーキの 生地・発酵生地(ブリオッシュ生地)など。
  **入れない**: クリーム・チョコ・あめ(→ cream)/ 完成品の 名前(マドレーヌ・フィナンシェ・マカロン など → sekai)/ 道具(→ dogu)
- cream(cr-。図は cake。場所は cream / choco / sugar / cold / finish / method): クリーム(カスタード・ホイップ・バタークリーム・ディプロマット・シャンティ・アングレーズ・クレームダマンド・ムースリーヌ)・ソース(クーリ・キャラメルソース)・チョコの 技術(テンパリング・ガナッシュ・ブルーム・コーティング)・あめ(シロップ・フォンダン・プラリネ・ヌガー・あめ細工・引きあめ・流しあめ・マジパン細工)・冷たい お菓子の 種類(ムース・ババロア・ゼリー・ソルベ・グラス)・仕上げ(ナパージュ・グラサージュ・デコレーション・ナッペ)など。
  **入れない**: 生地(→ kiji)/ 材料そのもの(生クリーム・ゼラチン・クーベルチュール → zairyo)/ 完成品の 名前(→ sekai)
- sekai(se-。図は world): **完成した お菓子の 名前**と 生まれた 国・由来・行事の お菓子・お菓子の 歴史の ことば。フランス(マカロン・マドレーヌ・フィナンシェ・ミルフィーユ・エクレア・シュークリーム・クレームブリュレ・タルトタタン・オペラ・サントノーレ・パリブレスト・カヌレ・ガレットデロワ・ブッシュドノエル・クグロフ など)/ イタリア(ティラミス・パンナコッタ・ジェラート・パネトーネ・カンノーリ)/ ドイツ(バウムクーヘン・シュトーレン・シュヴァルツヴェルダーキルシュトルテ)/ オーストリア(ザッハトルテ・アプフェルシュトゥルーデル・リンツァートルテ)/ イギリス(スコーン・ショートブレッド・プディング)/ スペイン・ポルトガル(チュロス・パステルデナタ)/ アメリカ(ブラウニー・チーズケーキ・パンケーキ・ドーナツ)/ アジア・中東(バクラヴァ・エッグタルト など)/ 日本生まれの 洋菓子(ショートケーキ・モンブランの 日本の 形 など、まちがいない もの)/ 南蛮菓子(カステラ・金平糖・ボーロ)/ お菓子の 歴史の 人物(カレーム など、まちがいない ときだけ)。
