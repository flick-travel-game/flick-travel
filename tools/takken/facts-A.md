## A. 試験

### A-1. 試験の しくみ
| 事実 | 出どころ |
|---|---|
| 試験は **都道府県知事**が 行う(法16条1項)。知事は 国土交通大臣の 指定する者(指定試験機関)に 試験事務を 行わせられる(法16条の2) | 法16条・16条の2(e-Gov) |
| 指定試験機関は **一般財団法人 不動産適正取引推進機構**。**昭和63年度(1988年度)から** 全ての 都道府県知事の 委任を 受けて 実施 | RETIO「宅建試験の概要」 https://www.retio.or.jp/exam/exam_detail/ |
| 試験は **毎年 少なくとも 1回**(規則10条1項)。筆記試験(規則9条) | 規則9条・10条(e-Gov) |
| RETIO: 試験日は **毎年1回、10月の 第3日曜日**。午後1時〜3時(**2時間**)。登録講習修了者は 午後1時10分〜3時(**1時間50分**) | RETIO「宅建試験の概要」 |
| **50問・四肢択一式**の 筆記試験(マークシート)。登録講習修了者は **45問** | RETIO「宅建試験の概要」・FAQ https://www.retio.or.jp/exam/faq/ |
| **出題の 根拠と なる 法令は、試験を 実施する 年度の 4月1日 現在 施行されて いる もの** | RETIO「宅建試験の概要」(※印の 注) |
| 受験資格: 日本国内に 居住する 方なら 年齢・学歴に 関係なく だれでも | RETIO「宅建試験の概要」 |
| 受験手数料 **8,200円**(消費税 非課税) | RETIO「宅建試験の概要」・スケジュール |
| 実施公告は 原則 毎年 **6月の 第1金曜日**(官報・RETIO の ホームページ)。合格発表は 原則 **11月下旬** | RETIO「宅建試験の概要」 |
| 試験の 内容(規則8条)は 7つ: ①土地の形質・地積・地目・種別、建物の形質・構造・種別 ②権利・権利の変動に関する法令 ③法令上の制限 ④税に関する法令 ⑤需給に関する法令及び実務 ⑥価格の評定 ⑦宅建業法と 関係法令 | 規則8条(e-Gov)・RETIO |
| 試験の 基準: 宅地建物取引業に関する **実用的な知識**を 有するかどうか(規則7条) | RETIO「宅建試験の概要」(規則7条を 引用) |
| 不正受験: 合格の 取消し・受験の 禁止。情状により **3年以内**の 期間 受験させない ことが できる | 法17条(e-Gov) |
| 平成26年度(2014年度)までは「宅地建物取引**主任者**資格試験」 | RETIO「宅建試験の概要」 |

### A-6. 合格した あと(登録・取引士証・法定講習)

## B. 宅地建物取引業法

### B-1. 定義
| 事実 | 出どころ |
|---|---|
| 宅地 = 建物の 敷地に 供せられる 土地 + **用途地域内の その他の 土地**(道路・公園・河川・政令の 公共施設の 用に 供せられて いる ものを 除く) | 法2条1号 |
| 政令の 公共施設 = **広場 及び 水路** | 令1条 |
| 宅建業 = 宅地・建物の **売買・交換**、または 売買・交換・**貸借の 代理・媒介**を **業として** 行う こと。→ 条文に「**自ら 貸借**」は 無い(自分が 貸主に なるのは 宅建業では ない) | 法2条2号 |
| 宅建業法は **国・地方公共団体には 適用しない** | 法78条1項 |

### B-2. 免許
| 事実 | 出どころ |
|---|---|
| **2つ以上の 都道府県**に 事務所 → **国土交通大臣**の 免許 / **1つの 都道府県**だけ → その **都道府県知事**の 免許 | 法3条1項 |
| 免許の **有効期間 5年** | 法3条2項 |
| 更新の 申請は 有効期間 満了の 日の **90日前から 30日前まで** | 規則3条 |
| 満了日までに 処分が なければ 前の 免許は 処分まで 効力が ある。更新されたら 新しい 期間は 前の 満了日の 翌日から | 法3条4項・5項 |
| 事務所 = 本店・支店(商人以外は 主たる・従たる 事務所)+ 継続的に 業務を 行える 施設で 契約締結権限の ある 使用人を 置く 場所 | 令1条の2 |
| 免許換え: 大臣 → 1つの 県だけに なった / 知事 → 別の 県へ 移った / 知事 → 2つ以上の 県に なった とき、新しい 免許で 前の 免許は 効力を 失う | 法7条1項 |
| 変更の 届出(商号・役員・政令の 使用人・事務所の 名称と 所在地・専任の 取引士の 氏名)は **30日以内** | 法9条(法4条1項1〜5号) |
| 廃業等の 届出は **30日以内**(死亡は 相続人・知った 日から / 合併消滅は 代表役員だった 者 / 破産は 破産管財人 / 解散は 清算人 / 廃止は 本人・代表役員) | 法11条1項 |
| 免許を 受けて **1年以内に 事業を 始めない**、または **引き続き 1年以上 休止** → 免許取消し(必ず) | 法66条1項6号 |

### B-3. 免許の 欠格事由(主な もの)
| 事実 | 出どころ |
|---|---|
| 破産手続開始の 決定を 受けて 復権を 得ない 者 | 法5条1項1号 |
| 不正手段で 免許を 受けた などで 免許を 取り消され、取消しの 日から **5年**を 経過しない 者(法人なら 聴聞の 公示の 前 **60日以内**の 役員も) | 法5条1項2号 |
| **拘禁刑以上**の 刑に 処せられ、執行を 終わり または 受けなくなった 日から **5年**を 経過しない 者 | 法5条1項5号 |
| この 法律・暴力団対策法 違反 / 傷害・暴行・脅迫・背任 などの 罪で **罰金刑** → **5年** | 法5条1項6号 |
| 暴力団員 または 暴力団員で なくなった 日から **5年**を 経過しない 者 | 法5条1項7号 |
| 免許申請前 **5年以内**に 宅建業に関し 不正 または 著しく 不当な 行為を した 者 | 法5条1項8号 |
| **心身の 故障**により 宅建業を 適正に 営めない 者として 省令で 定める もの | 法5条1項10号 |
| 取引士の 登録の 欠格事由(法18条1項)も ほぼ 同じ 形(未成年者で 行為能力の ない 者・5年 など) | 法18条1項 |

### B-4. 宅地建物取引士(業者が 置く 人数・登録)
| 事実 | 出どころ |
|---|---|
| 事務所等ごとに **成年者である 専任の 取引士**を 置く | 法31条の3第1項 |
| 数: **事務所** = 業務に 従事する 者の **5分の1以上** / **案内所など**(規則15条の5の2の 場所)= **1以上** | 規則15条の5の3 |
| 案内所などの 場所: 継続的施設・**10区画以上の 一団の 宅地 / 10戸以上の 一団の 建物**の 分譲の 案内所・展示会など(契約の 締結 または 申込みを 受ける もの) | 規則15条の5の2 |
| 足りなく なったら **2週間以内**に 必要な 措置 | 法31条の3第3項 |
| 案内所などを 設ける 届出(法50条2項)は 業務を 始める 日の **10日前まで** | 規則19条3項 |
| 登録の 移転: 登録を した 県 **以外の** 県の 事務所で 働く(働こうと する)とき、**移転先の 知事**に **元の 知事を 経由して** 申請 **できる**(義務では ない)。事務禁止 期間中は できない | 法19条の2 |
| 登録事項に 変更 → **遅滞なく** 変更の 登録 | 法20条 |
| 死亡等の 届出は **30日以内**(死亡は 相続人・知った 日から) | 法21条 |
| 取引の 関係者から 請求が あれば **取引士証を 提示** | 法22条の4 |
| 重要事項の 説明の ときは 請求が なくても **取引士証を 提示** | 法35条4項 |

### B-5. 営業保証金
| 事実 | 出どころ |
|---|---|
| **主たる事務所の もよりの 供託所**に 供託 | 法25条1項 |
| 額: **主たる事務所 1,000万円 + その他の 事務所 1か所ごとに 500万円** | 令2条の4 |
| 有価証券でも よい(国債など) | 法25条3項 |
| 供託した → 免許権者に **届け出た 後でなければ 事業を 始められない** | 法25条4項・5項 |
| 免許から **3か月以内**に 届出が なければ 催告 → 催告が 届いて **1か月以内**に 届出が なければ 免許を 取り消せる | 法25条6項・7項 |
| 事務所を 新しく 設けた → その 事務所の 分を 供託 | 法26条 |
| 還付を 受けられるのは 取引を した 者(**宅建業者を 除く**) | 法27条1項 |
| 還付で 不足 → 省令の 日から **2週間以内**に 供託。供託したら **2週間以内**に 届出 | 法28条1項・2項 |
| 取戻しは **6か月以上**の 期間を 定めて 公告(取戻し事由から **10年**たてば 公告 不要) | 法30条2項 |

### B-6. 保証協会(弁済業務保証金)
| 事実 | 出どころ |
|---|---|
| 弁済業務保証金分担金: **主たる事務所 60万円 + その他の 事務所 1か所ごとに 30万円** | 令7条 |
| 加入しようと する 者は **加入しようとする 日までに** 納付 | 法64条の9第1項1号 |
| 新しく 事務所を 設けた → その日から **2週間以内**に 納付(しないと 社員の 地位を 失う) | 法64条の9第2項・3項 |
| 協会は 分担金の 納付を 受けた 日から **1週間以内**に 弁済業務保証金を 供託(法務大臣・国土交通大臣の 定める 供託所) | 法64条の7 |
| 還付の 範囲は「社員で なかったら 供託すべき **営業保証金の 額**」まで。還付を 受けるには **協会の 認証** | 法64条の8第1項・2項 |
| 還付が あった → 協会は 省令の 日から **2週間以内**に 供託 | 法64条の8第3項 |
| 協会から 通知 → 社員は 通知を 受けた 日から **2週間以内**に **還付充当金**を 納付(しないと 地位を 失う) | 法64条の10 |
| 社員の 地位を 失った → **1週間以内**に 営業保証金を 供託 | 法64条の15 |
| 社員が 地位を 失った とき、協会は **6か月以上**の 期間で 認証の 申出を 公告 | 法64条の11第4項 |

### B-7. 業務の きまり(帳簿・名簿・標識・広告)
| 事実 | 出どころ |
|---|---|
| 帳簿: **事務所ごと**に 備え、取引の つど 記載 | 法49条 |
| 帳簿は 各事業年度の 末日で 閉鎖し、閉鎖後 **5年間**(**自ら 売主となる 新築住宅**に係る ものは **10年間**)保存 | 規則18条3項 |
| 従業者に **従業者証明書を 携帯**させる。請求が あれば 提示 | 法48条1項・2項 |
| 従業者名簿: 事務所ごとに 備え、**最終の 記載の 日から 10年間** 保存。請求が あれば 閲覧 | 法48条3項・4項・規則17条の2第4項 |
