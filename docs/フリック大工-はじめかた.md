## 2. はじめに けいくんに 聞く 5つ(「全部おすすめで」と 返ってくる ことが 多い)

2. **旅の 分けかた**(おすすめ 7つ + 🏆 マスター):
   🏠 家づくりの きほん `kihon`(大工・棟梁・工務店・設計図・平面図・木造・在来工法(木造軸組工法)・ツーバイフォー・地鎮祭・上棟式 …)/
   🌲 木と 材料 `ki`(杉・檜・松・欅・木目・柾目・板目・年輪・乾燥・集成材・合板・心材・辺材・節 …)/

   🏗️ 家の しくみ `kozo`(基礎・土台・柱・梁・桁・筋かい・耐力壁・小屋組・棟木・垂木・屋根・軒・床・壁・断熱 …)/

   🚪 内装と 仕上げ `shiage`(和室・床の間・敷居・鴨居・長押・建具・框・造作・フローリング・天井・階段・押入れ …)/

## 3. ⚠️⚠️⚠️ ぜったいの 決まり(整備士と 同じ。刃物と 高い ところは なおさら)
- ✅ **ほかの ゲーム(整備士・社会・理科 など)と 同じ 語を 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)。説明は **大工の 目線**で 書きなおす
- **読み(ひらがな)は 大工の 7つの 旅の 中では かぶらない**(ほかの ゲームとは かぶって よい。`terms_js.py` が 止める)
- ⚠️⚠️ **道具の 使いかた・作業の 手順を ぜったいに 書かない**(整備士の「締めつけの 手順は 書かない」と 同じ)。
  ❌「のこぎりは ◯◯の ように ひく」「丸のこは ◯◯して 切る」/ ⭕ その ことばが **何を さすか・何の ための 道具や 部材か・家の どこに あるか**。
  刃物・電動工具の 語の 説明には「おとなの 大工さんが 使う 道具」の ように **子どもが まねしない** 書きかたを する
- **小学生も あそぶ**: 落ちる・切る・けがの ようす・事故の 話を 書かない。「命に かかわる」も 使わない(整備士で「とても 危ない」に 直した 前例)。
  安全の ことば(安全帯(墜落制止用器具)・ヘルメット・足場・KY活動)は **「みんなで 安全を 守る しくみ」** として おだやかに
- **寸法・強さ・値段の 数字を 書かない**(尺・寸・間 などの **単位の 名前と 意味**は よい。「1間は 約1.8m」の ような **だれでも 確かめられる 単位の 大きさ**だけ。建築基準法の 数字・木材の 強さの 値は 書かない)
- **実在の 工務店・ハウスメーカー・道具メーカー・商品の 名前を 入れない**(歴史上の 建物(法隆寺・伊勢神宮 など)と 歴史上の 人は よい)
- **言い伝えは 言い伝えと 書く**(左甚五郎 など)。宗教の よしあしを 書かない(地鎮祭・上棟式は「家づくりの 節目の 行事」として)
- **作った 助手とは 別の 助手が 1語ずつ 確かめる**(意味・読み・使いかたや 手順を 書いていないか・数字の 決めうち・こわくないか)。ふりがなも 全語 見る(`tools/ruby_fix.json`)。
  ⚠️ 大工の ことばは **読みが ゆれる**(鴨居・長押・框・垂木・桁 など)。ゆれる 語は `acceptedReadings` に 入れ、**いちばん ふつうの 読みを 先頭**に

**建築大工技能士**(技能検定 = 国家検定。1級・2級・3級。実技(墨付け・加工・組み立て)と 学科。都道府県職業能力開発協会が 行う。受検資格の 実務経験。確かめる)/
大工に なる 道(工務店などで 見習い・職業訓練校・専門学校・工業高校の 建築科。確かめる)/
**二級建築士・木造建築士**(建築士法の 国家資格。大工が 上を めざす 道として 名前だけ。確かめる)/
建築基準法(名前と「建物の 安全の 最低の 決まり」だけ)/ 伝統の 技(「伝統建築工匠の技」が ユネスコ無形文化遺産に 登録 2020年。確かめる)。
⚠️ 「専門家になれるレベル」= **建築大工技能士 1級の 学科の 範囲の ことばを ひととおり 知っている**こと、と けいくんに 伝える

## 5. 作りかたの 手順(税理士・投資家の まとめと 同じ)
1. けいくんに 2 の 5つを 聞く → 返事を CLAUDE.md に 書く
2. `tools/daiku/PROMPT.md` `exam.txt` `mkmeta.py` → `meta.json` を 作る → 旅ごとに 助手に 70語ずつ 頼む(`PROMPT.md` を そのまま わたす。**助手は 2人ずつ**)→ `terms-<旅>.json`
3. `terms_js.py` で 止められた 語を 直す → 別の 助手が 1語ずつ 確かめる → ふりがな
4. `daiku/daiku.js`(zeirishi.js を 写す)・`build_games.py`・`index.html` の PLUG と SERIES → `python3 tools/build_games.py`
5. 手元で 通す: `python3 -m http.server 8765` → `node tools/play-all.mjs daiku/` / `node tools/click-all.mjs daiku/`
6. PR は **rebase で 取りこむ**(この 入れもの)。speed-king は squash。コミットの 末尾は Co-Authored-By と Claude-Session の 2行
7. かずとも `speed-king`: `FLICK_MODES` / `FLICK_LINK_TARGETS` に `daiku`(PR → squash)。`HOME_GAMES` は 絵と OK の あと
8. けいくんに ChatGPT で 絵を 頼む 文を わたす。**3つ**:
   ・トップの 絵(1536×1024)。**人物は 画面の 下 3分の1に 小さく**・指5本・首が 見える。木の 家の 骨組み(上棟の ころ)や 木の 香りの 作業場の 前で、大工の 服の 子どもと 白い 犬。
     **のこぎり・のみ・電動工具を 手に 持たせない**(手が 崩れやすい・刃物を 子どもが 持つ 絵に しない。道具は 道具箱や 台の 上に 置く)。**高い 足場の 上に 子どもを 立たせない**。
     絵の 中の 字は「フリック大工」だけ・ゲームに 無い 機能の 絵を 入れない・**実在の 会社の ロゴ・実在の 寺社の 名前の 看板を 描かない**。届いたら **まず 字を 切り出して 読む**
   ・四角い 絵(1254px)… **切らずに そのまま アイコンに する**ので、**小さく しても わかる 絵**(人と 犬と 家の 骨組み くらい。まわりに 字の 札を ならべない)で 頼む
   ・**題名だけの 透明 PNG**(CLAUDE.md「題名は ChatGPT に 切りぬいてもらう」の 文を そのまま。「フリック大工」と **はっきり 書く**。⚠️ ChatGPT は 字を 変える。**届いた 字を かならず 読む**)
9. 絵を 入れたら CLAUDE.md に 節を 書く(名前・旅・語数・確かめた 日・入れなかった 語と 理由)

## 6. 気をつける 前例
- 整備士で「命に かかわる」「毒の ガス」「投げだされる」を やわらげた(2026-10-01)。大工でも **落下・切り傷・粉じん** の 書きかたを おだやかに
- 整備士の 4つの 旅の 説明が「〜部品。」の 体言止めで はじまる 形に なっている。大工は **はじめから「〜です・ます」**で そろえる
- 読みの かぶりは 片方を べつの 語に(例: 「梁(はり)」と「針」は 大工の 中で 1つだけ。「桁(けた)」「棟(むね)」「框(かまち)」も 確かめる)
- 2026-10-03 の 時点で 30ゲーム(投資家まで)。**フォルダ・id・modes 名を まぜない**(`daiku`)
- 理科(`rika/`)の「てこ」「力」、社会の「伝統工芸」、整備士の「工具」と かさなる 語が ある。**同じ 語を 入れて よい**が、説明は 大工の 目線で
