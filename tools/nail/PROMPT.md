# フリックネイリスト: ことばの 作りかた(助手に 分けて 頼むときの 決まり)

けいくん 2026-11-06「フリックネイリストを **プロのネイリストになれるように** まとめてください」→ 5つの 問いに「全部おすすめで」。
**990語(9つの 旅 × 110語 = 入門20・中級30・上級60)**。「プロ」= サロンで お客さんに 施術できて、検定の ことばが わかり、自分の サロンも 開ける こと。
⚠️ ネイリストは **国家資格では ない**(美容師免許は 要らない)。民間の 検定(ネイリスト技能検定・ジェルネイル技能検定・ネイルサロン衛生管理士)が めやす。事実は `tools/nail/exam.txt` を 見る

## ⚠️⚠️⚠️ いちばん 大事な 決まり(さいしょに 読む)
1. ⭐⭐ **医療と まぜない**。爪の トラブル(グリーンネイル・二枚爪・巻き爪・爪の 白い にごり など)は
   「**名前と 見分けかた → 施術を ひかえて 医療機関(皮膚科)を すすめる**」まで。**診断・治療・薬の 名前・治しかたは 書かない**(医師法)。
   「治る」「よくなる」「爪が 強く なる」「割れなく なる」と **約束に 読める 文を 書かない**(薬機法)。「◯◯の ために 使われます」の 形に。
   「治療」「治す」「治る」「診断」「軟膏」の 字は `terms_js.py` が 止める
2. ⭐⭐ **やりかたを 書かない**。くすり(アセトン・プライマー・モノマー・リムーバー)の **量・時間・濃さ・%**、ライトの **秒数**、削る **手順・角度・回数**は 書かない(美容師と 同じ)。
   書くのは「**なに・なぜ そうするか**」の 考えかたまで(例: 「ジェルが はがれにくく なるよう、爪の 表面の 油分を とる 下じゅんび」)。「%」「秒」は 台本が 止める
3. ⭐ **安全の 考えかたは 書く**。換気・ダストを 吸わない・**ジェルを 皮膚に つけない**(アレルギーを ふせぐ)・器具の 消毒・使い捨て。**おだやかに**(こわがらせない)。
   けがの ようす(出血・深爪の いたみ・化膿)は 書かない
4. **見た目を わるく 言わない**。爪の 形・長さ・手の 大きさ・肌の 色に よしあしを 付けない。「◯◯な 爪には ◯◯が 似合います」の **ほめる 形**で。
   「汚い」「太い指」などは 台本が 止める
5. ✅ **道具・技法の 一般の 名前は 入れて よい**(ファイル・プッシャー・LED ライト・アクリル・フレンチ・マグネットネイル)。
   ❌ **ブランド名・商品名・サロン名・有名ネイリストの 名前・予約サイトや SNS の サービス名・実在の キャラクター名は 入れない**(台本の `BAN`)。「SNS」「予約サイト」の 一般の ことばは よい
6. **数字・金額で 約束しない**。「◯日 もつ」「◯円」「最安値」「ずっと 取れない」は 書かない。経営の 旅は **意味と 考えかただけ**(客単価 = 1人の お客さんが 1回に 払う 平均の 金額、の ように 文で)。「もうかる」「かならず 成功」も 書かない
7. ⚠️ **まつげエクステ・顔そり・脱毛・タトゥーは 入れない**(美容師・医師の しごとで ネイリストの しごとでは ない)
8. **検定の 本物の 問題を 写さない**。過去問・問題集・教本・Wikipedia の 文を 写さない。自分の ことばで
9. **小学生も あそぶ**。やさしい です・ます。迷ったら 入れない
10. **事実は 確かめる**。検定・法律・制度は `exam.txt` と WebSearch で 確かめた ものだけ。あやしい ものは 書かない・入れない

## ゲームの かたち
「表示された ひらがなを フリックで 打ち写す」タイピング。打ち終わると 説明(1〜3文)が 出る。説明の 下に 📘 分野 と 📝 検定の 札。
4択クイズ(説明 → ことば)も ある。あそぶのは 小学生〜プロの ネイリスト・サロンを 開く 人

## 1語の 形(JSON)
{"id":"ge-mikouka","name":"未硬化ジェル","reading":"みこうかじぇる","journey":"gel","category":"硬化","difficulty":2,"type":"concept",
 "emoji":"💧","mapNode":"gel:kouka","field":"ジェル","ruleset":"ジェル検定","relatedTerms":["ge-kouka","ge-topgel"],
 "description":"ライトを 当てた あとも 表面に 残る、かたまりきらない ジェルの 層。皮膚に つかない よう ふきとります。"}
- id: 旅の 頭文字2つ + "-" + 英小文字(ts- / ei- / ca- / co- / ge- / sc- / ar- / se- / ke-)
- name: 画面に 出す 名前
- reading: **ひらがなと ー だけ**。カタカナ語は ひらがなに(ネイルプレート → ねいるぷれーと)。**のばす 音(ー)・小さい 字を まちがえない**
  (ハイポニキウム = はいぽにきうむ・ルヌーラ = るぬーら・キューティクル = きゅーてぃくる・ミクスチュア = みくすちゅあ・イクステンション = いくすてんしょん)。
  英字は 読みに(LED ライト → えるいーでぃーらいと・Cカーブ → しーかーぶ・3D アート → すりーでぃーあーと)。ゆれは "acceptedReadings":["よみ1","よみ2"](先頭は reading)。
  ⚠️ 漢字の 読みまちがい注意: 甘皮=あまかわ / 爪床=そうしょう / 爪母=そうぼ / 爪上皮=そうじょうひ / 爪下皮=そうかひ / 爪甲=そうこう / 爪郭=そうかく / 深爪=ふかづめ / 巻き爪=まきづめ / 陥入爪=かんにゅうそう / 二枚爪=にまいづめ / 硬化=こうか / 補色=ほしょく / 彩度=さいど / 明度=めいど / 色相=しきそう / 表皮=ひょうひ / 真皮=しんぴ / 角質=かくしつ
  ⚠️ **読みは この ゲームの 9つの 旅の 中で かぶらない**(plan.json の とおり。同じ 読みを 2つ 入れない)
- difficulty: 1 = 入門(ネイルが すきな 人・小学生) / 2 = 中級(サロンで 働ける。技能検定 3級・2級、ジェル検定 初級・中級の めやす) / 3 = 上級(プロ・サロンを 開く。技能検定 1級・ジェル検定 上級・衛生管理士の めやす + 経営)
- type: いつも "concept"
- category: 図鑑で しぼる 分類(短い 日本語。旅の 中で 4〜8種類)
- emoji: 1つ。⚠️ けが・血の 絵文字(🩸 など)は 使わない
- mapNode: その 旅の 図の 場所(下の 表から)
- field: 学ぶ 分野: 爪の構造 / 皮膚科学 / 衛生と消毒 / 爪の病気 / 道具 / ケア / カラー / ジェル / スカルプチュア / アート / 接客 / 法律 / 経営 の どれか
  (爪の病気 = 見分けて 施術を ひかえ 医療機関を すすめる ための ことば)
- ruleset: 📝 検定の 札: 技能検定(ネイリスト技能検定)/ ジェル検定(ジェルネイル技能検定)/ 衛生(ネイルサロン衛生管理士・衛生の 基準)/ サロン(働く・開く・経営)/ 共通(入門の くらしの ことば・どの 検定にも)。**上級は かならず 付ける**(中級・入門も なるべく)
- relatedTerms: **同じ ファイルの 中の** id を 1〜3個
- description: 1〜3文・**130字以内**。やさしい です・ます。語と 語の あいだに 半角スペース(上の 例のように)。⭐ ときどき「へえ」の 1文。
  **ネイリストの 目線**(「サロンで どう 使うか」「お客さんに どう 説明するか」)で 書く(美容師の bmake・マナー・起業家・家事と かぶる 語も 目線を 変える)
- example: なくてもよい
