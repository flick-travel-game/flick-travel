## フリック哲学(`tetsugaku/`。けいくん 2026-10-03「哲学の専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」。まとめは `docs/フリック哲学-はじめかた.md`)

- 名前は「フリック哲学」(絵が 届いたら 題名に そろえる。フォルダ名 `tetsugaku` は 変えない)。シリーズの 絵文字は 🤔。`SERIES_ORDER` は **アドラー心理学の となり**
- 旅は 9つ(哲学のきほん `kihon`・古代ギリシャ・ローマ `kodai`・東洋の思想 `toyo`・中世から近代 `kinsei`・近代から現代 `gendai`・よく生きる(倫理学) `rinri`・知ることと心 `chishiki`・社会と国 `shakai`・日本の思想 `nihon`)+ マスター。
  **旅ごとに 70語(入門20・中級25・上級25)= 630語**。かずともの 旅の 名前は **`tt` で はじめる**(ttkihon / ttkodai / tttoyo / ttkinsei / ttgendai / ttrinri / ttchishiki / ttshakai / ttnihon / ttmas)。作る 前に ぶつからない ことを 確かめた(`t` は 教師・`tk` は 投資家)
- むずかしさは 3段: 入門(考える ことが すきな 子)→ 中級(**高校「倫理」・共通テスト「公共，倫理」の 範囲の めやす**)→ 上級(**大学の 哲学科の 入門〜専門書の ことばの めやす**)。
  1語ごとに **分野**(`field`)9つ: 形而上学 / 認識論 / 倫理学 / 美学 / 社会・政治哲学 / 論理学 / 心の哲学 / 東洋思想 / 日本思想
- ことばは `tools/tetsugaku/terms-<旅>.json`(決まりは `tools/tetsugaku/PROMPT.md`。**どの 語を どの 旅に 入れるかの 一覧**は `tools/tetsugaku/plan.json`)→ `tools/tetsugaku/terms_js.py` → `tetsugaku/terms.js` + `data/tetsugaku.json`。
  しくみは `tetsugaku/tetsugaku.js`(アドラーを 写した。4択クイズ あり)。ちがいは
  ・⭐ **💭 考えて みよう**(`toi`)… 1文の 問いかけ。**答えは 書かない**。こたえた あとの カードと 説明・図鑑に 出す。**1旅に 5〜10語**(いま 6〜9語)。`terms_js.py` が 形(「?」で 終わる・50字まで)と 数を 見る
  ・⭐ **📜 哲学者の 年表**(ホーム。`<details>` で たたむ)… 西洋・東洋・日本の 3本の 線に 37人。**同じ ころに 孔子・ブッダ・ソクラテスが いた** ことが 一目で わかる(紀元前5世紀ごろを 黄色の 枠)。
    年は **活やく した ころの めやす**(生まれた・亡くなった 年では ない)。古代と 近代に 人が 多いので **目もりを のびちぢみ** させている。名前が かさならないよう 上下 6段に 置く。
    出会った 人は 色が つき、名前を おすと その ことばが ひらく。中身は `tools/tetsugaku/mkmeta.py` の `NENPYO`(⚠️ name を ことばの name と 1文字も ちがえず そろえる)
  ・しくみ図(箱の 図)9つ。1つめは **哲学の 地図**(存在 / 知る こと / よい こと / 美しい こと / 社会 / 論理 + 問い・対話・定義・論証・思考実験・なぜ?)。
    時代の 旅(古代・東洋・中世から近代・近代から現代・日本)は **だれが だれに 影響したか の 矢印**(ソクラテス → プラトン → アリストテレス、ヒューム → カント → ヘーゲル など)
  ・ホームの 下に「🤔 哲学には 答えが 1つで ない 問いが たくさん あります。自分で 考えて みよう」の 1行(遊びかた・note にも)
- 専門家に なる 道は `tools/tetsugaku/exam.txt`(→ meta.json の `exam`)に **確かめた日つき**(2026年10月3日。文部科学省の 平成30年改訂 学習指導要領 Q&A(公民)・大学入試センターの 出題教科・科目・P4C の 紹介):
  **哲学に 国家資格・検定は 無い** / 高校の 公民は「公共」が 必履修・「倫理」「政治・経済」は その あと えらぶ 科目 / 共通テストの 公民は 令和7年度から「公共，倫理」「公共，政治・経済」「地理総合，歴史総合，公共」/
  大学の 哲学科・倫理学科 → 大学院 → 研究者 / 哲学対話・P4C(1970年代に アメリカで はじまった)。
  ⚠️「専門家に なれる レベル」は **高校「倫理」の ことばを ひととおりと、大学の 哲学科の 入門書の ことばを 知っている** めやす。本当の 力は「自分で 問いを 立てて 考える こと」
- ⚠️⚠️ **「どちらが 正しい」を 書かない**(功利主義と 義務論・経験論と 合理論・性善説と 性悪説 は 立場として ならべる。荀子は「学びと 努力で よく なる」)。**人の 考えを 決めつけない**(有名な ことばの 意味は ゆれる)
- ⚠️⚠️ **死・自殺・いのちを くらべる 話を 書かない**: 台本が「死」「殺」「血」「処刑」「トロッコ」「不条理」を 止める。トロッコ問題・ソクラテスの 最期・カミュ・死生観・『死に至る病』・ニーチェの「神は〜」は 入れていない。
  生まれた・亡くなった 年は 書かず「◯世紀ごろの 人」「◯年ごろ 活やく」。『パンセ』は「書きためた メモを のちに まとめた 本」
- ⚠️ **宗教・政治は 中立に**(最澄・空海・法然・親鸞・道元・日蓮・内村鑑三・ブッダ・孔子は 思想の 特徴だけ。宗教の しるしの 絵文字は 使わない)/ 今の 国・政党・政治家を 書かない(台本が 止める)/
  **昔の 哲学者の 差別的な 考えは 入れない**(「奴隷」「差別」「人種」を 止める)/ **生きている 人の 名前は 入れない**(メアリーの部屋・中国語の部屋・ハードプロブレム・潜在能力・討議倫理・公共圏は 人名を 出していない。ギリガンは 存命なので ケアの倫理は ノディングズ(2022年 没)で)
- ✅ 社会旅行・歴史旅行・アドラー心理学・国語・AI旅行と 同じ 語や 人を 入れて よい(説明は 哲学の 目線)。読みは **哲学の 9つの 旅の 中で** かぶらない(`terms_js.py` が 止める)。
  **人の 名前の 語は 1回だけ**(カントは 中世から近代に 人名・倫理に 定言命法・知ることに アプリオリ。ロックは 近代に 人名・社会に 抵抗権・『統治二論』)。ストア派の ゼノン(キティオンの ゼノン)と エレアの ゼノンは 別人として 別の 名前
