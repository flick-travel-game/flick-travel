# フリック歯科医師: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
どの 歯・お口の どこの 話か(🦷 札)・学ぶ 分野(歯科医師国家試験の 出題基準の 分け)・しくみ図の どこに あるか(📍)が 出る。
あそぶのは **小学生〜歯学部を めざす 中高生・歯学生・歯科衛生士を めざす 人・歯の 健康が 気に なる 大人**。
**歯医者さん(歯科医師)の ことばと 意味を おぼえる ゲーム**(試験の 問題集でも、治療の 手引きでも ない)。
もとは `tools/jui/PROMPT.md`(獣医師)と `tools/ishi/PROMPT.md`(医師)。
けいくん 2026-10-09「歯科医師の専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 7つ

### 1. ⭐⭐ 歯医者さんを こわく させない(いちばん 大事)
- **歯医者さんを こわがって いる 子が あそぶ**。この ゲームで「歯医者さん こわい」が 増えたら 失敗
- ❌ 名前・説明に **書かない 字**(台本が 止める): キーン / ドリル / 削る・けずる / 抜く・抜歯 / 注射 / 針 / 痛い・痛む・激痛・ズキズキ / 出血・血が / こわい・怖い
  - 麻酔は「**痛く ない ように する お薬**」まで。治療は「**悪い ところを きれいに して、つめる・かぶせる**」まで
  - 歯ぐきの 病気は「歯ぐきが 赤く はれる」まで(「血が 出る」とは 書かない)
- ⭕ **向き**: 「早く 見つければ 小さな 治療で すむ」「歯医者さんは 歯を 守る 味方」「定期検診で 早く 見つける」
- ⭐ 子どもの 安全に 役立つ ことは 書いて よい: 「歯が 抜けたら 乾かさずに すぐ 歯医者さんへ」「歯が いたい・ぐらぐら するときは 大人に 言う」
  (「抜けたら」「いたい」(ひらがな)は 止まらない)

### 2. 治療の やりかたを 書かない
- ❌ **書かない**: 治療・手術の **手順**・薬の **量**・「この しょうじょうなら この 病気 / この 治療」・正常値の 数字・
  **家で できる 治療**・フッ素の **濃さ・量**・治療の **回数・期間・費用**・保険の **点数**
- ⭕ **書く**: その ことばが **何を さすか**・**何の ために あるか**・**どんな しくみか**・歯科医師は どう かかわるか
  (例: デンタルミラー = お口の 中を 映す 小さな 鏡です。奥歯の うらがわなど、そのままでは 見えない ところを 見る ために 使います)
- 治療と 材料は **名前と 目的だけ**

### 3. 小学生も あそぶ(こわく しない・責めない)
- 病気は **「何が 起きている 状態か」+「歯医者さんが 助ける」** だけ。**迷ったら その 語を 入れない**
- ❌ **口の がん・こわい 病気の ようす・死**は 入れない(台本が 止める)
- ⚠️ **むし歯の 子・歯ならびの 子を 責めない・からかわない**。「あまい ものを 食べる 子は 悪い」と 書かない。
  **だらだら 食べ を しない・みがく** の 工夫として 書く。出っ歯・受け口 などは **「歯の ならびかたの 名前。矯正で ととのえられる」**まで
- 歯の 色・形・口の においで 人を からかう 書きかたを しない

### 4. 実在の 名前・商品・年ごとに 変わる 数字を 出さない
- **実在の 歯科医院・歯みがき粉・歯ブラシ・ガム・洗口液・材料の 商品名・会社名**を 書かない(台本が 止める)
- ⭕ **成分の 名前は よい**: フッ化物・キシリトール・ハイドロキシアパタイト など
- ⭕ 公の 組織・制度の 名前は よい: 厚生労働省・文部科学省・保健所・保健センター・WHO・日本歯科医師会(8020運動の 説明で)
- 人の 名前は 歴史として よい(**事実を 確かめて**。`tools/shika/exam.txt` に ある ものだけ)
- **合格率・人数・%・円・回数・保険の 点数**は 書かない(台本が 止める)。条の 番号(第◯条)も 書かない
- ⭐ **歯の 本数**(乳歯 20本・永久歯は 親知らずを ふくめて 32本。親知らずは 4本 ぜんぶ 生えるとは かぎらない)は 変わらない からだの 事実なので 書いて よい
- 「8020運動」「6歳臼歯」は 名前なので 数字が 入って よい

### 5. 歯科医師の 目線で 書く(ほかの ゲームと 同じ 語を 入れて よい)
- ✅ **医師・看護師・薬剤師・獣医師・からだ旅行・理科の 生物 など ほかの ゲームと 同じ ことばを 入れて よい**(けいくん決定 2026-09-30「復習になるから 同じ語入れていいよ」)
- ⚠️ ただし 説明は **歯科医師の 目線**で 書く: 「お口は 食べる・話す・笑う の 入り口」「歯は 一度 なくなると もどらない ので 守る」
- **読み(ひらがな)は 歯科医師の 9つの 旅の 中で かぶらない**(台本が 止める)。下の「旅ごとに 入れる 語」を 守る。**ほかの 旅の 欄に ある 語は 入れない**
- 文体は **はじめから「〜です・ます」**(体言止めで はじめない)
- 「へえ」を 1文 入れると よい(「エナメル質は からだで いちばん かたい」「歯の 本数」「むかしの 日本には 木の 入れ歯が あった」)

### 6. 事実を 正しく
- 事実が あやしい 語は 入れない。**自分の ことばで 書く**(教科書・Wikipedia・公式の 文を 写さない)
- 資格・試験・歴史の 事実は `tools/shika/exam.txt` に 合わせる(そこに 無い 年代・人名は 書かない)

### 7. 打ちまちがい
- 「歯科医士」「歯医者士」と 書かない(台本が 止める)

## 1語の 形(JSON)

```json
{"id":"ha-enamel","name":"エナメル質","reading":"えなめるしつ","journey":"ha","category":"歯の つくり","difficulty":1,
 "field":"総論Ⅱ 正常構造と機能・発生・成長・加齢","type":"concept","emoji":"💎","mapNode":"ha:enamel","relatedTerms":["ha-zoge"],"tooth":"歯ぜんぶ",
 "description":"歯の いちばん 外がわを おおう 白い 層です。からだの 中で いちばん かたい ところで、かむ 力から 歯を 守ります。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(歯科医院・教科書で ふつうに 使う 書きかた。漢字・カタカナ・英字の 略語)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)
  - カタカナ語は ひらがなで(デンタルフロス → でんたるふろす)。英字の 略語は 下の「略語の 読み」の とおり
  - ゆれる ことばは いちばん ふつうの 読みを reading に、ほかを `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は 上級だけ・旅で 1〜2語まで
  - ⚠️ **読みを まちがえやすい ことば**(歯科医師 しかいし・歯肉 しにく・歯髄 しずい・歯槽骨 しそうこつ・歯根膜 しこんまく・象牙質 ぞうげしつ・
    臼歯 きゅうし・智歯 ちし・咬合 こうごう・咀嚼 そしゃく・嚥下 えんげ・唾液 だえき・口蓋 こうがい・顎関節 がくかんせつ・う蝕 うしょく・
    歯垢 しこう・歯石 しせき・印象 いんしょう・義歯 ぎし・叢生 そうせい・口腔 こうくう(医療の 世界の 読み。acceptedReadings に こうこう))は **1語ずつ 確かめる**
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級(下の「3段の 分けかた」)
- **field**: 学ぶ 分野 = **歯科医師国家試験の 出題基準の 分け**。次の どれか(入門の 語でも いちばん 近い ものを 書く):
  - `必修の基本的事項` … 歯科医師の 役割・倫理・社会と 歯科医療・予防の きほん・初期救急・一般教養(入門の 語で 迷ったら ここ)
  - `総論Ⅰ 保健・医療と健康増進` … 公衆衛生・8020運動・学校歯科健診・フッ化物洗口・法律と 制度・保険・チーム医療・歯の 歴史
  - `総論Ⅱ 正常構造と機能・発生・成長・加齢` … 歯と 口の つくりと はたらき(解剖・生理)・歯の でき方・乳歯と 永久歯・年を とる 変化
  - `総論Ⅲ 病因・病態` … 病気の 原因と しくみ(細菌・歯こう・酸・炎症)
  - `総論Ⅳ 主要症候` … 気づく サイン(しみる・はれる・口の におい・口が かわく・あごが 鳴る)
  - `総論Ⅴ 診察` … 問診・医療面接・視診・触診・お口の 検査・診療台と 道具
  - `総論Ⅵ 検査` … レントゲン・歯科用CT・歯周ポケット検査・唾液検査・染め出し
  - `総論Ⅶ 治療` … 治療の 名前と 目的・麻酔・予防処置・歯みがき指導・リハビリ(⚠️ やりかたは 書かない)
  - `総論Ⅷ 歯科材料と歯科医療機器` … コンポジットレジン・セラミック・印象材・セメント・CAD/CAM・歯ブラシや フロスなどの 用具
  - `各論Ⅰ 成長・発育に関連した疾患` … 子どもの 歯・生えかわり・歯ならび・矯正・口の くせ
  - `各論Ⅱ 歯・歯髄・歯周組織の疾患` … むし歯・歯周病・知覚過敏・酸蝕症・歯の けが
  - `各論Ⅲ 顎・口腔領域の疾患` … 口内炎・親知らず・顎関節症・ドライマウス・口の 粘膜・だ液の 病気
  - `各論Ⅳ 歯質・歯・顎顔面欠損と機能障害` … 歯が なくなった ときの 入れ歯・ブリッジ・インプラント・かむ・飲みこむ 力の 不調
  - `各論Ⅴ 高齢者・有病者・障害者等の歯科診療` … オーラルフレイル・口腔ケア・訪問歯科・誤嚥性肺炎・介護・全身の 病気と お口
  (歯科医師国家試験 出題基準 令和9年版(第120回から)の 必修の基本的事項 + 総論 8 + 各論 5 = 14。名前は 短く した もの)
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(💀 ☠️ 🩸 🔪 💉 🪚 🔨 は 使わない。😱 😭 などの こわがる 顔も 使わない)
- **tooth**(⭐ この ゲームだけの 欄。**なるべく 付ける**): どの 歯・お口の どこの 話か。
  `前歯` `犬歯` `奥歯` `乳歯` `永久歯` `親知らず` `歯ぜんぶ` `歯の根` `歯ぐき` `舌` `くちびる` `ほお` `上あご` `あご` `だ液` `のど` `お口ぜんたい` `からだぜんたい` の どれか。
  2〜3つなら「・」で つなぐ(`"前歯・犬歯"`)。法律・制度など 場所の 無い 語は 付けないか `お口ぜんたい`
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / 何の ために あるか / 歯科医師は どう 見るか」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  専門用語を 専門用語だけで 説明しない。「1人」「2人」は ふりがなが 読みまちがえるので **ひとり・ふたり** に 言いかえる
- **example**: なくてもよい

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | **自分の 歯を 自分で 守れる 人**。歯の しくみ・むし歯の しくみ・歯みがき・子どもの 歯。小学生でも 聞いた ことが ある |
| 2 | 中級 | **歯科医院で 働く 人**。**歯科衛生士の 範囲の めやす**(予防・歯周病・材料の 名前・検査の 名前・患者さんへの 説明・法律の 基本) |
| 3 | 上級 | **歯科医師**。**歯科医師国家試験の 範囲の めやす**(解剖・病気の しくみ・治療の 名前・公衆衛生・法規) |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる
(ならんだ 順が そのまま ステージの 順に なる)。

## ぜったいに 守ること

- **自分の ことばで 書く**。教科書・問題集・Wikipedia・公式の 文を 写さない
- **数字(%・円・回・歳・℃・点)は 書かない**(歯の 本数・8020運動・6歳臼歯は よい)。資格・制度の 事実は `tools/shika/exam.txt` に 合わせる
- 「歯科医士」「歯医者士」の 打ちまちがいに 気を つける
- 「100マス計算」「百ます計算」の 字を 使わない

## 出すもの

`tools/shika/terms-<旅id>.json` に JSON の 配列(70語)で 書く。書いたら
`python3 tools/shika/terms_js.py --only <旅id>` で 形を 確かめる(まちがいが あれば 止まる)。
