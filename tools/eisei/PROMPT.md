# フリック衛生管理者: ことばの 作りかた(助手に 分けて 頼むときの 決まり)

けいくん 2026-11-10「**衛生管理者に 受かる レベル**に なれるように フリック問題で まとめてください」。名前は **フリック衛生管理者**(第一種衛生管理者 免許試験の 範囲。第二種の 範囲は その 中の 一部)。
**1,000語(10の 旅 × 100語 = 入門15・中級30・上級55)**。ほかに ⭕❌ 一問一答(`MARU.md`)と 🔢 数字クイズ(`NUM.md`)が ある。

## ⚠️⚠️⚠️ いちばん 大事な 決まり(さいしょに 読む)
1. ⭐⭐ **数字は 法令・公式の 資料で 決まった ものを 書く**(衛生管理者の 合否を 分ける)。**`tools/eisei/facts-A.md`・`facts-B.md`・`facts-C.md`(確かめた 事実の 一覧)に ある 数字だけ**を 使う。
   無い 数字は WebSearch で e-Gov(条文)・厚生労働省・安全衛生技術試験協会の ページで 確かめてから。**記憶で 書かない**。確かめられない ものは 入れない
   ❌ 書かない 数字: 合格率・合格点の 中身を 約束する 言いかた・実在の 会社の 事故の 件数・毎年 変わる 統計
2. ⭐⭐ **いまの 法令が 答え**(2026年11月 時点)。facts の「⚠️ 古い テキストと ちがう ところ」を かならず 読む(事務所衛生基準規則の 照度 2022年12月 / 化学物質の 自律的管理 2024年4月 / 熱中症対策の 義務化 2025年6月 / ストレスチェックの 対象の 拡大 / 女性の 就業制限 など)。
   古い 名前・古い 答えは **name に しない**。説明に「前は ◯◯でした」の 1文だけ
3. **法令の ことばづかいに そろえる**(衛生管理者・産業医・総括安全衛生管理者・特定業務従事者・特別教育・作業主任者・局所排気装置 …)。くだけた 名前は 説明の 中で「◯◯とも いいます」
4. ⭐ **科目の 札(ruleset)を 正しく**: 関係法令(有害以外) / 関係法令(有害業務) / 労働衛生(有害以外) / 労働衛生(有害業務) / 労働生理。
   有害業務の 法令(有機則・特化則・鉛則・電離則・酸欠則・粉じん則・石綿則・作業主任者・作業環境測定・特殊健康診断 など)は **関係法令(有害業務)**。有害要因・職業性疾病・保護具・局所排気は **労働衛生(有害業務)**。
   第二種の 人が 出る 範囲は「有害以外」と「労働生理」
5. ⭐ **手当て・処置の やりかたを 書かない**(胸骨圧迫の 深さ・回数・速さ / 薬の 量 / 診断の 決めうち / 行動の 指示)。**名前と「何の ための 手当て・しくみか」だけ**。
   「やりかたは 救命講習で 習います」と そえて よい。病気は 事実だけ おだやかに(こわがらせない)。死・自殺・殺 の 字は 使わない(`terms_js.py` の `BAN`)。⚠️ 「殺菌」「死傷病報告」は 法令の ことばなので 通る
6. **人を こわがらせない・だれかを わるく 言わない**(会社・上司・働く 人)。トラブルは「どう ふせぐか」で 書く
7. **実在の 会社・製品・事故の 名前を 書かない**。役所(厚生労働省・労働基準監督署・労働局)・公的な 団体(安全衛生技術試験協会・中央労働災害防止協会・日本産業衛生学会)は よい
8. **本物の 試験問題・過去問・問題集・テキストの 文を 写さない**。自分の ことばで
9. **小学生も あそぶ**。入門は「働く 人なら 知っておきたい」くらしの ことば(健康診断・手洗い・換気・休けい・熱中症・ストレス など)。やさしい です・ます。迷ったら 入れない

## ゲームの かたち
「表示された ひらがなを フリックで 打ち写す」タイピング。打ち終わると 説明(1〜3文)が 出る。説明の 下に 📘 分野 と 📝 科目の 札。

## 旅ごとの 語数
**100語: difficulty 1 を 15語、2 を 30語、3 を 55語**。同じ difficulty の 中は 大事な・試験に よく 出る 順。JSON の 配列も 1 → 2 → 3 の 順。
⭐ 入門の くらしの ことば(健康診断・手あらい・うがい・マスク・換気・休けい・水分補給・ストレッチ・睡眠 など)は 各旅に 散らして よい(その 旅の テーマに 近い ものを)

## ほかの ゲームと かぶる 語
医師・看護師・薬剤師・救急隊員(からだ・病気)・弁護士(法律)・からだ図鑑と 同じ 語を 入れて よい(けいくん決定 2026-09-30)。説明は **衛生管理者の 目線**(職場で どう 使うか)で 書きなおす
