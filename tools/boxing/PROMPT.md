# フリックワールドボクシング: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

## ⚠️⚠️⚠️ いちばん はじめに 読む: 入れない もの(ボクシングだけ ほかの スポーツより ずっと きびしい)

ボクシングは 人を なぐる 競技。でも この ゲームは **小学生も あそぶ**。けいくんは **子どもの スクールの 先生**。
だから 書くのは **技・ルール・歴史・ことば だけ**。

- ❌❌❌ **なぐられた 側の ようすを 1語も 書かない**。技は **出す 側の 動き**として だけ(「腰の 回転で 横から 打つ パンチです」まで)。
  「相手が 倒れる」「効く」「あごを 打ちぬく」「ふらつく」「ダメージ」「沈める」は 書かない
- ❌❌❌ **ケガ・血・脳・意識・死亡事故・病気**は 1語も 入れない(カットマンは「名前と 役目」だけ。何を 手当てするかは 書かない)
- ❌ **KO・TKO・ダウン・カウント・負傷判定・タオル**は **ルールの ことばの 意味だけ**。だれが どう 倒れたかは 書かない
- ❌ **名勝負は「名勝負」として だけ**。だれが 勝ったか・倒れたか・敗者の 名前は 書かない。⚠️ **負けた 選手の 名前を 答えに しない**
- ❌ **減量の 苦しさ・体重超過の 事件**・**薬物・ドーピング**・**八百長・賭け**・**事件・逮捕・私生活**・**ファイトマネー・お金**・
  **けんか・にらみあい(フェイスオフ)・挑発・暴言**・**団体どうしの もめごと**(IBA と World Boxing は 事実 1行まで)
- ❌ **いまの ベルト・いまの 戦績(◯勝◯敗)・ランキング・PFP の 順位・いまの 所属ジム・いまの 階級**(変わる)
- ❌ **グローブ・シューズの 商品名・メーカー名・スポンサー名**
- ❌ **まんが・アニメ・映画の 中の 技・登場人物**(『はじめの一歩』『あしたのジョー』の 技の 名前も)。映画『ロッキー』は **作品名を 事実として 1語なら よい**(あらすじは 書かない)
- **迷ったら 入れない**。事件・薬物・私生活で 知られる 選手は **入れない**(功績が 大きくても)。下の「入れない 人」を 見る
- 台本 `terms_js.py` が「血・傷・痛・倒れ・効い・脳・死・KO勝・◯勝◯敗・円・ドル・歳」などを 止める

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
どの 国の 話か(国旗の 札)・プロの 話か アマの 話か(ルールの 札)・学ぶ 分野・しくみ図の どこに あるか(📍)が 出る。
あそぶのは **ボクシングが すきな 小学生〜中高生・ジムに 通う 人・ボクシングが すきな 大人・解説者を めざす 人**。
**ボクシングの ことばと 意味を おぼえる ゲーム**(ニュースでも、記録集でも ない)。
もとは `tools/baseball/PROMPT.md`(ワールドベースボール)。けいくん 2026-10-12「ワールドボクシングの専門家(解説者)になれるレベルになるために必要な 知識、
主要な団体、有名ボクシング選手、有名な技、ルールをフリック形式の問題にしてください」→ 5つの 問いに「すべておまかせ」。
⭐ けいくんは **スポーツの 指導者**。まちがいは すぐ 気づかれる。**選手と 国・技と 使い手・年と 達成・ルールと プロ / アマ** は かならず 確かめて から 書く。

## ⚠️⚠️ この ゲームで 大事な 8つ

### 1. ⭐⭐ 数字が 変わる ものを 書かない
- ❌ いまの ベルト(防衛・返上・陥落で 変わる)・いまの 戦績・ランキング・PFP の 順位・ファイトマネー・いまの 所属ジム・いまの 階級・年齢
- ✅ **変わらない 事実は よい**: 国籍・かまえ(オーソドックス / サウスポー)・**得意な パンチ / スタイルの 特徴 / 異名**・
  **過去の 達成と その 年**(「2022年に バンタム級で 4団体を 統一した」)・**オリンピックの メダルと 年**・**引退した 選手の 記録**(`exam.txt` で 確かめた ものだけ)・
  **階級の 体重の 上限**(ポンドと kg)・ラウンドの 数・ジャッジの 人数

### 2. ⭐⭐ いまの スター選手(`star`)の 書きかた
- 「**日本の ボクサー。2022年に バンタム級で 4団体を 統一した。異名は 「モンスター」**」の ように **国・達成の 年・かまえ・スタイル・異名**で 書く
- ❌ いまの ベルト・戦績・所属ジム・プロモーター・「無敗」「連勝」「防衛中」は 書かない(台本が 止める)
- ⚠️ `exam.txt` の ⑦ で **現役と 確かめた 人**と、**入れない 人**を 見る。そこに 無い 人を 入れる ときは web で 確かめる(引退・事件・薬物)

### 3. ⭐⭐ ルールは プロと アマが ちがう(`ruleset` の 札)
- **プロ** = JBC(日本ボクシングコミッション)と 4団体(WBA・WBC・IBF・WBO)/ **アマ** = オリンピック・World Boxing・日本ボクシング連盟 / どちらも 同じなら **共通**
- ルールの 語には **`ruleset`** を 付ける(`"プロ"` `"アマ"` `"共通"`。「プロ・アマ」の ように 2つでも よい)。**説明にも どちらの 話か かならず 書く**(書いて いない 説明は まちがいに なる)
- 「3分 × 12ラウンド」は **プロの 世界タイトルマッチ**。アマは 3ラウンド。⚠️ 団体・興行で ちがう ルール(スリーノックダウン制 など)は「団体や 試合に よって ちがう」と 書く
- 事実は `tools/boxing/exam.txt` に 合わせる。そこに 無い 細かい 数字は 書かない。規則の 番号(第◯条)は 書かない

### 4. 実在の 選手・団体・ジム・会場の 名前は 入れて よい(事実として)
- ✅ 名前は よい。❌ 商品名・メーカー名・スポンサー名・会場の 命名権の 会社名
- カタカナは **日本の 新聞・JBC で よく 使う 書きかた**に そろえる(モハメド・アリ・マニー・パッキャオ・オレクサンドル・ウシク)
- ⭐ **階級名は 団体で 呼び名が ちがう**(スーパーフライ級 = ジュニアバンタム級 など)。**答えは 日本で よく 使う ほう(スーパー◯◯級・ミニマム級)に 決めて、もう片方は `acceptedReadings` で 受ける**。
  英字の 略語(WBA など)は 読みを reading に

### 5. 人を けなさない
- 「負けた 選手」「弱い 選手」の 書きかたを しない。ライバルは「名勝負を くりひろげた」まで
- ⭐ **ジョー・ルイス・モハメド・アリ**は「**壁を こえた 前向きな 話**」として。「差別」「人種」の 字は 使わない。⚠️ アリの 病気・兵役の 話は 書かない
- 亡くなった 名選手も 入れて よいが「亡くなった」とは 書かない(功績で 書く)

### 6. ラフプレー・反則を すすめない
- ローブロー・バッティング・ホールディング・ラビットパンチ・肘打ちは **反則の 名前と「してはいけない」**として だけ。どう あたると 危ないかは 書かない
- ⭐ **技は「練習で 身に つける 技」**として
- ⚠️ **技の 名前の もとは 説が 分かれる**。「◯◯が はじめた」と 言いきらず「◯◯の 得意技として 有名」「◯◯が 広めた」まで(`exam.txt` ⑨)

### 7. 事実を 正しく(⭐ かならず 確かめる)
- **選手と 国・技と 使い手・年と 達成・団体の 本部と 年・階級の 体重・ルールの プロ / アマ**は `exam.txt` に 合わせる。無い ものは web で 確かめてから。あやしい 語は 入れない
- **自分の ことばで 書く**(Wikipedia・公式の 文を 写さない)

### 8. ほかの ゲームと 同じ 語は よい(説明は ボクシングの 目線)
- **カウンター**(サッカーにも ある)・**ガード**(バスケの ポジション)・**フック**(バスケの フックショット)・**MVP**・**ラウンド** は **ボクシングでの 意味**で 書く

## 1語の 形(JSON)

```json
{"id":"wz-dempseyroll","name":"デンプシーロール","reading":"でんぷしーろーる","journey":"waza","category":"名前の ついた パンチ","difficulty":2,
 "field":"パンチと防御","type":"concept","emoji":"🌀","mapNode":"waza:named","relatedTerms":["wz-weaving"],"country":"アメリカ",
 "description":"上体を 8の字を えがく ように ゆらしながら、左右の フックを つづけて 打つ 技です。1920年代の ヘビー級王者 ジャック・デンプシーの 得意技として 有名です。"}
```
```json
{"id":"rl-tenpoint","name":"10点法","reading":"じってんほう","journey":"rule","category":"採点","difficulty":2,
 "field":"ルール","type":"concept","emoji":"📝","mapNode":"rule:score","relatedTerms":["rl-judge"],"ruleset":"共通","acceptedReadings":["じってんほう","じゅってんほう"],
 "description":"ラウンドごとに、取った 選手に 10点、もう ひとりに 9点 などを つける 採点の しかたです。プロでも アマでも 使われ、正しくは 「10ポイント・マスト・システム」と いいます。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(日本の 新聞・JBC で ふつうに 使う 書きかた)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白・「・」は ダメ)
  - カタカナ語は ひらがなで(サウスポー → さうすぽー)。「・」は 取る(モハメド・アリ → もはめどあり)
  - 英字の 名前は 読みで(WBA → だぶりゅーびーえー / KO → けーおー / TKO → てぃーけーおー / PFP → ぴーえふぴー)
  - ゆれる ことばは いちばん ふつうの 読みを reading に、ほかを `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は 上級だけ・旅で 1〜2語まで
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級
- **field**: 学ぶ 分野。次の 7つの どれか: `ルール` / `パンチと防御` / `戦術` / `団体・階級` / `選手` / `大会・歴史` / `用具・練習`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(🩸 💀 ☠️ 🔪 🤕 🚑 😭 😱 💢 😵 💫 🥵 は 使わない。🥊 ばかりに しない。国旗の 絵文字は 使わない(札で 出る ため))
- **country**(**関係が あれば 付ける**): その 選手・団体・技・大会が どの 国の 話か。
  `世界` `北アメリカ` `中南米` `アジア` `ヨーロッパ` `アフリカ` `オセアニア` `日本` `アメリカ` `カナダ` `メキシコ` `プエルトリコ` `キューバ` `パナマ` `ニカラグア` `アルゼンチン`
  `イギリス` `アイルランド` `フランス` `ウクライナ` `ロシア` `カザフスタン` `ウズベキスタン` `フィリピン` `タイ` `韓国` `中国` `オーストラリア` `ニュージーランド` `ガーナ` `コンゴ民主共和国` の どれか。
  2〜3つなら「・」で。選手は **国籍**。きほんの ことばなど 国と 関係ない 語は 付けない
- **ruleset**(**ルールの 語だけ**。`rule` の 旅は ぜんぶ・ほかの 旅でも ルールに かかわる 語は 付けて よい): `プロ` `アマ` `共通`(「プロ・アマ」の ように 2つまで)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / どんな 特徴か / へえ」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  文体は **はじめから「〜です・ます」**。「1人」「2人」は ふりがなが 読みまちがえるので **ひとり・ふたり** に 言いかえる
- 「へえ」を 1文 入れると よい(「赤コーナーは ふつう 王者や 上位の 選手」「後楽園ホールは 日本の ボクシングの 聖地」)

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | **ボクシングが すきな 小学生**。用具・きほんの パンチ・有名な 選手の 名前・4大団体 |
| 2 | 中級 | **ジムに 通う 人・ボクシングが すきな 大人**。ルール・階級・判定・技の 中身・プロと アマの ちがい |
| 3 | 上級 | **解説者**。戦術の ことば・ジャッジの 見かた・団体の しくみ・歴史・名トレーナー |

**1つの 旅に 70語: difficulty 1 を 20語、2 を 25語、3 を 25語**。同じ difficulty の 中は **よく 知られている 順**に ならべる。
