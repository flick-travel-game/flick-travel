# フリックスーパーカー: ことばの 作りかた(助手に 分けて 頼むときの 決まり)

けいくん 2026-10-21「すべてのスーパーカー、ハイパーカーを 知っている 専門家レベルになるために必要な知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」・ブガッティは「両方に入れて歴史の説明を書く」・約1,000語+📷写真クイズ・並びは「サッカーのすぐあと」。
もとは `tools/cabin/PROMPT.md`(キャビンアテンダント)と `tools/soccer/PROMPT.md`(サッカー)・`tools/seibi/PROMPT.md`(整備士)。まとめは `docs/フリックスーパーカー-はじめかた.md`

## ⚠️⚠️⚠️ いちばん 大事な 決まり(さいしょに 読む)
1. ⭐⭐⭐ **変わる 数字・ぶれる 数字を 答えに しない**(この ゲームで いちばん 事故が 起きやすい)
   - ❌ 書かない: **値段**(新車も オークションも 中古も)・**いま 売っているか / 生産が 終わったか**(変わる)・**最高速の 順位・「世界最速」**・**ニュルの タイムと 順位**・**確かめられない 生産台数**
   - ✅ 書いて よい: メーカーと 国・本社の 町・**発表した 年**・エンジンの 形(V12 など)・エンジンの 場所・ドアの 形・デザイナー・名前の 由来・**限定車の 予定台数(メーカーの 発表で 確かめた ものだけ)**
   - 馬力・最高速は 説明の 中に「◯◯馬力 ほど(メーカーの 公表値)」と **まるめて** 書くのは よい。**答えの 手がかりに しない**。自信が なければ 書かない
2. ⭐⭐ **スピードを あおらない**。子どもが 遊ぶ ゲーム。最高速・加速は **「テストコースで」「サーキットで」の 話**と はっきり 書く。
   「公道」「飛ばす」「スピード違反」「暴走」「ゼロヨン」「違法改造」の 字は 使わない(`terms_js.py` が 止める)。「速く 走ると かっこいい」と 書かない。車の すごさは **しくみ・デザイン・歴史**で 書く
3. ⭐ **お金の 話を しない**。「◯億円」「◯万円」「高い 車」「お金持ちの 車」「値段」「価格」「オークション」と 書かない。**持ち主の 有名人**も 書かない
4. **事故・死・燃えた 車・こわれた 車**を 入れない(⚠️ 有名人の 事故・ル・マンの 事故も)。亡くなった 人は 功績だけ(「亡くなった」とも 書かない)
5. ✅ **実在の メーカー・車名・人の 名前は 入れて よい**(事実と して。サッカーと 同じ)。⚠️ **ロゴ・エンブレムの 絵・メーカーの 宣伝文**は 入れない。**悪く 言う・くらべて けなす 書きかたを しない**
6. **数字・年・名前は まちがいない ものだけ**。記憶で あやしい ものは 書かない・入れない。デザイナーは 説が 分かれる 車が ある →「◯◯の デザインと して 知られる」と **言える ところまで**。名前の 由来も 説が 分かれる ものは「と 言われる」
7. **自分の ことばで 書く**。メーカーの サイト・Wikipedia・雑誌の 文を 写さない

## ゲームの かたち
「表示された ひらがなを フリックで 打ち写す」タイピング。打ち終わると ことばの 説明(1〜3文)が 出る。
遊ぶのは 車が すきな 小学生〜専門家。**スーパーカーの ことばを おぼえる ゲーム**

## 1語の 形(JSON)
{"id":"it-countach","name":"ランボルギーニ・カウンタック","reading":"かうんたっく","journey":"italia","category":"ランボルギーニの 車","difficulty":1,"type":"concept",
 "emoji":"🟡","mapNode":"italia:lambocar","field":"車","relatedTerms":["it-lamborghini","it-miura"],
 "country":"イタリア","maker":"ランボルギーニ","year":1971,"ei":"Countach",
 "description":"ランボルギーニの 車です。くさびの ような 平たい 形と、上に はね上がる ドアで 知られます。名前は イタリアの ピエモンテ地方で おどろいた ときに 言う ことば と 言われます。"}

- id: 旅の 頭文字2つ + "-" + 英小文字(ki- / gi- / it- / de- / gb- / sk- / jp- / hy- / dn-)。英小文字・数字・- だけ
- name: 画面に 出す 名前。⭐ **車は メーカー名を つけた 名前**(「ランボルギーニ・カウンタック」「ホンダ NSX」「フェラーリ F40」)。同じ 名前の 車が いくつも ある ため
- reading: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白は ダメ)
  - 車名は **日本で ふつうに 使う カタカナ読みを ひらがなで**(「かうんたっく」)。長く なりすぎる ときは 車名だけ(メーカー名は name に ある)
  - 英字・数字は 日本の ふつうの 読み(F40 → えふよんじゅう / NSX → えぬえすえっくす / GT-R → じーてぃーあーる / 911 → きゅういちいち / V12 → ぶいじゅうに)
  - ゆれる ことばは 1つに 決め、別の 読みは "acceptedReadings":["よみ1","よみ2"](先頭は reading と 同じ)
  - ⚠️ **読みは この ゲームの 9つの 旅の 中で かぶらない**(同じ 読みの 語を 2つ 入れない)
- difficulty: 1 = 入門(車が すきな 小学生) / 2 = 中級(車好きの 大人) / 3 = 上級(専門家)
- type: いつも "concept"
- category: 図鑑で しぼる 分類(短い 日本語。旅の 中で 4〜8種類)
- emoji: 1つ(⚠️ 国旗の 絵文字は 使わない。国は country で 出る)
- mapNode: その 旅の 図の 場所(下の 表から)
- field: **メーカー / 車 / しくみ / デザイン / レース / 人 / 歴史** の どれか
- relatedTerms: **同じ 旅の** id を 1〜3個(自分は ダメ)
- ⭐ country: **任意**(メーカー・車・人・町の 語には 付ける)。**イタリア / ドイツ / イギリス / フランス / スウェーデン / クロアチア / オランダ / デンマーク / アメリカ / 日本 / オーストリア / スイス / スペイン / ベルギー / モナコ / ニュージーランド / アルゼンチン / チェコ / メキシコ / ペルー / オーストラリア / 中国 / 韓国 / レバノン / 南アフリカ / モロッコ / 世界** の どれか(「・」で 3つまで)。
  ⚠️ **会社の 国**で 付ける(親会社の 国では ない: ランボルギーニ = イタリア・ブガッティ = フランス・ベントレー = イギリス)。⚠️ 人は 生まれた 国
- ⭐ maker: **任意**(車の 語・メーカーの 語に 付ける)。メーカーの 日本語の 名前(「フェラーリ」「ランボルギーニ」「メルセデス・ベンツ」「マクラーレン」)。**字だけ**(ロゴは 出さない)
- ⭐ year: **任意**(車の 語に 付ける)。**発表した 年**(数字。1971)。⚠️ 生産の 年・日本で 売った 年と まぜない。自信が なければ 付けない
- ei: **任意**。英語(または その 国の ことば)の 本当の つづり(Countach / Chiron / Huayra)。🔊 で 読む。英字・数字・空白・- . ' だけ(アクセント記号は 外す)
- description: 1〜3文・**130字以内**。やさしい です・ます。語と 語の あいだに 半角スペースを 入れる 書きかた(上の 例のように)。
  **カタカナ語を ならべない**。ふつうの 言葉で 言いかえて から 専門の 名前。⭐ ときどき「へえ」と 思える 事実を 1文(⚠️ 頭に「へえ:」とは 書かない。🔊 よみあげで 読まれる)
- example: なくてもよい

## 旅の 分けかたの 決まり(読みが かさならない ように)
- ⭐ **車は 国の 旅に**(italia / doitsu / igirisu / sekai / nihon)。**hyper は「ことば・技術・記録の 話」**に 寄せる(ハイパーカーの 車そのものは なるべく 国の 旅。hyper に 入れて よいのは 国の 旅に 入らなかった ハイパーカーだけ)。
  **densetsu は「ブーム・年代・ル・マン・デザイナー・カロッツェリア・創業者」**(ミウラ・カウンタック・F40 などの 車そのものは 国の 旅。densetsu では「スーパーカー消しゴム」「ガンディーニ」の ような 話)
- ⭐ **ブガッティ**(けいくん「両方に入れて歴史の説明を書く」): sekai に **メーカー「ブガッティ」**(country フランス・モルスハイム・ヴェイロン・シロン …)。doitsu には **別の 読みの 語**で 歴史を 書く(例: 「ブガッティの 復活」= 1998年に フォルクスワーゲングループが ブランドを 手に入れ、モルスハイムで ヴェイロンを 作った 話。country は フランス・ドイツ)。⚠️ 読みが かぶらない ように
- 整備士・サッカーと 同じ 語を 入れて よい。説明は **スーパーカーの 目線**で 書きなおす

## 旅ごとの 語数
**110語: difficulty 1 を 30語、2 を 40語、3 を 40語**。同じ difficulty の 中は 有名な・大事な 順。
書く ときは 1回目 70語 = 20 / 25 / 25 と 2回目 40語 = 10 / 15 / 15 に 分けて 頼んだが、⭐ **2026-10-21 に 110語 ぜんぶ 確かめ終わったので、まとめて `tools/supercar/terms-<旅>.json` に して 出した**(990語。あとから 足すと ステージの 中身が 入れかわるため、はじめから ぜんぶで 出した)。`later/` は もう 無い。語を 足す ときは うしろに つなぐ(前の 語の 順番・中身は 変えない)

## 入れない もの(けいくん 2026-10-21「全部おすすめで」)
値段・オークションの 値段・中古の 相場・年収・お金持ちの 自慢・持ち主の 有名人・事故(有名人の 事故・ル・マンの 事故も)・公道の スピード・違法改造・ゼロヨン・暴走・ロゴ・エンブレムの 絵・メーカーの 宣伝文を そのまま 写す・実在の 人の 顔写真・戦争の 話(軍の 車・戦闘機の エンジン …)

## 出すもの
`tools/supercar/terms-<旅id>.json` に JSON の 配列で 書く(110語)。
書いたら `python3 tools/supercar/terms_js.py --check --with-later` で 確かめる
