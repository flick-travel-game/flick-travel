# フリック美容師: ことばの 作りかた(助手に 旅ごとに 分けて 頼むときの 決まり)

ゲームは「画面に 出た ひらがなを フリックで 打ち写す」タイピング。打ち終わると その ことばの 意味(1〜3文)と、
しくみ図の どこに あるか(📍)が 出る。あそぶのは **小学生〜美容師を めざす 学生・大人**。
**美容の ことばと 意味を おぼえる ゲーム**(試験の 問題集でも、美容の 手引きでも ない)。
けいくん 2026-09-29「**美容師になれるレベルで**」→ 中級・上級で **美容師国家試験の 筆記の 範囲を ひととおり** ふくむ。

## ⚠️⚠️⚠️ この ゲームで いちばん 大事な 3つ

### 1. やりかたを 書かない(いちばん 大事)
- ❌ **書かない**: パーマ液・カラー剤・ブリーチ剤の 混ぜかた・置く 時間・薬の 濃さ・消毒液の 濃さや つける 時間・
  カットの 手順(何cm・何度で 引き出す)・かみそりの 使いかた・「こう すれば こう なる」の 手引き
- ⭕ **書く**: その ことばが **何を さすか**・**何の ために あるか**・どこで 出てくるか
  (例: パッチテスト = 髪を 染める 前に、うでの 内がわなどで かぶれないかを 調べる こと。お店や 薬の 説明書の きまりに したがって 行います)
- **数字は なるべく 出さない**(薬の 濃さ・時間・温度・pH の 数・%)。**「%」「分置く」「倍に うすめる」は 台本が 止める**。
  どうしても 要る ときは「だいたいの めやす」と 書き、**まちがいない ものだけ**(毛髪の 本数・生える 速さ など も 書かない ほうが よい)
- ⚠️ **自分の 髪や 人の 髪で ためしたく なる 書きかたを しない**。はさみ・かみそりは **刃物**、薬は **美容師さんが 使う もの** と 分かるように

### 2. 見た目の ことを わるく 言わない
美容は「きれいに なる」話。**子どもも あそぶ**ので、気にしている 子が いる。
- ❌ 書かない: くせ毛・白髪・うすい 髪・そばかす・肌の 色・体つき を **こまった もの・なおす もの**として 書く 言いかた。
  「かっこわるい」「悩み」「コンプレックス」「ごまかす」「かくす」(台本が いくつか 止める)
- ⭕ 書く: **その 人に 合う ものを えらぶ 仕事**として(例: くせ毛 = うまれつき うねりの ある 髪。その うねりを いかした スタイルも 作れます)
- 皮ふの トラブル(皮膚科学)は「どんな 状態か」+「お店では 気づいたら 無理に 施術せず、お医者さんを すすめる」まで。
  こわい 書きかた・うつる 病気で 人を 責める 書きかたは しない
- 「この 髪型が 一番」「この 商品が よい」と **順位を つけない**

### 3. ほかの ゲームと かぶらせない
**理科旅行・からだ旅行・看護師・保育士・パティシエ …** に もう ある 見出し(ぜんぶで 1万語 くらい)は **入れない**。
一覧は `tools/biyo/other-words.txt`。**同じ 字の 見出しは 台本が 止める**(かぶったら 美容の 言いかたに する)。
例: pH・酸性・中性・還元・酸化・水素結合・静電気(理科)/ たんぱく質・アミノ酸・細菌・ウイルス・アレルギー(からだ)/
消毒・滅菌・手洗い・手指衛生・接触感染・飛沫感染・結核・カルテ・マスク・手袋(看護)は **ダメ**。
→ 「器具消毒」「紫外線消毒器」「顧客カルテ」「シスチン結合」「アルカリカラー」の ように **美容の ことばに する**。
書いたら かならず `grep -x '見出し' tools/biyo/other-words.txt` か 台本で 確かめる

## 1語の 形(JSON)

```json
{"id":"ke-cuticle","name":"キューティクル","reading":"きゅーてぃくる","journey":"kami","category":"髪の断面","difficulty":2,
 "field":"人体の構造及び機能","type":"concept","emoji":"🐟","mapNode":"kami:cuticle","relatedTerms":["ke-cortex"],
 "description":"髪の いちばん 外がわの 層。うろこの ように 重なって、髪の 中を 守って います。"}
```

- **id**: 旅の 頭 + `-` + 英小文字(下の 表)。英小文字・数字・`-` だけ
- **name**: 画面に 出す 名前(美容の 現場・教科書で ふつうに 使う 言いかた。漢字・カタカナ)
- **reading**: 打つ ひらがな。**ひらがなと ー だけ**(カタカナ・英字・数字・記号・空白は ダメ)
  - カタカナ語は ひらがなに(わいんでぃんぐ)。英字は 読みを ひらがなに(UV → ゆーぶい。ただし 英字の 見出しは なるべく さける)
  - ゆれる ことばは 1つに 決め、別の 読みは `"acceptedReadings":["よみ1","よみ2"]`(**先頭は reading と 同じ**)
  - ⚠️ **20字を こえる 読みは 入れない**。16〜20字は **上級だけ**に、旅で 1〜2語まで
  - ⚠️ **読みを まちがえやすい ことば**は 1語ずつ 確かめる: 皮脂 ひし・毛根 もうこん・毛周期 もうしゅうき・頭皮 とうひ・
    香粧品 こうしょうひん・美容所 びようじょ・毛包 もうほう・毛乳頭 もうにゅうとう・立毛筋 りつもうきん・皮脂腺 ひしせん・
    汗腺 かんせん(感染と 同じ 読み!→ どちらかの 旅だけ)・角化 かくか・結髪 けっぱつ・日本髪 にほんがみ・髷 まげ・
    簪 かんざし・笄 こうがい・剃刀 かみそり・鋏 はさみ・梳き鋏 すきばさみ・毛先 けさき・生え際 はえぎわ・襟足 えりあし・
    疥癬 かいせん・白癬 はくせん・頭じらみ あたまじらみ・伝染性軟属腫 でんせんせいなんぞくしゅ・界面活性剤 かいめんかっせいざい・
    両性 りょうせい・陽イオン よういおん・陰イオン いんいおん・親水基 しんすいき・親油基 しんゆき・医薬部外品 いやくぶがいひん
- **journey**: その 旅の id(下の 表)
- **difficulty**: `1` 入門 / `2` 中級 / `3` 上級(下の「3段の 分けかた」)
- **field**: 美容師国家試験の 筆記の 課目。つぎの 8つの どれか(入門の 語でも いちばん 近い ものを 書く):
  `関係法規・制度及び運営管理` `公衆衛生・環境衛生` `感染症` `衛生管理技術` `人体の構造及び機能` `皮膚科学` `香粧品化学` `文化論及び美容技術理論`
- **type**: いつも `"concept"`
- **category**: 図鑑で しぼる 分類(短い 日本語。**旅の 中で 4〜8種類**に そろえる)
- **emoji**: 1つ(🩸 💀 など こわい 絵文字は さける。✂️ 🪒 の 多用も さける)
- **mapNode**: `"<図の id>:<場所の id>"`。**その 旅の 図だけ**から えらぶ(下の「しくみ図の 場所」)
- **relatedTerms**: **同じ ファイルの 中の** id を **1〜3個**(自分は ダメ)
- **description**: **1〜3文・130字以内**・やさしい です・ます。「何の ことか / どこで 出てくるか / なぜ 大事か」。
  **語と 語の あいだに 半角スペースを 入れる 書きかた**(この シリーズの 文体。上の 例のように)。
  専門用語を 専門用語だけで 説明しない。**「1人」「2人」は ふりがなが おかしく なるので ひらがなで(ひとり・ふたり)**
- **example**: なくてもよい

## 3段の 分けかた

| difficulty | 名前 | どんな ことば |
|---|---|---|
| 1 | 入門 | 美容室で 聞く ことば。小学生でも 聞いた ことが ある / 絵が うかぶ(シャンプー・前髪・ドライヤー・パーマ・ネイル) |
| 2 | 中級 | **美容師国家試験の 筆記の 範囲の めやす**(よく 出る ことば)。美容を 学ぶと 出てくる(ワインディング・キューティクル・界面活性剤・美容所) |
| 3 | 上級 | **美容師国家試験の 範囲の めやす**の こまかい ところ(シスチン結合の 化学・法律の こまかい きまり・髪型の 歴史・皮ふの 病気の 名前) |

**1つの 旅に 80語: difficulty 1 を 20語、2 を 30語、3 を 30語**。同じ difficulty の 中は **よく 知られている 順**に ならべる
(ならんだ 順が そのまま ステージの 順に なる)。
⚠️ けいくん「美容師になれるレベルで」。**中級+上級の 60語で その 課目の 大事な ことばを ひととおり** おさえる(教科書の 目次を 思いうかべて もれを さがす)

## ぜったいに 守ること

- **自分の ことばで 書く**。過去問・問題集・教科書・美容の 本・法律の **本文を 写さない**
- **お店・メーカー・商品の 名前は 使わない**(商標)。「シャンプー」「ドライヤー」の ような 一般の 言いかた
- **数字は まちがいない ときだけ**(法律が できた 年・細かい 数は 書かない)
- 歴史の 人の 話は **「〜と 言われている」** の 形。**事実が あやしい 語は 入れない**(まちがいを 書くより 入れないほうが よい)
- ほかの 旅と **読みが かぶらない**。**ほかの ゲームと 同じ 字の 見出しは 作らない**
- 「100マス計算」「百ます計算」の 字を 使わない
