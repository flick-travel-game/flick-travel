# フリック宅建士: ⭕❌ 一問一答の 作りかた

本物の 宅建試験は **4つから 1つ えらぶ 50問・2時間**。4つの 文の 正しい / まちがいを 見分けられれば 解ける。
この ゲームでは 1つの 文ずつ ⭕❌ で 練習し、🎯 模擬試験では ⭕❌ の 文を 4つ ならべて「正しい(誤っている)ものは どれか」の 4択に する。
合否を 分けるのは **ひっかけ** と **数字**。**約1,200問**。

## 旅ごとの 問題数
kenri 140 / bukken 130 / sozoku 120 / gyoho 150 / torihiki 160 / toshi 130 / kenchiku 130 / zei 110 / kakaku 130(= 1,200)

## 決まり
1. `PROMPT.md` の「いちばん 大事な 決まり」を ぜんぶ 守る(数字は facts-A/B/C.md の ものだけ・いまの 法律が 答え・こわく しない・実在の 会社を 書かない)
2. **答えが 1つに 決まる 文**だけ。判例が 分かれる・場合で 答えが 変わる・あいまいな 文は 作らない。主語(宅建業者が 自ら 売主・買主が 宅建業者 など)を はっきり 書く
3. **⭕ と ❌ は おおよそ 半分ずつ**(各旅 ⭕ 40〜60%)
4. **ひっかけを 多く**(上級は とくに): 「必ず」「一切」「〜できない」「〜しなければならない」「〜しても よい」「自ら 売主」「宅建業者 間の 取引」「善意 / 善意無過失」「以内 / 以上 / 超える / 未満」「知事 / 大臣」「許可 / 届出 / 不要」「事前 / 事後」「遅滞なく / ◯日以内」「取引士で なくても よい」「記名 / 説明」「売買 / 貸借」
   ❌ の 文は **本物らしく 少しだけ ちがう**(数字を 1つ 変える・例外を 消す・主語や 立場を 入れかえる)
5. **とき方**(`why`): なぜ ⭕/❌ か 1〜2文・**90字 以内**。❌ なら 正しい 形を 書く。やさしい です・ます
6. **どの 法律の 話か**(`law`): 「宅建業法37条の2」「民法177条」「借地借家法3条」の ように 法律名 + 条(わかる とき)。**facts に ある 条だけ**。わからなければ 法律名だけ(「民法」)
7. 問題文(`q`): **80字 以内**。試験と 同じ「〜できる。」「〜しなければならない。」の 形で よい(漢字は ふつうに 使う。ふりがなは 付かない)
8. 同じ ことを 聞く 問題を 2つ 作らない(同じ 事実の ⭕版と ❌版も 作らない)
9. **過去問・問題集・テキストの 文を 写さない**。自分の ことばで(「よく 出る 考えかた」を 自分の 文に)
10. `dv`: 1 = 入門(家を 借りる・買う 人が 知っておく こと。各旅 10問ほど)/ 2 = 中級(試験の 基本)/ 3 = 上級(ひっかけ・例外・数字)。上級を 半分 以上
11. `term`: その 問題に いちばん かかわる ことばの id(`terms-<旅>.json` に ある もの。無ければ 書かない)
12. `rs`: 試験の 科目(権利関係 / 宅建業法 / 法令上の制限 / 税・その他 / 免除科目)。**kakaku の 旅は 地価公示・鑑定評価 = 税・その他、住宅金融支援機構・景表法・土地・建物 = 免除科目**

## 形(JSON。`tools/takken/maru-<旅>.json` に 配列で)
{"id":"to-m001","q":"宅建業者が自ら売主となる宅地の売買で、買主が宅建業者でないとき、手付の額は代金の10分の2を超えてはならない。","a":true,
 "why":"自ら 売主で 買主が 宅建業者で ない とき、手付は 代金の 10分の2 まで です。","law":"宅建業法39条","dv":2,"term":"to-tetsukenoseigen","rs":"宅建業法"}
