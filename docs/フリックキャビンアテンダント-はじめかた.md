# フリックキャビンアテンダント(`cabin/`)を 作る ための まとめ(2026-10-20。新しい セッション用)

けいくん 2026-10-20「新しいセッションで フリックキャビンアテンダントを作成したい。**キャビンアテンダントに受かるレベル**になるために必要な知識をフリック形式の問題にしてください」

⭐ いちばん 近い 兄弟は **フリックパイロット(`pilot/`。`docs/フリックパイロット-はじめかた.md`)**(飛行機・空港・無線の ことば・4択クイズ・計算問題の 型)と **フリックマナー(`manner/`)**(接客の ことばづかい・おじぎ)。
救命は **フリック救急隊(`kyukyutai/`)**、英語は **フリック英会話(`eikaiwa/`)**、世界の 都市は **フリック世界旅行**、料理・ワインは **フリック料理人(`chef/`)** と かさなる。
⚠️ ほかの ゲームと ちがう 3つの 気をつけ:
① ⭐ **国家試験が 無い**。キャビンアテンダント(客室乗務員)は **航空会社の 採用試験**(書類・面接・英語・グループ討論・体力・健康診断)で えらばれ、**入社して から 社内の 訓練と 試験**で 乗れる ように なる。
   だから 「受かる レベル」= **採用試験と 入社後の 訓練で 使う ことばを ひととおり 知っている** こと、と けいくんに 伝える(面接の 受け答えや 笑顔は ゲームでは 身に つかない)
② **緊急の 話を こわく 書かない**(パイロットと 同じ。「こうして みんなを 守る」の 向きで)
③ **実在の 航空会社の 名前・制服・社内の マニュアルを 写さない**(商標・社外秘。説明に 出すときは 事実だけ。**「◯◯航空の 採用の コツ」は 書かない**)

## 3. ⚠️⚠️⚠️ ぜったいの 決まり(パイロット・マナー・救急隊と 同じ + この ゲームだけの もの)
- ⭐⭐⭐ **こわく しない**(パイロットと 同じ)。客室乗務員の いちばんの しごとは **みんなを 安全に 守る こと**。緊急の ことばは **「そう ならない ように / なっても 早く 安全に する しくみ」**の 向きで(「落ちる」「墜落」「死」の 字を 使わない。`BAN` で 止める)
- ⭐⭐ **見た目で 決めつけない**: 「きれいな 人が なる しごと」「身長が ◯cm 以上」の ような 書きかたを しない。**だれでも めざせる しごと**、ひつような のは **安全を 守る 力・おもてなしの 心・語学・チームワーク** と 書く。⭐ 男性の 客室乗務員も いる(「スチュワーデス → 客室乗務員」の わけ)
- ⭐ **これで 受かる わけでは ない** と 画面に 書く: 「これは ことばを おぼえる ゲームです。客室乗務員に なるには 航空会社の 採用試験を うけ、入社後の 訓練を うけます」「実在の 航空会社とは 関係ありません」
- **宗教・文化は 決めつけない**(「◯◯の 国の 人は ◯◯」と 書かない。「こういう 決まりを 大事に する 人が いる」)
- **会社名**: 航空会社・機体メーカーは **事実の 説明に 1回なら よい**。ロゴ・制服・広告の ような 書きかた・悪い 例 は しない
- ✅ **ほかの ゲーム(パイロット・マナー・救急隊・英会話・料理人・世界旅行)と 同じ 語を 入れて よい**。説明は **客室乗務員の 目線**で 書きなおす
- **読みは この ゲームの 9つの 旅の 中では かぶらない**(`terms_js.py`)。**先に 9つの 旅の 語の 一覧を 1人の 助手に 作らせて** 置き場所を 決める(`hoan` と `kyumei`(酸素マスク)、`service` と `sekai`(特別食)、`manner` と `eigo`(あいさつ)が かさなりやすい)
- **カタカナ語を ならべない**。**ふつうの 言葉で 言いかえて から** 専門の 名前(「ギャレー = 機内の 小さな 台所」)
- **別の 助手が 1語ずつ 確かめる**(意味・読み・英語の つづり・空港コード・時差・**こわく ないか**・**見た目の 決めつけが ないか**・会社名)。計算問題は **1しゅるいずつ 手で 答えを 確かめる**

## 4. 採用と 訓練の 事実は **その日に 公式の ページで 確かめてから** 書く
`meta.json` の `saiyo` に 確かめた 日を つける。**記憶で 書かない**:
・客室乗務員の **国家資格は 無い**(確かめる)・採用は **航空会社ごと**(新卒 / 既卒 / 契約 など。⚠️ 会社名を ならべない)
・採用試験の ながれの めやす(エントリー → 書類 → 面接(何回か)→ 英語 → 体力・健康診断)
・入社後の **訓練**(保安・救急・サービス。⚠️ 何か月 かは 会社で ちがう)
・役に 立つ 資格の めやす(**TOEIC**・**サービス接遇検定**・**秘書検定**・**普通救命講習** など。⚠️ 「ひつよう」と 書かず「役に 立つ ことが ある」)
⚠️ 「受かる レベル」= **採用試験と 訓練の ことばを ひととおり 知っている**こと、と けいくんに 伝える。**面接・笑顔・ことばづかいの 練習・英語の 力は ゲームの 外で**(ゲームは その 土台)
