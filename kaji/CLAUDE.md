## フリック家事(`kaji/`。けいくん 2026-10-03「主婦の専門家になれるレベルになるために必要な 知識をフリック形式の問題にしてください。お母さんが家族の為に休み無しでどれほど大変で頑張っているかが伝わる内容がいいね。子ども達や家族がお母さんありがとうと言いたくなる内容がいいね」→ 同じ日「フリック家事にした方が良くない!」→「家事にして」。まとめは `docs/フリック家事-はじめかた.md`)

- 名前は「フリック家事」(絵が 届いたら 題名に そろえる。フォルダ名 `kaji` は 変えない)。シリーズの 絵文字は 🏠。`SERIES_ORDER` は **保育士の となり**
- ⚠️ **はじめの 5つの 問いは けいくんに 聞かずに まとめの おすすめの まま 作った**(花屋と 同じ)。ちがう ところが あれば 直す
- ⭐ **いちばん大事な ねらい**: あそんだ 子どもや 家族が「家の 仕事って こんなに ある。おうちの 人 いつも ありがとう」と 気づく こと。
  **名前の ない 家事**(トイレットペーパーの 補充・献立を 考える・学校の 手紙を 読む …)の 旅が この ゲームの 心
- 旅は 10こ(おうちの人の1日 `ichinichi`・料理と献立 `ryori`・洗濯と衣類 `sentaku`・掃除と住まい `soji`・子育て `kosodate`・家計とお金 `kakei`・健康と看病・安全 `kenko`・季節の行事と暮らし `gyoji`・名前のない家事 `namonaki`・家族の心を支える `kokoro`)+ マスター。
  **旅ごとに 70語(入門20・中級25・上級25)= 700語**。かずともの 旅の 名前は **`kj` で はじめる**(kjichinichi / kjryori / kjsentaku / kjsoji / kjkosodate / kjkakei / kjkenko / kjgyoji / kjnamonaki / kjkokoro / kjmas)。作る 前に ぶつからない ことを 確かめた
- むずかしさは 3段: 入門(お手伝いを はじめる 子ども)→ 中級(家事を まかせられる 人。**家庭科(中学・高校)の 範囲の めやす**)→ 上級(家の 仕事の 専門家。**整理収納アドバイザー・食生活アドバイザー・FP3級の 家計の ことばの めやす**)。
  1語ごとに **学ぶ 分野**(`field`)6つ = 家庭科の 分け: 家族・家庭 / 保育 / 食生活 / 衣生活 / 住生活 / 消費生活・環境(中学の 家庭分野 A 家族・家庭生活 / B 衣食住の生活 / C 消費生活・環境 の B を 食・衣・住に 分け、保育を 足した)
- ⭐ **新しい 欄 2つ**(`tools/kaji/terms_js.py` が 形を 見る。どちらも **1旅に 3〜5語だけ**・60字まで):
  ・`arigato` → 「💐 ありがとう ポイント」。「しない」「困らせ」「だめ」「しなさい」「べき」は 止める(責めない・押しつけない)
  ・`otetsudai` → 「🙋 できる お手伝い」。**子ども 1人で 安全な ことだけ**(包丁・火・コンロ・漂白剤・アイロン・薬・高い ところ・電球・熱湯 を 止める)
- ことばは `tools/kaji/terms-<旅>.json`(決まりは `tools/kaji/PROMPT.md`。**どの 語を どの 旅に 入れるかの 一覧**は `tools/kaji/plan.json`)→ `tools/kaji/terms_js.py` → `kaji/terms.js` + `data/kaji.json`。
  しくみは `kaji/kaji.js`(花屋を 写した。4択クイズ あり)。ちがいは
  ・💐 ありがとう ポイント / 🙋 できる お手伝い を こたえた あとの 説明と 図鑑に 出す
  ・**旅を 1つ 終えた(その 旅の 語に ぜんぶ 出会った)とき**「今日、おうちの 人に「ありがとう」を 言って みよう 💐」。**700語 ぜんぶ**なら「家の 仕事の マスター! これを 毎日 休まず やって いるのが おうちの 人です」
  ・ホームに **📊 家の 仕事の 図**(コードで 描く SVG 4枚。⚠️ 時刻・時間の 数字は 書かない・「ある 家の 例」と 書く):
    ⏰ 1日の 時計(白い すきまの ☕ が ひと休み)/ ⛰ 名前の ある 家事 と 水の 下まで 大きい 名前の ない 家事(見つけた 数)/ 🗓 1週間(土日も 休み なし)/ 👕 洗濯の 流れ(仕分け → 洗う → ほす → 取りこむ → たたむ → しまう)。
    図の 下に「家の 仕事を する 人は お母さんだけ では ありません」
  ・しくみ図(箱の 図)は 旅ごとに 10(`tools/kaji/mkmeta.py`)。ホームでは たたんで ある

- ⚠️⚠️ **しない こと**(`PROMPT.md` と `terms_js.py` の `BAN`): 子ども・お父さん・ほかの 家族を 責めない・比べない / 「家事は 女の人の 仕事」と 決めつけない(ふだんは「おうちの 人」)/
  「お母さんが いて あたりまえ」に しない(ひとり親・祖父母・施設で くらす 子も あそぶ)/ 働く 人・家に いる 人を 比べない / 年収の 換算を 書かない / 死・命・血・重い 病気の 字 /
  医療の 判断・薬の 量 / 火・包丁・漂白剤・アイロンの 手順(「おとなが する」まで)/ 洗剤を 混ぜる 化学(「いっしょに 使わない」まで)/ 時間・値段・温度・%の 数字(公式の 番号 #8000・119・171・#7119 は よい)/ 実在の 商品・家電・お店・会社の 名前
