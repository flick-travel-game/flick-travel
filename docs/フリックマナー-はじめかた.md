# フリックマナー(`manner/`)を 作る ための まとめ(2026-10-03。新しい セッション用)

けいくん 2026-10-03「新しいセッションで フリックマナーを作成したい。**マナーの専門家になれるレベル**になるために必要な 知識をフリック形式の問題にしてください」

## ⭐ このゲームの 心(いちばん はじめに 決めて おく)
- **マナーは「相手を 思いやる 気持ちを 形に した もの」**。きまりを おぼえる ゲームでは なく、**「なぜ そう するのか」(相手が うれしい・こまらない ため)** が わかる ゲームに する。
  説明文は かならず **理由**を 書く(例: 「名刺を 両手で わたす = 相手を 大切に 思って いる 気持ちを 伝える ため」)
- ⚠️⚠️ **人を 責めない・はずかしめない**。「マナー違反の 人は …」「こんな ことも 知らないと はずかしい」は 書かない。**知らなかった ことは、知れば いい**
- ⚠️⚠️ **「正解は 1つ」と 決めつけない**。マナーは **地域・家・お店・国・宗教・時代で ちがう**。「〜が 一般的」「〜と される ことが 多い」「〜と いう 考えかたも ある」の 形で
- ⚠️⚠️ **根拠の うすい「新しい マナー」を 入れない**(ネットで 広まった「とっくりの 注ぎ口を 使うのは 失礼」「はんこは おじぎする ように 斜めに 押す」の ような **根拠が はっきり しない もの**)。**ひろく 知られ、本や 検定に のって いる もの だけ**

## 5. 作りかたの 手順(家事の ときと 同じ)
1. けいくんに 2 の 5つを 聞く → 返事を CLAUDE.md に 書く
2. `tools/manner/PROMPT.md` `meta.json` を 作る → **先に 10の 旅の 語の 一覧を 1人の 助手に 作らせて 置き場所を 決める** → 旅ごとに 助手に 70語ずつ 頼む(`PROMPT.md` を そのまま わたす。**助手は 2人ずつ**)→ `terms-<旅>.json`
3. `terms_js.py` で 止められた 語を 直す → 別の 助手が 1語ずつ 確かめる(**理由・責め・決めつけ・根拠・宗教 / 性別・こわさ**)→ ふりがな
4. `manner/manner.js`(kaji.js を 写し、💡 なぜ そうするの? の 表示を 足す)・`build_games.py`・`index.html` の PLUG と SERIES → `python3 tools/build_games.py`
5. 手元で 通す: `python3 -m http.server 8765` → `node tools/play-all.mjs manner/` / `node tools/click-all.mjs manner/`(W=320 も)
6. PR は **rebase で 取りこむ**(この 入れもの)。speed-king は squash。コミットの 末尾は Co-Authored-By と Claude-Session の 2行
7. かずとも `speed-king`: `FLICK_MODES` / `FLICK_LINK_TARGETS` に `manner`(PR → squash)。`HOME_GAMES` は 題名の 絵と OK の あと(章も 聞く)
8. けいくんに ChatGPT で 絵を 頼む 文を わたす。**3つ**:
   ・トップの 絵(1536×1024)。**人物は 画面の 下 3分の1に 小さく**・指5本・首が 見える。明るい 和室と 洋風の レストランが つながった 部屋で、子どもと 白い 犬が ていねいに おじぎ して いる 絵。まわりに お箸・ナイフと フォーク・名刺・のし袋・手紙・地球の 小さな 絵。
     **お葬式の 絵を 入れない**。**宗教の しるしを 描かない**。**実在の ホテル・お店の ロゴを 描かない**。絵の 中の 字は「フリックマナー」だけ・ゲームに 無い 機能の 絵を 入れない。届いたら **まず 字を 切り出して 読む**
   ・四角い 絵(1254px)… **切らずに そのまま アイコンに する**ので、**小さく しても わかる 絵**(おじぎ する 子と 犬 くらい。まわりに 字の 札を ならべない)で 頼む
   ・**題名だけの 透明 PNG**(CLAUDE.md「題名は ChatGPT に 切りぬいてもらう」の 文を そのまま。「フリックマナー」と **はっきり 書く**。⚠️ ChatGPT は 字を 変える(「マナ一」の 長音が 漢数字に なったり「マナー旅行」と 足したり)。**届いた 字を かならず 読む**。かずともの 一覧・規約の 名前は **ロゴの 字に そろえる**)。⚠️ **家事で 題名の 絵が 来ない まま 止まった** ので、トップの 絵と いっしょに 題名も 頼む
9. 絵を 入れたら CLAUDE.md に 節を 書く(名前・旅・語数・確かめた 日・入れなかった 語と 理由(**根拠の うすい マナーで 外した もの**も))

## 6. 気をつける 前例
- 家事(`kaji/`)で 断捨離(商標)・ワンオペ育児(責めに 読める)を 外した。マナーも **責めに 読める 言葉は 外す**
- 哲学(`tetsugaku/`)で「どちらが 正しい を 書かない」「宗教は 中立」に した。マナーも **地域・宗派の ちがいを ならべて、勝ち負けを つけない**
- 国語旅行(`kokugo/`)の 敬語・英会話(`eikaiwa/`)の あいさつ・花屋(`hanaya/`)の 母の日・家事の 行事と かさなる。**同じ 語で よい**が **相手を 思う 目線**で
- 看護師で 統合失調症 → 適応障害に 入れかえた ように、**こわく 感じる ものは 入れない**。お悔やみの 旅で 迷ったら 入れない
- **フォルダ・id・modes 名を まぜない**(`manner`)。作る 前に `tools/build_games.py` の 先頭の 一覧で いまの ゲームを 見る
