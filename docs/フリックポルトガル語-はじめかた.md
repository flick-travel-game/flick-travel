# フリックポルトガル語(`porutogaru/`)を 作る ための まとめ(2026-11-06。新しい セッション用)

けいくん 2026-11-06「ポルトガル語バージョンを まとめてください」

⭐ **フリックスペイン語(`supein/`)の ポルトガル語版**。スペイン語は **作り終わって 動いている**(2026-10-16)ので、**しくみも 決めごとも スペイン語を そのまま 写す**のが いちばん 安全。
⭐ 手本は 3つ: **`supein/`(いちばん 近い)** → `kankoku/`(韓国語)→ `eikaiwa/`(英会話。おおもと)。まとめの 形は `docs/フリックスペイン語-はじめかた.md` と 同じ。
スペイン語と ちがうのは 4つだけ:
① **ブラジルと ポルトガルで 発音・言いかたが かなり ちがう**(スペインと 中南米より 大きい)
② **つづりどおりに 読まない ところが ある**(ブラジルでは de → ぢ・te → ち・語の おわりの o → う・l → う)→ 読みの ひらがなを 表だけで 作れない 語が スペイン語より 多い
③ **鼻に ぬける 音**(ão・ões・ãe・in・um)と 記号(ã õ ç á â ê ô à)
④ **記号だけで 意味が 変わる 大事な 語**が ある(avô = おじいさん / avó = おばあさん)

## 2. はじめに けいくんに 聞く 5つ(スペイン語では「おすすめ」「韓国語と同じ」だった)

### 2-1. ⭐⭐ **打つ 字**(おすすめ: **スペイン語と 同じ**)
- **はじめは 読みの ひらがなを 打つ**。ポルトガル語を 大きく(記号つき。ã õ ç á â ê ô à は 色を かえて)見せて 🔊 を 聞きながら 打つ
- **「⌨️ 打ちかた」で ABC に 切りかえ**(つづりを 打つ)。**記号は 打たなくても 正解**(ã→a・ç→c で くらべる)。記号まで 打てたら「✨ アクセントも ばっちり」
- ⚠️ **記号を はずすと 意味が 変わる 大事な 組は 1つの 短い 文で 両方 見せる**(スペイン語の si / sí と 同じ やりかた):
  **avô(おじいさん)/ avó(おばあさん)**・**pais(親)/ país(国)**・e(と)/ é(〜です)・por / pôr・da / dá・nos / nós・pode / pôde
  例: 「O meu avô e a minha avó」(わたしの おじいさんと おばあさん)

### 2-2. ⭐⭐ **名前と どこの ポルトガル語か**(おすすめ: **ブラジルが 基本 + ポルトガルは 札**)
- 名前は「**フリックポルトガル語**」(10字)。フォルダ `porutogaru`・modes `PORUTOGARU`・旅の id は **`pt` で はじめる**:
  ptkihon / ptw1 / ptw2 / ptw3 / ptw4 / ptgram / pttalk / ptnative / ptmas。
  ⚠️ 2026-11-06 に 確かめた: `flick.ts` と `build_games.py` に `pt…` の 旅は 無い(`index.html` の「ptable」は 理科の 周期表の 札で 旅の id では ない)。`porutogaru` も 空き。**作る 前に もう一度 確かめる**
- **なぜ ブラジルが 基本か**: 話す 人が いちばん 多い・**日本に ブラジルの 人が たくさん 住んでいて 出会う ことが 多い**(学校・まち)・ブラジルの ことばは サッカーの ことばとも つながる
- ポルトガル(とくに リスボン)だけの 言いかた・発音は **`region` の 札**(`BR` / `PT` / 空 = どちらも)。「🇧🇷 ブラジルで よく 使う」「🇵🇹 ポルトガルで よく 使う」。**どちらが 正しい とは 書かない**
  例: バス = ônibus(BR)/ autocarro(PT)、電車 = trem(BR)/ comboio(PT)、朝ごはん = café da manhã(BR)/ pequeno-almoço(PT)、あなた = você(BR)/ tu(PT のふだん)、携帯 = celular(BR)/ telemóvel(PT)
- 🔊 の 声は **`pt-BR`**(ポルトガルの 声 `pt-PT` に する かも 聞く)

### 2-3. **旅の 分けかた**(おすすめ: **スペイン語と 同じ 9つ**)
- 🔤 **発音と つづりの きほん** `ptkihon` 60(⭐ ポルトガル語だけの へえ: **鼻に ぬける 音**(ão = あぅん・ões・mãe(まんい))・**ブラジルでは de = ぢ / te = ち**(Bom dia = ぼん ぢあ)・**語の おわりの o は う**(obrigado = おぶりがーど / おぶりがーどぅ)・**語の おわりの l は う**(Brasil = ぶらじう)・**r ではじまると は行に 近い**(Rio = ひーお)・**ç**(さ行)・**lh = りゃ行 / nh = にゃ行**・**ã õ の なみ線**・アクセント記号の 決まり)
- 🌱 **入門の 単語** `ptw1` 200(数・家族・色・食べもの・動物・からだ・曜日・月・あいさつ(olá / oi / obrigado・obrigada(⭐ 男の人と 女の人で 言いかたが ちがう))。名詞は 性(o / a)を いっしょに)
- 📘 **初級** `ptw2` 200 / 🧭 **中級** `ptw3` 200(⭐ **スペイン語と にているのに 意味が ちがう 語**(note に)・英語と にている 語)/ 🏙 **上級** `ptw4` 200(ことわざ・慣用句)
- 📐 **文法と 活用** `ptgram` 200(**ser と estar**・冠詞と 前置詞の くっつき(de + o = do・em + a = na)・性と 数の 一致・動詞の 活用(規則 / 不規則・過去・未来・命令・接続法)・**você と tu**(ブラジルの ふだんは você)・**a gente**(= nós。ブラジルの 会話で よく 使う)・**縮小辞 -inho / -inha**(cafezinho))
- 💬 **日常会話** `pttalk` 300(15場面 × 20。あいさつ・自己紹介 / 気持ち・あいづち / 聞き返す・たのむ / 食堂(⚠️ お酒の 場面に しない)/ 買い物 / 道案内 / 空港・ホテル / 病院・困ったとき / 電話・約束 / 学校 / 仕事 …。⭐ **日本に 住む ブラジルの 友だちと 話す 場面**(学校・公園・おとなりさん)を 入れると 役に 立つ。**サッカーの 話**は「サッカー」「試合」「ゴール」の ことばまで)
- 🌟 **ネイティブの 表現** `ptnative` 200(あいづち(Legal! / Beleza! / Tá bom / Nossa!)・よく 使う 言いまわし(Tudo bem? / Valeu!)・縮めた 言いかた(tá = está・pra = para・cê = você。上級)・呼びかけ(⚠️ やさしい ものだけ)・**文化の ことば**(Carnaval・festa junina・feijoada・pão de queijo・brigadeiro・açaí・samba・bossa nova・capoeira・fado(🇵🇹)・pastel de nata(🇵🇹)・saudade(⭐ 訳しにくい ことばの 代表))
- 🏆 マスター `ptmas`
- ⚠️ スペイン語と 同じく **1回 10問・スピード記録勝負**。苦手克服・ふくしゅうは 作らない(⚠️ 運転免許だけの 例外は ここには 広げない)

### 2-4. **むずかしさの 4段**(スペイン語と 同じ)
1 入門 = 発音が 読めて あいさつ / 2 初級 = 旅行や まちで 困らない / 3 中級 = 友だちと ふつうに 話せる / 4 上級 = ネイティブ。
画面に 試験の ことば(CELPE-Bras・ポルトガル語検定)は 出さない(作る 側の めやすには よい)

### 2-5. **語数**(おすすめ: **はじめから スペイン語と 同じ 1,560問**)
スペイン語は「はじめから 英会話と 同じ量」で 作って うまく いった。同じ 量で 作る(発音 60 + 単語 4段 × 200 + 文法 200 + 会話 300 + ネイティブ 200)

## 3. ⚠️⚠️⚠️ ぜったいの 決まり(スペイン語の PROMPT.md と 同じ + ポルトガル語だけの もの)
- **ネイティブが いま ふつうに 使う 形**。直訳は ダメ。**記号は 例文・答えとも かならず 正しく**
- **名詞は 性を いっしょに**(o / a)・**形容詞の 性と 数を 合わせる**・**obrigado / obrigada**(言う 人が 男か 女かで 変わる。例文に だれが 言うかを 書く)
- 文の 旅は **`style`(você / tu / o senhor・a senhora / vocês / -)と `who`(だれが だれに)**を かならず 書く。⚠️ お店の人・年上・先生には **o senhor / a senhora**(ていねい)
- ⭐⭐ **読みの ひらがなは 手で 書かない**。`kana_pt.py` の **1つの 表**で 作る(ブラジルの 読み):
  母音 あいうえお / **語の おわりの o → う・e → い**(ブラジル)/ **de → ぢ・te → ち・di → ぢ・ti → ち** / **語の おわりの l → う** / **はじめの r・rr → は行** / **lh → りゃ行・nh → にゃ行** / ç・ce・ci → さ行 / **ão → あぅん・õe → おいん・ãe → あいん** / ch → しゃ行 / j・ge・gi → じゃ行 / x は 語に よって ちがう(しゃ・す・くす)→ `pron` で。
  ⚠️ **スペイン語より 表で 決まらない 語が 多い**(x・e と o の 開き / 閉じ・語の アクセントの 位置)。**`pron` が 要る 語は 助手が 1語ずつ 印を 付けて、別の 助手が 読みを 確かめる**
- ⚠️⚠️ **入れない 語**(`porutogaru_js.py` の `BAN` が 止める。⭐ 次の 人が 足しもどさない ように CLAUDE.md にも 残す):
  ・**国に よって 下品・差別に なる 語**: rapariga(🇵🇹 女の子 / 🇧🇷 下品)・puto(🇵🇹 男の子 / 🇧🇷 下品)・bicha(🇵🇹 行列 / 🇧🇷 差別の 語)・pica・cacete・cu ほか。**迷ったら 入れない**
  ・**記号を はずすと 子どもに 不向きな 語に なる もの**: cocô(うんち)→ coco(ココナツ)と かさなる。⚠️ ABC で coco と 打てば どちらも 正解に なって しまう → **cocô は 入れない**(ココナツは 入れて よい)
  ・悪口・からかいの 言葉(feio・gordo・burro など)・お酒(cachaça・caipirinha)・たばこ・お金もうけ・こわい話・恋愛の 話
  ・**実在の 選手・歌手・クラブ・会社・お店の 名前**(⚠️ サッカーの 国だが 選手名は 入れない)
  ・**政治・歴史の あらそい**(植民地・奴隷・独裁の よしあし)・**貧しさや 治安を 下げて 書く 文**(ファヴェーラを こわい 場所と して 書かない。⚠️ 名前ごと 入れない ほうが 安全)
- ✅ **食べもの・地名・行事の 名前は よい**(フェイジョアーダ・ポン・デ・ケージョ・ブリガデイロ・アサイー・パステル・デ・ナタ・リオデジャネイロ・サンパウロ・リスボン・ポルト・カーニバル)
- ✅ **スペイン語と 同じ 意味の 語を 入れて よい**(復習に なる)。⭐ **にているのに 意味が ちがう 語**(スペイン語の embarazada の ような もの)は note に。⚠️ 子どもに 不向きな ものは 入れない
- **同じ ポルトガル語を 2回 入れない**(記号を はずして くらべる。`porutogaru_js.py` が 止める)
- 日本語は やさしく・訳の 語の あいだに 半角スペースを 入れない(英会話と 同じ)
- 画面に「これは ことばを おぼえる ゲームです」・🔊 は「端末の 読み上げ機能を 使うので、端末に よって 声が ちがいます」・「アクセント記号は 打たなくても 正解に なります」
- **作った 助手とは 別の 助手が 1語ずつ 確かめる**(意味・性と 数・活用・você / o senhor・記号・**ひらがなの 読み**・ブラジル / ポルトガルの 札・子どもに よいか・**国に よって 下品に ならないか**)。⚠️ **ネイティブの 人の 目で 見てもらえる と いちばん よい**(⭐ スクールや まわりに ブラジルの 人が いれば。けいくんに 聞く)

## 4. 事実は **その日に 確かめてから** 書く
- つづり … **1990年の つづりの 取り決め(Acordo Ortográfico)の あとの 形**(ブラジルでは 2016年から、ポルトガルでも 使われている。⚠️ 年は 確かめる)。例: ideia(前は idéia)・voo(前は vôo)・**trema(ü)は 使わない**
- 国ごとの 言いかた … ブラジルと ポルトガルの 辞書(Michaelis・Priberam など)で 確かめる
- 話す 国・人の **数字は 書かない**(変わる)。「ブラジル・ポルトガル・アフリカの 国などで 話されている」まで
- ⚠️ 「ネイティブに なれる レベル」= ネイティブが ふだん 使う ことば・文法・言いまわしを ひととおり 知っている こと、と けいくんに 伝える。**話す・聞く 力は 🔊 と 実際の 会話で 身に つく**(スペイン語と 同じ 伝えかた)

4. `porutogaru/porutogaru.js`(supein.js を 写し、🔊 は pt-BR・`region` は BR / PT)・`build_games.py`・`index.html` の PLUG / SERIES / **SERIES_CHAPTERS** / **`ownTts()` に `portuguese`** → `python3 tools/build_games.py`
5. 手元で 通す: `node tools/play-all.mjs porutogaru/`(ひらがな)/ `play-abc.mjs` を 写して ABC(記号つき・記号なしの 両方)/ `node tools/click-all.mjs porutogaru/`(W=320 も)。⚠️ **🔊 は Playwright では 鳴らないので けいくんの iPhone で 1回 聞いてもらう**
6. PR は **rebase で 取りこむ**(この 入れもの)。speed-king は squash。コミットの 末尾は Co-Authored-By と Claude-Session の 2行
7. かずとも `speed-king`: `FLICK_MODES` に pt… / `FLICK_LINK_TARGETS` に `porutogaru`。`HOME_GAMES` は 絵と OK の あと
8. けいくんに ChatGPT で 絵を 頼む 文を わたす。**3つ**:
   ・トップの 絵(1536×1024)。**人物は 画面の 下 3分の1に 小さく**・指5本・手首から 腕が 1本だけ・首が 見える(CLAUDE.md「人物を 小さく写す」の 6つの 文を かならず 入れる)。
     スペイン語の 絵と 同じ 雰囲気で、**ブラジルの 海と 緑の 山・カラフルな 家なみ・リスボンの 黄色い 路面電車と タイル(アズレージョ)** の 上を、男の子と 白い 犬が 飛んで 旅する 絵。トロピカルな 果物・ギター・カーニバルの 色紙。
     **実在の 建物・像を そっくりに 描かない**(大きな 像の ある 山 などは 描かない)。**お酒・実在の 選手・クラブの ロゴ・国旗の まちがった 形**を 描かない。
     ⚠️ ChatGPT は ã ç を くずす。**ふきだしは Olá! 1つだけか 字なし**。絵の 中の 日本語は「フリックポルトガル語」だけ。届いたら **まず 字を 切り出して 読む**
   ・四角い 絵(1254px)… 男の子と 犬と Olá! の ふきだし 1つ くらい
   ・**題名だけの 透明 PNG**(「フリックポルトガル語」と はっきり。⚠️「フリックポルトガ語」「フリックポルトガル」に なりやすい。**届いた 字を かならず 読む**)
9. 絵を 入れたら CLAUDE.md に 節を 書く(名前・打つ字・どこの ポルトガル語か・旅・語数・確かめた 日・**入れなかった 語と 理由**)

## 6. 気をつける 前例
