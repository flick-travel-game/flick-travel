## フリック料理人(`chef/`。けいくん 2026-09-30「料理人(調理師)になれるレベルになるために必要な 知識をフリック形式の問題にしてください」→ 5つの 問いに「全部おすすめで」+「ワイン・日本酒の 銘柄や 飲みかた・カクテルも入れてください」)

- 名前は「フリック料理人」(絵が 届いたら 題名に そろえる。フォルダ名 `chef` は 変えない)。シリーズの 絵文字は 🍳
- 旅は **8つ**(食材のことば `shokuzai`・切りかたと下ごしらえ `kiri`・調理のわざ `waza`・日本料理 `washoku`・世界の料理 `sekai`・衛生と安全 `eisei`・栄養と食文化 `eiyo`・**お酒と飲みもの `osake`**)+ マスター。
  **旅ごとに 70語(入門20・中級25・上級25)= 560語**。かずともの 旅の 名前は **`f` で はじめる**(fshokuzai / fkiri / fwaza / fwashoku / fsekai / feisei / feiyo / fosake / fmas)
- 🍷 お酒の 旅は **けいくんの 決定**(まとめの おすすめは「料理酒・みりんだけ」だった)。入れたのは 産地(ボルドー など 地名)・ぶどうの 品種・日本酒の 種類・焼酎・カクテルの 一般の 名前・飲みかた・ペアリング・二十歳未満飲酒禁止法。
  ⚠️ **会社・蔵元・ワイナリー・商品の 名前は 入れない**(「銘柄」は 地名・品種・種類で 表す。商標)/ 度数・配分の 数字・酔う 楽しさを すすめる 書きかたは しない / 画面に「お酒は 20歳に なってから」
- むずかしさは 3段: 入門(台所で 聞く)→ 中級(**調理師試験の 6科目の めやす**)→ 上級(プロの 厨房・調理技術技能評価試験・フランス語/中国語の 厨房の ことば)。
  1語ごとに **調理師試験の 科目**(`field` → 画面では 📘 調理師試験の 科目。公衆衛生学 / 食品学 / 栄養学 / 食品衛生学 / 調理理論 / 食文化概論)
- ことばは `tools/chef/terms-<旅>.json`(決まりは `tools/chef/PROMPT.md`)→ `tools/chef/terms_js.py` → `chef/terms.js` + `data/chef.json`。
  しくみは `chef/chef.js`(教師を 写した。4択クイズ あり)。しくみ図は コードで 描く 箱の 図 8つ(食材の たな・まな板・コンロ・和食の 膳・世界の 料理地図・**厨房の 地図**・栄養と 食文化・お酒の たな。`tools/chef/mkmeta.py` が meta.json を 作る)。ホームでは たたんで ある
- 試験・資格の いまの形は `tools/chef/exam.txt`(→ meta.json の `exam`)に **確かめた日つき**(2026年9月30日に e-Gov の 調理師法・食品衛生法施行規則・酒の 法律・厚生労働省・消費者庁・調理技術技能センター・千葉 岩手 群馬 長野県の ページで 確かめた):
  名称独占・都道府県知事の 免許 / 養成施設 1年 以上 か 2年 以上の 実務 → 調理師試験 / 6科目・60問・4択・総得点の 6割 以上で 0点の 科目なし / 指定試験機関(調理技術技能センター)に まかせる 県も ある /
  **調理技能士は いま「調理技術技能評価試験」**(6分野)。合格した 調理師が「専門調理師・調理技能士」。⚠️ **1級・2級は 確かめられなかったので 書かない**(まとめの「1級・2級」は 使わなかった)/
  ふぐは「ふぐ処理者」(都道府県知事などが 認める)/ 調理師は 講習なしで 食品衛生責任者 / HACCP 2021年6月1日 / 特定原材料 9品目(カシューナッツ 2026年4月1日)
- ⚠️⚠️ **小学生も あそぶ**: 包丁・火・油・食中毒は「安全に 使う・食べる 人を 守る」書きかただけ。しょうじょうは「おなかを こわす」まで。手順(油の 温めかた・包丁の 動かしかた)を 書かない。
  **レシピの 数字(分量・温度・時間)は 書かない**(大量調理施設衛生管理マニュアルの 中心温度 75℃ 1分間 以上 だけ 書いた)
- ✅ パティシエ・看護師 など ほかの ゲームと 同じ 語を 入れて よい。読みは **料理人の 8つの 旅の 中で** かぶらない(`terms_js.py` が 止める)。
  懐石料理と 会席料理は 読みが 同じ(かいせきりょうり)なので 懐石は「茶懐石」にした。冬至(とうじ)は 杜氏と かぶるので 入れていない。まな板の使い分けは 衛生の 旅だけ
- `terms_js.py` の `BAN` は 調味料・お酒の 会社や 商品の 名前・こわい 言いかた・レシピの 単位(大さじ・g・mL)・一気飲み を 止める(「殺菌」は 通す)
- ふりがなの 読みまちがいは **料理人の 中だけで** 直す(`terms_js.py` の `FIX`): 乾物(ひもの → かんぶつ)・田楽・白髪ねぎ・生肉・栗・飲茶・花椒・辛さ・しょうぶ湯・原材料・種(しゅ → たね)・うるち米/もち米・アレルギーの 乳・7日間
- 作った 助手とは **別の 助手が 1語ずつ 確かめた**(8つの 旅 ぜんぶ)。直しは でんぷんの老化・IH調理器・ムニエル(粉屋の おかみさん)・ビビンバ・ぬる燗・泡盛(おもに タイ米)・ノンアルコール(20歳未満には すすめられていない)・
  がめ煮(「炒めてから」を 消した = 油の 手順)・火候(reading かこう。ほーほう・ひこう も 通る)など
