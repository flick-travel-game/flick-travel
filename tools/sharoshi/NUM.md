# フリック社労士: 🔢 数字クイズの 作りかた

社労士は **数字が いちばん 多い 試験**(日数・年数・%・人数・時間・円)。数字を 4つから えらぶ クイズ。**約250問**。旅ごとの `tools/sharoshi/num-<旅>.json` に 配列で(id は 旅の 中で n001 から)。roki は **約30問**。

## 決まり
1. **facts に ある 数字だけ**。条文・公式の 資料で 確かめた もの。合格率・統計は 入れない。⚠️ 毎年 4月に 変わる 数字(年金額・保険料率 など)は「◯年度」を 問いに 書く
2. 正解 1つ + まちがい 3つ。まちがいは **試験で まぎらわしい 数字**(30日 ↔ 14日 ↔ 60日 / 45分 ↔ 30分 ↔ 60分 / 2割5分 ↔ 3割5分 ↔ 5割 / 3年 ↔ 5年 ↔ 2年 / 10人 ↔ 30人 ↔ 50人 / 45時間 ↔ 42時間 ↔ 80時間)。同じ 単位で そろえる
3. 問い(`q`): 70字 以内。答えが 数字に なる 形。主語と 条件を はっきり
4. `why`: 90字 以内・やさしい です・ます。`law`: 法令名 + 条
5. `j`: どの 旅か。`rs`: 科目(MARU.md と 同じ)
6. 同じ 数字を 2回 聞かない
